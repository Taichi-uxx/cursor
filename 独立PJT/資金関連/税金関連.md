## 各項目の詳細

### 1. 所得税（+復興特別所得税）

- **課税対象**：事業所得（売上 − 経費 − 青色申告特別控除65万 − 所得控除）
- **税率**：超過累進課税（5%〜45%）
- **概算（売上1,200万時）**：**約96万**
- **納付**：年1回、翌年3月中旬
- **申告**：確定申告（2月16日〜3月15日）

**税率表（速算式）**
| 課税所得 | 税率 | 控除額 |
|---|---|---|
| 〜195万 | 5% | 0 |
| 〜330万 | 10% | 9.75万 |
| 〜695万 | 20% | 42.75万 |
| 〜900万 | 23% | 63.6万 |
| 〜1,800万 | 33% | 153.6万 |
| 〜4,000万 | 40% | 279.6万 |
| 4,000万超 | 45% | 479.6万 |

**復興特別所得税**：所得税額 × 2.1%

---

### 2. 消費税（2割特例）

- **課税対象**：課税売上に対する消費税
- **2割特例の計算**：売上税額の20%を納付
- **概算（売上1,200万時）**：**約24万**
  - 売上税額 = 1,200万 × 10% = 120万
  - 納付税額 = 120万 × 20% = 24万
- **納付**：年1回、翌年3月末
- **申告**：消費税確定申告（1月1日〜3月31日）
- **適用期間**：2026年10月〜2029年9月の課税期間（3年間）
- **注意**：2割特例は届出不要、申告時に選択できる

---

### 3. 住民税（都道府県民税+市区町村民税）

- **課税対象**：前年の所得
- **税率**：所得割 約10%（都道府県4% + 市区町村6%） + 均等割 約5,000円
- **概算（課税所得687万時）**：**約68万**
- **納付**：年4回（6月・8月・10月・翌年1月）
- **申告**：確定申告と連動。別途申告不要
- **通知**：5〜6月に自治体から納付書送付

---

### 4. 個人事業税

- **課税対象**：事業所得 − 事業主控除290万
- **税率**：3〜5%（業種による）
  - マーケティング業／広告業／コンテンツ制作業 → **業種指定なし＝5%が一般的**
- **概算（事業所得835万時）**：**約27万**
  - (835万 − 290万) × 5% = 27.25万
- **納付**：年2回（8月末・11月末）
- **申告**：確定申告と連動。別途申告不要
- **通知**：8月頃に都道府県から納付書送付
- **メリット**：翌年の必要経費として計上できる

---

### 5. 国民健康保険料

- **課税対象**：前年の所得
- **保険料**：地域により差が大きい
- **概算（東京都想定・所得700万時）**：**年約80万**
- **納付**：通常10期分割（6月〜翌年3月）
- **通知**：6月に自治体から納付書送付
- **注意**：所得が上がると翌年から急増する

---

### 6. 国民年金保険料

- **保険料**：定額 月額17,000円（2026年度）
- **年額**：**約20.4万**
- **納付**：毎月納付／2年前納で割引あり
- **前納割引**（口座振替）
  - 6ヶ月前納：約1,160円割引
  - 1年前納：約4,270円割引
  - 2年前納：約16,590円割引
- **付加年金**：月400円追加で将来の年金増額（余裕あれば検討）

---

### 7. 予定納税（該当時）

- **対象**：前年の所得税額が15万円以上
- **納付額**：前年所得税額の1/3ずつ、年2回
- **納付**：7月末（第1期）・11月末（第2期）
- **注意**：確定申告時に精算される（払いすぎなら還付）

**田村さんの場合**：初年度（2027年3月申告）は前年収入がフリーランス扱いではないので発生せず。翌年（2028年）から発生する見込み。

---

### 8. 消費税の中間納付（該当時）

- **対象**：前年の消費税額が48万円超
- **納付**：期中に1〜11回に分けて中間納付
- **注意**：2割特例で年24万なら通常は発生しない

## 請求書発行時の源泉徴収対応（クライアントからの依頼時）

クライアント（法人）から「源泉徴収税適応の上、再発行してください（参考：所得税法第204条／100万円未満は10.21%）」と依頼が来たときの対応まとめ。

### 結論（Misoca操作手順）

課税設定画面の「源泉徴収税種別」を **「あり（復興税あり）」** に変更 → 保存 → 再発行。

1. 「課税設定」画面中段の「源泉徴収税種別」を確認
2. 「なし」→ **「あり（復興税あり）」** に変更
3. 自動で **10.21%** 分が計算・請求金額から差し引かれる
4. 画面下部の合計金額欄で反映を確認 → 「保存する」で再発行

**税率の内訳**：基本の源泉徴収税 10% ＋ 復興特別所得税 0.21%（10% × 2.1%）＝ **10.21%**（2037年までの時限措置）

### なぜこの対応が必要か

1. **源泉徴収は法人側の義務**（所得税法第204条）
   - デザイン制作／LP制作／原稿・ライティング等の特定業務を個人事業主に発注する場合、支払う側の法人には報酬から所得税を天引きして国へ納める義務がある
2. **10.21%は法定税率**
   - 100万円未満：10.21%（10% + 復興特別所得税0.21%）
   - 100万円超部分：20.42%（20% + 復興特別所得税0.42%）
3. **請求額と入金額を一致させるため（実務上ここが最重要）**
   - 請求書に源泉徴収税額を明記していないと、先方が独自に10.21%を差し引いて振込 → 「請求書金額」と「入金額」にズレ → 双方の帳簿突合で手間・ミス発生
   - あらかじめ源泉徴収分を差し引いた最終金額を請求書に明記すれば、先方は「請求書金額をそのまま振り込むだけ」で済む

### 源泉徴収された分の確定申告での扱い

**二重課税にはならない。ただし確定申告で必ず精算する必要がある。**

- 源泉徴収は **「税金の前払い」**（仮払い）であり、この時点で最終税額が確定するわけではない
- 確定申告で1年間の実際の利益（売上−経費−各種控除）から正しい所得税額を計算し、**すでに前払いした源泉徴収税額を差し引いて精算**
- フリーランスは経費・控除で実効税率が10.21%より低くなるケースが多く、その場合は **払いすぎ分が還付金として戻ってくる**
- 逆に、確定申告で源泉徴収額を申告し忘れると **税金の払い損** になる

### 帳簿記録のルール（重要）

源泉徴収された請求書を発行したら、確定申告のために以下を必ず記録：

- 請求書番号／発行日／クライアント名
- 請求額（税込）
- 源泉徴収税額（10.21%分）
- 実際の入金額（源泉徴収後の金額）

→ freeeで請求書登録時に源泉徴収項目を必ず入力する。確定申告時に「源泉徴収税額」欄へ集計転記する。

| 方法 | 対応税目 | メリット | デメリット |

## 積立運用ルール（税金プール口座）

### 基本ルール

- **月30万を税金プール口座に自動振替**（事業口座から）
- 年間積立額：360万
- 想定納付総額：約315万（2割特例前提）
- **バッファ約45万**（想定売上下振れ・想定外税負担への備え）

### 積立フロー

```
① クライアント入金 → 事業用口座
② 月末に自動振替（30万） → 税金プール口座
③ 各支払月に税金プール口座から納付
④ 年度末に余剰があれば事業口座or個人口座に戻す
```

### 支払月に必要な残高

| 支払月 | 必要残高 | プール口座に必要な蓄積 |
|---|---|---|
| 3月 | 約128万 | 前年12月時点で最低120万 |
| 6月 | 約27万 | 常時30万以上あれば余裕 |
| 8月 | 約40万 | 常時40万以上 |
| 10月 | 約27万 | 同上 |
| 11月 | 約24万 | 同上 |

**運用のコツ**：積立を10月に始めるなら、翌3月までに120万を貯める必要がある。月30万積立でギリギリ間に合う。**初年度は特に3月支払い分に注意**。

## 節税・注意ポイント

### 節税レバー

| 施策 | 効果 | 実施タイミング |
|---|---|---|
| **青色申告特別控除65万** | 課税所得を65万圧縮 | 開業届＋青色申告承認申請書（T03-7, T03-8）で対応済み |
| **2割特例（消費税）** | 消費税を売上税額の20%に圧縮 | 申告時に選択（2026-10〜2029-09） |
| **小規模企業共済** | 月最大7万積立→全額所得控除 | 独立後にiDeCoと併用検討 |
| **iDeCo** | 月最大6.8万積立→全額所得控除 | 独立後に加入検討 |
| **家事按分** | 家賃・通信費・光熱費の事業使用分を経費化 | freeeで自動処理 |
| **経費計上の徹底** | 事業関連支出をすべて計上 | 領収書即撮影＋freee連携 |
| **国民年金 2年前納** | 約16,590円の割引 | 口座振替設定時 |

### 注意ポイント

- **初年度は住民税・国保料が安い**（前年所得ベースなので、副業のみの金額で算定）→ 独立2年目から負担が跳ね上がる
- **予定納税は2年目から発生**（初年度は請求されない）
- **消費税の2割特例は3年間限定**（2029年10月以降は簡易課税or原則課税へ）
- **世界一周中も日本の税務は継続**（住民票国内継続のため）
- **確定申告は毎年2/16〜3/15**（世界一周中でもe-Taxで対応可能）
- **freeeモバイルで領収書即撮影**（世界一周中は特に）

### 世界一周中の対応

| 項目 | 対応 |
|---|---|
| 確定申告 | e-Taxで海外からも可能。マイナンバーカード＋ICカードリーダー（スマホでも可）が必要 |
| 税金納付 | ダイレクト納付・クレカ納付なら海外から可能 |
| 国保・年金 | 口座振替設定で自動 |
| 領収書 | freeeモバイルで即撮影＋クラウド保管 |
| 帳簿 | freeeでオンライン管理 |

## 通知の受け取り方（退職後）

税金・社会保険料の通知は基本的に**住民票の住所に紙で届く**。ただし自分で能動的に動かないと届かないものもある。

### 各税金の通知フロー

| 税目 | 通知される？ | 誰から | 届く時期 | 通知先 |
|---|---|---|---|---|
| 住民税 | ✅自動で届く | 市区町村 | 5〜6月 | 住民票住所 |
| 個人事業税 | ✅自動で届く | 都道府県税事務所 | 8月頃 | 事業所所在地 |
| 国民健康保険 | ✅自動で届く | 市区町村 | 6月頃（加入手続き後） | 住民票住所 |
| 国民年金 | ✅自動で届く | 日本年金機構 | 切替手続き後 | 住民票住所 |
| 所得税（本税） | ❌通知なし | — | 自分で確定申告して自主納付 | — |
| 予定納税（所得税） | ✅自動で届く | 税務署 | 6月頃 | 税務署届出住所 |

**やらないと**：無保険期間が発生→医療費全額自己負担のリスク／年金の未納期間発生

### 世界一周中の通知対応（超重要）

通知は**紙で住民票住所に届く**のがデフォルト。世界一周中は物理的に受け取れないので対策必須。

#### 対応策の組み合わせ

| 対策 | メリット | デメリット |
|---|---|---|
| 実家や家族に転送してもらう | 確実、費用ゼロ | 家族への依頼が必要 |
| 郵便転送サービス（郵便局） | 郵便物を指定先に転送 | 1年限定・延長申請必要 |
| e-Tax／マイナポータルで電子通知化 | 海外からもスマホで確認可能 | 対応する通知が限定的 |
| 私書箱・バーチャルオフィス | 有料だが通知確実に受取 | 月額コスト（1,000〜5,000円） |

#### 推奨構成

1. 住民票は実家 or 現住所のまま → **✅ 実家住所で決定済み**
2. 重要通知は実家に届く紙書類を家族が連携 → **✅ 家族連携で対応予定**
3. e-Tax・マイナポータルを最大限活用 → **✅ 利用開始済み**
4. 世界一周中の税金支払いは口座振替＋クレカ納付＋e-Taxダイレクト納付で完全電子化 → 独立後に順次設定

**田村さんの現状**：下地（住民票実家設定＋家族連携＋マイナンバーカード＋e-Tax＋マイナポータル）はすべて整備済み。あとは独立後の口座振替設定とeLTAX利用開始（T14a）で完了。

#### 6〜8月は特に要注意

| 月 | 届く通知 |
|---|---|
| 5〜6月 | 住民税納付書、国民健康保険料決定通知書、予定納税通知書（該当時） |
| 7月 | 予定納税納付書（第1期） |
| 8月 | 個人事業税納付書 |

→ 世界一周開始が12月なら、初年度の6〜8月主要通知は日本で受け取れる。2年目以降は海外滞在中に来るので、その前に転送・電子化の仕組みを確立しておく。
