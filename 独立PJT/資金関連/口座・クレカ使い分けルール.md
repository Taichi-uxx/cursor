# 事業用／個人用 使い分けルール

フリーランス独立＋世界一周に向けた、事業用と個人用の銀行口座・クレジットカード・決済の使い分けルール。

---

## 基本ルール

| 用途 | 事業用 | 個人用 |
|---|---|---|
| 収入 | 案件報酬の入金 | — |
| PC・カメラ・機材購入 | ✓ | |
| ソフトウェア（Adobe、freee、CapCut Pro等） | ✓ | |
| 事業関連の書籍・セミナー | ✓ | |
| クライアントとの打ち合わせカフェ代 | ✓ | |
| 事業関連の交通費 | ✓ | |
| ドメイン・サーバー代 | ✓ | |
| 事業関連の広告費・マーケティング費 | ✓ | |
| 家賃 | 家事按分 | 家事按分 |
| 通信費（スマホ・Wi-Fi） | 家事按分 | 家事按分 |
| 食費（プライベート） | | ✓ |
| 娯楽費・服飾費 | | ✓ |
| 生活雑貨 | | ✓ |
| プライベート旅行 | | ✓ |

**判断に迷ったら**：「税務調査で経費として説明できるか？」
- 説明できる → 事業用
- 説明できない → 個人用

## グレーゾーン：家事按分

事業と個人で共用するものは、**使用比率で分けて経費計上**する。これを「家事按分」という。

| 項目 | 按分の考え方 |
|---|---|
| 家賃 | 事業スペースの床面積割合（例：全体の30%を仕事場として使用→30%が経費） |
| 通信費 | 事業使用時間の割合（例：週の稼働時間から算出） |
| 電気代 | 同上 |
| スマホ料金 | 事業使用比率 |

**実務**：
- 支払い自体はどちらのカードでもOK
- freeeで「事業○%」と入力すればあとは自動計算
- ただし**支払いカードは統一した方が管理が楽**（例：全部個人カードで払って、freeeで按分入力）

## 世界一周中の特殊対応

一番判断が複雑なのがここ。移動費・宿泊費・食費が「観光」なのか「コンテンツ制作/案件納品目的」なのかで扱いが変わる。

| ケース | 扱い | 理由 |
|---|---|---|
| 案件納品するためのカフェ代・Wi-Fi代 | 事業経費 | 業務遂行に必要 |
| コンテンツ撮影地への移動費 | 事業経費（按分可） | コンテンツ制作目的 |
| 撮影機材・追加カメラ購入 | 事業経費 | 明確に事業用 |
| 現地の食事（撮影対象） | 按分（コンテンツ素材なら一部経費） | 撮影目的なら按分可 |
| 純粋な観光地観光 | 個人 | プライベート |
| 移動費（案件+観光両目的） | 按分 | 主目的で判断 |
| 通信費（海外SIM/eSIM） | 按分 | 案件対応もするため |
| 宿泊費（作業スペースあり） | 一部按分可 | 事業用スペース比率で |

### 世界一周中の記録ルール（超重要）

- **その場でメモ**：freeeモバイルアプリで領収書撮影＋「何のための出費か」を1行メモ
- **移動時**：目的（案件用/撮影用/観光）を記録
- **後回し禁止**：3ヶ月後に「これ何だっけ？」となると経費計上できない
- **写真もエビデンス**：撮影現地のロケ地写真は「取材目的の証拠」として記録に残す

### 振込手数料の見込み

- 楽天銀行 屋号口座 → 楽天銀行 個人口座：**同行内無料**

- **税金プール月30万は暫定値**。1年運用後に実績（所得税・住民税・国保・年金・事業税の年間合計）が見えたら月15〜20万に調整、差額は個人or事業投資へ
- **住信SBIネット銀行（目的別口座機能）への移行**は現状しない方針。管理が複雑になったら再検討

## 実務の判断フロー

```
支払い発生
    ↓
これは事業経費として認められるか？
    ├─ YES → 事業用カードで払う
    │       ↓
    │       家事按分か？
    │       ├─ YES → freeeで按分入力（例：事業70%）
    │       └─ NO  → 全額経費として計上
    │
    └─ NO  → 個人用カードで払う
```

## 発信活動が収益ゼロでも事業経費で計上できるか

**答え：YES、計上できる**。ただし条件と注意点あり。

### 税務上の考え方

事業経費として認められる条件は「事業に関連する支出」であること。**収益発生時期は関係ない**。むしろ「収益を上げるための投資段階の費用」も経費として認められる。

例：
- 開業初年度で赤字でも、機材購入は経費
- 事業立ち上げ準備の費用も経費
- マーケティング投資（収益化に時間かかる）も経費

### 事業経費として認められる条件（事業性）

1. **反復継続性**：単発の趣味ではなく継続的に行う
2. **営利性**：収益を目指している（明確なロードマップがある）
3. **独立性**：事業として自立している

田村さんの場合：
- 反復継続性：週N本ペースで継続投稿予定
- 営利性：広告収入・案件獲得への導線・企業案件を目指す明確な計画あり
- 独立性：開業届提出済み

→ すべてクリア

### 実務上の対応（重要）

- **開業届の事業内容に発信を含める**
  - 例：「マーケティング業／広告運用支援業／**メディア運営／コンテンツ制作業**」
  - これで発信関連経費（機材、ソフト、撮影費）が経費として認められやすくなる
- **発信活動の記録を残す**
  - 企画メモ、撮影記録、投稿履歴
  - 「収益化を目指す事業活動」であることの証拠
- **収益化のマイルストーンを持つ**
  - 進捗.mdの「2月投稿開始→PDCA」があれば十分

### グレーゾーン（税務調査で見られやすい）

| 項目 | リスク | 対策 |
|---|---|---|
| 開業から3年以上収益ゼロ | 「事業性なし＝趣味」と否認されるリスク | 収益化ロードマップを明示、少額でも収益化する |
| 高額機材（100万超のカメラなど） | 家事按分される可能性 | 完全事業使用の証拠を残す |
| 世界一周中の海外費用 | 「取材・コンテンツ制作目的」の証明が必要 | 撮影ログ、投稿実績、企画メモを残す |

## 事業主貸のフローと個人口座への資金移動

フリーランス（個人事業主）は法人と違って「事業と個人が別人格」ではない。事業用口座から個人口座に移すお金は「**事業主貸**」という会計処理で扱う。

### 基本フロー

```
① クライアント入金 → 事業用口座（売上として記帳）
       ↓
② 事業用口座 → 個人用口座 に振込（「事業主貸」として記帳）
       ↓
③ 個人用口座 → 生活費支払い（記帳対象外・プライベート）
```

- **事業主貸**：事業用の資金を個人（プライベート）に移すこと
- **事業主借**：逆に個人資金を事業に入れること（自己資金投入）
- どちらも**経費でも売上でもない、財布間の移動**
- freeeを使えば「事業→個人への振込」は自動で事業主貸と判定してくれる

### 推奨運用：「月給制」で自分に払うイメージ

- 毎月決まった日に **定額** を事業口座→個人口座に振込
- 例：毎月25日に30万円を振込（自分に給料払うイメージ）
- 個人口座はこれで生活費を賄う
- 事業口座には税金・経費支払い用の資金を残す

これで「個人カード引き落とし＞個人口座残高」を防げる。

### 生活防衛資金と口座設計

| 口座 | 役割 | 残高目安 |
|---|---|---|
| 個人口座 | 生活費・生活防衛資金 | 半年〜1年分の生活費（世界一周中の予備費含む） |
| 事業口座 | キャッシュフロー用 | 次月の生活費原資＋税金・経費支払い分 |
| 税金プール口座（オプション） | 所得税・住民税・国保・年金の支払い用 | 想定納税額を毎月積み立て |

### 振込手数料を無料にする銀行組み合わせ

**同銀行内なら振込手数料が無料**のケースが多い。設計時にここを揃えると得。

| 銀行 | 同行間振込 | 他行振込 |
|---|---|---|
| GMOあおぞらネット銀行 | 無料 | 月20回まで無料 |
| 住信SBIネット銀行 | 無料 | ランクに応じ月1〜20回無料 |
| 楽天銀行 | 無料 | ランクに応じ月0〜3回無料 |

**推奨**：事業用と個人用を同じネット銀行系で揃える（例：事業=GMOあおぞら屋号口座、個人=GMOあおぞら個人口座）と、振込手数料ゼロで運用できる。
