# English/ — 英語学習フォルダ用CLAUDE.md

このフォルダで作業する際は、親の `~/.cursor/CLAUDE.md` の方針に加え、以下の英語学習特化ルールを必ず守ること。

## 目的
**ネイティブと日常会話・ちょっとしたやりとり・意見交換などをストレスなくできるようになる。**

- ビジネス英語は対象外。日常生活でのカジュアルなやりとりに焦点を絞る
- 教科書英語ではなく、ネイティブが実際に日常で使う生の表現を重視する
- スラング・カジュアル表現も日常頻度が高ければ積極的に学習対象に含める

## 学習方針
**「知ること」より「使えること」を最優先する。**

- 単語・フレーズの「意味を知っている」状態では不十分。実際の場面で口から出る状態を目指す
- そのために、単純な訳語ではなく、例文・ニュアンス・使い分け・口語感まで一緒に押さえる
- 「明日のCamblyで試せる／話せる」が常に基準

## あなた（Claude）の立ち振る舞い

### 単語・フレーズを扱うときの基本姿勢
意味・訳語だけで終わらせない。必ず以下をセットで提供する：

- **例文**：具体的な場面が浮かぶもの。抽象的な「I like apples.」のような無味乾燥な例文は禁止
- **ニュアンス・使い分け**：複数の意味・用法があれば全て番号分けして、それぞれに例文を付ける
- **カジュアル度／フォーマル度**：日常会話で使えるか／使うと浮くかの感覚
- **注意点**：綴りから推測しにくい発音、攻撃的・侮蔑的なトーン、類似表現との違い等

### 重要度の付与（必須）
新規追加する単語・フレーズには必ず重要度を★5〜★1で付与する。

- **★5**：毎日のように耳にする／使う
- **★4**：週に何度か耳にする
- **★3**：知っておくと役立つ中堅
- **★2**：文脈限定／やや専門・フォーマル
- **★1**：ほぼ使わない／古風／文脈依存

**評価軸は「日常会話での頻度」のみ。** ビジネス英語頻度では評価しない（ビジネス頻出でも日常で使わないなら★低、日常スラングなら★高）。

全ての星に振り分ける必要はない（仮に★1が0個でもOK）。

### 例文を作るときの方針
- ストーリー性のある具体的な場面を作る
- 既存ファイルの世界観・登場人物に揃えると記憶に定着しやすい（`vocabulary.md` は現状NARUTOの世界観で統一されているので、追加分も同じ題材で揃える）
- 1つの単語に複数の用法・意味があれば、それぞれに別の例文を付ける

### ニュアンスを扱うときの方針
- 直訳では伝わらない感情・トーン・場面の限定をはっきり書く
- 攻撃的・侮蔑的・差別的なニュアンスがある語は必ず注記し、使用すべきでない場面を明示する
- 似た意味の語との違いがあるなら対比して示す

### ミス・言い回しの改善例を扱うときの方針（reviewing系ファイル）
- 「なぜそれが不自然か」「ネイティブならどう言うか」「ニュアンスの差は何か」をセットで説明する
- 単なる正解の提示で終わらせない。次回同じ場面で迷わないための判断材料を残す
- 出てきた表現は「次に使うとしたらどんな場面か」をイメージできる形で記録する

## フォルダ構成

### `vocabulary.md` — 単語・フレーズのストック
- 出会った単語・フレーズを蓄積していくファイル
- 重要度（★5〜★1）順に並べて管理
- 1エントリの基本構成：
  - 見出し（単語／フレーズ）
  - 重要度
  - Meaning（意味・訳語。複数意味あれば番号分け）
  - Example（例文。複数意味なら各意味ごと）
  - Nuance／Usage（必要に応じて）
  - 注意（発音・使い分け等、必要に応じて）

### `reviewing_cambly（日付）.md` — 実践レビュー（日付順）
- Cambly等の英会話セッション中に出てきたミス・言い回しの改善例・重要イディオム・フレーズ・例文等
- `vocabulary.md` より実践寄り。「今日のセッションで何が引っかかったか／何を学んだか」を記録する場
- 日付ごとに分けるのは、後から学習履歴を時系列で辿れるようにするため

### `reviewing_cambly_重要度順.md` — 実践レビュー（重要度順）
- `reviewing_cambly（日付）.md` と同じ内容を、日常会話での使用頻度（★5〜★1）順に並べ替えた派生ファイル
- 復習・口慣らし用。「使用頻度の高いものから順に体に入れる」目的で参照する
- フォーマットは `vocabulary.md` と同じ（見出し / 重要度 / Meaning / Example / 必要に応じて Nuance・注意）

## ファイル更新ルール
- `vocabulary.md` に新規追加する際は、必ず重要度を付与し、既存の星順位を崩さない位置に挿入する
- 既存エントリと重複する単語・フレーズはスキップする（更新が必要な場合は事前に相談）
- 例文の世界観は既存ファイルに合わせる
- 既存エントリの重要度を見直す場合、まとめて再評価・並び替えする
- 修正・削除など不可逆な操作は事前確認する

### `reviewing_cambly（日付）.md` を更新したら必ず `reviewing_cambly_重要度順.md` も更新する
日付ファイルに新規追記が発生したら、同じ内容を必ず重要度順ファイルにも反映する。

- 反映時は重要度（★5〜★1）を日常会話頻度のみで評価して付与する
- 重要度順ファイル側の既存エントリと重複する表現は1つに統合し、複数の意味・用法は番号分けで追記する
- 元の日付ファイルは編集せず保持する（時系列の学習履歴を残すため）
- 追記内容が複数日分溜まっていた場合も、漏れなくすべて反映する
- 反映後、追記分が重要度順ファイルに正しく入っているか一行ずつ突き合わせて確認する

補助として、`afterFileEdit` フック（`~/.cursor/hooks/reviewing-cambly-reminder.sh`）が日付ファイル編集後に自動リマインダーを出すよう設定済み。ただしフックは保険であり、ルール遵守の責任はあなた（Claude）側にある。
