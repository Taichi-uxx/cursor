## 【デザイン指示：AIっぽくなく、のっぺりしない表現】
1. 質感・奥行きのある背景
   - 背景は完全なベタ塗りではなく、微妙なグラデーションやごく薄いノイズテクスチャを重ねて、平面的にならないようにしてください。
   - セクションごとに淡い色味やトーンを変化させて、縦スクロール時にリズム感をもたせてください。
2. シャドウ・レイヤリング
   - カードやコンテンツブロックには薄いドロップシャドウ (例: box-shadow: 0 4px 8px rgba(0, 0, 0, 0.05)) を付け、要素が少し浮いているような奥行きを出してください。
   - メインビジュアルのテキストや画像が重なる部分では、軽いオーバーラップを作り、立体感を演出してください。
3. 適度な装飾や不揃いの演出
   - 完全に均等なレイアウトではなく、一部要素はあえて左右にずらすなど、人間がデザインしたような"微妙な崩し"を加えてください。
   - 見出しや強調テキストに軽い下線・波線・背景ハイライト等の装飾を入れ、フラットすぎない印象を与えてください。
4. タイポグラフィ
   - 見出しは大きめ（例：H1=32px以上）で、下線やグラデーション文字など軽い装飾も検討してください。
   - 本文サイズは16px前後で行間1.6〜1.8倍、字間をやや広めにし、ゆったりと読みやすい印象にしてください。
   - 強調部分には太字＋アクセントカラーや背景ハイライトなどを使い、単調にならないようにしてください。
5. 色使い
   - メインカラー1色 + アクセント1色 + モノトーン（グレー系）を基本とし、多彩な色を乱用しないようにしてください。
   - セクションや背景色には微妙なグラデーションや淡い色変化を加えて、のっぺりしないよう意識してください。
   - CTAボタンは背景としっかりコントラストを取り、ホバー時に0.2〜0.3秒程度のトランジションで色やシャドウが変化するようにしてください。
6. 画像・アイコン
   - AIっぽい汎用イラストではなく、サービスの世界観にマッチした写真やブランド感のあるイラストを使用してください。
   - アイコンは統一感あるスタイル（ラインアイコン / フラットアイコンなど）を選び、全部でバラバラにならないようにしてください。
7. マイクロインタラクション
   - スクロール時のフェードイン / スライドインなど、簡易アニメーションを小刻みに入れ、ページに動きを与えてください。
   - ボタンや画像にホバーした際、少し拡大・色変化・シャドウの強調など、機械的でない自然な挙動を演出してください。

3. 実績/お客様の声
   - カード形式で導入事例やレビューを並べ、薄いシャドウで浮かせる
