## 1. 本プロジェクトの目的

『採用一括かんりくん』の採用AIエージェント化を市場に認知させ、新規及びリプレイス需要を獲得する。

- 月間新規問い合わせ数：現在:60件 → 3ヶ月で累計150件（月40→50→60件の段階的達成）
- セグメント別：Excel層100件、ATS利用層50件

## 2. 市場環境・自社ポジション

### ターゲット市場の規模と特性

採用管理システム（ATS）市場は年々拡大。国内市場規模は数百億円に達している。
年間10名以上採用企業全体に占めるボリュームゾーンは「100～999名規模企業の未導入層（61%）」。

一方、採用手法全体で見ると、ダイレクトリクルーティング市場は急速な成長を遂行しており、2024年度の市場規模は前年度比18.7%増の1,275億円（矢野経済研究所）。特に地方エリアの中小企業での導入需要が拡大中。

### 中小中堅企業が直面する採用課題の現実

#### バックグラウンド

**社会課題**

日本のGDPの減少/いかに上げていくか

- 労働人口は減少傾向で今後30年で半減
- 仕事に対して前向きな人は5%と129カ国中128位

日本は働く人が減るかつ、仕事に対して前向きな人が少ないのが現状

それを変えていくために
**量✖️質のアプローチが必要**

- 量は女性や高齢者、外国人の労働人口増加へのアプローチ
- 質はミスマッチを減らしていき、仕事に前向きな人を増やすということ。

当社は質に関して特に注力している。

中堅中小企業で働いている人は国内で70%。
ここにアプローチをしていきたい。

課題としてあるのは

- 中堅中小企業がマッチした人材を採用することができない
- さらに人事で働く人も人口減少に比例して今後減少していく。

結果的に人手不足による経済損失が16兆円となっている
([参考リンク](https://vdata.nikkei.com/newsgraphics/labor-supply-constraint/))

ここに採用DX（AIX）を加えて解決していく必要がある。

#### 課題1：「集める」の困難性

**売り手市場による母集団形成の難化**

- 従来の「求人掲載」による待ちの採用では、応募が集まりづらい
- 従業員300名未満企業の求人倍率は3.4倍。1人の候補者を3～4社が取り合う状況
- 中小企業は知名度で大企業に劣り、そもそも選択肢に入らないケースが多い

**ダイレクトスカウトの有効性は認識されるも、実行リソースが不足**

- ダイレクトリクルーティングの導入企業は66.2%が満足度を示す高い手法
- しかし、スカウト媒体の個別最適な配信（候補者ごとの文面カスタマイズ、タイミング最適化）には、1名採用あたり100名以上へのアプローチが必要
- スカウト文面の作成（従来1件3～5分）、ターゲット選定、返信対応等の工数は多く、採用担当者1～2名（兼務）では対応不可能な水準

#### 課題2：「魅力付け」（アトラクト）の不足

選考プロセスにおける候補者エンゲージメント向上の有効性は認識されるも、実行されていない

- 採用における「評価フィードバック」「マッチ度の共有」は候補者の入社意欲を高める有効な手段として認識されている
- しかし、面接官の評価に基づいた「その候補者に響く評価メッセージ」を1人1人に作成する時間がない
- 結果として、選考案内は事務的な連絡に終わり、「最後の1人」の確保に失敗するケースが頻発

**内定辞退の理由の多くが「アトラクト不足」**

- 複数企業を並行して受けている候補者は、最終段階で大企業の内定を選ぶケースが多い
- 内定辞退の多くは、採用担当者や面接官の「内定者フォロー経験不足」が原因（Wantedly調査）
- 「面接を『候補者を見極めるだけ』の目的で実施している」という受身の姿勢が、辞退につながる

#### 課題3：「リソース不足」による戦略実行の停滞

**人事体制の脆弱性**

- 中小企業では人事部門が小規模であることが多く、採用活動に十分なリソースを割くことができない
- 採用担当者の多くが総務・労務との兼務で、「作業」に追われて「採用戦略」を考える時間がない
- PDCAを回す余裕がなく、毎年同じ募集方法で効果を検証できていない

**採用予算の不足**

- 大企業の採用費総額平均1,783.9万円に対し、非上場企業は375.1万円（マイナビ）
- 限られた予算で、複数の採用手法（求人媒体、ダイレクトスカウト、人材紹介、アトラクト）を実行することは困難

**結果として、やるべき「採用戦略」が実行できない悪循環**

- 「母集団形成に課題がある」ことは認識しているが、ダイレクトスカウトの運用工数が多すぎて実行できない
- 「候補者を口説き落とす必要性」は理解しているが、1人1人にカスタマイズされたアトラクト対応ができない
- 結果として、採用成功率は上がらず、大企業との「非対称な採用競争」に敗け続ける

### 補足

---

#### ダイレクトリクルーティング市場の急速な成長と中小企業の対応遅れ

**ダイレクトリクルーティングは「新常識」へ**

- 新卒採用におけるダイレクトリクルーティング市場は年平均58.1%のCAGRで成長（i-plug）
- 大企業だけでなく、中小企業でもダイレクトリクルーティングの導入が加速中
- スカウト受信経験者：22卒94%、23卒86%、24卒66%と定着

しかし、中小企業のダイレクトリクルーティング運用は「運用代行サービス」に依存する構造化

- 中小企業がダイレクトリクルーティングを「やりたい」と思っても、実行リソースがないため、スカウト代行サービスに依存する傾向
- これは継続的な採用コストの増加につながり、「脱中堅化」「リソース確保」の課題を解決しない

#### 自社ポジション：採用支援の進化系としてのAIエージェント化

中小中堅企業が直面する3つの課題を統合的に解決する必要性
従来の採用管理システムでは「管理」機能に留まり、上述の「集める」「魅力付け」「リソース不足」という戦略レベルの課題は未解決。

**自社の進化系（RPA → AI）**

- 段階1：応募者情報の一元管理・選考プロセスの可視化 → 「情報管理」を支援
- 段階2：LINE連携による候補者コミュニケーション → 「接触回数」を増加
- 段階3：RPA自動化（日程調整等） → 「時間」を創出
- 段階4（今回）：AI による「採用戦略の実行支援」 → 「人手」を補完

#### AIエージェント化の要項（機能一部）

**「集める」をAIで実行支援**

- ダイレクトスカウトは有効だが、候補者ごとの「個別最適な文面」作成が工数障壁
- AIが、候補者データと企業情報から「パーソナライズされたスカウト文面」を自動生成
- 従来1件3～5分 → 0分で完了。月のスカウト送付数の制約が消滅

**「魅力付け」をAIで実行支援**

- 面接官の評価から「その候補者に響く評価フィードバック」を自動生成
- 「マッチ度」「評価ポイント」を具体的に伝えることで、入社意欲を高める「アトラクト」が実行可能に
- 従来「事務的な選考案内」 → 「心を掴む『口説きメッセージ』」に変質

**「自動化」をRPA + AIで補完**

- RPA：日程調整、リマインド、ステップ移動等のオペレーション自動化 → 時間創出
- AI：評価の自動生成等の「戦略業務」をAI支援 → 人手補完
- 結果として、採用担当者は「戦略的な意思決定」に集中可能

#### 市場のニーズ vs 競合の対応状況

- **市場の真のニーズ**：「採用成功」の戦略的実行
- **競合ATSの現状**：「管理」機能に特化。AI搭載も限定的。「戦略実行支援」までは提供していない

**自社がAIエージェント化することで：**

- 「単なるATS」から「採用成功を支援するパートナー」へのポジション転換が可能
- 「ツール」ではなく「中小中堅企業の採用を勝たせるための武器」として認識される

## 3. ターゲットセグメント定義

### セグメントA：Excel兼務層（新規層）

- 企業規模：50～500名
- 採用規模：年間10～30名
- 採用担当者：1～2名（総務・労務兼務が多い）
- 現在の採用管理ツール：Excel、スプレッドシート、紙ベース
- 月間作業工数：50～100時間/担当者
- 主要課題：「作業」に時間を奪われ、採用戦略が立案できない
- 投資優先度：低（初期費用・月額費用への感度が高い）
- 経営判断：社長・経営層の説得が必要

### セグメントB：既存ATS利用層（リプレイス層）

- 企業規模：100～1000名
- 採用規模：年間20～50名
- 採用担当者：2～3名、組織化
- 現在のATS利用：ジョブカン採用管理、HRMOS採用等
- 利用期間：2年以上
- 主要課題：「管理」は楽になったが、「採用成果」（内定承諾率）が改善していない
- 投資優先度：中程度（ROI・成果改善への関心が高い）
- 経営判断：採用担当者（人事責任者）主導で判断

## 4. ポジショニング・メッセージング

### 独自の価値提案（POD）

中小中堅企業が採用で勝つための3段階の採用支援：

1. **「集める」戦略をAIで実現**
   - パーソナライズされたスカウト文面の自動生成（開封率50%以上）により、質の高い母集団を形成

2. **「選ぶ」精度をAIで高める**
   - AIが客観的な評価を自動生成することで、採用基準を標準化し、ミスマッチを防止

3. **「口説く」質をAIで実現**
   - 候補者の心を掴む「アトラクトレター」の自動生成により、貴重な候補者の確保率を向上

これらを「RPA（自動化機能）」と組み合わせることで、「作業」を完全に消し去り、採用担当者が本来の「採用戦略」に集中できる環境を実現する。

### セグメント別コアメッセージ

**セグメントA向け**

「月130時間の採用業務を削減。その時間で、本来やるべき『採用戦略』に集中する」
→ 直感的な「作業削減」を訴求。具体的な時短効果を強調

**セグメントB向け**

「採用成果が上がらない理由は、ツールではなく『戦略』。AIが採用成功をサポートする」
→ 戦略的な「採用成功」を訴求。「管理」から「成果」への転換を示唆

## 5. 競争戦略

### 競合分析

- ジョブカン採用管理・HRMOS採用：「採用管理・効率化」訴求で認知獲得済み。
- sonar ATS：「採用の在り方が変化」という戦略的切り口で後発対抗中
- Excel：依然として70%程度の中小企業が利用。デジタル化への抵抗感が存在

### 回避すべき

「採用管理システム」という既に競合の比較広告はと採用管理で戦うのは避けるべき。

### 採用すべき

市場の真のニーズであるAI活用での「採用成功」という異なる切り口から、認知獲得を狙う。

### 基本方針

「中小中堅企業が採用で勝つために」というターゲット企業の本来のニーズに寄り添い、「採用管理」を避け、「採用成功」という広い文脈でのポジショニングを実現する。

### セグメント別施策

#### セグメントA向け施策

1. **Web広告（Google・Yahoo・Facebook/Instagram）**
   - キーワード：「採用管理 Excel」「採用業務 自動化」「採用 AI」等
   - ターゲット層：Excel利用企業の採用担当者
   - クリエイティブ：「作業からの劇的な解放」を直感的に理解させるビジュアル
   - 具体例：「月130時間削減」「スカウト送付時間0分」等の効果を示す動画・画像
   - LP：AI履歴書読み取りのデモ、導入企業のビフォーアフター事例

2. **オウンドメディア・SEO**
   - ターゲットキーワード：「採用管理システム 中小企業」「Excel採用管理の限界」
   - コンテンツ例：「Excelから脱却すべき5つの理由」「採用が劇的に楽になる3つのAI」等
   - タッチポイント：無料チェックシート「採用管理、こんなことで困ってませんか？」

3. **SNS・インフルエンサー連携**
   - 人事ブロガー、採用コンサルタント等との提携
   - フック：「採用担当者のリアルな困りごと」と「AI導入事例」の組み合わせ

4. **営業支援ツール**
   - 自動相談予約システム、チャットボット（FAQ対応）

#### セグメントB向け施策

1. **リスティング広告**
   - キーワード：「ATS比較」「採用管理システム リプレイス」「採用 成果」「AIスカウト」
   - ターゲット層：既存ATS利用企業で「採用成果」を探している採用責任者

2. **LinkedIn・業界メディア広告**
   - ターゲット層：人事責任者、採用マネージャー

3. **ウェビナー・ホワイトペーパー**
   - テーマ例：「中堅・中小企業が採用で勝つための3つのAI活用法」
   - 対象：既存ATS利用企業

4. **パートナーシップ営業**
   - 既存ATS提供企業からのスイッチング層へのアプローチ

### 施策タイムライン

## 10. リスク・仮定

### 前提仮定

1. 市場仮定：中小企業の「AIへの信頼」が段階的に高まる / 大規模経済変化がない
2. 競合動向：既存ATS（ジョブカン、HRMOS等）が同期間に大規模AI施策を実施しない
3. プロダクト：AI機能の実績値（開封率50%等）が確実に達成 / 継続率85%以上
4. セグメント：A・B双方からの反応が予測通り / リプレイス率20%達成
5. キャンペーン：Web広告CTRが業界平均以上 / オウンドメディア単価5万円以下

### リスク要因と緩和策

#### リスク1：AI への不信感・抵抗感

- **緩和策**：親しみやすいメタファー（右腕・軍師）、具体的効果表示、ビフォーアフター事例、無料トライアル期間設定

#### リスク2：既存ATS利用企業のリプレイスハードル

- **緩和策**：リプレイスコスト削減サービス（無料データ移行）、試験導入プラン、パートナーシップ営業強化

#### リスク3：Web広告CV単価の上昇
