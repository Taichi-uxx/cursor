# 本質の再定義で「Yes」を取って、議論の主導権を握る！

## ①なぜこの話をしているか

商談や提案の場で、相手の論点に乗せられてしまうケースあると思ってて、 「どの媒体を使うか」「どの代理店を選ぶか」みたいな、手段レベルの話で終わってしまうことがある。

でも、手段 vs 手段で会話しちゃうと、どうしても他社と比較されるだけになってしまう。

そうじゃなくて、自分たちのポジショニングや"本質"を再定義して、議論をこちら主導で進めていくことが大事。

1個上のレイヤー（目的・本質）で会話することで、主導権を取れる

## ②「本質の再定義でYesを取る」とは？

相手が"手段（どうやるか）"の話をしている時に、こちらから"目的（なぜやるか）"の話に引き上げて、その定義に対して相手から「そうですね（＝Yes）」をもらうこと。本質思考。

この"最初のYes"を取った瞬間に、

- 会話の軸がこちらの設計になる
- 相手が「自分の目的を理解してくれている」と感じる
- 以降の議論を"目的起点"でリードできる
- 比較されづらくなる、構えられなくなる(防御姿勢を崩す)

つまり、Yesを取る＝議論の定義を握ること。

### 具体例

#### :ダメな例
```
CL：「Googleは一本化したいと思っています」
RH：「いえ、複数代理店で競わせた方が成果が出ますよ」
→ 手段 vs 手段の議論になり、どちらが正しいかの勝負になる。
```

#### :良い例（本質の再定義でYesを取る）
```
CL：「Googleは一本化したいと思っています」
RH：「なるほど。ただ目的は"Googleを一本化すること"ではなく、
 "投下したコストで一番効率よくCVを取ること"ですよね？」
CL：「そうですね」 ← 🎯 このYesで主導権を獲得！
→ ここから"目的に沿った手段"の話に変わる。
→ 相手は「この人は本質をわかってる」と感じる。
```

## ③なぜこの"1回のYes"が大事なのか

### a. 主導権を握れる
目的を再定義してYesを取ることで、議論の土俵をこちらが設計できる。
→ 「説明する側」から「意思決定を設計する側」へ。

### b. 相手の防御を解ける
反論から入らず、"本質の確認"で共感を取る。
→ 「自分の目的を理解してくれている」と感じ、心理的安全性が生まれる。

### c. 会話が共創になる
「どっちが正しいか」ではなく、「どうすれば目的を達成できるか」に話が変わる。
→ 対立が減り、合意形成が早くなる。

### d. REHATCHらしさを体現できる
"本質を見抜き、構造を設計する"というREHATCHの強みを、営業の会話そのもので体現できる。
→ 話している時点で「考え方が深い」「信頼できる」と感じてもらえる。
