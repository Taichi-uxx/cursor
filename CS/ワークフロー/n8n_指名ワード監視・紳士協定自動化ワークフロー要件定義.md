# 指名ワード監視・紳士協定自動化 n8nワークフロー生成依頼

## 概要
検索広告で指名ワードに出稿している競合企業を自動検知し、紳士協定のための初回コンタクト文面を生成する週次自動ワークフローをn8n用JSONで作成してください。

## 要件詳細

### 実行条件
- **実行頻度**: 毎週月曜日 9:00 JST
- **トリガー**: スケジュール実行（Cron）

### 処理フロー

#### 1. 指名ワード検索
- **対象媒体**: Google検索、Yahoo!検索
- **検索対象**: 広告枠のみ
- **地域設定**: 日本全国
- **検索キーワード**: 設定可能な指名ワードリスト（会社名、サービス名、ブランド名）

#### 2. 出稿企業特定
- 広告のランディングページURLから企業名を特定
- ドメイン解析による企業サイト特定

#### 3. 問い合わせ先収集
- 企業サイトから以下を自動収集:
  - 問い合わせフォームURL
  - 問い合わせ用メールアドレス
- 収集できない場合は「問い合わせ先不明」として記録

#### 4. データ保存
- **保存先**: Google スプレッドシート
- **保存項目**:
  - 実行日時
  - 検索キーワード
  - 企業名
  - サービス名
  - 企業サイトURL
  - 問い合わせ先（フォームURL/メールアドレス）
  - ステータス（正常/問い合わせ先不明）

#### 5. 文面生成
以下のテンプレートに企業情報を差し込んで文面を生成:

```
株式会社{対象企業名}　広告ご担当者様

突然のご連絡失礼いたします。
株式会社{自社名}の{担当者名}と申します。

広告の除外設定をご依頼させていただきたく、ご連絡いたしました。

Google検索にて弊社の指名KWに該当するKWで検索を行うと、貴社サービス「{対象サービス名}」様の広告が掲出されます。
拡張などで意図的ではないと存じますが、該当のキーワードは弊社サービス名となりますので、お手数をおかけしますが、除外設定をいただけますでしょうか。

----------------------------------------------
・対象媒体：Google検索、Yahoo!検索
・対象キーワード：「{検索キーワード1}」「{検索キーワード2}」「{検索キーワード3}」
・除外設定：フレーズ一致除外、部分一致除外、完全一致除外
----------------------------------------------

また、弊社でも、貴社名や商標などで除外が必要なものがあれば設定させていただきますのでご指示ください。

お手数おかけしますが、除外設定を完了されましたらご一報いただけますと幸いです。

何卒よろしくお願いいたします。
```

#### 6. Slack通知
以下の内容を指定チャンネルに通知:
- 実行結果サマリー（検知企業数、成功/失敗件数）
- 検知企業リスト
- 各企業の生成文面
- 例外ケース一覧（問い合わせ先不明等）

### エラーハンドリング

#### 検索結果0件の場合
- Slackに「該当企業なし」として通知
- スプシに実行ログのみ記録

#### 企業サイトが見つからない場合
- 該当企業をスキップして次へ進行
- ログに「企業サイト不明」として記録

#### 問い合わせ先が見つからない場合
- 「問い合わせ先不明」として結果に含める
- 文面は生成するがSlack通知で明記

### 設定項目（n8nの変数として設定）

#### 監視設定
- `SEARCH_KEYWORDS`: 監視対象キーワード配列
- `EXECUTION_SCHEDULE`: Cron式（デフォルト: "0 9 * * 1"）

#### 企業情報
- `COMPANY_NAME`: 自社名
- `CONTACT_PERSON`: 担当者名
- `SERVICE_NAME`: 自社サービス名

#### 外部サービス設定
- `SPREADSHEET_ID`: Google スプレッドシートID
- `SLACK_WEBHOOK_URL`: Slack Webhook URL
- `SLACK_CHANNEL`: 通知先チャンネル名

### 技術要件

#### 必要なn8nノード
- Schedule Trigger（Cron実行）
- HTTP Request（検索API呼び出し）
- HTML Extractor（ページ解析）
- Google Sheets（データ保存）
- Slack（通知）
- Code（JavaScript処理）
- IF/Switch（条件分岐）
- Set（変数設定）

#### 外部API
- Google Custom Search API または Serpapi（検索結果取得）
- Google Sheets API（データ保存）
- Slack Webhook API（通知）

### 期待する出力
n8nで直接インポート可能なJSONワークフローファイルを生成してください。コメント付きで各ノードの役割と設定内容を明記し、実運用で即座に利用できる完成度を目指してください。

### 注意事項
- レート制限を考慮したAPI呼び出し間隔の調整
- 大量データ処理時のメモリ効率化
- エラー時の適切なログ出力
- セキュリティを考慮した認証情報の管理
