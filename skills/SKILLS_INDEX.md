# スキル一覧

> Claude Code から呼び出せるスキル一覧。新しいスキルを追加・削除した際はこのファイルを更新すること。
> 実体: `~/.cursor/skills/` ｜ Claude Code参照: `~/.claude/skills/`（シンボリックリンク）

---

## デザイン・UI

| スキル | 何ができる？ | こんなとき使う |
|---|---|---|
| frontend-design | プロ品質のフロントエンドUI生成。創造的でデザイン性の高いインターフェースを実装 | LP・コンポーネント・UIモックを高品質に作りたいとき |
| canvas | Cursor Canvas（チャット横に表示できるライブReactアプリ）でリッチなビジュアル成果物を作成 | 分析結果・ダッシュボード・データ可視化を見せたいとき |

## ユーティリティ

| スキル | 何ができる？ | こんなとき使う |
|---|---|---|
| shell | `/shell` で続くテキストをそのままシェルコマンドとして実行 | コマンドを直接実行したいとき |
| ss | macOSクリップボードからスクリーンショットを読み取り | `/ss` でスクショを共有して解析させたいとき |
| knowledge-import | 記事URL・X投稿・YouTube動画・PDF・文書を構造化mdにまとめ、work/contents配下の最適フォルダへ自動格納 | `/knowledge-import` で他形式ナレッジをストックしたいとき |
| appeal-match | 案件概要・募集要項を渡すと、職務経歴書から刺さるアピールポイントを抽出・微加工して箇条書きで出力 | 案件相談DM・スカウト返信・カジュアル面談前のアピール文を即作りたいとき |
| appeal-match-shumatsu | シューマツワーカー専用。募集要項＋必須要件＋歓迎要件を渡すと、職務経歴書から「必須要件へのアピール」「歓迎要件へのアピール」「その他自己PR」の3ブロックを応募フォームに貼れる形で生成 | シューマツワーカーで新規案件に応募するとき（必須欄・歓迎欄・自己PR欄の3つを埋めたいとき） |
| English-review | 英語学習mdファイル（`vocabulary.md` / `reviewing_cambly_重要度順.md` 等）からミス欄に×が付いたエントリを×多い順にソートし、30問ずつクイズ出題→答え合わせ→間違えた番号の×を実ファイルに追加 | Cambly後の復習・忘れやすい単語を強化したいとき |
| English-review-jp2en | `English-review` の日→英（英作文）版。例文の日本語訳のみを提示し、ユーザーが英訳する形式。答えは「英単語＋英例文＋日本語意味」の3点セット。ファイル更新ロジック・ソート・ミス管理は `English-review` と共通 | 「意味は分かるけど自分では英語で口から出ない」フェーズを潰したいとき |
| English-addlist | 英単語・フレーズ・学びメモを `vocabulary.md` or `reviewing_cambly_日付順.md` に既存フォーマットで追記。重複はスキップ、`vocabulary.md`／`重要度順` 側には「新規：✓」フラグ付与、日付順を更新したら重要度順にも自動同期 | Cambly後・海外ドラマ視聴後に出会った表現をストックしたいとき |
| contract-manager | 業務委託契約を一元管理。`独立PJT/契約書関連/契約一覧.md` の追加・更新、月初のChatwork通知（launchd）セットアップ、通知への回答（自動延長／終了／期日指定延長）に応じた一覧書き換えまで担当 | `/contract-manager` で契約追加・通知回答による更新・cron導入をしたいとき |
| ad-update-weekly | 広告代理店ブログ5サイト＋LINEヤフー公式ニュース＋X投稿（Grok Live Search）から広告媒体アップデート情報を過去7日で収集し、重複排除＋AI要約（タイトル＋URL＋3行）＋媒体別グループ化してChatworkに週次通知。launchd（週次cron）対応 | `/ad-update-weekly` で広告媒体アップデートを週次でChatworkに投げたいとき／初回セットアップ時 |
| competitor-weekly | 案件別3c分析の直接競合について、Meta広告ライブラリ（Playwright MCP）／リスティング広告LP／newsroom・PRTimesリリースを過去7日で収集し、Chatwork集約ルームに案件別セクションで週次通知＋各案件memory.mdに「競合ウォッチ」セクションを追記蓄積。対象案件は`active_clients.yaml`、案件別探索設定は各案件フォルダの`competitor_sources.yaml`で管理。launchd（月曜9:30）対応 | `/competitor-weekly` で担当案件全社の競合の動きを週次で把握・蓄積したいとき／初回セットアップ時 |

## AI-Studio ワークフロー

| スキル | 何ができる？ | こんなとき使う |
|---|---|---|
| copy-build | LP URL（必須）と媒体（必須）から、媒体補正をかけた6アプローチ×3案=18案を生成し、3ペルソナ採点→⑤CD採否ループ→①CMO最終QCで採用コピーを選抜。LPはPlaywright取得、ペルソナ無ければ自動生成 | `/copy-build <LP URL> 媒体=<媒体>` で広告コピーを量産・選抜したいとき |
| lp-build | LP URL（必須）・媒体（必須）・FV面（必須：pc or sp）から、アイキャッチ先行のLP生成。⑰がG1 FVコピー→G2 ビジュアル設計＋文字込み一枚絵プロンプト（最小指示型）→G3 実画像（**AIで文字込み一枚絵生成**・gen_full_fv.py で PC 1536×1024 or SP 1024×1536 のいずれか1面 oneshot）を3ゲート（各⑤CD承認）で確定→⑨が確定FV制約下で本文構成3案→⑤合体整合→①最終QC | `/lp-build <LP URL> 媒体=<媒体> FV面=<pc\|sp>` でLPのアイキャッチと本文構成を作り合体させたいとき |
| banner-ad-build | LP URL（必須）・媒体（必須）・競合バナー（任意・参考画像扱い）から、バナー広告生成。⑧が3型（コピー強/ビジュアル強/数値訴求）設計→⑤CD構成承認→**AIで文字込み一枚絵生成**（1080×1080固定・gen_full_banner.py）→3ペルソナ＋生成後ゲート＋日本語崩れ判定→⑤CD採択→①CMO最終QC。競合バナーは⑧が参考画像として裁量で読み取る（表面模倣防止の構造判定は廃止） | `/banner-ad-build <LP URL> 媒体=<媒体> [競合=<画像>]` でバナーを量産・選抜したいとき |
| lp-inspiration-scout | 業界（必須）を指定すると、海外の「イケてる／勢力を伸ばしている」サイト・LPをデザインギャラリー横断＋Web検索のハイブリッドで収集・厳選し、各サイトのFV型/構成/見せ方を一言で添えた軽量リスト化。出典＋サムネスクショ必須、Markdown（work/knowledge配下）＋Canvasボード出力。独立完結（lp-build非連携） | `/lp-inspiration-scout <業界>` で新規LP考案前に似業界の海外勢から見せ方・構成の着想を得たいとき |
