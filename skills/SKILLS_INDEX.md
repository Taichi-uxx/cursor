# スキル一覧

> Claude Code から呼び出せるスキル一覧。新しいスキルを追加・削除した際はこのファイルを更新すること。
> 実体: `~/.cursor/skills/` ｜ Claude Code参照: `~/.claude/skills/`（シンボリックリンク）

---

## デザイン・UI

| スキル | 何ができる？ | こんなとき使う |
|---|---|---|
| frontend-design | プロ品質のフロントエンドUI生成。創造的でデザイン性の高いインターフェースを実装 | LP・コンポーネント・UIモックを高品質に作りたいとき |
| canvas | Cursor Canvas（チャット横に表示できるライブReactアプリ）でリッチなビジュアル成果物を作成 | 分析結果・ダッシュボード・データ可視化を見せたいとき |

---

## Cursor設定・カスタマイズ

| スキル | 何ができる？ | こんなとき使う |
|---|---|---|
| statusline | CLIのステータスライン（プロンプト上部の情報表示）をカスタマイズ | ターミナル上部にセッション情報を表示したいとき |
| update-cursor-settings | Cursor/VSCodeのsettings.jsonを編集（テーマ、フォント、フォーマット等） | エディタ設定を変更したいとき |
| update-cli-config | Cursor CLIのcli-config.json設定（権限、承認モード、Vimモード等）を編集 | CLI動作を細かく調整したいとき |

---

## スキル・サブエージェント・自動化作成

| スキル | 何ができる？ | こんなとき使う |
|---|---|---|
| create-skill | 新しいCursor Agent Skillの作成ガイド（SKILL.md構造、ベストプラクティス） | 独自スキルを作りたいとき |
| create-subagent | 専門タスク用カスタムサブエージェントの作成（コードレビュー、デバッグ等） | 特定タスク専用のAIを作りたいとき |
| create-hook | Cursorフック（hooks.json）の作成、エージェントイベント自動化 | エージェントの動作を自動化したいとき |
| create-rule | Cursorルール（.cursor/rules/）の作成、コーディング規約・プロジェクト規約の設定 | 永続的なAIガイダンスを設定したいとき |
| migrate-to-skills | 既存ルール/コマンドをAgent Skills形式に変換 | .mdcルールや.mdコマンドをSKILL.mdへ移行したいとき |

## Git・PR・ワークフロー

| スキル | 何ができる？ | こんなとき使う |
|---|---|---|
| babysit | PRをマージ可能状態に保つ（コメント整理、コンフリクト解決、CI修正をループ実行） | PRレビュー対応を自動でこなしたいとき |
| split-to-prs | 現在の作業を小さくレビュー可能なPRに分割 | 大きな変更を分割してPRにしたいとき |

## Peon Trainer（運動ログ・通知）

| スキル | 何ができる？ | こんなとき使う |
|---|---|---|
| peon-ping-log | 腕立て・スクワット等の運動レップ数を記録 | 「腕立て25回やった」を記録したいとき |
| peon-ping-toggle | peon-pingサウンド通知のON/OFF切り替え | セッション中に音をミュート/復帰したいとき |
| peon-ping-use | このチャットで再生するボイスパック（キャラクターボイス）を指定 | GLaDOS/Peon/Kerrigan等のボイスに切り替えたいとき |
| peon-ping-config | peon-pingの詳細設定（音量、パックローテーション、カテゴリ等）を変更 | peon-ping設定を細かく調整したいとき |

## ユーティリティ

| スキル | 何ができる？ | こんなとき使う |
|---|---|---|
| shell | `/shell` で続くテキストをそのままシェルコマンドとして実行 | コマンドを直接実行したいとき |
| ss | macOSクリップボードからスクリーンショットを読み取り | `/ss` でスクショを共有して解析させたいとき |
| knowledge-import | 記事URL・X投稿・YouTube動画・PDF・文書を構造化mdにまとめ、work/contents配下の最適フォルダへ自動格納 | `/knowledge-import` で他形式ナレッジをストックしたいとき |

|---|---|---|
