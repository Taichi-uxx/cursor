# lp-inspiration-scout — 海外イケてるLP着想スカウト

`/lp-inspiration-scout <業界（必須）> [媒体=<媒体 任意>] [件数=<N 既定8>] [地域=<既定: 海外>] [補足=<商材/USP/ターゲット 任意>]`

> 目的: 新規LPを考案する前に、似た業界で勢いのある海外サイト・LPから
> **見せ方・構成の着想**を素早く得る。深掘りティアダウンはしない。
> 「URL＋出典＋サムネ＋見どころ一言」の**軽量リスト**が成果物。

## 入力

| 項目 | 必須 | 内容 |
|---|---|---|
| 業界 | **必須** | 例: SaaS / フィンテック / D2Cスキンケア / 人材 / クリニック / 不動産 / BtoB SaaS。曖昧なら確認（業界でギャラリーのカテゴリ・検索クエリが変わる） |
| 媒体 | 任意 | 流入媒体。指定があれば「その媒体から来た人に効くFV/構成か」の着眼を一言コメントに加味 |
| 件数 | 任意 | 厳選して残す件数。既定 8（5〜12 目安） |
| 地域 | 任意 | 既定 **海外**（英語圏中心・日本語LPは除外/劣後）。`地域=US` 等で絞り込み可 |
| 補足 | 任意 | 商材/USP/ターゲット等。あれば業界内の近い圏に寄せて精度向上 |

## 設計原則（厳守）

1. **オーケストレーター（このスキルを動かすメインエージェント）はロングリスト収集を自前でやらない。** 多数のギャラリー/検索ページを横断する重いリサーチは**独立リサーチサブエージェント**に委譲する（CLAUDE.md「重いタスクはサブエージェントに切り出せ」）。オーケストレーターの役割は「入力解釈」「サブエージェント委譲」「Playwrightスクショ取得（ツール実行）」「集約・出力」。
2. **出典を必ず記載する**（`feedback_sources.md`）。各サイトに「どのギャラリー or どの検索クエリで見つけたか」＋ライブURL＋取得日を残す。出典不明の候補は採用しない。
3. **海外・勢いのあるものを優先**。意匠の鮮度＋**事業のモメンタム**の両面で選ぶが、モメンタムは緩いOR束ではなく**階層判定＋裏取り必須＋時間窓**で締める（定義は §「勢力を伸ばしている」の定義 と reference.md）。裏取れない意匠優良サイトは捨てず**「意匠枠」として区別明示で少数併記**（全体の最大3割）。日本語LP・古い/陳腐な意匠・テンプレ然としたものは落とす。
4. **軽量を守る**。各サイトの所見は**一言（1〜2行）**。FV型・構成・見せ方のどこが盗めるかに絞る。サイト別の長文ティアダウン・横断パターン大全は作らない（ユーザーが軽量リストを選択。深掘りが要るときは別途依頼を受けてから）。
5. **品質優先**。件数を埋めるために弱い候補を混ぜない。良いものが N に満たなければ正直に少なく出し、その旨を明記する。

## 「勢力を伸ばしている」の定義（モメンタム階層）

狙いは「勢い」自体ではなく、**そのLP/訴求が市場で機能している蓋然性が高い＝マネる価値がある**の代理指標。次で締める。

- **時間窓**: シグナルは**直近18〜24ヶ月以内**のもののみ有効。古い実績（数年前の調達だけ等）単独は失格。
- **強シグナル（1つで「勢い枠」採用可）**
  - 直近24ヶ月以内の資金調達（ラウンド名＋時期が Crunchbase / TechCrunch等信頼メディア / 自社プレス で裏取れる）
  - 著名アクセラレータの直近バッチ（例: YC 直近2期）
  - 公開された急成長指標（ARR・利用者数の前年比、決算・プレスで明示）
- **中シグナル（2つ以上で「勢い枠」採用可）**
  - 信頼メディアの注目/急成長企業リスト掲載（リスト自体の信頼性を吟味。SEOまとめは不可）
  - 採用の急拡大（複数職種同時募集・自社採用ページで確認）
  - 業界アワード直近受賞 かつ 現役プロダクト
- **弱シグナル（補強のみ・単独採用不可）**: SNS言及量、Product Hunt上位、コミュニティ話題 等
- **裏取り必須**: 「勢い枠」採用サイトは **シグナル種別＋時期＋出典URL** を1行で必ず記録（出典必須ルールと整合）。裏取れない／時間窓外／弱シグナルのみ → 「勢い枠」不採用。
- **意匠枠（区別明示・少数）**: 勢いは裏取れないが意匠/見せ方が明確に優れるものは、**`枠: 意匠（勢い未確認）` と明示**して併記可。ただし**最終リストの最大3割まで**。残り7割以上は「勢い枠」で埋める。埋まらなければ件数を減らす（意匠枠で水増ししない）。
- **現実的制約**: Similarweb/Crunchbase等の有料データに直アクセスは無い（WebSearch＋公開ページのPlaywrightのみ）。トラフィック急増の厳密検証は弱いので、実務上は**調達・アクセラレータ・信頼メディアリスト・採用**が主軸。これを前提に裏取りする。

## 実行フロー

```
- [ ] Step 1: 入力解釈・既定値確定・保存先決定
- [ ] Step 2: ロングリスト収集（独立リサーチSA・ハイブリッド）
- [ ] Step 3: 厳選（選定基準でN件に絞る）
- [ ] Step 4: サムネスクショ取得（Playwright）
- [ ] Step 5: 見どころ一言の確定
- [ ] Step 6: 出力（Markdown ＋ Canvasボード）＋保存提案
```

### Step 1: 入力解釈・既定値確定・保存先決定
1. 業界を確定（曖昧/未指定なら止めて確認）。媒体/件数/地域/補足の既定を埋める（件数=8, 地域=海外）。
2. 保存先を決める：
   - md: `work/knowledge/クリエイティブ/LP/lp-inspiration_<業界>_<yymm>.md`
   - スクショ: `work/knowledge/クリエイティブ/LP/_refs/<業界>_<YYYY-MM-DD>/`（無ければ作成）
3. ツールは deferred。**ToolSearch** で `WebSearch` / `WebFetch` / `browser_navigate` / `browser_wait_for` / `browser_snapshot` / `browser_take_screenshot` / `browser_resize` を先に読み込む。

### Step 2: ロングリスト収集（独立リサーチSA・必須・ハイブリッド）
オーケストレーターは収集を代行しない。独立リサーチサブエージェント（`general-purpose`）に下記タスクを渡して**20〜30候補のロングリスト**を作らせる。件数が多い/網羅性を上げたいときは「ギャラリー班」「Web検索班」の**2体並列**に分けてよい（過剰なファンアウトはしない＝最大2体）。

サブエージェントへの指示骨子（自己完結で渡す。会話文脈は見えない前提）：
- 目的: `<業界>` の新規LP着想用に、**海外の「イケてる／勢力を伸ばしている」サイト・LP**を集める。
- **ハイブリッド収集（両方やる）**:
  - **A. デザインギャラリー横断**（意匠の鮮度）。JS描画なので `browser_navigate`→`browser_wait_for`→`browser_snapshot` で見る（`WebFetch` は不可になりがち）。`reference.md` の「ギャラリー一覧」と検索パスを使い、業界カテゴリ/タグで絞って収集。
  - **B. Web検索**（事業の勢い）。`reference.md` の「検索クエリ雛形」で `WebSearch` し、資金調達/急成長/話題の実プロダクトの**本物のLP/トップページ**へ到達。ギャラリー内サムネではなくライブサイトURLを取る。
- 各候補に必ず付ける: サイト名 / ライブURL / 業界カテゴリ / **出典（ギャラリー名 or 検索クエリ）** / **モメンタム根拠**（§定義の強/中/弱どれか＋時期＋裏取り出典URL。`reference.md` のモメンタム検証クエリで会社名×調達/採用を裏取る。裏取れなければ「未確認」と正直に書く） / 見どころ仮（FV型・構成・見せ方で着想になる点を一言）。
- ロングリスト時点で各候補に **暫定枠**（`勢い` 候補 / `意匠` 候補）を付ける。ギャラリー発は意匠選別なので原則 `意匠` 候補から始め、モメンタムが裏取れたものだけ `勢い` へ格上げ。
- 除外: 日本語主体LP（地域指定が日本でない限り）、リンク切れ、古い/テンプレ然とした意匠、業界とズレるもの。
- 出力: 上記フィールドを持つ候補リスト（Markdown表 or 箇条書き）。

### Step 3: 厳選（N件・枠別）
ロングリストから**選定基準**で件数N件に絞る。基準（明示してログに残す）：
- ① 海外・地域条件適合 ② 意匠の鮮度（陳腐でない・最近のトレンドを体現） ③ **モメンタム判定**（§「勢力を伸ばしている」の定義に機械的に当てる：時間窓18〜24ヶ月内か／強1 or 中2／裏取り出典URLがあるか） ④ 業界・補足との近さ ⑤ 見せ方/構成の**多様性**（同型ばかりにしない＝FV型・構成パターンを散らす） ⑥ 重複・同一企業の別ドメイン排除。
- **枠の確定**: ③を満たし裏取りURLあり → `勢い枠`。意匠は優れるが③未達/未確認 → `意匠枠`。
- **クォータ厳守**: `意匠枠` は最終リストの**最大3割**。`勢い枠` が7割に届かなければ件数Nを下げる（意匠枠で水増ししない）。
- 良候補が N 未満なら無理に埋めず、実件数＋枠内訳（勢い◯/意匠◯）＋理由を明記（品質優先）。

### Step 4: サムネスクショ取得（オーケストレーターがツール実行）
厳選した各サイトについて Playwright で取得：
- `browser_navigate <URL>` → `browser_resize`(1280x800) → `browser_wait_for`（描画待ち）→ `browser_take_screenshot`（FV=ファーストビュー基本。構成も見たい場合は `fullPage:true` も可）。保存先: `_refs/<業界>_<YYYY-MM-DD>/<連番>_<サイト名スラッグ>.png`。
- 取得失敗（重い/ブロック/タイムアウト）したサイトは `スクショ取得不可` と明記して**リストには残す**（URLと出典は価値がある）。落とさない。

### Step 5: 見どころ一言の確定
各サイトに**1〜2行**で「新規LPに盗める着眼」を確定。観点（どれか1つに絞って具体に）：
- **FV型**: 例「製品UIを大きく見せる型／一文ベネフィット＋デモ動画型／ソーシャルプルーフ前傾型」
- **構成**: 例「課題→デモ→数値実績→料金の順で迷わせない」「ユースケース別タブで自分ごと化」
- **見せ方**: 例「余白とモーションで高級感」「ダーク基調＋グラデで先進感」「比較表でスイッチ訴求」
- 媒体指定があれば「その媒体流入で効くか」を一言加味。
- 出典（ギャラリー名 or 検索クエリ）と取得日、**枠（勢い/意匠）とモメンタム根拠1行**を必ず併記。

### Step 6: 出力（Markdown ＋ Canvasボード）
**6-1. Markdown** を保存先（Step1）へ。テンプレ：

```markdown
# LP着想スカウト — <業界>（<YYYY-MM-DD>）

- 業界: <業界> ／ 媒体: <媒体 or 指定なし> ／ 地域: <地域> ／ 件数: <実N>（勢い枠 <a> / 意匠枠 <b>・意匠枠は最大3割）
- 収集方式: デザインギャラリー横断 ＋ Web検索（ハイブリッド）
- モメンタム基準: 時間窓18〜24ヶ月／強1 or 中2＋裏取りURL（§定義準拠）
- 選定基準: 海外適合/意匠鮮度/モメンタム判定/業界近接/見せ方の多様性

## 勢い枠（モメンタム裏取り済み）

### 1. <サイト名>
- URL: <ライブURL>
- カテゴリ: <業界カテゴリ>
- 出典: <ギャラリー名 or 検索クエリ>（取得 <YYYY-MM-DD>）
- 枠: 勢い
- モメンタム根拠: <強/中シグナル種別 ＋ 時期（例: 2025-09 Series B $40M） ＋ 裏取りURL>
- スクショ: `_refs/<業界>_<YYYY-MM-DD>/01_<slug>.png`
- 見どころ: <FV型/構成/見せ方の着眼を1〜2行>

（…勢い枠 続き…）

## 意匠枠（勢い未確認・少数・最大3割）

### <通番>. <サイト名>
- URL: <ライブURL> ／ カテゴリ: <業界カテゴリ>
- 出典: <ギャラリー名>（取得 <YYYY-MM-DD>）
- 枠: 意匠（勢い未確認）
- スクショ: `_refs/<業界>_<YYYY-MM-DD>/<連番>_<slug>.png`
- 見どころ: <FV型/構成/見せ方の着眼を1〜2行>

（…意匠枠 続き…）

## ざっくり傾向（任意・3行以内）
- <この業界の海外LPで今多いFV型/構成の傾向を最大3点。軽量厳守。無ければ省略>

## 前提・出典
- 収集ギャラリー: <使ったギャラリー列挙>
- 主な検索クエリ: <使ったクエリ列挙（モメンタム裏取りクエリ含む）>
- 枠内訳と未達理由: <勢い◯/意匠◯。勢いが7割未満なら件数を下げた旨と理由>
- 取得不可サイト: <あれば>
```

> 「ざっくり傾向」は着想の足がかりとして**最大3行**まで。これを越える横断分析・サイト別ティアダウンはこのスキルの範囲外（軽量リスト厳守）。深掘りが要るときはユーザーに確認してから別途。

**6-2. Canvasボード**: `canvas` スキルを使い、スクショサムネ＋サイト名＋見どころ＋出典＋**枠バッジ（勢い/意匠）**＋モメンタム根拠をグリッドで並べたブラウズ可能なボードを作る。勢い枠と意匠枠は視覚的に区別（色/セクション分け）。（`canvas` スキルのSKILL.mdを読んでから `.canvas.tsx` を作成）。画像はStep4の保存パスを参照。

**6-3. 保存提案**: md・スクショの保存先を提示し、別案件フォルダ等に置きたいか確認。`work/client/<案件名>/` が文脈にあれば併せて保存先を提案。
