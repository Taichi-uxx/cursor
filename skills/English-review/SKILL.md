# English-review — 英単語・フレーズ復習クイズ

`/English-review [ファイルパス]`

## 入力

| 項目 | 必須 | 内容 |
|---|---|---|
| ファイルパス | 任意 | 出題対象の英語学習mdファイル。省略時は `~/.cursor/English/vocabulary.md` |

## 対象ファイル形式

想定する主なファイル:
- `~/.cursor/English/vocabulary.md` （単語ストック・NARUTO世界観）
- `~/.cursor/English/reviewing_cambly_重要度順.md` （Cambly実践レビュー・重要度順）
- 上記と同構造の他ファイル

**基本構造（両ファイル共通）:**
```
### <英単語 or フレーズ>   ← 「/」区切りで複数表現の場合あり（例: `I get it / I get that`）
ミス：×（または ××、×××、... ）  ← このスキルの対象は「ミス：」欄が存在するエントリのみ
重要度：★★★★★
Meaning：<意味・訳>
Example：<例文>
```

**Meaning書式のバリエーション（両対応必須）:**

パターンA（`vocabulary.md`）: 英語+カッコ内日本語
```
Meaning：Real or authentic.（本物の／マジの）
```

パターンB（`reviewing_cambly_重要度順.md`）: 日本語直書き
```
Meaning：なるほど／納得できる
```

**複数意味エントリ:**
```
### <word>
ミス：××
重要度：★★★★
Meaning：
　1. <意味1>
　2. <意味2>
Example：
　1. <例文1>
　2. <例文2>
```

## 実行フロー

```
- [ ] Step 1: ファイル読み込み・エントリのパース
- [ ] Step 2: ミス欄がある（×が1つ以上）エントリを抽出＋×の数で降順ソート
- [ ] Step 3: 30問ずつバッチ出題（問題は英語のみ）
- [ ] Step 4: ユーザーが「答え」と言ったら答え合わせ（英単語＋日本語訳）
- [ ] Step 5: 間違えた問題番号を聞く
- [ ] Step 6: 該当エントリのミス欄に×を1つ追加（Editツールで実ファイル更新）
- [ ] Step 7: 未出題の×付きエントリが残っていれば Step 3 に戻る
```

### Step 1: パース

- ファイルを `### ` で分割し、各エントリを構造化
- 各エントリから以下を取得:
  - `word`: `### ` の直後の見出し（`/` 区切りの複数表現もそのまま保持）
  - `mistake_count`: `ミス：` 行の × の数（`ミス：` 行が存在しなければそのエントリは対象外）
  - `meaning_jp`: `Meaning：` から日本語訳を抽出（下記ルール参照）
  - `example`: `Example：` 内の例文（複数あれば全て）

**`meaning_jp` 抽出ルール（両書式対応）:**

1. `（...）` が含まれる場合 → カッコ内を日本語訳として採用（vocabulary.md想定）
2. `（...）` が無い場合 → `Meaning：` の後ろ全体を日本語訳として採用（reviewing_cambly想定）
3. 複数意味エントリ（`　1. ...　2. ...`）は各行ごとに上記ルールを適用
4. どちらのパターンでも「日本語部分だけ」を取り出す（英語の意味説明があってもそれは訳ではない）

### Step 2: フィルタ＋ソート

- `mistake_count >= 1` のエントリのみ対象
- `mistake_count` の降順でソート（×が多い＝忘れやすい＝優先）
- 同数の場合は元ファイル出現順を維持

### Step 3: 出題（30問／バッチ）

**問題文には日本語を一切含めない。** 英単語（フレーズ）と例文のみ。

出力形式:
```
**Q1. <word>**
"<example sentence>"

**Q2. <word>**
"<example sentence>"

...

**Q30. <word>**
"<example sentence>"

---

答え合わせしたくなったら「答え」って言ってください。
```

複数例文があるエントリは、例文1つを代表として選ぶ（原則1番目）。

### Step 4: 答え合わせ

ユーザーが「答え」「answer」等の合図を出したら、以下の形式で回答:

```
**Q1. <word>** — <日本語訳>
例文：<英語の例文>
訳：<例文の日本語訳>

**Q2. <word>** — <日本語訳>
例文：<英語の例文>
訳：<例文の日本語訳>

...
```

**例文の日本語訳は必ず付ける**（単語単体ではなく例文とセットで覚えるため）。
例文の日本語訳が元ファイルに無い場合は、その場で自然な日本語に訳して提示する。

複数意味あるエントリは全て番号付きで列挙:
```
**Q3. crack** — ①ひび／割れ目 ②パキッという音 ③難問を解く・見破る
例文：Shikamaru managed to crack the enemy's formation strategy.
訳：シカマルは敵の陣形戦略を見破ることに成功した。
```

末尾で:
```
---
間違えた問題番号を教えてください（例：「1, 5, 8」「Q3とQ7」など）。
```

### Step 5: 間違えた番号を受け取る

- 「1, 5, 8」「Q3とQ7」「全部」「なし」等の自由入力を解釈
- 番号を特定 → 対応する `word` を確定

### Step 6: ミス欄に×追加

**Editツールで実ファイルを更新する。**

対象エントリの `ミス：×...` 行を `ミス：×...×`（×を1つ追加）に置換。

- 対象エントリの直前の `### <word>` を含めてコンテキストを一意にする:
  ```
  ### <word>
  ミス：×（旧値）
  ```
  → 
  ```
  ### <word>
  ミス：××（新値）
  ```

- 複数の間違いがあれば、それぞれ個別に Edit する（1回ずつ）

更新完了後、以下の1行でまとめ:
```
更新完了：<word1>, <word2>, ... に×を1つ追加しました。
```

### Step 7: 次バッチへ

- 未出題の×付きエントリが31問目以降に残っていれば「次の30問行きますか？」と確認
- 「はい」等の合図で次バッチを Step 3 から実行
- 「もういい」「終わり」等で終了

全て出題しきったら:
```
全ての×付きエントリの出題が完了しました。おつかれさま。
```

## 実行原則

1. **問題文に日本語を絶対に混ぜない**。単語/フレーズと例文のみ。
2. **答え合わせの前に答えを見せない**。ユーザーが「答え」と明示するまで待つ。
3. **答えは「単語の意味＋例文＋例文の日本語訳」の3点セット必須**。例文の訳が元ファイルに無ければその場で自然な日本語に訳す。単語の訳だけで済ませない。
4. **×の追加は実ファイルへの反映を必ず行う**（Editツール）。会話上だけで済ませない。
5. **×の数によるソートを守る**。多い順から先に出題（＝忘れやすいものから優先強化）。
6. **1バッチ30問固定**。それ以下の場合は残り全部を1バッチで出す（例: ×付きが12個なら1バッチ12問）。
7. **重複出題しない**。同一セッション内で同じエントリを2回出さない。
8. **ミス欄がないエントリは絶対に対象外**（例：`### farewell party` のように `重要度：` 直下にミス行が無いもの）。
