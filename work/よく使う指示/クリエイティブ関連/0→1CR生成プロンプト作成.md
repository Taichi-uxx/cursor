# 指示

送付するLPから、情報を抽出して、広告バナー生成用のテンプレを5パターン作成して下さい。

いずれもバナーとして異なる見せ方になるように、訴求やデザインを変更してバリエーションを増やすことが1番の目的になります。

情報が足りない場合はHPを回遊して、必要な情報を可能な限り集めてください。時間はかかっても構いません。



# 制約

- 画像は必ず正方形で生成

- ハルシネーション防止のために、抽出した情報の正誤を確認して誤った情報はアウトプットに記載しない



# テンプレの型（[]内だけ修正、その他はそのまま出力）

- 対象LP：http://---（入力されたLPのURLを記載）

- [①広告目的] のための [②サイズ/比率] の [③言語] バナーを制作。

- ターゲットは [④ターゲット層]、訴求は [⑤主要ベネフィット] と [⑥サブベネフィット/根拠]。

- ブランドトーンは [⑦トーン/世界観]、ブランドカラーは [⑧メインカラー] と [⑨アクセントカラー]。

- 必須要素：[⑩商品（またはサービス）ビジュアル]、[⑪キャッチコピー]、[⑫補足テキスト（※など）]、[⑬CTA文言]、[⑭CTAの視覚要素（ボタン/バッジ/矢印等）]。

- レイアウトは固定せず、以下のいずれか（または組み合わせ）で最適化して提案：

  - ヒーロー構図（中央大きく）

  - スプリット構図（左右/上下分割）

  - Z型導線、F型導線、中央集中

  - 余白多めのミニマル、情報多めのダイレクト

- [⑮背景の雰囲気]（例：濃色ボケ、ハイキー、抽象図形、生活シーン）と [⑯質感]（例：高級、クリーン、テック）を表現。

- テキストは読みやすく、商用広告品質、シャープ、高解像度。ロゴの正確な再現は不要（後入れ前提）。



# 生成例

- ブランドトーンは [濃紺]、ブランドカラーは [濃紺] と [金]。

- 必須要素：[⑩商品（またはサービス）ビジュアル]、[メインテキスト：ぼやけ・かすみが気になる方へ]、[補足テキスト：見る力をサポート]、[CTA文言：初回50％OFF/アンケートはこちら]、[CTAの視覚要素：赤]。

- レイアウトは固定せず、以下のいずれか（または組み合わせ）で最適化して提案：

  - ヒーロー構図（中央大きく）

  - スプリット構図（左右/上下分割）

  - Z型導線、F型導線、中央集中

  - 余白多めのミニマル、情報多めのダイレクト

- [⑮背景の雰囲気：濃色ボケ]と [⑯高級]を表現。
