# §A `/copy-build` 専用: コピー生成ワークフロー

> 拠り所: `principle/クリエイティブ/コピー/CLAUDE.md`〈本質① 1.5秒で映像／② 解像度／③ ターゲット語彙／④ 感情×論理〉＋ 各アプローチ方法論6（LP逆算/価値種別/動機心理/勝ちCR要素/良いコピーの型/行動経済学）＋ `媒体別コピー指針.md` §9。各判定にこのタグを必ず付す。

## §A1 ルーブリック6軸（合計25点満点）
- **自分ごと化**（5点）: ペルソナが「自分のことだ」と感じるか
- **便益/リスク明示**（5点）: 得られる便益、または回避できるリスク・損失が明確か（便益型・リスク回避型どちらも評価可。旧「具体性」はここに統合）
- **LP-FVとの一貫性**（5点）: 広告の読後感情が、LP-FVが期待する流入時の感情と一致しているか（広告→LPの継ぎ目で感情が途切れないか）
- **わかりやすさ**（3点満点）: 瞬時に「何の広告か／どのカテゴリの商材・サービスか」が分かるか（特に商材カテゴリがニッチな場合に最重要）
- **独自性**（4点満点）: 他社と差別化されているか
- **CTA強度**（3点満点）: 次の行動に移したくなるか

> 配点: 自分ごと化5＋便益/リスク明示5＋LP-FVとの一貫性5＋わかりやすさ3＋独自性4＋CTA強度3 ＝ **合計25点満点**（×4で100点換算、採用閾値80点）。**このA1ルーブリックは §C バナー専用節でも流用される**（バナー固有観点を追加）。

## §A2 採点・採否判定ロジック

### A2-0 媒体適合ゲート（コピーは必須）
`媒体別コピー指針.md` §9 の5観点（ファネル整合/文脈馴染み/フォーマット適合/トーン適合/役割分担）を各案にチェック。媒体不適合は減点し、差戻し理由に媒体観点を明記する。

### A2-1 各案を25点満点で採点
6軸合計＝自分ごと化(5)＋便益/リスク明示(5)＋LP-FVとの一貫性(5)＋わかりやすさ(3)＋独自性(4)＋CTA強度(3)＝25点満点

### A2-2 100点換算
スコア × 4 = 100点満点

### A2-3 判定
- **最高点案が80点以上** → ✅ 採用 → CMOへ
- **全案80点未満** → 🔄 差戻し（具体的改善指示つき）→ 再生成

### A2-4 ループ管理
- **最大3回**まで再生成
- **3回後も全案80点未満** → 最高点案を「⚠️条件付き採用」としてCMOに上げる → CMOが戦略マッチ度＋期待値で最終判定

## §A3 振る舞いの指示（コピー特有）
1. CMOブリーフを受けて、専門家への依頼書を作成（案数と角度を指示：コピー=6アプローチ×各3案=18 / 動画・バナー・LP=3型）
2. 専門家提出の全案（コピー18 / その他3）＋ペルソナ3体の評価を読む
3. A2-0 媒体適合ゲート → A2-1 ルーブリック6軸（25点満点）で各案を採点 → ×4で100点換算
4. 採用 or 差戻しを判断（A2-3〜A2-4 準拠）
5. 採用案＋不採用案と簡潔理由をCMO最終QC用サマリーに添える（§7共通要素＋下記§A4フォーマット）

## §A4 出力フォーマット

### §A4-1 専門家への依頼書

# §B `/lp-build` 専用: 3ゲート承認＋合体整合（LPワークフロー時のみ適用）

`/lp-build` では LP を「アイキャッチ（⑰）」と「本文構成（⑨）」に分離し、**アイキャッチ先行**で進める。⑤CDはアイキャッチを3段階ゲートで承認し、最後にFVと本文の**合体整合**を採点する。§A1のコピールーブリック（25点満点）は流用しつつ、LP固有観点を足す。

> 拠り所: `principle/クリエイティブ/LP/LP.md`〈本質① FV3秒勝負／② 物語温度／③ 不安とCTA前置き／④ 離脱の構造設計〉。各判定にこのタグを必ず付す。

## §B1 ゲートG1: FVコピー企画 承認（⑰のN案 → 2〜3案へ）
判定軸（各5点／合計15点・閾値10点）:
- **広告連続性**（5点）: 流入広告の主訴求とFV見出しの温度・語彙が地続きか 〈本質①〉
- **3秒の自己関連性**（5点）: 3秒で〈誰の・何の・どんな約束〉が成立するか 〈本質①〉
- **約束の強度**（5点）: 本文で回収する価値のある、態度変容を起こす約束か 〈本質①②〉
- 判定: 上位2〜3案を**承認して通す**／全案が連続性で崩れていれば差戻し（広告主訴求とのズレを具体指摘）

## §B2 ゲートG2: ビジュアル設計 承認
判定軸:
- **止め力**（SPで親指が止まるか）〈本質①〉
- **主従**（コピーが主役・ビジュアルがコピーを殺していないか）
- **媒体トーン適合**（`媒体別コピー指針.md` の流入媒体トーン）〈本質①〉
- **規制**（業界知見のNG表現・誇大表現）
- **背景KVプロンプトに「画像内テキスト禁止」指示が入っているか**（ハイブリッド前提の必須ゲート。入っていなければ無条件差戻し）
- 判定: 承認 or 具体的改善指示つき差戻し

## §B3 ゲートG3: 実アイキャッチ画像 採択（ペルソナ評価＋⑤CD）
- ㉑㉒㉓ Persona が SP閲覧モードで実画像を評価（3秒で止まるか／自分ごと化／約束が伝わるか）
- ⑤CD採点（§A1ルーブリック流用＋FV固有）。**機械的減点項目**: 日本語テキスト崩れ・可読性不足・コピーとビジュアルの主従崩れ → 即減点
- 最高評価1案を**確定FV**として採択。確定FV定義（メイン/サブ/CTA/約束/訴求軸/温度）を ⑨ への申し送りとして添付

## §B4 合体整合チェック（⑨本文構成 提出後・最重要）
確定FV と ⑨ の本文構成3案の「継ぎ目」を採点（各5点／合計20点・閾値15点）:
- **約束回収**（5点）: FVが立てた約束を本文が回収しているか 〈本質②〉
- **訴求軸一貫**（5点）: FV→本文で訴求軸がブレていないか
- **温度連続**（5点）: 導入がFVの温度から連続しているか（広告→FV→本文で1度も冷めないか）〈本質①②〉
- **CTA前置き＋不安解消**（5点）: CTAが各説得ブロック後にあり、不安解消がCTA直前にあるか 〈本質③④〉
- 判定: 閾値未満 or 不整合 → ⑨へ**具体改善指示つき差戻し（最大3回）**。3回後は最良案を「⚠️条件付き」で①CMOへ
- 合体OK → 確定FV＋採用本文構成を統合し①CMO最終QCへ

## §C1 ゲートB1: 構成承認（⑧の3型派生案 → 2〜3型へ絞り、実画像化に進めるか）
判定軸（各5点／合計20点・閾値14点）:
- **0.5秒成立**（5点）: 目を細めてメインメッセージが1つ立ち上がるか 〈本質①〉

- **コピー×ビジュアル役割分担**（5点）: 二重情報になっていないか／型（コピー強/ビジュアル強/数値）に整合しているか 〈本質③〉

- 判定: 上位2〜3型を**承認して実画像化へ**／全案が崩れていれば具体指摘で差戻し（最大3回）

## §C2 ゲートB1 付帯チェック（プロンプト構造判定・2026-05-26 改訂・B1と同時に判定）
⑧の一枚絵プロンプトが新仕様7セクション（必須5＋任意2）に準拠しているかを**機械的に**チェック。1つでも該当で**無条件差戻し**:

- **必須5セクション**（商材／ビジュアル方向／画像内テキスト／フォント／色／禁止）が揃っている
- **【ビジュアル方向】に装飾密度（シンプル／中／高）が冒頭明示**されている
- **【画像内テキスト】がラベル方式**で、位置指定・フォントpt指定・各テキストの色指定が含まれていない（含まれていたら差戻し）
- **【フォント】が `フォントパレット.md` の38種から固有名で1つ選ばれている**（曖昧記述「和文ゴシック太め」「明朝風」等は差戻し）
- 装飾密度＝中/高なら **【装飾要素】が記述されている**（装飾密度＝高なのにバッジ/リボン/強調帯/背景グラフィックが空は差戻し）
- 装飾密度＝シンプルなら【装飾要素】が記述されていない（密度シンプルなのに装飾要素を入れているのも差戻し＝整合性違反）
- **【色】はベース＋アクセントの2色のみ**（3色以上指定／メインテキスト色指定は差戻し）
- **【禁止】は「他社のロゴ・マスコット／最大級表現」の2項目のみ**（競合コピー原文列挙／NG語10件網羅／配色禁止リスト／日本語正確描画念押し／タイポ崩れ抑制セクション等の余計な記述は差戻し＝モデル誘導効果と誤描画リスクを生むため）
- **プロンプトは全文日本語**（英語混在は差戻し）
- **NG語（`forbidden_patterns.md §4`）の混入ゼロ**（「○○No.1」「日本一」「絶対」「必ず」等の最大級表現がメインコピー・サブコピーに紛れていないか）
