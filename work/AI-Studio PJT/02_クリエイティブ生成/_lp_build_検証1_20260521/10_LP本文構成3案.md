- **FVの「凛とした内省・健康投資の落ち着き」を、本文では『3人の判断プロセスを物語として追体験させる』形に転換**。1人目=Cペルソナ近似（40代健康駆動）／2人目=Bペルソナ近似（30代ワーママ実利精査）／3人目=軽度〜中度の30代女性。**ただし「体験談・お客様の声」は限定解除4要件未充足ではLP掲載NG**（クリニック.md §鉄則2）のため、**個人体験談は使わず、「こういう判断軸で選ぶ人がいる」という"判断プロセスの構造紹介"として記述**する（個別実名・実顔・実数値は使わない）。共感ストーリー→転換→解決→決断の物語装置で温度カーブを階段状に上げる（LP.md §勝ち筋B共感ストーリーFV型の本文版応用）。

> **重要な設計制約**: 物語型は典型的に「お客様の声」を主軸にしがちだが、自由診療＋治療内容＋費用＋主なリスクの**限定解除4要件**を同一画面で全て満たさない患者体験談はLP掲載NG。本案Cは**「実在患者の体験談」ではなく「判断プロセスの構造紹介（"こういう判断軸で選ぶ人がいる"の中立的記述）」**として設計する。実在症例の Before/After 写真や個人名・実発言を使う場合は、症例ページ側で限定解除4要件を同一画面に必ず併記する形でのみ運用する。本案を最終採択する場合、⑤CDと法務での個別確認を強く推奨する。

## 3案比較・優劣の見立て（**⑤CD合体整合チェックへの準備**）

### 各案の強み・弱み

#### 案A：PASONA型 — 「健康投資としての全顎矯正、その地図を1枚に。」
- **強み**:
  - PASONA構造で温度カーブを階段状に上げる「教科書的勝ち筋」（LP.md §勝ち筋C「PASONA縦＋各CTA」）
  - Problem→Agitationで自己関連性を確定させた後、Solution→Narrowingで透明性を提供する構造が**副B・規制ゲートCの精査モードと最も相性が良い**
  - セクション数が11と多めだが、CTA5箇所＋SP追従で「決断した瞬間に押せる」配置が最強
  - C評価§本文回収10項目を**最も自然に**配置できる（#7-#9に集約）
- **弱み**:
  - PASONA構造の弱点として、Problem→Agitationで「不安煽り」に見えるリスクがある（本案では事実訴求・長期視点で煽りを避ける設計だが、コピーライティング段階で煽り口調に堕ちると規制適合性が崩れる）
  - 副軸b流入の「マウスピースで本当に治るのか」という最初の懐疑に対し、案Bの「Interestで正面回答」より遅れて応える構造（Solution段で初めて出る）

#### 案B：AIDMA型 — 「気づかれていない『噛み合わせ起因の不調』に、医療として答える。」
- **強み**:
  - **副軸b流入の「マウスピースで本当に治るのか／実績・規模・保証で安心したい」温度に最も連続性が取りやすい**（#3 Interest段で最初の懐疑に正面回答）
  - AIDMA の Attention→Interest→Desire→Memory→Action の知的順序は、副軸b流入の懐疑→検証→納得→記憶→行動という精査モード読者の頭の中の順序と最も親和性が高い
  - **不安煽り（Problem→Agitation）がないため、規制適合性のリスクが PASONA より構造的に低い**
  - Memory段（#6-#8）で「保証条件→医師・運営→適応範囲」と精査要素を3層で記憶定着させる構造が、Cの「3院ハシゴ・2院目以降の比較材料」に最も乗りやすい
- **弱み**:
  - AIDMA の Desire 段（#5）でベネフィットを語る際、「美容ではなく機能性」を維持するため**ベネフィットの感情起動力がPASONA案Aより弱い**（「治る」「軽くなる」が使えない制約上）
  - PASONAの「Problemで自己関連性を確定」のような強い起点フックがなく、流入広告の温度連続性に依存する度合いが高い

#### 案C：物語型 — 「40代で『噛み合わせから』を選んだ、3人の判断」
- **強み**:
  - LP.md §勝ち筋B「共感ストーリーFV型」の本文応用として、読者が「自分の話」と認識する確率が最も高い設計
  - 「実在患者の体験談」ではなく「判断プロセスの構造紹介」として規制適合させる設計で、**患者像を物語で描きながら規制をクリアする工夫**を内包
  - C評価§本文回収10項目を物語の文脈で自然に配置できる
- **弱み**:
  - **規制適合性のリスクが3案中最大**。「判断プロセスの構造紹介」と「事実上の患者体験談」の線引きが運用段階で曖昧になりやすく、限定解除4要件未充足の体験談に転落するリスク
  - 物語の中で「治った」「軽くなった」を一切書かない制約上、**感情起動力が物語型本来の強さを発揮しきれない**
  - 田村の「中途半端なアウトプットは出さない」基準で見ると、「規制適合と感情起動の折衷で両方が中途半端になる」懸念
  - 最終QCで法務確認が必須となり、運用コストが PASONA・AIDMA より高い

### 推奨採用案（次工程⑤CD合体整合チェックの参考意見）

**推奨採用案: 案B（AIDMA型）**

**理由（5段階で展開）**:

**第1段階 — 確定FVとの整合性**: 確定FVは「副B＋規制ゲートC」を主役に置き、流入は副軸b（仮説3 症例幅・安心の中でも全顎・保証側文脈）専用クリエとして並走配信する前提（`09_G3_CD採択と確定FV.md` §5）。副軸b流入の「マウスピースで本当に治るのか／実績・規模・保証で安心したい」温度を**本文導入の最初のセクション**で正面受けする構造は、3案中で案B（AIDMA）が最も自然。案A（PASONA）はProblem→Agitationを経由してSolutionに至るため、副軸b流入の最初の懐疑に応えるまで2段階遅れる。

**第2段階 — 規制適合性のリスク管理**: 案A（PASONA）はProblem→Agitationで「不安煽り」に見えるリスクが構造的にあり、コピーライティング段階で煽り口調に堕ちると規制適合性が崩れる。案C（物語型）は体験談規制のリスクが3案中最大で、最終QC時に法務確認が必須となり運用コストが高い。**案B（AIDMA）はProblem/Agitationがないため、規制適合性のリスクが構造的に最も低い**。クリニック.md §鉄則「最大級表現NG」「効果断定NG」「体験談NG」の3点に対し、AIDMAは構造的に違反しにくい設計。

**第3段階 — 副B・規制ゲートCの精査モードへの適合**: AIDMA の Memory 段（#6-#8）で「保証条件→医師・運営→適応範囲」を3層で記憶定着させる構造は、Bの「総額と保証条件をスプレッドシートで詰める」精査モード、Cの「3院ハシゴの2院目以降の比較材料として精査リストに入れる」精査モードに最も乗りやすい。B評価§32/40・C評価§29/40で両ペルソナがFV段階で「保存して今夜PCで詳細を読む」「精査リストに入れる」と判定した行動を、本文で受け止めて「数日後の予約行動」につなげる動線が AIDMA の Memory→Action 構造と完全合致する。

**第4段階 — CMO§7事業LTV構造との整合**: 自由診療歯科は「初回検診→契約→継続治療（数ヶ月〜2年）→紹介」のLTV型ビジネス。スターター9.9万のみで取って全顎36万に上がらない設計は事業利益視点で弱い。案Bの Memory 段で全顎36万＋保証条件＋医師経歴を3層記憶定着させる設計は、**「契約見込みのある来店質を最大化」（CMO§7）に直接寄与**する。AIDMA の Memory→Action 構造が「数日後に思い出して予約」のワーママB行動と完全合致するため、CMO§2「FV主軸=A／本文中核=B（仮説3実績・保証・出典）／規制ゲートC」役割分担の中でも、本文中核=Bの設計責任を最も果たせる。

**第5段階 — 田村判断軸への適合**: 「So What・3秒判定・温度連続性・態度変容・売上利益・感情を動かす」の6軸で案Bが ◎+ を3軸（3秒判定／温度連続性／売上利益）獲得し、他3軸も ◎ で揃う。中途半端なアウトプットを避ける品質優先方針に対し、案Bは「規制適合性と精査モードへの適合」を両立した設計で、両方が中途半端化するリスクが3案中最も低い。

**補欠候補**: 案A（PASONA型）。PASONA構造の「教科書的勝ち筋」（LP.md §勝ち筋C）で副B・規制ゲートCの精査モードと完全マッチする設計で、案B採用後の差戻し時の最有力代替。Problem→Agitationの不安煽り口調を回避できれば、A流入（仮説2諦め本音）併走配信時の本文としても応用可能（案A の Problem を「諦めていた本音」フックに振り替える派生案）。

**最終判断は⑤CDが合体整合チェックで決定**: ⑨は3案を地続き設計まで責任を持つが、採点・採否は⑤CDの担当領域（⑨ロール定義§やらないこと）。⑤CDが合体整合採点（20点中15点以上）と3ペルソナ採点で最終決定する。
