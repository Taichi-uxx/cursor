## 案C-1
- メインコピー（20字以内）:「矯正、もう諦めた人へ」（10字）
- サブコピー（30字以内）:「”80万円が当たり前”は、もう昔の話。」（19字）
- CTAラベル:「▶ 無料で見積もりだけ見る」
- オファー要素: 3ヶ月24枚／90,000円税抜〜・検査費0円・LINEで完結・後戻り治療一生無料
- 狙うペルソナ: A（価格で諦めかけてる契約社員ミナ）
- 広告連続性ロジック: 流入広告主訴求「3ヶ月9万円〜のマウスピース矯正／検査無料」→ FVで「諦めていたあなた」と名指し→「”80万円が当たり前”は昔の話」と前提を覆す。広告で芽生えた「え、本当に？」を、FVで「そう、あなたが信じてた常識のほうが古かった」と肯定する地続き。価格驚きの温度を一度も下げない。
- 3秒判定: 誰の=矯正を価格で諦めた20代女性 / 何の=マウスピース矯正の新しい価格基準 / どんな約束=過去の見積もり額の常識をアップデートできる
- 担当アプローチからの紐付け根拠（最重要・このSAの差別化点）:
  - 採用したパーツ要素番号: **要素1[行動・思考の否定・問いかけ]** ＋ **要素2[常識の否定]**（2要素併用）
  - その要素の言語パターンをどうカスタマイズしたか:
    - 要素1の「まだ◯◯している人」「◯◯やめてください」型（例: #085「まだ手袋つけて白髪染めしている人」／#46「まだプロテイン飲んでるの?」）の”過去の行動を名指しで止める”構造を採用。ただし「やめろ」と命令する強さは、自費医療×IGの上品トーンに不適合のため、「諦めた人へ」という静かな呼びかけに落とし込んだ（IG・自然光・審美ラグジュアリーに馴染ませる媒体補正）。
    - 要素2の「◯◯は間違い!?」「実は9割が知らない◯◯」型（例: #01,05「ダイエット=運動+食事制限は間違い!?」／#085「実は9割が知らない白髪の一因」）の”信じてた前提を覆す”構造を、サブで「”80万円が当たり前”は、もう昔の話」と数字＋常識転倒で具現化。ミナのトラウマ「3年前のW社88万見積もり」に直接刺さる。
  - 23要素のどの語感を継承して何を排除したか:
    - 継承: 「呼びかけ＋常識転倒」の二段構え／数字を1つだけ置く節度／「？」「！？」のフックではなく句点で止める静けさ
    - 排除: 「やばい」「最強」「神」など俗っぽい煽り語（IG・クリニック・規制リスク全てに不適）／「絶対」「最新」「No.1」など医療広告ガイドライン違反語／「諦めるな！」など強要トーン（諦め癖のあるミナを突き放す）
- 規制適合性自己チェック: 最大級表現=なし（”当たり前は昔の話”は市場相場の変化を示す事実言及で誇大表現に該当せず） / 体験談引用=なし / 出典なし数値=なし（”80万円”は3年前のW社見積もり例の言及で、自社優位の数値主張ではない） / 自称専門医=なし

## 案C-2
- メインコピー（20字以内）:「式まで半年。前歯、間に合う。」（14字）
- サブコピー（30字以内）:「実は、前歯だけなら3ヶ月で動き出します。」（21字）
- CTAラベル:「▶ 検査0円で診てもらう」
- オファー要素: 部分矯正対応・3ヶ月24枚〜・検査費0円・LINE当日予約OK・後戻り一生無料保証
- 狙うペルソナ: B（式までに完璧にしたい婚約30歳サキ）
- 広告連続性ロジック: 流入広告主訴求「前歯だけ・短期間・式に間に合う／無料検査」→ FVで「式まで半年。前歯、間に合う」と”間に合う”を完了形宣言→サブで「実は、前歯だけなら3ヶ月で」と新常識を提示。広告で「もしかして間に合う？」と上がった期待を、FVで「間に合う」と即断言して冷ます瞬間を作らない。サキの締切思考と完璧主義に”期限内に完了する具体プラン”として地続きに着地。
- 3秒判定: 誰の=式まで半年に控えた婚約中の30代女性 / 何の=前歯だけの短期マウスピース矯正 / どんな約束=式当日の写真に映る笑顔に”歯並びの不安”を残さない
- 担当アプローチからの紐付け根拠（最重要・このSAの差別化点）:
  - 採用したパーツ要素番号: **要素1[悩みの名指し]** ＋ **要素2[衝撃の事実・新常識]**（2要素併用・C-1と別組み合わせ）
  - その要素の言語パターンをどうカスタマイズしたか:
    - 要素1の”状況を名指しで自分ごと化させる”型（例: #01「将来のためにコツコツ貯金してるのに全然貯まらない」／#06「手足の痺れは年だから仕方ない そう諦めているそこのあなた」）の”状況描写でターゲットを特定する”構造を採用。ただしクリニック×IG×30代既婚に対しては「諦めているそこのあなた」のような直接呼び込みは押しが強すぎるため、「式まで半年」という時間状況だけを置いて読み手に自己投影させる引き算型に変換。
    - 要素2の”実は◯◯”型（例: #09「実は市販の化粧品って分子が大きすぎて〜」／#085「実は9割が知らない白髪の一因」）の”常識を裏返す事実提示”構造を、「実は、前歯だけなら3ヶ月で動き出します」と部分矯正の期間事実に変換。サキの思い込み「半年でできる矯正＝簡易版／部分矯正＝中途半端」をピンポイントで覆す。
  - 23要素のどの語感を継承して何を排除したか:
    - 継承: 「状況名指し＋実は事実」の二段構え／”動き出します”という現在進行の生々しさ／読点で間を作るリズム（IGスクロールで読みやすい）
    - 排除: 「激変」「一発で消えた」など医療効果断定（ガイドライン違反）／「ビフォーアフターで人生変わる」など過度な変容約束／”最短で完了”など最大級／「やばい」「神」など俗語（30代既婚IG上品層に不適合）／”諦めてるそこのあなた”の押しの強さ（サキの完璧主義プライドを刺激しない）
- 規制適合性自己チェック: 最大級表現=なし（”間に合う”は症例適応前提の可能性提示、断定でない） / 体験談引用=なし / 出典なし数値=なし（”3ヶ月”は商材ブリーフ記載の「3ヶ月24枚〜」プランに準拠） / 自称専門医=なし
