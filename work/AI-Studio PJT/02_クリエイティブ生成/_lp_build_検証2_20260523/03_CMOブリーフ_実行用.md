# ①CMO キックオフブリーフ 実行用 — キレイライン矯正 LP319 / Meta(IG)

## 1. 目的（態度変容ゴール・1行）
- 「矯正は私には一生無縁」と諦めかけていた20代女性に、「これなら今の私でも踏み出せる」と思わせ、無料カウンセリングLINE予約まで動かす。

## 2. 引き起こしたい感情温度（1〜3行）
- FV: 「諦めの壁が崩れる」静かな衝撃（コーラルピンク価格バッジ着地）。
- 本文: 「自分と同じ所得層の人が普通に通っている」共感→「一生保証で失敗しても無料」の安心で温度を保温。
- CTA: 「行ったら強引に契約させられる」恐怖を「無料で相談だけして帰れる」軽さで上書きし、指を動かす。

## 3. 絶対やらないこと（5〜8項目）
- 「絶対安全」「最新」「最高」「No.1」「業界最大級」など最大級表現の使用
- 「業界新水準」「圧倒的」を画像内に焼き込む（自社比較明示なし）
- 患者体験談・口コミの転載（限定解除4要件未充足）
- Before/Afterで「治療内容・費用・リスク」の同一画面併記を欠く
- 「専門医」自称（認定機関リスト記載者のみ可）
- 税抜・月額のみ表記で総額を後出しにする
- FV画像内へのコピーテキスト焼き込み（HTML/CSS重ね必須）
- IGの自然光・上品トーンを崩す通販LP的な煽り（赤字爆発・カウントダウン等）

## 4. 評価軸（2軸まで）
- 期待値プラス: 主役ペルソナAが「価格の壁が崩れた」と感じFV直下まで読み進むか／自由診療LTVに見合うCV単価を許容できる温度設計か。
- 戦略マッチ80%超: 「価格×品質×一生保証」の3点が破綻なく地続きで、IG流入の温度（自然光・審美ラグジュアリー）とFVが断絶していないか。
