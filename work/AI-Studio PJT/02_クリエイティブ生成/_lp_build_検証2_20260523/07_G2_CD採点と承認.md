## 3. 各案の所見（1案ずつ・詳細）

### SA-A（汎用方法論／18点）

- **止め力 4/5**: 視線最強点を「コーラルピンク価格バッジ」に置く設計が物理的に明快。バッジに水彩滲み1mmを与えて「ボタン感・通販感」を消す指示も的確。被写体は「肩の力が抜けた控えめな微笑み」で、爆笑モデルでIG広告然となる罠を回避できている。**減点1点**: バッジを「メインコピー直下12px」とコピー本体に近接配置するため、SPサムネ表示で「価格バッジが文字塊の一部」として読まれ、コピーとバッジが**同一面積で競合する**リスク。バッジ単独で0.5秒拾わせる磁力としてはSA-Bの「楕円バッジを画面左下視線最強点として面積確保（短辺20%）」より弱い。
- **主従 5/5**: 「ビジュアルは脇役・コピーが主役」を冒頭で宣言し、被写体を右1/3に圧縮・コピー領域を左2/3に確保。バナーCLAUDE.md勝ち筋A「人物視線＋商品＋ベネフィットコピー」を「商品→価格バッジ」に置換した変奏型として論理が一貫。
- **媒体トーン適合 4/5**: IGの自然光・低彩度・暖色を完全遵守。ただし「水彩滲み価格バッジ」と「シャンパンゴールド罫線」がIGフィードの**UGC文脈**には若干**作り込みすぎ**に振れる可能性（IG広告色を消す§4「広告色を消すことで成果が改善することもある」観点で-1点）。SA-Cの「自宅×UGC質感」より広告然としている。
- **規制 5/5**: 「諦めた」が過去形感情語で誇大表現に該当しない点まで自己チェック済。税抜・別途消費税の補記をHTML/CSS段階で添える申し送り（クリニック§2-6）も網羅。白衣・診療台・水色・冠・月桂樹・受賞リボン全て禁止指定。

**G3進行可否**: ✅ 進行。

- **止め力 4/5**: 「コーラルピンク楕円バッジを短辺の20%面積で視線最強点として確保」「人物の視線を左下＝バッジ方向に明示誘導」の二段構えが、3案中で最も**視線物理に忠実**。「9万円」数字部分はコーラルピンクで反復され、バッジ→コピー内の数字色まで色で1本の線が通っている。**減点1点**: ただし「鉄板Z字」「鉄板配置」は鉄板ゆえに**新規性は薄い**——SA-Cの手鏡仕草のように「サムネで他社IG広告と差別化する独自動作」が無い。鉄板を選ぶ＝失敗が少ない代わりに突き抜けない。
- **主従 5/5**: 「キャッチコピー＋ターゲットコピー＋商品説明（価格バッジ）＋CTA」のPモデル4点セットを過不足なく装備。被写体表情は「すごい」ではなく「**すごいらしい**＝静かな安堵」と§5.2 女性右脳型訴求を明示採用——コピーを殺さない控えめさが言語化されている。

- **止め力 4/5**: 「手鏡を口元に当てる独自動作＋伏し目」で**他社IG広告（爆笑モデル横並び）と一線を画すサムネ密度**を獲得。これはA/B両案にない武器で、IGフィード内のスワイプを止める「異物感」としては最強。**減点1点**: ただし「内省・静かな後悔」のトーンは、IGビューティーフィードの**初見0.5秒では『暗い／何の広告か分からない』に転ぶ**リスクが構造的にある。被写体が左1/3／視線も画面外（右下）なので、「人物が広告主役」というIG広告の文法から外れる方向の冒険——G3実画像で初見判定が分かれる。
- **主従 4/5**: パーツ集要素4（後悔フック）＋要素13（感情変化）＋要素1（呼びかけ）の3要素クロスで、ビジュアルが「**諦め→希望の感情遷移**」という独自情報を担う設計。コピー「諦めた矯正、9万円から。」の「諦めた」をビジュアルが意味的に反復する。**減点1点**: ここがリスクで、バナーCLAUDE.md鉄則5「コピーとビジュアルで同じ情報を二重に書かない」と紙一重。「諦めた」をコピーとビジュアル両方で言うのは厳密には**冗長化リスク**——ただしビジュアル側が「諦め『の余韻』」までで止めコピー側が「9万円から」で前進を担う役割分担で踏みとどまっている。
- **媒体トーン適合 4/5**: 「自宅×自然光×UGC質感」はIG文脈に最も馴染む方向。「過度なレタッチを排除」「等身大」の指示はIG広告色消しの王道。**減点1点**: 一方で「手鏡を覗く」演出はIGビューティー広告では**やや作家性が立つ**（編集系雑誌のビジュアル文脈に寄る）ため、フィード回遊の暇つぶしモードには「重く感じる」可能性。

**G3進行可否**: ✅ 進行。**鉄板2案（A/B）と差別化された変奏案**としてG3実画像で比較する価値あり。「鉄板で失敗しない」と「冒険で突き抜ける」の両軸を実画像評価に持ち込める。

## 4. G3への申し送り（承認案ごと）

### SA-A → G3
- **gen_kv.py守るべき事項**: プロンプト末尾の禁止指定（no text系・no before/after・no crown/laurel）は**順序固定**で削らない。被写体右3分の1配置・視線「正面〜やや左下」を厳守（PCで右下に逃がさない）。
- **focal指定**: 画像生成時のfocal は「人物の口元〜頬」ではなく「**左2/3のネガティブスペース上端**」に設定し、コピー乗せ位置を生成段階で物理的に空ける。
- **期待ベスト枚数**: 4〜6枚生成。「水彩滲みコーラルピンクの光が左壁にうっすら反射しているか」をベスト1選定の軸に置く（HTML/CSSの価格バッジと色が地続きに見える条件）。

### SA-B → G3
- **gen_kv.py守るべき事項**: 「人物を右1/3／視線を左下／左半分が完全なネガティブスペース」の3条件を**最優先で評価**。1枚でも視線がカメラ正面に向いた生成物は不採用——本案の論理破綻になるため。
- **focal指定**: focalは「左半分のシャンパンゴールド〜アイボリーグラデーション最明部」に置き、コピー領域の明度を生成段階で確保する。
- **期待ベスト枚数**: 6〜8枚生成。3案中で最も「鉄板の精度」が成果を分けるため、人物の表情温度（「ホッとした笑顔」＝爆笑ではない／無表情でもない）の中央値を引く枚数を多めに確保。

### SA-C → G3
- **gen_kv.py守るべき事項**: 「左1/3に被写体／手鏡を口元に近づける／視線は右下／右2/3が完全なネガティブスペース」の4条件をすべて満たすかを生成1枚ごとに検収。手鏡が顔の前面を**遮蔽**する生成物は不採用（顔が見えないとIG広告として機能しない）。
- **focal指定**: focalは「**手鏡と唇の中間／指先の位置**」に置き、独自動作の意味が0.5秒で立ち上がる条件を物理的に作る。
- **期待ベスト枚数**: 6〜8枚生成。「内省トーンが暗くなりすぎず／朝光で十分に明るい」の中央値を引くのが最難関のため枚数多め。表情が悲しみ側に振れた生成物は全て不採用。
