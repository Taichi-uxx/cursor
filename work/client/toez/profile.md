# 株式会社TOEZ（トイズ） - ベビーパーク プロファイル

TOEZが運営する0〜3歳児と親のための幼児教室「ベビーパーク」の広告支援案件。0歳児の発達を促しIQ130→140を目指す教育サービスで、弊社としては未配信の新規案件。2026-09-03に西岡→田村の引き継ぎMTGを実施し、田村主体で配信立ち上げに入る。

## 案件概要

- **KPI**: 教室体験予約CPA 15,000円（クライアント目標）／初動想定30,000円前後
- **支援形態**: 弊社は制作の構成案（ワイヤーフレーム）まで担当。コーディング・制作実務はクライアント側ハウスエージェンシーへ委託

## 現在の広告運用状況（引き継ぎ時点）
- インハウスチーム＋広告代理店5社が並行して配信中の複雑な状況
- Facebook広告ライブラリ上、複数代理店のアカウントが公式Facebookページに紐付き識別困難
- 弊社は競合カニバリ回避・学習リセット目的で **新規Facebookページを作成** し、独立したアカウント運用で立ち上げる方針
- 制作フローは「弊社=構成案（ワイヤーフレームまで）」「クライアント側ハウスエージェンシー=コーディング・制作実務」で分業

## 初期戦略（引き継ぎMTG時点でフィックス）
- **LP**: 従来の申し込み直結型LP → **アンケート形式のナーチャリングLP** へ変更。現状LPも改修余地ありのため、両者でABテスト実施
- **クリエイティブ**: ショート動画6〜7本での検証を並行
- **予算運用**: 月50万円で初動 → パフォーマンス確認しながら段階的に拡大 → 数千万円規模を目標
- **CPA**: 初動30,000円想定でスタートし、ヒアリング・改善で目標15,000円へ引き寄せ
