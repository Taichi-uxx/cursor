# マーキャリ Next CAREER（株式会社エムエム総研） 7P分析

> 作成日: 2026-09-05
> 作成: REHATCH株式会社 田村太一 / 市場調査エージェント
> 目的: 広告戦略・LP改善・訴求設計の与件として、マーキャリ NEXT CAREER のマーケティングミックスを7P（Product/Price/Place/Promotion/People/Process/Physical Evidence）で分解し、広告改善余地を洗い出す。現状はオプトが月次約300万円で運用中であり、弊社（REHATCH）が拡張余地として提案する際の与件でもある。

---

## サマリー（先読み）

- **サービス性質**: SaaS/IT業界の「The Model型組織」（IS / FS / CS / マーケ）に完全特化した転職エージェント。総合エージェント（doda、リクルート等）でも、若手ハイクラス全般エージェント（アサイン、ムービン等）でもない**"職種×業界特化"の第三ポジション**。
- **価格帯**: 求職者側は完全無料（成功報酬モデル）。企業側フィーは業界相場の年収30〜35%、SaaS/IT特化のため35〜45%レンジの可能性が高い（※要確認）。
- **強い訴求資産（現状の広告で埋没している可能性）**:
  1. **書類通過率90% / 一次面接突破率61%**（一般的な転職市場水準を大きく上回る具体数値）
  2. **SaaS人事の86%が「注目する」と回答**（企業側からの評価）
  3. **みんなのキャリアAWARD 2022・2023 で2年連続W最優秀賞**（第三者機関評価）
  4. **累計キャリア面談数5,000名突破**（実績厚み）
  5. **母体エムエム総研の1,000社超・13,000プロジェクト超のBtoB営業/マーケ支援実績**
- **広告での最大レバレッジ**:
  - 「なぜSaaSに強いのか」の**構造的根拠**（BtoB支援1,000社→人事とのリレーション→情報の非対称性）を1つのストーリーとして見せられていない
  - 数値実績（90/61/86%）をLPで見せているが、広告クリエイティブでの露出フックとして機能させる余地大
  - オプトの現行運用がどこまでこれらを使い切れているか要検証。もし「無料相談」「SaaS転職」等の一般訴求に留まっているなら、REHATCHは**"数値ソーシャルプルーフ×職種深掘り"**で差分提案可能

### 1-3. 独自性（差別化の核）

- **業界×職種の二重特化**: 総合エージェントは業界横断、若手ハイクラス系（アサイン等）は職種横断。「SaaS×The Modelの4職種」の二重絞りは同一ポジションの直接競合が薄い。
- **母体エムエム総研のBtoB営業支援基盤**:
  - 1989年創業、代表 萩原張広氏。1998年NYで法人マーケティング型営業に感銘を受け事業転換
  - **BtoBマーケティング/セールス支援 1,000社超・13,000プロジェクト超の実績**
  - コアクライアントは外資系ITベンダー・SaaS企業
  - → SaaS企業の**採用側とのリレーションが構造的に太い**（マーケ・営業支援で入っている企業が採用も相談）
  - 2017年に「エムエム・デジタルセールス・アカデミー」設立、教育事業も展開
- **数値実績の裏付け**:
  - 書類通過率**90%**
  - 一次面接突破率**61%**
  - SaaS人事の**86%が「注目する」と回答**
  - 累計キャリア面談数**5,000名突破**（2周年時点）
- **受賞**: みんなのキャリアAWARD 2022・2023 で「IT業界キャリアアップ部門」「マーケター・クリエイター向けキャリアアップ部門」で**2年連続W最優秀賞**

**So What**: 差別化の核はProductそのものより**「なぜSaaSに強いのか」の構造的根拠**にある。BtoB支援1,000社の顧客リレーション→人事情報の非対称性→90%の書類通過率、というストーリーで語れば、「アサインのAIデータ資産」と対抗軸になる（人力×リレーション vs AI×診断）。ここが広告で最も打ち出せていない資産。

## 2. Price（価格）

### 2-1. 料金体系

| 項目 | 金額／条件 |
|---|---|
| 求職者側 | **完全無料**（一般的な転職エージェントモデル） |
| 企業側フィー（推定） | 想定年収の30〜35%（一般相場）／SaaS・IT特化は35〜45%レンジの可能性 ※要確認 |
| 返金規定 | ※要確認（早期退職時の返金は業界標準あり） |
| 支払方法 | 企業→エムエム総研への成功報酬（求職者との金銭発生なし） |

### 2-2. 求職者から見た「価格ポジション」

求職者は無料で使えるため、価格そのものは差別化要素にならない。しかし**「なぜ無料か」＝企業側が高いフィーを払うほどのマッチング品質があるから**、という論理は広告で使える（優良誤認回避のため直接的な表現は避けるが、「企業が信頼しているから、あなたにも良い求人が届く」の間接訴求は可）。

### 2-3. 競合との価格ポジション

| サービス | 求職者側 | 企業側フィー（推定） | ポジション |
|---|---|---|---|
| **マーキャリ NEXT CAREER** | 無料 | 30〜45%（SaaS特化のため上位帯の可能性） | SaaS×職種特化 |
| アサイン | 無料 | 30〜45%（若手ハイクラス特化） | 業界横断×若手ハイクラス |
| ムービン、コトラ等ハイクラス | 無料 | 35%〜 | 業界横断ハイクラス |
| リクルートエージェント／doda等総合 | 無料 | 30〜35% | 総合 |

**So What**:
- 求職者から見た価格差はゼロ → 広告では**「無料」の一言を強調するより、"完全無料"＋"なぜ質を担保できるか"のセット訴求**が競合差別化上有効
- 企業側フィーが高いとしても、SaaS企業の**紹介経由採用単価**（他社経由と比較したCPA）が下がれば正当化される → 企業側訴求の武器にもなる
- 現状の広告でオファーが「無料キャリア相談」に留まるなら、**"完全無料の面談で、SaaS人事の86%が評価する会社の求人に出会える"**のような数値×無料の複合訴求で強度アップ余地

## 3. Place（流通・チャネル）

### 3-1. 展開エリア／面談チャネル

- **面談方式**: 完全オンライン中心（URL送付、Zoom等）
- **面談可能時間**: 平日9〜21時、土日祝は要相談
- **拠点**: エムエム総研本社は東京都新宿区新宿。求職者向けの物理拠点は基本的にオンラインで完結（※要確認：対面面談の可否）
- **対応エリア**: 全国（オンラインのため首都圏〜地方まで理論上カバー、ただし求人は首都圏SaaS企業中心の可能性が高い）

### 3-2. 求人ネットワーク

- **求人保有数の具体値**: 公表なし ※要確認
- **特徴**: 「取り扱い求人数は多くはないが、密度が濃い」との第三者評価。**非公開求人比率が高い**（企業とのパイプの太さの証左）
- **提携SaaS企業**: SaaS転職LIVE / EXPO で登壇する人気SaaS企業3社〜複数社（例：SmartHR、Sansan、freee等の系譜が想定されるが公表企業名は要確認）
- **企業ネットワークの深さ**: エムエム総研本体のBtoBマーケ支援クライアント（1,000社超）と重なる企業群でリレーション構築

### 3-3. パートナー・アライアンス

- **「みんなのキャリア」への掲載** ： AWARD受賞をきっかけに露出強化
- **メディア連携**: マイナビ・エキサイトニュース・BIGLOBEニュース等でのプレスリリース経由露出
- **アフィリエイト経済圏**: note・個人ブログでの体験談記事が多数（コエテコキャリア／IT業界ノート／転職バイアス等）

**So What**:
- **オンライン完結×全国対応**はLPで明示するとネガ払拭になる（地方在住SaaSワーカーは「エージェント＝東京に呼び出される」不安がある）
- 求人数を数で押せない構造 → **"数より濃さ"** の方向で訴求（「厳選された求人だけ」「求人票に載らない情報」）
- SaaS転職LIVE等の**ライブイベント**は現状の広告動線に組み込まれていない可能性 → 顕在層向けの二段目CVとして活用余地大（無料面談が重い層へのライトCV代替）

### 6-1. 求職者フロー

```
[認知] 検索／Meta広告／SNS／MEDIA記事／SaaS転職TV／みんキャリ掲載

   ↓

   ↓
```

### 6-2. LP/CV導線の評価

**強み（推定）**:
- 登録フォームが8問と超軽量 → CVR構造的に高いはず
- オンライン面談で全国対応 → 地方在住者もCVできる
- 平日夜21時までの面談枠 → 現職者フレンドリー

**改善余地（LPを実際にfetchして評価すべき点）**:
- **既存診断コンテンツの広告動線への未組込の可能性**: マーキャリは**Career Matrix診断（LINE経由・16タイプ・約5分・将来年収予測付き）＋デジタルセールス適職診断（3分）を既に保有**。ただしMeta広告の1stフックとして動線化されているか、診断LPが広告遷移向けにFV最適化されているか要検証（アサインは「3分AI診断」でアプリDLのライトCV → Web面談本命の二段構え）
- **数値実績のFV配置**: LP本体に90%/61%/86%が入っているとしても、広告→LP遷移時の視認導線が最適化されているか
- **求人票非表示 vs 具体求人例の見せ方**: 「密度重視」を維持しつつ、企業ロゴ例やポジション例（匿名でも）を出すと具体性が増す

### 6-3. オンボーディング

- 初回面談で「キャリア戦略の言語化」を実施 → **単なる求人紹介屋さんとの差別化ポイント**
- 「転職しない選択肢も含めて相談」というアサイン型の潜在層フックにも対応

### 6-4. リテンション

- 内定後・入社後のフォロー
- **Next CAREER → Plus への内部送客動線**（転職成功者が数年後に業界内キャリアアップ相談で戻ってくる）
- MEDIA / SaaS転職TV会員としての継続接点

**So What**:
- **登録の軽さは業界最強クラス**。広告CTAで「たった8問で登録完了」を打ち出す価値あり
- **平日夜21時面談OK**は現職者ペインを外す強力ファクト。SaaS営業の「月末バタバタ問題」に刺さる → Plus向け訴求と共通する武器
- **既存のCareer Matrix診断・デジタルセールス適職診断を広告動線に組み込む提案は REHATCH 側の最大レバレッジ**。新規制作コスト不要で、面談CVの前段にLINE友だち化＝リマーケ資産化も同時に実現できる

## 9. オプト現行運用に対する REHATCH からの価値仮説

**前提**: 現在のオプト運用は月次300万円、媒体はGoogle/Meta。実クリエイティブの検証は必要だが、以下の**構造的な提案軸**でREHATCH（田村）は差分を出せる可能性が高い。

### 9-1. 仮説：オプト現行運用の「見えている穴」

以下は仮説ベース（要検証）で、オプトの運用に構造的に発生しやすい "抜け" ：

1. **数値実績（90/61/86%）が広告クリエイティブで独立訴求として立っていない可能性**
   - LP側では使っていても、広告→LP遷移時の初動フックとして使い切れていない
   - REHATCH仮説：静止画バナーで数字大きく置くだけでCTR改善余地

2. **既存Career Matrix診断が広告動線に組み込まれていない可能性**
   - マーキャリは**Career Matrix診断（LINE・16タイプ・5分・将来年収予測）＋デジタルセールス適職診断（3分）を既に保有**
   - Meta広告のCPAは入口の重さで決まる。無料相談1本だと下がりきらない
   - REHATCH仮説：既存診断コンテンツを Meta広告の1stフックとして動線化＆LP最適化＆16タイプ×職種訴求マトリクス化（新規制作コスト不要）

3. **職種別クリエイティブ分岐の不足**
   - IS/FS/CS/マーケ を一括で「SaaS転職」と括ると自認しづらい
   - REHATCH仮説：職種別LP＋職種別クリエイティブでCVR改善

4. **エコシステム資産（MEDIA/TV/イベント）の広告動線未組込**
   - 顕在層＝面談、潜在層＝コンテンツ、の二段構え設計余地

5. **クリエイティブの内製化余地**
   - オプトのクリエイティブ制作コストが月次予算に含まれる場合、内製化で本数を稼げる
   - REHATCH仮説：GPT×Canva運用で静止画バリエーション大量生成→勝ち軸を動画化
