## AI判定の学び

- 2026-09-11: 数値だけ見るとMeta指標は良好（CTR 0.9・マッチング診断実施率24%）だが、CPA・LP内CTA・友達登録率の指標で不整合が起きている。単一指標最適化ではなく、ファネル全体の整合性を確認する必要あり。
- 2026-09-11: LINE広告は「友達登録単価が激安（¥164）」でも診断完了率が絶対値で低ければ意味がない。中間指標だけで媒体判断してはいけないという事例（8月停止判断の裏付け）。
- 2026-09-11: クリエイティブ別に見ると「動画第2弾（マッチ訴求）」が575件登録・44.2%転換率と圧倒的で、他クリエイティブとの差が大きい。勝ちパターンが明確に存在するなら派生・量産の優先度が高い。
- 2026-09-11: 面談CV11件の流入元内訳は Metacpc 3件／LINE広告 1件／学ぶ！Sa活 2件／比較サイト 1件／LINE公式 1件／Metasocial 1件／不明 2件と分散。CVレベルでは非広告経由（オーガニック・比較サイト）が過半を占める点は事業構造理解の重要ポイント。

## 勝ち筋・検証結果メモ

- **クリエイティブ**: 診断系は表現バリエーションを広げやすいカテゴリ。営業色を強めた訴求パターンを積むべし
- **勝ちクリエイティブ**: 「Career Matrix診断_マッチ_動画（第2弾／マッチ訴求）」＝累計友達登録575件・LINE転換率44.2%。訴求軸は相性のいいSaaS商材＋5年後年収予測＋おすすめ求人のセット。派生量産のベース
- **負けクリエイティブ**: 「情緒訴求」（実友達登録単価¥23,657・LINE転換率10.0%）はCPCは高いが後段転換弱い。感情訴求より機能・具体訴求が診断系では強い
- **ターゲティング分離**: マーキャリ既存アカウントと同ターゲティングだとカニバリ・パイ頭打ちが発生する
- **第三者視点広告**: 別FBページ経由の紹介型クリエイティブは選択肢として有効（別案件でも横展開余地）
- **LINE緑CTA**: LPのCTAボタンをLINEカラー（緑）にすることはブランド観点でも許容
- **ターゲット**: 営業経験があれば業種・職種不問（SaaS現職者限定ではない）
- **リスティング判断軸**: チャネル継続可否は「16タイプ診断の回答結果等の属性データ」で判定できる
- **リスティングKW戦略**: 少額予算＋診断特化KW（完全一致：キャリアマトリックス診断／Career Matrix 診断）で運用。指名広告カニバリ回避のため広域KWは避ける
- **年収訴求の可能性**: 2026-09-10追加の「5年後年収予測」訴求は、マッチング診断②完了率向上を狙った打ち手。効果検証待ち
- **リリース時一斉配信の有効性**: マッチング診断リリース時（2026-02末）の休眠層一斉配信で1件CV化。新機能・シーズナリティで既存友達再エンゲージメント可
