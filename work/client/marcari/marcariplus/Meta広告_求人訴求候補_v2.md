# Meta広告 求人訴求候補 v2

**v1からの主な変更点**：
- ロゴ／企業名なし（求人内容だけで訴求）
- 平均年収（=(下限+上限)/2）で並び替え。上限のみの派手さは減点
- フルリモート訴求は排除、ハイブリッド勤務前提
- SaaS業界未経験訴求は排除（PLUSがSaaS現職者向けのため）
- ペルソナを「メンバーから次のキャリアジャンプ狙い」に固定し、**新規事業／グローバル／事業責任者候補／上流戦略／裁量**の5軸で作り分け

---

## 0. Executive Summary

1. **勝ち筋の訴求は「次に欲しい経験」で語る**：「年収」「ブランド」ではなく「今のポジションでは絶対に手に入らない経験」＝新規事業・グローバル・事業責任者・上流戦略・若手裁量。ペルソナが自身の物足りなさを言語化できる訴求文言に置き換える
2. **CV量産の主戦は5軸並行**：X 新規事業／Y グローバル／Z 事業責任者・幹部候補／W 上流戦略・経営企画／V 裁量・抜擢。それぞれ心理的スイッチが異なるため、1軸単発ではなくローテーションで刺し込む
3. **数字の使い方**：企業名/ロゴなしでも、求人内で語られる「◯期連続増収」「日経225の30%が採用」「シリーズD 累計◯◯億調達」「シェアNo.1」等の**属性のみを抽象化して打ち出す**ことで信頼担保する
4. **平均年収は900〜1500万レンジが刺さる**：現年収500-800万のメンバーレイヤーから見て「手が届く飛び幅」。上限2000万＋下限400万のような幅広求人は「実現性がない」と判断されて逆効果
5. **v1の"ロゴ集合"は捨て、v2は"求人内容型カルーセル"に移行**：1枚に3-6求人の属性・年収レンジ・獲得できる経験を並べる。カルーセルとの相性◎

## 1. 制約と設計方針

### 1-1. 今回のNG制約
| 制約 | 理由 | 反映方法 |
|------|------|---------|
| 企業名・ロゴ不可 | 掲載許諾・ブランド管理の観点 | 訴求は「求人内容の属性」で語る（"シェアNo.1のSaaSプロダクト"／"導入2万社超のクラウドサービス"等） |
| 上限5000万など非現実的 | 実現性が低いと"嘘っぽい"判定・CVR低下 | 上限2500万でキャップ／平均年収でソート |
| フルリモート訴求不可 | ゆるく働きたい浅いユーザー流入で面談CV低下 | ハイブリッド（リモート主体・リモート有）のみ表出。フルリモートは訴求文言から除外 |
| SaaS業界未経験可訴求不可 | PLUSはSaaS現職者向け | 業界未経験メイン訴求求人は除外／要件にSaaS経験が明記された求人を優先 |

### 1-2. ペルソナ（Ver.2固定）
- **職種**: 現職SaaS営業（フィールドセールス／インサイドセールス／カスタマーサクセス）メンバーレイヤー
- **年齢**: 20代後半〜30代前半
- **年収**: 500〜800万
- **状態**: そこそこ成果は出したが、今のポジションでは新しい経験ができないと感じている
- **キャリア欲求**:
  - **もっと事業に近い場所で働きたい**（新規事業・事業開発）
  - **日本の枠を超えたい**（グローバル・海外拠点・海外展開）
  - **裁量を持ちたい／責任者になりたい**（事業責任者・幹部候補・部長）
  - **営業から経営に近づきたい**（経営企画・事業戦略）
  - **20代のうちに抜擢されたい**（若手抜擢・年次関係なく・CEO直下）

## 5. Meta広告クリエイティブ落とし込み案（v2）

### 5-1. クリエイティブ設計の原則
- **ロゴ・企業名を出さない**：求人内容の属性（"シリーズD 88億調達"／"日経225の30%が採用"／"8年連続シェアNo.1"）を抽象化して信頼担保
- **平均年収レンジで語る**（例：「平均年収1,200-1,500万」）
- **働き方は"ハイブリッド"表記**：フルリモートは絶対に打ち出さない
- **SaaS営業経験を前提にした呼びかけ**：「SaaS営業3年目のあなたへ」等でペルソナを絞る

### 5-2. クリエイティブ案（5パターン）

#### 案1. 新規事業訴求「次は、"売る"から"創る"へ」
- **静止画**：左「今のあなた（メンバーとして売る）」／右「次のあなた（BizDevとして創る）」の対比
- **メインコピー**：「SaaS営業3年、次に欲しいのは"新規事業"の経験。」
- **サブ**：「シリーズD調達済みのLLM事業／取締役直下VP／執行役員候補…新規事業ポジション◯◯件」
- **CTA**：「無料でキャリア診断（60秒）」

#### 案2. グローバル訴求「日本のSaaSを、海外へ」
- **静止画**：世界地図×SaaS営業アイコン。「日本から、アジアへ、欧州へ、北米へ」
- **メインコピー**：「日本のSaaSを、次はアジアで売る側に。」
- **サブ**：「インド／中国／欧州の海外拠点立ち上げポジション。平均年収1,200-1,500万」
- **CTA**：「グローバル求人を見る」

#### 案3. 事業責任者訴求「メンバー止まりで終わらない」
- **静止画**：階段の途中で止まっている人と、階段を登っている人の対比
- **メインコピー**：「メンバーの延長線上に、事業責任者はない。」
- **サブ**：「執行役員候補／VP候補／事業責任者ポジション、平均年収1,200-1,800万」
- **CTA**：「責任者ポジションを見る」

#### 案4. 上流戦略訴求「営業から、経営へ」
- **静止画**：数字を追う人 → 数字を設計する人へ変化
- **メインコピー**：「営業の延長線上に、経営がある。」
- **サブ**：「経営企画部長／VP of BizDev／CEO室 事業戦略担当。平均年収1,300-1,600万」
- **CTA**：「上流ポジションを見る」

#### 案5. 若手裁量訴求「20代のうちに、事業を動かす側に」
- **静止画**：CEOと若手が並んで議論するビジュアル
- **メインコピー**：「20代のうちに、事業を任される。」
- **サブ**：「CEO直下／若手抜擢型／年次関係なく事業責任者へ」
- **CTA**：「抜擢型求人を見る」

## 6. カルーセルクリエイティブ設計（v2の目玉）

企業名NGでも「求人内容カード」の3-6枚並列カルーセルは強力。1枚目でフックし、2-4枚目で複数求人を提示、最終カードでCTA。

### カルーセル例：新規事業軸
| 位置 | 内容 |
|------|------|
| 1枚目（表紙） | 「SaaS営業3年、次のキャリアは"新規事業"へ」 |
| 2枚目 | 「LLM新規事業／執行役員候補／年収1000-1500万／ハイブリッド」＋累計88億調達 |
| 3枚目 | 「新規事業BizDev（CEO直下）／年収804-1500万／リモート主体」＋急成長SaaS |
| 4枚目 | 「事業責任者候補（新規領域）／年収650-1800万／ハイブリッド」＋東証プライム20期連続増収 |
| 5枚目 | 「無料でキャリア診断（60秒）」＋CTAボタン |

### カルーセル例：グローバル軸
| 位置 | 内容 |
|------|------|
| 1枚目 | 「日本のSaaSを、次はアジアで売る側に。」 |
| 2枚目 | 「Global Enterprise AE, India Expansion／年収1000-1600万」 |
| 3枚目 | 「Global Enterprise AE, China Expansion／年収1000-1600万」 |
| 4枚目 | 「Global Enterprise AE, Europe Expansion／年収1000-1600万」 |
| 5枚目 | 「グローバル求人一覧を見る」＋CTA |

**カルーセルのポイント**：カードごとに1求人の属性（年収帯／勤務／獲得できる経験）だけをシンプルに置く。読ませすぎない・スワイプさせる設計。
