# 一戸建てショールーム ショート動画 撮影指示書

> **目的**: インスタリール / YouTubeショートで再生数が取れるルームツアー動画の素材撮影  
> **完成尺**: 30〜45秒（編集後）  
> **画面比率**: 縦型（9:16）＝ スマホを縦に持って撮影  
> **参考動画**:
> - [アイフルホーム ルームツアー vol.1](https://youtube.com/shorts/2vefZ6cRlH4)（6万再生・43秒）
> - [atelier SUBACO 38坪2階建て](https://youtube.com/shorts/14yWY158o1o)（45万再生・33秒）

---

## 撮影前の準備

### 機材

| 項目 | 推奨 | 備考 |
|------|------|------|
| カメラ | iPhone または Android スマホ | 4K/60fps または 1080p/60fps に設定 |
| 手ブレ補正 | スマホ用ジンバル（DJI OM等）| なければスマホの手ブレ補正ONでも可 |
| レンズ | 超広角（0.5x）を基本使用 | 部屋が広く見え、ダイナミックな映像になる |
| 三脚 | ミニ三脚（固定カット用） | あれば便利だがなくてもOK |

### カメラ設定（撮影開始前に必ず確認）

1. **縦向き**でスマホをロック（横にしない）
2. **超広角レンズ（0.5x）**に切り替え
3. **解像度**: 4K 60fps または 1080p 60fps
4. **手ブレ補正**: ON
5. **フラッシュ**: OFF
6. **グリッド線**: ON（水平を保つため）
7. **スマホの画面ロック**: 撮影中に画面が回転しないよう自動回転をOFF

### 現場の準備

- **照明**: 撮影する部屋のすべての照明をONにする。自然光が入る場合はカーテンを開ける
- **清掃**: テーブルの上、カウンター、棚の上の不要物を撤去。生活感のあるもの（ティッシュ箱、リモコン等）は隠す
- **演出小物**: 観葉植物、花、雑誌、コーヒーカップなど「暮らし」を感じさせるアイテムを配置
- **出演者の服装**: 白・ベージュ・グレーなどナチュラルカラーの服。派手な柄やロゴ入りは避ける

## 撮影の基本ルール（全カット共通）

### カメラワークの3原則

1. **ゆっくり動く** — 歩く速度の半分くらいのイメージ。急な動きは絶対にNG
2. **水平を保つ** — グリッド線を見て傾かないように意識する
3. **一方向に動く** — 1カットの中でカメラの動きは1方向のみ（左→右、低→高、前進のみ等）

### 1カットの長さ

- 撮影時: **5〜10秒**撮る（編集で1〜2秒に切るため、余白を持って撮影する）
- 実際に使う素材は**1カットあたり1〜2秒**

### 出演者の動き

- **自然体**を意識。カメラをチラチラ見ない
- ドアを開ける、歩く、触れる、座るなど「動作」を入れる
- 動きはゆっくり丁寧に。バタバタしない

---

## カット別 撮影指示

> 各カットは**必ず2〜3テイク**撮影してください。  
> 「OK」と思っても、もう1テイク撮る習慣をつけることでクオリティが安定します。

---

### カット1: 外観（建物全体）

**目的**: 最初の1〜2秒で「おしゃれな家だ」と思わせる掴みのカット

#### パターンA: 下から上へのティルトアップ

| 項目 | 内容 |
|------|------|
| カメラ位置 | 建物正面から5〜8m離れた場所、膝の高さからスタート |
| カメラの動き | 膝の高さ → ゆっくり上に → 建物の全体が収まるまで |
| レンズ | **超広角（0.5x）** |
| 出演者 | **不要**（建物だけを撮影） |
| 撮影秒数 | 8〜10秒（ゆっくりティルト） |
| ポイント | 空も少し入るように。電線や隣家が映り込まない角度を探す |

#### パターンB: 出演者が歩いてくる＋建物

| 項目 | 内容 |
|------|------|
| カメラ位置 | 玄関アプローチの横、腰の高さで固定 |
| カメラの動き | **固定**（動かさない） |
| レンズ | 超広角（0.5x） |
| 出演者 | 画面の奥から手前に向かって歩いてくる。建物が背景に映る |
| 撮影秒数 | 8秒 |
| ポイント | 出演者は笑顔でリラックスした表情。カメラは見ない |

> **両パターンとも撮影し、編集時にどちらか選べるようにしてください**

---

### カット2: アプローチ（家に向かって歩く）

**目的**: 「この家に入りたい」というワクワク感を演出

| 項目 | 内容 |
|------|------|
| カメラ位置 | 出演者の**後ろ**から追いかける形。腰〜胸の高さ |
| カメラの動き | 出演者の後ろをついて歩く（前進のみ） |
| レンズ | 超広角（0.5x） |
| 出演者 | 門やアプローチから玄関ドアに向かってゆっくり歩く |
| 撮影秒数 | 8〜10秒 |
| ポイント | 足元の素材（タイル、石畳等）や植栽が映るように。出演者の全身が入るフレーミング |

---

### カット3: 玄関ドアを開ける

**目的**: 「家の中に入る」瞬間のトランジション。ここが動画の大きな転換点

#### 3-A: ドアを開けるクローズアップ

| 項目 | 内容 |
|------|------|
| カメラ位置 | 出演者の横、ドアハンドルが画面中央に来る高さ |
| カメラの動き | **固定**またはゆっくり寄っていく |
| レンズ | **標準（1x）**でハンドル周りをアップに |
| 出演者 | ドアハンドルに手をかけ、ゆっくり開ける |
| 撮影秒数 | 5〜6秒 |
| ポイント | 手の動きを丁寧に。ドアが開いた瞬間に中の光が差し込む感じが理想 |

#### 3-B: 玄関ドアの内側から撮影

| 項目 | 内容 |
|------|------|
| カメラ位置 | 玄関の中から、ドアに向かって構える。腰の高さ |
| カメラの動き | **固定** |
| レンズ | 超広角（0.5x） |
| 出演者 | 外からドアを開けて入ってくる。自然に靴を脱ぐ仕草まで |
| 撮影秒数 | 8秒 |
| ポイント | ドアが開くと外の光が入り、出演者のシルエット→顔が見える流れが映画的 |

> **3-Aと3-Bの両方を撮影してください**

---

### カット4: 玄関ホール

**目的**: 第一印象を伝える。収納力や広さのアピール

#### 4-A: 玄関全体（広さを見せる）

| 項目 | 内容 |
|------|------|
| カメラ位置 | 玄関の隅、床から30cmの低い位置 |
| カメラの動き | 低い位置から**ゆっくり左→右**にパン |
| レンズ | 超広角（0.5x） |
| 出演者 | フレーム内に立っている（動かなくてOK） |
| 撮影秒数 | 6〜8秒 |
| ポイント | 低い位置から撮ると天井が高く見え、空間が広く感じる |

#### 4-B: シューズクローク等の収納（ある場合）

| 項目 | 内容 |
|------|------|
| カメラ位置 | 収納の正面、胸の高さ |
| カメラの動き | ゆっくり**後ろに引く**（収納の中→全体が見える） |
| レンズ | 超広角（0.5x） |
| 出演者 | 扉を開ける動作 or 靴を置く仕草 |
| 撮影秒数 | 5〜6秒 |
| ポイント | 収納内部が暗い場合は照明をつけるか、撮影者のスマホライトを当てる |

---

### カット5: 廊下〜リビングへの移動

**目的**: 空間のつながりとワクワク感の演出

| 項目 | 内容 |
|------|------|
| カメラ位置 | 出演者の**前方**（出演者の方を向いて後ろ歩き）、胸の高さ |
| カメラの動き | 後ろ歩きで出演者と一緒に移動。出演者の上半身をフレームに収める |
| レンズ | 超広角（0.5x） |
| 出演者 | 廊下をリビングに向かって歩く。表情はリラックスした笑顔 |
| 撮影秒数 | 6〜8秒 |
| ポイント | 廊下が短い場合はこのカットは省略可。後ろ歩きが難しい場合は、出演者の後ろからついていく形でもOK |

**⚠️ 後ろ歩き撮影の注意**: 撮影前に後ろの障害物を必ず確認してから撮影開始

---

### カット6: リビング

**目的**: 動画のメインパート。開放感・デザイン性・暮らしの雰囲気を伝える

#### 6-A: リビング全景（ドア側から奥へ）

| 項目 | 内容 |
|------|------|
| カメラ位置 | リビングの入口、胸の高さ |
| カメラの動き | ゆっくり**前進**しながらリビング全体を見渡す |
| レンズ | **超広角（0.5x）** |
| 出演者 | **不在**でOK（空間の広さを見せるカット） |
| 撮影秒数 | 8〜10秒 |
| ポイント | 窓からの光が入るタイミングで撮影。天井や梁が見えるように少し上を向ける |

#### 6-B: ソファ周り（暮らしの雰囲気）

| 項目 | 内容 |
|------|------|
| カメラ位置 | ソファの斜め前、膝の高さ |
| カメラの動き | **固定**またはゆっくり右にスライド |
| レンズ | 標準（1x） |
| 出演者 | ソファに座る or クッションに触れる仕草 |
| 撮影秒数 | 5〜6秒 |
| ポイント | テーブルの上に雑誌やコーヒーカップを置いて生活感を演出 |

#### 6-C: 窓・吹き抜け（開放感）

| 項目 | 内容 |
|------|------|
| カメラ位置 | 窓の正面、床に近い低い位置 |
| カメラの動き | 下から上へ**ティルトアップ**（床→窓→天井/吹き抜け） |
| レンズ | 超広角（0.5x） |
| 出演者 | 窓の前に立って外を眺める（カメラに背を向ける） |
| 撮影秒数 | 6〜8秒 |
| ポイント | 逆光になるが、シルエットが美しく映るのでそのまま撮る。吹き抜けがある場合は必ず撮影 |

#### 6-D: ディテールカット

| 項目 | 内容 |
|------|------|
| カメラ位置 | 対象物に近づいて |
| カメラの動き | ゆっくり**寄り**or **スライド** |
| レンズ | **標準（1x）〜望遠（2x）** |
| 出演者 | 不要 |
| 撮影秒数 | 各3〜5秒 |
| 撮影対象 | ①照明器具 ②壁の質感/アクセントウォール ③スイッチプレート ④観葉植物 |
| ポイント | 建物のこだわりポイントを1つずつ寄りで撮影。最低3つは撮る |

---

### カット7: キッチン

**目的**: 設備の高級感と使いやすさをアピール

#### 7-A: キッチン全景

| 項目 | 内容 |
|------|------|
| カメラ位置 | カウンター越し（リビング側から）、カウンターの高さ |
| カメラの動き | **左→右にゆっくりパン**（端から端まで） |
| レンズ | 超広角（0.5x） |
| 出演者 | キッチンの中に立ち、カウンターに手をつく or 何かを触っている |
| 撮影秒数 | 8秒 |
| ポイント | カウンターの上は綺麗に片付けておく。花を一輪置くと映える |

#### 7-B: 水栓/天板のアップ

| 項目 | 内容 |
|------|------|
| カメラ位置 | キッチン天板に近い高さ |
| カメラの動き | 天板をなぞるように**スライド** |
| レンズ | 標準（1x） |
| 出演者 | 水栓を触る or 引き出しを開ける仕草 |
| 撮影秒数 | 5秒 |
| ポイント | 素材の質感が伝わるように。水栓のデザインが良い場合は必ず撮影 |

#### 7-C: カップボード/背面収納

| 項目 | 内容 |
|------|------|
| カメラ位置 | 正面、胸の高さ |
| カメラの動き | 固定 or ゆっくり引き |
| レンズ | 超広角（0.5x） |
| 出演者 | 扉を開ける動作 |
| 撮影秒数 | 5秒 |
| ポイント | 収納内に食器などを美しく並べておくとベスト |

---

### カット8: 洗面所・バスルーム

**目的**: ホテルライクな上質さをアピール

#### 8-A: 造作洗面台

| 項目 | 内容 |
|------|------|
| カメラ位置 | 正面、鏡に自分が映らない角度 |
| カメラの動き | ゆっくり**前進して寄る** |
| レンズ | 超広角（0.5x）→ 寄る過程で標準に切り替えてもOK |
| 出演者 | 水栓をひねる仕草 or タオルに触れる |
| 撮影秒数 | 6秒 |
| ポイント | **⚠️ 鏡に撮影者が映らないよう角度に注意**。タオルやソープディスペンサーを綺麗に配置 |

#### 8-B: バスルーム

| 項目 | 内容 |
|------|------|
| カメラ位置 | ドア側から、腰の高さ |
| カメラの動き | ドアを開けながら**ゆっくり前進** |
| レンズ | 超広角（0.5x） |
| 出演者 | ドアを開ける手だけ映る or 不要 |
| 撮影秒数 | 5〜6秒 |
| ポイント | 浴室は照明をつけて明るくしておく。水滴は拭いておく |

---

### カット9: 階段

**目的**: 空間のつながりと動きのあるカット

| 項目 | 内容 |
|------|------|
| カメラ位置 | 階段の下、見上げる角度 |
| カメラの動き | **出演者を追いかけて階段を上がる** or **固定で見上げる** |
| レンズ | 超広角（0.5x） |
| 出演者 | 階段を上がる。手すりに手をかけながらゆっくり |
| 撮影秒数 | 6〜8秒 |
| ポイント | リビング階段やスケルトン階段がある場合は特にしっかり撮る。足元のアップも1カット追加で撮影 |

**⚠️ 階段での撮影は転倒注意。手すりを持てない場合は固定カットで撮影**

---

### カット10: 2階居室（寝室・子供部屋）

**目的**: プライベート空間の快適さを伝える

#### 10-A: 部屋全景

| 項目 | 内容 |
|------|------|
| カメラ位置 | ドアの前、胸の高さ |
| カメラの動き | ドアを開けると同時に**ゆっくり前進** |
| レンズ | 超広角（0.5x） |
| 出演者 | ドアを開ける → 部屋に入る |
| 撮影秒数 | 6〜8秒 |
| ポイント | ベッドやカーテンは整えておく。窓からの光を活かす |

#### 10-B: クローゼット（ウォークインがある場合）

| 項目 | 内容 |
|------|------|
| カメラ位置 | クローゼットの入口 |
| カメラの動き | ゆっくり**中に入っていく** |
| レンズ | 超広角（0.5x） |
| 出演者 | 扉を開ける or 中に入って振り返る |
| 撮影秒数 | 5秒 |
| ポイント | 広さが伝わるように。空でもOKだが、ハンガーを数本かけておくと雰囲気が出る |

---

### カット11: バルコニー・庭

**目的**: 開放感のある締めカット候補

| 項目 | 内容 |
|------|------|
| カメラ位置 | 室内側から窓/サッシに向かって |
| カメラの動き | 室内→窓を開ける→**外に出ていく** |
| レンズ | 超広角（0.5x） |
| 出演者 | 窓を開けてバルコニーに出る → 手すりに手をかけて景色を見る |
| 撮影秒数 | 8秒 |
| ポイント | 空が綺麗な時間帯（午前中 or 夕方ゴールデンアワー）に撮影するのがベスト |

---

### カット12: エンディング（建物を振り返る）

**目的**: 余韻を残す締めのカット

#### パターンA: 外から建物全体

| 項目 | 内容 |
|------|------|
| カメラ位置 | 建物から離れた位置、目の高さ |
| カメラの動き | **ゆっくり後ろに引いていく**（建物がだんだん全体像に） |
| レンズ | 超広角（0.5x） |
| 出演者 | 玄関前に立ち、カメラに向かって笑顔 or 建物を見上げる |
| 撮影秒数 | 6〜8秒 |

#### パターンB: 室内の印象的なカット

| 項目 | 内容 |
|------|------|
| カメラ位置 | リビングの一番良い角度 |
| カメラの動き | ゆっくり**回転パン**（部屋を見渡す） |
| レンズ | 超広角（0.5x） |
| 出演者 | 窓辺やソファでくつろいでいる |
| 撮影秒数 | 8秒 |

## 撮影の進め方（タイムスケジュール目安）

| 時間 | 作業内容 |
|------|----------|
| 0:00〜0:15 | 現場到着・照明ON・小物配置・不要物撤去 |
| 0:15〜0:25 | カメラ設定確認・テスト撮影（色味と明るさチェック） |
| 0:25〜0:35 | **外観カット**（カット1・2）撮影 |
| 0:35〜0:45 | **玄関カット**（カット3・4）撮影 |
| 0:45〜1:00 | **リビング・キッチンカット**（カット5・6・7）撮影 |
| 1:00〜1:10 | **水回りカット**（カット8）撮影 |
| 1:10〜1:20 | **階段・2階カット**（カット9・10）撮影 |
| 1:20〜1:30 | **バルコニー・エンディングカット**（カット11・12）撮影 |
| 1:30〜1:40 | **撮り直し・追加カット** |
| 1:40〜1:45 | 撮影データ確認・現場原状復帰 |

> **所要時間: 約1時間45分**

## 撮影時のチェックリスト

撮影後に以下を確認し、漏れがあれば撮り直してください。

### 必須カット

- [ ] 外観（建物全体が映っているカット）
- [ ] アプローチ（家に向かって歩くカット）
- [ ] 玄関ドアを開ける瞬間
- [ ] 玄関ホール全景
- [ ] リビング全景
- [ ] リビングでくつろぐカット
- [ ] キッチン全景
- [ ] 階段を上がるカット
- [ ] 2階居室
- [ ] エンディングカット

### あると良いカット

- [ ] ディテール（照明・壁材・スイッチ等）×3つ以上
- [ ] 窓/吹き抜けの開放感カット
- [ ] 洗面台アップ
- [ ] バスルーム
- [ ] クローゼット内部
- [ ] バルコニーからの景色
- [ ] 水栓を開ける/引き出しを開ける等の「動作」カット

### 品質チェック

- [ ] 全カット手ブレが許容範囲内か
- [ ] 鏡に撮影者が映り込んでいないか
- [ ] 不要物（掃除道具、段ボール等）が映り込んでいないか
- [ ] 暗すぎるカットがないか（暗い場合は照明追加して撮り直し）
- [ ] 各カット2テイク以上撮っているか

## よくあるNG例と対処法

| NG | なぜダメか | 対処法 |
|----|-----------|--------|
| カメラをガクガク動かす | 酔う映像になり即スワイプされる | 腕を体に固定し、体全体で移動する |
