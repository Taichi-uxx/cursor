# B案：危機感・経営者視点型

## コンセプト
「採用の悩み」を「事業存続の経営課題」に再定義する。CEO対CEOの本音トーンで、危機意識を行動に変える。

ベテランの職人や技術者があと数年で定年を迎える。

そして、高卒採用の解禁が目前に迫った今こそ、
手を打てる大事なタイミングだと考えております。

高卒の若手人材は、育てれば10年、20年と会社を支えてくれる存在です。
しかし、求人票を出すだけでは、高校生に届きません。

実際に、求人票では応募が来なかった企業様が、

もし今、採用や人材のことで少しでもお考えがあれば、
お気軽にお声がけいただけませんでしょうか。
今できること、今やるべきことを率直にお伝えいたします。
お話をお聞きするだけでも構いません。

ご連絡を心よりお待ちしております。

## 工夫したポイント

1. **「採用課題」を「経営課題」に再定義**
   「採用がうまくいかない」は人事の話だが、「事業が続けられない」は経営者自身の問題。同じ事象を経営者の言語に変換し、"自分ごと"として読ませる。

2. **現場のリアリティ→危機感→事例→CTAの流れ**
   抽象的な危機感だけでなく、「ベテランが定年」「案件を断る」という実感ベースの描写で当事者意識を高めた後、事例で「動けば変わる」という希望を提示。危機感だけで終わらせず、行動への道筋を示す。

3. **事例を「危機の処方箋」として配置**
   危機感を語った直後に事例を置くことで、「このままではまずい→でも方法はある」という構造を作る。応募16名・内定12名の具体数字が「本当に変われる」という確信を与える。

4. **「担当ではなく代表が書いた」という構造的な説得力**
   商談は担当が行ったが、代表が改めて手紙を書くという構造が「一人の経営者として」のポジショニングに自然な説得力を与える。営業担当の後追いではなく、経営者同士の対等なコミュニケーションになる。

5. **売り込みを封印し「率直さ」で信頼を得る**
   「率直にお伝えいたします」「お話をお聞きするだけでも構いません」——過去の高額投資失敗による警戒心を踏まえ、"売らない姿勢"を明示して心理的障壁を下げる。
