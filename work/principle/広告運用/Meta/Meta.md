# Meta広告 — 鉄則・勝ち筋・負け筋

## 1. このドメインの本質

Meta広告は **「潜在ニーズに割り込みで気づかせる広告」**。
検索広告と違い、ユーザーは何かを探しに来ているわけではない。フィードを流し見しているところに、興味関心データを使って広告が割り込む構造。だから勝負を決めるのは「クエリ × LP」ではなく **「クリエイティブで何秒止められるか」**。設計・運用精度より、**クリエイティブの当て続けで勝つ媒体**。

この本質を分解すると、Meta広告は4つの構造ゲームの重ね合わせで成立している。

### 本質① クリエイティブ消耗ゲーム
Meta広告は **クリエイティブが疲弊する速度が異常に速い**。同じクリエイティブを2週間配信し続けるとCTRもCV率も半減する。理由は単純で、フィードという「同じユーザーが何度も見る面」だから。
だからこの媒体での運用者の本業は「**当てる**」ではなく「**当て続ける**」。月10本〜30本のクリエイティブを連続投下できる供給体制がそのまま競争力になる。クリエイティブが枯れた瞬間、CPAは2倍に跳ねる。

### 本質② 機械学習の食欲ゲーム
Metaの自動最適化（Advantage+ / 詳細ターゲティング自動拡張 / 予算最適化）は **「学習データを大量に食わせるほど精度が上がる」設計**。
そのため、ターゲティングを細かく絞る・予算を小さく分散する・広告セットを多数並列する、これらは全て「機械学習を飢えさせる行為」。Metaの推奨は「広いオーディエンス × まとめた予算 × Advantage+」。運用者の仕事は **絞ることではなく、機械学習に十分な餌を与えてから絞る**こと。

### 本質③ 計測信号ゲーム（CAPI / Pixel）
Meta広告は **iOS14以降、ブラウザCookieだけでは計測が穴だらけ**。サーバー間通信（CAPI: Conversions API）でサーバー側からCV信号を送らないと、機械学習がCVを見失う。
CAPI未実装の状態で「CPAが悪い」と言っても、それは広告が悪いのではなく **計測信号がMetaに届いていないだけ**の可能性が高い。Meta広告の運用は、半分は「計測実装の話」。

### 本質④ オーディエンス重複ゲーム
Meta広告は **広告セットを増やすほど、同一ユーザーへの重複配信（オークションオーバーラップ）が発生**する。重複配信は自社内で入札を競り合うことになり、CPMを自分で釣り上げる。
だから「セットを分けてテストすればするほど良い」というSearch広告的な発想は、Metaでは逆効果になる。**シンプルに、太く、まとめて配信する**のがMetaの勝ち筋。

## 2. 鉄則（破ってはいけない）

> 表記凡例: 各項目末尾の **〈本質①〜④〉** は、その鉄則がどの本質に紐づくかを示す。

1. **クリエイティブを月10本以上の供給で運用する** — 1本のホームランより、20本の打席数。供給が止まればCPAは必ず悪化する。〈本質①: クリエイティブ消耗が速いため、供給が運用の中核〉

2. **CAPIは初期実装の必須事項** — CAPIがない状態でCPAを語っても無意味。Pixelだけだと計測欠損が30〜40%発生する。〈本質③: 計測信号が学習の食物〉

3. **Advantage+ オーディエンスをまず試す** — 詳細ターゲティング（興味関心・年齢・性別）を細かく組む前に、まずAdvantage+で機械学習に任せる。〈本質②: 機械学習の食欲を満たす〉

4. **広告セットは2〜3個までに絞る** — 同一目的で5個も6個も並列すると、オーディエンス重複でCPMが釣り上がる。〈本質④: 自分で自分を競り合わない〉

5. **学習期間（最初の50CV取得まで）は触らない** — 予算変更・クリエイティブ追加・ターゲット変更で学習がリセットされる。〈本質②: 学習を観察するのが最初の仕事〉

6. **クリエイティブは「最初の1秒」で止める設計にする** — フィードの平均視認時間は1.7秒。冒頭のフックがない動画は3秒で離脱される。〈本質①: 消耗ゲームの最大変数は冒頭〉

7. **類似オーディエンス（Lookalike）はソース1000人以上から作る** — ソースが小さいと類似精度が出ない。購入者リスト・LTV上位顧客が理想ソース。〈本質②: 学習の質はソースで決まる〉

## 3. 勝ち筋（再現性のある勝ちパターン）

### 勝ち筋A: 「Advantage+ × CBO × 太い予算」シンプル構造
- **場面**: 新規アカウント立ち上げ / 月予算100万円以上
- **内容**: 広告セット1〜2個、ターゲティングはAdvantage+、予算はCBO（キャンペーン予算最適化）に寄せる
- **なぜ勝てるか**: 〈本質②④〉機械学習に十分な学習データを与えつつ、セット間重複も発生しない。Metaが最も得意とする構造に乗る。

### 勝ち筋B: クリエイティブの「軸 × フォーマット」マトリクス供給
- **内容**: 訴求軸（機能/情緒/実績/比較/緊急）× フォーマット（静止画/動画/カルーセル/UGC）で月20本生産
- **なぜ勝てるか**: 〈本質①〉消耗が速い前提で、軸×フォーマットの掛け算で母数を確保。Advantage+ クリエイティブ機能と組み合わせれば、組合せ最適化で「勝ちパターン」が浮かび上がる。

### 勝ち筋C: UGC（顧客の声・体験動画）の組織的活用
- **内容**: 既存顧客にインタビュー動画を撮影してもらう／レビューを動画化する
- **なぜ勝てるか**: 〈本質①〉自社制作の「広告らしい」素材より、UGCの方が冒頭フックが強くスクロールが止まる。Metaのフィード文化に最も馴染む。

### 勝ち筋D: 既存顧客 → Lookalike → Advantage+ の3層構造
- **内容**: ①既存顧客リスト（リターゲ・除外含む）／②類似1%／③Advantage+（広いオーディエンス）の3層で配信
- **なぜ勝てるか**: 〈本質②〉学習データの粒度が違う3層を並列することで、機械学習が自動で最適な配分を見つける。Advantage+単体より天井が高い。

### 勝ち筋E: CAPI + Aggregated Event Measurement の徹底実装
- **内容**: CAPI実装 + ドメイン認証 + 優先イベント設定 + 拡張コンバージョン
- **なぜ勝てるか**: 〈本質③〉計測欠損を埋めるだけで、機械学習の精度が体感で1.5倍になる。「広告改善」ではなく「計測改善」が最大のROI改善になる。

## 4. 負け筋（典型的な失敗・地雷）

### 負け筋A: クリエイティブを枯らしたまま運用継続
- **症状**: 1ヶ月前はCPA好調だったのに、今月は2倍に悪化
- **原因**: 〈本質①〉同じクリエイティブをCV取れているからと差し替えず使い続け、リーチが頭打ち＋疲労で離脱率上昇
- **回避策**: 「フリークエンシー2.5を超えたクリエイティブは退役」を運用ルール化

### 負け筋B: 詳細ターゲティングで絞り込みすぎる
- **症状**: CPMが想定の2倍、CV数が伸びない
- **原因**: 〈本質②〉年齢・性別・興味関心を細かく絞った結果、機械学習に与えるデータが足りなくなった
- **回避策**: ターゲティングは最低でも100万人規模を確保。Advantage+ を先に試す

### 負け筋C: CAPI未実装のままCPA判断
- **症状**: 「Meta広告はCPAが悪い」と社内判断 → 予算カット
- **原因**: 〈本質③〉Pixelだけだと計測欠損30〜40%。Meta上のCPAは実態より悪く見える
- **回避策**: 運用開始前にCAPI実装を完了。GA4と必ず突合する

### 負け筋D: A/Bテスト目的で広告セットを乱立
- **症状**: 5個のセットを並列、全部CPA悪化
- **原因**: 〈本質④〉オーディエンス重複で自社内入札競合 → CPM高騰
- **回避策**: テストは「広告セット内のクリエイティブテスト」で行う。セット分割は最小限

### 負け筋E: 学習期間中の頻繁な触り
- **症状**: 学習中（50CV未満）に予算やクリエイティブを毎日変更 → 永遠に学習が完了しない
- **原因**: 〈本質②〉Metaの学習アルゴリズムは大きな変更でリセットされる
- **回避策**: 学習期間中は予算20%以内の変更にとどめ、原則1週間は触らない

### 負け筋F: 静止画ばかりで動画を投下しない
- **症状**: CPMだけ高くなり、リーチ効率が落ちる
- **原因**: 〈本質①〉現在のMetaは動画優位のフィード。静止画だけでは冒頭1秒の握力が弱い
- **回避策**: 動画：静止画＝7：3を目安。Reels/Storiesも必ず縦型動画で配信

## 5. 判断分岐（迷ったときの基準）

| 状況 | 取るべきアクション | 紐づく本質 |
|---|---|---|
| CPA悪化が2週間続く | クリエイティブ疲労を疑う | ①消耗ゲーム |
| CPM高騰 | 広告セット重複・絞り込みすぎを疑う | ②④オーバーラップ |
| CV数頭打ち | Advantage+ / 広いオーディエンスを試す | ②機械学習の食欲 |
| 計測CPAがGA4と大きく乖離 | CAPI実装・ドメイン認証を点検 | ③計測信号 |
| 新規アカウント立ち上げ | Advantage+ × CBO × シンプル構造 | ②④ |
| Lookalike精度が低い | ソースリストの量・質を確認 | ②学習ソース |
| クリエイティブ供給が止まる | UGC活用・外部制作で月10本確保 | ①供給体制 |
| ABテストしたい | セット分割ではなく広告内テスト | ④重複回避 |
