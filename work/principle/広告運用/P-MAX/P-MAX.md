# P-MAX広告 — 鉄則・勝ち筋・負け筋

## 1. このドメインの本質

P-MAX（Performance Max）は **「Googleが持つ全在庫を1キャンペーンで丸ごと自動化する広告」**。
Search/Display/Shopping/YouTube/Gmail/Maps/Discover、これら全在庫横断で機械学習が自動配信する。運用者は **入札・配信面・クリエイティブ組合せを直接操作できない**。代わりに **シグナル（アセット・オーディエンス・コンバージョン）を入力するゲーム**になる。クリエイティブ媒体ではなく、設計媒体でもなく、**「機械学習に正しい入力を与え続ける媒体」**。

この本質を分解すると、P-MAXは4つの構造ゲームの重ね合わせで成立している。

### 本質① アセット = 入力品質ゲーム
P-MAXに渡せるのは **アセット（テキスト・画像・動画・ロゴ）とその組合せルール** のみ。Googleはこのアセットを掛け合わせて、全在庫向けの広告を自動生成する。
だから「アセットの種類と量と質」がそのまま配信品質になる。動画アセットが無ければGoogleが自動生成した低品質な動画が配信される。テキスト見出しが5本しかなければ、組合せ多様性が出ず配信効率が落ちる。**アセットの戦いがP-MAXの本丸**。

### 本質② オーディエンスシグナル = 学習ヒントゲーム
P-MAXのターゲティング欄は「設定」ではなく「**シグナル（ヒント）**」と呼ばれる。Googleはシグナルを「最初の方向性」として参考にし、最終的には自分で対象を決める。
つまり「絞り込み」ではなく「学習の出発点を指定する」機能。**シグナルを与えないと学習はゼロから始まり、汎用的すぎる配信になる**。カスタムセグメント（検索意図キーワード）／顧客リスト／ウェブサイト訪問者などをシグナルに入れることで、学習の初動が早くなる。

### 本質③ コンバージョンデータ = 燃料ゲーム
P-MAXは **全自動の代償として、自動入札（tCPA/tROAS）を強制的に使う**。手動入札の選択肢はない。だから機械学習を回す **コンバージョンデータの質と量が全成果を決める**。
過去30日でCV30件未満のアカウントでP-MAXを動かすと、学習が回らずCPAが暴走する。マイクロCV（カート投入・登録など）を中間目標として使う、価値ベース入札を使う、など **「燃料の供給設計」が事前準備の中核**。

### 本質④ ブラックボックス = 観察制限ゲーム
P-MAXは **配信先・配信内容・どのオーディエンスが効いたかが、ほぼ見えない**。検索語句レポートは限定公開、配信先プレースメントも限定公開、アセットレポートも「Best/Good/Low」の3段階のみ。
だから「データを見て微調整する」というSearch広告的な運用ができない。**観察できる少ない指標から構造を推測し、入力（アセット/シグナル/CV/除外）の側で操作する**ことが運用者の唯一の仕事。

## 2. 鉄則（破ってはいけない）

> 表記凡例: 各項目末尾の **〈本質①〜④〉** は、その鉄則がどの本質に紐づくかを示す。

1. **アセットは各種類「最大数」を埋める** — 見出し15本・説明文5本・画像20点・動画5本・ロゴ複数。アセット枠が空白だとGoogleが自動生成し品質が落ちる。〈本質①: 入力品質が配信品質〉

2. **動画アセットは必ず自社で用意する** — 動画なしだとGoogleが画像から自動生成した低品質動画がYouTube面に流れる。〈本質①: 自動生成は最低品質〉

3. **オーディエンスシグナルを必ず投入する** — カスタムセグメント・顧客リスト・データセグメントを最低3種類入力。空欄でローンチしない。〈本質②: 学習の出発点を与える〉

4. **CV計測の正確性・量の確保が前提** — 過去30日CV30件未満ではP-MAX起動しない。マイクロCV・拡張CV・オフラインCVも併用。〈本質③: 燃料の質と量〉

5. **ブランドキーワードは必ず除外設定**（ブランド除外リスト機能） — 何もしないとP-MAXがブランドKWで「成果が出る」と学習し、本来Search広告で取れていたCVを横取りする。〈本質③④: 学習の偏りと評価の歪み〉

6. **キャンペーン分割は商品マージン・カテゴリで行う** — tROAS入札を商品差で分けるため。1キャンペーンに全商品入れるとROASが平均化されて高粗利商品が伸び悩む。〈本質③: 入札目標の解像度〉

7. **アセットグループは「テーマ別」で複数作成** — 1つのアセットグループに全商材を詰め込むと、組合せ最適化が機能しない。〈本質①: テーマで切り、組合せ精度を上げる〉

## 3. 勝ち筋（再現性のある勝ちパターン）

### 勝ち筋A: 「マージン軸キャンペーン分割 × 商品セット」設計
- **場面**: ECサイトでP-MAX運用、商品数が多い
- **内容**: 高マージン商品 / 標準商品 / 在庫処分商品の3キャンペーンに分割。それぞれtROAS目標を変える
- **なぜ勝てるか**: 〈本質③〉tROASは「全商品平均」では機能しない。マージンで切れば、それぞれの目標で最適化される。

### 勝ち筋B: ブランド除外 + 非ブランド成果評価
- **内容**: ブランドKW除外機能を使い、P-MAXは「非ブランド成果」だけで評価
- **なぜ勝てるか**: 〈本質④〉ブランド込みでP-MAXのROASを見ると「Search広告のCVを横取りしているだけ」が見えない。非ブランドで評価することで、純粋な拡張効果を測れる。

### 勝ち筋C: カスタムセグメント（検索意図KW）でのシグナル指定
- **内容**: 競合名・カテゴリKW・ユースケースKWを束ねたカスタムセグメントをオーディエンスシグナルに投入
- **なぜ勝てるか**: 〈本質②〉Googleに「この検索行動をしている人が当社の見込み客」と教えることで、学習初動が劇的に速くなる。

### 勝ち筋D: アセット5フォーマット完備（見出し/長見出し/説明文/画像/動画/ロゴ）
- **内容**: 各種類の最大数を埋め、軸（機能/情緒/実績/緊急）別に網羅
- **なぜ勝てるか**: 〈本質①〉組合せ最適化の母数が指数関数的に増える。アセット20点と50点では、後者のほうが配信効率が2倍違うケースがある。

### 勝ち筋E: マイクロCV併用での学習加速
- **内容**: 購入CVだけでなく、カート投入・会員登録・3ページ閲覧などのマイクロCVを併用
- **なぜ勝てるか**: 〈本質③〉CV数が少ないアカウントで自動入札を回すには燃料が足りない。マイクロCVで燃料を10倍に増やせば、学習が回り始める。

## 4. 負け筋（典型的な失敗・地雷）

### 負け筋A: ブランドCV取り込みによる成果水増し
- **症状**: P-MAXのROASは異常に良いが、Search広告のブランドCV数が半減
- **原因**: 〈本質③④〉P-MAXがブランドKWで成果出していると学習し、横取りした結果。実際はP-MAX起動前後で全体CVは増えていない
- **回避策**: ブランド除外リスト機能を必ず使う。導入前後で「ブランドCV / 非ブランドCV」を別評価

### 負け筋B: アセット不足での発進
- **症状**: CPCは安いがCV取れない、ブランド毀損的なクリエイティブが配信される
- **原因**: 〈本質①〉動画なし / 画像5枚 / 見出し5本だけで発進 → Googleが補完で低品質クリエイティブを自動生成
- **回避策**: ローンチ前にアセット最大数を埋める。動画は必ず自社用意

### 負け筋C: オーディエンスシグナル空欄
- **症状**: 立ち上げ4週間経っても学習が安定しない、CPAブレ大
- **原因**: 〈本質②〉シグナルなしだとGoogleがゼロから学習。汎用配信が続き、特定セグメントに収束しない
- **回避策**: カスタムセグメント・顧客リスト・データセグメントを最低3種類投入

### 負け筋D: CV30件未満でP-MAX起動
- **症状**: tCPA設定の3倍CPA、予算溶ける
- **原因**: 〈本質③〉燃料不足で機械学習が暴走。少ないCVデータから誤った最適化方向に走る
- **回避策**: 過去30日CV30件未満ならP-MAX起動しない。Search広告で母数を作ってから移行

### 負け筋E: 1キャンペーンに全商品詰め込み
- **症状**: ROAS平均が目標到達も、売れ筋商品ばかり配信され在庫過多商品は売れ残る
- **原因**: 〈本質③〉1つのtROAS目標で動かすと、高ROAS商品に予算が寄る
- **回避策**: 商品グループ・マージン別にキャンペーン分割。tROAS目標を変える

### 負け筋F: アセット効果の「Best/Low」ラベルで一喜一憂
- **症状**: 「Lowラベルのアセットを削除→翌週もLow出現→また削除」の永久ループ
- **原因**: 〈本質④〉Best/Lowは相対評価。母数の中で常に「Low」は発生する。削除し続けると母数が枯渇
- **回避策**: アセットは「削除」ではなく「追加」で運用。Lowを削るのは最終手段

## 5. 判断分岐（迷ったときの基準）

| 状況 | 取るべきアクション | 紐づく本質 |
|---|---|---|
| CV30件未満 | P-MAX起動を見送る | ③燃料不足 |
| 学習が安定しない | オーディエンスシグナルを増やす | ②学習ヒント |
| ROAS高いが全体CV増えていない | ブランドCV横取りを疑う | ③④評価の歪み |
| 配信が偏っている | キャンペーンを商品軸で分割 | ③入札解像度 |
| CTR低い | アセット（動画・画像）追加 | ①入力品質 |
| 売れ筋ばかり配信 | キャンペーン分割で目標差をつける | ③ |
| Lowアセットが多い | 削るのではなく軸違いを追加 | ①観察制限 |
| 新規アカウント立ち上げ | Search広告先行で燃料作る | ③ |
