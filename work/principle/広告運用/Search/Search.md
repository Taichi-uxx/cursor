# Search広告 — 鉄則・勝ち筋・負け筋

## 1. このドメインの本質

検索広告は **「顕在ニーズに後出しジャンケンで応える広告」**。
ユーザーは既に答えを探しに来ているので、こちらの仕事は「正しい答えを正しい順序で差し出す」だけ。クリエイティブで心を動かす媒体ではなく、**設計と運用精度の積み重ねで勝つ媒体**。

この本質を分解すると、検索広告は4つの構造ゲームの重ね合わせで成立している。

### 本質① 3階層シリアル整合性ゲーム
検索広告の成果は「**クエリ意図 × 広告文 × LP**」の積算で決まる。
どれか1つが90点でも、他が30点なら結果は 90×30×30=8万 にしかならない。**直列構造なので、最弱の階層が天井を決める**。「広告文だけ磨く」「LPだけ磨く」では絶対に勝てないのはこのため。

### 本質② 機械学習への餌やりゲーム
現代のSearchは自動入札（tCPA/tROAS/コンバージョン最大化）が主戦場。
ここでの運用者の仕事は「入札を細かく操作すること」ではなく **「機械学習に正しい餌（コンバージョン信号・除外・予算）を与えて、正しい方向に学習させること」**。
餌が雑なら、Googleは雑に学習して雑な結果を返す。CV計測のズレ、除外KW放置、予算の急変動はすべて「学習の汚染」。

### 本質③ 残存検索量との戦い
検索広告には **「その月に世の中で発生する検索回数」というハードキャップ**がある。CPMで増やせる枠ではない。
したがって伸ばすには「**取り切れていない検索量を取りに行く**」か「**ムダ打ちを削って同じ予算で取れる量を増やす**」しかない。「予算を倍にしたら成果も倍」が成立しにくいのはこのため。

### 本質④ 競合との相対勝負
検索結果の広告枠は上位4枠程度に限られ、**入札 × 品質スコア = 広告ランク** で相対順位が決まる。
つまり「自社が良くなった」のと同じくらい「**競合が崩れた／参入してきた**」が成果を左右する。Auction Insights を見ない運用は片目を閉じているのと同じ。

## 2. 鉄則（破ってはいけない）

> 表記凡例: 各項目末尾の **〈本質①〜④〉** は、その鉄則がどの本質に紐づくかを示す。

1. **検索意図とLPの一致を最優先する** — クエリと着地ページがズレるとCV率が桁で落ちる。CPCを下げる前にここを直す。〈本質①: 3階層の最弱が天井を決めるため、まずLP整合性で天井を上げる〉

2. **マッチタイプは必ず混在管理**（完全/フレーズ/部分） — 部分一致だけだと無関係クエリで予算が溶ける。完全一致だけだと機会損失。〈本質②③: 部分一致は「機械学習に食わせる粗い餌」、完全一致は「精緻な餌」。両方ないと学習も検索量取得もバランスしない〉

3. **除外キーワードを毎週見直す** — 「無料」「やり方」「とは」など情報収集クエリを放置すると、機械学習がその方向で最適化を始める。〈本質②③: 餌の汚染を取り除く＋ムダ打ちを削る〉

4. **品質スコアを下げる原因は3つに絞られる**（広告関連性／LP関連性／推定CTR） — 不調時はこの順で点検。〈本質①④: 3階層整合性が直接スコアになり、それが相対順位を決める〉

5. **コンバージョン計測の正確性が全ての前提** — 二重計上、未計測、遅延CV、計測ズレ状態で運用判断するのは禁止。〈本質②: 餌が腐っていたら学習は必ず狂う〉

6. **入札戦略の切替直後は学習リセット。1〜2週間は触らない** — 切替→数日でCPA悪化→慌てて戻す、は最も典型的な事故。〈本質②: 機械学習には「観察期間」が必要〉

7. **ブランドキーワードは必ず防御出稿する** — 他社にブランドKWを取られると、最もCV率の高い枠を奪われる。〈本質①④: 指名クエリは3階層整合性が最強で、相対勝負でも品質スコアで圧勝するため最優先で確保〉

## 3. 勝ち筋（再現性のある勝ちパターン）

### 勝ち筋A: 「指名 × 一般 × ロングテール」3層キャンペーン構造
- **場面**: 新規アカウント立ち上げ / 構造リセット時
- **内容**:
  - 指名（ブランドKW）: 完全一致中心、tCPA低
  - 一般（カテゴリKW）: フレーズ中心、tROAS or tCPA
  - ロングテール（複合KW）: 部分一致、コンバージョン最大化
- **なぜ勝てるか**: 〈本質②〉学習対象を「クエリの確からしさ」で分離するため、機械学習が層ごとに最適化できる。混ぜると指名の高CV率データに釣られて一般・ロングテールの入札が暴走する。

### 勝ち筋B: RSAアセットの「訴求軸別」設計
- **内容**: 見出し15本を「機能訴求×4／実績訴求×4／緊急性×3／価格×2／指名×2」のように軸で割り振る
- **なぜ勝てるか**: 〈本質①〉ユーザーのクエリ意図は軸が違う（機能を知りたい人 / 実績を知りたい人）。軸を散らせば、Googleの組合せ最適化が「クエリ意図 × 軸」のマッチを見つけやすい。同じ軸のコピーを15本並べると、最強の軸しか機能しない。

### 勝ち筋C: 「LPだけ差し替え」A/Bテスト
- **場面**: CTRは出てるがCV率が低いとき
- **内容**: 広告群・KWは固定、LPだけ差し替え。最低2週間 or CV30件
- **なぜ勝てるか**: 〈本質①〉3階層のうち「LP階層だけ」を切り分けて変数化することで、原因特定が綺麗にできる。広告とLPを同時に変えると、どちらが効いたのか永遠に分からない。

### 勝ち筋D: 業界別「除外KW先回り登録」
- **内容**: 業界別の鉄板除外リスト（求人系なら「バイト/パート/転職会議」、医療系なら「副作用/口コミ/まとめ」など）を初日から流し込む
- **なぜ勝てるか**: 〈本質②③〉学習初期に汚染データが入ると、それを引きずって2〜3ヶ月CPAが悪化する。「最初の餌の純度」が長期成績を決める。

### 勝ち筋E: 自動入札への移行は「過去30日CV30件超え後」
- **内容**: tCPA / tROAS への切替は、過去30日でCV30件を超えてから
- **なぜ勝てるか**: 〈本質②〉機械学習には統計的に有意な観察データが必要。30件未満で自動入札を回すと、ノイズで暴走する。

## 4. 負け筋（典型的な失敗・地雷）

### 負け筋A: 部分一致 × 自動入札の「初期暴走」
- **症状**: 立ち上げ1週間で予算を食い尽くす / CPAが想定の3倍
- **原因**: 〈本質②③〉学習データなしで部分一致 × tCPA を投入 → Googleが「とにかくCV取れそうなクエリ」を探して無関係クエリで学習。汚染された学習は剥がすのに数週間かかる。
- **回避策**: 初期は手動入札 or コンバージョン最大化（上限CPC設定）で「餌の純度」を保つ

### 負け筋B: 広告文を頻繁に書き換える
- **症状**: CTRが安定しない、品質スコアが上がらない
- **原因**: 〈本質②④〉Google側の機械学習がリセットされ続け、品質スコアが育たない。相対勝負で負け始める。
- **回避策**: 同時並行で2-3パターンをRSA内でテスト。差し替えは月1まで

### 負け筋C: LP直帰99%なのに広告を触り続ける
- **症状**: 予算消化はするがCV0
- **原因**: 〈本質①〉LP階層が0点だと、上流の広告階層をいくら磨いても積算で0。「最弱の階層」を放置している典型。
- **回避策**: 直帰率80%超 or LP滞在5秒未満なら **広告凍結 → LP修正** が先

### 負け筋D: インプレッションシェアだけ追う
- **症状**: シェア80%取れてるのにCV伸びない
- **原因**: 〈本質③〉そのKW群の検索量天井に到達している。「シェアを取る」と「成果を伸ばす」は別問題。
- **回避策**: 「IS×CV」のクロス分析。シェア取れててもCV出ないKWは予算カット、新規KW開拓へ振る

### 負け筋E: 競合KWへの過剰防衛
- **症状**: 他社名KWでクリック取れるがCV極低、CPA悪化
- **原因**: 〈本質①〉他社名クエリの意図は「他社を探している」なので、自社LPとの整合性が崩れている
- **回避策**: 比較系クエリ（「A vs B」「B 評判」など）に絞る。単純な他社名は基本見送り

### 負け筋F: 「先月のCPAが良かった」で判断する
- **症状**: 単月で評価して打ち手がブレる
- **原因**: 〈本質④〉成果は「自社の良し悪し」だけでなく「競合の参入/撤退」で揺れる。Auction Insights を見ずに自社要因に帰着させると、判断を誤る。
- **回避策**: CPAが揺れたらまず Auction Insights → 市場要因を切り分け → そのうえで自社要因を疑う

## 5. 判断分岐（迷ったときの基準）

| 状況 | 取るべきアクション | 紐づく本質 |
|---|---|---|
| CTRは高いがCV低い | LPまたは商品力を疑う | ①最弱階層を特定 |
| CTR低い | 広告文・KWマッチ度を疑う | ①上流の整合性 |
| CPAが目標の1.5倍超 | まず除外KW追加→入札調整 | ②餌の純度が先 |
| CV単価高騰が3日続く | 一時停止せず「予算半減」 | ②学習リセット回避 |
| 過去30日CV<30件 | 自動入札は使わない | ②データ量不足 |
| 新規アカウント立ち上げ | 手動入札→2-4週後に自動入札 | ②餌を貯めてから |
| 季節要因で急変動 | 季節調整入札を使う | ②tCPAを動かさずに済む |
| シェア80%超でCV伸びない | 新規KW開拓に予算シフト | ③天井打ち |
| CPAが先月から急悪化 | Auction Insights を最初に見る | ④競合要因の切り分け |

## 6. 実務チェックリスト

### 立ち上げ時
- [ ] 計測（CV/MCV/拡張CV）が正しく動いているか 〈本質②〉
- [ ] 指名キャンペーンを分離してあるか 〈本質②〉
- [ ] 除外KWの初期リストを投入したか 〈本質②③〉
- [ ] RSAは見出し15本・説明文4本を埋めたか 〈本質①〉
- [ ] LPの読込3秒以内・SP最適化されているか 〈本質①〉

### 週次運用
- [ ] 検索語句レポートを確認、除外追加 〈本質②③〉
- [ ] CV単価 × CV数 × IS の3軸で各キャンペーン点検 〈本質③〉
- [ ] 品質スコア悪化KWを抽出 〈本質①④〉
- [ ] LP直帰率の異常変動を確認 〈本質①〉

### 月次運用
- [ ] 入札戦略の効果検証 〈本質②〉
- [ ] 構造（キャンペーン/広告グループ分割）の見直し 〈本質①②〉
