# YDA（Yahoo!広告ディスプレイ）— 鉄則・勝ち筋・負け筋

## 1. このドメインの本質

YDA は **「日本人の生活動線に張り込んで認知と再接触を取る広告」**。
GDN・Meta と違い、YDA の主戦場は **Yahoo!ニュース・Yahoo!トップ・Yahoo!天気・Yahoo!知恵袋といった「日本人の日常閲覧面」**。ユーザーは何かを探しに来ているわけではなく、「ニュースを見に来た」「天気を確認しに来た」。そこに、Yahoo! ID を起点としたパーソナライズで広告が割り込む構造。
だから YDA は **「面の質」と「ID 起点のターゲティング精度」で勝つ媒体**。クリエイティブ単体勝負（TikTok）でも、設計精度勝負（Search）でもない、**第3の戦い方**。

この本質を分解すると、YDA は4つの構造ゲームの重ね合わせで成立している。

### 本質① 「日本人の生活面」面質ゲーム
YDA の最大の差別化要素は **Yahoo! プレミアム面（Yahoo! トップ／Yahoo! ニュース）にリーチできる唯一の媒体**であること。ここは Meta でも Google でも到達不可能で、特に **30〜60代の意思決定層・PCユーザーへの接触率が群を抜く**。
逆に、若年層やスマホ完結層へのリーチでは Meta / TikTok に劣る。だから運用者の仕事は「YDA を Meta の代替として使う」ではなく **「YDA でしか取れない層・面に意図的に予算を流す」**こと。YDA を Meta と同じKPIで評価すると必ず負ける。

### 本質② Yahoo! ID 起点パーソナライズゲーム
YDA のターゲティングの強さは **Yahoo! ID に紐づく検索履歴・購買履歴・利用サービス履歴のデータ量**にある。Yahoo!ショッピング・PayPay・ヤフオク・Yahoo!ファイナンス等のサービス利用データが、すべて広告ターゲティングに使える。
具体的には「サーチターゲティング（過去に特定KWで検索した人）」「サイトリターゲティング」「オーディエンスリスト（年収・購買力など）」が強力。**Yahoo! ID を持つ国内ユーザーは推定6,000万人**で、日本市場では Google にも引けを取らない母集団。

### 本質③ ブランド広告との同居ゲーム
YDA は伝統的に **ブランド広告（純広・予約型）と運用型が同じ面で同居している媒体**。これが何を意味するかというと、YDA のプレミアム面では **入札型の運用広告でも、ある程度「ブランド露出」としての価値を持つ**ということ。
だから YDA の評価指標は CV単体ではなく、**ビュースルーCV・後追いCV・指名検索リフト**まで含めて見ないと過小評価する。Last Click だけで判断すると「YDA は数字が出ない媒体」になるが、実態は **検索やSNSの上流に効いている**ケースが多い。

### 本質④ クリエイティブ「日本語・実写・信頼感」ゲーム
YDA のユーザー層は Meta より平均年齢が高く、PC利用比率も高い。だから刺さるクリエイティブの作法が違う。
- 派手すぎるアニメーションより **きちんとした日本語・実写・実績訴求**
- 「クリック！」「今すぐ！」より **「比較できます」「資料請求はこちら」**
- 年齢層に合った写真・モデル選定

つまり Meta / TikTok 用のキレイで若々しい素材をそのまま流すと、面とのミスマッチで CTR が伸びない。**YDA 専用素材を作る覚悟が必要な媒体**。

## 2. 鉄則（破ってはいけない）

> 表記凡例: 各項目末尾の **〈本質①〜④〉** は、その鉄則がどの本質に紐づくかを示す。

1. **YDA を「Meta の代替」として評価しない** — 取れる層・取れる面が違うため、KPIも別建てで設計する。〈本質①: 面質が違う〉

2. **サーチターゲティング（過去検索者）を必ず使う** — YDA で最も強力なターゲ機能。Yahoo! 検索の履歴をリタゲ的に活用できる。〈本質②: ID起点パーソナライズの中核〉

3. **クリエイティブは Meta 用を流用しない** — 30〜60代に合うトーン・実写・落ち着いた色味で別制作する。〈本質④: 面・ユーザー層に合わせる〉

4. **評価指標に「ビュースルーCV」「指名検索リフト」を必ず含める** — Last Click だけでは YDA の本当の効果が見えない。〈本質③: ブランド広告的価値〉

5. **Yahoo!プレミアム面（トップ/ニュース）を意図的に取りに行く** — 「全配信面」放置だと、安価な低品質面ばかりに流れて意味が薄れる。〈本質①: 面の質を選ぶ〉

6. **リターゲティングを必ず構築する** — 自社サイト訪問者・カート離脱者へのリターゲは、YDA で最も CV 率の高い面。〈本質②: ID 起点で正確に追える〉

7. **新規アカウントは検索連動とセットで立ち上げる** — Yahoo! の検索 → ディスプレイのデータ連動でターゲ精度が上がる。〈本質②: ID データの蓄積〉

## 3. 勝ち筋（再現性のある勝ちパターン）

### 勝ち筋A: 「サーチターゲティング × プレミアム面」の高品質リーチ
- **場面**: 検討期間が長い商材（不動産・金融・BtoB・高額商材）
- **内容**: Yahoo! 検索で特定KWを叩いたユーザーに、Yahoo! トップ/ニュース面で広告を当てる
- **なぜ勝てるか**: 〈本質①②〉「検索意図が顕在化したユーザー × 信頼感の高い面」の組合せ。Yahoo! でしか作れない接触パターン。

### 勝ち筋B: 検索連動とのフルファネル設計
- **内容**: 上流（YDA：プレミアム面で認知）→ 中流（YDA：サーチターゲ／リタゲで再接触）→ 下流（Yahoo!検索：指名・一般KWでCV回収）
- **なぜ勝てるか**: 〈本質②③〉Yahoo! の ID データが上流〜下流で一気通貫で使える。Meta / Google を組み合わせるよりデータ連携がクリーン。

### 勝ち筋C: リターゲティング階段（離脱箇所別）
- **内容**: ①TOP離脱／②商品ページ離脱／③カート離脱／④購入完了者の除外 を階段で構築
- **なぜ勝てるか**: 〈本質②〉Yahoo! ID 起点でユーザーを正確に追跡できるので、リタゲセグメントの分解能が高い。離脱箇所ごとに訴求を変えるだけで CPA が大きく改善する。

### 勝ち筋D: 動画広告（YDA動画）でブランドリフト + 検索リフト狙い
- **内容**: 縦型・横型の動画素材を YDA 動画面に配信、KPIは指名検索リフト・ビュースルーCV
- **なぜ勝てるか**: 〈本質③④〉YDA の面は「広告を見て、後で検索する」動線が強い。Last Click では取れないが、検索ボリュームを押し上げる効果が定量化できる。

### 勝ち筋E: 業種別オーディエンス（カテゴリ・購買意向）の活用
- **内容**: Yahoo! 独自の購買意向オーディエンス（旅行検討中／自動車検討中／不動産検討中など）を併用
- **なぜ勝てるか**: 〈本質②〉Yahoo!ショッピング・ヤフオク・Yahoo!不動産等の利用データから組成されたオーディエンスは、Meta の興味関心より購買意向の確度が高い。

## 4. 負け筋（典型的な失敗・地雷）

### 負け筋A: Meta のクリエイティブをそのまま流用
- **症状**: CTR が想定の半分、CPA が Meta より悪い
- **原因**: 〈本質④〉若年層向け・SNS的トーンの素材は、Yahoo! のプレミアム面・年齢層と合わない
- **回避策**: YDA 専用に、実写・落ち着いた配色・信頼感重視の素材を別制作する

### 負け筋B: Last Click だけで評価して「YDA は効かない」と判断
- **症状**: 単月で CPA が悪く見え、予算カット → 検索の CV も連動して落ちる
- **原因**: 〈本質③〉YDA は上流効果・ビュースルー寄与が大きいため、Last Click では過小評価される
- **回避策**: ビュースルーCV・後追いCV・指名検索リフトを必ず可視化。MMM 簡易版での寄与分析も検討

### 負け筋C: 配信面を放置して低品質面に流れる
- **症状**: インプレッションは取れているのに CTR・CV ともに低い
- **原因**: 〈本質①〉プレースメント指定をせず「全配信面」で回した結果、安価な低品質面ばかりに配信されてプレミアム面に届いていない
- **回避策**: Yahoo! トップ/ニュース等のプレミアム面を指定。除外プレースメントも定期的に棚卸し

### 負け筋D: サーチターゲティングを使わない
- **症状**: 「ターゲット拡張」「興味関心」だけで運用 → CV 効率が伸びない
- **原因**: 〈本質②〉YDA の最大の武器であるサーチターゲ未活用は、本媒体を選んだ意味の半分を捨てている
- **回避策**: 商材関連KW（指名・一般・競合・課題系）でサーチターゲを必ず組成

### 負け筋E: リターゲティングタグ未実装で運用開始
- **症状**: 立ち上げ直後の CV が全く出ない
- **原因**: 〈本質②〉YDA で最も CV 効率の高いリタゲ面が使えていない
- **回避策**: サイトリターゲティングタグを運用開始前に必ず実装。離脱箇所別のリスト分割も同時に

### 負け筋F: 検索広告と分断して運用
- **症状**: YDA と Yahoo!検索でターゲがバラバラ、データが連動しない
- **原因**: 〈本質②〉Yahoo! の強みは ID データの一気通貫。検索とディスプレイを別運用してしまうとその強みが消える
- **回避策**: 同一アカウント・同一コンバージョン設定で運用し、サーチターゲ・リタゲをまたいで設計

## 5. 判断分岐（迷ったときの基準）

| 状況 | 取るべきアクション | 紐づく本質 |
|---|---|---|
| Meta と同じ KPI で評価したくなる | KPIを別建てで再設計（ビュースルー込み）| ③ブランド広告的価値 |
| CTR が Meta の半分 | クリエイティブを YDA 専用に作り直す | ④面・年齢層の作法 |
| CV が伸びない | サーチターゲ・リタゲの組成状況を確認 | ②ID起点ターゲ |
| Last Click では悪いが指名検索が増えている | 上流寄与を評価指標に追加 | ③上流効果 |
| 新規アカウント立ち上げ | 検索連動 + サーチターゲ + リタゲをセットで | ②データ連携 |
| 検討期間が長い商材 | プレミアム面 + サーチターゲ重視 | ①②高品質接触 |
| ブランド毀損を避けたい | 配信面をプレミアム面に指定 | ①面の質 |
| 30〜60代がターゲット | YDA の比率を上げる | ①面のリーチ層 |
