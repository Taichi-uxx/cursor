# LINE広告（LINE Ads Platform）— 鉄則・勝ち筋・負け筋

## 1. このドメインの本質

LINE 広告は **「日本人の連絡インフラに広告が割り込む」唯一の媒体**。
日本国内 MAU 約9,600万人、ほぼ全世代の生活インフラとなった LINE のトーク・ニュース・タイムライン（VOOM）面に広告が出る構造で、他媒体では絶対に到達できないユーザー層（高齢層・スマホ完結層・低デジタル感度層）にリーチできる。
ただし、LINE は本来「コミュニケーションのアプリ」であって「広告を見に来るアプリ」ではない。だからユーザーの広告許容度は他媒体より低く、**「広告で売る」より「友だち追加して長期で関係を作る」の方が圧倒的に勝ちやすい**。**CPA単発勝負ではなく、CRM起点で設計する媒体**。

この本質を分解すると、LINE 広告は4つの構造ゲームの重ね合わせで成立している。

### 本質① 「日本人の生活インフラ」リーチゲーム
LINE は **日本国内で他媒体と比較してリーチ独占性が最も高い**媒体。Meta / TikTok が届かない高齢層・低デジタル感度層・地方層に届く唯一の選択肢で、特に40代以上・主婦層・シニア層へのリーチは LINE 一強。
逆に、Z世代の「広告許容度」では TikTok / Instagram に劣る。だから LINE を「Meta の補完」ではなく **「Meta で届かない層を取りに行く媒体」**として位置づけるのが正解。Meta と同じターゲット・同じKPIで運用すると必ず負ける。

### 本質② 友だち追加 × CRM ゲーム
LINE 広告の最大の特徴は **「友だち追加（CPF: Cost Per Friend）」を CV にできる**こと。一度友だち追加してもらえば、その後は **LINE 公式アカウント経由で無料で何度でも配信できる**。
つまり LINE 広告は「広告単体の CPA」だけでなく **「友だち獲得 → 公式アカウントでの育成 → CV」の2段ロケットで考える**媒体。商品単価が高い／検討期間が長い／リピート前提の商材ほど、LINE の CRM 連動が刺さる。**広告と公式アカウント運用を切り離すと、LINE の真価が出ない**。

### 本質③ チャネル別配信面ゲーム
LINE 広告は **配信面の性格が他媒体より極端に分かれる**。
- **トークリスト面**: クリック率は高いが「邪魔だ」と感じられやすい。CPF・低単価CV向き
- **LINE NEWS 面**: 落ち着いた閲覧文脈。中〜高単価商材・BtoB と相性が良い
- **LINE VOOM（旧タイムライン）**: SNS的な閲覧文脈。動画クリエイティブとの相性が強い
- **ウォレット/ホーム面**: 決済・金融系商材と高相性

「全配信面」で雑に回すと面ごとの性格差で評価が歪むので、**面別に KPI と運用方針を分けるのが基本**。

### 本質④ クリエイティブ「日本人の生活感」ゲーム
LINE のユーザー層は男女比・年齢比がほぼ日本人口の縮図に近く、**Meta / TikTok より平均年齢が高く、地方比率も高い**。
だから刺さるクリエイティブの作法は YDA に近く、**実写・日本語・生活感のある写真・実績や信頼性訴求**が強い。Meta の「キャッチー・若々しい・SNS的」素材をそのまま流すと、面とのミスマッチで CTR は半分以下になる。**LINE 専用素材を別制作するか、最低でも文字情報・トーンを面ごとに調整する**必要がある。

## 2. 鉄則（破ってはいけない）

> 表記凡例: 各項目末尾の **〈本質①〜④〉** は、その鉄則がどの本質に紐づくかを示す。

1. **LINE を「Meta の代替」として評価しない** — 取れる層が違う。Meta で届かない層を取りに行く媒体として位置づける。〈本質①: リーチ独占性〉

2. **友だち追加を CV ゴールに据える設計を必ず検討** — 商材によっては購入直接CVより、CPF → CRM の方が ROI が高い。〈本質②: 2段ロケット〉

3. **公式アカウント運用と広告を一体で設計** — 友だち追加した後の配信シナリオがなければ LINE 広告の半分は捨てている。〈本質②: CRM連動〉

4. **配信面を必ず分けて評価する** — トーク／NEWS／VOOM／ウォレットを同じKPIで見ない。〈本質③: 面ごとに性格が違う〉

5. **クリエイティブは Meta 用を流用しない** — 日本人の生活感に寄せた実写・日本語訴求で別制作する。〈本質④: 面・ユーザー層に合わせる〉

6. **LINE タグ（LINE Tag）を運用開始前に必ず実装** — リターゲ・類似配信の前提。未実装だと媒体性能の半分が死ぬ。〈本質②: 計測・CRM の起点〉

7. **オーディエンス機能（LINE Audience Network / Look-a-like）を活用する** — 公式アカウント友だちリスト・購入者リストを起点に類似配信を組む。〈本質②: CRM データを広告に逆流〉

## 3. 勝ち筋（再現性のある勝ちパターン）

### 勝ち筋A: 「友だち追加 → 公式アカウント育成 → CV」の2段ロケット運用
- **場面**: 検討期間が長い商材（不動産・金融・教育・BtoB）／リピート前提の商材（D2C・健康食品）
- **内容**: 広告 CV は「友だち追加」、その後ステップ配信で7〜14日かけて CV に誘導
- **なぜ勝てるか**: 〈本質②〉広告単体 CPA は高くなりがちな商材でも、CPF にすれば1桁安く取れる。CRM 経由で長期的に CV を回収できるため LTV ベースで圧勝する。

### 勝ち筋B: 公式アカウント友だちリスト起点の Look-a-like 配信
- **内容**: 公式アカウントの友だちリスト（特に購入歴のある優良顧客）をシードに類似配信
- **なぜ勝てるか**: 〈本質②〉Meta の Lookalike と同じ理屈だが、LINE は「LINE ID ベース」なので日本市場での精度が高い。CRM データを広告に逆流させる構造。

### 勝ち筋C: 「Meta で届かない層」を狙い撃ち
- **場面**: 40代以上の主婦層・シニア層・地方層がターゲットの商材
- **内容**: ターゲットを年齢40〜65歳に絞り、LINE NEWS 面中心に配信
- **なぜ勝てるか**: 〈本質①③〉Meta / TikTok でリーチが薄い層に、生活インフラとして毎日開かれている LINE で接触できる。リーチ独占性の差がそのまま競争優位になる。

### 勝ち筋D: チャネル別出し分け（同一訴求でも面ごとにクリエイティブ変更）
- **内容**: トークリスト面用＝短文・即訴求、NEWS 面用＝落ち着いた実写・信頼訴求、VOOM 用＝縦型動画
- **なぜ勝てるか**: 〈本質③④〉LINE の配信面はそれぞれ閲覧文脈が違うため、同一クリエイティブで全面配信すると面ごとに歪みが出る。面別最適化で全体 CTR が1.3〜1.5倍になる。

### 勝ち筋E: 動画クリエイティブ × VOOM 面でブランドリフト
- **内容**: 縦型15〜30秒動画を LINE VOOM 面メインで配信、指名検索リフト・ブランド認知をKPIに置く
- **なぜ勝てるか**: 〈本質①③〉LINE VOOM はSNS的閲覧で動画と相性が良い。Meta / TikTok と並べた時に「LINE でしか取れない層」への動画接触ができる。

## 4. 負け筋（典型的な失敗・地雷）

### 負け筋A: 公式アカウント運用なしで広告だけ回す
- **症状**: 友だちは増えるが CV が出ない／CRM が放置で離脱率高い
- **原因**: 〈本質②〉LINE 広告の真価は「広告 + 公式アカウントの2段ロケット」。1段目だけ撃って終わっている
- **回避策**: 広告開始前に公式アカウントのステップ配信シナリオを準備。最低7〜14日分の配信を組む

### 負け筋B: Meta のクリエイティブをそのまま流用
- **症状**: CTR が Meta の半分以下、CPM が高い
- **原因**: 〈本質④〉若年層向け・SNS的トーンの素材は、LINE の生活インフラ的な閲覧文脈と合わない
- **回避策**: LINE 専用に、実写・日本語訴求・生活感のある素材を別制作する

### 負け筋C: 全配信面を同じKPIで評価
- **症状**: CV単価のバラつきが大きく、改善ポイントが見えない
- **原因**: 〈本質③〉トーク／NEWS／VOOM／ウォレットは閲覧文脈が違うのに、同じKPIで評価して打ち手が混乱
- **回避策**: 面ごとにキャンペーン or 配信グループを分け、KPIを別建てで管理

### 負け筋D: 友だち追加を CV にせず、購入直CVだけで運用
- **症状**: CPA が想定の3倍、すぐに予算カット判断
- **原因**: 〈本質②〉LINE は購入直CV では CPA が高くなりやすい構造。CPF + CRM で取り戻すのが本道
- **回避策**: 商材特性に応じて、友だち追加を1次CV、購入を2次CVに分けて評価設計

### 負け筋E: LINE タグ未実装で運用開始
- **症状**: 立ち上げから1〜2ヶ月、機械学習が進まず CPA 改善しない
- **原因**: 〈本質②〉LINE タグがないとコンバージョン信号が機械学習に渡らない・リタゲもできない
- **回避策**: 運用開始前に LINE タグを必ず実装。CV 計測も同時に検証

### 負け筋F: ターゲットを若年層に寄せて Meta と競合
- **症状**: Z世代狙いの広告で LINE を運用するも、CTR・CV ともに Meta / TikTok に劣る
- **原因**: 〈本質①〉LINE の強みは「Meta で届かない層」。Z世代狙いでは LINE の差別化が出ない
- **回避策**: 40代以上・主婦層・地方層にターゲ重心をずらす。Z世代狙いなら Meta / TikTok を優先

## 5. 判断分岐（迷ったときの基準）

| 状況 | 取るべきアクション | 紐づく本質 |
|---|---|---|
| Meta と同じ KPI で評価したくなる | KPIを別建て（CPF・LTV含めて）で再設計 | ②2段ロケット |
| CV単発の CPA が高い | 友だち追加を1次CVにスイッチ | ②CRM連動 |
| CTR が Meta の半分 | クリエイティブを LINE 専用に作り直す | ④面・年齢層の作法 |
| 検討期間が長い／リピート前提の商材 | CPF + 公式アカウント育成設計 | ②2段ロケット |
| 40代以上・主婦・シニア層がターゲット | LINE の比率を上げる | ①リーチ独占性 |
| 配信面の評価がバラつく | 面ごとにKPIを分けて見る | ③面別の性格差 |
| 新規アカウント立ち上げ | LINE タグ + 公式アカウントの準備が前提 | ②起点整備 |
| 公式アカウント友だちリストがある | Look-a-like で類似配信に活用 | ②CRM逆流 |
