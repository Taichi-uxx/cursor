# Dynamic広告 — 鉄則・勝ち筋・負け筋

## 1. このドメインの本質

動的リターゲティング広告は **「ユーザーの行動履歴 × 商品データフィードを掛け算で配信する広告」**。
新規認知ではなく「サイトに来たことのある人 / 商品を見たことのある人」に、その人が見た商品（または類似商品）を自動生成して見せ続ける媒体。クリエイティブの良し悪しで勝つのではなく、**フィードの鮮度・行動データの精度・配信タイミングの3点で勝つ媒体**。

この本質を分解すると、動的広告は4つの構造ゲームの重ね合わせで成立している。

### 本質① 商品データフィード = 弾薬庫ゲーム
動的広告は **フィードがなければ1発も撃てない**。広告クリエイティブはフィード内の商品データ（画像・タイトル・価格・在庫）からその場で自動生成される。
だから「フィードに載っていない商品 = この世に存在しない商品」と同じ。価格が古い・在庫切れ・画像が低解像度・タイトルが意味不明、これら全てが直接クリエイティブの質になる。**広告のクリエイティブを磨く前に、まずフィードを磨く**のがこのゲームの第一原則。

### 本質② オーディエンス = 燃料ゲーム
動的広告のもうひとつの主役は「タグで取れたユーザー行動データ」。サイト訪問・カート投入・カート放棄・購入完了など、**シグナルの粒度がそのまま配信精度になる**。
カート放棄1日以内のユーザーと、TOPページを30日前に1回見ただけのユーザーを同じ束で配信すれば、当然ROASは崩れる。**シグナル別にオーディエンスを切り分け、それぞれに違う商品セット・違いの予算を当てる**のが運用の主戦場。

### 本質③ 配信タイミング = 鮮度ゲーム
動的広告には「**離脱後どれだけ早く再接触できるか**」という時間軸の戦いがある。カート放棄から1時間以内と1週間後では、コンバージョン率が桁で違う。
一方で同じユーザーに1日30回見せれば、当然嫌悪と疲弊（フリークエンシー疲労）が発生する。「**早く・適切な回数で・離脱前に**」というタイミング設計が、機械学習の自動化では拾いきれない領域。

### 本質④ リターゲ依存 = 母数ゲーム
動的広告の成果は、結局のところ **「新規流入のサイズ」の関数**。月10万人来るサイトと月1000人しか来ないサイトでは、リターゲのCV余地は100倍違う。
だから動的広告だけを磨いても天井は来る。**上流（Search/SNS/SEO）で母数を流し込んで、はじめて動的広告が活きる**。「動的広告のCPAが良い」のは当然で、問題は「動的広告で取れているCVは、上流が無くても本当に取れていたのか」という上書きCV問題が常に潜む。

## 2. 鉄則（破ってはいけない）

> 表記凡例: 各項目末尾の **〈本質①〜④〉** は、その鉄則がどの本質に紐づくかを示す。

1. **フィードの鮮度を週次で監視する** — 在庫切れ商品の配信、価格ズレ、画像欠損は即CV率を破壊する。Merchant Center / 各DSPのフィードステータスを週次で必ず確認。〈本質①: フィードが弾薬庫。弾が腐っていれば撃つほど被害が広がる〉

2. **オーディエンスは行動シグナル別に必ず分割する** — カート放棄／商品閲覧／カテゴリ閲覧／TOP訪問は別物。1つのキャンペーンに混ぜない。〈本質②: シグナルの粒度がそのまま配信精度〉

3. **フリークエンシーキャップは必ず設定する** — 同一ユーザーへの1日露出は3〜5回が目安。無制限は嫌悪を生み、ブランド毀損につながる。〈本質③: 鮮度ゲームは「適切な回数」も含む〉

4. **新規流入施策とセットで予算配分する** — 動的広告単体で予算を増やしてもCV総量は増えない。Search/SNS/SEOの上流予算とのバランス設計が前提。〈本質④: 母数ゲームの天井を意識〉

5. **コンバージョン計測の上書き問題を見抜く** — 動的広告のCVは「他チャネルで決まっていたCVを横取りしているだけ」のケースが多い。ラストクリック以外（アシスト/データドリブン）でも評価する。〈本質④: 上書きCVの罠〉

6. **商品セット（プロダクトセット）を意図的に作る** — 全商品を1つのセットで撒くのは怠慢。売れ筋／高粗利／在庫過多などの軸で商品セットを切り、別予算で運用する。〈本質①②: フィードの切り出し方とオーディエンスの掛け算で配信を設計〉

7. **画像規定（背景・余白・テキスト量）を商品画像段階で守る** — 後加工では限界がある。商品撮影・EC側の画像運用ルールに介入することが、動的広告運用者の本来の仕事。〈本質①: 弾薬の品質はEC側で決まる〉

## 3. 勝ち筋（再現性のある勝ちパターン）

### 勝ち筋A: 「カート放棄 × 24時間以内 × 高頻度」キャンペーン
- **場面**: ECで売上を1段引き上げたいとき
- **内容**: カート投入後24時間以内に未購入のユーザーに、まさにそのカート商品を高頻度で見せる
- **なぜ勝てるか**: 〈本質②③〉シグナル最強（カート投入は購入意図ほぼ確定）× 鮮度最強（記憶が新しい）の掛け算。動的広告で最もROASが立つゾーン。

### 勝ち筋B: 商品セット「売れ筋 / 在庫過多 / 高粗利」3分割運用
- **内容**: 全商品ではなく、ビジネス目的別に3セットに切り、別キャンペーンで運用
- **なぜ勝てるか**: 〈本質①〉フィードを「ビジネス意図」で再構造化することで、機械学習に「何を売りたいか」を伝えられる。全商品を1つの袋に入れると、機械学習は売れ筋ばかり配信して在庫過多商品は永遠に売れ残る。

### 勝ち筋C: 「閲覧7日以内 × 類似商品レコメンド」での再接触
- **内容**: 閲覧商品そのものではなく、関連商品・上位グレード商品を見せる
- **なぜ勝てるか**: 〈本質②〉ユーザーは「閲覧した商品」を見ても飽きている。同じ価格帯の別商品・上位商品をぶつけることで、検討の幅を広げて再来訪を促す。

### 勝ち筋D: 新規流入キャンペーンと予算連動
- **内容**: Search/SNS新規予算を増やすタイミングに合わせて、動的広告の予算上限も引き上げる
- **なぜ勝てるか**: 〈本質④〉動的広告は新規流入の関数。上流が膨らんだ翌週〜2週後に動的のCVが必ず伸びる。タイミングを合わせるだけでROASが安定する。

### 勝ち筋E: フィード最適化（タイトル・画像）の継続改善
- **内容**: タイトルに「ブランド名 / カテゴリ / 主要属性 / サイズ・色」を含めるルールでフィードを整備。背景白・商品単独の画像に統一
- **なぜ勝てるか**: 〈本質①〉動的広告のクリエイティブは100%フィード由来。フィード改善は、すべての動的広告の底上げになる。「広告運用」ではなく「フィード運用」が成果の源泉。

## 4. 負け筋（典型的な失敗・地雷）

### 負け筋A: 在庫切れ商品の延々配信
- **症状**: クリックは取れるがCV0、CPCだけ消化
- **原因**: 〈本質①〉フィードの在庫ステータスが古い／EC側と同期していない。クリックしても「在庫切れ」表示でユーザーが離脱。
- **回避策**: フィードを最低日次で更新。在庫切れ商品はフィードから自動除外する仕組みをEC側に組む

### 負け筋B: 全ユーザーを1つのオーディエンスで配信
- **症状**: CV数は出ているがCPAが想定より高い／頻度疲労クレーム
- **原因**: 〈本質②〉カート放棄も30日前のTOP訪問も同じ予算で撒いている → 後者にムダ予算が流れる
- **回避策**: 最低でも「カート放棄 / 商品閲覧 / カテゴリ閲覧」の3階層に分割

### 負け筋C: フリークエンシー無制限による嫌悪
- **症状**: ブランドへのSNSクレーム、解除リクエスト増加
- **原因**: 〈本質③〉同一ユーザーへの1日10回以上の露出。鮮度ゲームを「量」で殴った結果、ブランド毀損
- **回避策**: 1日3〜5回キャップ。7日以内でCV/離脱したユーザーは配信停止

### 負け筋D: 動的広告単体でCPAを評価する
- **症状**: 「動的広告だけCPAが良いから予算増やします」→ 増やしても総CV増えない
- **原因**: 〈本質④〉動的広告は上書きCVが多く、単体評価ではROASが過大に見える。母数を変えずに動的だけ増やすと、同じユーザーへの過剰露出になるだけ
- **回避策**: 全体ROAS / アシストCV / 新規CV割合で評価。動的単体ROASは参考値

### 負け筋E: 商品画像が雑（背景がごちゃつき / テキスト埋め込み）
- **症状**: CTRが他媒体より明らかに低い、CV率も低い
- **原因**: 〈本質①〉EC側で運用している商品画像をそのまま使うと、各DSPの審査・表示で破綻する。背景白・余白十分・テキストなしが標準
- **回避策**: 動的広告用の画像規定をEC側に共有し、商品登録段階で守ってもらう

### 負け筋F: 新規流入が枯れているのに動的予算を増やす
- **症状**: 予算は使えるが、CV総数が3ヶ月横ばい
- **原因**: 〈本質④〉母数（新規訪問）が増えていないのに動的だけ膨らませても、同じ池の魚を高頻度で狙うだけ
- **回避策**: 動的予算増額の前に「先月の新規UU数 vs 動的キャンペーンのリーチ数」を必ず比較

## 5. 判断分岐（迷ったときの基準）

| 状況 | 取るべきアクション | 紐づく本質 |
|---|---|---|
| CV数頭打ち | 上流（新規流入）を疑う | ④母数の天井 |
| CTR低い | フィード（画像・タイトル）を疑う | ①弾薬の品質 |
| CV率低い | 在庫切れ・価格ズレを疑う | ①フィード鮮度 |
| ROAS悪化 | オーディエンス階層を再分割 | ②シグナル粒度 |
| 頻度疲労クレーム発生 | フリークエンシーキャップ即修正 | ③鮮度の適量 |
| 動的だけCPAが異常に良い | 上書きCV比率を確認 | ④評価軸の歪み |
| 新商品が売れない | 商品セット分割（売れ筋と分離） | ①②セット設計 |
| 季節商品の在庫過多 | 在庫過多セットに切り出し予算配分 | ①フィードの再構造化 |
