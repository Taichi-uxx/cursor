# Shopping広告 — 鉄則・勝ち筋・負け筋

## 1. このドメインの本質

Shopping広告は **「商品データフィードがそのまま広告クリエイティブになる広告」**。
Search広告と違って、運用者はキーワードも広告文も書かない。代わりに **Merchant Center に登録した商品データ（タイトル・画像・価格・在庫・GTIN等）が、Googleの判断で検索結果に商品カードとして表示される**。だから運用の中心は「入札・KW・広告文」ではなく **「フィードの整備」と「商品データそのものの最適化」**。広告のクリエイティブを磨くのではなく、**商品データを磨く**ことが本業。

この本質を分解すると、Shopping広告は4つの構造ゲームの重ね合わせで成立している。

### 本質① 商品データ = 広告そのものゲーム
Shopping広告のクリエイティブは100%商品データ。**タイトル / 画像 / 価格 / 商品説明 がそのまま広告に出る**。
広告運用者の仕事はキーワードを書くことではなく、「商品タイトルに何を入れるか」「画像を何にするか」を決めること。タイトルに「ブランド名 / 商品カテゴリ / 主要属性 / サイズ・色」が含まれていないと、Googleがどの検索クエリにマッチさせていいか分からず、配信機会を逃す。**広告運用の本丸は商品マスター運用**。

### 本質② Merchant Center審査 = 配信権ゲーム
Shopping広告は **Merchant Centerで商品が承認されていないと1秒も配信されない**。価格不一致／在庫切れ／GTINミス／画像規定違反／商標違反など、不承認理由は多岐にわたる。
不承認商品は広告だけでなく無料リスティングからも消える。**「フィードを入稿しました」で終わらず、毎週ステータスを確認し不承認を解消することが運用業務の中核**。承認されていない商品は存在しないも同然。

### 本質③ 価格・在庫 = 構造勝負ゲーム
Shopping広告は **同じ検索クエリで複数店舗の商品カードが並んで表示される**。ユーザーは価格・送料・レビューを横並びで比較するため、運用者が広告で頑張っても **価格が競合より20%高ければクリックすらされない**。
逆に言えば「商品力（価格・在庫・送料・レビュー）」がそのまま広告成果になる。広告運用部門が触れない領域だが、ここを商品部・EC部と連携して改善できるかが、Shopping広告で勝てるかの分水嶺。

### 本質④ キャンペーン構造 = 入札解像度ゲーム
Shopping広告にはキーワード設定がない代わりに、**「商品グループ」と「入札（または目標ROAS）」で配信精度を作る**。1キャンペーンに全商品を入れて1つの目標ROASで動かすと、高ROAS商品ばかり配信され、平均的な商品は機会損失。
マージン / カテゴリ / 価格帯 / 在庫状況などの軸で商品グループを切り、それぞれに別の入札目標を当てるのが運用の主戦場。**「商品マスターをどう束ねるか」が入札設計**。

## 2. 鉄則（破ってはいけない）

> 表記凡例: 各項目末尾の **〈本質①〜④〉** は、その鉄則がどの本質に紐づくかを示す。

1. **商品タイトルに「ブランド / カテゴリ / 主要属性 / サイズ・色」を必ず入れる** — タイトルがクエリマッチの主要シグナル。情報不足だと表示機会を逃す。〈本質①: タイトルが広告本体〉

2. **Merchant Centerの不承認を週次でゼロにする** — 不承認商品は配信されない。放置するほどアカウント全体の信頼性も下がる。〈本質②: 配信権がない商品は無いも同然〉

3. **商品データフィードは最低日次で更新** — 価格・在庫の不一致は不承認の最大要因。EC側との自動連携を組む。〈本質②③〉

4. **キャンペーンはマージン・価格帯で分割する** — 1キャンペーン全商品入れは怠慢。最低でも売れ筋／一般／在庫処分の3分割。〈本質④: 入札解像度〉

5. **GTIN（JANコード）は必須項目** — GTIN欠損商品はインプレッションが大幅に落ちる。新商品でも仮GTINでも入力する。〈本質①②〉

6. **競合価格を月次でモニタリング** — 自社価格が競合より明らかに高ければ広告改善で勝てない。商品部と価格戦略を相談する。〈本質③〉

7. **商品レビューを必ず収集・連携する** — 商品評価（★）が広告カードに表示されると、CTRが体感1.3倍。Google Customer Reviewsや外部レビューサービスの連携を組む。〈本質③〉

## 3. 勝ち筋（再現性のある勝ちパターン）

### 勝ち筋A: マージン軸キャンペーン3分割
- **場面**: 商品数が50点以上あるECサイト
- **内容**: 売れ筋（高ROAS狙い）／一般商品（中ROAS狙い）／在庫過多（薄利覚悟で消化）の3キャンペーン
- **なぜ勝てるか**: 〈本質④〉商品ごとに最適な入札目標が違う。分割すれば、それぞれの目標で機械学習が最適化される。

### 勝ち筋B: タイトル最適化（属性網羅）
- **内容**: 「ブランド名 + カテゴリ + 主要属性（素材/サイズ/色等） + 用途キーワード」のフォーマットで全商品タイトルをリライト
- **なぜ勝てるか**: 〈本質①〉タイトルがクエリマッチの最大シグナル。属性網羅すれば、ロングテールクエリでの表示機会が増える。

### 勝ち筋C: Merchant Center不承認の即時解消フロー
- **内容**: 毎週月曜に不承認商品を抽出 → 原因別（価格不一致 / 画像 / GTIN）に担当割り → 当週中に解消
- **なぜ勝てるか**: 〈本質②〉不承認商品はその間ゼロ表示。週単位で潰せば、機会損失が最小化される。

### 勝ち筋D: 商品レビュー連携で★表示
- **内容**: Google Customer Reviews / Yotpo / 楽天レビュー連携で、商品カードに★評価を表示
- **なぜ勝てるか**: 〈本質③〉同じ商品が並んだ時、★ありとなしではCTRが1.2〜1.5倍違う。広告枠の競争で勝つ。

### 勝ち筋E: ネガティブKW + 商品グループ除外で純度確保
- **内容**: Shopping広告でもネガティブKWは効く。「無料」「中古」「使い方」などを除外
- **なぜ勝てるか**: 〈本質②④〉Shopping広告は自動マッチなので、意図しないクエリにも表示されがち。除外で純度を上げると、入札効率が劇的に改善。

## 4. 負け筋（典型的な失敗・地雷）

### 負け筋A: フィード入稿しっぱなしの放置運用
- **症状**: 表示回数が3ヶ月間徐々に減少
- **原因**: 〈本質②〉不承認商品が累積、価格不一致が増え、Merchant Center全体の信頼性スコアが下がる
- **回避策**: 毎週フィードステータス確認、不承認解消を運用フローに組み込む

### 負け筋B: 1キャンペーン全商品まとめ
- **症状**: 平均ROASは目標到達も、特定商品にしか配信されていない
- **原因**: 〈本質④〉1つのtROASだと高ROAS商品に予算が寄る。中位・低位商品は配信されない
- **回避策**: マージン・カテゴリで最低3分割。tROAS目標を変える

### 負け筋C: タイトルが「商品名」だけ
- **症状**: ロングテールクエリで表示されない、CTR低い
- **原因**: 〈本質①〉タイトルに属性情報がなく、Googleがクエリマッチを判定できない
- **回避策**: 全商品タイトルをフォーマット化（ブランド+カテゴリ+属性+用途）

### 負け筋D: 競合より価格が20%高いまま広告改善を試みる
- **症状**: いくら入札上げてもCV取れない、CPCだけ消化
- **原因**: 〈本質③〉Shopping広告は横並び比較構造。価格差は広告で覆せない
- **回避策**: まず商品部と価格戦略を協議。広告改善は2番目

### 負け筋E: GTIN未入力商品の放置
- **症状**: 新商品の表示回数が異常に低い
- **原因**: 〈本質①②〉GTIN欠損商品はGoogleが商品の信頼性を疑い、表示頻度を絞る
- **回避策**: 新商品登録時にGTIN（または仮GTIN）必須項目化

### 負け筋F: 商品レビュー連携の未実装
- **症状**: 競合商品カードに★が表示されている中、自社だけ無印
- **原因**: 〈本質③〉レビュー連携の手間を後回しにした結果
- **回避策**: Google Customer Reviewsは無料、他レビューサービスも連携対応多い。優先導入

## 5. 判断分岐（迷ったときの基準）

| 状況 | 取るべきアクション | 紐づく本質 |
|---|---|---|
| 表示回数が減少 | 不承認・価格不一致を疑う | ②配信権 |
| CTR低い | タイトル・画像・★レビューを点検 | ①③ |
| ROAS低いがCV数は出る | キャンペーン分割で目標差をつける | ④入札解像度 |
| 特定商品のみ配信される | 商品グループ・予算の偏りを点検 | ④ |
| CPA高いが価格は妥当 | ネガティブKW追加で純度向上 | ②④ |
| 新商品の表示低い | GTIN・属性情報の登録を確認 | ①②商品データ |
| 競合より価格が高い | 広告改善より商品部と価格戦略相談 | ③構造勝負 |
| 不承認が多発 | 入稿フォーマット・価格同期を見直し | ②配信権 |
