# エモーションリレー × LP逆算コピー — 鉄則・勝ち筋・負け筋

## 1. このドメインの本質

LP逆算コピーは **「LPに埋め込まれた"感情の設計図"を逆さに読み、その入口（リレーの第1走者）に見込み客を立たせる広告を作る技術」**。
普通のコピーは商品起点で「何を言うか」を考える。LP逆算は着地点起点で「**このLPは、どんな課題・悩み・インサイトを抱えた人が／どんな感情の順序で／何に納得して買う設計か**」を逆読みし、その起点感情を広告で点火する。
ベースにあるのは木下勝寿氏（北の達人コーポレーション）の **エモーションリレー** ──「各パーツの仕事は商品を売ることではなく"次を読ませること"。感情のバトンが途中で落ちた瞬間に離脱する」──という考え方を、**広告とLPの境界をまたいで**適用する発想。

この本質を分解すると、LP逆算コピーは4つの構造ゲームの重ね合わせで成立している。

### 本質① 感情はリレーである（一発勝負ではなく連鎖）
読み手の感情は静止していない。1行読むごとに「不安 → 共感 → 興味 → 疑念 → 納得 → 欲求 → 決断」と変化していく。広告/LPの各パーツの仕事は「商品を売ること」ではなく、**「読み手を今の感情から次の感情へ1歩運び、次の1行を読ませること」だけ**。だから個々のコピーの良し悪しは「単体で上手いか」ではなく「**前の感情を正しく受け取り、次の感情へ正しく渡せているか**」で決まる。リレーは1区間でもバトンを落とせば負ける競技で、**最も弱いバトンパスが全体のCVRを決める**（＝直列構造で最弱が天井を決める）。

### 本質② 広告とLPの「継ぎ目」がバトン落下の最大ポイント
リレーは広告内・LP内だけで起きるのではない。**広告→LPの遷移そのものが、最も観測されにくく最も漏れる1区間**。広告で「不安・焦り」の感情を起こしたのに、LPのファーストビューが「明るい商品自慢」から始まっていれば、その瞬間に感情の連続性が切れ、読者は「思っていたのと違う」と無言で離脱する。CVRの最大の漏れは広告単体でもLP単体でもなく、しばしば**両者の継ぎ目**にある。LP逆算コピーの存在理由はここ──広告の出来栄えではなく「**LPのFVが期待している"流入時の感情"に着地させること**」が仕事。

### 本質③ 良いLPは「逆向きに読める設計図」である
売れているLPには、作者が意図したか否かに関わらず「**誰が・どんな感情の順序で・何に納得して・何で背中を押されて買うか**」が構造として埋まっている。FV＝起点感情の定義、共感パート＝読者の現状の言語化、ベネフィット＝欲求の点火、証拠＝疑念の解消、オファー/CTA＝決断の後押し。これを順向き（商品→訴求）ではなく**逆向き（着地点→起点）に読む**と、「このLPは"誰の・どんな感情"を入口に設計されているか」が抽出できる。コピーの起点は商品スペックではなく、この**逆抽出された起点インサイト**。ただし設計図が壊れているLP（古い/作り込み不足）から逆算すれば、壊れた起点しか出てこない。

### 本質④ 起点インサイトの「解像度」が点火力を決める
広告の役割は「LPの第1走者の手前に立つ見込み客の感情に火を点ける」こと。点くか点かないかは**起点インサイトの解像度**で決まる。「美容に悩む人」では火は点かない。「鏡を見るたびファンデで隠して、夜に落とすとき小さな罪悪感がよぎる人」まで解像度が上がって初めて「**これは私の話だ**」という感情が起動する。LP逆算の最大の価値は、この解像度の高い起点を**書き手の想像ではなく"完成したLP"という検証済みの実物から逆算で得られる**点にある。想像で書く通常コピーより、起点の確からしさが構造的に高い。

## 2. 鉄則（破ってはいけない）

> 表記凡例: 各項目末尾の **〈本質①〜④〉** は、その鉄則がどの本質に紐づくかを示す。

1. **コピーを書く前に「このLPは誰の・どの瞬間の・どの感情を入口に設計されているか」を1文で逆抽出する** — 起点を定義せずに書いたコピーは、結局"商品起点"に戻ってしまいLP逆算の意味が消える。〈本質③④: 起点インサイトの逆抽出がこの手法の出発点そのもの〉

2. **広告の読後感情 ＝ LPのFVが期待する流入時感情、を必ず一致させる** — 広告とLPを別々の成果物として評価した瞬間、最大の漏れ（継ぎ目）が見えなくなる。〈本質②: バトン落下の最大ポイントは継ぎ目にある〉

3. **広告のゴールはCVではなく「LPの第1走者にバトンを渡すこと」と心得る** — 広告だけで売り切ろうとすると感情を詰め込みすぎ、リレーが破綻する。〈本質①: 1パーツの仕事は"次を読ませること"だけ〉

4. **起点インサイトは抽象語で書かない。行動描写レベルまで解像度を上げる** — 「節約したい人」では脳内に映像が立たず、火が点かない。〈本質④: 解像度が点火力を直接決める〉

5. **LPの感情リレーに"断絶"があっても、広告コピーで穴埋めしようとしない** — LP本体の修正は⑨LP Architectの担当領域。断絶を広告で糊付けしても根本解決にならず、無理に背負うとコピーが破綻する。広告は"成立している区間"に向けて設計する。〈本質①②: 最弱のバトンパスはLP側でしか直せず、コピーが代替できない〉

6. **感情の順序（階段）を飛ばさない** — 共感を飛ばしていきなり欲求・決断に行くと、バトンが宙に浮いて「煽り」と警戒される。〈本質①: リレーは1区間ずつしか運べない〉

7. **LPが古い／作り込み不足のときは、逆抽出した設計図をそのまま信じない** — 壊れた設計図から逆算すると、起点も壊れる。先に"あるべきリレー"を再設計してから逆算する。〈本質③: 逆読みできるのは設計が成立しているLPだけ〉

## 3. 勝ち筋（再現性のある勝ちパターン）

### 勝ち筋A: 「LP-FV感情への意図的接続」設計
- **場面**: 既存LPを使う運用案件（LP差し替え不可のケースが多い実務で最頻出）
- **内容**: 広告ラストの読後感情を、LPファーストビューの第一感情に意図的に重ねて着地させる
- **なぜ勝てるか**: 〈本質②〉CVR改善余地が最も大きいのは広告でもLPでもなく"継ぎ目"。ここの段差を消すだけで、広告・LPに一切手を入れずCVRが動く。多くの運用者が見ていない一区間を独占できる。

### 勝ち筋B: 「共感パート逆輸入」フック
- **場面**: 共感ブロックが作り込まれた高品質LP
- **内容**: LPの共感パートで最も解像度が高い"悩みの一文"を、そのまま広告のフックに前倒しする
- **なぜ勝てるか**: 〈本質③④〉そのLPで既にCVに繋がっている＝検証済みの「刺さる言語化」を入口に持ってこられる。ゼロから刺さるフックを当てる賭けではなく、勝ち筋の前倒し。

### 勝ち筋C: 「感情リレー・マッピング」のワークシート化
- **場面**: 起点が掴めない／チームで再現したいとき
- **内容**: LPを6ブロック（FV/共感/ベネフィット/証拠/オファー/CTA）に分解し、各ブロックの「入感情 → 出感情」を表に起こす
- **なぜ勝てるか**: 〈本質①〉感情の断絶箇所が物理的に可視化され、「広告がどの感情を作って渡せばいいか」が議論ではなく構造で確定する。属人性が消え、レビューもしやすくなる。

### 勝ち筋D: 「起点インサイトの3階層化」
- **内容**: 起点を ①表層課題（本人が言える） ②深層悩み（言えるが言いたくない） ③インサイト（本人も言語化できていない本音） の3層で抽出し、広告は②〜③層を突く
- **なぜ勝てるか**: 〈本質④〉表層課題は競合も全員叩いている。深層・インサイト層は解像度が深く、そこに触れた瞬間「なぜ私のことを知ってるのか」という最強の自分ごと化が起動する。解像度の深さ＝そのまま差別化。

## 4. 負け筋（典型的な失敗・地雷）

### 負け筋A: 広告とLPを別々に評価する
- **症状**: 広告のCTRは高いのにLP直帰率が異常に高い／CVが出ない
- **原因**: 〈本質②〉広告とLPを独立した成果物として点検しているため、最大の漏れである"継ぎ目の感情段差"が誰の視界にも入っていない
- **回避策**: 広告コピー → LP-FVを1つの文章として連続音読し、感情が途切れる箇所を物理的に探す

### 負け筋B: LPの表面コピーをそのまま広告に転記
- **症状**: 既視感が強くCTRが低い／"良いことは言っているのに反応がない"
- **原因**: 〈本質③④〉LP本文の結論的コピーは"納得した後"の読者に向けた言葉。まだ点火されていない広告の読者には文脈が無く響かない
- **回避策**: LPは「文言の流用元」ではなく「感情の順序を逆抽出する対象」。抜くのは結論ではなく"起点"

### 負け筋C: 出来の悪いLPを鵜呑みに逆算
- **症状**: 逆算した起点が的外れで、何案出しても刺さらない
- **原因**: 〈本質③〉設計が崩れたLPから逆算しても、崩れた起点しか出てこない（壊れた地図で逆走している）
- **回避策**: 逆算前にLP品質を診断。低品質なら"あるべきリレー"を先に再設計してから起点を取る

### 負け筋D: 感情の階段を飛ばす
- **症状**: 「煽り広告」と警戒される／クリックされてもCVに繋がらない
- **原因**: 〈本質①〉共感を飛ばしていきなり欲求・決断に誘導すると、受け取る感情の土台がなくバトンが宙に浮く
- **回避策**: 広告が担うのは原則"起点点火 → 共感への橋"の1〜2区間まで。納得・証拠・決断はLPに委ねる

### 負け筋E: 起点インサイトが抽象のまま
- **症状**: コピーがどれも教科書的で、誰の心も動かさない
- **原因**: 〈本質④〉「節約したい人」「健康に気を遣う人」では脳内に映像が立たず、点火しない
- **回避策**: 起点の解像度供給源をLPの共感パートに置く。本人の行動・つぶやきレベルまで具体化してから書き始める

### 負け筋F: 全部の感情を広告に詰め込む
- **症状**: 広告コピーが長くなり、結局何も伝わらない
- **原因**: 〈本質①②〉広告の仕事はリレー全区間ではなく"第1走者にバトンを渡す"1区間だけ。全部背負うとパスが雑になり継ぎ目で落ちる
- **回避策**: 広告は起点点火に絞る。証拠・実績・スペックはLPの担当区間と割り切る

## 5. 判断分岐（迷ったときの基準）

| 状況 | 取るべきアクション | 紐づく本質 |
|---|---|---|
| 広告CTR高・LP直帰高 | 広告ラスト感情とLP-FV感情の段差を疑う | ② 継ぎ目で落ちている |
| 既存LPが高品質 | 共感パートから起点を逆抽出しフック化 | ③④ 検証済みの言語化を前倒し |
| 既存LPが古い/低品質 | 逆算前にあるべきリレーを再設計 | ③ 壊れた設計図は信じない |
| 起点が「〜したい人」で止まる | 行動描写レベルまで解像度を下げる | ④ 抽象では点火しない |
| 広告コピーが長くなってきた | 担う感情区間を1つに絞る（起点点火のみ） | ① 1区間ずつしか運べない |
| LPが複数ある | LPごとに起点が違う前提で別コピー | ③④ 設計図はLPごとに異なる |
| LP内に感情の断絶を発見 | 広告で埋めず、LP修正は⑨LP Architectに委ねる | ②① コピーで継ぎ目は直せない |
| 感情の順序が掴めない | 6ブロック分解で入感情/出感情をマッピング | ① 断絶を構造で可視化 |
