# LP方法論：FV設計とLP構成の本質

> **用途**：LP関連スキル（lp-build / banner-ad-build / copy-build / lp-inspiration-scout 等）が読み込むための共通方法論ドキュメント。
> **出典**：`work/knowledge/クリエイティブ/LP/CVをとるLP.md` を方法論として再構成。

---

## 0. 根本思想（すべての判断の土台）

### 0.1 LPの成否は「リサーチと設計」で8割決まる
- **失敗するLP＝商品のことだけ考えて作ったLP**。
- LP制作に入る前に必ず以下を押さえる：
  - ターゲットが商品にどんな**一般的な常識・印象**を抱いているか（裏切ることが鉄板の打ち出し）
  - なぜ買ったのか／何に不満・不安があるのか／どんな条件なら買うのか

### 0.2 ユーザーは「不特定多数」ではなく「人間」
- ユーザーもバカではない：広告を広告と認識し、「満足度○％」を疑い、最良の商品を求める。
- 人は**感情で買い、理論で正当化**する。
- 人は常に**損失を回避**したい（保証・返金が効く理由）。
- 読む人は商品を信じていないし、買うモチベーションも高くなく、いつでも離脱できる状態にいる。

### 0.3 ベネフィットと結果を分けて考える
- **結果**：商品を使うとどうなるか（例：髪が綺麗になる）
- **ベネフィット**：使うと自分にどう影響・変化するか（例：寝起きの髪で出かけられる）
- **ベネフィットは常に「結果の奥の奥」にある**。先にベネフィットで未来を想像させ、結果で現実的に裏付ける。

## 1. FV（ファーストビュー）の設計

### 1.1 FVの絶対要件
- **3秒以内**に「これだ」と思わせる。
- 成果が上がらないLPはほとんどFVだけ見て離脱されている。
- FVに最低限含める要素：**キャッチコピー / 結果（KV内に入れてよい） / ビジュアル / CTA**。

### 1.2 キャッチコピー作成手順（連想ゲーム法）
1. **商品の特徴を挙げる**
2. **「だから何？」を繰り返す**
3. **人の関心の中に入るまで連想を続ける**
4. **ベネフィットリストを作成**（複数挙げて並べる。業界外・顧客の声を取り入れる）
5. **8つの根源的欲求のどれを刺激するかを確認**
6. **キャッチコピーに落とす**

#### ベネフィットリストの作り方
- ベネフィット＝「ユーザーが商品を購入したときに得られる**変化**」。
- **業界内では当たり前すぎて気づかない**強みが多いので、業界外の人・顧客にヒアリングする。

### 1.3 8つの根源的欲求（これに訴求すると強い）
1. 生き残り、人生を楽しみ、長生きしたい
2. 食べ物・飲み物を味わいたい
3. 性的に交わりたい
4. 他人に勝り、世の中に遅れをとりたくない
5. 愛する人を気遣い、守りたい
6. 恐怖、痛み、危険を免れたい
7. 快適に暮らしたい
8. 社会的に認められたい

> 強い欲求ではあるが根源には敵わないもの：情報欲・清潔欲・利便性・美と流行・掘り出し物・好奇心・能率・信頼性・節約。これらは補助として使う。

### 1.4 ベネフィット型 vs USP型 の使い分け
| 型 | 向き | 例 |
|---|---|---|
| **ベネフィット型** | ライフスタイル・情緒的訴求 | AMEX：ライフスタイル・スタイリッシュさ |
| **USP型** | 機能・スペック訴求 | 楽天カード：ポイント○倍、年会費無料 |

判断軸：**商材／強み／広告媒体／キーワード**。機能を打ち出したいならUSP型、ベネフィットが弱い商品もUSP型。

### 1.5 キャッチコピーの悪い例
- ❌ **商品中心**：「フレームもレンズも薄い！東京大学教授監修の老眼鏡が登場！」
- ❌ **聞こえの良さ重視**：「こんなメガネ、探してました」

### 1.6 良いキャッチコピーのコツ
- **一瞬で「自分に必要だ」と思ってもらう**
- **使うとどうなるか、結論を先に言う**
- **自分に関係があると思わせる**

### 1.7 FVセルフチェック項目
- [ ] 人の**根源的欲求**に訴求できているか？
- [ ] **他商品・一般常識との違い**は伝わるか？
- [ ] **流入元（媒体・キーワード）とユーザーが求めるもの**とマッチしているか？
- [ ] 商品中心になっていないか（ユーザーの変化が主語か）？
- [ ] 結論（結果）が先にあるか？

## 2. LPの鉄板構成（8パート）

> 「喚起→結果→証拠→共鳴→信頼→ストーリー→クロージング→PS」。
> 上から順に「興味→納得→信用→欲求→決断」へとユーザーの心理状態を遷移させる。

| # | パート | 目的 | キーメッセージ |
|---|---|---|---|
| 1 | **喚起** | 3秒で掴む | 「あなたはこう変化します」 |
| 2 | **結果** | 具体的な結果を提示 | 「使うと実際こうなります」 |
| 3 | **証拠** | 主張を裏付ける | 「なぜならこうだからです」 |
| 4 | **共鳴** | 「私のことだ」と感じさせる | 「あなたに似た人も変化しています」 |
| 5 | **信頼** | 第三者権威で補強 | 「あの人もこう言っています」 |
| 6 | **ストーリー** | 感情を動かす | 「私たちはこういう想いで作っています」 |
| 7 | **クロージング** | 今すぐ買う理由 | 「今買うべき理由はこれです」 |
| 8 | **P.S.** | 最後のひと押し | 「追伸、もう一つだけ」 |

### 2.1 喚起パート
- 速攻で心をつかむキャッチコピー（→ §1）。

### 2.2 結果パート
- ベネフィットで未来を想像させた後、**現実的にどう結果が出るか**を見せる。
- 結果は**KV内に含めても構わない**。

### 2.3 証拠パート — 効果的な5種
1. 数値的根拠
2. 客観的事実（公的機関データ等）
3. 科学的・医学的根拠
4. 特許
5. 動画やデモンストレーション（操作性／使用感／ビフォーアフター）

> 押し付けがましさを避け、**客観的に見せる**ことが重要。

### 2.4 共鳴パート（BtoBでは事例）
- **「体験」と「属性」の2軸**でユーザーに「私のことだ」と思わせる。
- BtoBや工事系などレビュー獲得が難しい場合：2ショット写真／数値ビフォーアフター／酒席ぶっちゃけトークなど工夫する。

#### お客様の声の強度ランキング
| 順位 | 形式 | 信憑性 |
|---|---|---|
| 1位 | 実名＋動画（テロップ＋下に文字起こし＋写真） | 最強 |
| 2位 | 実名＋写真 | 強 |
| 3位 | 仮名＋写真 | 中（ここから落ちる） |
| 4位 | 写真なし＋直筆アンケート | 弱 |
| 5位 | 写真素材＋テキスト | ❌信用されない／全体が嘘くさくなる |

#### アンケート取得時のポイント
- 最初は**Yes/No・○×形式**で答えやすく（一貫性の原理）
- 文字数制限・回答例を提示
- **「購入前の悩み／購入後の変化／同じ悩みを持つ人へのメッセージ」**の3点を必ず聞く
- Amazonレビュー形式は最強（**デメリットも明示**して損失回避バイアスを軽減）

### 2.5 信頼パート — 棲み分け
- **証拠＝あなたの主張** / **共鳴＝使用者の主張** / **信頼＝第三者権威の意見**
- 例：テレビ・新聞・ラジオ／有名人出演／権威者推薦／第三者認定／受賞歴・設立年数／取引先企業
- 注意：**ターゲットの変化・関心に関係あるもの**だけに絞る。

### 2.6 ストーリーパート
- 商品誕生秘話・経営への情熱・販売にかける想い。
- 書き方：
  - 明確に存在する人物・商品の話である
  - ごく個人的に書く
  - 誰かに話しかけるように書く
  - **失敗談と乗り越えた挑戦**を入れる
  - 良いことも悪いことも話す
- **必ず最後に「買ってもらいたい」と明確に意思表示する**。

### 2.7 クロージングパート — 「今買う理由」4要素
1. **返金・返品保証**
2. **期間限定オファー**
3. **速さの訴求**（今すぐ悩みが解決できる）
4. **特典**

> これらを組み合わせて他社に負けないオファーを作る。

### 2.8 P.S.パート
- 最下部をCTAで終えると「読了感」で満足してしまう。**最後の一言**で背中を押す。
- 例：「追伸、このオファーは本当に今月で終了します」「絶対に後悔させません」「自信があるから返金保証に踏み切りました」。

## 3. 構成が鉄板にハマらないとき：32パーツから8つ選ぶ

> 10,000px以内に収まるよう、以下から**8つ**選んで「選択と集中」する。

- メリット紹介 / スペック紹介 / 具体的サービス内容 / 会社概要・地図（外部リンク禁止）
- ギャップ（認知的不協和） / 代弁（パート繋ぎに） / よくあるお悩み（共感＋解決イメージ）
- 煽り / ベネフィットのビフォーアフター / 事実のビフォーアフター
- 導入事例 / 選ばれる理由 / **ノウハウ紹介**（BtoB・知的労働で強い／一部見せる）
- 他社比較 / メディア掲載 / パートナー企業紹介 / 著名人の関わり
- お客様の声 / お客様属性（円・棒グラフ） / 驚き（「へーそうだったんだ」）
- ご利用の流れ / スタッフ紹介（BtoB「ちゃんとした会社」印象） / 特典・返金・キャンペーン
- No.1訴求 / 第三者推薦 / よくある質問 / **利用シーン想定**（BtoBソフトは画面動画）
- 理念・価値観・代表挨拶・ストーリー

## 4. LPの評価基準（4つの問い）

### 評価1：一番伝えたいことは伝わっているか
- **大事なことは言い方を変えて3回**繰り返す。
- 例：「クセ毛が治る」を伝える場合
  - キャッチコピー：「寝起きの髪でお出かけできちゃう」
  - お客様の声：「長年クセ毛で悩まされていたのが嘘のよう」
  - 追伸：「私も20年間クセ毛で悩んでいました」
- 各パートで使うことで訴求のブレを防ぐ。

### 評価2：行動を促す要素が入っているか
- ベネフィットがリアルに想像できるか？
- クロージングオファーは魅力的か？
- 商品使用後・導入後が具体的にイメージできるか？

### 評価3：他社より優れていると思わせているか
- 他社比較・USP・実績・事例・ビフォーアフター

### 評価4：新しい驚きがあるか
- 元々持っていた商品イメージとの違いが提示されているか？

## 5. UI/UX上の運用ルール

### 5.1 購入ボタンの配置
- **上中下の3箇所**に設置、または**フローティングボタン**で追尾。
- フローティング注意点：**直接的な購入ボタンは追尾NG**（「今買うわけじゃない」と離脱を誘発）。資料請求・無料体験など軽いCTAなら可。

### 5.2 メールフォーム最適化チェックリスト
- [ ] フォーム上にメッセージあり
- [ ] フォームページに**他リンクがない**
- [ ] 入力項目は極限まで少なく
- [ ] ひらがな/漢字/大小/ハイフン指定なし
- [ ] 入力例あり
- [ ] 入力ボックスは大きく・角丸
- [ ] 送信ボタン大きく
- [ ] 個人情報保護表記あり
- [ ] 入力ミス箇所を明示
- [ ] 「入力→確認→完了」の現在地表示
- [ ] スマホで最適キーボード（電話番号は数字入力）
- [ ] 最初の項目はチェックボックス/ラジオで入力ハードルを下げる
- [ ] フォーム上下にオファー・PS的テキストを添える
- 離脱率分析：**GA「目標到達プロセス」**で確認。

### 5.3 サイト型LPの作り方
- TOPに8コンテンツを集約。
- **1パートで全てを伝え切らなくてOK**。サマリーだけ見せて下層で詳細を紹介。
- 上部にグローバルナビを設置。

### 5.4 縦型 vs サイト型
| 観点 | 縦型LP | サイト型LP |
|---|---|---|
| 訴求対象 | 顕在ユーザー | 顕在ユーザー |
| 構築スピード | 速い | 遅い |
| お金になるまで | 最速 | 時間がかかる |
| SEO | × | ○ |
| 説明量が多い商品 | △ | ◎ |
| 信頼性重視商品 | △ | ◎ |
| テスト | しやすい | しにくい |
| 流入 | 広告中心 | 広告＋SEO＋ソーシャル |

> 縦型LPは**潜在ニーズの中でも根源的欲求**（ダイエット・健康・効率化・薄毛・モテ・お金・出世）に強い。

## 6. リサーチ・3C・ペルソナ（FV/構成設計の前段）

### 6.1 ターゲットニーズリサーチ
- 直接聞く／検索ツール／ネット調査／調査会社の4手段。
- 把握すべき4点：商品への印象・買った理由・不満や不安・買う条件。
- **顧客が抱く「商品の常識」を裏切るのがLPの鉄板**。

### 6.2 検索ツール活用
- **サジェスト**を見る（最短）→ **検索結果上位TOP10**を見る（ニーズと求められるコンテンツが分かる）。
- Amazon書籍上位タイトル＆レビュー／口コミサイト／Yahoo!リアルタイム検索／Googleキーワードプランナー／Googleトレンド／Search Console。

### 6.3 3C分析
- **市場（Customer）**：マクロ（PEST）＋ミクロ（5Force）。顧客分析は「過去と現在の顧客変化」。
- **競合（Competitor）**：ビジネス結果＋結果を出せた理由。
  - 競合チェックシート：縦軸＝競合／横軸＝施策（送料無料、メルマガ限定、無料分析、デモ等）／スペック（売上・粗利・上場・投資フェーズ等）。
  - **競合サービスを買ってみる・メルマガ取得**は必須。
- **自社（Company）・商品**：市場と競合との比較から空きポジションを見出す。

### 6.4 ペルソナ
- **内面的要素**が最重要：「何に悩み」「どうなりたく」「いつ、何で検索したか」。
- これらを元にセールスの方向性・広告コピーを設計する。

## 7. 集客とLPの連携（参考）

- **リスティング**：品質スコアの「LP利便性」は**LPが全画像だと不利**（関連テキストが必要）。滞在時間・離脱率も影響。
- **ディスプレイ**：衝動買い商品・無料オファー・スマホゲームが向く。
- **SNS**：購入動機が低い → フロントエンド商品や低ハードルCV設計。
- **アフィリエイト**：完全成果報酬だがブランディング毀損リスクあり。

## 8. LP運用：効果を伸ばし続ける

### 8.1 ABテスト
- **最も影響が大きいのは「キャッチコピー」と「オファー」**。
- 成果の出ないLPはFVで離脱されている／オファーが魅力的でないことがほとんど。

### 8.2 LP量産
- **キーワード・媒体（Google/Facebook/Twitter等）に応じてLPを使い分ける**のが推奨。

### 8.3 メルマガでの温度上昇
- **プレゼント（取得フック）＋おまけ（好感醸成）**を組み合わせる。
- 連日プレゼント送付→最後にキャンペーン案内が王道シーケンス。

## 9. LP制作で押さえる本質ポイント（チェックリスト）

- [ ] 相手の**変化・メリット**にフォーカスしているか（商品中心でないか）
- [ ] 読者は商品も書いてあることも**信じていない**前提か
- [ ] 買うモチベーションが**そもそも高くない**前提か
- [ ] **感情で買い、理論で正当化する**設計になっているか
- [ ] 読者は**いつでも離脱できる**前提で各セクションが「次を読ませる」設計になっているか
- [ ] **保証・特典**でリスクを取り除いているか
- [ ] **「お客さんのことをとにかく考える」**が貫かれているか

## 10. LPスキル向け：実装時の判断ガイド

### 10.1 FV生成時の必須要素
1. **キャッチコピー**（ベネフィット型 or USP型を商材で選択）
2. **結果（KV内に内包可）**
3. **ビジュアル**（ターゲット属性に近い人物・利用シーン）
4. **CTA**（強さは商材／流入媒体で調整）
5. **流入元との一貫性**（広告コピー・KWとFVがマッチ）

### 10.2 構成設計時の判断フロー
```
1. 商品の特性を確認
   ├─ 説明量が多い／信頼が重要 → サイト型LPを検討
   └─ 顕在ニーズ・根源欲求 → 縦型LPで鉄板構成
2. 鉄板構成（喚起→結果→証拠→共鳴→信頼→ストーリー→クロージング→PS）に当てはめる
3. ハマらない場合は32パーツから8つを選ぶ（10000px以内）
4. 評価4軸でセルフチェック
```

### 10.3 「これはやらない」リスト（アンチパターン）
- 商品スペック中心のFVキャッチコピー
- 写真素材＋テキストの「お客様の声」（信用が崩壊する）
- 直接購入ボタンの常時フローティング追尾
- 会社概要から外部サイトへのリンク
- CTAで終えてP.S.を入れない
- 全てを1パートで伝え切ろうとする（サイト型LP）
- 「満足度○％」だけの空虚な訴求

---

> **本質**：LPは「商品を説明する場」ではなく、「**人間の感情を動かして行動を変える場**」。
> リサーチで相手を理解し、FVで掴み、構成で納得させ、オファーで決断させる。
