# ランディングページ — 鉄則・勝ち筋・負け筋

## 1. このドメインの本質

LPは **「広告で温めた感情を、行動まで運ぶ運搬装置」**。
広告でクリックした瞬間、ユーザーの感情は「気になる／買えるかも」という温度になっている。LPの仕事はその温度を**冷まさず、むしろ上昇させながら、CVボタンを押すという身体行動へ繋ぐ**こと。情報を伝える場所ではなく、**広告とCVの間を物語で接続する橋**として設計する必要がある。LPで多くのページが失敗するのは、「情報を載せる場所」と勘違いし、温度を冷ます方向に設計してしまうため。

この本質を分解すると、LPは4つの構造ゲームの重ね合わせで成立している。

### 本質① ファーストビュー（FV）の3秒勝負
LPの離脱の50〜70%は**FVだけで決まる**。3秒以内に「広告と同じ世界観」「自分への約束」「読み進める価値」の3つが提示されないと、ユーザーは戻るボタンを押す。FVで広告との連続性が切れた瞬間、温まっていた感情は急冷する。FVは「広告コピーの続き」として設計すべきで、独立したLPの表紙ではない。広告→FVが「同じ物語の次ページ」になっているかが、最初の関門。

### 本質② 物語構造（PASONA/AIDMA/共感ストーリー）の温度設計
読み進めるユーザーの感情は、放っておくと冷める。**意図的に温度を上げ続ける物語装置**が必要になる。PASONA（問題→共感→解決→提案→具体→行動）やAIDMA（注意→関心→欲求→記憶→行動）は単なるテンプレではなく、**感情の温度カーブを段階的に上げる地図**。物語装置がないLPは、情報のフラットな羅列になり、温度カーブが平坦になる。平坦なカーブはCVボタンの前で力尽きる。

### 本質③ 不安解消とCTA前置きの構造
ユーザーは「買いたい」と「失敗したくない」の両方を抱えている。**買いたい欲が90、不安が91なら、CVは押されない**。不安（価格／品質／使い方／キャンセル／個人情報）を1つずつ言語化し、回答を物語の中に置く。さらにCTAボタンは「読み切ってから押す」より「決断した瞬間に押せる場所にある」方が強い。**ボタンを下まで隠すのは離脱を増やす設計**。各セクション末・各説得ブロック後にCTAを前置きするのが鉄則。

### 本質④ 離脱ポイントの構造的設計
LPは縦長スクロールの中で、**読了率が階段状に落ちる**。30%地点で1段、50%地点で1段、CTA直前で1段。各段の落差を最小化するのがLP最適化の核仕事。**離脱は偶然ではなく構造的に発生する**。重い画像で読込が遅い、SPでテキストが小さすぎる、興味を引かない見出しが続く、不安に答える前に価格が出る、といった構造的トラップを潰す作業がLP改善の中心。

## 2. 鉄則（破ってはいけない）

> 表記凡例: 各項目末尾の **〈本質①〜④〉** は、その鉄則がどの本質に紐づくかを示す。

1. **FVの見出しは広告コピーと地続きにする** — 広告で「30日で肌が変わる」と言ったなら、FVも同じ温度・同じ語彙で続ける。〈本質①: 広告→FVの温度連続性が切れた瞬間に離脱する〉

2. **FVに「誰の・何の・どんな約束」を必ず明示する** — 商品名より先にターゲットとベネフィットを置く。〈本質①: 3秒で自己関連性を判定させる〉

3. **物語構造（PASONA/AIDMA）に沿った縦の流れを設計する** — セクションの順序は感情の温度カーブを階段状に上げるよう配置。〈本質②: 平坦な情報羅列ではCVボタンに届かない〉

4. **不安は隠さず、章として置く** — FAQ・お客様の声・返金保証・個人情報の扱いは独立セクションで明示。〈本質③: 不安は隠した分だけCVRが落ちる〉

5. **CTAボタンは各セクション末・各説得ブロック後に必ず配置する** — 「読み切ってから」ではなく「決断した瞬間に押せる場所」に。〈本質③: ボタン到達コストが高いと離脱する〉

6. **SP最適化を最優先する** — 多くの媒体で7〜9割がSP流入。SPで読みにくいLPはPCで完成度が高くても成果が出ない。〈本質①②④: SP前提で構造を組まないと離脱トラップが量産される〉

7. **読込速度は3秒以内（LCP）** — 3秒超過で離脱率が約30%上昇する。画像最適化、不要スクリプト削除を制作工程に組み込む。〈本質①④: 読み始める前に閉じられたら全てが無効化される〉

## 3. 勝ち筋（再現性のある勝ちパターン）

### 勝ち筋A: 「広告コピー = FV見出し」完全一致型
- **場面**: 広告→LPの直行型流入
- **内容**: 広告クリエイティブの主訴求とFV見出しを完全一致させ、サブコピー・KVも同じ世界観で揃える
- **なぜ勝てるか**: 〈本質①〉広告で温まった感情を1度も冷まさずFVに着地させられる。LP直帰率が大幅に下がり、その後の物語構造も機能しやすくなる。

### 勝ち筋B: 「共感ストーリーFV」型
- **場面**: 美容・健康・教育・SaaSなど、感情訴求が成立する商材
- **内容**: FVを「ターゲットの本音独白」で開く（「鏡を見るたび、また増えてる気がする」など）
- **なぜ勝てるか**: 〈本質①②〉商品紹介で開くLPと違い、ターゲットが「自分の話だ」と即認識する。物語の入口に立てた時点で、その後の物語構造が機能する確率が大幅に上がる。「体験を追体験させる」LPの基本形。

### 勝ち筋C: 「PASONA縦構造 + 各セクションCTA」型
- **場面**: 検討期間が短い商材（コスメ・サプリ・無料体験等）
- **内容**: 問題→共感→解決→提案→具体→行動の縦並びで、共感後・解決後・具体後の3箇所にCTAを置く
- **なぜ勝てるか**: 〈本質②③〉感情の温度が上がった各ピーク地点でCTA選択肢を提示するため、読み切らずとも決断したユーザーを取り逃がさない。

### 勝ち筋D: 「不安先回り解消セクション」型
- **場面**: 単価が高い・継続契約系・センシティブ商材
- **内容**: CTA直前に「よくある不安と答え」を独立章で配置（価格／解約／効果実感／個人情報）
- **なぜ勝てるか**: 〈本質③〉CVボタンの前で「不安91 vs 買いたい90」の状態を解いて「不安85 vs 買いたい90」に持っていく。不安を隠したLPと真逆の発想で、CVRが大きく動く。

### 勝ち筋E: 「お客様の声 × Before/After × 数字」三層型
- **場面**: 実績訴求が成立する商材
- **内容**: 一般的なお客様の声＋ Before/After写真＋ 数字（満足度98%等）を三層で配置
- **なぜ勝てるか**: 〈本質②③〉感情（共感者の声）と論理（Before/After視覚・数字）を両方提示し、感情温度の上昇と論理裏付けを同時に行う。決断に必要な両輪が揃う。

## 4. 負け筋（典型的な失敗・地雷）

### 負け筋A: FVが「商品名 + 商品写真 + キャッチコピー」だけ
- **症状**: LP直帰率70%超
- **原因**: 〈本質①〉広告との連続性がなく、ターゲットの自己関連性が判定できない。3秒勝負で負ける典型構造
- **回避策**: FV見出しを「ターゲットの悩み」または「広告コピーの続き」に書き換え、商品名は補助位置へ。

### 負け筋B: セクションが「会社紹介 → 商品特長 → 価格 → CTA」の順
- **症状**: スクロール率は出るがCVR壊滅
- **原因**: 〈本質②③〉感情温度が上がる前に会社紹介で冷まし、不安解消なしに価格を見せる。物語構造の逆走
- **回避策**: PASONA等の物語順に並び替え。会社紹介はフッター付近、価格は不安解消後。

### 負け筋C: CVボタンが最下部にしかない
- **症状**: スクロール深度80%超でもCVR低い
- **原因**: 〈本質③〉決断した瞬間にボタンが見えず、スクロールコストで離脱する。「読み切ってから押す」前提の古い設計
- **回避策**: ファーストビュー、各説得ブロック後、最下部の最低3箇所にCTA配置。SPは追従CTAも検討。

### 負け筋D: SPで文字が小さい・タップ領域が狭い
- **症状**: SP流入のCVRがPCの半分以下
- **原因**: 〈本質①④〉SP前提の設計を後回しにしてPCのリサイズで作っている
- **回避策**: SP本文14px以上、見出し20px以上、ボタン高さ48px以上を最低基準に。SPファースト設計。

### 負け筋E: 読込速度が5秒超
- **症状**: 広告クリック後の直帰が異常に高い（80%超）
- **原因**: 〈本質①④〉ユーザーが読み始める前に閉じている。物語構造もFVも到達していない
- **回避策**: 画像WebP化、Lazy Load、不要JS削除、LCPを3秒以内に。PageSpeed Insightsで定期計測。

### 負け筋F: お客様の声が「素敵な商品でした」レベル
- **症状**: 信頼区間で機能していない、CVR寄与なし
- **原因**: 〈本質②③〉解像度の低い声は「広告会社の作文」と即見抜かれ、逆に不信を生む
- **回避策**: 「使用前後の生活変化を行動描写レベル」で言語化された声を採用。固有名詞・数字・具体シーンを含める。

## 5. 判断分岐（迷ったときの基準）

| 状況 | 取るべきアクション | 紐づく本質 |
|---|---|---|
| LP直帰率70%超 | FVを広告コピーと地続きに改修 | ① 温度連続性 |
| スクロール率は出るがCV低 | 物語構造とCTA位置を再設計 | ②③ 温度カーブ・CTA前置き |
| CTA直前で離脱が多い | 不安解消セクションを直前に追加 | ③ 不安と買いたいの天秤 |
| SP CVRがPC比半分以下 | SP最適化を最優先で実施 | ①④ SP前提構造 |
| 読込3秒超 | 画像最適化・スクリプト削除 | ①④ 読込トラップ |
| お客様の声が機能しない | 解像度の高い行動描写型に差し替え | ②③ 具体性で信頼獲得 |
| 単価高・検討期間長 | 共感ストーリーFV＋証拠章増強 | ②③ 物語と裏付け強化 |
| 広告は出るがLPだけ弱い | LPだけのA/Bテスト（広告固定） | ①②③④ LP単独で勝てる構造 |

## 6. 実務チェックリスト

### 企画フェーズ
- [ ] 広告コピーとFV見出しが地続きに設計されているか 〈本質①〉
- [ ] 物語構造（PASONA等）に沿った縦並びになっているか 〈本質②〉
- [ ] ターゲットが抱える不安リストを言語化したか 〈本質③〉
- [ ] CTAを置くポイントを最低3箇所決めたか 〈本質③〉

### 制作フェーズ
- [ ] FV3秒で「誰の・何の・約束」が成立するか 〈本質①〉
- [ ] SP最適化（文字サイズ・ボタン領域・追従CTA）を実装したか 〈本質①④〉
- [ ] 画像最適化・Lazy Load・LCP3秒以内を確認したか 〈本質①④〉
- [ ] お客様の声・実績・数字が行動描写レベルの解像度か 〈本質②③〉

### 配信後フェーズ
- [ ] LP直帰率・読了率・CTAクリック率を計測しているか 〈本質④〉
- [ ] ヒートマップ／スクロールマップで離脱ポイントを特定したか 〈本質④〉
- [ ] FV／物語／CTA／不安解消のどこで負けているかを切り分けたか 〈本質①②③〉
- [ ] LP単独A/Bテストで仮説検証→抽象化を行ったか 〈本質①②③④〉
