# 動画クリエイティブ — 鉄則・勝ち筋・負け筋

## 1. このドメインの本質

動画広告は **「時間を借りて、感情を1段階動かす装置」**。
静止画と違い、ユーザーから「秒」という最も希少な資源を借り受けて成立する。借りた秒数の中で態度変容（知らない→気になる、気になる→欲しい、欲しい→今買う）を1段階でも動かせなければ、その秒数は丸ごと負債になる。「再生された」「最後まで見られた」は手段であって目的ではない。**目的は感情のメーターを1ノッチ上げることだけ**。

この本質を分解すると、動画広告は4つの構造ゲームの重ね合わせで成立している。

### 本質① 時間軸の物語性ゲーム
動画は静止画と違い「順番」が固定された表現形式。**観た順に意味が立ち上がる**ため、最初の1カットでフックを置かなければ、その後の名カットも見られない。Hook→Body→CTAという構造は単なるテンプレではなく、感情の温度を「冷→温→沸」へ階段状に上げていく**温度設計の地図**。この階段が崩れると、いくら個別カットが綺麗でも視聴者の心は動かない。動画は静止画の集合ではなく、**時間そのものを編集する表現**だと捉える必要がある。

### 本質② 視聴維持率の戦い
配信プラットフォームのアルゴリズムは「視聴維持率（特に3秒・25%・50%・75%・100%）」を品質シグナルとして読む。維持率が高いクリエイティブは配信が伸び、低いものは即座に止まる。**つまり離脱は単に1人逃しただけでなく、全体配信量を縮める**。だから「離脱しそうな2秒」を狩り続けるのが運用の中心仕事になる。ヒートマップ的に視聴維持カーブを見て、ガクッと落ちる場所がそのクリエイティブの「弱い場所」。

### 本質③ 音声と視覚の役割分担ゲーム
動画は「音あり前提」と「音なし前提」で別物のクリエイティブになる。Meta/TikTokは音オフ視聴が半数以上、YouTubeは音あり視聴が中心。**音なし環境で意味が伝わらない動画は、字幕とビジュアルだけで物語を完結させる必要がある**。逆に音あり前提媒体では、ナレーション・SE・BGMが感情の温度を上げる主役になる。「視覚で意味、音声で感情」という役割分担を意識しないと、両方が中途半端になる。

### 本質④ Hook→Body→CTAの起承転結
動画クリエイティブは、最初の2〜3秒（Hook）で「これは私のための動画だ」と認識させ、中盤（Body）で課題提起・解決提示・証拠提示を行い、最後（CTA）で具体的な次の行動を引き出す、という三幕構成で機能する。**Hookで負ければ後はゼロ、Bodyで負ければCTAは押されない、CTAで負ければ全部が無駄になる**。各パートには独立した勝利条件があり、どれか1つでも欠けると動画全体が機能停止する。直列構造のため、最弱パートが成果の天井を決める。

## 2. 鉄則（破ってはいけない）

> 表記凡例: 各項目末尾の **〈本質①〜④〉** は、その鉄則がどの本質に紐づくかを示す。

1. **最初の2秒で「誰の動画か」を宣言する** — 「30代で肌荒れに悩むあなたへ」のように、ターゲットを明示するか、ターゲットが反応する記号（症状・状況・言葉）を冒頭に置く。〈本質①④: Hookが機能しないと後段の温度設計が全て無効化される〉

2. **音なしで意味が通るように字幕とビジュアルを設計する** — Meta/TikTokは音オフ視聴が前提。字幕がないだけで視聴維持率は明確に落ちる。〈本質②③: 音なし前提の媒体では字幕とビジュアルだけで物語を完結させる必要がある〉

3. **視聴維持カーブのガクッと落ちる地点を毎週点検する** — 離脱地点の修正は、新規制作より優先される。〈本質②: 維持率は配信量そのものを規定するため、離脱点は売上の漏れ穴〉

4. **CTAは「動詞 + 具体行動」で締める** — 「今すぐタップ」「LINEで無料相談」など、次の行動を一文で言い切る。「ぜひご覧ください」は弱すぎる。〈本質④: CTAパートの勝利条件は「次の動作を引き出すこと」一点に集中する〉

5. **Hookと商品提示の間に必ず「共感」のブロックを挟む** — いきなり商品を出すと「広告だ」と認識されて閉じられる。〈本質①: 温度を冷から温へ上げる段階を飛ばすと感情の階段が断絶する〉

6. **縦型と横型は別クリエイティブとして作る** — 縦型を黒帯付きで横型に流用すると視聴維持率が崩壊する。〈本質③: 媒体ごとの視聴文脈が違うため、画面比率はクリエイティブの設計変数〉

7. **CV計測と再生計測を必ず分離して見る** — 再生は伸びてCVが伸びないクリエイティブは「Hookは強いがBody/CTAが弱い」と即診断できる。〈本質④: 三幕構成のどこで負けているかを数値で切り分ける〉

## 3. 勝ち筋（再現性のある勝ちパターン）

### 勝ち筋A: 「悩み宣言→共感→解決→証拠→CTA」の5段階構成
- **場面**: 認知〜検討フェーズの主力訴求
- **内容**: 2秒で悩みを宣言、4秒で共感シーン、6秒で解決提示、6秒で証拠（数字・実績・口コミ）、2秒でCTA。計20秒。
- **なぜ勝てるか**: 〈本質①④〉感情の温度を「冷→温→熱→沸→行動」と階段状に上げる物語構造に忠実なため、各段階で離脱しても次段階が次のフックになる。「体験を追体験させる」設計の基本形。

### 勝ち筋B: UGC風の素人感クリエイティブ
- **場面**: SNS媒体（Meta/TikTok）での新規開拓
- **内容**: スマホ縦撮り、ナレーション素人感、字幕は手書き風、BGM控えめ
- **なぜ勝てるか**: 〈本質①③〉ユーザーがフィードで見慣れたUGCの文脈に溶け込むため「広告だ」と認識される前にHookを通過できる。態度変容の前段にある「閉じられない壁」を越える設計。

### 勝ち筋C: 「先に結論」型フック
- **場面**: 機能訴求が明確な商材（ツール/家電/サプリ等）
- **内容**: 1秒目で「これ1本で〇〇が解決」と結論を出し、その後に理由・証拠を畳みかける
- **なぜ勝てるか**: 〈本質②④〉視聴維持率の最大の崖は3秒地点。1秒目に最大価値を置くことで3秒の壁を突破でき、Bodyに来た時点でほぼ温まった視聴者が残る。

### 勝ち筋D: 「使用シーン×Before/After」の追体験構造
- **場面**: ビフォーアフターが視覚的に伝わる商材（美容/掃除/収納等）
- **内容**: 使用前の不快感を5秒、使用シーンを5秒、使用後の解放感を5秒、CTAを5秒
- **なぜ勝てるか**: 〈本質①③〉視覚的に「体験を追体験させる」最も強い構造。ユーザーは商品ではなく「使用後の自分」を欲しがるため、その状態を視覚化することが態度変容のスイッチになる。

### 勝ち筋E: 「複数本×訴求軸別」並走運用
- **内容**: 同じ商材で「機能訴求×2／感情訴求×2／実績訴求×2／価格訴求×2」を同時配信し、媒体側に最適化を委ねる
- **なぜ勝てるか**: 〈本質②〉ユーザーの心が動く軸はセグメントによって違うため、軸を分散させると媒体側のアルゴリズムが「ユーザー × 軸」のマッチを見つけやすい。1軸に絞ると最強の1軸しか機能しない。

## 4. 負け筋（典型的な失敗・地雷）

### 負け筋A: 冒頭3秒がブランドロゴ・社名アニメーション
- **症状**: 再生数は出るが3秒離脱率70%超
- **原因**: 〈本質①②④〉Hook の貴重な秒数を「誰の動画か」の宣言ではなく自社ブランディングに使ってしまっている。視聴者にとっては「知らない会社の知らない動画」でしかなく、即離脱トリガーになる。
- **回避策**: ロゴは末尾CTAに回す。冒頭はターゲット宣言かベネフィット宣言で開く。

### 負け筋B: 音ありを前提に作って字幕なし
- **症状**: Meta/TikTokで視聴維持率が他媒体の半分
- **原因**: 〈本質③〉音オフ視聴者にとっては「無音の謎の映像」になってしまい、意味が通る前に閉じられる
- **回避策**: 字幕は必須。さらに「字幕だけ読んでも意味が通る」レベルまで情報を字幕に乗せる。

### 負け筋C: 長尺すぎて中盤離脱
- **症状**: 60秒以上の動画で50%地点で半分以上が離脱
- **原因**: 〈本質②④〉Bodyパートに情報を詰め込みすぎて、感情の温度を上げる前に飽きられている。「言いたいこと」が多すぎて「動かしたい感情」が分散している。
- **回避策**: 15秒・30秒・60秒の3バリアントを用意し、媒体・面に応じて使い分ける。1動画1メッセージを徹底。

### 負け筋D: CTAが「ぜひチェック」「お見逃しなく」
- **症状**: 再生・視聴維持は出るのにCVR壊滅
- **原因**: 〈本質④〉CTAパートの勝利条件は「具体行動の引き出し」だが、抽象的な締めだと次の動作が想起されず、動画を見終わって満足して閉じられる
- **回避策**: 「LINEで30秒診断」「今夜まで30%OFF」など、行動と理由をセットで提示。

### 負け筋E: 縦動画を黒帯付き正方形/横長に変換して流用
- **症状**: 流用先媒体で視聴維持率が半分以下
- **原因**: 〈本質③〉画面比率はクリエイティブの設計変数。黒帯は「他媒体からの流用」と即バレし、媒体内の自然な視聴文脈から外れる
- **回避策**: 媒体ごとに撮り直すか、最低限「画面比率に合わせた構図再編集」を行う。

### 負け筋F: クリエイターの自己満足カット（綺麗な引きの絵・凝った演出）
- **症状**: 完成度は高いが視聴維持率・CVRがどちらも低い
- **原因**: 〈本質①②〉「綺麗」と「感情が動く」は別物。引きの絵やシネマティック演出は雰囲気を作るが、ターゲットの感情のメーターを1段階動かす機能を持っていない
- **回避策**: 各カットに「このカットでユーザーの感情をどこからどこへ動かすか」を1行で書き出してから撮影に入る。

## 5. 判断分岐（迷ったときの基準）

| 状況 | 取るべきアクション | 紐づく本質 |
|---|---|---|
| 3秒離脱が60%超 | Hookを差し替え（5本テスト） | ①④ Hook弱で全段階機能不全 |
| 視聴維持50%地点で急落 | Bodyの中盤を1要素削る | ②④ Body冗長で温度が下がる |
| 視聴維持は出るのにCV低い | CTAパートを差し替え | ④ CTAの行動引き出し失敗 |
| 媒体A好調・媒体B不調 | 画面比率と音声前提を疑う | ③ 媒体文脈の不一致 |
| 配信量が伸びない | 維持率カーブを点検 | ② アルゴリズム評価が低い |
| CTRは高いがCV出ない | LP整合性と訴求軸の連続性確認 | ④ 動画→LP段差 |
| クリエイティブ疲労（フリークエンシー高） | 同じ訴求軸の別バリアント投入 | ① 物語の変奏 |
| 新規アカウント立ち上げ | 訴求軸4本×フォーマット2種で並走 | ② 学習素材を散らす |

## 6. 実務チェックリスト

### 企画フェーズ
- [ ] ターゲットが冒頭2秒で自己認識できるか 〈本質①④〉
- [ ] 各カットに「動かしたい感情の段階」が言語化されているか 〈本質①〉
- [ ] CTAで引き出したい具体行動が1つに絞られているか 〈本質④〉
- [ ] 「体験を追体験させる」設計になっているか（情報を伝えるだけになっていないか）〈本質①〉

### 制作フェーズ
- [ ] 音なしで意味が通るか（字幕＋ビジュアルで完結するか）〈本質③〉
- [ ] 縦/横/正方形の必要な比率で別撮りまたは別編集しているか 〈本質③〉
- [ ] CTAパートが動詞＋具体行動になっているか 〈本質④〉
- [ ] BGM・SEがHook/Body/CTAの温度に対応しているか 〈本質①③〉

### 配信後フェーズ
- [ ] 視聴維持カーブの急落地点を特定したか 〈本質②〉
- [ ] 3秒/25%/50%/75%/100%の各通過率を媒体別で見たか 〈本質②〉
- [ ] CTR×CVRで「Hook強・CTA弱」か「Hook弱・全体弱」かを切り分けたか 〈本質④〉
- [ ] 訴求軸別の勝ち負けを抽象化して次回企画に反映したか 〈本質①〉
