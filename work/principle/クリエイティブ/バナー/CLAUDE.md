# バナー制作 — フォルダ共通原則（必読・常時適用）

> このフォルダ（`principle/クリエイティブ/バナー/`）配下でバナー・静止画広告を設計・生成・評価・レビューする全エージェント（⑤CD / ⑧Banner Conceptor / ㉑㉒㉓Persona）は、**まず本ファイルを読み、ここに書かれた本質・鉄則・勝ち筋・負け筋を前提として作業すること**。個別ファイル（分析→生成マッピング.md / forbidden_patterns.md）や媒体別コピー指針・業界知見は、本ファイルの上に積む。

## 1. このドメインの本質

バナーは **「0.5秒で態度を1段階動かす視覚装置」**。
動画と違って秒数を借りられない。フィードでも検索面でもディスプレイでも、ユーザーが1枚のバナーに与える時間は**コンマ数秒**。その瞬間に「私に関係ある」「気になる」と判定させなければ、視野の外に流れる。つまりバナーは**情報を伝える広告ではなく、視線を止めて感情を1段階動かす視覚反射の設計物**。

この本質を分解すると、バナー広告は4つの構造ゲームの重ね合わせで成立している。

### 本質① 視認時間0.5秒の戦い
バナーを「読む」ユーザーはいない。あるのは**0.5秒のスキャンと、止まるか流すかの二択**。だから情報を全部詰め込むのは逆効果で、**0.5秒で意味の塊が1つだけ立ち上がる**よう設計する必要がある。文字数・要素数・色数の上限は「読みやすさ」のためではなく「0.5秒で意味が成立するか」の制約。多すぎる情報は「情報過多バナー」として認識され、即スキップされる。

### 本質② 視線誘導の物理
人間の視線は無秩序に動かない。**サイズの大きいもの・コントラストの強いもの・顔・矢印・数字**に強制的に引き寄せられる。だから「どの順序で何を見せるか」をデザイナーが決めない限り、視線は商品名やCTAに到達しない。視線のZ字／F字パターン、フォーカルポイント、視覚的階層（タイトル＞サブ＞CTA）といった原則は装飾ではなく、視線の物理に逆らわないための工学的設計。

### 本質③ コピー×ビジュアルの役割分担
バナーは「コピーで意味、ビジュアルで感情」の役割分担で機能する。**コピーが情報を全部担うとビジュアルが装飾化し、ビジュアルが情報を全部担うとコピーが冗長化する**。理想は「ビジュアルだけ見て世界観が伝わり、コピーだけ読んで具体性が伝わる」状態。両方が同じことを言っていると情報量が無駄になり、両方が違うことを言っていると意味が散る。役割分担を設計するのがバナー制作の中核仕事。

### 本質④ サイズ別最適化（配信媒体別レギュレーション）
1080×1080と1200×628と300×250は別クリエイティブ。**同じ素材をリサイズして使うと、必ずどこかで意味の塊が崩れる**。バナーは「サイズに最適化された情報配置」が前提で、媒体ごとに視認距離・並ぶ位置・周囲の文脈が違う。Meta フィード、Instagram ストーリー、Yahoo!ディスプレイ、GDN レスポンシブ、それぞれが別の戦場であり、サイズの違いはイラストや写真の違い以上に成果を分ける。

## 2. 鉄則（破ってはいけない）

> 表記凡例: 各項目末尾の **〈本質①〜④〉** は、その鉄則がどの本質に紐づくかを示す。

1. **「目を細めて見てもメインメッセージが取れる」かを必ずテストする** — 細部を捨て、視認時間0.5秒の状態を再現する。〈本質①: 0.5秒で意味の塊が立ち上がるかを物理的に検証〉

2. **1バナー1メッセージを徹底する** — 訴求は1つに絞り、それ以外の要素は補助に回す。〈本質①③: 0.5秒で再生できる意味は1つだけ。複数訴求は別バナーで散らす〉

3. **メインコピーの文字サイズは画像短辺の8%以上を確保する** — フィードで表示される実寸を意識する。〈本質①②: 視線が止まる物理的サイズの確保〉

4. **顔・目線・矢印・数字は視線誘導の主役** — 商品単体写真より、人物の視線が商品に向いている構図の方が止まる確率が高い。〈本質②: 視線の物理に逆らわない設計〉

5. **コピーとビジュアルで同じ情報を二重に書かない** — 写真でAfterを見せているのに「劇的な変化！」と書くのは情報の冗長化。〈本質③: 役割分担が崩れると情報密度が下がる〉

6. **配信媒体ごとにサイズ別バリアントを必ず作る** — 正方形→横長へのトリミング流用は基本禁止。〈本質④: サイズの違いは別クリエイティブ〉

7. **入稿規定（画像内テキスト比率・薬機法等）を企画段階で確認する** — Meta の20%ルール（緩和されたが今も評価には影響）など、媒体側のレギュレーションを後工程で発見すると差し戻し連鎖になる。〈本質④: 媒体規定はクリエイティブ前提〉

## 3. 勝ち筋（再現性のある勝ちパターン）

### 勝ち筋A: 「人物視線 + 商品 + ベネフィットコピー」の3点配置
- **場面**: SNS媒体での新規開拓
- **内容**: 人物（ターゲット属性）が商品に視線を向け、上または横にベネフィットコピーを配置
- **なぜ勝てるか**: 〈本質②③〉人物の顔と視線が視線誘導の主役となり、ユーザーの視線が「人物の顔→人物の視線先（商品）→コピー」とZ字に流れる。視線の物理に最も忠実な構造。

### 勝ち筋B: 「数字 + ベネフィット名詞」の超圧縮型
- **場面**: フィード／検索ディスプレイ
- **内容**: 巨大な数字（「30日」「98%」「2分」）＋ ベネフィット名詞 ＋ 商品ビジュアル
- **なぜ勝てるか**: 〈本質①②〉数字は視線を強制的に止める要素で、かつ意味密度が高い。「30日返金保証」より「30日（巨大）／返金保証」の方が0.5秒で読める。

### 勝ち筋C: 「Before/After 二分割」構図
- **場面**: ビフォーアフター訴求が成立する商材（美容・収納・痩身等）
- **内容**: 画面を縦/横で二分割し、左Before・右Afterを並置。中央に矢印または商品
- **なぜ勝てるか**: 〈本質①③〉視覚だけでベネフィットが成立する。「体験を追体験させる」最強の構図で、コピーがなくても態度変容のスイッチが入る。

### 勝ち筋D: 「テキスト主体 / ビジュアル最小」型
- **場面**: B2B、無形商材、検討フェーズ
- **内容**: 余白を大きく取り、大きな見出しコピー1本＋小さな補足＋控えめなビジュアル
- **なぜ勝てるか**: 〈本質①③〉B2B・無形商材は写真で感情を動かしにくい。視線をコピーに集中させ、論理訴求を0.5秒で通す設計が機能する。

### 勝ち筋E: 「UGC風／写真素人感」バナー
- **場面**: Meta/Instagramフィード
- **内容**: スマホ撮影風の自然光・素人感のある構図、手書き風文字
- **なぜ勝てるか**: 〈本質①〉フィードで広告然としたバナーはパターン認識で素通りされる。UGC風はフィードの文脈に溶け込み、「広告だ」と認識される前にメッセージを通せる。

## 4. 負け筋（典型的な失敗・地雷）

### 負け筋A: 情報詰め込み（コピー3行・要素5個以上）
- **症状**: CTR が媒体平均の半分以下
- **原因**: 〈本質①②〉0.5秒で意味の塊が成立せず、視線が止まらない。読み解こうとする前に流される
- **回避策**: メインメッセージ1つ＋ビジュアル1つ＋CTA1つの3要素に絞る。それ以上は別バナーへ。

### 負け筋B: 商品単体写真の白背景バナー
- **症状**: 視線が止まらず素通り
- **原因**: 〈本質②〉視線誘導の主役（顔・視線・数字・矢印）がなく、視線が掴まれない
- **回避策**: 人物の使用シーン、または巨大な数字をフォーカルポイントとして配置。

### 負け筋C: 写真とコピーが同じことを言う
- **症状**: 情報量が多いように見えて意味密度が低い
- **原因**: 〈本質③〉「変化を体感」というコピーの横にBefore/After写真は冗長。コピーが装飾化している
- **回避策**: 写真が「感情・世界観」、コピーが「具体性・数字」と役割を分ける。

### 負け筋D: 正方形バナーを横長にトリミング流用
- **症状**: 流用先媒体でCTR壊滅、メインコピーが切れる
- **原因**: 〈本質④〉サイズの違いは情報配置の前提が違う。トリミングするとメインコピーや顔が切れる
- **回避策**: 正方形／横長／縦長／長方形の主要サイズは別レイアウトで作る。

### 負け筋E: ブランドロゴ・社名が画面最上部に大きく配置
- **症状**: 視線がブランドで止まり、ベネフィットが読まれない
- **原因**: 〈本質②③〉視線誘導の最上位にブランドが置かれると、ユーザーは「知らない会社」と判定して即スキップ
- **回避策**: ブランドは右下または左下の補助位置に。視線最上位はベネフィット／数字／人物視線。

### 負け筋F: 訴求軸の異なるバナーをまとめて1枚にする
- **症状**: 1枚に「機能」「実績」「価格」を全部入れる
- **原因**: 〈本質①〉1.5〜2秒で複数訴求を読むのは不可能。結果的にどれも弱くなる
- **回避策**: 訴求軸ごとに別バナーを作って並走配信。媒体側のアルゴリズムに最適化を委ねる。
