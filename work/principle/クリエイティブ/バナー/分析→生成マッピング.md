# バナー 分析→生成マッピング — 競合を「自社の顔」に変換する

## 0. このファイルの役割

競合バナーを参考にすると、出来上がるのは多くの場合「劣化版」になる。原因は**競合の表面（色・構図・コピー）を写し、その背景にある自社の知見を入れていない**から。社内は「うちらしくない」、競合は「パクリ」と感じる ── 両方に違和感が出る構造。

これを解く唯一の方法は **「競合の表面を取り込む」のをやめ、「競合が当てている訴求の構造だけ抽象化して、表現は自社の知見で作り直す」** こと。
本ファイルはその抽象化→変換のロジックを定義する。`CLAUDE.md` の本質①〜④が「なぜそう作るか」、本ファイルが「競合をどう自社化するか」を担う。

> 適用条件: `/banner-ad-build` に競合バナーが入力されたときのみ本ファイルを起動する。競合入力が無いときは⑧が商材ブリーフから3型を素設計する（本ファイルは不要）。

---

## 1. 8軸 訴求フレーム（競合バナーを必ずこの軸で読む）

競合バナーを見たら、まず「**主訴求1つ・副訴求1つ**」を以下8軸から判定する。印象論で真似ない。軸に分解してから変換する。

| 軸 | 名称 | 競合が当てているサイン | 主に紐づく本質 |
|---|---|---|---|
| A1 | 価格訴求 | 金額・割引率・コスパ・「業界最安」級 | ③ コピーが情報を担う |
| A2 | 機能訴求 | 機能名・性能数値・スペック・UI提示 | ③ コピー×ビジュアル役割分担 |
| A3 | 感情訴求 | 痛みの描写／理想像／共感ストーリー／表情 | ② 顔・視線で止める |
| A4 | 権威訴求 | 導入数・受賞・実績ロゴ並列・専門家 | ① 数字で0.5秒成立 |
| A5 | 限定訴求 | 期間・数量・早期特典・締切 | ① 0.5秒で緊急性を立てる |
| A6 | ベネフィット訴求 | 使用後の変化・Before/After・結果像 | ②③ 視覚でベネフィット成立 |
| A7 | 課題提起訴求 | 「こんな悩みありませんか」型の問い | ① 自分ごと化を0.5秒で |
| A8 | トーン訴求 | 親しみ／高級感／革新性／UGC感 等の世界観 | ① パターン認識回避（広告然回避） |

判定アウトプット（Step4で必ずこの形）:
```
- 競合バナー#: <ファイル名/識別>
- 主訴求軸: A_ <根拠：画面のどの要素から読めるか>
- 副訴求軸: A_ <根拠>
- 構図タイプ: <人物視線3点 / 数字主役 / Before-After二分割 / テキスト主体 / UGC風 等（CLAUDE.md勝ち筋A〜Eで言語化）>
- CTAタイプ: <無料/即日/保証/資料DL/今すぐ 等の「型」。文言そのものは抽出しない>
- 緊急性レベル: <高/中/無>
- トーン: <言語化（高級/親近/堅実/勢い 等）>
- 競合固有要素（継承禁止リスト用に必ず抽出）: <ロゴ/マスコット/競合キャッチコピー原文/競合ブランドカラー組合せ/特定人物の顔>
```

## 2. 継承 / 変換 / 継承禁止 マトリクス（変換の核）

抽象化した競合分析を、3バケツに必ず仕分ける。**「継承禁止」を1つでも残したら lookalike（劣化パクリ）確定**。

### 継承してよい（＝競合が証明した「効く構造」。自社で同じ構造を使ってよい）
| 要素 | 理由（本質紐付け） |
|---|---|
| 訴求軸（A1〜A8のどれを当てるか） | 〈本質①〉その市場の0.5秒で刺さる軸は競合が検証済の市場情報。軸の選択は誰の所有物でもない |
| 構図タイプ（人物視線/数字主役/二分割等） | 〈本質②〉視線誘導の物理に沿った構図は普遍。CLAUDE.md勝ち筋A〜Eと同じ |
| CTAタイプ（無料/即日/保証 等の型） | 〈本質①〉ファネル位置に対する定石。型は共有財 |
| ターゲット感・緊急性レベル・トーンの方向 | 〈本質①〉市場の温度感の読み。方向は継承、表現は変換 |

### 必ず変換する（＝継承した構造を「自社の顔」に作り替える）
| 要素 | 変換ルール | 理由 |
|---|---|---|
| コピーの言い回し | 競合の文を**翻案・微改変しない**。同じ訴求軸を自社の商材ブリーフ原文（強み・お客様の声・実績数値）から作文し直す | 〈本質③〉コピーは自社の具体性を載せる器。借文は中身が空になる |
| カラーパレット／配色 | 自社ブランドカラー（案件のbrand指定 or LP主要色）に置換 | 〈本質②〉色は視線誘導の主役。自社色でないと「他社の顔」 |
| CTAテキスト | 型は継承、文言は自社トーンで作文 | 〈本質①〉 |
| 具体ペルソナ・人物の属性表現 | Step2で③が作った自社ペルソナに合わせる | 〈本質②〉 |
| フォント・タイポの方向 | 自社トーン（媒体別コピー指針／案件指定）に合わせる | 〈本質①〉 |
| 数値・実績 | 競合の数字を**絶対に流用しない**。自社商材ブリーフの実績数値のみ | 景表法（→ forbidden_patterns.md／業界知見） |

### 継承禁止（＝1つでも残れば不採用。背景KVプロンプト・negativeに必ず除外指示を注入）
- 競合の**ロゴ・社名・マスコット/キャラクター**
- 競合の**キャッチコピー**（原文・直訳・語順入替・同義言い換え＝「業界No.1→業界トップ」レベルの微改変も全部禁止）
- 競合の**ブランドカラーの組み合わせ**（単色一致は許容しうるが、競合を想起させる配色セットは禁止）
- 競合バナーに写る**特定人物の顔・タレント・体験者**
- 競合の独自図版・グラフの体裁・固有ビジュアルモチーフ

→ 詳細な除外実体リストと判定基準は `forbidden_patterns.md`。

## 3. 変換 → 派生案 設計（⑧の出力単位）

⑧は競合分析を上記マトリクスで仕分けた上で、`CLAUDE.md` の3型（**コピー強型／ビジュアル強型／数値訴求型**）に落として派生案を出す。各派生案は下記を**全項目埋める（modified_expression が空配列の案は不採用）**:

```
## 派生案 <#>（型: コピー強 / ビジュアル強 / 数値訴求）
- inherited_appeal_axis: <継承した訴求軸 A_ ＋ なぜこの市場で効くか（本質紐付け）>
- inherited_structure: <継承した構図/CTAタイプ/緊急性/トーン方向>
- modified_expression: <空配列禁止。最低1つ。色/コピー/構図/人物/数値のどこを自社へどう変えたか>
- headline（メイン20字以内）: <自社ブリーフ原文素材から作文>
- subcopy（サブ30字以内）: <同上>
- cta: <型は継承・文言は自社トーン>
- target_audience: <Step2の自社ペルソナA/B/Cのどれを狙うか>
- visual_direction: <被写体/構図/視線誘導/配色＝自社ブランドカラー/トーン。背景KVプロンプト草案へ橋渡し>
- forbidden_clear: <継承禁止リストの何を確実に排除したか（ロゴ/競合コピー/競合色/顔）>
- rationale: <なぜ自社の顔になっているか／競合と並べて別ブランドと分かる理由>
- 紐付け: 〈本質①〜④〉<この派生がどの本質に効くか1行>
```

**最低条件（破ったら⑤CDが機械的に差戻し）**
1. `modified_expression` が空でない（色もコピーも構図も同じ＝ lookalike 確定）
2. 継承禁止リストの要素が0
3. headline/subcopy が競合コピーの翻案でなく自社ブリーフ素材由来
4. 配色が自社ブランドカラー基準
5. 〈本質①〜④〉のどれに効くか説明できる

## 4. 「劣化版」を生む典型変換ミス（負け筋・⑤CD採点観点）

| ミス | 症状 | なぜ負けるか（本質） | 正しい変換 |
|---|---|---|---|
| 競合コピーの微改変 | 「うちらしくない」「パクリ」両方の違和感 | 〈本質③〉自社の具体が無く中身が空 | 訴求軸だけ継承し自社ブリーフ原文から作文 |
| 競合配色のまま自社ロゴ載せ | 競合の顔に自社名が乗った状態 | 〈本質②〉色＝視線の主役が他社 | 自社ブランドカラーに置換 |
| 構図も色もコピーも踏襲（modified空） | SSIM/見た目で競合と区別不能 | 〈本質①②④〉lookalike確定 | 最低1要素を必ず自社変換 |
| 競合の実績数値を流用 | 景表法リスク・虚偽訴求 | 規制違反 | 自社ブリーフの実績数値のみ使用 |
| 競合の人物/タレント踏襲 | 肖像・ブランド混同 | 継承禁止違反 | 自社ペルソナ属性で被写体を作り直す |
| 8軸を飛ばして印象で真似 | 何を継承したか説明できない | 抽象化の欠落 | 必ず主・副軸を言語化してから変換 |
