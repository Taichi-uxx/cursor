# バナー フォントパレット — Nano Banana 2 実利用可能フォント38種

`/banner-ad-build` 実験モードの画像生成（Nano Banana 2＝`gemini-3.1-flash-image-preview`）で、**画像内テキストとして実利用可能**な日本語/欧文フォントの一覧と、訴求型・業種・装飾密度別の選択ガイド。

> **使い方**: ⑧Banner Conceptor は画像生成プロンプトの **【フォント（必須）】** セクションで本リストから1つを選び、**フォント名をそのまま記載**する（例：「Noto Sans JP」「Zen 角ゴシック New」「しっぽり明朝」）。「和文ゴシック太め」のような曖昧な記述ではなく、固有名で指定することで再現性が上がる。
>
> **数値訴求型は和文＋欧文の2フォント指定可**：和文側で日本語を、欧文側で英数字（数字訴求の主役）を別フォントで指定すると数字の見栄えが上がる。

## ⑧Banner Conceptor のフォント選択チェックリスト

1. **LPのフォント観察**：商材ブリーフ §視覚DNA「タイポグラフィ」項を確認。LPで使われているフォントの方向性（ゴシック太め／明朝／丸ゴシック等）を継承するのが基本（**LPとバナーで温度を合わせる**鉄則）
2. **業種・規制**：医療/福祉/行政は BIZ UD 系優先。日本酒/和菓子/旅館は明朝or筆系
3. **装飾密度**：高密度（駅貼り系）なら **Dela Gothic One** や **ランパート One**、シンプル系なら **Zen 角ゴシック New** や **Noto Sans JP**
4. **数値訴求型の数字**：和文フォント＋欧文フォントの2指定可（「数字は IBM Plex Sans JP の太字で」「数字は Nunito の極太で」のように）
5. **メインコピーと脚注で別フォント？**：基本は1フォントに統一（メイン太め・脚注細めの太さ違いだけで対応）。複数フォント混在はバランス崩れリスク

## プロンプトでの記述例

### 数値訴求型・装飾密度高（いえとち本舗風）
```
【フォント（必須）】
和文＝Zen 角ゴシック New（メインコピーは太め、脚注は細め）／数字＝Noto Sans JP の太字（数値「53,018」を視線の主役として強調）
```

### コピー強型・余白系（ハイブランド系）
```
【フォント（必須）】
しっぽり明朝（メインコピー・上品な見出し）
```

### 業界規制（医療系）
```
【フォント（必須）】
BIZ UDゴシック（メインコピー・脚注・全テキスト統一・可読性最優先）
```

### コミック・エンタメ系
```
【フォント（必須）】
和文＝しっぽりアンチック（メインコピー）／欧文＝Comic Shanns（英字補助）
```

## 注記・運用

- 本リストは**2026-05-26時点**の Nano Banana 2 利用可フォント。モデル更新でフォントが追加/廃止された場合は本ファイルを更新
- 「**BIZ UD**」系はユニバーサルデザインフォントで、可読性最優先の場面（医療・行政・福祉）で第一候補
- 「**しっぽり明朝**」「**ひな明朝**」「**Zen 角ゴシック New**」「**IBM Plex Sans JP**」は近年Google Fontsで人気の高品質フォント。汎用的に質感が出る
- 「**Dela Gothic One**」は駅貼り系の力強さが必要な場面で有効だが、業種・LP温度との整合をよく確認する（量販トーンが商材と合わないと逆効果）
- フォント名を指定しても、Nano Banana 2 がそのフォントを**完全に再現する保証はない**（実際のレンダリングはモデル側の解釈）。とはいえ「太め and 駅貼り系」よりは「Dela Gothic One」と書く方が再現性が高い
