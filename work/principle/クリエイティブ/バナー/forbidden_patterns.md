# バナー forbidden_patterns — lookalike を構造的に止める

機械（または当面はLLM）が「人間がやると見落とす部分」を確定で止めるための基準。
**判定不能なら必ず止める（silent pass 絶対禁止）**。「たぶん大丈夫」で通すのが最大の事故源。

---

| Step | 効かせ方 | 紐付く本質 |
|---|---|---|
| Step4 競合8軸分析 | 競合固有要素を「継承禁止リスト」として抽出（§2） | 〈本質②③〉 |

## 2. 継承禁止：競合固有要素（Step4で抽出 → 生成で必ず排除）

1案でも残れば**不採用**。生成プロンプトの否定指示にも個別注入する。

- 競合の**ロゴ・社名・サービス名・マスコット/キャラクター**（一部・崩し・想起表現も不可）
- 競合の**キャッチコピー**：原文／直訳／語順入替／同義言い換え（「業界No.1→業界トップ」級の微改変も**全部禁止**）
- 競合の**ブランドカラーの組み合わせ**（競合を一目で想起する配色セット。単色の偶然一致は可だが組合せ模倣は不可）
- 競合バナーの**特定人物・タレント・体験者の顔**（似た構図でも自社ペルソナ属性で被写体を作り直す）
- 競合の**独自図版・グラフ体裁・固有ビジュアルモチーフ**

> 抽出粒度：`分析→生成マッピング.md §1` の判定アウトプット「競合固有要素」欄に必ず実体名で書き出す。「なんとなく似た雰囲気」では止められない。具体物で列挙する。

---

## 3. anti-copy 指示（生成プロンプト先頭に固定注入）

⑧が出す生成プロンプトの**先頭**に必ず以下を内包する。**実験モード（文字込み一枚絵）／安定モード（ハイブリッド背景KV）** で文言は異なる。

### 3-A. 実験モード（gen_full_banner.py：文字込み一枚絵）
> 競合の固有要素を一切再現しない：競合ロゴ・社名・マスコット・キャッチコピー（直訳/微改変含む）・競合ブランドカラー組合せ・競合バナーの特定人物の顔・競合の独自図版を使わない。**日本語コピー原文「<原文>」を正確に描画する（誤字・脱字・字形破綻・代替文字置換を一切しない。crisp typography, legible Japanese kerning）**。

→ 安定モードと違い「画像内テキスト禁止」指示は**入れない**（テキストは描かせる前提）。代わりに「**コピー原文の正確描画指示**」が必須。**この指示が無い一枚絵プロンプトは⑤CDがB-compで無条件差戻し**。

### 3-B. 安定モード（gen_bg.py：背景KVのみ・compose_banner.pyで重ね）
> 競合の固有要素を一切再現しない：競合ロゴ・社名・マスコット・キャッチコピー（直訳/微改変含む）・競合ブランドカラー組合せ・競合バナーの特定人物の顔・競合の独自図版を使わない。背景KVに文字（テキスト/タイポ/ロゴ/透かし）を一切入れない。

加えて `gen_bg.py` のプロンプトハードニング（no text/no letters/no logo/no watermark）と二重で効かせる。**この指示が無い背景KVプロンプトは⑤CDがB-compで無条件差戻し**。

## 4. 全社共通 NG 語（生成段階で弾く・negative側へ）

景表法・品位の観点で全社共通除外。生成段階で弾く（採点後では手戻り）。

- 「業界No.1」「日本一」「最高」「最強」「絶対」「100%」「必ず」「確実」
- 「圧倒的」「驚異的」「革命的」「劇的」「魔法のように」
- 客観データ無き比較（「他社より〇倍」「他社と桁が違う」等）
- 競合実績数値の流用（自社商材ブリーフの実数のみ使用可）

> 業界別の追加禁則（薬機法の効能効果断定／医療・美容・金融の規制表現等）は
> `/Users/apple/.cursor/work/principle/業界知見/<業界>/` を必ず通す。本ファイルは全社共通分のみ。
> 数値・媒体規定の最新は `媒体別コピー指針.md` ＋ `広告運用/` を運用時に確認（陳腐化しうる）。

## 5. 生成後ゲート（Step8・3観点＋実験モード固有1観点）

**段階導入＝当面は独立サブエージェントのvision/テキスト判定**。下記の閾値は判定の言語的基準であり、安定後に `scripts/`（カラー距離・コピー編集距離・SSIM）へ機械化する（lp-build と同じ自己完結scripts方針）。**判定に必要な材料（競合バナー実体／生成画像）が揃わず判定できない場合は pass させず Step8 を停止**して田村レビューに戻す。

### 5-1. competitor_lookalike（構造的類似）
- 判定: 生成バナーと各競合バナーを並べ「**別ブランドと一目で分かるか**」
- 当面の言語基準: 構図・配色・コピー位置・人物配置のうち**最低2要素**が明確に別／全体印象が別ブランド → pass。1要素しか違わない／competitorと混同しうる → fail
- 後日script化の目安: SSIM `≤0.50 pass / 0.50–0.65 要確認 / >0.65 不採用`

### 5-2. copy_similarity（コピー類似）
- 完全一致・語順入替・同義言い換え → 不採用
- 後日script化の目安: 編集距離 30% 未満は要確認

### 5-3. brand_fit（自社ブランド適合）
- 主要色が**自社ブランドカラー**に寄っているか（競合色のままでない）
- 継承禁止要素（ロゴ/競合コピー/競合人物/競合図版）の混入ゼロ
- NG語（§4）・業界規制表現の混入ゼロ
- `modified_expression` が実体として効いているか（色もコピーも構図も同じ＝fail）

### 5-4. typography_integrity（実験モード＝文字込み一枚絵のみ・必須）
- ① **日本語テキスト崩れ**: 誤字／脱字／文字化け／非標準漢字／字形破綻 → **fail（不採用・許容しない）**
- ② **可読性**: コントラスト不足／フォントサイズ不足／背景に埋もれて読めない → fail
- ③ **コピー原文との一致**: ⑧プロンプトに指定したコピー原文と生成画像内のテキストが一字一句一致するか（自動句読点追加・濁点欠落も fail）
- 判定: 全画素 / 全テキスト要素について上記をvision SAが確認。**1箇所でも該当で fail**
- 安定モード（ハイブリッド）では本観点は不要（テキストはHTML/CSSで正確に重ねるため）

### 集約ルール（lp-build/copy-build の採点思想に整合）
- いずれか fail → 全体 **fail（不採用・⑤CDへ差戻し理由明記）**
- fail なし・要確認あり → **needs_human_review（田村目視に回す）**
- 全 pass → **pass**
- 判定材料不足で判定不能 → **停止（silent pass 禁止）**

## 6. ブランド安全性レポート（Step10出力に必ず含める）

各派生案 variant 単位で：

```
- variant: <派生案#／型>
- competitor_lookalike: pass/needs_review/fail（根拠：別ブランドと分かる理由 or 似ている要素）
- copy_similarity: pass/fail（競合コピーとの近さ）
- brand_fit: pass/fail（自社色・継承禁止混入・NG語）
- typography_integrity: pass/fail（実験モードのみ・日本語崩れ／可読性／原文一致）
- 総合 verdict: pass / needs_human_review / fail
- human_review_required: true/false（trueは田村が競合と並べて最終目視）
```
