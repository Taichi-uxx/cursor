# バナー forbidden_patterns — 全社NG語・ブランド適合・日本語タイポ完整性

機械（または当面はLLM）が「人間がやると見落とす部分」を確定で止めるための基準。
**判定不能なら必ず止める（silent pass 絶対禁止）**。「たぶん大丈夫」で通すのが最大の事故源。

> **2026-05-26 廃止**: 旧仕様の「lookalike（劣化パクリ）を構造的に止める」スキーム（§2 継承禁止リスト・§5-1 competitor_lookalike・§5-2 copy_similarity）は全廃。表面模倣防止の構造判定が⑧のSAコンテキストを膨らませてプロンプト精度を下げる副作用 vs 最終アウトプット品質への寄与の薄さ、のトレードオフ判断。`分析→生成マッピング.md` も同日アーカイブ。

## 3. プロンプト【禁止】セクションの規定（生成プロンプト末尾に固定）

⑧が出す生成プロンプトの【禁止】セクションは以下のみ（**2026-05-26 確定・最小指示型**）：

> 【禁止】他社のロゴ・マスコット、「○○No.1」「日本一」等の最大級表現は入れない。

**2項目のみ**で運用する。以下は**書かない**（2026-05検証1の学び）：
- 競合キャッチコピー原文の禁止列挙（書いた瞬間モデルが意識する誘導効果＝書くと逆に類似する）
- NG語10件網羅（最重要1〜2件のみで足りる）
- 配色禁止リスト（"no flyer yellow, no signal red..." 等）
- 日本語コピー原文「正確に描画」明示（Nano Banana 2 等の最新モデルは標準で日本語描画精度が高い・念押しは効かない）
- タイポ崩れ抑制セクション（同上・念押しは効かない／pt指定は誤描画の元）

**競合バナーは⑧Banner Conceptor が「参考画像」として裁量で読み取る運用**（または skill 発動時に田村が「添付バナーの〇〇を参考にして」と手動指示）。表面模倣防止の構造判定（旧 modified_expression／継承禁止リスト／競合と同カテゴリのフォント選択回避 等）は2026-05-26に廃止。

> **2026-05-26 廃止**: 旧 §3-A（実験モード）／§3-B（安定モード＝ハイブリッド）の区分は廃止。一枚絵モードを確定方式として採用したため、本セクション（§3）は単一の【禁止】規定のみに簡素化。旧 §3-B の背景KVプロンプト（gen_bg.py 用）は対応スクリプト共々2026-05-26 に廃止・物理削除済（banner-ad-build／lp-build 両方）。

## 4. 全社共通 NG 語（生成段階で弾く・negative側へ）

景表法・品位の観点で全社共通除外。生成段階で弾く（採点後では手戻り）。

- 「業界No.1」「日本一」「最高」「最強」「絶対」「100%」「必ず」「確実」
- 「圧倒的」「驚異的」「革命的」「劇的」「魔法のように」
- 客観データ無き比較（「他社より〇倍」「他社と桁が違う」等）
- 競合実績数値の流用（自社商材ブリーフの実数のみ使用可）

> 業界別の追加禁則（薬機法の効能効果断定／医療・美容・金融の規制表現等）は
> `/Users/apple/.cursor/work/principle/業界知見/<業界>/` を必ず通す。本ファイルは全社共通分のみ。
> 数値・媒体規定の最新は `媒体別コピー指針.md` ＋ `広告運用/` を運用時に確認（陳腐化しうる）。

## 5. 生成後ゲート（Step7・2観点＋一枚絵固有1観点）

**段階導入＝当面は独立サブエージェントのvision/テキスト判定**。下記の閾値は判定の言語的基準であり、安定後に `scripts/`（カラー距離・vision OCR）へ機械化する（lp-build と同じ自己完結scripts方針）。**判定に必要な材料（生成画像）が揃わず判定できない場合は pass させず Step7 を停止**して田村レビューに戻す。

> **2026-05-26 廃止**: 旧 §5-1 competitor_lookalike（生成バナーと競合バナーの構造的類似度判定）と §5-2 copy_similarity（競合コピー編集距離判定）は全廃。表面模倣防止スキームの一括廃止に伴う措置。

### 5-3. brand_fit（自社ブランド適合・2026-05-26 改訂）
- 主要色が**自社ブランドカラー**（商材ブリーフ§視覚DNAのベース＋アクセント）に寄っているか
- NG語（§4）・業界規制表現の混入ゼロ
- 他社のロゴ・マスコットが描画されていない

### 5-4. typography_integrity（一枚絵モード＝文字込み一枚絵で必須）
- ① **日本語テキスト崩れ**: 誤字／脱字／文字化け／非標準漢字／字形破綻 → **fail（不採用・許容しない）**
- ② **可読性**: コントラスト不足／フォントサイズ不足／背景に埋もれて読めない → fail
- ③ **コピー原文との一致**: ⑧プロンプトに指定したコピー原文と生成画像内のテキストが一字一句一致するか（自動句読点追加・濁点欠落も fail）
- 判定: 全画素 / 全テキスト要素について上記をvision SAが確認。**1箇所でも該当で fail**
- ※ 旧ハイブリッド方式（テキストはHTML/CSSで正確に重ねる方式）は2026-05-26 に廃止。一枚絵モードに統一

### 集約ルール（lp-build/copy-build の採点思想に整合）
- いずれか fail → 全体 **fail（不採用・⑤CDへ差戻し理由明記）**
- fail なし・要確認あり → **needs_human_review（田村目視に回す）**
- 全 pass → **pass**
- 判定材料不足で判定不能 → **停止（silent pass 禁止）**

## 6. 生成後ゲートレポート（Step9 出力バンドルに必ず含める・2026-05-26 改訂）

各派生案 variant 単位で：

```
- variant: <派生案#／型>

- 総合 verdict: pass / needs_human_review / fail
- human_review_required: true/false（trueは田村目視）
```
