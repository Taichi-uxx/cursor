# YouTube — 鉄則・勝ち筋・負け筋

## 1. このドメインの本質

YouTubeは **「目的検索（What/How）」と「おすすめ発見」の2つのエンジンを同時に回す媒体**。
他のSNSが「タイムライン1本勝負」なのに対し、YouTubeは **検索（Google検索＋YouTube内検索）から長期的に拾われ続け、おすすめからも継続的に推薦される**。1本の動画が3年後も再生され続ける、唯一の**ストック型SNS**。さらに、**チャンネル単位での信頼蓄積**が新しい動画の初動を押し上げる、**フローとストックの両建てゲーム**。

この本質を分解すると、YouTubeは4つの構造ゲームの重ね合わせで成立している。

### 本質① 視聴時間＋CTRの二軸評価
YouTubeのアルゴリズムは **「サムネがクリックされる確率（CTR）」 × 「クリック後に長く見られるか（視聴時間・視聴維持率）」** の二軸で動画を評価する。CTRだけ高くて視聴時間が短いと「釣りサムネ」と判定され、視聴時間が長くてもCTRが低いと露出が増えない。**両方の最適化が必須**で、片方だけ高い動画は伸びない。

### 本質② サムネ × タイトルの組合せ最適化
YouTubeでは **動画の中身よりサムネ＋タイトルが先に見られる**。視聴者は0.5秒でサムネを判断し、1秒でタイトルを読み、クリックするかを決める。
ここでの勝負は「**サムネとタイトルの足し算ではなく、組合せで新しい意味を作る**」こと。サムネだけで完結する情報を載せると、タイトルが冗長になる。両者で1つのフックを作る設計力が問われる。

### 本質③ ユーザーの目的検索（What/How系）と発見（おすすめ）の二系統
YouTubeへの流入は大きく2つに分かれる。
- **目的検索**: 「〇〇 やり方」「△△とは」など、ユーザーが**答えを探しに来る**。検索意図が明確で、長期的に再生される
- **おすすめ発見**: 関連動画・トップページのおすすめ。視聴者は**たまたま流れてきた動画**を見る
両者は**最適な動画設計が異なる**。目的検索向けは「網羅性・正確性・構造化」、おすすめ発見向けは「驚き・物語・感情」。**狙う流入先で動画タイプを変える**設計が必須。

### 本質④ チャンネル単位の信頼蓄積
YouTubeはアカウント（チャンネル）単位での視聴履歴・登録者・継続視聴率を強く評価する。**「同じチャンネルの他の動画を見るか」「登録者が次の動画を見るか」**が、新動画の初動配信を決める。
これは諸刃で、**一貫したジャンル・キャラ・尺**を保てば信頼が雪だるま式に増える一方、**動画ごとにジャンルがブレるとチャンネル評価が下がる**。「動画単位」ではなく「**チャンネル単位の資産**」を作る発想が必要。

## 2. 鉄則（破ってはいけない）

> 表記凡例: 各項目末尾の **〈本質①〜④〉** は、その鉄則がどの本質に紐づくかを示す。

1. **サムネ＋タイトルに動画制作時間の30%を投じる** — 中身が良くてもクリックされなければ存在しない。**サムネはA/Bテストで複数案を比較**する。〈本質①②: CTRが入口の天井を決める〉

2. **冒頭30秒で視聴維持率の8割が決まる** — 冒頭で「この動画を見続けるとどんな価値があるか」を約束する。挨拶・自己紹介を冒頭に置かない。〈本質①: 視聴時間が配信を押し上げる〉

3. **目的検索動画と発見動画を「企画段階で」分ける** — 「〇〇のやり方」と「世界一周の感動エピソード」では脚本・尺・編集が違う。**同じ動画で両立させようとすると両方失敗**する。〈本質③: 流入別の設計分岐〉

4. **チャンネルのジャンル・キャラ・尺を一貫させる** — 動画ごとにジャンルがブレるとおすすめ配信が壊れる。**月単位でチャンネル全体を引いて評価**する。〈本質④: チャンネル単位の信頼蓄積〉

5. **動画の最後で次の動画への導線を作る** — エンドカード・終了画面・概要欄リンクで**チャンネル内回遊**を促す。1本見て終わるのではなく、2本目に繋ぐ。〈本質④: チャンネル滞在時間の最大化〉

6. **視聴維持率グラフを毎本確認する** — どこで離脱しているかが、編集改善の最大の情報源。**離脱ポイントが3本連続で同じなら、編集パターンを変える**。〈本質①: 視聴維持率の改善は仮説検証で〉

7. **Shortsは「Shorts単独で完結」させる** — Shortsから本編誘導は基本効かない。Shortsはあくまで**新規認知装置**として割り切り、本編とは別設計にする。〈本質③④: 流入の役割分担〉

## 3. 勝ち筋（再現性のある勝ちパターン）

### 勝ち筋A: 「目的検索独占」型の網羅動画
- **場面**: チャンネル初期・SEO的に強くなりたい
- **内容**: 検索ボリュームのある「〇〇 やり方」「△△とは」を1動画で網羅的に解説。10〜20分、構造化されたチャプター付き
- **なぜ勝てるか**: 〈本質③④〉目的検索は**長期的に毎月再生され続ける**ストック資産。1本作れば3年再生される動画になる。チャンネル内に複数本溜まると、**チャンネル登録者が雪だるま式に増える**。

### 勝ち筋B: 「体験追体験」型の発見動画（おすすめ流入）
- **内容**: 一人称・物語構造・感情曲線を意識した動画。世界一周・人生の選択・挑戦などのテーマに、**驚き・感動・転機**を脚本に組み込む
- **なぜ勝てるか**: 〈本質①③〉おすすめからの流入は「感情を動かされたか」で次の視聴・シェア・チャンネル登録が決まる。**情報伝達ではなく追体験**にフォーカスすると、視聴維持率もシェア率も跳ねる。田村のコンテンツ志向と最も相性が良い領域。

### 勝ち筋C: サムネ・タイトルの「組合せフック」設計
- **内容**: サムネは**視覚的な違和感**（表情・矢印・数字）、タイトルは**サムネを補強する一文**。両者を別々に最適化するのでなく、**組合せで意味が成立する**設計
- **なぜ勝てるか**: 〈本質②〉サムネだけで意味が完結するとタイトルが冗長になる。タイトルだけで意味が完結するとサムネが情報過多になる。**「両方見て初めて理解できる」設計**がCTRを最大化する。

### 勝ち筋D: シリーズ動画でチャンネル滞在を作る
- **内容**: 「〇〇シリーズ Part 1〜5」のように、関連動画を意図的に作る。エンドカード・再生リストでシリーズ視聴を促す
- **なぜ勝てるか**: 〈本質④〉YouTubeアルゴリズムは「チャンネル内で連続視聴された」シグナルを強く評価する。**1本視聴→続けて2本目視聴**が起きると、チャンネル全体の評価が押し上がる。

### 勝ち筋E: 公開直後24〜48時間の「初動最大化」
- **内容**: 公開直後にSNS（X/Instagram/LINE）で告知 → コミュニティ投稿で先行公開 → 高エンゲージメント層に最初に届ける
- **なぜ勝てるか**: 〈本質①④〉公開24〜48時間の視聴維持率・CTRがアルゴリズムの初期判定に強く効く。**最初の数千視聴が「コアファン」なら、視聴維持率が高くなり、その後の拡大配信に繋がる**。

## 4. 負け筋（典型的な失敗・地雷）

### 負け筋A: サムネ・タイトルが「内容説明」に終わる
- **症状**: CTRが2%以下、再生数が登録者数の10%未満
- **原因**: 〈本質①②〉「ノウハウ動画です」「日常動画です」のような中身の説明では、視聴者の指は止まらない。**フック（驚き・疑問・違和感）がない**。
- **回避策**: サムネは表情・数字・矢印で違和感を作る、タイトルは「結論の予告」「数字」「逆説」を入れる

### 負け筋B: 冒頭の挨拶・自己紹介が30秒を超える
- **症状**: 視聴維持率が冒頭1分で40%に急落
- **原因**: 〈本質①〉視聴者は「動画の本題」を見に来ている。挨拶・自己紹介は本題後半か、なくてもいい。
- **回避策**: 冒頭5秒以内に**本題の予告・最も面白い瞬間のチラ見せ**を入れる

### 負け筋C: ジャンルが動画ごとにバラバラ
- **症状**: 登録者数は伸びるが、新しい動画の初動が伸びない
- **原因**: 〈本質④〉「マーケティング動画→旅動画→料理動画」のようにジャンルがバラつくと、**YouTubeが「誰におすすめすべきか」判断できなくなる**。チャンネル評価が拡散して薄まる。
- **回避策**: 大ジャンルを1〜2本柱に絞る。チャンネル名・チャンネルアートでもジャンルを明確化

### 負け筋D: 目的検索向けと発見向けを混ぜた動画
- **症状**: 視聴維持率が中盤で大きく落ちる、コメントが「結論だけ知りたい」「冗長」と分かれる
- **原因**: 〈本質③〉目的検索層は「答えだけ欲しい」、発見層は「物語を体験したい」。同じ動画で両方狙うと**どちらの層も中途半端**になる。
- **回避策**: 企画段階で「これは目的検索動画」「これは発見動画」と決め打ちし、脚本・尺・編集を分ける

### 負け筋E: Shortsから本編登録に繋げようとする
- **症状**: Shortsはバズるが本編の登録者・再生数に繋がらない
- **原因**: 〈本質③④〉Shorts視聴者と長尺視聴者は**視聴姿勢が違う**（縦型短尺で消費 vs 横型長尺で没入）。Shortsで本編誘導しても継続視聴に繋がりにくい。
- **回避策**: Shortsは新規認知装置として割り切る。**Shortsからの登録者は別カウントで評価**し、本編KPIとは混ぜない

### 負け筋F: 概要欄・終了画面・カードを「設定しない」
- **症状**: 関連動画再生率・チャンネル登録転換率が伸びない
- **原因**: 〈本質④〉YouTubeは**チャンネル内回遊を支援する機能**を多数提供しているが、これを使わないと1本完結型の薄いチャンネルになる。
- **回避策**: 概要欄リンク・終了画面・カード・チャプターを全動画で必ず設定。再生リストも作成

## 5. 判断分岐（迷ったときの基準）

| 状況 | 取るべきアクション | 紐づく本質 |
|---|---|---|
| CTR 2%未満 | サムネ・タイトルを2案作りA/Bテスト | ②組合せ最適化 |
| CTRは高いが視聴維持率低い | 釣りサムネ判定リスク → 中身強化 | ①二軸評価のバランス |
| 視聴維持率が冒頭で急落 | 冒頭30秒の構成を全面見直し | ①視聴時間が配信を決める |
| 登録者数増えても再生伸びない | チャンネル一貫性・おすすめ配信を確認 | ④チャンネル単位評価 |
| 検索流入を増やしたい | キーワード狙い・網羅性ある長尺企画 | ③目的検索設計 |
| おすすめ流入を増やしたい | 物語型・感情型動画でシェア狙う | ③発見動画設計 |
| Shortsはバズるが本編伸びない | Shorts/本編の役割分担を明確化 | ③④流入別評価 |
| チャンネル全体が頭打ち | シリーズ化で滞在時間最大化 | ④チャンネル資産化 |

## 6. 実務チェックリスト

### 投稿前
- [ ] サムネ＋タイトルの組合せでフックが成立しているか 〈本質②〉
- [ ] 冒頭30秒で「価値の約束」と「本題予告」があるか 〈本質①〉
- [ ] 目的検索/発見のどちらを狙う動画か明確か 〈本質③〉
- [ ] 終了画面・カード・概要欄リンクが設定されているか 〈本質④〉

### 週次
- [ ] 公開動画のCTR・視聴維持率・平均視聴時間を確認 〈本質①〉
- [ ] 視聴維持率グラフで離脱ポイントを特定 〈本質①〉
- [ ] チャンネル登録率・関連動画再生率を確認 〈本質④〉

### 月次
- [ ] チャンネル全体を引いて見て「ジャンル一貫性」を確認 〈本質④〉
- [ ] 上位3動画・下位3動画の差分を抽象化 〈本質①②〉
- [ ] 検索流入動画 / おすすめ流入動画の比率を確認 〈本質③〉
- [ ] シリーズ化できる切り口を1つ新設 〈本質④〉
