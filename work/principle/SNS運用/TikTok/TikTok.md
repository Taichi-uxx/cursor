# TikTok — 鉄則・勝ち筋・負け筋

## 1. このドメインの本質

TikTokは **「フォロワー数を完全に無視し、1本ごとに動画を裸で評価する装置」**。
他SNSが「フォロワーに届ける」ためのアカウント装置なのに対し、TikTokは**For Youアルゴリズムが視聴者ごとに完全パーソナライズされた動画リストを作る**。フォロワー1人でも10万再生は起きるし、フォロワー10万でも300再生は起きる。**「アカウントを育てる」発想を捨て、「動画ごとに勝ちに行く」発想**に切り替えないと一生伸びない媒体。

この本質を分解すると、TikTokは4つの構造ゲームの重ね合わせで成立している。

### 本質① For Youアルゴリズムの完全パーソナライズ
TikTokは視聴者の過去視聴履歴（最後まで見た／途中離脱／いいね／シェア／プロフィール訪問）を完全に学習し、**1人1人異なる動画リスト**を生成する。フォロワー関係はアルゴリズム上ほぼ意味を持たない。
これは「**動画自体の質ですべて決まる**」ことを意味し、X/Instagramのような**過去フォロワー資産が初動を作る構造ではない**。毎本ゼロから勝負。

### 本質② 視聴維持率＋ループ＋シェアの三位一体
TikTokが評価する深いシグナルは **「動画完全視聴率」「複数回ループ視聴」「シェア／保存」** の3つ。いいねは軽い、フォローはオマケ。
特に「**最後まで見た上でもう1回見た**」は最強のシグナルで、これが起きる動画は数十万〜数百万再生に飛ぶ。逆に**冒頭2秒で離脱されると、その動画は死ぬ**。

### 本質③ フォロワー数の無関係性（裸の動画勝負）
TikTokの「次の動画が出る」順序は、フォロワー数の多寡ではなく**ユーザーの興味マッチで決まる**。よって過去にバズった人でも、今日の動画が弱ければ300再生で終わる。
これは諸刃で、**新規参入者にも初日から大バズの可能性がある**一方、**過去の実績は次の動画に効かない**。「動画1本のホームラン勝負」を毎本仕掛ける覚悟が必要。

### 本質④ トレンド乗り遅れの致命性
TikTokは**音源・編集テンポ・編集スタイル・ハッシュタグのトレンド寿命が極端に短い**（1〜3週間）。流行音源を使うと初動配信が大きく押し上げられるブースト効果がある一方、**流行を過ぎて使うと「古い感」で離脱率が跳ねる**。
この媒体は「今この瞬間に何が伸びているか」を毎週アップデートしないと、**動画の質が高くても媒体側の波に乗れず沈む**。

## 2. 鉄則（破ってはいけない）

> 表記凡例: 各項目末尾の **〈本質①〜④〉** は、その鉄則がどの本質に紐づくかを示す。

1. **最初の2秒に全投資する** — フックが弱い動画は3秒以内に8割が離脱。**冒頭で「これは何の動画か」を伝えず、視覚的・聴覚的に強い違和感を作る**。〈本質②: 視聴維持率が全評価の起点〉

2. **「フォロワー向け」の発信をしない** — フォロワーが見るのではなく、**For Youでたまたま流れてきた他人が見る**前提で作る。文脈依存の内輪ネタは死ぬ。〈本質①③: 裸の動画勝負で文脈共有はない〉

3. **動画長は「完全視聴される長さ」に最適化する** — 短くしすぎるとループ視聴狙いになるが情報密度が落ちる、長すぎると離脱する。**自分のジャンルの完全視聴率が最大化される尺**を探る。〈本質②: 視聴維持率最大化〉

4. **トレンド音源は「使う／作る」の両方を視野に** — 既存トレンド音源に乗るのが基本だが、独自音源がトレンドに乗れば**爆発的にリーチが伸びる**。〈本質④: 媒体側の波に主体的に絡む〉

5. **1日1本以上ではなく、週3〜5本の「完成度」を優先する** — 量で殴る運用は質を落としやすい。**1本の完全視聴率が次の動画の初動を決める**。〈本質②③: 動画単位評価の積み上げ〉

6. **コメントを「会話の場」にする** — TikTokはコメント返信動画・ピン留めコメント・コメント絡みで滞在を伸ばせる。**コメント欄は2本目の動画**として運営する。〈本質②: 滞在時間の二次レイヤー〉

7. **完全視聴率20%未満の動画はパターンとして即廃止** — 視聴維持率がジャンル平均を下回る編集テンポ・冒頭設計は、3本連続でダメなら方向転換。〈本質②③: ホームラン勝負を続けるための仮説検証〉

## 3. 勝ち筋（再現性のある勝ちパターン）

### 勝ち筋A: 「2秒フック × 7秒主張 × ループ動画」の三段構造
- **場面**: 新規アカウント立ち上げ・新ジャンル投入時
- **内容**: 0-2秒で強い違和感（疑問・断言・予想外の絵）→ 3-7秒で本題提示 → ラスト1秒を冒頭1秒に繋がる映像にしてループ視聴を狙う
- **なぜ勝てるか**: 〈本質②〉冒頭離脱を最小化し、完全視聴率→ループ視聴の最強シグナルを意図的に発生させる。**「もう一回見た」を構造的に作る**設計。

### 勝ち筋B: 「体験追体験型」縦型動画（一人称視点）
- **内容**: 主観カメラ・1人称ナレーションで、視聴者を**動画の中に連れていく**。世界一周・日常の出来事・思考プロセスを「視聴者自身が体験した気持ちになる」構成
- **なぜ勝てるか**: 〈本質②③〉TikTokは縦型・全画面・音ありで没入を生む唯一のSNS。**情報伝達ではなく追体験**を志向すると、視聴維持率とシェア率が両方上がる。田村のコンテンツ志向（人生を動かす発信）と最も相性が良い構造。

### 勝ち筋C: トレンド音源 × 独自切り口の掛け合わせ
- **内容**: 今週急上昇している音源に、自分のジャンル特有の文脈を乗せる。例: 流行ダンス音源に「広告運用あるある」を載せる、流行ナレーション音源に「世界一周中のシーン」を載せる
- **なぜ勝てるか**: 〈本質④①〉トレンド音源は媒体側の初動配信ブーストを得られ、独自切り口は For Youアルゴリズムが「新しいジャンル組合せ」として評価する。**媒体の波 × 個人の独自性**の掛け算が最強。

### 勝ち筋D: コメント返信動画で連作シリーズ化
- **内容**: 反応の良かった動画のコメントに「動画で返信」する機能を使い、シリーズ化。視聴者の質問・感想を起点に2本目・3本目を作る
- **なぜ勝てるか**: 〈本質①②〉For Youアルゴリズムは「同じ視聴者に類似動画を見せる」傾向があり、**シリーズ化すると同じ視聴者に複数本届く確率が上がる**。さらにコメントが視聴者参加型になり、滞在時間が伸びる。

### 勝ち筋E: 投稿後3時間の「初動シグナル監視」
- **内容**: 投稿後3時間で完全視聴率20%超 / 平均再生時間がジャンル平均超 / コメント発生があれば「拡大配信」フェーズに入る。基準未達なら次の動画の改善に集中
- **なぜ勝てるか**: 〈本質②③〉TikTokのアルゴリズムは初動3〜24時間で配信規模を段階的に判定する。**初動の数字をリアルタイムで読み、勝ち動画と負け動画を即仕分け**することで、次の打ち手の精度が上がる。

## 4. 負け筋（典型的な失敗・地雷）

### 負け筋A: 「フォロワーが増えたら伸びる」幻想
- **症状**: フォロワー1万人になったが、相変わらず動画は300〜1000再生
- **原因**: 〈本質①③〉TikTokはフォロワー数で初動配信が決まらない。**動画自体の質が伸びていなければ、フォロワーは何の救援にもならない**。
- **回避策**: フォロワー数指標を捨て、**1本ごとの完全視聴率・平均再生時間**だけを追う

### 負け筋B: 冒頭の「説明」「自己紹介」「BGMから入る」
- **症状**: 平均視聴時間が動画長の20%未満
- **原因**: 〈本質②〉冒頭2秒で離脱されると後の編集は全て無価値。「これから話します」「みなさんこんにちは」は最大級の地雷。
- **回避策**: 冒頭は**結論・違和感・予想外の絵**から始める。説明は本題後半に回す

### 負け筋C: 他SNSの動画をそのまま転載
- **症状**: 縦型ではない、テロップが読めない、音源がトレンドにない → 全動画300再生
- **原因**: 〈本質①④〉YouTube・Instagram用の横型動画や、過去音源動画はTikTokの**縦型全画面没入＋トレンド音源**という設計と噛み合わない。
- **回避策**: TikTok用に再撮影 or 再編集。**「使い回し」は媒体の前提を破壊する**

### 負け筋D: 投稿頻度を上げて1本あたりの質を落とす
- **症状**: 毎日投稿しているのに全動画1000再生未満
- **原因**: 〈本質②③〉低い完全視聴率の動画が連続すると、**アカウント全体の「興味スコア」が下がる**可能性が指摘されている（公式は明言していないが体感的事実）。
- **回避策**: 週3〜5本でいい。**完全視聴率がジャンル平均を超える動画**だけを公開する判断軸を持つ

### 負け筋E: トレンドを追わず「自分の作りたい動画」だけを作る
- **症状**: 過去の傑作1本だけバズり、その後は全く再現しない
- **原因**: 〈本質④〉TikTokは媒体側の波（音源・編集テンポ・トレンド）が初動配信に効く。**個人の表現意欲だけでは媒体側の追い風が得られない**。
- **回避策**: 毎週1回、急上昇音源・急上昇クリエイターを30分リサーチする時間を取る

### 負け筋F: ハッシュタグに過度に依存
- **症状**: 大規模HTを大量に付けるが伸びない
- **原因**: 〈本質①〉TikTokのアルゴリズムは**音源・動画内容の類似度**でカテゴリ判定するため、ハッシュタグの影響はInstagramより弱い。
- **回避策**: ハッシュタグは3〜5個に絞り、**動画内容と完全に一致するもののみ**。HT詰め込みは不要

## 5. 判断分岐（迷ったときの基準）

| 状況 | 取るべきアクション | 紐づく本質 |
|---|---|---|
| 平均再生時間が動画長の20%未満 | 冒頭2秒・編集テンポを全面見直し | ②視聴維持率の起点 |
| フォロワー増えても再生伸びない | フォロワー指標を捨て動画単位評価へ | ①③裸の動画勝負 |
| 1本バズって続かない | パターンを抽象化し再現実験 | ②③ホームラン勝負の再現性 |
| 完全視聴率は高いが拡散しない | シェア・コメント誘発設計を強化 | ②深いシグナル |
| 投稿しても300再生で止まる | 初動3時間の完全視聴率を確認 → 動画死亡判定 | ②③初動シグナル |
| 動画ジャンルがバラバラ | For Youの興味タグが分散している → ジャンル絞る | ①パーソナライズ精度 |
| トレンドに追いつけない | 週次でトレンド音源を必ずリサーチ | ④波に乗る義務 |
| ループ視聴を起こしたい | 冒頭1秒とラスト1秒を映像的に繋げる | ②ループ視聴設計 |

## 6. 実務チェックリスト

- [ ] 縦型・全画面・音源がトレンドに乗っているか 〈本質①④〉
- [ ] ループ設計（最後と最初が繋がる）になっているか 〈本質②〉

### 週次
- [ ] 各動画の平均再生時間・完全視聴率を確認 〈本質②〉

- [ ] 上位3動画・下位3動画の差分を抽象化 〈本質②③〉
