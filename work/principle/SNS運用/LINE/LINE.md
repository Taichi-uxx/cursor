# LINE — 鉄則・勝ち筋・負け筋

## 1. このドメインの本質

LINE公式アカウントは **「許可制プッシュ通知で、ユーザーの可処分注意を一方的に取れる唯一のチャネル」**。
他のSNSが「フィードに置いてもらえるか」のリーチ争いをしている一方、LINEは **友だち追加された瞬間、配信が必ず通知として届く**。だがその強さは諸刃で、**1通の重さが他SNSの100倍**ある。ブロックは不可逆、信頼を一度失えば二度と取り戻せない。**届ける力が強いほど、何を届けるかを慎重に選ぶ**媒体。

この本質を分解すると、LINEは4つの構造ゲームの重ね合わせで成立している。

### 本質① プッシュ通知のクローズドリーチ
LINEのメッセージは「友だち全員のスマホに通知として届く」。アルゴリズムによる選別が**ほぼ存在しない**ため、リーチ率は理論上ほぼ100%。これは他SNSにない圧倒的優位性であり、**「配信する＝届く」が成立する唯一の媒体**。
ただし、その確実性ゆえに「届かせる責任」がある。雑な配信は通知ストレスとして直接体感され、ブロックに繋がる。

### 本質② 友だち追加の摩擦（流入コストの高さ）
LINEは「ID追加・QRスキャン・友だち追加ボタン」など、必ず**ユーザーの意思決定が1ステップ挟まる**。Instagramのフォローや、Xのリポストのような「軽い接続」はない。
つまり1人の友だち追加は重い意思表示であり、追加してくれる人は **「自分の通知欄を渡してもいい」と判断したユーザー**。ここを軽く扱うと、追加直後にブロックされる。

### 本質③ ブロックの不可逆性
他SNSは「ミュート」「フォロー外し」など段階的離脱があるが、LINEは **ブロック1択で、しかも復活の手段がない**。一度ブロックされたユーザーには、二度とリーチできない。
この不可逆性が、配信頻度・配信内容の両面で **「迷ったら送らない」** という原則を強制する。X/Instagramの「とりあえず投稿」は、LINEでは絶対にやってはいけない。

### 本質④ セグメント配信の意義（一斉配信の限界）
全友だちに同じ内容を送る一斉配信は、必ず誰かに刺さらない。**「興味ない通知」が積み重なるとブロック**される。
LINEは属性・行動・タグでセグメントを切れる機能を持っており、これを使うか使わないかで**ブロック率・反応率が桁で変わる**。一斉配信は「最大公約数の薄い情報」しか送れず、結果として全員にとって価値の低い通知になる。

## 2. 鉄則（破ってはいけない）

> 表記凡例: 各項目末尾の **〈本質①〜④〉** は、その鉄則がどの本質に紐づくかを示す。

1. **配信頻度は「週1〜2通」が上限の目安** — 通知の重みを忘れた瞬間にブロック率が跳ねる。月10通超えはほぼ確実に離脱を生む。〈本質①③: プッシュの強さとブロック不可逆性の表裏〉

2. **友だち追加直後の「初回メッセージ」に最大の投資をする** — 追加直後はブロック率最高地点。**1通目で「この通知は来てよかった」と思わせる**ことが、その後の全配信の生死を決める。〈本質②③: 摩擦を越えて追加してくれた瞬間の体験設計〉

3. **「全員に送る」を疑う** — セグメント機能があるのに使わないのは、ブロックを自ら生んでいるのと同じ。配信前に「これは誰に向けた通知か」を必ず問う。〈本質④: 一斉配信は最大公約数で薄まる〉

4. **リッチメニューを「導線の司令塔」として使う** — トーク画面下部のリッチメニューは、唯一**ユーザー側からアクセスできる常設導線**。配信に頼らずユーザー主導でアクセスできる構造を持っているか。〈本質①: プッシュに頼らない接点を作る〉

5. **クーポン・割引を多用しない** — クーポン依存のアカウントは「値引き通知が来るアカウント」と認識され、本来伝えたい価値が刺さらなくなる。**価格訴求の通知は月1以下**に抑える。〈本質③: ブロックの原因第1位は「価値のない通知」〉

6. **ブロック率は「配信ごと」に追う** — 全体ブロック率ではなく、**どの配信でブロック率が跳ねたか**を追跡する。これが配信内容の良し悪しの最も率直なシグナル。〈本質③: ブロックは不可逆だからこそ予兆を計測する〉

7. **追加導線の文脈を揃える** — 「割引目当てで追加した友だち」に思想・コンテンツ配信をしてもブロックされる。**追加時の期待値と配信内容の一致**が継続率を決める。〈本質②④: 摩擦を越えた理由とセグメントは紐づく〉

## 3. 勝ち筋（再現性のある勝ちパターン）

### 勝ち筋A: 「ステップ配信」での初期信頼構築
- **場面**: 新規友だち追加直後
- **内容**: 追加直後 → 3日後 → 7日後 → 14日後の自動配信を組む。最初は自己紹介と価値提供、徐々に深い情報・オファーへ
- **なぜ勝てるか**: 〈本質②③〉追加直後の関心が最も高いタイミングを逃さず、信頼を段階的に積み上げる。手動配信に頼らず**「追加時点で関係構築が始まる」**設計にできる。

### 勝ち筋B: タグ × セグメント配信
- **内容**: 流入経路・興味カテゴリ・購入履歴でタグ付け → セグメント別に配信を分ける。「全友だちに同じ内容」を捨てる
- **なぜ勝てるか**: 〈本質④〉セグメント配信はクリック率が一斉配信の2〜5倍に達する事例が多い。**「自分宛て感」が反応率を桁で変える**。ブロック率も下がるため、長期で送れる総量が増える。

### 勝ち筋C: リッチメニューの「ハブ化」
- **内容**: トーク画面下部のリッチメニューに、よくある質問・最新情報・SNSリンク・予約フォームなど、**配信に頼らず自走するメニュー構成**を置く
- **なぜ勝てるか**: 〈本質①〉プッシュ通知を多用せずとも、ユーザーが自発的に情報を取りに来る導線が完成する。配信頻度を下げてもアカウント価値を維持できる構造。

### 勝ち筋D: 配信1通の「情報密度」最大化
- **内容**: 配信は週1〜2に絞り、その代わり1通に **「価値・体験・次のアクション」を必ず含める**。リッチメッセージ・カード型・動画も活用
- **なぜ勝てるか**: 〈本質①③〉LINEは「届く前提」だからこそ、**1通あたりの体験密度**が記憶を作る。「いつも来る薄い通知」ではなく「来ると嬉しい通知」になれば、ブロックされない・むしろ友人に紹介される。

### 勝ち筋E: 「双方向化」の仕組み導入
- **内容**: アンケート・チャットボット・キーワード応答で、**ユーザーが返信する設計**を組み込む
- **なぜ勝てるか**: 〈本質①②〉返信したことのあるユーザーはブロック率が桁で低い。「一方通行の通知」を「対話の場」に変えることで、LINEならではの **親密性ある関係**を作れる。

## 4. 負け筋（典型的な失敗・地雷）

### 負け筋A: 「とりあえず週3配信」のルーチン化
- **症状**: ブロック率が月3%超、3ヶ月で半数が消える
- **原因**: 〈本質①③〉ネタがないのに頻度だけ守ろうとして、薄い通知を量産。LINEで最もやってはいけない。
- **回避策**: 配信本数より配信の重さ。**1通の質を保てない週はスキップ**する判断を持つ

### 負け筋B: クーポン・割引配信の連発
- **症状**: クーポン配信時のみクリックされ、それ以外の通知は完全にスルー
- **原因**: 〈本質③〉アカウントが「クーポン配布マシン」と認識され、ブランド・思想を届けるチャネルとして機能しなくなる。
- **回避策**: クーポン配信は月1まで。残りは価値・体験・物語で構成する

### 負け筋C: 一斉配信のみで運用
- **症状**: クリック率が常時2%未満で頭打ち
- **原因**: 〈本質④〉最大公約数の通知は誰にも刺さらない。**「全員に通じる薄い情報」しか送れない**構造的限界。
- **回避策**: 最低3〜5セグメントに切る。タグ設計を最初に決める

### 負け筋D: 友だち追加導線と配信内容のズレ
- **症状**: 追加直後の3日以内ブロックが半数
- **原因**: 〈本質②④〉「無料相談」目当ての追加者にプロモーションを送る、「限定情報」目当ての追加者に勧誘を送るなどの**期待値ズレ**。
- **回避策**: 追加経路ごとにタグ付け → 経路別ステップ配信。最初の3通は**追加理由に直結する内容**だけ

### 負け筋E: ブロック率を「全体平均」でしか見ない
- **症状**: ブロックは増えているのに原因が特定できない
- **原因**: 〈本質③〉配信ごとのブロック率を見ないと、**どの内容が嫌われたか**が永遠に分からない。ブロックは不可逆だから、予兆計測が命綱。
- **回避策**: 配信単位のブロック率を毎週レビュー。跳ねた配信を抽象化し、二度と打たない

### 負け筋F: リッチメニューを「飾り」にする
- **症状**: 設置はしているが押されていない（タップ数が月10未満）
- **原因**: 〈本質①〉メニュー構成がユーザーの動線と無関係。配信依存になり、配信本数を増やさざるを得なくなる悪循環。
- **回避策**: メニューはユーザーが「**もう一度見たい/今すぐ使いたい**」と思う情報・機能に絞る。月次でタップ率を見直す

## 5. 判断分岐（迷ったときの基準）

| 状況 | 取るべきアクション | 紐づく本質 |
|---|---|---|
| ブロック率が月3%超 | 配信頻度・内容を即見直し | ③不可逆な離脱を止める |
| 配信のクリック率が落ちている | セグメント分割を進める | ④最大公約数からの脱却 |
| 友だち数は増えるが反応薄い | 追加導線と配信内容のズレ確認 | ②期待値の一致 |
| 配信ネタが枯れた | スキップ。打たない週を作る | ①③1通の重さを守る |
| クーポン以外への反応がない | 価値・物語配信を増やし依存解消 | ③アカウント認知の修正 |
| 配信本数を増やしたい | リッチメニュー強化で配信依存を下げる | ①ユーザー主導動線 |
| 新規追加が伸びない | 流入導線（QR/LP/SNS連携）を見直す | ②摩擦の最小化 |
| エンゲージメントを上げたい | 双方向化（アンケート/キーワード応答） | ①②対話への転換 |

## 6. 実務チェックリスト

### 配信前
- [ ] この配信は「誰に」向けたものか明確か 〈本質④〉
- [ ] ブロックされても惜しくない内容か（=本当に価値があるか） 〈本質③〉
- [ ] 1通に「価値・体験・次のアクション」が含まれているか 〈本質①〉
- [ ] 一斉ではなくセグメントで送れないか検討したか 〈本質④〉

### 週次
- [ ] 直近配信のブロック率を確認 〈本質③〉
- [ ] クリック率・既読率をセグメント別に確認 〈本質④〉
- [ ] リッチメニューのタップ率を確認 〈本質①〉

### 月次
- [ ] 追加経路別の継続率（30日後残存率）を確認 〈本質②〉
- [ ] 配信1通あたりの平均反応を昨月比でレビュー 〈本質①③〉
- [ ] タグ・セグメント設計を見直し（増減・統合） 〈本質④〉
