# Instagram — 鉄則・勝ち筋・負け筋

## 1. このドメインの本質

Instagramは **「ビジュアル一瞬で殴り、保存と滞在で居座らせる場所」**。
スクロール速度は1秒1枚。タイムラインに流れた瞬間に「指を止めさせる絵」がなければ、その投稿は存在しなかったのと同じ。一方で、指が止まった後は「**保存したくなる情報密度**」と「**もう一枚見たくなる連続性**」で評価される、**瞬発と粘着の二段ロケット**で動く媒体。

この本質を分解すると、Instagramは4つの構造ゲームの重ね合わせで成立している。

### 本質① ビジュアル選好アルゴリズム
Instagramは「画像/動画の見た目」を最初の評価軸にする。文字より絵、雑な絵より整った絵、整った絵より「世界観のある絵」。
ここで負けると、どれだけ中身が良くてもタップされない。**1枚目の表紙（カバー）が全コンテンツの入口**であり、テキスト系SNS（X/note）と最も違う点。世界観・色設計・フォントの統一が「無意識のブランド認知」を作る。

### 本質② 保存・滞在の重み（深いシグナル優先）
いいねは軽い、コメントはやや重い、**保存・シェア・滞在時間は最も重い**。Instagramは「もう一度見たい」「人に教えたい」と思わせた投稿を露出拡大する。
つまり消費される投稿（眺めて終わり）より、**辞書化される投稿（あとで使う）**が伸びる。1秒で消費される絵で指を止めさせ、その後10〜30秒「読ませる」構造に持ち込めるかが勝負。

### 本質③ フィード/ストーリーズ/Reelsの役割分担
3つの面はそれぞれ役割が違う。フィードは**資産（プロフィール訪問時の世界観形成）**、ストーリーズは**親密性（既存フォロワーとの日常接点）**、Reelsは**新規リーチ獲得（発見タブ・おすすめ流入）**。
ここを混同して「全部に世界観のあるフィード投稿だけ流す」運用は、新規が入らず既存も飽きる典型。**3面それぞれに別の役割を割り振る**のが原則。

### 本質④ ハッシュタグ＋発見タブの相互作用
ハッシュタグは「カテゴリ申告」、発見タブは「ユーザーの過去行動からの推薦」。
ハッシュタグだけで伸ばす時代は終わり、現在は **「過去の保存・滞在データ × ハッシュタグ申告 × ビジュアル類似度」** の3つで発見タブの推薦が決まる。ハッシュタグは「初動の方向付け」、発見タブは「中長期の獲得装置」と切り分けて運用する。

## 2. 鉄則（破ってはいけない）

> 表記凡例: 各項目末尾の **〈本質①〜④〉** は、その鉄則がどの本質に紐づくかを示す。

1. **1枚目（カバー）に投資の8割を寄せる** — カバーで止まらなければ中身は0点。文字載せ・色・余白の3点でA/Bテストする。〈本質①: ビジュアル選好の入口を制圧する〉

2. **保存される構造でコンテンツを作る** — 「あとで使える情報」「保存価値のあるリスト」「テンプレ化」。読み終わって完結するより、**読み終わって持ち帰らせる**。〈本質②: 深いシグナルが配信を決める〉

3. **3面（フィード/ストーリーズ/Reels）に別の役割を持たせる** — フィードは世界観、ストーリーズは親密性、Reelsは新規獲得。同じ内容を3面に流しても増えない。〈本質③: 役割分担が崩れると新規も既存も死ぬ〉

4. **プロフィール訪問時の「9枚グリッド」を意識する** — 個別投稿が伸びても、プロフィールに飛んで世界観が崩れていればフォローされない。**フォロー転換はグリッドで決まる**。〈本質①③: 資産としてのフィードはグリッド単位で評価される〉

5. **ハッシュタグは「規模違いを混ぜる」** — 巨大HT（100万件超）だけだと埋もれる、小規模HT（1万件未満）だけだと天井が低い。**大中小をミックス**して初動の方向付けをする。〈本質④: 発見タブへの橋渡しを設計する〉

6. **Reelsは「最初の3秒」で目的を伝える** — フィードと違いReelsは縦型・全画面・短尺。**3秒で「これは何の動画か」が分からないと離脱**。〈本質①②: ビジュアル瞬発＋視聴維持の二段で評価される〉

7. **発信者の顔・声・人格を出す** — 商品やノウハウだけの匿名アカウントは「保存対象」にはなっても「人格に紐づくファン」にはならない。世界一周や人生を動かす発信を志向するなら、**人格こそが最大の差別化**。〈本質②③: 親密性が継続視聴・シェアの源泉になる〉

## 3. 勝ち筋（再現性のある勝ちパターン）

### 勝ち筋A: 「カバー型」フィード投稿（保存特化）
- **場面**: 認知拡大・フォロワー獲得を狙う初期〜中期
- **内容**: 10枚カルーセル形式。1枚目=強いタイトル＋ビジュアル、2〜9枚目=具体ステップ、10枚目=保存促し＋プロフィール誘導
- **なぜ勝てるか**: 〈本質②〉カルーセルは滞在時間が伸びやすく、保存される確率が単発画像より高い。「あとで読む」装置として機能する。

### 勝ち筋B: Reels × フィードの「両面切り出し」
- **内容**: Reelsで新規流入を取り、フィードで世界観を固定する。Reelsを編集した静止画（カバー絵）をフィードにも置き、訪問者がプロフィールに飛んだときに「動画と静止画の世界観が地続き」になっているようにする
- **なぜ勝てるか**: 〈本質③〉Reelsで来た新規が「プロフィール→フィード」に飛んだとき、世界観の一貫性がフォロー判断を決める。新規獲得（Reels）と転換装置（フィード）の役割分担が明確化する。

### 勝ち筋C: 「体験追体験型」のストーリーズ毎日更新
- **場面**: 既存フォロワーとの関係構築・ファン化
- **内容**: 旅・日常・思考プロセスを「いま起こっていること」として連投。質問スタンプ・投票で会話を作る
- **なぜ勝てるか**: 〈本質②③〉ストーリーズの返信・閲覧完了率は「親密度シグナル」となり、フィード投稿の初動配信を押し上げる。**ストーリーズが既存リーチを温め、フィード/Reelsの初速を稼ぐ**構造。

### 勝ち筋D: 「世界観の固定パターン」を3〜5個に絞る
- **内容**: 構図・色・フォント・テンプレを「3〜5パターン」に固定し、それを循環させる。全投稿が違うデザインだとブランドにならない
- **なぜ勝てるか**: 〈本質①④〉発見タブの推薦は「ビジュアル類似度」も評価する。デザイン統一は人間の認知（覚えやすさ）にもアルゴリズム（類似推薦）にも効く二重の利得がある。

### 勝ち筋E: 投稿後24時間の「滞在最大化動線」
- **内容**: 投稿直後にストーリーズで投稿告知 → 質問スタンプで投稿に絡む質問を募集 → コメント返信で深い会話 → DMで個別フォロー
- **なぜ勝てるか**: 〈本質②〉投稿後24時間の深いシグナル（保存・コメント・DM・滞在）がアルゴリズム評価のピーク。**最初の1日に密度を寄せる**運用が伸び率を決める。

## 4. 負け筋（典型的な失敗・地雷）

### 負け筋A: 「いいね数」だけで投稿評価
- **症状**: いいね数は伸びるがフォロワー増えない、外部誘導も死ぬ
- **原因**: 〈本質②〉いいねは最も軽いシグナル。**保存・シェア・プロフィール訪問数を見ない運用は、表層だけ見て判断している**。
- **回避策**: 評価軸は「保存数/リーチ」「プロフィール訪問数」「フォロー転換率」の3つに置く

### 負け筋B: フィード・ストーリーズ・Reelsで同じものを流す
- **症状**: 既存フォロワーの反応が薄れ、新規も入らない
- **原因**: 〈本質③〉3面の役割を無視すると、ストーリーズの親密性も、Reelsの新規獲得も両方失われる。
- **回避策**: 3面に別コンテンツ。最低でも「Reels=切り出し、ストーリーズ=裏側、フィード=完成形」の役割を分ける

### 負け筋C: 投稿頻度を上げて質を落とす
- **症状**: 投稿数増やしたのにフォロワー減少
- **原因**: 〈本質①②〉カバーで止まらない投稿、保存されない投稿を増やすと、**アカウント全体の質的評価が下がる**。Instagramは「アカウント単位の平均エンゲージメント率」も見ている。
- **回避策**: 週3で良いカバー＞週7で凡庸。**頻度より1投稿の保存率を優先**

### 負け筋D: ハッシュタグを30個MAXで詰める
- **症状**: リーチが伸びない、シャドウバン疑惑
- **原因**: 〈本質④〉現在のアルゴリズムでは「過剰な大規模HTのみ」「無関係HT」はスパム判定対象。発見タブの推薦からむしろ外れる。
- **回避策**: 10〜15個に絞る。**大規模3：中規模5：小規模5** のミックスで方向付けを明確にする

### 負け筋E: フォロワー数が増えてもエンゲージメントが伸びない（数だけ追う）
- **症状**: 1万フォロワーいてもいいね100、保存10
- **原因**: 〈本質②〉相互フォロー・キャンペーンで集めたフォロワーは保存・シェアしない。**アクティブ率の低いフォロワーはアカウント評価を下げる**。
- **回避策**: 「人格に紐づくファン」を集める設計（顔・声・思想の発信）。数より深さ

### 負け筋F: 「商品紹介だけ」のフィード
- **症状**: 投稿は綺麗だがフォローされない
- **原因**: 〈本質②③〉商品情報は「保存」されるが「親密性」が育たない。世界一周や人生発信を志向するなら、**人格・思想・体験**がコアになる。
- **回避策**: 商品/情報7：人格/体験3 のミックス。プロフィール訪問時に「何屋か」だけでなく「誰か」が伝わる構成にする

## 5. 判断分岐（迷ったときの基準）

| 状況 | 取るべきアクション | 紐づく本質 |
|---|---|---|
| リーチは出るがフォローされない | プロフィール・グリッドを修正 | ①③世界観の入口 |
| いいねは多いが保存ゼロ | 「保存される情報設計」に変える | ②深いシグナル |
| Reelsが伸びない | 最初の3秒・縦型最適化を見直す | ①②瞬発と維持 |
| フィード投稿の初動が弱い | ストーリーズで投稿前後を温める | ②③親密性で初速作る |
| ハッシュタグ流入ゼロ | 大中小ミックスに変える | ④初動の方向付け |
| エンゲージメント率1%未満 | フォロワー質を疑う、整理する | ②アカウント平均評価 |
| Reels新規は来るがフォロー残らない | フィードの世界観・固定3〜5パターン化 | ①③転換装置を直す |
| 既存フォロワーの反応が冷めた | ストーリーズ毎日・対話設計 | ③親密性の毎日積立 |

## 6. 実務チェックリスト

### 投稿前
- [ ] カバー1枚目で「何の投稿か」が3秒で伝わる 〈本質①〉
- [ ] 保存される理由（リスト/テンプレ/まとめ）が含まれている 〈本質②〉
- [ ] グリッド配置で世界観が崩れない 〈本質①③〉
- [ ] ハッシュタグ大中小ミックスで10〜15個 〈本質④〉

### 週次
- [ ] 保存数/リーチ・プロフィール訪問数・フォロー転換率を見る 〈本質②〉
- [ ] ストーリーズの閲覧完了率と返信数を確認 〈本質③〉
- [ ] Reelsの平均視聴時間と最初の3秒離脱率を確認 〈本質①②〉

### 月次
- [ ] グリッドを引いて見て「世界観統一」を再評価 〈本質①〉
- [ ] 上位3投稿・下位3投稿の差分を抽象化 〈本質②④〉
- [ ] フォロワー属性（地域・年齢・性別）と発信方向のズレを確認 〈本質④〉
