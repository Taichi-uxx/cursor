# 店舗業界 — 鉄則・勝ち筋・負け筋

## 1. このドメインの本質

店舗ビジネスは **「物理的距離が需要を支配する市場」**。
WEB広告の手法をそのまま流用すると、商圏外のクリックで予算が溶ける。リスティングもSNS広告も「半径◯km」「徒歩◯分」というローカル制約の前で再設計される必要がある。さらに **「来店」というアクションは「クリック」より圧倒的に重いCV** であり、認知→興味→比較→**来店決断** という階段が他業界より長い。

この本質を分解すると、店舗市場は4つの構造ゲームで動いている。

### 本質① 商圏ゲーム（物理距離が需要天井を決める）
店舗の顧客は **9割が半径2〜5km以内**（飲食は2km、美容室は3km、家電量販は10km等業態で異なる）。
商圏外にいくら広告を打っても来店しない。**「ターゲットエリア × 商圏内人口 × 来店頻度」が売上の数学的天井**で、この上限を超える施策は存在しない。商圏分析を飛ばした集客施策は構造的にズレる。

### 本質② Google Map（MEO/GMB）支配ゲーム
店舗検索の70%以上がGoogle Map経由（業態によっては90%超）。
ユーザーは「渋谷 ラーメン」で検索 → Mapパック（上位3件）から選ぶ。**この上位3枠を取れるかどうかが集客の8割を決める**。リスティング広告より、Googleビジネスプロフィール最適化（写真・口コミ・営業情報・カテゴリ）への投資効率が高い場面が多い。

### 本質③ 口コミ依存度ゲーム
店舗は **「行ったことのない場所への不安」を口コミで埋める市場**。
Google・食べログ・ホットペッパーの星評価が3.5未満だと来店CVRが半減。**口コミは広告では買えない資産**で、店舗運営の質が直接マーケに跳ね返る。「広告で連れてきても、口コミが悪ければ覆せない」。

### 本質④ 来店動線ゲーム（クリック→来店の橋）
店舗ビジネスのCVは「電話予約」「Web予約」「来店」のいずれか。**クリック後の動線設計が他業界より複雑**。
ユーザーは「営業時間」「アクセス（駅から徒歩○分）」「駐車場の有無」「予約必須か」を確認してから動く。これらの情報が広告/LPで一発で見えないと「明日でいいか」で離脱する。**情報の即時開示が来店CVRを左右する**。

## 2. 鉄則（破ってはいけない）

> 表記凡例: 各項目末尾の **〈本質①〜④〉** は、その鉄則がどの本質に紐づくかを示す。

1. **広告配信地域を必ず商圏内に絞る** — 半径設定／市区町村指定／除外設定を必須。デフォルトの広域配信は予算の半分を捨てる。〈本質①: 商圏外クリックは構造的に来店しない〉

2. **Googleビジネスプロフィール（GBP/旧GMB）整備を広告より優先する** — 写真・営業時間・カテゴリ・属性の3層を最初に固める。〈本質②: MEO投資効率は広告より高い場面が多い〉

3. **口コミ返信を全件、48時間以内に実施する** — 返信率は検索順位の評価要素であり、ユーザーの信頼判断にも直結する。〈本質②③〉

4. **写真は最低30枚、店内・料理・スタッフ・外観の4カテゴリ揃える** — 写真の質と量はGBP評価・口コミ後押しの両面で効く。〈本質②③〉

5. **営業時間・住所・電話番号・地図リンクをLP上部に必ず配置する** — 来店動線で最重要の情報を埋めない。〈本質④: 即時情報開示〉

6. **景表法の「価格・特典」表現に注意する** — 「半額」「○○%OFF」は元値の根拠（最近4週間の販売実績）が必須。飲食の「ボリューム」「素材産地」も誇大表現NG。〈本質①②: 法的リスクとMEO評価への影響〉

7. **新規来店CPAではなく「来店からのLTV」で考える** — 飲食なら年間来店回数、美容なら次回予約率まで遡る。〈本質①③: 商圏内顧客は固定母数なので、深耕戦略がROIを決める〉

## 3. 勝ち筋（再現性のある勝ちパターン）

### 勝ち筋A: GBP × 口コミ獲得施策の2軸基盤
- **場面**: ローカル集客全般
- **内容**: GBP最適化（写真・カテゴリ・属性）＋ 来店客への口コミ依頼フロー（QR・LINE・帰り際の声かけ）
- **なぜ勝てるか**: 〈本質②③〉Mapパック上位3枠を取れれば広告ゼロでも集客できる。広告は補助、MEOが本丸。

### 勝ち筋B: 「徒歩○分」「駅近」訴求 × エリア絞り込み広告
- **内容**: 駅名・ランドマーク + 業種でターゲティング、徒歩何分を広告文に必ず入れる
- **なぜ勝てるか**: 〈本質①④〉「最も近い店」が選ばれる市場。距離が勝負を決める変数なので、最初に開示する。

### 勝ち筋C: 平日昼・夜・週末で別キャンペーン設計
- **内容**: 平日昼=ランチ訴求、夜=飲み訴求、週末=ファミリー訴求と時間帯別に分離
- **なぜ勝てるか**: 〈本質①〉時間帯で来店者層が完全に変わる。同一クリエイティブだと最大公約数化して全部弱くなる。

### 勝ち筋D: Instagram位置情報投稿 × ローカルハッシュタグ
- **内容**: 来店客のInstagram投稿を促す（特典付き）、ローカルハッシュタグ（#渋谷ランチ等）で発見性を確保
- **なぜ勝てるか**: 〈本質③〉口コミの代替として、リアルタイムの「実体感」が信頼を作る。広告で買えない発見経路を作れる。

### 勝ち筋E: 雨の日／天候別広告配信
- **内容**: 雨予報日は屋内型店舗（カフェ・カラオケ）の広告強化、晴れの日は屋外型（テラス・観光）
- **なぜ勝てるか**: 〈本質①④〉外的要因が来店意向を直撃する市場。天候連動は他業界より効果が露骨に出る。

## 4. 負け筋（典型的な失敗・地雷）

### 負け筋A: 商圏外への広告配信放置
- **症状**: クリック数・CPC好調なのに来店ゼロ
- **原因**: 〈本質①〉全国配信や広域配信で予算が商圏外に流れる
- **回避策**: 半径2〜5km / 市区町村単位で配信、除外設定で他県を切る

### 負け筋B: GBP放置（写真3枚・営業時間古い）
- **症状**: 検索しても上位に表示されない、表示されても選ばれない
- **原因**: 〈本質②〉MEO評価が低くMapパックから外れる
- **回避策**: 写真30枚、営業時間更新、属性記入、口コミ返信を週次運用化

### 負け筋C: 口コミ星3.0未満で広告に投資
- **症状**: クリックは来るが来店しない
- **原因**: 〈本質③〉広告で連れてきても、口コミ確認で離脱
- **回避策**: 広告予算の前に運営改善（接客・清潔・料理）と口コミ獲得施策

### 負け筋D: LPで営業時間・アクセスが見つけにくい
- **症状**: 直帰率80%超、電話・予約に至らない
- **原因**: 〈本質④〉来店判断に必要な情報を1スクロール以内に置いていない
- **回避策**: ファーストビューに住所・営業時間・地図・電話ボタンを固定

### 負け筋E: 「○○%OFF」を根拠なく表記
- **症状**: 景表法の有利誤認、消費者庁措置命令
- **原因**: 〈本質①〉二重価格表示は元値の販売実績が必要
- **回避策**: 「通常価格」の販売実績（直近4週間以上）を確保してから訴求

### 負け筋F: 新規CPAだけ追って常連離れ
- **症状**: 新規は取れるが売上横ばい、客単価低下
- **原因**: 〈本質①③〉商圏内人口は有限なので、深耕戦略を持たないと天井打ち
- **回避策**: 既存客のLTV施策（会員カード・再来店クーポン）を新規施策と同等の予算配分

## 5. 判断分岐（迷ったときの基準）

| 状況 | 取るべきアクション | 紐づく本質 |
|---|---|---|
| クリック多いが来店なし | 配信エリア設定を半径◯kmに修正 | ①商圏外漏れ |
| 検索しても店が出ない | GBP最適化を最優先 | ②MEO起点 |
| 口コミ★3.5未満 | 広告停止し運営改善優先 | ③口コミ覆せず |
| 来店CVR低い | LPの営業時間・地図を再配置 | ④情報開示 |
| 集客頭打ち | 商圏内人口を確認、深耕戦略へ | ①天井打ち |
| 価格訴求したい | 元値の販売実績を準備してから | ①景表法 |
| 競合店舗が増えた | 差別化軸（メニュー・特典）の再設計 | ②③相対勝負 |
| 雨／天候で来店激減 | 天候連動広告で予算配分動的化 | ①④外的要因 |

## 6. 実務チェックリスト

### 立ち上げ時
- [ ] 商圏分析（半径・人口・競合密度）を完了したか 〈本質①〉
- [ ] GBP（写真30枚・カテゴリ・属性・営業時間）を整備したか 〈本質②〉
- [ ] 口コミ獲得フローを店舗側で組み込んだか 〈本質③〉
- [ ] LPに住所・営業時間・地図・電話を上部配置したか 〈本質④〉
- [ ] 広告配信エリアを商圏内に限定したか 〈本質①〉

### 週次運用
- [ ] 新規口コミに48時間以内に返信したか 〈本質②③〉
- [ ] GBP写真を3枚以上追加したか 〈本質②〉
- [ ] 配信地域別の来店CVRを確認したか 〈本質①〉

### 月次運用
- [ ] Mapパック表示順位の推移を確認したか 〈本質②〉
- [ ] 口コミ平均★・件数を競合と比較したか 〈本質③〉
- [ ] 商圏内シェア・既存客LTVを試算したか 〈本質①〉
