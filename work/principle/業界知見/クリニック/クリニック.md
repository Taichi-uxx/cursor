# クリニック業界 — 鉄則・勝ち筋・負け筋

## 1. このドメインの本質

クリニックは **「医療広告ガイドラインに縛られながら、医療不信の壁を越える」市場**。
身体に侵襲を伴う意思決定なので、ユーザーは普通の商品よりも何倍も慎重。だが医療法・医師法は **「効果」「専門性」「実績」を訴求することを構造的に制限している**。「やりたいことが法的にできない」業界。広告ではなく、信頼形成・コンテンツ・口コミの総合戦になる。

この本質を分解すると、クリニック市場は4つの構造ゲームで動いている。

### 本質① 医療広告ガイドラインゲーム（医療法6条の5）
クリニック広告は **2018年医療法改正で大幅に厳格化**。
「絶対安全」「最新」「最高水準」「No.1」がNG、Before/After画像も「治療内容・費用・主なリスク」併記がなければ違反、患者の体験談（口コミ・LP内）は **原則禁止**（限定解除要件あり）。**広告で訴求できる項目が法律で「ホワイトリスト化」されている**ため、他業界のクリエイティブセオリーがほぼ通用しない。

### 本質② 医療不信ゲーム（侵襲への恐怖）
医療は **「失敗が取り返しのつかない結果を生む」市場**。
特に美容医療・歯科・整形は「やってから後悔」事例がネットに溢れる。ユーザーは「医師の経歴」「症例数」「料金の透明性」「アフターフォロー」「リスク説明」を執拗にチェック。**信頼を作るのは派手な訴求ではなく、誠実な情報量と実績の可視化**。

### 本質③ 専門性訴求の制約ゲーム
医師法・医療広告ガイドラインで **「専門医」「指導医」の名乗りは認定機関のリストに制限される**。
「美容専門医」「シミ治療のスペシャリスト」など自称専門性はNG。学会発表・論文・所属学会の **客観的事実のみ訴求可**。「医師の権威性で売る」が他業界より圧倒的に難しい。

### 本質④ 高額自由診療ゆえのLTVゲーム
自由診療は単価10万〜100万円。**「1人を獲得するCPAは高く設定できる」が、その分競合も予算をぶつけてくる**。
さらにクリニック経営は「初回客→継続治療→紹介」のLTV構造で成立する。新規CPAだけ見ると判断を誤る。**継続率・紹介率・客単価まで含めたLTV計算が必須**。

## 2. 鉄則（破ってはいけない）

> 表記凡例: 各項目末尾の **〈本質①〜④〉** は、その鉄則がどの本質に紐づくかを示す。

1. **「絶対安全」「最新」「最高」「No.1」など最大級表現を使わない** — 医療広告ガイドライン明確違反。〈本質①: 医療法6条の5〉

2. **患者の体験談は限定解除要件（自由診療・治療内容・費用・リスク併記等）を全て満たさない限り掲載しない** — LP内のお客様の声、口コミ転載もNG。〈本質①〉

3. **Before/After画像は「治療内容・費用・主なリスク」を同一画面で併記する** — 一方だけの掲載は違反。〈本質①〉

4. **専門医・指導医の名乗りは認定機関（日本専門医機構等）のリストに限定** — 自称表現は使えない。〈本質①③〉

5. **症例写真・実績数値は客観的根拠と出典を明示する** — 「症例10,000件」と書くなら年度・出典・算定方法を明記。〈本質①③〉

6. **料金は税込・追加費用込みで完全に開示する** — 「初診料別」「麻酔代別」が後出しだとクレーム・行政指導の対象。〈本質②④: 信頼破壊リスクが致命的〉

7. **新規CPAではなく「継続患者LTV」をKPIに置く** — 自由診療は継続前提のビジネス。初回だけの黒字化は不可能。〈本質④〉

## 3. 勝ち筋（再現性のある勝ちパターン）

### 勝ち筋A: 「無料カウンセリング」CTA × 透明な料金表
- **場面**: 美容皮膚科・美容外科・歯科自由診療
- **内容**: 全プランの料金表（追加費用込み）を完全開示、CVは無料カウンセリング
- **なぜ勝てるか**: 〈本質②④〉価格不透明への不信が最大の壁。透明化は信頼獲得と来院ハードル低下を同時達成。

### 勝ち筋B: 医師の経歴・所属学会・論文の客観情報訴求
- **内容**: 院長の卒業大学・所属学会・論文・症例数（客観根拠付き）をLPトップで明示
- **なぜ勝てるか**: 〈本質②③〉自称専門性が禁じられている分、客観実績の積み上げが信頼を作る唯一の方法。

### 勝ち筋C: 治療プロセス・リスクの詳細解説コンテンツ
- **内容**: 治療法ごとに「適応／非適応」「ダウンタイム」「副作用」「失敗例」まで詳細解説するコラム/動画
- **なぜ勝てるか**: 〈本質②〉ネガティブ情報も含めた誠実な解説が「信頼できる医師・クリニック」のポジショニングを作る。SEOにも効く。

### 勝ち筋D: 限定解除要件を満たした症例ページの整備
- **内容**: 治療内容・費用・主なリスク・副作用を併記した症例ページを症例数百件規模で整備
- **なぜ勝てるか**: 〈本質①②〉ガイドライン適合範囲内でBefore/After資産を構築。SEOと信頼形成を同時に効かせる。

### 勝ち筋E: LINE公式 × 予約・カウンセリングフォロー
- **内容**: LINE登録→24時間以内にカウンセラーがフォロー→予約日決定の動線
- **なぜ勝てるか**: 〈本質②④〉医療は「不安解消の対話」がCV直前で決定的。電話より心理ハードルの低いLINEがCVR2〜3倍。

## 4. 負け筋（典型的な失敗・地雷）

### 負け筋A: 「絶対安全」「最新治療」「業界最大級」
- **症状**: 医療広告ガイドライン違反、自治体指導、保健所立入
- **原因**: 〈本質①〉最大級表現の明確な違反
- **回避策**: 「機械を使用」「○○認可治療」など事実ベースの訴求に統一

### 負け筋B: 患者の体験談・口コミをLPに掲載
- **症状**: 医療広告ガイドライン違反指摘
- **原因**: 〈本質①〉限定解除要件未充足での体験談掲載
- **回避策**: 体験談を掲載しない、もしくは限定解除要件4項目を全て満たす

### 負け筋C: 「専門医」自称
- **症状**: 認定機関リスト外の専門医表記で違反
- **原因**: 〈本質①③〉日本専門医機構等の認定機関リストに掲載されていない肩書きの使用
- **回避策**: 客観的に認定された資格のみ表記、その他は学会所属・論文等で代替

### 負け筋D: 後出し追加料金（麻酔代・初診料・薬代別）
- **症状**: 来院後のクレーム、契約解除、クチコミ大悪化
- **原因**: 〈本質②④〉信頼の核である料金透明性を裏切る
- **回避策**: 総額提示、追加可能性ある項目は全て事前明示

### 負け筋E: 新規CPAだけで採算判断
- **症状**: 新規CPAは目標達成だが事業赤字
- **原因**: 〈本質④〉自由診療の利益構造は継続治療と紹介が中心
- **回避策**: 来院後の継続率・紹介率を月次KPI化

### 負け筋F: SEOコラムを医療広告ガイドライン非適用と誤解
- **症状**: 自社サイト内コラムでガイドライン違反
- **原因**: 〈本質①〉自院サイト・コラム・LPも医療広告に該当する
- **回避策**: 全コンテンツをガイドライン適合チェック後に公開

## 5. 判断分岐（迷ったときの基準）

| 状況 | 取るべきアクション | 紐づく本質 |
|---|---|---|
| 「最高」「最大級」表現使いたい | 即削除、事実ベース表現へ | ①医療広告違反 |
| 患者の声を載せたい | 限定解除4要件を全て満たすか確認 | ①体験談規制 |
| Before/After使いたい | 治療内容・費用・主なリスクを同一画面併記 | ①画像要件 |
| 専門医名乗りたい | 認定機関リスト在籍を確認 | ①③肩書き要件 |
| CVR低い | 料金透明化・医師経歴掲載を優先 | ②④信頼形成 |
| 新規CPA好調・事業赤字 | 継続患者LTV/紹介率を月次KPI化 | ④LTV設計 |
| 競合より高CPC | 訴求軸を「説明丁寧」「カウンセリング無料」へ転換 | ②差別化 |
| 自社サイトのコラム作成 | 医療広告ガイドライン適合チェック | ①対象範囲 |
