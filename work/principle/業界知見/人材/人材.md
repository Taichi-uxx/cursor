# 人材業界 — 鉄則・勝ち筋・負け筋

## 1. このドメインの本質

人材業界は **「求人広告ではなく、人生の意思決定を扱う市場」**。
ユーザーは「年収」「働き方」「自己実現」「家族の生活」を天秤にかけ、半年〜1年単位で動く。広告の役割は「説得」ではなく「**意思決定の最後の一押し**」と「**比較検討の土俵に上がる**」こと。応募CVは入口に過ぎず、収益は採用決定（人材紹介）／応募数→面接化率（求人広告）まで遠い。

この本質を分解すると、人材市場は4つの構造ゲームで動いている。

### 本質① 需給ゲーム（有効求人倍率の支配）
人材は **景気・労働人口・職種需給で容易に天井が動く市場**。
2024年以降、エンジニア・介護・建設は売り手市場（求人倍率2.0倍超）、事務系は買い手市場と二極化。「求人広告にいくら積んでも候補者が枯れている」は構造側の問題で、施策では解けない。**まず需給を読まないと施策はすべて空転する**。

### 本質② 候補者の心理的ハードルゲーム
転職は **「現職を捨てる恐怖 × 未来への期待」のせめぎ合い**。
クリック→応募の間に「履歴書を書く」「面接日程調整」「家族に話す」という重い行為が挟まる。CVR1〜3%が標準なのはこのため。広告コピーで「年収」「残業」「人間関係」のどれを下げるかが応募の摩擦を直撃する。**摩擦を下げた者が勝つ市場**。

### 本質③ 規制ゲーム（職業安定法・労基法・性差別禁止）
人材広告は **広告というより「公的責任を伴う情報開示」**。
職業安定法第5条の3で「労働条件の明示義務」、男女雇用機会均等法で「性別を限定する表現の禁止」（「営業マン」「看護婦」「主婦歓迎」はNG）、年齢制限も原則禁止（雇用対策法10条）。違反は媒体審査落ち＋行政指導。**「攻めたコピー」が法的に書けない市場である**ことを前提に設計する。

### 本質④ LTVが「採用決定単価」で動くゲーム
人材紹介は成果報酬（年収の30〜35%）、求人広告はクリック・掲載課金だが、依頼主側のKPIは **「応募数」ではなく「採用1人あたりコスト」**。
応募が100件来ても全員ミスマッチなら0円。**CVではなく「採用決定可能性のある応募」まで遡って設計する**必要があり、ターゲット解像度が成果を決める。マッチしない応募を量産する施策は短期数字を作っても契約解除を招く。

## 2. 鉄則（破ってはいけない）

> 表記凡例: 各項目末尾の **〈本質①〜④〉** は、その鉄則がどの本質に紐づくかを示す。

1. **年齢・性別・国籍を限定する表現は使わない** — 「20代活躍中」「女性が輝く職場」も媒体審査で落ちる。例外要件（芸能・防犯等）以外は法令違反。〈本質③: 雇用対策法・均等法の絶対要件〉

2. **労働条件は広告内に明示する** — 給与レンジ・勤務地・就業時間・雇用形態を曖昧にしない。「給与応相談」だけはNG。〈本質③: 職安法5条の3、媒体審査の前提〉

3. **需給を読む前に予算を増やさない** — 求人倍率が高い職種で予算倍増しても応募は増えない。施策ではなく市場を見る。〈本質①: 検索量／登録者数の天井に施策は勝てない〉

4. **応募数ではなく「マッチ応募数」をKPIに置く** — 量だけ追うとクライアントの採用コストが悪化し、契約解除につながる。〈本質④: 採用決定までの遠い距離を逆算する〉

5. **「現職への不満」を煽るコピーは短期効果あり、長期で逆効果** — 不満動機で来た候補者は早期離職率が高く、紹介手数料返金規定（3〜6ヶ月以内退職で返金）に直撃する。〈本質②④: 摩擦を下げても、決断質が悪いとLTVが崩れる〉

6. **応募フォームは項目10個以内に絞る** — 履歴書相当の入力を要求すると応募CVRが半減する。〈本質②: 心理的ハードルの最大値はフォーム〉

7. **ペルソナを「現職・年齢・年収・通勤可能エリア」の4軸で必ず定義する** — どれか1つでも欠けるとマッチしない応募が量産される。〈本質④: マッチ精度はターゲット解像度の関数〉

## 3. 勝ち筋（再現性のある勝ちパターン）

### 勝ち筋A: 「現職比較」訴求での比較検討層獲得
- **場面**: 認知はあるが応募が伸びない中堅クライアント
- **内容**: 「年収」「残業時間」「リモート可否」を現職と比較できる表をLP上部に配置
- **なぜ勝てるか**: 〈本質②〉転職は「現職との差分計算」で意思決定される。差分が可視化されると比較検討の認知負荷が下がり、応募ハードルが落ちる。

### 勝ち筋B: 求人倍率の低い職種で「採用枠の希少性」訴求
- **内容**: 事務・経理など買い手市場の職種で「年間2名のみ採用」「未経験から月給28万」など具体性の高い数字を打ち出す
- **なぜ勝てるか**: 〈本質①②〉買い手市場では応募者が多く、候補者側は「選ばれる側」になるため、希少性訴求が刺さる。逆に売り手市場（エンジニア等）では希少性訴求は弱い。

### 勝ち筋C: 「面接前カジュアル面談」CTA設計
- **内容**: 応募CVではなく「30分カジュアル面談」をメインCVに置く
- **なぜ勝てるか**: 〈本質②〉「履歴書」「面接」というハードな単語の摩擦を回避し、CVRが2〜3倍に。後工程で本応募に転換させる2段階設計が機能する。

### 勝ち筋D: 「採用ペルソナ × 媒体」のマトリクス最適化
- **内容**: 20代若手はTikTok/Instagram、30代中堅はビズリーチ/LinkedIn、ミドル層はIndeed/Google、専門職はWantedlyと媒体を分離
- **なぜ勝てるか**: 〈本質④〉媒体ごとに登録者のセグメントが完全に異なる。マッチ応募を狙うなら媒体選定が最初の関門。

### 勝ち筋E: 既存社員インタビューを動画素材化
- **内容**: 同年代・近い職歴の社員インタビュー（90秒）を広告とLPに展開
- **なぜ勝てるか**: 〈本質②〉「自分と近い人が活躍している」は最強の心理的安心材料。エビデンスベースの判断材料を提供することで摩擦が下がる。

## 4. 負け筋（典型的な失敗・地雷）

### 負け筋A: 「未経験歓迎・高収入・自由な働き方」3点セット
- **症状**: 応募は集まるがマッチ率5%以下、クライアント離脱
- **原因**: 〈本質④〉誰にでも当てはまる訴求は誰にも刺さらず、ミスマッチ応募が大量発生
- **回避策**: 訴求軸を1つに絞り、ターゲットを狭く深く設計

### 負け筋B: 求人倍率3倍のエンジニア職で「応募単価を下げよう」とする
- **症状**: 予算下げて応募激減、上げてもCPA改善せず
- **原因**: 〈本質①〉そもそも候補者母数が市場に存在しない。CPAは需給の関数
- **回避策**: スカウト型・リファラル設計へ移管。広告は補完位置に

### 負け筋C: 年齢・性別を匂わせるコピー
- **症状**: 媒体審査落ち、入稿遅延、行政指導リスク
- **原因**: 〈本質③〉「主婦活躍中」「若手のフレッシュな職場」も実質NG
- **回避策**: 「ライフスタイルに合わせて働ける」「成長意欲のある方」など属性ではなく行動・志向で表現

### 負け筋D: 応募フォーム20項目超え
- **症状**: 広告クリック1000・応募3件
- **原因**: 〈本質②〉フォーム入力の心理ハードルがCVR最大の壁
- **回避策**: 第1段階は氏名・連絡先・希望勤務地の3〜5項目。詳細は面接前に別フォームへ

### 負け筋E: 短期CPA改善で「現職への不満煽り」コピー
- **症状**: 半年後の早期離職率上昇、紹介手数料返金、契約解除
- **原因**: 〈本質②④〉不満動機の候補者は採用後の定着率が低い
- **回避策**: 「未来像」「成長機会」「価値観の一致」など肯定的動機を訴求

### 負け筋F: Indeedの自動マッチで予算を任せきり
- **症状**: 関係ない職種・地域からの応募が大量発生
- **原因**: 〈本質①④〉Indeedの自動最適化は応募数最大化に寄るため、マッチ精度を犠牲にする
- **回避策**: 入札キーワード・地域・職種を手動コントロール下に置く

## 5. 判断分岐（迷ったときの基準）

| 状況 | 取るべきアクション | 紐づく本質 |
|---|---|---|
| 応募が伸びない | まず求人倍率・市場需給を確認 | ①需給天井の確認が先 |
| 応募は来るがマッチしない | ターゲット定義の4軸を再点検 | ④解像度不足 |
| CVRが1%未満 | フォーム項目数とCTA文言を見直し | ②心理ハードル |
| 媒体審査落ちが続く | 年齢・性別表現の有無を全文チェック | ③法令違反 |
| エンジニア職で苦戦 | 広告以外（スカウト・リファラル）へ予算移管 | ①需給構造 |
| 応募単価が他社の半分以下 | 採用後の定着率を疑う、内訳を分析 | ④マッチ品質 |
| クライアント離脱兆候 | 応募数ではなく採用決定数で会話 | ④KPI再設定 |
| 売り手市場の職種 | 希少性訴求は捨て、候補者目線の便益訴求へ | ①②市場ポジション |

## 6. 実務チェックリスト

### 立ち上げ時
- [ ] 求人倍率・職種需給を確認したか 〈本質①〉
- [ ] ターゲット4軸（現職・年齢・年収・エリア）を定義したか 〈本質④〉
- [ ] 労働条件の明示要件を満たしているか 〈本質③〉
- [ ] 年齢・性別を限定する表現がないか全文チェックしたか 〈本質③〉
- [ ] 応募フォームを10項目以内に収めたか 〈本質②〉

### 週次運用
- [ ] 応募数ではなくマッチ応募数を見ているか 〈本質④〉
- [ ] 媒体審査落ち広告の理由を確認したか 〈本質③〉
- [ ] 検索クエリ・流入元の質を確認したか 〈本質①〉

### 月次運用
- [ ] 採用決定率・面接化率まで遡って分析したか 〈本質④〉
- [ ] 早期離職率・契約継続率を確認したか 〈本質②④〉
- [ ] 競合求人の動向（給与レンジ・訴求軸）を比較したか 〈本質①〉
