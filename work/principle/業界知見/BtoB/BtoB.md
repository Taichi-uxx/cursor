# BtoB業界 — 鉄則・勝ち筋・負け筋

## 1. このドメインの本質

BtoBは **「組織が組織から買う」市場**で、BtoCのセオリーが概ね通用しない。
意思決定者が複数、検討期間が3〜18ヶ月、契約金額が大きく、購買は感情ではなく **「失敗したくない／上司に説明できる」論理**で動く。1人の感情を動かすBtoCに対し、**複数人の論理を満たす**ゲーム。

この本質を分解すると、BtoB市場は4つの構造ゲームで動いている。

### 本質① 複数意思決定者ゲーム（DMUの存在）
BtoBの購買意思決定には **平均5〜7人**が関与する（Gartner調査）。
担当者（情報収集）、上長（予算承認）、決裁者（最終判断）、利用部門（実際の使用者）、情シス・法務（リスクチェック）、購買部門（条件交渉）。**1つのコピー・1つのLPで全員を満たすことは構造的に不可能**で、ペルソナ別・フェーズ別のコンテンツ分業が必須になる。

### 本質② 長期検討ゲーム（リードナーチャリング前提）
BtoBの検討期間は **3ヶ月（小規模ツール）〜18ヶ月（基幹システム）**。
広告クリック→即契約はほぼ存在しない。マーケの役割は **「リードを取り、MQL→SQL→商談→契約まで段階を踏ませる」**こと。新規CV単体ではなく **「リードから商談への転換率」「商談から受注への転換率」**まで遡らないとROIが見えない。BtoCと違い、CRM・MA（マーケティングオートメーション）が不可欠。

### 本質③ 論理・実績・ROIゲーム
BtoBの購買は **「上司・経営層に説明できる根拠」が必要**。
「感動した」「楽しそう」では稟議が通らない。「○ヶ月で投資回収」「○%のコスト削減」「○社の導入実績」「セキュリティ認証ISMS/SOC2」が必要な訴求。**ホワイトペーパー・導入事例・ROI計算ツール**が広告クリエイティブより強い武器になる場面が多い。

### 本質④ ABM（Account-Based Marketing）の重要性
BtoBは **「市場全体に網を張る」より「狙い撃ち」が効率的**な場合が多い。
ターゲット業界が10業界、ターゲット企業が500社しかない場合、Mass広告は8割の予算を無関係な企業に使う構造になる。**特定の企業・部門・職位に絞った深いアプローチ**（ABM）の方がROIが圧倒的に高い。BtoCの「リーチ最大化」と真逆の思想。

## 2. 鉄則（破ってはいけない）

> 表記凡例: 各項目末尾の **〈本質①〜④〉** は、その鉄則がどの本質に紐づくかを示す。

1. **CVを「資料DL」「ホワイトペーパーDL」「無料診断」など軽量CTAで設計する** — 「お問い合わせ」だけだとCVRが低すぎてリードが枯れる。〈本質②: 検討期間中の早期接点〉

2. **MA・CRMとの連携を前提に広告を設計する** — リードがCRMに入らない広告施策はBtoBでは無意味。〈本質②: ナーチャリング不在は致命的〉

3. **ペルソナを「業種・企業規模・職位・課題」の4軸で必ず定義する** — どれか欠けるとメッセージが拡散する。〈本質①: DMU別の訴求が分けられない〉

4. **CPAではなく「商談化率」「受注率」まで遡って評価する** — 質の悪いリードは商談化せず、CPA好調でも事業に貢献しない。〈本質②: 全工程で見ないとROIが見えない〉

5. **導入事例・実績ロゴ・第三者評価を最大限活用する** — 「自社で言うこと」より「他社が証明していること」が圧倒的に強い。〈本質③: 稟議材料として機能〉

6. **競合比較を堂々と提示する** — BtoBユーザーは必ず比較する。比較を避ける姿勢自体が不信を生む。〈本質③: 比較情報の事前提供〉

7. **広告ターゲティングは「興味関心」より「企業属性（業種・規模・役職）」で絞る** — LinkedIn・Meta Lead Gen・ABM広告等を活用。〈本質①④: 個人属性より組織属性が決定変数〉

## 3. 勝ち筋（再現性のある勝ちパターン）

### 勝ち筋A: ホワイトペーパーDL × MAナーチャリング × インサイドセールスの3点セット
- **場面**: SaaS・コンサル新規開拓
- **内容**: 広告→ホワイトペーパーDL（リード獲得）→ MAでメール配信（教育）→ スコア基準値超えでインサイドセールスがアプローチ
- **なぜ勝てるか**: 〈本質②③〉長期検討の中で「適切なタイミングで適切な情報を出す」仕組みが商談化率を3〜5倍に高める。

### 勝ち筋B: 導入事例ページの徹底拡充
- **内容**: 業種別・企業規模別・課題別に20件以上の導入事例ページを整備、ABテストでLP内に動的表示
- **なぜ勝てるか**: 〈本質③〉「自社と同じ規模・業種の事例」は最強の意思決定材料。BtoB SEOでも検索流入の30%を占めることがある。

### 勝ち筋C: ROI計算機・診断ツールをLP内に設置
- **内容**: 「自社業種・従業員数・現状コストを入力 → 想定削減額を即時算出」のツール
- **なぜ勝てるか**: 〈本質③〉稟議書に必要な「投資回収◯ヶ月」の数字を自社で作らせず、ツールで提供する。

### 勝ち筋D: LinkedIn広告 × ABMリスト
- **場面**: ターゲット業界・職位が明確な高単価SaaS
- **内容**: ターゲット500社をLinkedInのアカウントターゲティングで指定、決裁者役職に配信
- **なぜ勝てるか**: 〈本質①④〉Mass広告と違い、無駄打ちが構造的に少ない。CPCは高いが商談化率が桁違い。

### 勝ち筋E: ウェビナー × リード獲得
- **内容**: 月次でテーマ別ウェビナー開催、参加者をMAで管理、後日商談化
- **なぜ勝てるか**: 〈本質②③〉60分の接触時間は記事・広告と桁違いの情報量・関係構築効果。リードの熱量も高い。

## 4. 負け筋（典型的な失敗・地雷）

### 負け筋A: 「お問い合わせ」だけがCVのLP
- **症状**: PV高いがCV月数件、リード枯渇
- **原因**: 〈本質②〉検討初期のユーザーが手を上げられるCTAがない
- **回避策**: 「資料DL」「ホワイトペーパー」「無料診断」など軽量CTAを並列で設置

### 負け筋B: MA・CRM未整備で広告投下
- **症状**: リードは取れるが商談化しない、リスト放置
- **原因**: 〈本質②〉長期検討中の接点維持ができない
- **回避策**: MA・CRMを先に整備、最低限HubSpot/Salesforce/Marketo等の導入

### 負け筋C: BtoCクリエイティブの流用
- **症状**: 「楽しい」「便利」訴求でリード来るが商談化率低い
- **原因**: 〈本質③〉論理・ROI・実績訴求が必要なのに感情訴求している
- **回避策**: 「○ヶ月で投資回収」「○%コスト削減」「○社導入」の数字訴求に切替

### 負け筋D: CPA最適化だけ追って質を無視
- **症状**: CPA達成だが受注ゼロ、営業から「リードの質が悪い」苦情
- **原因**: 〈本質②〉商談化率・受注率まで遡って評価していない
- **回避策**: 受注ファネル全段階を月次KPI化、CPAより「受注獲得単価（CPO）」を最終指標に

### 負け筋E: ターゲット企業の網を広く張りすぎる
- **症状**: 広告費投入しても狙う企業から反応なし
- **原因**: 〈本質①④〉「すべての中小企業」では誰にも刺さらない
- **回避策**: ABMリスト構築、業種・規模・職位で絞り込む

### 負け筋F: 競合比較を避ける
- **症状**: ユーザーが比較記事を見て競合へ流出
- **原因**: 〈本質③〉ユーザーは必ず比較するので、自社主導で比較情報を出さないと他社の土俵で比較される
- **回避策**: 比較表・選び方ガイドを自社サイトで先に提示

## 5. 判断分岐（迷ったときの基準）

| 状況 | 取るべきアクション | 紐づく本質 |
|---|---|---|
| CV少ない | 軽量CTA（資料DL）を追加 | ②検討初期の接点 |
| リードあるが商談化しない | MA・ナーチャリング設計を見直す | ②検討期間中の教育 |
| 営業からリード質低いと苦情 | KPIをCPAから受注率まで遡る | ②③質指標 |
| 訴求軸が決まらない | 業種・規模・職位・課題でペルソナ再定義 | ①DMU解像度 |
| 競合に流出 | 比較表・選び方ガイドを自社で先に出す | ③比較情報 |
| ターゲット企業が500社以下 | LinkedIn ABMへ予算シフト | ①④網vs狙撃 |
| 検討期間6ヶ月以上 | ウェビナー・コンテンツマーケで接触頻度を増やす | ②長期関係 |
| 経営層への訴求が必要 | ROI計算ツール・経営課題訴求へ転換 | ③論理訴求 |

## 6. 実務チェックリスト

### 立ち上げ時
- [ ] MA・CRMの導入とリード連携が完了したか 〈本質②〉
- [ ] ペルソナ4軸（業種・規模・職位・課題）を定義したか 〈本質①〉
- [ ] 軽量CTA（資料DL・ウェビナー・無料診断）を3つ以上設置したか 〈本質②〉
- [ ] 導入事例を業種・規模別に10件以上整備したか 〈本質③〉
- [ ] CPA以外のKPI（商談化率・受注率）を設定したか 〈本質②〉

### 週次運用
- [ ] 新規リードのMA内ステータス推移を確認 〈本質②〉
- [ ] 営業へ渡したリードのフィードバックを収集 〈本質②③〉
- [ ] LP・広告のメッセージとペルソナのズレを確認 〈本質①〉

### 月次運用
- [ ] 商談化率・受注率・受注獲得単価（CPO）を分析 〈本質②③〉
- [ ] ABMリスト企業からの流入と接触状況 〈本質①④〉
- [ ] 競合の動向（事例追加・新機能・価格変更）を把握 〈本質③〉
