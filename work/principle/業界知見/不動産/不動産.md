# 不動産業界 — 鉄則・勝ち筋・負け筋

## 1. このドメインの本質

不動産は **「人生で最も高額な意思決定」を扱う市場**。
住宅購入は3000万〜1億円、賃貸でも数十万の初期費用が動く。広告クリックから契約まで **3ヶ月〜2年**かかる典型的な長期検討商材。Webマーケの「即CV」常識が通用しない。

この本質を分解すると、不動産市場は4つの構造ゲームで動いている。

### 本質① 宅建業法ゲーム（広告表現に対する厳格な法規制）
不動産広告は **宅建業法・不動産公正取引協議会の表示規約で「書ける表現」が極めて限定される**。
「徒歩◯分」は道路距離80m=1分換算、「新築」は建築後1年未満かつ未入居、「角地」「南向き」「最寄駅」全てに具体的定義がある。**広告クリエイティブの自由度は他業界の半分以下**と思って設計する必要がある。違反は措置命令・業務停止処分まで及ぶ。

### 本質② 長期検討ゲーム（CVは「資料請求」「来場予約」が起点）
購入決定までの平均検討期間は **賃貸2〜4週間、注文住宅6〜18ヶ月、中古マンション3〜6ヶ月**。
「Web広告→即契約」は存在しない。施策の役割は **「比較検討の土俵に入る」「リードを獲得し、ナーチャリングする」**。最終CVではなく「資料請求」「来場予約」「内見申込」がKPIとなり、そこからの商談化率・契約率まで追わないとROIが見えない。

### 本質③ 地域性ゲーム（エリアが商品価値そのもの）
不動産は **「物件そのもの」より「立地（駅・学区・治安・周辺施設）」が価値を決める**。
ユーザーは「中野区 賃貸」「武蔵小山 新築マンション」のように **エリア起点で検索する**。これは商圏でなく「探索エリア」で、エリアを跨いで広告を打っても刺さらない。**SUUMO・HOMES・athome等のポータルサイト依存度が極めて高い**点も特徴で、自社広告だけで戦うのは構造的に不利。

### 本質④ 高額単価ゆえの「失敗回避動機」ゲーム
購買意思決定は **「ワクワク」より「失敗したくない」が優位**。
「悪い口コミ」「ハザードマップ」「過去事故」「将来の資産価値」を執拗にチェックする。広告は **不安を煽るのではなく、不安を解消する情報を提供する役割**。透明性・専門性・誠実さが派手な訴求より勝つ。

## 2. 鉄則（破ってはいけない）

> 表記凡例: 各項目末尾の **〈本質①〜④〉** は、その鉄則がどの本質に紐づくかを示す。

1. **「徒歩◯分」は道路距離80m=1分換算で計算する** — 直線距離や信号無視はNG。違反は措置命令対象。〈本質①: 不動産公正取引協議会の表示規約〉

2. **「新築」表記は建築後1年未満かつ未入居の物件のみ** — それ以外は「未入居」「築浅」と表現する。〈本質①: 宅建業法規制〉

3. **「最寄駅」「南向き」「角地」など全ての修飾語に定義がある** — 不動産公正取引協議会のガイドラインを必ず参照する。〈本質①〉

4. **CVは「資料請求」「来場予約」とし、契約までのリードナーチャリングを必ず設計する** — 即契約を期待した広告設計は破綻する。〈本質②: 長期検討の構造〉

5. **エリア指定は市区町村ではなく駅・学区単位で行う** — 不動産検索の最小単位は駅・学区。〈本質③: ユーザーの検索粒度〉

6. **おとり広告（売却済みの好条件物件を掲載し続ける）は絶対にやらない** — 業界の構造的問題だが、宅建業法違反であり信頼破壊が決定的。〈本質①④: 法的・倫理的の二重リスク〉

7. **ハザードマップ・周辺環境のネガティブ情報も誠実に開示する** — 隠蔽は契約後の解約・訴訟リスク、信頼コストの方が大きい。〈本質④: 失敗回避動機への対応〉

## 3. 勝ち筋（再現性のある勝ちパターン）

### 勝ち筋A: 駅×条件のロングテール検索広告
- **場面**: 賃貸・売買仲介
- **内容**: 「武蔵小山 2LDK ペット可」「中野駅 中古マンション 4000万」など3語以上の組合せで広告群を細分化
- **なぜ勝てるか**: 〈本質③〉ユーザーは具体条件で検索する。CPCは安く、CVRは高い。広範ワード（「中野 賃貸」）は競合過多・コスト高。

### 勝ち筋B: 「資料請求＋メルマガナーチャリング」型2段階CV設計
- **内容**: 資料請求を初期CV → メール・LINEで物件情報・市況情報を月次配信 → 来場予約に転換
- **なぜ勝てるか**: 〈本質②〉購入検討6ヶ月の途中で接点を保てる仕組みが、最終契約率を3倍に押し上げる。

### 勝ち筋C: 動画内見・VR内見の標準装備化
- **内容**: 全物件にVR・360度動画・YouTubeルームツアーを設置
- **なぜ勝てるか**: 〈本質②④〉現地に行く前の判断材料を増やすことで、来場ハードルを下げ、来場後のミスマッチも減らす。

### 勝ち筋D: 「学区・通学路」訴求のファミリー向けLP
- **内容**: 物件単位で学区・徒歩通学距離・周辺の公園・スーパーを地図上で可視化
- **なぜ勝てるか**: 〈本質③④〉ファミリー層の購買意思決定は「立地」が9割。子供の通学環境は最大の不安要素。

### 勝ち筋E: 「住宅ローン試算ツール」をLP内に設置
- **内容**: 物件価格・頭金・年収・年齢を入力すると月々の返済額を即算出
- **なぜ勝てるか**: 〈本質④〉「自分は買えるのか」が最大の不安。試算ツールが「現実的な選択肢か」を即時判定し、検討熟度を高める。

## 4. 負け筋（典型的な失敗・地雷）

### 負け筋A: 「徒歩○分」の不正確表記
- **症状**: 媒体審査落ち、措置命令、信頼失墜
- **原因**: 〈本質①〉直線距離計算、信号無視、坂道無視
- **回避策**: Googleマップの徒歩ルート時間ではなく、規約の80m=1分換算を厳守

### 負け筋B: おとり広告（売却済み物件の掲載放置）
- **症状**: 業務停止処分、レピュテーション崩壊
- **原因**: 〈本質①④〉短期集客のための禁じ手だが、業界全体の信頼コストを上げる
- **回避策**: 在庫管理システムと広告データの自動同期、売却即日の取り下げ

### 負け筋C: 即CV型広告設計（クリック→即契約期待）
- **症状**: 広告費投入しても契約ゼロ、ROAS算出不能
- **原因**: 〈本質②〉長期検討商材で短期コンバージョン期待は構造的に成立しない
- **回避策**: 資料請求／来場予約をKPIに、CRM・ナーチャリングを必ずセット

### 負け筋D: ポータルサイト依存しすぎ
- **症状**: SUUMO・HOMES掲載費に予算9割、自社流入ゼロ
- **原因**: 〈本質③〉短期は効率良いが、ポータル値上げ・他社競合増で利益率が長期低下
- **回避策**: ポータル6割、自社SEO・広告4割でブランド資産も並行構築

### 負け筋E: ネガティブ情報の隠蔽
- **症状**: 契約後クレーム・解約・訴訟
- **原因**: 〈本質④〉ハザード・事故・嫌悪施設の隠蔽は宅建業法の説明義務違反
- **回避策**: 透明開示を逆に強みとし「誠実な不動産屋」ポジショニング

### 負け筋F: ファミリー向け物件を独身広告クリエイティブで打つ
- **症状**: クリックは来るが資料請求の質が悪い
- **原因**: 〈本質③〉物件特性とターゲット属性のミスマッチ
- **回避策**: 物件単位でペルソナを設定、クリエイティブをペルソナ別に分離

## 5. 判断分岐（迷ったときの基準）

| 状況 | 取るべきアクション | 紐づく本質 |
|---|---|---|
| 「徒歩○分」表記に不安 | 道路距離80m=1分で再計算 | ①法令要件 |
| Web広告で即契約期待 | KPIを資料請求／来場予約に修正 | ②長期検討 |
| エリア指定でクリック高単価 | 駅・学区粒度に細分化 | ③エリア粒度 |
| 物件売却済み | 即時に広告取り下げ | ①おとり広告防止 |
| 来場予約から契約への転換低い | ナーチャリング設計を見直す | ②検討期間中の接点 |
| ハザード情報を載せるか | 載せる、誠実性が長期信頼 | ④失敗回避 |
| ポータル依存度高い | 自社チャネルへの予算配分を増やす | ③依存リスク |
| 高額物件のCVR低い | 試算ツール・VR内見を実装 | ④不安解消 |
