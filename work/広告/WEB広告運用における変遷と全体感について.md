# WEB広告運用における変遷と全体感について

## 1. Google広告の変遷の詳細

### 初期の運用手法
- 極度の細分化運用が特徴
- 1グループ1キーワードの構造
- デバイス、地域などあらゆる要素で分割
- すべての組み合わせに対して手動で入札価格を設定
- 人力による緻密な管理が必要

### HAGAKURE時代
- 自動入札システムの導入
- シンプルなアカウント構造への移行
- データの集約化を重視
- グループ/キャンペーン単位でのデータ最適化
- 運用効率の向上を目指した構造改革

### GORIN時代
- ターゲット属性に基づくグループ分けを導入
- LP（ランディングページ）とターゲット像の一致を重視
- クリエイティブの重要性が増加
- ユーザーニーズに合わせた適切な情報提供を重視
- コミュニケーション戦略の体系化

### MUGEN時代
- 配信量の最大化を目指す
- データドリブンアトリビューションの実装
- DSA（動的検索広告）の活用
- 部分一致キーワードの活用
- レスポンシブ検索広告の導入

### Search Quattro時代
- ビジネスKPIを重視した運用へ
- 価値ベースの入札戦略
- ROAS（広告収益率）の重視
- より包括的な事業目標との連携
- 売上・利益への直接的な貢献を重視

## 2. 運用レベルの定義詳細

### レベル1（基礎レベル）の特徴
#### 理解度
- 運用要素（ターゲティング、クリエイティブ、入札強度）を個別に認識
- 各要素の連携性の理解が不足
- 指標や施策の基本的な知識はあるが、活用が不十分
#### 問題解決アプローチ
- 表面的な対処に終始
- 例：CPAが高いキーワードを単純に除外
- 根本的な原因分析が不足
- 短期的な視点での対応が多い

### レベル2（中級レベル）の特徴
#### 理解度
- 媒体推奨設定の理解と適切な実装
- コンバージョン最適化の重要性を理解
- 自動入札の仕組みへの理解
#### アプローチ
- データに基づいた運用判断
- 媒体上のコンバージョンを重視
- 適切な運用構造の設計が可能
- 標準的な改善施策の実施

### レベル3（上級レベル）の特徴
#### ビジネス理解
- 事業モデルの深い理解
- 市場特性の把握
- 競合状況の分析
- ユーザー行動の深い理解
#### 戦略的アプローチ
- 事前調査の徹底
- 包括的なヒアリングの実施
- ビジネスゴールに基づいた運用設計
- 長期的な成果を見据えた戦略立案
#### 差別化ポイント
- 運用者として稀少な存在
- 事業戦略と運用の統合的な理解
- クライアントビジネスへの深い理解
- 独自の運用手法の確立

このレベル分けは、単なる技術的スキルだけでなく、ビジネス理解度や戦略的思考力も含めた総合的な評価基準となっています。
