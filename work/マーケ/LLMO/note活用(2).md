# noteの生成AI流入が強い理由：検索エンジン流入期待値を4.2倍上回る実態分析

## 参照
- https://x.com/fladdict/status/1965636803685470429?t=0GHAqg3JRhGiaXnQLdGR3Q&s=19
- https://note.com/roberto_saito/n/n545a303c8fa4 

## 要約・サマリ

本記事は、株式会社ヴァリューズの行動ログデータを用いて、検索エンジン経由流入と生成AI経由流入の関係性を分析した調査結果をまとめたものである。主要な発見は以下の通り：

1. **相関関係の確認**：検索エンジン経由流入が多いサイトほど、生成AI経由流入も多いという通説が定量的に確認された（R二乗0.5551、P値0.0001未満）。

2. **noteの例外的な強さ**：note.comは検索エンジン流入から算出される期待値に対して、生成AI経由流入が**4.2倍**という驚異的な超過トラフィック（エクセスAIトラフィック）を獲得している。

3. **noteのSEO優位性の構造**：大規模サイトの恩恵を個人ユーザーが享受できる仕組みにより、①サイトの権威性（site_qualityスコア）、②URL発見の早さ、③インデックス化速度、④サイト全体の良質なユーザー行動シグナルといった要素が、個人記事にも反映されている。

4. **生成AI経由流入の定義**：ChatGPT、Perplexity、Geminiなどの生成AIツールが質問応答や要約の際に参照・提示するURLから発生する流入を指す（GoogleのAI Overviewsは含まない）。

5. **調査の意義**：先行研究ではAIによる引用率やメンション率の集計は存在するが、ユーザーが実際に遷移しているかを大規模データで明らかにした例は本調査が初めてとされる。

## 調査の背景と目的

### 検証テーマ

**「検索流入が多いサイトほど、生成AI経由流入も多いことが見込まれる」**という通説の検証。

このテーマは、**ダブルジョパディの法則**と類似した構造を持つと仮定：
- 規模が大きいサイトは、LLMの事前学習データにも多く出現
- ドメイン優遇のSerps状況から、リアルタイム検索（RAG）においてもヒットしやすい傾向
- 「富めるものがますます富む」という状況の確認

ただし、**相関から外れた例外的な存在（外れ値）にこそ示唆がある**という観点から、note.comを中心に分析を実施。

### 生成AI経由流入の定義

生成AI（GEN AI）経由流入とは：
- ChatGPT、Perplexity、Geminiなどの生成AIツールが、質問応答や要約の際に参照・提示するURLから発生する流入
- **注意**：Googleの検索結果上に表示されるAIによる概要「AI Overviews」は含まない

従来の検索流入（Google、Yahoo!、Bingからのクリック）とは異なり、AIが情報源として選ぶ過程を含むため、新しい対応策が必要とされている。

- **傾向線のR二乗（決定係数）**：0.5551
- **P値**：0.0001未満
- **相関の強さ**：中程度の正の相関が確認された

## 主要な調査結果

### 1. 全体としての相関関係

検索エンジン経由流入と生成AI経由流入には一定の相関が確認された。これは以下の仮説を支持する：

**因果の向きの仮説**：
「検索エンジンにて上位表示 → LLMの事前学習データに含まれやすく、RAGの対象となりやすい」

この仮説に基づき、**検索エンジン流入規模から生成AI経由流入の期待値を算出できる**ことが示された。

### 2. 例外サイトの存在

相関関係から外れた例外的な存在として、以下のサイトが観測された：
- **note.com**（最も顕著な例）
- Wikipedia
- GitHub

これらのサイトは、検索流入から期待される値を大きく上回る生成AI経由流入を獲得している。

### 3. note.comの驚異的な超過トラフィック

#### 数値データ

note.comへの生成AI経由流入は、検索エンジン流入から算出される期待値の**4.2倍**に達している。

#### エクセスAIトラフィックの意味

「エクセス（excess）」とは、過多・過剰・超過・過度を示す単語。マーケティングにおけるダブルジョパディの法則では、ブランドの規模から期待される行動ロイヤリティ以上のロイヤリティを獲得しているブランドを「エクセス・ロイヤリティ」と表現する。本調査では、同様の概念を生成AI経由流入に適用し、「エクセスAIトラフィック」と呼称。

## noteのSEO優位性の構造

### 大規模サイトの恩恵を個人ユーザーが享受できる仕組み

noteのSEO的な強さは、以下の構造により実現されている：

#### ① サイトの権威性（site_qualityスコア）

Googleのアルゴリズムの特徴量の一つであるサイトの権威性が、note全体の評価として機能。個人ユーザーが執筆した記事にも、この権威性が反映される。

#### ② URL発見の早さ

新規記事が公開されると、迅速にGoogleに発見される仕組みが整備されている。これにより、検索エンジンに早期にインデックスされ、検索結果に表示されるまでの時間が短縮される。

#### ③ インデックス化されるまでのスピード

記事公開から検索結果への反映までの時間が短い。これは、note全体のクローラビリティの高さと、サイト構造の最適化によるもの。

#### ④ サイト全体の良質なユーザー行動シグナル

note全体のユーザー行動（滞在時間、ページビュー、直帰率など）が良好であることが、Googleの評価に反映される。この評価が、個々の記事にも波及効果をもたらす。

### 個人ユーザーへのインセンティブ

上記の構造により、**note全体の評価と恩恵を個人ユーザーが享受できる**ことが、記事執筆者に強いインセンティブ（上位表示のしやすさ）を与える形となっている。

## 調査の意義と独自性

### 先行研究との違い

先行データでは、プロンプトを大量に打ち込み、AIによる引用率やメンション率を集計する研究が存在し始めている。しかし、**ユーザーが実際に遷移しているかどうか**については、株式会社ヴァリューズの行動ログによって初めて明らかにされた。

### ユーザー行動データの重要性

本調査では、以下の観点でユーザー行動を分析：
- 生成AIに引用された後に、ユーザーが実際に遷移しやすい/遷移しにくいサイトの存在
- 検索エンジン経由流入と生成AI経由流入の関係性を大規模データで表現

この観点で、検索エンジン経由流入と生成AI経由流入の関係性を大規模データで表現した例は、寡聞にして存じないとされる。

## まとめ

本調査により、以下のことが明らかになった：

1. **検索エンジン経由流入と生成AI経由流入には一定の相関がある**ことが定量的に確認された。

2. **note.comは例外的な存在**として、期待値の4.2倍という驚異的な生成AI経由流入を獲得している。

3. **noteのSEO優位性は構造的なもの**であり、大規模サイトの恩恵を個人ユーザーが享受できる仕組みが機能している。

4. **ユーザーが実際に遷移しているか**を大規模データで明らかにした点で、本調査は独自性を持つ。

5. **例外サイトにこそ示唆とヒントがある**という観点から、noteの事例は今後のマーケティング戦略に重要な示唆を与える。

AI時代における検索マーケティングにおいて、従来のSEO手法だけでなく、生成AIが情報源として選ぶ過程を理解し、最適化することが重要であることが示された。
