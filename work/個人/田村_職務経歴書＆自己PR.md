## 成果をあげるための仕組み — "自動化"による「検知とPDCAの高速化」

下記の通知・レポートを **日次／週次で自動配信**。「気づくのが遅れた」を構造的に防ぎ、競合・市場・運用の変化に先手で打ち手を講じる体制を構築している。

### ① 無関係 / 競合クエリ通知（日次）
**検索クエリの無駄・抜け漏れを即発見**
- 無関係KW・社名等の自動フラグ
- 競合社名クエリの流入検知
- 除外設定の打ち手提案まで

### ② 競合オークション状況通知（週次）
**オークション参加状況の変化を可視化**
- 新規参入競合のアラート
- IS / 上位掲載率 の変動
- 入札強化タイミングの判断

### ③ 成果の大幅変動通知（日次）
**CV / CPA / CTR の急変を即時検知**
- 閾値超え時に自動アラート
- 媒体・キャンペーン別の異常検知
- 原因仮説まで併記して配信

### ④ 運用面の大きな変動通知（日次/週次）
**アカウント内の構造変化を捕捉**
- RSA タイトル変化
- 上位KW・検索クエリの変化
- デバイス割合 / LP の変化

### ⑤ 競合クリエイティブ通知（週次）
**競合の打ち手をクリエイティブ単位で追跡**
- Google：広告文・LP（検索画面より取得）
- Meta：クリエイティブ・LP（広告ライブラリより取得）
- 切り口・訴求軸の分析、競合の狙いを素早く検知

### ⑥ 自社 / 競合 事業通知（週次）
**事業単位の動きを継続ウォッチ**
- プレスリリース・新規施策
- 採用要項からの戦略推測
- 資金調達・組織変化

### ⑦ アップデート情報（随時）
**媒体・市場の最新動向を継続キャッチ**
- 媒体アップデート情報
- 媒体公認の最新事例
- 業界トレンド・先進パターン

> → 上記すべての通知が自動化され、人手の"見落とし"を構造的に排除。先手で対策を打てる体制が、成果の安定基盤を構築している。

※ Slack等への配信レポート・通知の実例画面も資料内に掲載。

### ▼ BtoB / 人材（4ケース）

#### 01. BtoB（知財系サービス）
- **役割**: 顧客担当
- **媒体・領域**: リスティング / SNS広告
- **課題**: 獲得数の頭打ちにより事業としての拡大が進んでいなかった。要因として、業界特有の市場構造やユーザー行動を把握できていない運用設計となっていた。
- **アプローチ**:
  - 業界特有の検索市場構造を深く分析し、Tier別のキャンペーン設計を構築（Tier1: 業界特化用語=指名級／Tier2: ニーズ顕在クエリ／Tier3: 関連業務クエリ）
  - 市場特性を最大限活かした運用設計に落とし込み、高CVR領域を最優先化
  - SNS広告からの指名検索への跳ね返りも加味したアロケーション・媒体評価を実施
- **成果**:
  - リード/契約数：**ギネス達成**
  - 移管後6ヶ月で **リード数 135%**

#### 02. 人材（特化型転職エージェント）
- **役割**: 顧客担当 兼 案件統括
- **媒体・領域**: リスティング / SNS / LPO
- **課題**: 前体制下でCPAが高止まり。アカウント構造・ターゲティング・クリエイティブ・最適化など各変数にて改善の余地があった。
- **アプローチ**:
  - 顧客担当 兼 プロジェクト統括として、戦略設計から実行まで一気通貫で推進
  - 広告の運用改善を中心に行い、移管後1.5ヶ月で移管前対比でCPAを約半分まで改善
  - 先方社内のアセットとして存在していた動画の活用によるLP改善を主導し、CVR125%UPを実現
- **成果**:
  - 登録CPA（移管後1.5ヶ月）：**50%改善 達成**
  - LP変更によるCVR改善：**125%達成**

#### 03. BtoB（SNS拡張ツール）
- **役割**: 運用担当
- **媒体・領域**: リスティング / SNS / サイト改善・LPO
- **課題**: 既存の運用設計が現状の顧客像とずれており、商談数・効率ともに頭打ち。広告媒体データだけでは課題が見えなかった状況。
- **アプローチ**:
  - 顧客ヒアリング（定性ニーズ・課題）・商談データ（受注/失注理由）・Salesforceデータ（パイプライン全量）の3ソースを横断分析
  - 商談・受注につながる勝ち筋を分析・特定し、運用設計の根本から再構築
  - サイト改善・LPOも同時に推進
- **成果**:
  - 移管後6ヶ月で **商談数 150%**
  - サイト改善施策により **CVR 135%**

#### 04. BtoB（領域特化 採用サービス）
- **役割**: 顧客担当
- **媒体・領域**: リスティング / DSP / SNS / 営業支援 / DM / AI活用
- **課題**: 広告施策だけではリード数の拡大に限界。営業体制側にも商談化のボトルネックが存在していた。
- **アプローチ**:

  - IS支援施策を提案し、実行をディレクション。商談獲得のフローを根本から強化（実行はパートナー企業が対応）
- **成果**:
  - 移管後6ヶ月で **リード数 130% / 商談数 120%**
  - IS支援施策を実行し、**商談数 +50件/月** を達成

### ▼ 不動産（4ケース）

- **役割**: 運用担当（2名体制） / 月間予算 2億円規模
- **媒体・領域**: リスティング / DSP / SNS / ダイナミック / 認知広告

- **アプローチ**:
  - ターゲティングの網羅性や業界カスタマイズ観点を中心に運用設計を見直し
  - 頭打ち後からは、準顕在層向けの動画施策を新規企画
  - 顧客データを活用した機械学習最適化を導入し、媒体ミックスを再設計
- **成果**:
  - 移管後6ヶ月で **問合せ数 130%**
  - 認知〜獲得までの **フルファネル支援**
  - 月間運用予算2億円規模 / メイン媒体5種（リスティング / DSP / SNS / DA / 認知）

#### 06. 不動産（法人向け売買領域）
- **役割**: 運用担当 / アカウント新規立ち上げ
- **媒体・領域**: リスティング / ディスプレイ
- **課題**: 法人向け不動産は購入意向の変動要因が複雑。一般的な運用設計だけでは安定した投資効率を出しにくかった。
- **アプローチ**:
  - 為替変動とリード数の相関関係を独自に発見
  - 為替指標に基づき運用額を動的に調整するロジックを構築（為替高水準=運用額拡大／中水準=維持／低水準=抑制）
  - 投資効率を最大化
- **成果**:
  - 移管後6ヶ月で **問合せ数 120%**
  - 為替との連動を踏まえ運用し **問合せ数（最大）140%**

#### 07. 不動産（賃貸管理領域）
- **役割**: 運用担当 / アカウント新規立ち上げ
- **媒体・領域**: リスティング / SNS広告
- **課題**: ゼロからの新規アカウント構築。短期間で成果を出す必要があり、設計の精度が成否を分ける状況だった。
- **アプローチ**:
  - マッチタイプの設計（完全一致=主要KW／フレーズ=購入意向KW／部分一致=探索+SmartBid）と最適化ポイントの戦略的見直しを実施
  - 最適化ポイントの戦略再設計（ターゲットCPA／マイクロCVの活用／入札戦略の段階移行）
  - 短期間で成果を創出できる構造を組み込み
- **成果**:
  - 移管後6ヶ月で **問合せ数 120%**

#### 08. 不動産（地域特化 戸建て販売）
- **役割**: 顧客担当 兼 案件統括
- **媒体・領域**: リスティング / ディスプレイ / SNS / 認知 / LINE / IG / WP制作
- **課題**: 移管前は媒体上のCV数を最大化するような設計になっていた。また、先方社内の事業KPIを達成するには単一チャネル改善では限界があり、マーケ全体の統合的な設計が必要だった。
- **アプローチ**:

  - 広告・SNS・LINE・インフルエンサー・WP制作までを横断的にディレクション
  - チャネル横断の統合マーケ施策を設計・実行
- **成果**:
  - 移管後6ヶ月で **来店数 145%**
  - **6チャネルの施策を横断で設計・ディレクション**
