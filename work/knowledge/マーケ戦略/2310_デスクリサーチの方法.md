# デスクリサーチの方法

## 出典
- 社内研修ドキュメント（移管元: `知見・ナレッジ移管/マーケティング全体/デスクリサーチの方法.docx`、2023-10-08）

## 用途（こんな時に見る）
- 新規クライアントのデスクリサーチを始めるときの情報源カタログとして
- 公開データ・調査レポートを探したいが、どこを見ればいいか思い出せないとき
- 業界研究・市場規模調査で「他の信頼できるソースは？」と探したいとき
- 政府統計の所在（白書・統計局・e-Stat）を素早く参照したいとき

---

## ① クライアント公式HP（確認必須）

| 見る場所 | 何が分かるか |
|---------|------------|
| 会社概要 | 企業としての考え方 |
| **新卒向けページの会社紹介** | 会社の目指す方向性が分かりやすく記載 |
| **中途採用ページ（募集求人）** | どこが今足りていないのか・どこに投資したいのかが分かる |

## ② ポータルサイトの検索から探す

- Google / Yahoo!JAPAN
- 専門サイトから探す（企業研究）

### 検索の組み合わせ
1. まず「**【案件名】**」で検索
2. 「**【案件】+調査**」「**【案件】アンケート**」
3. アンケートで取れないものは「**【対象エリア】+ 観光協会**」など → サイト内の統計情報

### SharedResearch
- 全企業網羅ではないが、載っている場合はかなり詳しい

### SUSTAINA
- 会員（無料）登録必要
- 会社の健康状態を独自分析

| サイト | 概要 |
|--------|------|

## ④ アンケート調査の公開データ

| サイト | 注意点 |
|--------|--------|
| **調査のチカラ** | うまく検索しないと引っかからない／古い調査もヒット。Google/Yahooで引っかからない時はまずこちら |
| **リサリサリサーチ（Dilemma）** | 新しいサービス、まだ案件少なめ |
| **博報堂生活総合研究所** | 行動・生活に関する調査。ブランド／業界以外の目的で |
| **博報堂メディア環境研究所** | 4マスやインターネットの利用状況。「調査リリース」or「CONTENTS INDEX」→「コンテンツで選ぶ」 |
| **マクロミル自主調査・市場調査レポート** | DLにメルアド・氏名登録必要 |
| **HONOTE（記事）** | 市場調査メディア |
| **インテージ自主調査** | 調査レポートライブラリ／**Intage知るGallery**（コラム系） |

## ⑤ 政府関連（官庁）の公開データ

### メインで使う
| サイト | 用途 |
|--------|------|
| **総務省統計局** | 通信利用動向調査もここ（なぜかe-Statには入っていない） |
| **e-Stat（政府統計の総合窓口）** | 統計局のかなりのデータがまとめられている。**官庁データはまずここを見る**。ちょっとした集計もできる |
| **統計ダッシュボード** | 主に省庁の主要統計データを抽出できるASP。e-Statの抽出システム版。地域別抽出可能 |

### 参考（上記3サイトで出ない場合）
| 省庁 | ページ |
|------|--------|
| 経済産業省 | 商業動態統計などもここ。「統計」 |
| 厚生労働省 | 「統計情報・白書」 |
| 国土交通省 | 「オープンデータ」 |
| 国土交通省・観光庁 | 「統計情報・白書」 |
| 内閣府 | 「活動・白書等」→「白書・年次報告書等」 |

## So What — 太一としての示唆

- **採用ページ（特に中途求人）** = 投資先の意思表示。事業理解ショートカットとして毎案件チェック
- 政府統計で迷ったら e-Stat → 統計ダッシュボード の二段構え
- 調査レポート探しは「**filetype:pdf**」テクニックと組み合わせる（[[2309_クライアント事業理解]] 参照）
- 自分の環境で利用可能なものは Similarweb / Googleトレンド / Keywordmap 系。クライアントオンボーディング時のリサーチテンプレに組み込む
