# ロワー案件でミドル・アッパーまで提案した事例を学ぶ（保険チャンネル）

## 出典
- 社内研修ドキュメント（移管元: `知見・ナレッジ移管/マーケティング全体/ロワー案件でミドル・アッパーまで提案した事例を学ぶ.docx`、2023-09-29）
- 資料作成者：青山さん**ではなく**営業・運用担当者 → **「自分でもできる」が最大のメッセージ**

## 用途（こんな時に見る）
- 小規模ロワー案件をミドル・アッパー提案に発展させる戦略を組みたいとき
- 提案前の「種まき」シナリオを設計したいとき（クライアントの課題を刷り込む技法）
- テストマーケのプラン設計（予算・期間・エリア・KPI）の参考にしたいとき
- 競合定義をJOBベース／市場構造から見直したいとき
- 「失敗を視野に入れる」検証プランの作り方を学びたいとき

---

## 知ってほしいこと（前提）

- **小さい案件だってミドル・アッパー施策は作れる**。むしろ小さい案件のほうが提案の自由度が高い（大きな案件は競合が手を付けている）
- 「受注した後が不安」という人もサポートが入るから大丈夫
- 顧客とたくさん会話することで施策を磨ける
- **お客さんはチームメイト**

## 事例概要：保険チャンネル

**クライアント**: 保険の相談をフィナンシャルプランナーにできるサービス
**目標**: 半年〜1年のロードマップで認知拡大 → 獲得増加

---

## ① 受注までの道のり — なぜ受注できたか

### 大前提
> **ロワーの広告で事業成果に貢献してきたから。**
> 「投資する価値がある／事業拡大のための投資価値がある」と判断された。

### やること、意識すること

#### a) ロワーで目標達成する（姿勢を見せる）
重要なのは姿勢を見せること：
- 目標達成のための半年〜1年のロードマップを作る
- 競合との差分を自主的に情報収集
- 媒体社を巻き込んで実績シミュレーションとともに新媒体提案

→ 効果が出るかどうかはともかく、**「成果を出したい姿勢」**を見せる → **「この人に任せたら成果を出してくれるかも」という信頼**を作る。

#### b) 動画施策の種まき
- 表ではロワー目標達成に真摯に向き合う
  - DSA導入 → CV発生KWを非指名に追加を繰り返す
  - 保険=ライフイベント時検討の特性を踏まえてFB提案
  - LINEで成果改善できず…の失敗
- 裏では同時に**課題点（動画施策につながる部分）を刷り込む**
  - 「指名検索数が伸びない」「指名って獲得効率いいはずなんだけど」
  - 「**やっぱり認知上げないと検索数って増えないかも、認知調査されてますか？**」

---

## ② プランニング編

### お題
> 「認知上げたら獲得増えるのか試したい」（フワッとした当然のこと）

### ターゲット考察ディスカッション

「認知が低いクライアントが認知をとったら成果が上がるのは当たり前。
**問題は『どうやって最短距離で認知を取りに行くか』**」

= 「どこで」「誰に」「何を」言うのか — 最も適切な形で。

#### 検索クエリ × IMPポテンシャル × CVRをプロット
- 住宅系クエリのCVRは高い
- キーワードプランナーで保険系クエリのIMPポテンシャル
- → **仮説**: 「直接的に保険に興味あるユーザー」より**「住宅ローンや資産運用に興味があるユーザー」のほうがCVR高い**

### 結論：保険以外のカテゴリにチャンスがありそう

→ STPを再確認すべき。競合優位点が明確でない、生活者に選ばれている感が足りない → **VP（バリュープロポジション）が必要**。

## ③ 市場構造の整理 — 真の競合は誰か

### 保険市場の3勢力

| 勢力 | サービス内容 | 例 |
|------|------------|-----|
| **新興：FP相談** | ライフプラン踏まえた提案。投資・住宅ローンも可。**保険を提案しないという選択肢もある** | マネードクター、保険チャンネル |
| 従来：保険ショップ | 様々な保険商品から最適提案。**保険相談のみ** | 保険の窓口 |
| 従来：保険営業員 | 自社の保険を提案。一番ごり押し | 日本生命、プルデンシャル生命 etc |

### シェアと狙い

- FP相談サービスは全体の**約5%のみ**
- 真の競合 = **15%シェアを占める保険ショップ勢力**
- 保険チャンネルは**既存保険ビジネスのディスラプター**

### 目指す状態 — 2つの認知を取る

| 認知 | 戦略 |
|------|------|
| 「保険ならFPに相談」 | **カテゴリエンハンスメント**：FPに相談する行為そのものを普及・盛り上げる<br>用事を解決する一番の方法（見返りの提示・標準化） |
| 「FPに相談するなら保険チャンネル」 | **脱コモディティ化**：他社FPとの違いを明確に<br>差別化・独自化（争点化、記号化、ユーザーの体験談） |

→ インサイト洗い出し → クリエイティブブリーフ。

## ④ メディアプラン — なぜ予算500万 / 期間2週間 / 千葉・兵庫なのか

### 背景
クライアント：「もしテストマーケでうまくいったら、来期 10〜20億の予算を確保」

→ **本当に投資価値があるか判断するため、500万というスモールビジネスで「再現性とスケーラビリティ」を最大限検証する**。

### 来期の姿（再現したい本番環境）
- 1ショット: 1億以上
- メディアミックス: TV・デジタル・PR・交通
- ターゲティング: 広い（最大: デモグラ、最小: ライフイベント）
- R&F: FQ少なくとも5回以上
- エリア: 保険チャンネル商圏範囲内

### 今期テストの設計
- 予算: 500万
- メディアミックス: YouTubeのみ
- R&F: 5回以上は確保
- 「ターゲティング優先 vs エリア優先」 → **ターゲティング優先**を選択（広いターゲのまま、エリアを狭めることでブロードメディア検証ができる）

#### 配信エリアの決め方
- 来期想定リーチ率を再現できること
- 都市圏であること
- リーチプランナーでシミュレーション → **千葉・兵庫**

## ⑤ 検証プランニング — 何を検証するのか

> **「届いたか」「伝わったか」「動いたか」**

| 観点 | 計測 |
|------|------|
| 届いたか | リーチ率・広告認知率 |
| 伝わったか | 利用意向（マクロミル調査）、BLS |
| 動いたか | VTNQ、指名検索ボリューム、予約数の増分（CausalImpact）、サービス利用調査（マクロミル） |

### 「失敗を視野に入れる」ことが大切
- うまくいかないこともある
- **「もしこういう結果だったらこういう理由ではないか」という仮説をあらかじめ作っておく**プランニング
- 検証できる設計にしておけば失敗が学びになる

## まとめ

| ポイント | 含意 |
|---------|------|
| 動画プランニングのツボは結局 **「どこで・誰に・何を」** | 戦略の基本に戻る |
| 検索広告データはターゲット理解にめちゃくちゃ使える | クエリ＝ユーザー意図がもろに出る |
| 同じことをやっている会社が競合とは限らない | 競合は保険ショップだった（マネードクターではなく） |
| 「**どのパイから顧客をとってくるか**」を考え抜く | お客さんとたくさん会話 |
| テストプランは**「本番環境を小さく再現すること」** | 本番をちゃんと言語化できる状態にする |
| 失敗した場合の設計を入れる | 上手くいかない可能性は低くない |
| **自分でもできる** | この資料を作ったのは青山さんではなく営業・運用の人 |

## So What — 太一としての示唆

- **「種まき」フェーズの言語化**が秀逸。「指名上げないと…ですよね？認知調査されてます？」のような疑問形での課題刷り込みは、CSの提案前パスとしてテンプレ化できる
- テストマーケ設計は「本番環境を再現する条件 → 再現できないものから除外していく」順で考えると整理しやすい
- 競合定義をJOBベース → 市場構造に降ろした流れは、新規LP案件のSTP整理にそのまま流用可
