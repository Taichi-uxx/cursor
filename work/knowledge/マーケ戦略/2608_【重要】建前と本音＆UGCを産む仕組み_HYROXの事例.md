## 用途（どんな時に活用できるか）

- クライアントに**「広告を回す前に商品体験の設計から見直す」**提案をしたいとき（訴求変更・CPA改善では突き抜けられないと感じているBRSの上流打ち手として）
- **UGC・紹介・オーガニック拡散が全然出ない**商材の、心理設計から仕込む枠組みとして
- **コミュニティ／イベント／体験型商品**を設計するときの、参加動機の言語化フレームとして
- 「そもそも自社商材がどの欲求に刺さっているのか、言語化できていない」クライアントに対する**欲求ラダー診断**の基盤として
- 新商品・新サービスの構想段階で、**"広告費をかけずに勝手に広がる形"を目指せるかの適性判定**として

## 記事の核（1行サマリ）

**建前（社会的に堂々と参加できる大義）で入口を開き、本音（人間の根源的欲求：帰属・承認・性）で回す。両者を1つの商品体験に組み込めば、参加者自身がSNSで拡散したくなり、広告費をほぼゼロに近づけられる。**

## Ⅰ. 中核フレーム：建前と本音の分離設計

### 定義

- **建前**：社会的に堂々と表明できる参加理由（健康・学び・スキル・自己成長・社会貢献など）
- **本音**：人間の根源的欲求（帰属・承認・出会い・優越・逃避など）。表向きに口にしにくい

### なぜ両方セットで必要か

- **建前だけ**：参加者の欲求が満たされないので、リピート・熱狂・拡散が起きない
- **本音だけ**：参加や投稿への心理的ハードルが上がる（自慢に見える／恥ずかしい／後ろめたい）
- **両立**：本音で燃料補給しながら、建前があるからSNSで堂々と投稿できる

### 商品設計の順番

1. どの本音（欲求）に刺すかを決める
2. その本音を満たす体験・仕掛けを設計する
3. その体験を**社会的に肯定される建前**でラッピングする
4. 参加者が**「建前の顔をした本音」を投稿できる**素材（写真・記録・成果）を用意する

## Ⅱ. 本音の設計 ── 人間の3つの根源欲求への刺し方

### 欲求① 帰属欲求：孤独な習慣に「集まる口実」を埋め込む

#### 抽象パターン

- 本来1人でやる孤独な習慣・活動には、**「みんなで集まる公式な口実」を作ると爆発**する
- 大人は同世代・同趣味の人と集まりたいが、そのための**理由**が要る
- 昭和平成の「飲み会」に代わる新しい**口実市場**が空いている

#### 設計要素

- **参加形態を複層化する**：ソロ／ペア／小グループ／大人数チーム、それぞれで参加可能に
  - → 一人でも寂しくない、恋人・友達・職場グループとも来れる
- **"一緒に取り組む"を公式ルールに組み込む**（ペア参加者が離れたらペナルティ等）
  - → 単なる同席ではなく、体験の中で協働が強制される
- **前後の余白を作る**：締切（大会日／リリース日）があると、その**前の練習・準備、後の打ち上げ・振り返り**まで含めて濃くなる
- **失敗の心理保険**：制限時間なし／完走率・成功率を極端に高くする → **「誘われた側が恥をかかない」**保険。エントリー・参加を迷わせない

#### 他ビジネスへの転用例

- 資格取得スクール → 個人／ペア／グループ受講、進捗共有部屋を公式化
- SaaS → 個人プラン／チームプラン／全社プラン、社内チーム対抗イベント
- 学習アプリ → フレンド機能／ペアラーニング／ギルド戦
- BtoB研修 → 部署単位／役職単位の"一緒に来る口実"設計

### 欲求② 承認欲求：顧客を"主役"にする仕組み

#### 抽象パターン

- 顧客・参加者を**プロやスター側の立場**に置き換えると、承認欲求が最大化する
- **費用と壁**は排除するのではなく、**"それを乗り越えた自分"のステータス化**に使う

#### 設計要素

- **参加のハードル（金額・スキル・準備）自体をステータス化**
  - 高い参加費 → 「出られる自分」がまず承認資産
  - 一定のスキル要件 → 「これができる自分」がフィルター
- **主役の逆転構造**：観客がお金を払って参加者を見に来る／消費者が生産者を応援する構造にする
  - 一般的な観戦・鑑賞は無料だが、この構造では**観る側が対価を払う** → 見られる側の希少価値が跳ね上がる
- **プロ品質のアウトプット素材を提供する**
  - プロカメラマン／プロ映像／プロ執筆／プロデザインの**"参加した証"** を用意する
  - 顔認識・自動個別化などテクノロジーで**全員分を確実に届ける**
  - **有料販売でも購入率が高い**（当該事例では約7割）＝それ自体が収益源にもなる
- **達成の可視化**：完走証／認定バッジ／スコア／順位表など、**投稿可能な達成物**を提供
- **建前の顔をした承認装置**：「頑張った」「達成した」「学んだ」の顔をして、実質は"イケてる自分"を提示できる

#### 他ビジネスへの転用例

- 資格スクール → プロ撮影の合格記念フォト／認定バッジ／修了式演出
- 会員制サービス → 会員だけの限定イベントで**会員を主役に**する構造
- ECブランド → 購入者のプロ品質着用写真キャンペーン
- BtoB SaaS → 顧客の導入事例をプロ品質記事＋動画で制作し**顧客を主役**に置く
- コミュニティ商品 → 卒業式・修了式・年次表彰など**イベント側で主役化**

### 欲求③ 出会い・性：直接言わないが"そう見える"場に見せる

#### 抽象パターン

- **「出会いの場です」と言わない**。ただし**"そう見える"体験にする**
- 「出会い」市場は昭和・平成の「夜×酒」形式の受け皿が沈み、**代替の受け皿が空いている**
- **参加動機を明示せず、視覚的印象で機能させる**のが肝

#### 設計要素

- **健康的・ポジティブな見た目に統一する**（暗い場所・夜・アルコール依存の対極）
- **男女比・年齢構成のバランスを取る**（片側だけに寄ると"そう見える"効果が消える）
- **参加者のビジュアル演出を許容する**（ファッション・コーデ・見た目に手をかける余地）
- 「出会いの場」と直接標榜せずとも、**参加者側から"○○は令和の出会いの場"**という声が上がる状態を作る
- ✕ 男性だけの競技会／女性だけのイベント：**"そう見える"効果が失われるので拡散が止まる**

#### 他ビジネスへの転用例

- ランニングクラブ／読書会／料理教室：**明示せず"そう見える"設計**
- コワーキング・シェアハウス：健康的で開かれた場に演出
- オンラインコミュニティ：適度な男女比・写真投稿文化の設計

## Ⅲ. UGCが自然発生する条件

上記3欲求を満たす体験を提供したうえで、**投稿を後押しする条件**が揃うと拡散が起こる：

### 投稿を促す4つの条件

1. **投稿素材が事前に用意されている**（プロ品質の写真・動画・スコア）
2. **建前があるので堂々と投稿できる**（健康・学び・達成の顔）
3. **セカンドバズを起こす著名人・インフルエンサーの参加動線**（一般人と同じ参加形式で出られる／出ることが本人のブランドにもなる）
4. **賛否含めた議論を許容する**：肯定派だけでなく批判・冷笑からの投稿も拡散燃料になる（**賛否含めて語られた時点で認知獲得は成功**）

### コンテンツの3段構造

インフルエンサー起点で自然に3段のコンテンツが生まれる：
- 準備段（申込・練習・仲間集め）
- 当日段（会場・体験・パフォーマンス）
- 結果段（達成報告・写真投稿・振り返り）

→ 商品体験の中に**時間軸で3段のコンテンツ機会**を仕込んでおくと、自然にシリーズ投稿になる。

## Ⅳ. 他ビジネスへの適用チェックリスト

自社商材で「広告費ゼロで回る」を目指すときの診断項目。

### A. 建前と本音の分離ができているか

- [ ] 自社商材の**社会的に堂々と語れる建前**を1行で言えるか
- [ ] 自社商材が刺している**本音の欲求**を1つ以上言語化できているか
- [ ] 建前と本音が**同じ体験の中で両立**しているか（片方だけになっていないか）

### B. 帰属欲求：集まる口実になっているか

- [ ] 参加形態がソロ／ペア／小グループ／大グループで**複層化**されているか
- [ ] 体験の中に**"一緒に取り組む"要素**が公式に組み込まれているか
- [ ] **締切・イベント日**があり、前後の余白（準備・振り返り）が濃くなる設計か
- [ ] **失敗の心理保険**（誰でも完走／初心者歓迎の明示）があるか

### C. 承認欲求：顧客が主役になっているか

- [ ] 参加ハードル（費用・スキル・準備）がステータス化されているか
- [ ] **観る側／応援する側**が対価を払う構造になっているか
- [ ] **プロ品質の"参加した証"素材**（写真・映像・記録・バッジ）を届けているか
- [ ] 素材が**個別化されて全員に届く**仕組みか（顔認識・自動生成など）
- [ ] 達成物が**投稿可能な形式**（画像・スコア表・証明書）になっているか

### D. 出会い・性：明示せずそう見えるか

- [ ] 商材の見た目・雰囲気が健康的・ポジティブか
- [ ] 参加者の男女比・年齢層のバランスが取れているか
- [ ] 参加者側から自然に**「○○は出会いの場」**と話題になり得る要素があるか

### E. UGC発生の下地

- [ ] 投稿素材が**参加後すぐ**に手に入る
- [ ] 参加体験が**時間軸で3段（準備／当日／結果）**に分解できる
- [ ] 著名人・インフルエンサーが**一般人と同じ形式で参加**できる
- [ ] 賛否両論の議論が起きても**炎上ではなく話題化**として消化される設計か

## Ⅴ. 太一の解釈と実務メモ

### 提案の入口を変える

- 従来の広告運用CS提案は「訴求変更→クリエイティブ改善→入札戦略見直し」の順が多い
- **その一段手前**、**"商品体験そのもの"に建前×本音の設計があるか**を診断する上流サービスを設計すれば、CPA改善では届かない突き抜けが出せる
- **提案時のフック**：「広告費をかけているのにUGC・紹介が1件も生まれない」「訴求を変えてもCPAが下がらない」「そもそも自社商材がどの欲求に刺さっているか言語化できていない」→ このどれかに"はい"なら、まず商品設計側の診断から

### 診断フレームを"3欲求ラダー"として資料化

- クライアント商材について、**建前1つ ×（帰属／承認／出会い／〔追加候補：優越・逃避・向上心〕）** をヒアリングで埋めるワークシートを作る
- 空欄が多いカテゴリー = **UGCが出ない構造的理由**
- 埋め切ったカテゴリー = **重点訴求候補・オーガニック拡散の起点**

### "投稿素材の事前設計"を必ず打ち手にする

- **顧客が投稿したくなる素材**（プロ品質の写真・シェアしたくなるスコア・ビフォアアフター・修了証）を、**商品体験の中に予め組み込む**
- 素材があるかないかで、UGC発生確率が桁違いに変わる
- BtoB案件でも「導入事例のプロ品質記事＋動画」を**顧客側の広報資産として使えるレベル**で作ると、紹介・言及率が上がる

### 「広告だけで成果」を売らない

- 元記事の結び：**「広告だけで成果が出るとは言わない」**
- REHATCHのCSポジションでも、**"商材が刺している欲求の見極めから一緒に設計"**をサービスの上流に置く価値がある
- 逆に言えば、**上流に踏み込まないCSは今後コモディティ化する**

### 現実的なスタンス

- UGCがゼロで回るのは希少事例（原文でも認めている）
- **UGCが出るのを待っていたら資金が尽きる**のが実態
- ただし**学ぶ順番は同じ**：闇雲に広告を回す前に「商品設計＋ユーザー心理」を洞察し、認知〜獲得を一気通貫で組む → **爆発的な成果はここから生まれる**。**広告はその中の1パーツ**

## 参考：HYROX事例のポイント（原典に触れたい人向け・最小限）

- 種目：1km走＋1種目を8回繰り返すフィットネスレース
- 直近シーズン：世界100大会超・150万人超参加（3年で16倍成長）
- 日本：横浜3,800人（2025年8月／初開催）→ 大阪8,087人（2026年1月）→ 千葉約12,000人（2026年8月）
- 参加費：約2万2,000円／観戦：約3,650円（大阪では観戦だけで6,173人）
- **有料広告ほぼゼロで売上200億円規模**（報道ベース）
- 出場形態：ソロ／ダブルス／リレー（ダブルスは並走ルールでペナルティあり）
- 完走率：98%超・制限時間なし
- 参加者写真：Sportografのプロカメラマンが全員撮影＋顔認識で個別配信、購入率約7割
- 芸能人・モデル・クリエイター参加でセカンドバズ
