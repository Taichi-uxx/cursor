# クリエイティブ戦略設計 — ストプラ的視点と実務フロー

**出典:** 社内勉強会資料「運用するクリエイティブ」/ 2023年9月  
**媒体:** 非特定（広告クリエイティブ全般）

---

## 用途（どんな時に活用できるか）

- 新規案件のキックオフ前に、クリエイティブ戦略の設計フローを整理したいとき
- 「なぜこの訴求を優先するのか」をクライアントに説明できる根拠を組み立てたいとき
- 担当案件のSTP・ターゲティング検証を改めてやり直したいとき
- クリエイティブブリーフを書く前の整理軸として使いたいとき

---

## 前提：なぜストプラ視点が必要か

> AIで大量バナーを作れるようになった今、人がやるべきは「質の高いクリエイティブを作る」こと。  
> 質を担保するには、**配信前の戦略的優先度付け（どの訴求から試すか）とPDCA設計**が不可欠。

クリエイティブ作成者がストプラ的視点を持つかどうかが、「作業者」と「戦略家」の分岐点になる。

---

## ストプラの実務フロー

| ステップ | 内容 |
|---|---|
| 1. オリエン | 与件・課題をヒアリング |
| 2. 3C分析 | デスクリサーチ＋デプスインタビュー |
| 3. 戦略策定 | リサーチ結果を基に戦略を組む |
| 4. クリエイティブブリーフ | 戦略をクリエイティブに落とす（一貫したストーリー） |
| 5. 壁打ち | 戦略仮説をクライアントにぶつけてディスカッション |
| 6. プラッシュアップ | フィードバックを反映して精度を上げる |
| 7. 提案 | |

### 主な調査手法

- **デスクリサーチ:** 自社・競合サービス内容、市場規模、SNSコメントなど多角的に収集
- **デプスインタビュー:** 複数のユーザー群で実施。インサイト深掘り＋戦略仮説の検証の場として使う
- **定量調査:** デスクリサーチ・デプスで見えた戦略の数字的裏付けとして実施（マクロミル等）

## フレームワークの活用

### 3C分析の整理順
**市場 → 競合 → 自社**の順に整理するとわかりやすい。  
※フレームワークを「穴埋め」として使うのは危険。平凡な戦略になりがち。目的はあくまで「仮説を導き出すこと」。

### STPによる戦略具現化

**セグメンテーションの4軸:**
- **デモグラフィック:** 年齢・性別・家族構成・学歴・職歴など
- **ジオグラフィック:** 国・地域・気候・文化など
- **サイコグラフィック:** 価値観・ライフスタイル・購入動機など
- **ビヘイビアル:** 購買頻度・使用用途・買い替えタイミングなど

**ターゲティングの確からしさを検証する視点:**

| 視点 | チェック内容 |
|---|---|
| **3C — Customer** | 市場規模・成長性・収益性はあるか |
| **3C — Competitor** | 競合との優位性差はどれくらいか |
| **3C — Company** | 自社の経営資源・戦略と整合しているか |
| **6R — RealisticScale** | 利益の出るボリュームがあるか |
| **6R — Rate of Growth** | 成長性はあるか。すぐ刈り尽くさないか |
| **6R — Rank & RippleEffect** | その塊を獲得すると連鎖的に取れる旨みがあるか |
| **6R — Rival** | そこを狙う競合は多くないか |
| **6R — Reach** | チャネル・メディアで到達可能か |
| **6R — Response** | 効果を測定できるターゲットか |

## 何を伝えるか — 4C分析で訴求軸を洗い出す

従来の訴求軸の洗い出しは「幅は広いが優先度が見えない」問題があった。4C視点で整理するとより鋭くなる。

1. **Customer Value（顧客価値）:** その商品が顧客にとってどんな価値をもたらすか
2. **Convenience（利便性）:** 使いやすさ・手軽さ
3. **Cost:** 価格・コスト面での優位性
4. **Communication:** 顧客対応・アフターサービスなど

→ デプスインタビューで仮説をぶつけ、リアクションで優先度を絞る。

## 戦略設計まとめ → クリエイティブブリーフへ

**Who / What / How で整理 → クリエイティブブリーフに肉付け**

クリエイティブブリーフは「戦略をクリエイティブに落とす橋渡し」。  
一貫したストーリーになっているかが品質の分岐点。

**まとめのフロー:**
1. 3Cで情報を整理しながらリサーチ
2. SWOTで仮説を立てる
3. STPで戦略を具現化
4. 4Cで訴求軸を絞り込み
5. Who/What/How → クリエイティブブリーフ

> **大事なこと:** フレームワークを埋めることが目的ではなく、「絞り込みと優先順位づけ」まで完遂すること。
