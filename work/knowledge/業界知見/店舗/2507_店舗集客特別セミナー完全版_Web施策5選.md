## 施策1：MEO（Googleビジネスプロフィール）— 経営者がやりがちなミス3つ

### ミス① 情報を全て入れていない
- 初期設定チュートリアルだけでは入らない項目がある → 管理画面で全項目埋まっているか必ず確認

### ミス② カバー写真が古い・クオリティが弱い
- **オープン直前にカメラマン投入**が理想（お客さんゼロ・最も綺麗な状態）
- 外観／内観／スタッフ／サービス提供の様子 **20〜30枚以上**アップ
- Photoshopでレタッチ（サビ・汚れ除去・色味調整）
- カバー写真は店舗の印象を決める → 何を選ぶかを意図的に決める

### ミス③ 低評価コメントを放置
- スタッフが**名乗って**返信すると自然な印象、承諾率も高い
- 実際に改善した内容を返信すると評価を付け直してもらえるケースあり
- **NG施策**：星5クーポン・低品質口コミ量産（Googleアルゴリズムがハック行為を減点）

## 施策2：リスティング広告 — 3つのポイント

### ① 業態名×エリア名/駅名に注力
- **ど真ん中ワード以外はCVに繋がらない**（実証済み）
  - ✗ ジム×所沢 → ピラティスへ横流し狙い → CV出ず
  - ✗ ピラティス×隣駅・西 → エリア外はCV出ず
  - ✗ 「痩せたい」等のニーズ換気ワード → 目ぼしい成果なし
- ✅ ピラティス×所沢（本命）でCV獲得

### ② 無駄な曜日・時間帯を切る
- 24時間365日配信は無駄が多い
- 実データ：夜中2〜6時はCVほぼゼロ → 配信停止
- 代理店では対応しにくい「奨学のチューニング」こそ内製化で効果大
- Google広告データ → Looker Studioで自動レポート化推奨（テンプレ提供あり）

### ③ 商圏以外の無駄な地域に配信しない
- 顧客の住所データ → Googleマイマップにマッピング → 実際の商圏を可視化
- 半径○km、市町村単位で配信エリアを絞る
- 感覚ではなく「実際の会員の来店データ」ベースで判断

## 施策3：SEO（詳細は別動画）
- 業態名×エリア名で1位を狙う → 「西新宿×パーソナルジム」型
- 記事量産ではなく**被リンク獲得でドメインパワー向上**が本質
- CVR最適化（サイトの魅力・オファー訴求）とセット

- LP/フォーム設計の最適化

## 太一の示唆
- REHATCHのクライアント提案でも使える「王道の全体像」— 特にMEO・リスティングは代行費用を圧縮しつつ内製化を促す文脈で使いやすい
- **Looker Studioでレポート自動化**は自分の案件でも即応用可能。管理画面の見づらさは店舗オーナーが動けない主要因のひとつ
