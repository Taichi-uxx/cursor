## 本文

### 第1章 | 基礎から学ぶBtoBマーケティング

#### 1-1. BtoBマーケティングの定義と全体像
- BtoBマーケ=**法人向け製品/サービスのリード獲得〜商談〜契約までの一連の活動**。
- 主業務は**リードジェネレーション（獲得）**と**リードナーチャリング（育成）**の2つ。
- 標準ファネル: **ブランド認知拡大 → 見込み顧客獲得 → 見込み顧客育成 → 有望見込み顧客 → アポ・訪問 → 商談 → 受注・リピート**。

#### 1-2. BtoB vs BtoC（比較表）
| 観点 | BtoB（高価格） | BtoC（低価格） |
|---|---|---|
| 対象顧客 | 法人・団体（複数） | 個人 |
| 利用者 | 購買者≠利用者のことも | 多くは購買者＝利用者 |
| 検討期間 | 長期 | 短期 |
| 重視点 | 機能・実績 | ブランド・付加価値 |
| 商材 | 生産財・資本財 | 完成品の消費財 |
| CVと売上 | CV≠売上 | CV=売上 |
- BtoBは**検討期間が長い・単価が高い・意思決定者が複数**＝CVから受注まで距離があるため段階的接触が必須。

#### 1-3. 全体プロセスと各フェーズの施策マッピング
- ブランド認知拡大 → 展示会／オンライン広告（見込み層）／SNS
- 見込み顧客獲得・育成 → オンライン広告（有望層）／セミナー／メルマガ／インサイドセールス
- 商談・受注 → セールス

#### 1-4. BtoBマーケが注目される背景
- ネット普及で**買い手は意思決定プロセスの57%を営業接触前に済ませている**（出典: The Digital Evolution in B2B Marketing）。
- 飛び込み/テレアポ/DMから、SEO・コンテンツ・メール等の**デジタルBtoBマーケ**への移行が加速。

#### 1-5. 代表プロセス「The Model」
- Salesforce.com発の組織営業ベストプラクティス。**フェーズごとに担当部署とKPIを設ける**ことで責任を明確化。
- フェーズ別KPI例:
  - 潜在獲得: 来訪者数 × 獲得率 = **見込み顧客数**
  - 育成: 見込み顧客数 × 案件化率 = **案件数**
  - 案件管理: 案件数 × 受注率 = **受注数**
  - 継続: 受注数 × 更新率 = **継続数**
- BtoB SaaSではまず徹底的に模倣→成果を積み上げてから自社カスタマイズ、が定石。

#### 1-6. 成功するポイント（4つ）
1. マーケを「コスト」ではなく**「投資」**として扱う（LTV/CAC/CPAで投資対効果を判定）
2. **決裁者がコミット**する（社員・役員クラスがPJに参画）
3. 経営・事業戦略から**目的と目標を設定**する
4. **定例会議でモニタリング**の仕組みを整える（実行こそカギ）

#### 1-7. 失敗するポイント（3つ）
1. 決裁権のない担当者だけで決める → 上申手間で施策が止まる
2. 知見のないメンバーだけで進める → スピードが落ちる
3. 定期的な数値確認の仕組みがない → 改善が回らない
- 推奨体制: **決裁者＋現場担当＋知見のある外部コンサル**。重要数値はSlack等で常時通知。

#### 1-8. 戦略立案（3C/SWOT/PEST → STP → 4C）
- 環境分析: **3C（顧客・競合・自社）／SWOT／PEST**。**一次情報を現場で掴むことが最重要**。
- STP: ①セグメンテーション（市場細分化）→②ターゲティング（どこを狙うか）→③ポジショニング（自社の立ち位置）。
- 価値定義の型: **「誰の」「何を」「どのように」** を1行で言語化し全メンバー共有。
  - 例: BtoB企業の／Webマーケの人・知識・環境の課題を／ノーコードツールと伴走サポートで解決
- 提供方法: **4C分析**（Customer Value／Cost／Convenience／Communication）も活用可。

#### 1-9. 戦略を戦術（具体施策）に落とす
- 認知〜CV〜商談まで全体像を描き、**段階ごとにユーザーの課題・心理**を考えて施策をリストアップ。
- 例（Web会議システム）の購買心理段階: 無関心 → 自分ごと化 → 課題認識 → 情報収集 → 比較検討 → 導入決定。
- オフライン施策マップ: TVCM/新聞/雑誌（無関心〜自分ごと化）→ セミナー・展示会（課題認識〜情報収集）→ セミナー・営業パーソン・商品説明・提案資料（比較検討〜決定）→ ユーザーイベント（リピート）。
- オンライン施策マップ: SNS・記事/タイアップ広告・PR・リサーチ・ブログ（広範囲）→ SEO・ダウンロード資料・用途活用例（中盤）→ LP・製品/サービスページ・価格表・お客様事例・FAQ・会社情報・オンラインセミナー・セミナーレポート・メルマガ（比較〜決定）→ オンライン注文（受注）→ 会員サイト・サポート情報（リピート）。

#### 1-10. 優先度の決め方:「CVに近いポイントから」
- 強化ステップ（CVに近い順、❶〜❹）:
  1. **サイト訪問→CV直前**: LP改善／コンテンツ強化／EFO／A/Bテスト／CTA設計
  2. **認知→サイト訪問**: SEO／広告出稿・改善／メディア露出／コンテンツ発信／SNS／イベント・展示会／DM
  3. **CV→商談**: 資料改善／MA導入／インサイドセールス導入・改善
  4. **商談以降**: 利用フロー改善／セールス改善／SFA改善／プロダクト開発／CS強化

#### 1-11. 顧客検討段階×施策（顕在度ピラミッド）
| 層 | 施策例 |
|---|---|
| 明確層 | 既存顧客深耕／紹介促進 |
| 顕在層 | リスティング広告／CVワードSEO／サイト改善／導入事例／LP作成／パートナー開拓 |
| 準顕在層 | セミナー／情報検索ワードSEO／記事広告／ホワイトペーパー／Facebook広告 |
| 潜在層 | PR／オフラインイベント／TVPR／SNS活用 |
- CV近い顕在層だけ攻め続けるとCPA高騰・受注率低下のリスク。**準顕在/潜在に拡張して市場をつくる**発想も併用。

#### 1-12. 実行で失敗する4ポイント
1. 継続しない／2. 責任者が不明瞭／3. 決めたことをやり切らない／4. 優秀な人材を採用しない
- 「思いつく施策が優れている」より**「施策を実行する能力」**が成果差。

### 第2章 | 施策別・具体的BtoBマーケノウハウ集

BtoBの主要リード獲得施策6カテゴリ: ①SEO・SEM ②自社サイト ③展示会 ④自社セミナー・ウェビナー ⑤テレビCM・交通広告 ⑥比較サイト・他社サイト活用。

#### 2-1. SEO・SEM
- SEMはSEO＋リスティング広告の総称。
- SEOの本質: 「検索者の質問に対する**回答**を用意し、検索で取り出されやすい状態を作ること」（出典: 土居健太郎『10年つかえるSEOの基本』技術評論社）。
  1. 検索者にとって**回答となるコンテンツ**を用意
  2. **クロール・インデックス登録**される状態を保つ
  3. アルゴリズムで優先表示される状態を作る
- **Point 1: 記事ネタは営業現場の質問から作る**
  > よく営業現場で質問されることです。その回答がコンテンツになります。
  - メリット: 確実な需要・企画不要・業務効率化（FAQ化）
- **Point 2: ツール活用**
  | ツール | 用途 |
  |---|---|
  | Googleキーワードプランナー | 月間検索ボリューム調査の定番 |
  | Googleトレンド | トレンド・リアルタイム検索の傾向 |
  | Neo Inspiration（neoinspire.net） | 共起語抽出 |
  | aramakijake.jp | 検索数予測・Yahoo検索量も確認可 |
  | Gyro-n SEO | 順位定点観測・競合比較 |
- **Point 3: SEOチェックリスト24項目**（一部抜粋）
  - パンくずアンカーテキスト変更／見出しタグ位置変更／h1テキスト変更／関連記事リンク／Titleタグ変更／フッターアンカー変更／HTMLサイトマップ／URL正規化／コンテンツ改善／著者情報追加／構造化データマークアップ／階層構造変更／ファーストビュー改善／内部リンク変更／関連記事追加・パンくず追加／はてな特化記事／TOPから各ページへのリンク増／重複コンテンツ正規化／低品質ページnoindex化／altタグ追加など
- **Point 4: リスティングは予算別で打ち手が異なる**

  | | 月額500万円以上 | 月額500万円未満 |
  |---|---|---|
  | おすすめ1 | 知見メンバーいれば社内運用 | 知見メンバーいれば社内運用 |
  | おすすめ2 | いなければ広告代理店 | 信頼できる知人・フリーランスに依頼 |
  | おすすめ3 | - | クラウド型自動化ツール（例: Shirofune） |
  - BtoBは**狙えるキーワードが限られる**ため最適化のための細かい調整が必要。

#### 2-2. 自社サイト（CVR向上）
- CVR = 成果地点（資料DL/問い合わせ等）への到達率。費用対効果を測る基本指標。
- **Point 1: CTA設計でCVRは2倍3倍に**。BtoBサイトでよく使うCTA14種:
  問い合わせ／資料請求／見積もり依頼／ホワイトペーパーDL／事例集DL／個別相談会／ノウハウ系セミナー／製品説明系セミナー／ワークショップ系セミナー／事例紹介系セミナー／カンファレンス／無料デモ／チャット／電話
- **Point 2: CVR観点の自社サイトチェック14項目**
  マイクロCV用意／CTA導線配置／CTAの動機付け／CTAは3つ以内／記事内容に合わせCTA設置／記事内容に合わせCTA文言変更／CTAはバナーでなくテキストリンクに／PCヘッダーにサイトテーマ記載／CVに繋がっているコンテンツ分析／CV経路デバイス分析／CV経路集客分析／ソーシャルボタン上下設置／ソーシャルボタンに数表示／CTA文言を分かりやすく（例: ebook→お役立ち資料）
- **Point 3: BtoB特有のフォーム最適化（EFO）**
  - BtoCでは入力少ない方がCVRは上がるが、**BtoBはCV後に商談を挟むため項目を極端に減らすと商談化・受注率が下がる**。
  - 「リード数を増やしたい」vs「リード質を保ちたい」のバランス調整が肝。
  - フォーム改善8チェック: 入力時間記載／入力しやすい項目から始める／営業に役立つ項目を入れる／必須と任意の使い分け／送信ボタンがファーストビュー内に収まる／資料の場合は内容説明／対象者を記載／資料の一部チラ見せ。
  - Google Analyticsで離脱率把握 → EFO改善（Entry Form Optimization）。
- **Point 4: 事例コンテンツの活用**
  - BtoBでは導入事例・事例インタビューが**「実際に導入したらどうなるか」のイメージ補助**として重要。
  - 事例集の活用シーン: 展示会/セミナー配布物／商談時資料／社内回覧資料／既存リードへのメール配信／Web掲載リード獲得用。
  - 導入事例チェックシート6項目: 獲得したい顧客層に近い事例を載せる／件数増えたら検索機能（参考: Sansan）／フォームは段階的に／成果を明記／事例集としてまとめる／展示会・セミナーで配布。

#### 2-3. 展示会
- 高単価商材や複数決裁者商材ではWebのみの意思決定が難しく、**対面接触で信頼感醸成・関係値構築**ができるオフライン施策として依然強力。
- メリット: 普段会えない層と会える／トークで魅力訴求。デメリット: コスト高（1回200万円以上が多く、**受注単価100万円以上推奨**）。
- **事前準備6注意点**
  1. 予算・目標策定: 展示会は**潜在層**へのアプローチがメイン。受注ではなく**アポ・セミナー誘導**をゴールに。
  2. 出展位置: **角の小間**が来場者が訪れやすい。
  3. 集客方法検討: ハウスリストへのメール告知／広告／SNS／サービスサイトにバナー（メインコンテンツの邪魔にならない設計）。
  4. 看板コピー・デザイン: 「何の／誰向けのサービスか」を一瞬で理解できる短いコピー。視認性の高い配色。
  5. ノベルティ作成: 接触頻度高い（捨てられにくい・目に触れる）or インパクト（他社と違う・意外性）で検討。
  6. チラシ・パンフレット: ブースと同じデザインで持ち帰り後の想起を助ける。業界別事例載せると自分ごと化しやすい。
- **当日の対応**
  - 明るく元気よく対応（ブランディング影響）／SNS投稿促進（ハッシュタグ告知・休憩スライドで投稿OKアピール）。
- **開催後フォロー3点**
  1. フォローメール送信（遅くとも翌日／写真・配布資料添付／サービスサイト誘導）
  2. 重要見込み客にはセールスから電話、**1週間以内にアプローチ完了**
  3. オウンドメディアに開催レポート掲載
- **複数回接触で段階的ナーチャリング**（Yappli・庵原氏の事例参考）
  - 展示会（リード獲得）→ カンファレンス（リード育成・成功事例共有）→ 自社イベント（ファン化・懇親会セット・年2回以上開催）

#### 2-4. 自社セミナー・ウェビナー
- 展示会比で**低コスト**かつ**少人数で密度高い**コミュニケーション可。
- **Point 1: 企画6パターン**
  1. 自社ノウハウ共有
  2. 業界トレンド・パネルディスカッション形式
  3. 関係値の濃い顧客に登壇してもらう
  4. 自社製品説明・デモ
  5. ターゲット重なるがサービス領域違う企業と共催
  6. 少人数の勉強会形式
- **Point 2: 目的を再確認**
  - 広くリード獲得目的 → **無料・中規模セミナー**
  - 受注目的 → **有料・小規模セミナー/ワークショップ**（スクリーニング効果）
- **Point 3: 集客方法6つ**
  1. 自社サイト掲載／2. 既存リードへメール／3. 公式SNS・社員個人SNS／4. Facebook広告／5. Peatix・connpass等イベプラットフォーム／6. 営業から個別メール
- **Point 4: 少人数セミナー（5〜10名）のススメ**
  - 個別具体話ができる／質疑応答盛り上がる／後の相談・懇親会率高い。
  - 「50名集めるより5〜10名の方が商談化数・受注数が高かった」というBtoBマーケターの声。
  - 人手少なくて済む／レンタルスペース不要のメリット。
- **Point 5: 質疑応答活性化の工夫**
  - 待ち時間に音楽／司会・登壇者のアイスブレイク／質問してもらえる場づくり／参加者同士の会話ワーク／教室型でなく対面しやすい配置／Sli.do等で書き込み質問。
- **Point 6: ウェビナーのメリット/デメリット**

  | | オフライン会場 | ウェビナー |
  |---|---|---|

#### 2-5. テレビCM・交通広告
- ITリテラシー低い層への訴求、**タクシー広告は決裁者層に多い**ため決裁者認知獲得に有効。
- **Point 1: 直接効果＋間接効果でROIを見る**
  - ROI = （直接効果＋間接効果）÷ コスト
  - 直接効果: サイト訪問数増／問い合わせ増／受注率向上
  - 間接効果: **商談期間の短縮／単価の向上／採用応募数増加**

### 第3章 | リード獲得後からの商談率を高める（2023年版追加章）

「リード獲得はできるが商談に繋がらない」課題への対処。**マーケ×セールス連携の4ステップ**。

#### 3-1. 目指すKPI
- 単純なCV数ではなく、**MQL数／アポ数（率）／商談数（率）／受注数（率）**を共に追う。
- マーケのコントロール外要素（受注キャパ等）が多いため、まずは IS（インサイドセールス）と一緒にMQL・アポ・商談数まで追う。

#### 3-2. 連携4ステップ

##### Step 1: MQLを定義する
- MQL（Marketing Qualified Lead）= セールスがアプローチすべき確度の高いリード。
- 例 ①アクション基準: 検討度高いアクション（問い合わせ・サービス資料DL）／MAスコア基準到達（メルマガからサービス紹介ページクリック・料金ページ再訪等）
- 例 ②フォーム情報基準: 有効な電話番号／個人でなく企業／BtoB事業をしている／企業規模30名以上／企業HPが存在
- 定義は厳しすぎると母数不足、緩いと営業負荷増。**運用しながら定期見直し**。
- フォーム項目に反映し、レポートで自動抽出できるように設定。

##### Step 2: レポート作成
- 流入経路 × 訴求/テーマ × CV数 × MQL × アポ数 × アポ率 × 商談数 × 商談率 × リードの質 を一覧化。
- 例（資料より抜粋）

  | 流入経路 | 訴求 | CV | MQL | アポ | アポ率 | 商談 | 商談率 | 質 |
  |---|---|---|---|---|---|---|---|---|
  | オーガニック（サービスサイト） | - | 200 | 150 | 60 | 40% | 57 | 95% | ○ |
  | リスティング | LP-A | 50 | 45 | 18 | 40% | 17 | 95% | ○ |
  | リスティング | LP-B | 100 | 80 | 20 | 25% | 18 | 90% | △ |
  | ホワイトペーパー | WP-A | 150 | - | 12 | 8% | 10 | 83% | 要ナーチャ |
  | ホワイトペーパー | WP-B | 50 | - | 3 | 6% | 2 | 67% | 要ナーチャ |
- 経路・訴求別に「リードの質」が見える状態を作るのがゴール。

##### Step 3: 定期MTG開催
- 頻度: 週1／隔週／毎月など意義あるサイクルで。
- 3種類の情報を交換:
  1. **定量フィードバック**: 結果・施策の改善案
  2. **定性フィードバック**: テレアポ・商談時の生反応（例: ターゲット外の問い合わせ増→広告Aに寄せる）
  3. **施策アイデア出し**: 顧客興味・課題からマーケ施策ヒント

##### Step 4: 仮説→お互い改善を実行
- マーケ: アイデアを実現形に落とし実行（例: キーワード予算試験運用）
- IS: 施策ストーリー理解し、リード経路別にトークスクリプト・送付資料を変える

#### 3-3. セールスのアポ率・商談率を高める機能
- **リアルタイム通知**: Slack/Chatwork/Teams連携でセールスがリアルタイム受信→**30分以内にアプローチ**。
- **商談予約**: 資料DL/問い合わせサンクスページから商談予約や無料デモ体験ができる仕組み。
- ferret One自社運用で効果実証済み。

#### 3-4. リード獲得後の取組まとめ
- マーケとセールス連携必須／MQL・アポ・商談などの質の高いKPI／レポート・定期MTG／商談率を上げる仕組み実装。

### 第4章 | 事業責任者向け｜BtoBの事業目標設定

#### 4-1. 投資と人員配置のステップ（1〜3年）
- Step 1: BtoBマーケの土台作り（戦略設計・サイト作成・分析改修） — GOAL: 顧客起点のサイト＋PDCA回せる
- Step 2: 新規顧客獲得（SEO・広告・集客型セミナー） — GOAL: 新規が一定数獲得しPDCA回る
- Step 3: 顧客育成（メルマガ・クロージング型セミナー） — GOAL: リスト育成から一定アポ獲得
- Step 4: 営業連携（SFA連携・スコアリング・ABM） — GOAL: 優先顧客スコアリング・顧客管理基盤構築
- 1年目はStep1-2中心、2年目Step2-3、3年目Step3-4の進行イメージ。

#### 4-2. LTV（Life Time Value）が求められる理由
- LTV = （購買単価 × 収益率）×（購買頻度）×（契約継続期間）−（顧客獲得・維持コスト）
- 「LTVを意識した経営」サイクル: 既存売上増 → 紹介増・マーケ予算増 → 新規獲得効率化 → ロイヤリティ向上 → 売上増の好循環。

#### 4-3. 広告費計画もLTVから算出
- **ユニットエコノミクス（1顧客当たり採算性）3倍以上を目指す**。
- 例: LTV 600万円（3年）÷ 3 = **CAC上限 200万円**
- LTVには上限なし。**LTVを高めることで投資余力＝広告予算が増える**。

#### 4-4. 顧客獲得単価（CPA）の最適設定

  | 項目 | 数値 |
  |---|---|
  | 購買単価 | 100万円 |
  | 購買頻度 | 2回/年 |
  | 契約期間 | 2年 |
  | 収益率 | 20% |

  - **LTV非加味**: 購買単価 × 利益率 = 100万 × 20% = **CPA上限 20万円**
  - **LTV加味**: 購買単価 × 購買頻度 × 継続期間 × 利益率 = 100万 × 2 × 2 × 20% = **CPA上限 80万円**
  - LTV加味で**4倍の柔軟な目標CPA**設計が可能 → 打ち手が広がる。

#### 4-5. KGI と KPI を別建てで置く
- KGI（重要目標達成指標）例:
  - 3ヶ月で成約数1.5倍／1年で売上2倍／半年でSNS経由セッション3倍
- KPI（中間目標）例:
  - 2ヶ月でセッション1.25倍／3ヶ月でCVR1.2倍
  - 半年でアポ1.6倍／1年で成約率1.3倍
  - 3ヶ月でTwitterフォロワー2倍／半年でCTR1.5倍
- 明確な期限と数値目標をセットで決め、進捗管理。

#### 4-6. KPI算出の考え方（営業プロセス係数）
- BtoBは目標売上/受注件数から逆算して必要リード数を出す。
- **商談プロセス係数の目安**:
  - **商談化率（リード→商談化）: 20〜30%**
  - **案件化率（商談化→案件化）: 40〜60%**
  - **受注率（案件化→受注）: 20〜40%**
- ※リード商談化率はリードソース・サービス単価で大きく変動するため目安。

#### 4-7. 売上から割り戻す具体例

  ```
  広告 月間100件 ┐
  メルマガ 月間50件 ┼→ リード数200件 →(商談化20%)→ 商談40件 →(案件化50%)→ 案件20件 →(受注25%)→ 成約5件
  オフライン 月間50件 ┘
  ```

#### 4-8. 受注目標とKPI整合性
- チャネル別のアポ率・案件化率・受注率を加味して全体設計。
- 例（資料抜粋）:

  ```
  リード①広告 100件 (アポ率20.0%) ┐
  リード②オーガニック 50件 (アポ率40.0%) ┼→ 商談 計45件 →(案件化25.0%)→ 案件11件 →(受注率30.0%)→ 受注3件
  リード③オフライン 50件 (アポ率10.0%) ┘                                                  × 受注単価400万円 = 売上1,200万円
  ```
- **受注単価 ≒ LTV**を算出しておくと売上予測も可能。月の受注件数目標から設定するのが進めやすい。

#### 4-9. 目標設定ポイントまとめ
- LTV計算で最適CPAが見えてくる
- 各施策の目標=KPIを仮置きしPDCA
- 最後にKPI ⇄ LTV・CPAで整合性チェック
