## 概要

D2C/リピート通販で成功するために抑えるべき論点を「ビジネスモデル → 顧客起点 → KPI設計 → EC運営の落とし穴 → 事業の脅威 → ECシステム要件」の流れで体系化したホワイトペーパー。

要点は以下の3つに集約される。

1. **「顧客データ」を自社の資産として直接握れるかが全ての起点**。モール出店では取れない顧客データを基に、商品開発・CRM・ファン化の好循環を回す。
2. **新規獲得は赤字スタートが前提。LTV（顧客単価×継続期間）で投資回収する事業構造**。F2転換率（2回目購入の継続率61%が損益分岐点）を最重要KPIに据える。
3. **獲得（広告/LP/フォーム一体型）×育成（同梱物/ステップメール/LINE/コールセンター）×解約防止（継続特典/お届け事前通知/マイページ）の3点セット**を回し、業務はオートメーション化して肥大化を防ぐ。

本資料は実際にはW2 Repeat（ECカートシステム）の販促ホワイトペーパーであり、後半（P45以降）はプロダクト紹介。前半のD2C/リピート通販の方法論パートが汎用ナレッジとして再利用価値が高い。

## 本文

### 1. 成功するD2C事業について（ビジネスモデルの種類と成功事例）

#### 1-1. サブスクリプションビジネスの3モデル

| モデル | 概要 | 商品例 | サービス例 |
|---|---|---|---|
| 定期購入型 | 特定の製品を販売 | 飲料水、サプリ、化粧品、日常消費財 | Amazon定期おトク便、健康食品/化粧品定期便 |
| 頒布会型 | 企業側がコースを設定し、毎回異なる商材を販売 | 食品、酒などの飲料系 | オイシックス、ドラフターズ（アサヒビール） |
| 利用権利型 | サービス/コンテンツの利用権を貸与 | ソフトウェア、デジタルコンテンツ、家具、車 | Netflix、Laxus（ブランドバッグ）、無印のサブスク、KINTO |

#### 1-2. サブスクリプションビジネスの成功要素 10点

1. お悩み系は商品は1種類、食品は頒布会
2. 自社や商品の信頼性を高める施策や仕掛けが設計されている
3. 定期的に消費される商品
4. モール出店ではなく自社サイト販売
5. 業務は可能な限り外注し、頭を使っても手を動かさない
6. 自社ブランドのサブスクで不動の地位を築くブランディング
7. 企画・製造・販売のシンプルな構造を自社管理
8. 自社でデータを蓄積できるシステムがある
9. **UI/UXがスマホに最適化されている（健康食品と化粧品は85%がスマホ）**
10. 直接ユーザーとつながり、顧客の一次情報を取得し顧客体験（CX）に反映できる

#### 1-3. 成功事例ハイライト

- **オイシックス**: 「暮らしの選択」を提供。"Oisixを使っている自分を好きになる"というプラスアルファ価値。定期ボックスの中身を**カスタマイズしない会員は解約しやすい**というデータを基に、未カスタマイズ会員へアラートを出して解約率低下に寄与。社長も月に1回は顧客宅を訪問。
- **ネスレ日本（ネスカフェアンバサダー）**: マシン無料レンタル＋カプセル継続購入モデル。2012年開始から4年で日本国内登録28万件→**2021年3月時点で49万人**。定期便会員総計**100万人**超、サブスク事業売上**100億円超**。Eコマース比率は2016年8月の12%→2019年3月発表で20%（売上2,020億円中約400億円がEC売上と推定）。
- **世田谷自然食品（せたがや日和）**: 商品宣伝なしのライフスタイル情報サイトをCRMの一環として運営。**メルマガ経由の売上が約20%アップ**。読者は告知をきっかけに自ら販売サイトへ流入。
- **アサヒビール（ドラフターズ）**: 本格泡リッチサーバーを貸し出し＋スーパードライ月2回配送。**LINEを活用したUX**（ソーシャルログイン、お届け日/数量変更、配送サイクル変更を全てLINE上で完結）。会員との「共創」を基本方針に。
- **はぐくみプラス**: 妊活/妊婦/赤ちゃん向けサプリ・化粧品EC。お手紙・プレゼント・会報誌など「絆を築く」アナログ×デジタルCRM。**CV・LTVが30%アップ**。LINE@導入で問合せ応対を半減しリピート施策に注力。
- **レッドビジョン（マイナチュレ）**: ヘアケアD2C。「商品を売るより**ブランドの世界観を伝える**」サイト設計。ポイントステージの最上位顧客に花束を贈るなど顧客視点の施策で**売上60億円**目標。
- **キナリ（草花木果）**: 「日本の自然由来」を貫く自然派化粧品。自社通販サイトが**販売の95%**。Instagram/読み物コンテンツでブランド力を高め、データ分析で「お客様を知る」ことを共通認識化。

### 2. ビジネスモデルの考え方

#### 2-1. 消費財商品（サブスクに向いている商品）のポイント

> サブスクリプションに向いている商品は、「商品のサイクルが長すぎないもの」、「価格が高すぎないもの」と言われています。

| 区分 | 適した特徴 |
|---|---|
| 化粧品 | 人の「悩み」に関連 / 無くなれば補充が必要 / 継続することで効果が表れる |
| サプリメント | 目的は健康「維持」 / 無くなれば補充が必要 / 継続することで効果が表れる |
| 食品 | スーパーで手に入らない厳選食材・調味料 / ブランドのファンに向けたサービス / 「今日何食べよう？」から解放される |

**重要**: 商品数より、**いかに長く購入してもらえるか（購入期間）**の方が重要。

#### 2-2. 利益の考え方（LTV型損益）

> 一度顧客を獲得すれば、同一の顧客から継続する限り、収益が安定。

- 広告等の獲得投資コストでスタートはマイナス。継続期間によりLTVが向上するためCPA・CPOを下げられる。
- 継続顧客からの利益が積み上がり安定収益化。LTV増加によりROASが向上 → 広告投資額の上限を算出可能に。

> LTV（顧客単価×継続期間）は継続期間に応じ増加

#### 2-3. LTVを向上させる分析の進化（やずや式CPM）

- **やずや式CPM**: 新規顧客の2年後の継続率が**80%**、社員60人で売上**300億**。「目先の売上ではなくLTVをKPIにすべき」という顧客ポートフォリオ理論。
- RFM分析（優良客/見込み客/新規客/離反客の4分類）の欠点である「離反客の中に隠れた優良客を見逃す」問題を解決。
- 「購入金額」「在籍期間」「離脱期間」の3軸で顧客を**10グループ**に分類:
  - 現役: 初回現役 / よちよち現役 / こっこっ現役 / 流行現役 / 優良現役
  - 離脱: 離脱初回 / 離脱よちよち / 離脱こっこっ / 離脱流行 / 離脱優良
- **「離脱」ステージを設けることでお客様への適切なコミュニケーションを再開できる**点が秀逸。

#### 2-4. 自社サイトとモールの比較

| 観点 | モール | サブスクリプションモデル（自社） |
|---|---|---|
| 顧客データ | 取得できない | 自社で取得可能 |
| ブランディング | できない | 一貫性のある展開が可能 |
| 顧客ロイヤリティ | 低い | 高い（ファン化） |
| リピート率 | 低い | 向上が図りやすい |
| 価格 | 価格競争が起きやすい | 価格決定権を自社で持つ |
| 利益率 | 低い | 高い |

> 全ては「顧客データ」が起点

※モールの活用は販路拡大やブランディング目的など、自社サイトと役割を分けることが必要。

### 3. D2Cを成功させるために重要な顧客起点

#### 3-1. 顧客データの声を起点に進化する事業（価値創出の好循環）

```
「顧客データ」を直接入手（自社固有資産として蓄積）
       ↓
「顧客データ」から顧客が求める商品・サービスを開発（付加価値提供／価格競争回避）
       ↓
ニーズにマッチしファン顧客化（固定ファン獲得）
       ↓
（最初に戻る）
```

#### 3-2. 定期通販におけるD2C事業のポイント（W2導入企業の平均売上成長率 354%）

D2C事業ではサプライチェーンを自社中心に構築する必要があり、新規顧客獲得と同時に**「獲得した1人のユーザーにいかに継続してもらうか（LTV）」**が重要。

新規獲得・顧客育成に必要な6要素:

| 要素 | 役割 |
|---|---|
| 広告 | 新規顧客の獲得目的。リスティング、アフィリエイト、ディスプレイ、リタゲなど多様 |
| ランディングページ | 顧客を刈り取るためのページ。デザインや構造のABテストを繰り返し最適化 |
| カートシステム | EC運営の心臓部、データが蓄積される基盤。マーケティング/受注処理など日常業務、各システムへのデータ連携 |
| 物流 | 倉庫で梱包作業〜出荷まで。**梱包と同時に同梱物（チラシ等）も重要なCRMツール** |
| 商品開発 | 商品企画後、製造工程。よいOEMパートナーの選定が重要 |
| コールセンター | 解約防止や問合せ対応。電話受注時はオペレーターのアップセル・クロスセル提案が重要 |

#### 3-3. D2C事業のビジネスモデル（3つの柱）

1. **世界観の共創**: 製品サービスの使用体験、一貫したブランド展開
2. **長期的な顧客関係構築**: 顧客データ保有、固定客化
3. **高い利益率**: 価格競争回避、直接販売

#### 3-4. LINEの活用

- 2021年日本国内アクティブユーザー数**約9,000万人**、50代以上も**1,400万人**（参考: Twitterの50代以上は約400万人）。**LINEはインフラ化**しており「若者のツール」ではない。
- プッシュ通知やトーク画面活用頻度、迷惑メールフォルダがないことから、**LINEメッセージ開封率はメール比3倍**。
- 全世代を通じて毎日利用頻度が高い。

### 4. KPIの設定と施策例（最重要セクション）

#### 4-1. 定期通販における顧客区分と新規/引上げ施策

| 顧客区分 | 顧客の状態 | 新規獲得/引上げ施策 |
|---|---|---|
| 見込顧客 | 商品/ECサイトにアクセスしている | SEO対策/導線設計、外部広告（専用LP） |
| 一般顧客 | 単発購入している、会員登録している | 初回購入の特別価格/値引き、初回購入の限定クーポン、初回購入の限定お試しセット、外部広告（専用LP） |
| 定期顧客 | 定期購入している | 定期専用の特別価格、定期申込の特典（同梱）、外部広告（専用LP） / 定着施策: 定期申込後のフォローメール、定期継続の特典（同梱）、定期継続の特別価格 |
| 優良顧客 | 定期購入＋他商品も購入＋SNS発信している | 長期定期利用の特典（同梱）、アップセル/クロスセルの特典、SNS連携/投稿の特典、専用LP |

階段: 見込顧客 → 一般顧客化 → 定期顧客化 → 定期定客 → 優良顧客化

#### 4-2. 定期通販におけるD2C事業のKPI

| 新規顧客獲得（LTVから逆算して投資可能額を決定） | 既存顧客育成（CRMでLTV向上） |
|---|---|
| CPR | 定期引上率 |
| CPO | F2転換率 |
| 定期CPO | 定期継続率（解約率） |
| 顧客単価 | クロスセル率 |

#### 4-3. 販売手法: ワンステップ vs ツーステップ

| ワンステップマーケティング | ツーステップマーケティング |
|---|---|
| 初回から定期商品を販売 | お試し商品から販売 |
| ツーステップに比較しCPOは高くなる | ワンステップに比較しCPOは低くなる |
| クロスセルなどでLTVを向上させる | **引上率20〜40%を目標** |

→ 市場と商材に合わせ、自社にあった販売手法を選択する必要がある。

#### 4-4. 新規顧客獲得: 広告の種類と特徴

| 広告 | 特徴 | メリット | デメリット |
|---|---|---|---|
| リスティング | 検索結果上部に表示 | SEOよりダイレクト流入、手軽 | 購入につながらない場合も費用発生 |
| ディスプレイ | Google/Yahoo!提携サイトに画像で表示 | 視覚訴求、幅広いユーザーに訴求 | 細かなルールあり審査厳しい |
| リターゲティング | 一度訪問したユーザーに再訪促進 | 売上に繋がりやすい | 新規ユーザー獲得には不向き、運用ノウハウが必要 |
| SNS | FB/Twitter/Instagram等のタイムラインに表示 | ユーザー属性に合わせ文言/画像変更可 | 該当SNS利用者にしか届かない、炎上リスク |
| アフィリエイト | ASP経由で様々なサイト/ブログに掲載 | 成果報酬制、無駄広告費少ない | どのページで紹介されているか把握しにくい |
| メルマガ広告 | ポイントサイト等のメルマガに広告出稿 | 積極的アクセスが期待できる | アクセスが成果に直結しにくい（目的はポイント稼ぎ） |

> **業界平均CVRは2%前後、指名検索は10%以上が合格ライン**

#### 4-5. 新規顧客獲得: LP制作のポイント

- LPの質はCPOに直結。一度作って完了ではなく**PDCAで最適化**必要。
- **画面遷移を少なくするフォーム一体型LPは必須要素**。確認画面・サンクスページでアップセル/クロスセルで定期引上げ・顧客単価UPに繋げる。
- 構造: LP（ABテスト） → 注文確認画面（アップセル/クロスセル） → サンクスページ（アップセル/クロスセル） → 数値分析でPDCA。

> **LPの質 ＝ キャッチコピー × コピーライティング × デザイン**
> LPのPDCAを回すことでCVRが400%以上改善する場合もある

#### 4-6. 新規顧客獲得: その他

- **インフルエンサーの活用**: 特にZ世代は企業広告より好きなインフルエンサーの紹介を信じる傾向。Instagram/TikTokを通じた販促が注目。**フォロワー単価1〜3円程度**で発信が可能。マスアプローチからコミュニティアプローチへ。
- **Pay関連キャンペーンの活用**: PayPay等のキャッシュバックは消費者購買行動に大きな影響。ID決済への対応有無がサイト売上に影響。

#### 4-7. 既存顧客育成: CRM

> 定期通販は恋愛に比喩されるビジネスモデル。
> 新規（初回）購入 = 交際スタート / 定期購入の継続 = 円満な交際

「いかに自社のブランドを知ってもらい、いかに好きになってもらえるか」という企業努力が継続率に繋がる。

**自社ブランドを知ってもらうには**:
1. 製品開発の背景や当時のエピソードを紹介
2. 他商品とどのような点が違うのかを訴求
3. どのような思いで作られた商品なのかを訴求
4. ユーザーにどのような価値を与えるのかを訴求

**既存顧客育成**:
1. ユーザーのニーズを理解し満足度向上（お問合せ対応、メール配信などタッチポイント全ての品質向上）
2. 大衆向けではない1to1アプローチ（誕生日目つ、定期継続率の高いユーザーに1to1施策）
3. 自社とユーザーのコミュニケーション頻度向上（SNSでの口コミ収集など）

→ **ファン化が促進されたユーザーは、ロイヤルカスタマーとなり、高い継続率を維持。⇒ LTVの最大化**

#### 4-8. 既存顧客育成: 定期引上（ステップメール）

ステップメールで商品レビューやお客様の声を「届ける」ことで心理的ハードルを下げ、必要以上にお得感をアピールせず「長く使うことで健康をサポートできる」というメリットでアピールする（品質への不信感を抱かせない）。

**ステップメール例（新規購入後）**:

| タイミング | 内容 |
|---|---|
| 発送から3日後 | フォロー |
| 7日後 | フォロー |
| **14日後【販促】** | レビュー / クロスセル |
| **21日後【販促】** | クーポン / 定期紹介 |
| 30日後 | お客様の声 / SNS紹介 |
| **45日後【販促】** | 特別セール / ポイント倍 |

→ 14日後以降に初回リピート成功シナリオへ分岐。

#### 4-9. 既存顧客育成: F2転換率（最重要KPI）

> 本商品を購入してもらえればその後のリピート率は大幅に上がる傾向にあり、2回目の購入が増えれば売上を順調に伸ばすことができます。

F2転換率を上げる最大の鍵は**タイミング**。**2回目購入の継続率は初回購入から2ヶ月を過ぎると大きく下がる**。フォローアップは初回購入から2ヶ月以内が大きなタイミング。

**回数別 継続率/離脱率**:

| 回数 | 2回目 | 3回目 | 4回目 | 5回目 | 6回目 | 7回目 | 8回目 |
|---|---|---|---|---|---|---|---|
| 継続率 | **61%** | 38% | 31% | 27% | 25% | 23% | 22% |
| 離脱率 | **39%** | 62% | 69% | 73% | 75% | 77% | 78% |

> F2転換率を向上させることがLTVを向上させることにつながり、事業の安定成長を実現することができます。

#### 4-10. 既存顧客育成: 同梱物（**開封率100%**）

**ユーザーの心を掴むコミュニケーション**:
- ユーザーに自社ブランドを好きになってもらう
- 定期購入への引き上げ
- 定期購入の解約を防止
- モールのお客様も同梱物で個人情報を取得

**同梱物の3系統**:

| 系統 | 内容 |
|---|---|
| お手紙施策系 | 購入に対しての御礼と挨拶（定期購入は交際スタートの状態）、既存ユーザーの声（第三者の意見で信頼up） |
| 引き上げ施策系 | 定期購入によるお得なキャンペーン、A商品を買った人はB商品も、新商品のサンプル |
| 解約施策系 | 商品の正しい使い方を案内 ⇒ 解約理由である**「商品の余り」**を防止 |

> 同梱物の開封率は**100%**、LTV最大化に同梱施策は不可欠

#### 4-11. 既存顧客育成: オフライン対応（コールセンター）

> コールセンターを上手く活用すれば、LTV向上、ユーザーの満足度向上など実現できるが、逆に上手く活用できなければ、解約率の向上、最終的にはブランド、企業イメージのダウンにもつながる。

**主要な解約理由 BEST3**:
1. **余っている**
2. **効果がない**
3. **金銭的**

→ 解約希望に対し、スキップを促す/正しい使い方を案内する/ダウンセルの案内をする、など適切な対応で解約率を抑える。VOCとして蓄積し、製品やサイト運営に活かす。

**重要観点**: LTVを最大化するためにはコールセンターを**コスト部門としてではなく、カスタマーサクセス（攻めの姿勢）として見ることが重要**（カスタマーサポート=待ちの姿勢、と区別）。

### 5. EC運営の落とし穴

#### 5-1. 業務の種類と分類（専門性が高い／売上影響が大／ルーティン業務）

| 業務 | 専門性 | 売上影響 | ルーティン |
|---|---|---|---|
| 戦略（Web戦略/事業計画/リソース管理） | ○ | ○ | × |
| 企画（商品/キャンペーン/コンテンツ） | ○ | ○ | × |
| 集客（web広告/SEO/SNS/メルマガ） | ○ | ○ | × |
| 制作（サイト/クリエイティブ/ページ更新） | ○ | ○ | × |
| 運営（商品登録/受注処理/サイト更新） | × | × | ○ |
| コールセンター（顧客対応/VOC/解約処理） | × | × | ○ |
| 物流（梱包/配送/同梱） | × | × | ○ |

→ **下3つはオートメーション化対象**。

#### 5-2. 収益を左右する業務のポイント

- 売上が上がることに比例して業務（受注/物流/CRM）が増大しルーティン業務肥大化。**物流業務が基幹業務を圧迫**。
- 複数モール出店や自社サイト並売で販売チャネルが多岐に渡り、注文情報や顧客管理が煩雑化。**戦略や企画に使う時間が失われサイトの成長を止める**。

#### 5-3. 課題を解決するデジタライゼーション（オートメーション化）

- **成長を止めない事業インフラを構築**: ルーティン業務（定型施策とバックヤードオペレーション）を自動化し、売上UPでも業務がボトルネックにならない構造を作る。
- **バックヤード業務の効率化**: OMS/WMSを活用しバックヤード自動化を推進。空いたリソースをマーケティング施策や新商品開発に集中させる。

### 6. 事業の脅威と対応について

#### 6-1. 不正注文とセキュリティ対策

- 2020年日本国内BtoC-ECの市場規模**19.3兆円**。クレジットカード不正注文被害は**2019年: 234億円 → 2020年: 253億円**と増加傾向。
- チャージバックによる売上損失も拡大（カード会社/購入店舗に支払取消要求 → EC事業者は返金で売上損失）。

**主要な脅威**: フィッシング / 転売ヤー / カード盗難 / スキミング

**セキュリティ対策**:
- IDS/IPS等、世界基準のセキュリティ対策
- 3Dセキュア（本人認証）の標準実装
- 不正注文/不正検知サービスの活用（O-PLUX、O-MOTION等）
- 第3者機関によるセキュリティ診断、ISMSによる組織対策

#### 6-2. 快適なお買い物体験と機会損失

**表示速度の影響**:
- Amazonの調査: サイト表示が0.1秒遅くなると売上1%減少、1秒高速化で売上10%向上。
- 米Aberdeen Group調査: ページ表示速度が1秒遅くなると**PV: 11%減、CVR: 7%減、顧客満足度: 16%減**。

**アクセス集中とサイバー攻撃**: DOS攻撃、BOTからの大量アクセスによる被害が増加 → サーバダウンで機会損失。

### 担当D2C案件への落とし込み

#### 戦略軸 — クライアントへの提案レバー

1. **「LTVから逆算した投資可能額」をクライアントと握り直す**
   - CPA改善を目的化しがちな広告運用CSとして、本資料の**F2継続率61%（2回目）→ 38%（3回目）→ 31%（4回目）**の業界相場を持ち出し、**「うちのF2は何%か、損益分岐は何回目か」**から逆算した広告投資上限を再設計する提案ができる。
   - 現状CPAではなく「2ヶ月以内のF2転換率」を共通KPIに昇格させる打ち手。

2. **「広告 × LP × 同梱物 × CS」の4点セットで提案する**
   - 広告運用だけでは限界がある（業界平均CVR 2%、指名検索10%が天井）。**同梱物の開封率100%**という事実を武器に、運用外の打ち手（同梱物設計／ステップメール14・21・45日／コールセンタートークスクリプト）まで提案範囲を広げる。
   - これは「単純なCPA改善ではなく、売上・利益に直結する施策」という自分のスタンスそのもの。

3. **解約理由の3大要素「余っている／効果がない／金銭的」に対する具体打ち手リスト化**
   - クライアントヒアリングで「解約理由TOP3とその対応策の有無」を確認するチェックリスト化。
   - 「余り」対策 = 同梱物で正しい使い方案内 / スキップ提案
   - 「効果」対策 = 利用者の声・ステップメール
   - 「金銭」対策 = 継続割引・継続回数特典
   - W2のフレームを借りるだけで、提案の網羅性が一気に上がる。

#### 戦術軸 — 即提案できる施策

4. **フォーム一体型LP導入による CVR 2〜3倍を狙う**
   - 既存LP案件で、購入フローが6ステップ型ならフォーム一体型LP移行を提案。確認画面・サンクスページでのアップセル/クロスセル設計もセットで。
   - 「LPのPDCAでCVR 400%改善事例」も提案の説得材料として持っておく。

5. **ステップメール/LINE配信シナリオの標準テンプレを作る**
   - 3日後/7日後/14日後/21日後/30日後/45日後のメール配信シナリオを、自分のスタンダードとして保存（本資料の図がそのまま使える）。
   - LINEはメール開封率の3倍。LINE未導入クライアントへの導入提案を1案件ピックして試す。

6. **顧客ステージ別 価格設定/特典のマトリクスを案件横展開**
   - 「見込→一般→定期→優良」の階段で、それぞれに対する**特別価格／同梱／クーポン／専用LP**のマッピングを作り、CRM施策の抜け漏れチェックに活用。
   - 既存案件で「優良顧客への施策ゼロ」のクライアントを洗い出すと、伸びしろが見える可能性。

#### 振り返り軸 — So What?

7. **「ファン化＝LTV最大化」を自分の発信テーマにも転用できる**
   - D2Cで「商品を買ってもらって終わりではなく、好きになってもらう」という発想は、自分のコンテンツ発信（contents/）にも転用可能。
   - 「LTVを上げる発信」「F2転換率（2投稿目以降のリピート閲覧率）」という捉え方で、自分のSNS運用にも応用できないか検討。

8. **コールセンター = カスタマーサクセス（攻め）／サポート（待ち）の対比は他業界にも転用可**
   - 広告運用CSとしての自分のスタンスも、「待ちのレポート提出」ではなく「攻めの売上提案」が必要、というメタファーとして社内/個人発信で使える。
