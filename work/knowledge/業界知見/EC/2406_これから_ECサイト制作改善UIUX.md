### 1. ECサイトの売上構成

#### 1-1. EC事業の課題（運営者調査）
> 株式会社これから(2019)『通信販売事業に関する調査報告書』 n=300より

- EC/ネットショップ事業運営の課題上位は「**新規集客**」と「**サイトUI/UX**」。
- いずれも売上に直結しやすい領域であり、ここをセットで改善することが売上向上の最短ルート。

#### 1-2. 売上の方程式
- 実店舗: 売上 = 来店数 × 購入率 × 客単価
- ネットショップ: **売上 = 訪問者数 × 購入率 × 客単価**

#### 1-3. 戦略・戦術の策定イメージ（要素分解）
売上向上のためには「**売上 = 購入件数（流入数 × 購入率）× 購入単価**」の要素分解からスタートする。

| 階層 | 要素 | 主な打ち手 |
|---|---|---|
| 流入数の増加 | 自然検索 | SEO対策 |
| | 広告 | 広告配信 |
| | SNS | SNS運用 |
| | リファラル | アライアンス／PR |
| | 再訪 | CRM施策 |
| 購入率の増加 | 回遊率改善 | 特集ページ制作・回遊導線設計 |
| | カート追加率改善 | 商品詳細UI改善 |
| | カート通過率改善 | カート/フォーム最適化 |
| | CVR改善（UI/UX改善） | AIによるUI解析、GA/ヒートマップ解析 |
| | 新規 vs リピーター別 | デバイス別（PC/SP/タブレット）・ページ種別（トップ/一覧/詳細）で設計 |
| 購入単価の増加 | 客単価UP | クロスセル・アップセル、レコメンド |

> Instagramなど集客施策の成果を最大化させるためには **購入率の強化** が必要。

### 2. 購入率アップ施策

> 基本方針: **CVRが高いページへの流入数を増やしてCVを伸ばす**。
> ステップ: ①CVRが高いページを抽出 → ②CVRが高いページへの流入数を増やせる導線を検討 → ③実装 → ④効果検証
> 改善インパクトが大きいページ（CVRが高くアクセス数が少ないページ等）から着手する。代表ツールはGoogle Analytics。

#### 2-1. 特集ページ

- 特集ページは**通常の商品一覧ページよりも購入率が高い**。網羅的に用意することが有効。
- 特集パターンは多岐に渡るので、**年間を通して制作**を進めることで成果が拡大する。

##### 季節特集（押さえるべきはまず季節イベント）
- 商材と相性のいいイベントを選定し、**毎月イベントに合わせた特集コンテンツが公開できるよう企画**を行う。
- 例: バレンタイン、母の日、夏物、ハロウィン、クリスマス、福袋など。

##### 通年特集
- ランキング、新着アイテム、**インスタ掲載商品**、再入荷など、通年で活用できる特集ページも網羅。
- 結果としてサイト内の回遊性が向上し、購入率が向上しやすい。

##### スケジュール／物量目安
- 季節ごと・通年それぞれ分けてスケジュールを組む。
- **50ページ以上のアーカイブ**を目指して展開していくと効果的。

#### 2-2. 共通部分（ヘッダ/FV）

##### ニーズ別振り分け（FV）
- ターゲットが異なる商品を扱う店舗では、**ユーザーをファーストビューでニーズ別に振り分ける**。
- ニーズに合った商品のみを提案できるページへ誘導することで、CVRを高める。

##### フリーワード検索窓のFV設置
- **フリーワード検索窓をファーストビューに設置**し、検索誘導を強化。
- 展開式（クリック展開）ではなく、**検索窓が露出しているタイプ**を採用するとさらに利用率が高まる。

#### 2-3. トップページ

##### SNSと同じクリエイティブで掲載
- Instagramで紹介した商品を**SNSと同じクリエイティブでサイトにも掲載**。
- インスタのファンユーザーがアプリ上で気になった商品を、サイト上でもすぐに探せるように配慮する（一貫性のあるトーン&マナー）。

#### 2-4. 商品一覧ページ（カテゴリページ）

##### 最上部にカテゴリ内ランキング
- カテゴリーページ最上部には、**閲覧中のカテゴリー内の人気ランキング**を表示。
- 人気アイテムを最短で閲覧させることで、迷うことなく商品ページへ誘導でき、CVRが高まる。

##### 下位カテゴリへのリンク
- 商品一覧よりも**上部に下位カテゴリへのリンク一覧**を配置。
- 顕在化したニーズをもったユーザーが、商品を探す手間を極力減らし、ユーザビリティを向上。

##### 並び替えボタン
- 商品一覧上に**並び替えボタン**を配置し、現在の並び順は強調表示。
- デフォルトの並び順は「**新着順**」とし、最新のアイテムから順に並ぶようにするとよい。

##### NEW/SALE/再入荷ラベル
- 商品一覧には**NEW・SALE・再入荷などのラベル**をつけて、比較検討を促進。
- 複数のラベルを同時に付与することを想定して、サイズ感・デザイン・レイアウトを調整する。

##### 割引率・打ち消し線
- セール商品には、**○○%OFFなどの割引率や、割引前の価格を打ち消し線で強調表示**。
- 値下げ対象の商品がどれかわかりやすくすることで、商品詳細ページへの遷移率が向上。

#### 2-5. 商品詳細ページ

##### FV内カート導線
- **ファーストビュー内にカート導線を表示**して、購入導線を明確にする。
- オプションなどの要素は**ポップアップ形式で格納**することで縦幅を圧縮するのもよい。

##### 商品画像は「サイズ感／着用感／使用イメージ」
- 「**サイズ感」「着用感」「使用イメージ」が湧く画像を複数枚用意**し、商品画像だけで購入を判断できる状態を目指す。
- セット商品の場合は、**セット内容を明確にする**ことも重要。

##### カートボタン付近の安心訴求
- カートボタン付近には、**送料無料条件・利用可能な決済方法（Amazon Pay等）・獲得ポイント・特典**などを表示。
- 購入に対しての心理的ハードルが軽減され、CVRが高まりやすくなる。

##### 残在庫数の表示で締め切り感を演出
- 残り在庫数が少ない場合には、カートボタン付近に「**残りわずか**」や「**残り○個**」を表記。
- 在庫が切れてしまう締め切り感を煽ることで、今すぐ買いに繋げる。

##### 再入荷お知らせボタン
- 在庫切れ商品には**再入荷お知らせボタン**を設置し、再入荷時にユーザーへ通知を送信できる仕組みを用意。
- リクエストは**バリエーション毎に受付**できるレイアウトを採用すると効果的。

##### お気に入り追加ボタン
- お気に入り追加ボタンは**カート追加ボタンと並べて配置**することで利用率を高める。
- バリエーションがある商品は、**バリエーション毎にお気に入り追加**できるレイアウトを採用。

##### 比較・併売導線
- 同種でスペックの異なる商品は比較検討の上で購入される。
- ページ上部に**比較される商品への回遊導線／比較表／併売される商品への導線**を設置することで、ユーザーの検討を促進。

##### 追従型カートボタン（SP）
- 縦に長くなりやすいスマートフォンサイトの商品詳細は、**追従型のカートボタン**を設置。
- ページ内のどこからでもカートインできる仕組みにすることで、カートイン率を高める。

#### 2-6. 外部ツール導入による底上げ

##### ソーシャルギフト（eギフト）
- ギフト向け商品の販売促進には**eギフトの導入がマスト**。
- 相手の住所を知らなくても**LINEやSNSでギフトを贈れる**から、購入ハードルが下がりCVRが高まる。

##### レビュー・UGCツール
- SNSのUGCやユーザーレビューを**自動収集→ECサイトへ自動掲載→購入導線まで一気通貫**で提供。
- 検索結果に**スターレートが表示**されるため、CTR（アクセス数）とCVR双方の向上が期待できる（例: kitai 等）。

### 3. チェックリスト（実務向け診断シート）

> 各ページのチェック項目を抜粋整理。【運用】は運用フェーズで定常的に回す施策、〈重要〉は優先度の高い項目を示す。

#### 3-1. トップページ（共通ヘッダー）
- 想定ユーザー: **ファン度の高い既存ユーザ**が利用するページ。新規ユーザへの配慮は不要。
- 役割: 入口ページ／回遊後の気持ちのリセットページとして行動の起点になる。共通ナビゲーションも同様。
- 狙い: 「特集」「新商品」「お気に入り」「購入履歴」「再入荷」「閲覧履歴」など**様々な商品一覧への誘導**。

**ファーストビュー**
- フリーワード検索導線を目立たせる 〈重要〉
- 特集を「画像＋テキストリンク＋テキスト解説」で数個露出し、残りの特集すべてを掲載した特集一覧に誘導する 〈重要〉
- CVRの高い特集を評価し、配置順を変更する 【運用】

**ページ中部**
- 新商品を「画像＋商品名＋価格」で数個露出し、新商品一覧へ誘導 〈重要〉
- お気に入り／購入履歴／再入荷／閲覧履歴／セール／カート内商品 を露出し各商品一覧へ誘導
- オススメする商品一覧へ誘導（商品詳細数個露出＋もっと見るリンク）

**共通ヘッダナビゲーション（※ハンバーガーメニュー含む）**
- お気に入り／購入履歴／再入荷／閲覧履歴／セール／カートへのリンクを張り、**値下げ／再入荷／在庫少をバッジ通知**する 【運用】〈重要〉
- 全商品に辿れるように**主要カテゴリを10個前後**配置する
- マイページへの入口を配置する

#### 3-2. 商品一覧ページ
- 新規向け: 直帰させず目的商品へスムーズに誘導しつつ、**このECで購入する理由を刷り込む**（送料無料/Web限定など）
- 既存向け: **他の切り口の商品一覧への回遊導線**を強化し、定期回覧を促進
- 感性で選べる商品は**写真を多く表示できるタイル形式**が選びやすい（≠理性型は1カラムで縦に並べる方が選びやすい）

**ファーストビュー**
- 商品が最低1行は見えるように上部エリアを圧縮 〈重要〉
- 下位カテゴリ／関連特集へのリンクを配置（数が多い場合はアコーディオン）〈重要〉
- ECの強みを細いバナーで訴求（◯◯品揃えNo1／送料無料／Amazon Pay可／70%OFFセール開催中など）【運用】〈重要〉
- 絞り込み機能へのリンクを配置し、特にCVRの高い導線を目立たせる
- 並べ替えリンクを配置し、現在の並び順を商品一覧上に明示
- フリーワード検索導線を配置

**ページ中部**
- 商品画像＋商品名＋価格＋口コミをタイル形式で並べる 〈重要〉
- Web限定／当店限定／人気No1〜3／値下げ／再入荷／NEW は商品画像にラベル 【運用】〈重要〉
- フローティングリンクでCVRの高い特集に誘導 【運用】〈重要〉
- 上からランキング順に3個→「ランキングをもっと見る」誘導→その下から新着順に商品表示

**ページ下部**
- オススメする商品一覧／特集へ誘導 【運用】〈重要〉
- パンくずリンクを表示

#### 3-3. 商品詳細ページ
- 新規向け: 直帰されないようにサイト内に誘導しつつ、このECで購入する理由を刷り込む
- 既存向け: カート直行以外に、**再訪時の購買に繋がるお気に入り／再入荷登録を促す**。商品一覧への回遊導線も強化
- 写真だけで選べるように、**サイズ感／着用感／使用イメージが湧く画像を複数用意**

**ファーストビュー**
- サイズ感／使用イメージが湧く画像を複数用意 【運用】〈重要〉
- Web限定／当店限定／人気No1〜3／値下げ／再入荷／NEW のラベル付与 【運用】〈重要〉
- 価格の右か直下に、送料無料条件／Amazon Pay可／獲得ポイント／特典 を表示 〈重要〉
- 残り在庫数が少ない場合に締め切り感を煽る 〈重要〉
- ECの強みを細いバナーで訴求（◯◯品揃えNo1／70%OFFセール開催中など）【運用】

**ページ中部**
- カート追加／お気に入り追加を並べて配置 〈重要〉
- 在庫切れ商品には再入荷希望ボタンを設置 〈重要〉
- 比較される商品／併売される商品への回遊動線を設置 【運用】〈重要〉
- 購買に繋がりやすい口コミを表示 【運用】〈重要〉

**ページ下部**
- オススメする商品一覧／特集へ誘導 【運用】〈重要〉
- パンくずリンクを表示

#### 3-4. カートページ
- 購入手続きへの遷移ボタンは**ファーストビューに設置**し、何も思考させずに購入手続きに流す
- **送料無料バーへの残金**を表示したうえで、**スーパーのレジ前商品**のようについで買いしたくなる商品を並べる
- カート投入商品の数量変更／削除は必須だが、「**あとで買う**」も用意し、お気に入りリストに残せるようにする

**購入手続きへの導線**
- ファーストビューに購入導線への直行リンクを張る 〈重要〉
- Amazon Payできることを明示 〈重要〉
- スクロール時に購入導線へのリンクが追従

**送料表示**
- 送料無料になるまでに必要な金額を強調表示 〈重要〉
- 送料目安とヘルプを表示（ログイン前等で表示不可なら「有料／無料」だけでも良い）

**カート投入商品一覧**
- 数量変更／削除／後で買うをカート内で行えるようにする

**レジ前商品リスト**
- 「**後で買う ＞ もう一度買う ＞ 閲覧履歴 ＞ お気に入り**」の優先度順に商品リストを表示 〈重要〉
- 値下げ／在庫僅かの商品があれば強調して通知 〈重要〉
- 代替品／併売品も表示

> 注意事項: 各サイトでCVRの高いページは異なる。自社のCVRの高いページを知りたい場合はレイアウト診断（無料）へ。
> 例: オーダーカーテンECの「注文の仕方」ページ／アウトドア用品ECの「テントの立て方」動画／後払い決済の訴求 など。

## 太一視点の示唆 / 次のアクション

### 示唆
1. **「集客 × CVR」のセットで売上は伸びる**: 広告運用CSとして「広告でCPA下げる」だけでなく、**LP/サイト側のCVR改善メニュー**を提案できると、同じ広告予算で売上を2倍以上に押し上げられる。「ここから成果を2倍にするには？」の問いに対しては、**広告（流入数）×サイト（CVR）×購入単価**の3軸分解が常套手段。
2. **CVRが高いページを抽出 → 流入数を増やす**: GA分析で「**高CVR・低アクセス**」ページを特定し、そこへトップやヘッダから集中導線を引く。これは広告のLP選定にも応用可能（広告流入は最もCVRの高い特集ページに送る、など）。
3. **特集ページは"CVR資産"**: 通常の一覧より購入率が高く、毎月の季節特集＋通年特集で**50ページ以上のアーカイブを目指す**運用は、SNS/広告のリンク先弾切れも防げる。EC案件に対して「**特集ページ年間カレンダー**」を提案できる。
4. **商品詳細ページのチェックリストは即戦力**: 〈重要〉項目だけでも12項目あり、これをそのまま**クライアントECの診断シート**として使える。特に「FV内カート導線／追従型カート（SP）／カートボタン付近の安心訴求／残在庫表示／お気に入りとカートの並列配置」は実装ハードル低くインパクト大。
5. **カートページの「レジ前商品」発想**: 後で買う→もう一度買う→閲覧履歴→お気に入りの優先順位は**客単価UPの実装ガイド**としてそのまま使える。広告でCV取った後の「もう一品」設計まで提案できると、ROAS向上に直結する。
6. **eギフト・UGCツール導入は外部レバレッジ**: 自社改修なしでCVRを押し上げる外部ツール導入の提案カードを持っておく。特にギフト商材を扱うEC、レビューが少ないEC案件にハマる。

### 次のアクション
- **担当EC案件のチェックリスト診断**: 上記3-1〜3-4のチェックリストを元に、現在担当しているEC案件のサイトを**ページ別に診断シート化**する（〈重要〉項目で◯✕△を付ける）。
- **改善ロードマップ化**: 診断結果から「**①FV／カート導線などインパクト大かつ実装容易**→②特集ページ年間設計→③UGC/eギフト等の外部ツール導入」の3段階ロードマップに整理し、クライアント提案資料に落とす。
- **広告施策との接続**: 担当案件で「広告流入の着地LP」を見直し、**CVRが高い特集ページ・カテゴリページに広告を寄せる**A/Bテストを設計する。
- **横展開ナレッジ化**: 「商品詳細ページの〈重要〉12項目チェックリスト」を独立したマークダウンナレッジに切り出し、別案件でも即時参照可能にする（`work/knowledge/業界知見/EC/` 配下）。
- **AI-Studioへの組み込み検討**: lp-build / copy-build スキルのEC案件適用時に、本資料の**ページ別チェックリスト**を「採点項目」として組み込む（特にFV／カート導線／安心訴求のチェック）。
