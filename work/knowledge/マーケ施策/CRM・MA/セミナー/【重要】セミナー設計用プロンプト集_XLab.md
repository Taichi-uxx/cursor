# AI自動化プロンプト20種 STARTER KIT（Claude × WebinarBase）

## 出典
- **発行元**：株式会社エックスラボ SeminarBase 事業部（責任者：中山 晃希）
- **形式**：セミナー参加者向けSTARTER KIT（PDF・全32ページ）
- **制作日**：2026年4月（v2改訂 — スライド設計プロンプトを2段階化し、台本の直後に配置）
- **原本の出処**：当社制作の WebinarBase AI Skills v2.0.1 に含まれる各スキル定義より、一般の生成AI環境でも活用できるよう再編集
- **入手経緯**：セミナー「セミナーで商談をつくる方法」の参加特典
- **利用条件**：個人利用の範囲内（社内利用OK・第三者への複製譲渡/公開/類似サービス制作は禁止）
- 参照：https://app.box.com/s/ha4w0wvuxx5tu69tlu7ynkjdubkxcvgo

## 用途 — どんな時に活用できるか

### 1. 自社/クライアントのセミナー・ウェビナー準備の丸ごと短縮
- ターゲット設計 → 台本 → スライド → LP → 広告まで一気通貫でAI下書き作成
- 「毎回、白紙から考えるのがしんどい」時のテンプレとして即使える
- ChatGPT / Claude / Gemini どれでも動く形式（プロンプトのみ・ツール依存なし）

### 2. LP・広告コピー制作の効率化（セミナー以外にも転用可）
- No.15「LPキャッチコピー生成（AIDA）」、No.16「LP全文構成（新PASONA準拠）」はセミナー以外のLPにも流用可能
- No.17「Meta広告メインテキスト（PAS法）」、No.18「Google検索広告（RSA）生成」はクライアントの広告運用でそのまま使える
- No.20「キャッチコピー4U採点ブラッシュアップ」は、書いたコピーの品質判定に汎用的に使える

### 3. AIプロンプト設計の"型"の参照
- 各プロンプトは「役割定義 → 入力情報（変数化）→ 出力してほしいもの → 制約」の共通構造。**自作プロンプトの型として応用可**
- 特にNo.14（スライド設計 2段階プロンプト = STAGE1構成設計 → STAGE2 PPTX化）は、Claude ArtifactsとPPTX生成の使い分けの実例として参考になる

### 4. クライアント/社内での「AI活用」提案の実物ソース
- 「AIをこう使うと何が短縮されるか」の具体例を、20カテゴリ分の実物プロンプトで示せる
- 提案書に「例：Metaメインテキストを5本量産、5〜10分」など、AI活用の即効性を具体数字で示せる

| スライドだけ先に作りたい | 03 → 06 → 14 |

### 使い方 — 3ステップ
1. お使いのAI（ChatGPT / Claude / Gemini）のチャットを開く
2. プロンプト本文を丸ごとコピー。本文中の`{中括弧}`部分を、自身のセミナーテーマ・ターゲット・商品情報に置き換える
3. AIの出力を叩き台にして、自分の言葉・トーンで仕上げる

### ポイント
- 1つ目のプロンプトの出力を、次のプロンプトの入力情報にすると精度がどんどん高まる（連結が効く）
- 「もっと具体的に」「別の切り口で」と追加指示で深掘り可能
- 長文全体を一度に完璧にしようとせず、セクションごとに仕上げるのがコツ

## 各プロンプトの詳細（本文＋概要）

### No.01 ターゲットペルソナ深層リサーチ
- **カテゴリ**：ターゲット・ペルソナ
- **得られること**：属性だけでなく、悩み・欲求・感情・購買トリガーまで立体的に言語化する。セミナー全体の訴求軸を固める最初の一歩
- **使うタイミング**：セミナー設計を始める前 / LP・広告のコピー方針を決める前

#### プロンプト本文
```
あなたは講師業向けの深層リサーチャーです。
以下のセミナー情報をもとに、受講生像を立体的に言語化してください。

#入力情報
- セミナー・講座のテーマ: {テーマ}
- ざっくり想定ターゲット: {年代・職業・状況}
- セミナー後に売りたい本商品: {商品名・価格帯}
- 講師自身がかつて抱えていた悩み: {あればストーリー}

#出力してほしいもの
1. 基本プロフィール(名前仮名・年齢・職業・家族構成・年収・情報収集チャネル)
2. 一日のリアルな行動タイムライン(朝〜夜の行動と感情)
3. 悩みの3層マップ
   - 表面の悩み(口に出せる)
   - もう少し深い悩み(認識はあるが言いにくい)
   - 根本の悩み(感情・自己評価・恐れ)
4. 感情プロフィール(理想の姿・現在の感情・講座への期待・不安)
5. 購買トリガー3つ以上
6. このペルソナに刺さる言葉・キーワード5〜10個、避けるべき言葉も併記
7. 別角度の有望サブペルソナを2案(メインとの違い・狙い目の理由付き)
```

### No.02 競合リサーチ・差別化整理
- **カテゴリ**：競合分析
- **得られること**：直接競合・間接競合を俯瞰し、自社がどこで勝てるかを言語化。LP・広告の差別化コピーに直結する素材
- **使うタイミング**：セミナー設計 / LP原稿 / 広告コピーの前段

#### プロンプト本文
```
あなたは講師業・教育サービスの市場調査アナリストです。
以下の自社サービス情報をもとに、競合分析レポートを作成してください。

#入力情報
- 自社サービス概要: {内容・提供形式}
- 価格帯・提供形式: {月額/単発/成果報酬など}
- 意識している競合(あれば): {競合名・URL}

#出力してほしいもの
1. 直接競合5社(同ターゲット×同課題×類似価格帯)
   各社: サービス名/提供者/価格帯/提供形式/強み/弱み/集客チャネル
2. 間接競合5社(同ターゲットの同じ課題を別手段で解決)
3. 自社 vs 競合の比較表(比較項目: ターゲット/価格/提供形式/強み/弱み)
4. ポジショニングマップ(縦軸=価格帯、横軸=提供形式の軸で自社と競合を配置)
5. 自社の差別化戦略3ポイント(どこで勝てるか・どう伝えるか・避けるべき戦い方)
6. LP・広告に使える「刺さる差別化コピー」3案
```

### No.03 60分セミナーの全体設計
- **カテゴリ**：セミナー設計
- **得られること**：ノウハウ型ではなくセールス型の心理設計で、成約率が高く参加者満足度も高いセミナー構成
- **使うタイミング**：セミナーの企画段階 / タイムラインを決める時

#### プロンプト本文
```
あなたは講師業専門のセミナー設計者です。
以下の情報をもとに、60分のクロージング型セールスセミナーの
設計書を作成してください。

#入力情報
- 誰向けか(ターゲット): {具体的属性+悩み}
- 何を提供するか(商品・サービス内容と価格): {詳細}
- 参加後どう変わるか(ベネフィット): {得られる変化}
- 講師の実績・権威性・ストーリー: {信頼の根拠}
- オファー内容(価格・特典・日時・申込方法): {詳細}

#出力してほしいもの
1. セミナー種別の判定
   (リードジェネ型/ナーチャリング型/クロージング型のどれか+理由)
2. セールス型セミナーの心理的流れ
   ①自分の問題に気づかせる
   ②原因の腑落ち
   ③解決の方向性
   ④この人なら解決できる
   ⑤自然な次のステップとして商品提示
3. 60分のタイムライン
   (黄金比: 本編30分・クロージング15分・Q&A10分・オープニング5分)
4. 各ブロックで伝える内容・心理状態・演出(実演/事例/質問/ワーク)
5. 10分ごとのインタラクション設計(離脱防止)
6. KPI・数値目標(参加率・成約率・CPA目安)
7. 集客・フォローアップ設計
```

### No.07 オープニング「つかみ」作成
- **カテゴリ**：台本パーツ
- **得られること**：冒頭5〜10分で「聞く価値がある」と確信させ、離脱を防ぐつかみ
- **使うタイミング**：セミナー冒頭の台本を書く時 / ウェビナー離脱率を下げたい時

#### プロンプト本文
```
あなたはセールスセミナーの冒頭設計の専門家です。
以下の情報をもとに、セミナー開始から10分以内で
「聞く価値がある」と確信させるつかみを作成してください。

#入力情報
- ターゲットの最大の悩み: {悩みを一言で}
- セミナーで得られる最大のベネフィット: {60分後にどうなるか}
- 講師の権威性・実績: {数字・肩書・経験}
- セミナー内で実演するもの(あれば): {内容}

#出力してほしい要素
1. 冒頭30秒の挨拶スクリプト(長くしない)
2. 期待値セット「今日終わったら○○ができる」の具体的宣言
3. 最後まで見る理由を作る「特別オファー予告」
4. インパクトのある問いかけor数字(スクロールを止める第一声)
5. 講師の自己紹介(参加者にとっての価値から逆算・30秒版と1分版)
6. 全体の流れの説明テンプレート(3点に絞る)
7. 最初のインタラクション(チャット呼びかけ or 挙手)

口語調で、実際にそのまま読める文体で出力してください。
```

### No.08 悩みの3層構造言語化
- **カテゴリ**：台本パーツ
- **得られること**：参加者が「自分のことだ」と感じる自分事化パート。LPの問題提起・広告コピーにも流用可
- **使うタイミング**：セミナー台本の共感パート / LP問題提起セクション / 広告コピー

#### プロンプト本文
```
あなたは講師業の共感ライティング専門家です。
ターゲットの悩みを3層構造で言語化してください。

#入力情報
- テーマ: {講座テーマ}
- ターゲット: {具体像}

#出力してほしいもの
1. 表面の悩み(本人が言語化できて、口に出せる悩み) 3つ
   例: 「集客がうまくいかない」
2. 中間の悩み(認識はあるが言いにくい悩み) 3つ
   例: 「SNSで発信しているのに反応がない」
3. 根本の悩み(感情・自己評価・恐れの核心) 3つ
   例: 「自分の価値を正しく伝えられていない気がする」

#さらに各悩みに対して
- そのまま使える代弁フレーズ(「○○ですよね」「○○、ありませんか?」)
- セミナーチャットで共感を引き出す問いかけ
- 広告・LPのFV(ファーストビュー)で使える短いキャッチコピー

参加者が「この人、わかってる」と感じる具体的な言葉で書いてください。
一般論・抽象論は避けてください。
```

### No.09 原因分析ブロック作成
- **カテゴリ**：台本パーツ
- **得られること**：「なるほど」「知らなかった」という知的満足感を与え、講師の専門性・権威を示すブロック
- **使うタイミング**：問題提起の直後に配置する原因分析パートを書く時

#### プロンプト本文
```
あなたはセールスセミナーの教育パート専門家です。
問題提起の後に置く「原因分析ブロック」を作成してください。

#入力情報
- ターゲットの主な悩み: {悩み}
- その悩みに対する一般的な解釈(世間の常識): {一般論}
- 本当の原因(講師独自の視点): {本質的な原因}
- 講師の経験・データ: {根拠}

#出力してほしい構造
1. 導入フック「実はこの問題の本当の原因、ご存知ですか?」
2. 一般的な解釈(世間はこう考えている)を具体的に言語化
3. なぜ一般的な解釈では解決しないのか
```

## 太一の解釈・示唆

### 即戦力になるプロンプト（自分の業務でそのまま使える）
- **No.15・16・17・18**：LP・広告のコピー生成系。REHATCHクライアント案件でMeta・Google広告の初稿量産に即応用可能
- **No.20**：書いたコピーの4U採点。自分/他人が書いたコピーの品質判定を数値化できるのが強い。案件レビューでも使える
- **No.02**：競合リサーチ。新規クライアント案件の環境分析パートの初稿を高速化できる
- **No.14 STAGE1**：スライドインデックス設計。「まじん式プロンプト_スライド自動生成」と並ぶ実用プロンプト。役割タグ・BLOCK構成・品質チェック項目まで含まれるのが強い

### プロンプト設計の型として学べる点
- 全プロンプト共通の構造：**#役割 → #入力情報（{中括弧}で変数化）→ #出力してほしいもの → #制約・NGパターン**
- この4ブロックが揃っていると、AIの出力精度が安定する。**自作プロンプトのテンプレとして使える**
- 特にNo.14の2段階設計（構成設計→PPTX化）は、複雑な生成タスクを分割して精度を担保する好例

### 20種の設計思想（メタ観点）
- 「AIで台本を書く」ではなく「セミナー営業の心理設計を型化したものをAIで再現する」というスタンス
- PASONA / PAS / AIDA / PREP / PASTOR / 4Uなどの古典的コピーライティングフレームを、プロンプトの内部ロジックとして組み込んでいる
- **AIプロンプトは、"良い型を持っている人ほど強い"** という原則の実物ソース

### 注意点
- 本文中に「AI出力は叩き台」と繰り返し明記されている通り、そのまま使うのではなく最終的には人の言葉・トーンで整える前提
- 特にBefore→After事例（No.11）の「誇張・捏造は禁止」の制約は、案件で使う際に必ず守るべき原則
- 各プロンプトの出力を次のプロンプトの入力にする「連結」が精度を大きく上げる — 単発ではなく組み合わせで使う設計
