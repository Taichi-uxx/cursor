# REHATCH × HubSpot活用 MA提案（アグリプロダクツ向けナーチャリング）

## 出典
- ファイル名: `REHATCH_hubspot活用_MA提案.pdf`
- 種別: REHATCH社内 / クライアント向け提案資料（営業フェーズ）
- 作成時期: 2024年9月
- 想定提案先: 住友化学アグロ事業部 / デンカ社アグリプロダクツ製品（アグリ系toC×プロ顧客）
- 全21ページ

## 用途
- REHATCHの**「HubSpot CRM/MA × 公式LINE」二刀流ナーチャリング提案**の標準フォーマットとして、自分の案件で使い回す元ネタ。
- 特に下記の状況にハマる案件で再利用：
  - クライアントが「リード獲得はできるが検討段階を引き上げる動線がない」
  - 「メール配信の型が決まっておらず、Lステップ等LINE活用も検討中」
  - 「toCに近いリード（個人事業主・若手層含む）に対してデジタル接点を強化したい」
- HubSpot単体ではなく「HubSpot＝顕在層へのクロージング配信」「LINE＝認知〜検討段階の継続接点」という役割分担で売る型として参照する。

## 概要
- 顧客の課題は「リードは取れているが、購買意欲を上げる動線・ナーチャリング基盤がない」。
- 提案は「HubSpot CRM/MA」＋「公式LINEマーケティング」のセット導入による**「認知 → 検討段階の底上げ → 購入/ファン化」**の動線構築。
- 立ち上げ期はHubSpotメルマガで配信、LINEユーザが溜まったらLINEに主軸を移し、HubSpotは**顕在層へのクロージング**に役割転換するハイブリッド設計が肝。
- 3〜4ヶ月でインフラ整備、5ヶ月目以降は売上に効く企画・改善体制に切り替える6ヶ月支援。
- 支援費用: **50万円/月 × 6ヶ月**、想定工数67h/月、PM+HubSpotスペシャリスト+LINEスペシャリスト+企画ライター+デザイナーの5名体制。

## 本文

### 1. 与件整理（クライアント要望）

> デジタルマーケティングを強化していきたい。オンライン上でのコミュニケーションにより、顧客の購買意欲を上昇させる動線構築・ナーチャリング施策を行いたい。

| 項目 | 内容 |
|---|---|
| 背景 | アグリプロダクツ製品のマーケティング戦略の変化。**40〜50代の若い農家**をターゲットとして、デジタルを活用したマーケティング施策へ中長期的にシフトしたい |
| 現状の課題 | ・獲得リードに対するナーチャリング施策を行なっていくためのインフラ整備<br>・リードの検討段階を引き上げる/売上に繋げる動線設計が不足<br>・施策を立案・実行するリソースが不足 |
| 予算 | 40万円〜50万円/月 |
| 時期 | 9月〜にて想定 |
| その他 | LINEはLステップを導入予定 |

### 2. ご提案施策の全体像

> 認知から購入まで検討段階を底上げする — Hubspot CRM/MA × 公式LINEマーケティング を実行支援・運用支援。

「**HubSpot CRM/MA**」と「**公式LINEマーケティング**」の2軸並列で実行/運用支援を行う。

### 3. ご提案の背景 — なぜLINEを軸に据えるのか

#### 3-1. LINEのリーチ力
- 国内MAU 9,500万人OVER（日本の人口の約8割）
- DAU/MAU比率 85%（毎日利用しているユーザー）
- 性別・年代・職業に関係なく利用（10〜60代まで均等に分布、職業も会社員48.6%/主婦パート30.6%/学生10.8%）
- 出典: マクロミル社・インターネット調査（2022年7月実施/全国15〜69歳のLINEユーザー対象/サンプル数2,060）、メルマガ・LINE公式アカウント・Lステップの比較（https://linestep.jp/lp/01/comparison.html ）

#### 3-2. 「即時×高リーチ×ニーズ別」の3条件
> 顧客の検討段階を引き上げる/売上に繋げるために、リード転換されたタイミングで**即時にアプローチでき、リーチ率が高く、ユーザのニーズに合わせたコンテンツ配信ができる仕組み**が必要。

> メール施策の決まった型が現状ない、Lステップの導入検討を進めていることを考慮すると、**LINE施策の方が優先度が高い**（リッチメニューやアンケート機能など施策の幅も広い）。

### 4. 理想とするユーザ導線（3段階ファネル）

| フェーズ | 内容 | 支援スコープ |
|---|---|---|
| **① 認知・リード獲得** | SNS / オンラインセミナー / プレゼントキャンペーン / 無料サンプル / フライヤーQRコード経由でのリード獲得は今後より強化していくポイント。オフラインでの接触機会からのリード登録も継続 | **支援スコープ外**（クライアント側で実施） |
| **② 検討段階の底上げ** | メルマガ登録のみでLINE登録がまだのユーザにも、LINE公式アカウントの追加を促すメッセージを伝えていく。LINE登録後は即時のウェルカムメッセージ／アンケート機能／リッチメニューでユーザの求める情報を提供 | 支援スコープ |
| **③ 購入の最大化 / 顧客のファン化** | 購入意欲を高められたユーザに対して購入に繋がる導線設計を構築。すでに購入経験のあるユーザには有益な情報提供。問い合わせを行いたいユーザはリッチメニューで問い合わせページへすぐ辿り着ける導線でエンゲージメント向上 | 支援スコープ |

### 5. 施策のポイント（LINE側の3本柱）

#### 5-1. 公式アカウント登録数の最大化
> Hubspotフォームでリード獲得している以上、メルマガリストとして登録、そこからLINE登録に誘導が必要となる。可能なメディアはLINE登録を優先した動線への切り替えを進めていきたい。

#### 5-2. ウェルカムメッセージ（登録直後）
> 登録した時点が最も情報収集意欲が高い、そのタイミングでLINE登録の目的や購入経験の有無をアンケート機能により収集し、回答内容に合わせてニーズに合わせたコンテンツの配信を行う。

#### 5-3. 定期配信
> ブロックを誘導しない頻度（**週1回**）で、デンカ社の製品紹介やキャンペーン告知を行う定期配信を行う。**単純接触効果**により、検討フェーズでの第一想起を獲得する。

### 6. LINE・HubSpotの役割分担（フェーズで切り替える）

#### フェーズA：LINE立ち上げ期
- LINE立ち上げ期は**HubSpotメルマガでのコンテンツ配信に注力**する。
- メールでしかリーチできない/リーチした方がいい方ユーザがいるため、**メール配信は継続**する。

#### フェーズB：LINEユーザー蓄積後
- LINEユーザが溜まってきたら、コンテンツのブラッシュアップや指標改善は**LINEに注力**する。
- 企画のLPなど、フォーム機能による参加者管理などは**HubSpotの機能を活用**していく。

#### フェーズC：HubSpotの役割転換（重要な思想）
> 新たなHubSpotの役割として、**検討段階の高いユーザへのクロージングコンテンツを届ける機能**を持たせる。WEBサイト訪問のトラッキング機能・セミナー参加管理機能が存在するため、定義したWEBページの訪問を**顕在層と定義**し、彼らにより顕在層に刺さるコンテンツの発信を行っていく。

→ HubSpot＝広く配信するメルマガツール、ではなく「**Webトラッキング×セミナー参加管理を活用した顕在層へのクロージングMA**」として位置付ける。

### 7. ウェルカムメッセージ設計（具体UI）

登録されたタイミングで下記3ステップでメッセージを送る：

1. **登録直後に送信するメッセージ**：友達追加お礼＋メニュー導線案内（例：「★新着＆おすすめ求人 ★転職ノウハウコラム」）
2. **続いてアンケートを送信**：選択式（カルーセル/ボタンUI）でニーズ把握
3. **最後にユーザに合わせたコンテンツを送信**：アンケート回答に応じた製品/サンプル情報

#### アンケート分岐例
```
質問「知りたいテーマを選択してください」
選択肢
  1. デンカの製品が知りたい → 製品紹介ページへ遷移
  2. デンカの製品を使ってみたい → 無料サンプルページへ遷移
  3. その他
```
→ **LINE登録に至った背景を適切に把握でき、意欲の高いタイミングにベストな情報提供ができる。**

### 8. リッチメニュー設計

## 太一視点の示唆 / 次のアクション

### 示唆① — この提案の「型」を抽象化すると
- 既に「メルマガ運用が中途半端」「LINE活用に興味がある」企業に対しては、**「HubSpot＝メール／LP／フォーム」＋「LINE＝即時接触／ニーズ別配信」の二刀流**で売り込むのが最も筋が良い。
- 単に「MA入れましょう」ではなく「**HubSpotをWebトラッキング×顕在層クロージング配信のツールに役割転換させる**」という思想を打ち出すことで、HubSpot既存導入企業にもアップセル提案できる。

### 示唆② — 「即時×高リーチ×ニーズ別」の3条件は他案件でも使える
- toC寄りのリード（個人事業主、士業、若手ホワイトカラー、農家、美容クリニック顧客など）には、メルマガよりLINEが優先という主張を**LINE国内MAU 9,500万人/DAU85%**の数字とセットで使えば、ほぼどんな業界でも刺さる。
- 「メール施策の決まった型がない」「Lステップ導入検討中」という与件は超頻出。テンプレ化して各案件のヒアリングシートに組み込みたい。

### 示唆③ — ウェルカムメッセージのアンケート分岐は超重要
- 「登録直後＝情報収集意欲が最高潮」の論理は、ナーチャリング全般に通底する原則。
- アンケート1問で「製品を知りたい」vs「使ってみたい」vs「その他」と分岐させ、購入意欲別の動線に流す設計は、自分の担当案件（EC・スクール・人材）でも全部応用可能。**特にスクール案件は「無料相談か」「教材を試したいか」で分岐させると刺さる。**

### 示唆④ — 「単純接触効果」を週1配信の根拠として明示する説明力
- 「週1回」という頻度設定の根拠を「ブロックを誘導しない×単純接触効果による第一想起獲得」と論理化している点は秀逸。クライアントへの説明資料に流用したい。

### 示唆⑤ — 4ヶ月インフラ整備→5ヶ月目から企画・改善 の進め方
- 50万円×6ヶ月＝300万円の見積で、「3〜4ヶ月でインフラ、5ヶ月目以降は売上直結企画」と区切るのは契約期間を6ヶ月以上に伸ばす常套手段。
- 後半フェーズで「Hubspot/LINEだけに留まらないマーケティング施策/企画を提案していく」とスコープを意図的にぼかしてアップセル余地を残す書き方は学べる。
