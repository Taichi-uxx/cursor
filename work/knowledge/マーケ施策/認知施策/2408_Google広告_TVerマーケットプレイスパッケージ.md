# Google広告 × TVer マーケットプレイスパッケージ (MPP) アルファ案内

## 出典
- ファイル: `知見・ナレッジ移管/外部向け-Google広告TVer-External-Pitch-Deck-Marketplace-Packages-for-Japan.pdf`
- 発行元: Google
- 発行: 2024年8月頃（資料内のフォーキャストは2024年1月〜2月時点）
- ページ数: 30
- 内容: Google広告管理画面から在京キー局のTVer在庫を買い付けられる「Marketplace Package (MPP) アルファ」の外部向け提案資料。各局のパッケージ仕様（Deal ID・フロアCPM・尺）、設定手順（10ステップ）、注意点、DV360との比較、TVer媒体資料が一体化されている。

## どんな時に活用できるか
- クライアントに **コネクテッドTV（CTV）／TVer配信を提案する時の媒体選定・パッケージ選定**
- YouTube認知キャンペーンに対して **「TVer面も含めた在京キー局CTV面」をアドオン提案**したい時
- DV360を契約していないクライアントに、**Google広告管理画面だけでTVer買付**を行うルートを案内する時
- CTV／TVer配信時の **CPM水準・尺制約・入稿規定・事前審査リードタイム**を確認したい時
- 認知施策の **Pre/Mid/Postロール構成、視聴完了率、ブランドセーフティ**の根拠数値を提案資料に流用する時
- Google広告（MPP）とDV360の **買い方・機能差を整理して見積比較**する時

## 1. 背景：CTV/OTT広告市場とGoogle広告の課題

### 市場背景
- CTV/OTT広告市場の伸長に伴い、動画配信サービスの多様化が進行
- 広告主側は「さらなる統合」「効率性」「価値ある広告」を求める段階に
- ※OTT (Over-the-top) 定義: Roku, Apple TV, Smart TV, ゲーム機等のTV接続デバイスでストリーミング配信される動画コンテンツ（Comscore/IAB定義準拠）

### これまでのGoogle広告の課題（MPP登場前）
- **課題1：YouTube以外の在庫がない**
  - Google広告ではYouTubeのCTV在庫以外にアクセス不可
  - TVerをはじめとする人気CTV動画配信サービスへの配信ができなかった
- **課題2：設定や購買フローの課題**
  - TV局・パブリッシャーの番組・ネットワークに対する透明性がなかった
  - YouTube以外のCTV在庫を買い付ける方法がGoogle広告に用意されていなかった

### 太一視点での提案ポイント
- これまでDV360を契約していないクライアント、もしくは小規模アカウントは「Google広告だけではYouTube止まり」だった。MPPでTVer面まで一気通貫で買えるようになる、というのが提案の核

## 4. Google広告 設定方法（10ステップ）

### Step 1-2: 配信アカウント準備とキャンペーン作成
1. **配信希望アカウントをホワイトリスト化**（Google営業担当者へ連絡）
2. **認知動画広告**を設定し、 **"動画のリーチ"** を選択、 **"スキップ不可でのリーチ"** を作成
   - キャンペーン目的: Brand awareness and reach
   - キャンペーンタイプ: Video
   - サブタイプ: Video reach campaign → Non-skippable in-stream

### Step 3-5: 基本設定
3. キャンペーンに名前をつけ、予算・開始日・終了日を入力
4. ネットワーク下部の **"Google ディスプレイ ネットワークの動画パートナー"** にチェックがついていることを確認（必須）
5. "地域"で日本および他の必要な場所をターゲティング

### Step 6: YouTube在庫を除外（最重要）
6. キャンペーンが **"Premium Network CTV"** でのみ提供されることを確認。プレースメントの"入力"タブで設定：
   - URL `https://www.youtube.com/watch?v=zYyW_H03XuI` をテキスト入力欄に記載し "1個のプレースメントを追加" をクリック
   - ⚠️ **この設定によりYouTube在庫への配信量がゼロになる**（TVer面に絞るための重要ステップ）

### Step 7-8: Deal IDの登録
7. Marketplace Package listを確認し、広告を流したいCTV/OTTパッケージを決定。 "Deal ID"をコピーし、 "プレースメント"の"入力"タブをクリック
8. "Deal ID"をテキスト入力欄にペーストし、 "1個のプレースメントを追加"をクリック
   - ⚠️ **アルファフェーズでは、広告グループごとに1つのパッケージのみ追加可能**。複数パッケージをターゲットしたい場合は複数広告グループor複数キャンペーンを作成

### Step 9-10: クリエイティブと入札
9. **15秒までのノンスキップクリエイティブ**（6-15秒であればどの長さでもOK）をアップロード
10. 入札額を **"目標インプレッション単価"** の欄に入力し、 "キャンペーンの作成"をクリック

### 太一視点での運用ポイント
- **Step 6のYouTube除外は絶対に忘れない**。これを忘れるとYouTube在庫に流れる
- **広告グループ1つに対してパッケージ1つ**（アルファ仕様）。5局全部に出したいなら広告グループ5つ or キャンペーン5つに分ける必要あり。集計設計が煩雑になる前提で提案する
- **クリエイティブは6-15秒のNon-skip**が基本。日テレdramaなど一部30s対応のパッケージはあるが、全局横断するなら15s尺で揃えるのが安全

## 5. TVer/放送局在庫購入時の注意点

MPPアルファ版利用時の注意点（今後変更の可能性あり）：

1. **TVerの入稿規定に合うクリエイティブを入稿**
2. バイヤーは通常のGoogle広告の承認プロセスに加え、 **TV局様が実施するクリエイティブ「事前審査」（業態・表現等の考査）を通過必須**
3. **2〜6営業日以上経過しても承認されない場合、不承認の可能性あり**（リードタイムは目安。各局のパッケージ説明に記載あり）

### 太一視点での運用ポイント
- 事前審査リードタイムを **本番配信開始日の1〜2週間前** には織り込んだスケジュールでクライアントに提示する
- 業態（金融・健康・薬機・出会い系・ギャンブル等）はTV局考査が厳しいので事前に局確認

## 6. 配信ケイパビリティと効果計測

### アルファで可能
- **ターゲティング**: 国/地域、属性（年齢/性別）
- **レポーティング**: Google広告管理画面、ユニークリーチオーディエンス（※重複接触抽出は不可）
- **配信ケイパビリティ**: TVer単独での予算管理

### ベータ以降利用可能（予定）
- **ターゲティング**: アフィニティ／番組ジャンル
- **レポーティング**: ブランドリフト・サーチリフト、3Pリーチ・インパクト計測
- **配信ケイパビリティ**: YouTube SelectとネットワークCTVディール間でのフリークエンシーキャップ、モバイル・PC・デスクトップへの配信
  - ※アルファ時点ではTVer単独での予算管理は可、フリクエンシー統合はNG

### 太一視点での運用ポイント
- アルファ時点は **「ターゲティング粗い・BLS不可・YT統合FQ不可」** という制約がきつい。これが許容できる案件＝「CTVリーチを純増させたい」＋「効果計測は内部指標で良い」プロジェクトに限定的に勧める
- BLS／サーチリフトでKPIを置く必要があるならDV360やベータ移行を待つ

## 8. Google広告（MPP）とDV360の比較

| 項目 | Google 広告 (MPPアルファ) | DV360 |
|---|---|---|
| ステータス | アルファ（2024 Q1時点） | GA（一般提供） |
| 買い付け方法 | **フロア価格に基づいたオークション** | PMP (PG/PD) |
| 配信可能媒体 | YouTube / TVer | YouTube / TVer / ABEMA / DAZN / Spotvnow 等 |
| YTとの統合FQ | ✗ | ◯ |
| デバイス | **CTVのみ**（今後mApp対応予定） | All |
| 掲載場所 | (Pre), Mid, Post | Pre, Mid, Post |
| TVer個別の予算管理 | ◯ ※今後unofficialな方法になる可能性 | ◯ |
| BLS（ブランドリフト） | ✗（今後対応予定） | ◯ |
| ユニークリーチオーディエンス | ◯ ※α時点では重複は出ない | ◯ |

※ MPPを使ってDV360で配信することも可能

### 太一視点での提案使い分け
- **DV360あり・複数SSP在庫を横断したい・BLSが必要** → DV360で買う
- **DV360なし・Google広告で完結したい・小規模予算で試したい** → MPPアルファでTVer面のみピンポイント
- 「YouTube認知の続きでTVerも試す」というステップアップ提案にちょうど良い

## 9. TVer媒体プロフィール（補足資料）

### TVerとは
民放テレビ局がひとつになったプラットフォーム。各局の好きな番組、約400番組以上のコンテンツをすべて無料でSD・PC・テレビに配信。

| 指標 | 数値 | 時点・出典 |
|---|---|---|
| アプリダウンロード数 | **6,500万** | 2023年8月時点 |
| MUB（TVer単体） | **3,000万** | 株式会社TVer調べ |
| 再生数（TVer単体） | **3.9億回** | 2023年8月時点・ビデオリサーチ算出 |
| 認知率（15〜69歳/男女） | **69.9%** | 2023年4月時点・マクロミル調べ |
| 視聴可能期間 | 番組放送終了から約7日間見放題 | — |

### ユーザー属性
- **エリア**: 人口動態に近い形で分布（関東42%、近畿18%、中部15%、九州・沖縄9%、東北5%、中国5%、北海道4%、四国2%）
- **デモグラ別UB構成比（2021年10-12月）**: MF15-19が10.2% / M20-34が12.7% / M35-49が17.2% / M50-64が11.9% / **F20-34が14.0% / F35-49が20.3%（最大）** / F50-64が13.7%
- **F1-F2（女性20-49歳）の構成比は34.3%** ← 女性をターゲットにする商材で強い
- **TVerユーザーの10人に3人は普段あまりテレビを見ないローテレ層**（1日あたりのリアルタイムテレビ利用60分未満）への訴求が可能 ※2020年9月・ビデオリサーチ調べ

### 民放キャッチアップ配信先
- 公式テレビポータル「TVer」
- 各放送局自社サイト（日テレ無料TADA!、FOD、ネットもテレ東、TBSFREE、テレ朝キャッチアップ、MBS動画イズム、カンテレドーガ、ytv MyDo!、テレビ大阪 等）
- ※放送局ごとに外部配信先は異なる。放送局コンテンツのみに配信

## 10. TVer広告の特徴（3つの強み）

### 強み1：高い視聴完了率で広告認知を実現
- CMの視聴完了率：**15秒 96.0% / 30秒 95.2% / 60秒 93.4%**（2021年10-12月TVer広告実績）
- **Audible and Visible on Complete Rate (30秒)**：
  - TVer: **84.6%**
  - インストリーム無料動画投稿サイト: 46.1%
  - インフィードSNS: 2.4%
- → **有音・大画面・最後まで見られる**ため、CMメッセージが伝わりやすい

### 強み2：嫌悪感・違和感なく広告が受け入れられる
- 権利処理済かつJIAA（日本インタラクティブ広告協会）のブランドセーフティ基準を満たした「安心・安全」なコンテンツにのみCM配信
- 広告枠構成例: プレロール → コンテンツ → ミッドロール① → コンテンツ → ミッドロール② → コンテンツ → ミッドロール③ → コンテンツ → ポストロール（1時間構成のドラマを基にした例）
- 「**動画広告を自然に見られる**」: 民放CU **47.6%** vs 無料動画投稿サイト 31.7%
- 「**子どもや青少年に不適切・不快な表現がある（CM）**」: 民放CU **2.5%** vs 無料動画投稿サイト 29.1%
- 「**コンテンツに不適切・不快な表現がある**」: 民放CU **3.7%** vs 無料動画投稿サイト 40.8%
- ※2021年10月時点・マクロミル調べ

### 強み3：コネクテッドTVへの配信
- **テレビデバイスでの視聴比率は毎月増加傾向**
- 2022年1月時点のデバイス別UB割合: **SD（スマホ） 63.5% / TV 24.9% / PC 11.6%**
- 対応デバイス（年々拡充）: BRAVIA / fire tv stick / AQUOS / J:COM TV / VIERA / Google Chromecast / au ひかりテレビサービス / FUNAI / REGZA 等

### 太一視点での提案フック
- 「**TVerの30秒CM完視聴率84.6%はYouTube・SNSの数倍**」 → 認知/ブランディング目的で**動画フル尺を最後まで見せたい商材**で強力な訴求
- 「**ブランドセーフティ・嫌悪感の低さ**」 → 大手・金融・保険・通信などレピュテーションを気にする業種に響く
- 「**コネクテッドTV比率24.9%＋伸長中**」 → "テレビCMの代替/補完" 文脈で提案できる

## 11. 太一向けまとめ：提案する時のシナリオ

### MPPを使うべきケース
- DV360を契約していない/予算が合わないクライアント
- YouTube認知を既に運用しており、CTV面のリーチ拡張をテストしたい
- 在京キー局のTVer面を「Google広告画面の延長線上」で運用したい
- 認知/ブランディングKPIで、効果はリーチ・完視聴率で良い（BLS不要）

### MPPを使わない方が良いケース
- ブランドリフト計測必須 → DV360（or ベータ待ち）
- ABEMA/DAZN等の在庫も横断したい → DV360
- YT-TVer統合のフリクエンシーキャップ必須 → DV360（or ベータ待ち）
- モバイル/PCも含めたい → アルファはCTVのみなので不適

### 提案資料に流用しやすい数値
- CTV比率 24.9%（TVer 2022年1月）
- TVer認知率 69.9%（2023年）
- 30秒完視聴率 84.6%（vs SNS 2.4%）
- 民放CU vs 無料動画投稿サイトのブランドセーフティ比較
- F1F2構成比 34.3%
