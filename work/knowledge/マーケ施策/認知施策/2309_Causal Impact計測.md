# Causal Impact計測｜TVCM・Web動画の純増CV分析

## 出典
- ファイル: `知見・ナレッジ移管/Causal Impact.docx`
- 作成: 2023年9月頃（推定）
- 内容: TVCM・Web動画のインクリメンタル効果（純増CV）を時系列統計モデルで測定する手法「CausalImpact」の理論・適用条件・分析手順まとめ

## どんな時に活用できるか
- TVCMやWeb動画のインクリメンタル効果（純増CV）をクライアントに数値で説明する時
- 管理画面では計測できない指名検索・オーガニック検索への跳ね返り効果を可視化したい時
- 認知系施策が「全体最適」でどれだけ売上に貢献したかを評価したい時
- マーケ全体の純増効果が見えず、CPA改善の文脈以外で施策評価が必要な時
- エリアテスト（関東配信／関西未配信 等）を組んで効果検証する設計を提案する時

---

## 1. TVCM・Web動画の効果計測モデル全体像

純増CV計測には大きく3つのモデルがある。CausalImpactは「全体最適」型。

| モデル | 使うデータ | 強み | どんな時に使う |
|---|---|---|---|
| **時系列統計モデル（CausalImpact）** | Dailyレポート等の長期時系列 | 「広告を打たなかったら」の反実仮想を推定し、純増効果を算出 | TVCM・Web動画全体の成果を見たい「**全体最適**」 |
| **短期間スパイク検出モデル** | 分単位データ | 番組枠単位・時間帯・ジャンル別の効果を細かく検出 | 番組ごとの成果を見たい「**個別最適**」（例：ダブルスコア） |
| **シングルソースアトリビューションモデル** | CTV視聴ログ × インターネット行動ログ | CM接触後の流入経路特定、非接触者とのリフト率比較 | 特殊分析。ただし**ITP影響で使いづらくなってきている** |

---

## 2. CausalImpactとは（統計的因果推論）

### 基本コンセプト
- 結果に影響を与えうる施策（TVCM等）を打って生じた結果と、**施策を打たなかった場合の結果（反実仮想）** の差分を施策効果と捉える
- 「施策を打たなかった場合の数値」は、テスト群と似た特徴を持ち、かつ施策影響を受けていない**コントロール群**を参照して推定

### 計算式
```
広告の純増効果 = 広告を打った時の実績値 − 反実仮想値
```

### イメージ
実際に広告を打ったエリア／打たなかったエリア両方の実績をもとに、「もし広告を配信していなかったら？」をシミュレーション。反実仮想値を統計的に弾き出してくれる。

## 3. 必要なデータセット・ツール

### データ
- **広告配信エリア**における広告配信前30日〜配信期間のデイリーレポート
- **広告未配信エリア**における広告配信前30日〜配信期間のデイリーレポート
- → **全国配信の場合はこの分析はできない**（未配信エリアが取れないため）

### ツール
- **AssetView**：統計ソフト。データDLに使用
- **R**：統計分析・可視化用の解析言語
- **RStudio**：Rを視覚的に扱うためのIDE

---

## 4. 適用条件｜配信エリアと未配信エリアの相関

反実仮想値を正しく算出するには、配信エリアと未配信エリアのKPI傾向が似ている必要がある。

### NG例
- 関東と関西で商材が売れる傾向が全然違う → 関西データで関東の反実仮想を作っても精緻さを欠く
- 関東で2/15〜4/15にTVCM放映、未放映の関西で大規模屋外広告を3/15〜3/31に実施 → 未配信エリアにノイズあり、正しく反実仮想を組めない

### 検定方法
- **CORREL関数**で2エリアの相関を測る

| 相関値 | 判定 |
|---|---|
| **0.7以上** | 2エリアに相関あり。未配信エリアとして問題なく使える |
| **0.7以下** | 相関なし。未配信エリアにノイズがあるので、別エリアを選び直す |

## 5. 使うべき／使わなくていい場面

### 使った方が良いとき
- マーケ施策のインクリメンタル効果が可視化できない
- 管理画面ではレポーティングが難しい
- 管理画面で数値確認できるが、インクリメンタル数値以外への影響も大きく出ていそう
  - 例：動画広告を配信。動画経由CTSは管理画面で判明するが、**指名検索やオーガニック検索への跳ね返りは確認できない**

### 使わなくても良さそうなとき
- 通常獲得向けで、管理画面でKPI達成が分かる（差分の差分法やD&Eで足りる）
- アトリビューション分析で広告効果が判断できる

## 6. 分析手順（RStudio）

### Step1：必要パッケージのインストール
```R
install.packages("CausalImpact")
library(CausalImpact)
```
※ 多少時間がかかるので事前にインストールしておく

### Step2：ローデータ作成
ローデータに必要なカラムは**3つだけ**（日付・テスト群・コントロール群）。エクセルかcsvで保存。

### Step3：分析スクリプト
```R
df <- read.csv(file.choose())
time.points <- seq.Date(as.Date("yyyy-mm-dd"), by=1, length.out=XX)
test <- ts(df$test)
other <- ts(df$control)
data <- zoo(cbind(test, other), time.points)
head(data)
pre.period <- as.Date(c("yyyy-mm-dd", "yyyy-mm-dd"))
post.period <- as.Date(c("yyyy-mm-dd", "yyyy-mm-dd"))
impact <- CausalImpact(data, pre.period, post.period)
plot(impact)
summary(impact)
```

#### スクリプト解説
| 行 | 内容 |
|---|---|
| 1行目 | ファイル選択ダイアログを開く |
| 3行目 | `yyyy-mm-dd` 以降のデータを取り込む。`XX` はデータ行数 |
| `pre.period` | データ開始日〜広告配信前日（広告打つ前のベースライン期間） |
| `post.period` | 広告配信開始日〜終了日（効果測定期間） |

#### 具体例（TVCM放映期間 2/15〜4/15、1/12からデータ取得）
```R
df <- read.csv(file.choose())
time.points <- seq.Date(as.Date("2021-01-12"), by=1, length.out=99)
test <- ts(df$test)
other <- ts(df$control)
data <- zoo(cbind(test, other), time.points)
head(data)
pre.period <- as.Date(c("2021-01-12", "2021-02-14"))
post.period <- as.Date(c("2021-02-15", "2021-04-15"))
impact <- CausalImpact(data, pre.period, post.period)
plot(impact)
summary(impact)
```

### Step4：分析結果の読み方

#### グラフ
- 実測値（実線）が反実仮想（点線）から大きくリフトしていれば効果あり

#### 実数値
- **Absolute effect**：絶対リフト値＝広告効果で増加したKPI指標
- **p値が0.05超え**：有意差なし＝リフトがあったとは言えない

#### リフトが出ない場合の想定
- 配信量が少なすぎる
- 広告による効果がそもそも小さい

## 太一の解釈・示唆
- **「インクリメンタル効果を見える化したい」**は認知系施策の提案で必ず刺さるテーマ。CausalImpactは「指名検索・オーガニック検索への跳ね返り」を数値化できるので、TVCM／Web動画施策の評価ロジックとして強い
- 適用前に**CORREL 0.7以上**の条件チェックが超重要。ここを怠ると分析が無意味になる。提案時のエリア設計から織り込む
- **全国配信案件は使えない**ので、提案フェーズで「エリアテスト型で組みましょう」と設計を引っ張る必要あり
- 「全体最適（CausalImpact）」と「個別最適（スパイク検出／ダブルスコア）」は併用が理想。番組単位の最適化はスパイク検出、施策全体の費用対効果はCausalImpactで二段構え
