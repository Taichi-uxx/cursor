## 記事の核（1行サマリ）

## AI検索で発見されるための4つのステップ

### ステップ1：オーディエンスの検索エコシステムをマッピング

ビジビリティを高める**前**に、オーディエンスがどこにいるかを把握する。次の3点を特定：

- オーディエンスが利用しているプラットフォーム
- オーディエンスが信頼しているパブリッシャー
- オーディエンスが参加しているコミュニティ

推奨ツール：**SparkToro**（※日本語非対応。オーディエンスがどこで何を読み、どこでエンゲージしているかを可視化）

事例：CRM分野では ChatGPT・Claude を積極利用するオーディエンスが目立つ → 「どのAIプラットフォームに露出するか」の優先順位が決まる。

### ステップ2：オーディエンスのインサイトを抽出

**Redditとサブレディット**が特に情報密度が高い。そこの会話から拾える3点：

- オーディエンスが解決しようとしている具体的な課題
- オーディエンスが問題を説明するのに使う**言葉**
- 意思決定前に抱く疑問

重要な事実：
> **RedditはChatGPTで引用されることが特に多い情報源の1つ**。

→ オーディエンスの会話 = LLMの学習データ、という二重の意味で価値がある。

### ステップ3：第三者による評価を中核的な手段として構築する（デジタルPRの3手法）

第三者評価は**AIビジビリティの最重要手段**。Journey Furtherで成果のあった手法：

#### (a) リスト記事や製品レビュー

- 「厳選リスト」「おすすめ〇〇選」に取り上げられることが最強シグナルの1つ
- ユーザーの質問の仕方と合致するのでLLM回答によく表示される
- 事例：
  - Delish（米レシピサイト）の「料理のプロが教える、本当に節約になるキッチン用品12選」
  - CNN「50歳の誕生日に贈りたい、本当に節目にふさわしい最高のプレゼント36選」「200ドル以下で買える50歳の誕生日プレゼント」
- 実際のLLMでの挙動：ChatGPTに「200ドル以下で買える50歳の誕生日プレゼント、何がいい？」と入力 → **CNNの記事が引用され、Virgin Experience Gifts が推奨される**
- 自社単独掲載でなくてもよい。**モデルが信頼するメディアに、適切なコンテキストで自社が含まれていればOK**

#### (b) データの裏付けがある調査・消費者調査

- 標準的なブランドメッセージングより影響力が強い
- 事例：フォーチュン500入りのドッグフードブランドが「米国で最も犬に優しい都市」の調査を実施 → **タイムアウト誌に掲載 → 「AIによる概要」に表示される**
- ジャーナリストもデータ主導ソースを優先するようになっている

#### (c) ソートリーダーシップと専門家の解説

- Journey FurtherがSalientツールでドメインオーソリティ40超のカバレッジ4000件を分析 → **半数近くが「専門家の解説」「データ調査」で構成されている**（製品コンテンツではない）
- 一方で「専門知識の捏造」問題も発生。事例：英国で王室の清掃員話題を複数メディアが取り上げたが、後日ジャーナリストが「そんな人物は存在しない」と特定 → 業界全体でファクトチェック強化
- 専門性を示すためのセット：
  - 信頼できる経験を備えた専門家
  - サイト上に掲載されている執筆者略歴
  - 更新されているLinkedInプロフィール
  - ジャーナリストが検証可能な資格情報

#### デジタルPRを「配信エンジン」として捉え直す

デジタルPRを**リンク獲得**で捉えるのは狭すぎる。以下3領域で「信頼」シグナルを底上げする配信エンジンとして機能する：

- 従来検索（引き続き **E-E-A-T** が重要）
- AIによる概要（情報源が選択されて要約される）
- LLMの応答（複数参照元から回答が構築される）

つまり、**「LLMに引用される情報源になる」 or 「LLMが回答根拠にする情報源に自社ブランドが確実に含まれる」**、そのどちらかが必要。デジタルPRは双方を押し上げる。

### ステップ4：測定可能な成果につながるデジタルPRのワークフロー

Journey Furtherの原則：**「インサイトに始まり、エビデンスで終わる」**。

#### インサイトとオーガニックな機会

クリエイティブに入る前に把握するもの：

- 自社サイトが高順位を獲得している／もう一歩で獲得しそうなキーワード
- **LLMで頻繁に表示される業界誌**
- オーディエンスがどこで時間を費やし、何にエンゲージしているか
- 自社ブランドと競合とのギャップ

→ 「どこに表示されるか／何が欠けているか／どこに注力すべきか」が明確化。

#### アイデア出しと独創的コンセプト

- 「ブランド主導 × オーディエンス重視」のコンセプトを策定
- 一貫したストーリーを伝える
- **AIは君について書かれたあらゆる情報を横断してパターンマッチング**する → 特定トピックとの関連付け頻度が高いほど推奨されやすい

#### アウトリーチ

- インサイトで特定したメディア（LLMで頻繁に引用されるメディア／オーディエンスが利用するサイト）にターゲット

## 【中核】AI検索でのパフォーマンスを測定する4つの手法

AI検索プラットフォームは**ウォールド・ガーデン**（ChatGPT用のGSCも、アトリビューションモデルも存在しない）。しかし「ビジビリティ／プロンプト／サイテーション」の3軸で組めば測定できる。

### 手法1：プロンプトバンクの構築

「プロンプト単位の検索ボリューム」は取れない。代わりに**オーディエンスの検索の仕方を反映した代表的クエリセット**を作る。

3つの中核ソース：

| ソース | 役割 |
|---|---|
| Googleの **PAA（People Also Ask）** | キーワードと会話形式クエリを自然に接続。需要量に代わる質問リストが得られる |
| **Redditのディスカッション** | オーディエンスが実際に使う言葉。会話自体がLLMの学習データでもある |
| **AI検索プロンプト** | オーディエンスが実際に尋ねているクエリ（PAA / フォーラム / 独自調査から抽出） |

Journey Furtherの実運用規模：
> クライアント追跡用のプロンプトバンクに **2000件の質問・クエリ** を格納。ファネル全体の主要な意図を網羅（PAA / FAQ / レビュー / フォーラム由来）。

このバンクは以下すべての基盤になる：
- ブランドのビジビリティ追跡
- サイテーションのギャップ特定
- PR・コンテンツ活動の成果測定

### 手法2：複数モデルをまたぐブランドのビジビリティ追跡

AI検索には順位がない。代わりに **ブランドの露出回数** を測る：

- オーディエンスが利用するモデル**全体**での表示を追跡
- オーディエンスデータに基づいてプラットフォーム優先順位付け
- プロンプトバンク全体でのブランドメンションを計測
- 引用URLを深堀り：モデルが自社／競合を引用する際の情報源を特定 → 自社ではなく競合が表示されるプロンプトから、**PR注力先を判断**

### 手法3：ファンアウトクエリで、LLMが何を優先しているかを理解する

**ファンアウトクエリ = LLMが1件のプロンプトに答えるために裏側で実行する複数の基本検索**。プロンプトをどう分解し、追加でどんな調査をしているかを可視化する。

例：「エンタープライズビジネスに最適なCRM」というクエリを、モデルは複数の視点に展開し、それぞれの回答を統合する。

Journey Furtherの分析結果：

- **ファンアウトクエリの41%は9語以上**（※Web担編注：原文は「9語」だが「9語以上」と判断）
- **71%に「最高」「最速」「最安」などの最上級表現**が含まれる
- **情報の鮮度／価格／レビュー**はクエリ全体で一貫して登場

→ LLMが回答生成時に何を優先しているかがわかり、コンテンツ戦略の指針になる。

### 手法4：AIボットリクエストを、既存指標と相互に関連付ける

最も信頼できるデータは自分自身のデータ。

手順：
1. **Webサーバーログ**からAIボットのクロールリクエストを取得
2. GSCクリック数 / GA4セッション / コンバージョン等の既存指標と紐付け

Journey Furtherの発見：
> Google Search Consoleのクリック数とChatGPTのリクエスト数に、**ページ単位で高い相関**が見られた。**優れたSEOが優れたGEO**であることを裏付ける。

真の価値は**ギャップ**から出る：
- 「GSCクリック数は多いが、ChatGPTリクエスト数が少ないページ」 → **AIボットがコンテンツを正しく読めていない可能性** → オンサイト最適化の改善対象
- クローズドなAI環境ではアトリビューションに限界があるが、ボットログ × 既存指標で **ステークホルダーに提示できる具体成果** に落とせる

## 結論（原文）

> AIでのビジビリティを高めたいなら、引用される価値のあるブランドになろう。ビジビリティは今や、ウェブ全体で信頼が得られるかどうかにかかっている。専門家の解説やデータ調査、また信頼性を中心としたPR戦略を通じて、信頼される情報源になることに注力しよう。
>
> AIでのビジビリティを高める近道はない。ブランドメンションやサイテーションは強力な基盤から得られる副産物であり、時間をかけて積み重ねられていくものだ。

## 太一の解釈・実務メモ

- 4ステップは**「①どこにオーディエンスがいるか → ②何を話しているか → ③どう第三者評価に載せるか → ④どう再現可能な仕組みにするか」**の順で、そのままLLMO案件のプロジェクト計画書のWBSに落とせる
- 前編の「93%が第三者由来」→ 後編の「デジタルPRを配信エンジンとして捉える」までがワンセット。**LLMO提案では「PR/広報部門との共同プロジェクト化」を最初から提案設計に組み込むべき**
- **プロンプトバンク2000件**はJourney Furtherの実運用規模。日本語案件では初期100〜300件から始めて、四半期ごとに増やす運用が現実的
- 測定手法4はほぼ全部**代理店側でセットアップ可能**：
  - ①プロンプトバンク → スプレッドシート＋LLM横断チェックスクリプトで内製可
  - ②複数モデル横断ビジビリティ → Perplexity/ChatGPT/Claude APIを叩く監視スクリプト
  - ③ファンアウト分析 → 同じスクリプト内で `search_queries` を記録
  - ④AIボットログ → Webサーバー側で `User-Agent` に `GPTBot`, `ChatGPT-User`, `PerplexityBot`, `ClaudeBot`, `Google-Extended` などをフィルタして集計
- 「GSCクリック多い × ChatGPTリクエスト少ない」ページ = **AIボットにコンテンツが読めていない疑い**は、AIレポートに載せる「次のアクション」の鉄板ネタになる。担当クライアント全社で1度は走らせる価値あり
- 「71%に最上級表現」は日本語だと「最強」「最速」「一番安い」「決定版」あたり。コンテンツ側のタイトル・見出し設計に転用可能なインサイト
