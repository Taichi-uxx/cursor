# GA上でのAI経由のトラフィック
- 7割が「ダイレクト」として計上されている（正確に取れていない）

# ボリュームについて
- 検索エンジン経由のボリューム自体が減っているわけではない
  - AI触ってから、検索に移行するという場合もあるため
- AI経由のトラフィックは増えている
- つまり、AI分が積み増しされ、検索面のボリューム全体が増えている（検索エンジン＋AI経由）

# クエリについて
- 検索クエリが増える・ターゲティングが細かくなる
- ロングテールにとってさらに追い風 →AI広告
- エージェントが購買行動を改革すると、ホームページにアクセスするのではなく、商品詳細ページに直接遷移することが増える。なので商品詳細ページをAIの検索にひっかかりやすいように最適化する必要がある。
