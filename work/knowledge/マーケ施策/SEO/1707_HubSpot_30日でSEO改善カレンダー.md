# SEO対策カレンダー — ウェブサイトのSEO対策を30日で改善するためのプラン

## 出典
- HubSpot Japan × OnPage.org（移管元: `知見・ナレッジ移管/SEO/トラフィックを増やすためのSEO対策.pdf`、CreationDate 2017-07-14）

## 用途（こんな時に見る）
- 既存サイトのSEOテコ入れを30日プランとして組み立てたいとき
- 「何から手を付けるか」迷ったとき、1日1テーマで頭から潰す枠組みとして
- クライアントへの90日プラン提案の元ネタとして（30日×3コース等）

> ⚠️ 2017年作成のため、現在は陳腐化している項目もある（特にKWツールはAdWords→Google Adsへ）。**思考フレームとして使い、具体的ツール／数字は最新版で更新する**こと。

## 各日のキーポイント抜粋

### Week 1: 基礎整備（Day 1-7）

| Day | 数値・目安 |
|-----|----------|
| 1 タイトル/説明 | タイトルは**70文字以降切られる**。説明は**120文字程度** |
| 2 Alt属性 | 画像の意味を検索エンジンに伝える。視覚障害者対応にもなる |
| 3 壊れたリンク | 404多発はメンテナンス不良と見なされる → 301リダイレクトで修正 |
| 4 リダイレクト | **301（永続）と302（一時）**を使い分ける。SEO資産は301で引き継がれる |
| 5 URL構造 | ディレクトリレベルは**最大4段階**まで |
| 6 URL短縮 | **74文字以内**で検索結果に全体表示。冠詞・接続詞（the / a / and）を避ける |
| 7 内部リンク | リンクなしページはクロール中断要因 |

### Week 2: 構造・性能（Day 8-14）

| Day | キーポイント |
|-----|------------|
| 8 アンカーテキスト | 「こちら」「もっと詳しく」NG。KW入れる |
| 9 クリックパス | **3クリック以内**で全ページに到達 |
| 10 sitemap.xml | 検索エンジン向けに全URLとメタデータを伝える |
| 11 robots.txt | クロール対象を制御。User-agent / Disallow |
| 12 キーワード調査 | Googleキーワードプランナー / Googleトレンド / Übersuggest |
| 13 ナビゲーション | バウンス率の高いページ → ナビ改善のヒント |
| 14 読み込み時間 | **Google PageSpeed**でチェック。画像圧縮 / CSS・JS最適化 |

### Week 3: コンテンツ品質（Day 15-21）

| Day | キーポイント |
|-----|------------|
| 15 モバイル最適化 | viewport タグ確認 |
| 16 重複コンテンツ | www/http/https、`/` 末尾、PDF版での重複をチェック |
| 17 canonicalタグ | コピー側からオリジナルへ。**相対URLは使わない** |
| 18 TF*IDF | キーワードとの関連性分析でユニークさを担保 |
| 19 タイトル作成 | h1は1つだけ。CSSでフォントサイズ調整、タイトルタグでサイズ変更しない |
| 20 キュレーション | インフォグラフィックス / 調査統計 / ガイドブック / ケーススタディ / ゲスト寄稿 |
| 21 コンテンツ再利用 | 古い記事をガイドブックへ／プレスリリースをブログへ |

### Week 4: 配信・分析（Day 22-30）

| Day | キーポイント |
|-----|------------|
| 22 コンテンツ比率 | テキストが全体の**25%以上** |
| 23 多様性 | テキスト + 画像 + 動画 + インフォグラフィックス |
| 24 多国語対応 | `hreflang` タグを `<head>` に追加 |
| 25 ローカル最適化 | 同企業名・住所・電話番号で統一 / Google MyBusiness 登録 |
| 26 SNS | 投稿で対話発生 → 検索エンジンが記録、コンテンツ評価UP |
| 27 ユーザー対話促進 | コメント／質問／FAQ |
| 28 Search Console | sitemap.xmlアップロード、HTMLの改善点チェック |
| 29 Google Analytics | KPIに重大変化が出た時にメール通知設定 |
| 30 モニタリング | **継続が前提**。Analytics + Search Consoleの2大無料ツール |

## So What — 太一としての示唆

- 90日プランに引き伸ばすと毎週1テーマ×3週=21テーマで余裕を持って実装可能 → クライアント提案テンプレに使える
- ツール名や数字は2017年当時のもの。最新版は [[2312_StockSun_SEOガイドライン]] でアップデート可能
- 「**3クリック以内で全ページ到達**」「**75文字以内のURL**」「**テキスト25%以上**」など定量目安が多く、診断レポートの基準として転用可
- 内容の8割は [[2312_StockSun_SEOガイドライン]] とオーバーラップ。本資料は「順序立てて30日で動かす」観点で残す
