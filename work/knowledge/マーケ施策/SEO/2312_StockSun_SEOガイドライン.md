# StockSun SEOガイドライン（2023/12/01更新）

## 出典
- StockSun株式会社「SEOガイドライン」（移管元: `知見・ナレッジ移管/SEO/【StockSun】SEOガイドライン.pdf`、CreationDate 2023-12-04）

## 1. 内部施策（38項目）

### 1-1. サイト構造・対策ページ
| # | チェック | 要点 |
|---|---------|------|
| 1.1 | 対策KWに対応するページが存在するか | 検索意図を満たすページが必須 |
| 1.2 | 対策ページのリンク階層は浅いか | TOPから何クリックで到達か。ディレクトリ階層は深くても可 |
| 1.3 | カニバリが発生していないか | 発生時は削除 or 統合＋301 |
| 1.11 | 対策ページはインデックスされているか | noindex／robots.txt／内部リンクなし が原因候補 |

### 1-2. クロール制御
- 1.4 クロール不要ページを robots.txt で制御
- 1.5 重要ページを誤って Disallow していないか
- 1.6 robots.txt はルートディレクトリに設置
- 1.7-1.8 XMLサイトマップ生成 & Search Console送信
- 1.9 noindex を適切に使用（低品質・重複ページに設定 / 重要ページに誤設置していないか）
- 1.10 パンくずリスト全ページ設置 + 構造化マークアップエラーなし

### 1-3. リンク内部構造
- 1.12 対策ページの発リンク（リンク切れ）を修正
- 1.13 重要度高い対策ページに内部リンクを集める（関連性のないページからの無意味リンクは避ける）
- 1.14 内部リンクのアンカーテキストに**遷移先で狙うキーワード**を含める（画像リンクはalt属性が該当）

### 1-4. 重複・低品質
- 1.15 低品質ページはインデックスなら削除 or noindex、未インデックスでも可能なら削除
- 1.16 重複ページは削除、必要なら canonical で正規化

### 1-5. URL構造（Google URL構造ベストプラクティス準拠）
| # | チェック |
|---|---------|
| 1.17 | 意味のない長いID番号は使わない |
| 1.18 | アンダーバー（_）NG → ハイフン（-）使用 |
| 1.19 | 単語間を繋げない（`/service-features` ○ / `/servicefeatures` ×）|
| 1.20 | URL変更時は301リダイレクト（一時的変更は302） |
| 1.21 | canonical or 301でURL正規化 |

### 1-6. モバイル
- 1.22 Search Console モバイルユーザビリティのエラーなし
- 1.23 モバイル表示崩れなし
- 1.24 PC vs モバイルの表示内容に大幅乖離なし
- 1.25 URL異なる場合は alternate（PC側）・canonical（SP側）

### 1-7. スパム回避
| # | チェック |
|---|---------|
| 1.26 | インタースティシャル広告など邪魔な広告がないか |
| 1.27 | クローキング（検索エンジンとユーザーで異なる表示）NG |
| 1.28 | 不正なリダイレクト（モバイルだけスパムページ等）NG |
| 1.29 | 隠しテキスト・隠しリンク（背景同色／極小フォント／画像で覆う）NG |
| 1.30 | 内容の薄いアフィリエイトサイトになっていないか |
| 1.31-1.32 | 手動による対策・セキュリティの問題の通知なし |

### 1-8. 構造化データ & CWV
- 1.33 解析不能な構造化データエラーなし
- 1.34 LCP（最大コンテンツ表示）≤ 2.5秒
- 1.35 FID（最初のアクション反応速度）≤ 0.1秒
- 1.36 CLS（レイアウトズレ）良好
- 1.37 Google Analytics 設定済み・分析可
- 1.38 Search Console 設定済み・分析可

## 3. EEAT施策（10項目）

> EEATは直接的なランキング要素ではないが、**「他のシグナルに反応し、良いコンテンツとして判断される可能性が高い」**（2023年1月26日 Googleポリシーオフィスアワー）

| # | チェック |
|---|---------|
| 3.1 | コンテンツ制作ポリシーページ（誰が／どのように／なぜ作成したか） |
| 3.2 | EC: 返金ポリシーページ |
| 3.3 | プライバシーポリシーページ |
| 3.4 | 連絡先情報 / お問い合わせフォーム |
| 3.5 | 運営者情報ページ（会社概要・所在地・代表者・連絡先）|
| 3.6 | 利用規約ページ |
| 3.7 | Whois情報を**ドメイン保持者で公開**（代行ではなく）|
| 3.8 | Googleビジネスプロフィール登録 |
| 3.9 | SSL化（https） |
| 3.10 | YMYL領域は適切な著者・監修者を採用 |

## 4. コンテンツ施策（32項目）

### 4-1. タイトル・メタ
- 4.1 タイトルタグにキーワード（**完全一致**で含める。文脈不自然なら除く）
- 4.2 1ページ目に来ているページはCTR向上タイトルに（「2023年最新」「おすすめ20選」「【】墨付き」）
- 4.3 タイトル誇張で誤解を与えない
- 4.4 メタディスクリプションでページ／サービスの魅力を伝える
- 4.5 h1タグに対策キーワード（タイトルタグでなくh1が表示されるケースもある）
- 4.6 h要素は**入れ子構造**を守る（東京都→世田谷区→三軒茶屋駅 ○ ／ 渋谷区 ×）

### 4-2. コンテンツ品質
| # | チェック |
|---|---------|
| 4.7 | キーワードスタッフィング（詰め込み）NG |
| 4.8 | DB型サイトはデータ数が競合と比較して劣後していないか |
| 4.9 | 検索意図を満たす十分なコンテンツがメインに存在 |
| 4.10 | 検索意図が近しい関連KWも同時対策 |
| 4.11 | ポゴスティッキング（検索結果⇔サイトを行き来）発生しにくいコンテンツ |

### 4-3. 情報鮮度（フレッシュネスアルゴリズム）
- 4.12 情報鮮度が重要な記事は**実際に内容を更新**（日付だけNG）
- 4.13 ニュース・キャンペーン記事は更新日を表示
- 4.14 公開日・更新日を**構造化マークアップ**

### 4-4. オリジナリティ・読みやすさ
- 4.15 可能なら一次情報を含める（独自アンケート、自社しか出せない情報）
- 4.16 オリジナル画像・インフォグラフィック
- 4.17 alt属性は画像を適切に表す
- 4.18 引用は blockquote タグ＋出典明記
- 4.19 ランキング操作目的の自動生成NG（AIで有用コンテンツ作成は可）
- 4.20-4.21 誤字・事実誤認なし（YMYL領域は監修者を）
- 4.22 複数情報羅列は table / list タグで読みやすく
- 4.23 コピペチェック必須（CCD、コピペリン）

### 4-5. 発リンク・重複
- 4.24-4.26 低品質発リンクNG／信頼できない発リンクは nofollow ／信頼できる発リンクは dofollow
- 4.27 テンプレ生成ページ（エリア・店舗等）の重複率を独自コンテンツで下げる
- 4.28 FAQ構造化マークアップでCTR向上

### 4-6. キーワード戦略
- 4.29 **SEOは手段**。目的に合わせたキーワード選定（CV目的なのにCVから遠いKWばかりはNG）
- 4.30 上位表示が現実的でないKWで無理に対策しない
  - Ahrefs SEOツールバーでDRを確認 → 自社サイトとのDR乖離が大きい場合は被リンク獲得が必要
- 4.31 競合の取得KW調査でお宝KW発掘
- 4.32 強調スニペット対策（簡潔な検索意図への回答／表示形式に合わせる）

## 5. CV施策（番外編 / 10項目）

### CTA配置
| # | チェック | 目安 |
|---|---------|------|
| 5.1 | 離脱防止バナー | CTR 0.3〜1%+ |
| 5.2 | 導入文直下に最初のCTA（顕在KW流入は前半でCV狙う）|  |
| 5.3 | 記事内の関連箇所にCTA（商品紹介部、解決策の部分）|  |
| 5.4 | モバイルフッターバナー | CTR 0.5%+ |

### CTAデザイン・コピー
- 5.5 CTAデザインを十分目立つものに
- 5.6 ボタンに影をつけるなどクリックできることを伝える
- 5.7 ラベルは簡潔・動詞使用（何が起きるか明確に）
- 5.8 マイクロコピー：「○秒で登録完了」「○%オフキャンペーン」「〜が体験し放題」

### 計測・最適化
- 5.9 GTMで記事ごとのCTAクリック数を計測 → どの記事に注力すべきか・新規KWを判断
- 5.10 **成果地点をキーワードに合わせる**（「知りたい」意図には「お問い合わせ」「購入」ではなく「お役立ち資料DL」）

## So What — 太一としての示唆

- 既存案件のSEOオーディットは本ガイドラインを**1次チェックリスト**として使うのが最効率（101項目で網羅性◎）
- 4.29「**SEOは手段**」「成果地点をKWに合わせる」(5.10) は、CSの戦略提案で言語化しておくと刺さる
- 1.30「内容の薄いアフィリエイトサイト」と 4.19「自動生成コンテンツ」は、AI生成コンテンツが当たり前になった今こそ慎重に判断すべき
- 4.14 構造化マークアップ（公開日・更新日）は地味だがフレッシュネス対策として必須
