# SEOに強いブログの執筆 実践ガイドBOOK（HubSpot）

## 出典
- HubSpot Japan「SEOに強いブログの執筆 実践ガイドBOOK」（移管元: `知見・ナレッジ移管/SEO/SEOガイド.pdf`、ファイル日付 2023-08-15）

## 用途（こんな時に見る）
- 新規でSEOブログを立ち上げるとき、トピック選定〜運用までの全体プロセスを設計したいとき
- 「ブログは問い合わせを増やすためのものではない」を経営層に説明したいとき
- トピッククラスター戦略（ピラーページ + クラスターページ）を実装したいとき
- アウトライン作成の作法（読み手・データ・競合分析）を新人に教えるとき
- リソース配分（社内 vs 社外 / マーケ知識・専門知識・構造化力・文章力）を判断したいとき

---

## 1. ビジネスブログ実施の必要性

### ブログは問い合わせを増やすためのものではない
- 経営陣「問い合わせを伸ばせ」→ マーケ「ブログ始めます」 はミスマッチ

### カスタマージャーニーで位置づける

```
認知 → 検討 → 決定
                 ↓
            SOS（問い合わせ）= 営業のアプローチ層
```

| ステージ | 誰が動くか |
|---------|-----------|
| 認知ステージの潜在顧客 | **ブログ**で情報発信 |
| 検討ステージの見込み顧客 | **ブログ**で比較検討情報を提供 |
| 決定ステージ以降の上澄み | **営業**がアプローチ |

> ブログは「**認知**ステージで見つけてもらう」「**検討**ステージで比較・検討可能な情報を提供する」ため。

---

## 2. SEOに効果的なブログの必須要素

### 2つの軸
1. **読み手にとって価値のある情報**を提供
2. **必要最低限のSEO**を理解

### 価値ある情報 = 既読後に読み手が意思決定して目標に向けて行動できる状態
- **ブログにはCTAを付けることが必須**
- ペルソナの **目標 × 課題** を深堀りしてから書く

### 最低限おさえるSEO施策
- タイトルにSEOキーワード入れる
- 見出し（h2, h3）にキーワード
- モバイルファースト
- **関連性のあるコンテンツを増やす**
- **低品質なコンテンツをなくす**

### トピッククラスター戦略
キーワードではなく**トピック**に重点を置く戦略。サイト構造を改善しコンテンツの関連性をGoogleが認識しやすくする。

```
        コアトピック（ピラーページ）
        例：SEO、ビッグデータ
           ↓
        サブトピック（クラスターページ）
        例：SEO手法、SEO効果、ビッグデータとは
```

| ページ種別 | 役割 | 例え |
|----------|------|------|
| **ピラーページ** | 特定トピックの包括的情報 | 本の目次 |
| **クラスターページ** | 深掘りした情報 | 本の各章 |

→ Googleアルゴリズム変化に対応するためのフレームワーク。

## 3. 実践的なブログ執筆プロセス（8ステップ）

```
1. コアトピック選定  →  2. サブトピック選定  →  3. アウトライン作成  →  4. ドラフト作成
       ↓
5. レビュー  →  6. 記事公開  →  7. トラフィック分析  →  8. リライト
```

### Step 1: コアトピック選定

**アプローチ**：
1. ペルソナ調査でターゲットが興味を持ちそうなコンテンツ
2. セールス／マーケ部門に最も寄せられる質問
3. 自社ノウハウで一般的に知られていないこと・逆説的なこと
4. 業界トレンドの説明と自社の見解

**ツール**: Googleトレンド

### Step 2: サブトピック選定

**潜在ニーズを調べる**
- STEP 1: Google検索のサジェスト・関連検索を確認
- STEP 2-a: 関連キーワード取得ツール（Googleサジェスト＋goo＋知恵袋を一括）
- STEP 2-b: Googleキーワードプランナー（検索ボリューム確認）

**カテゴリ化**: ノウハウ系（とは / 違い / 事例）／求人系 など分類してサブトピック化。

→ ピラーページではサブトピックを**見出し**に、サブトピックは**深掘りしてブログで執筆**。

### Step 3: アウトライン作成

#### コンテンツと料理は似ている
- 料理 = コンテンツ
- レシピ = アウトライン
- 食べる人 = 読み手
- 材料 = 事例 / データ

#### 読み手を考える（記事ごとにペルソナを考える）

| 項目 | 内容 |
|------|------|
| 目標 | 〇〇から学習し、〇〇のアクションプランを作るためのヒントを見つける |
| 状況 | 〇〇部署立ち上げ、1人目に立候補した |
| 課題 | 一般論は収集済、実践的情報を見つけられない |
| 関心事 | A vs Bをどう切り離すか、自社サイズではどう取り組むべきか |

#### 材料 = 事例 / データ

| 例 | 評価 |
|----|------|
| 「イチローはすごいバッターだ」 | NG（何がすごいかわからない） |
| 「MLB移籍後10年連続200本安打」 | NG（野球知らないとピンとこない） |
| 「日米通算安打4367本でギネス記録認定」 | **OK**（野球知らなくても凄さが伝わる） |

#### 競合分析
- 実際にSEOワードでGoogle検索して上位5記事のタイトル・見出しを確認
- 上位記事の類似性 → 一致する見出しのトピックを把握
- オリジナリティを出せる余白を考察

### Step 4: ドラフト作成 — 書き方の原則

| 原則 | 例 |
|------|-----|
| 量をこなしていけば慣れる | ビジネス書を読んでインプットも増やす |
| **一文を長くしすぎない** | 文章は読みやすいサイズで区切る |
| **主語と述語を離しすぎない** | NG: 店員は男性客が女性客が…<br>OK: 女性客でも気軽に利用できるお店のほうが…と男性客が言っていたのを店員は聞いた |
| **漢字を開く** | 出来ます→できます／〜と言う→〜という／是非→ぜひ |

### Step 5-6: レビュー & 公開
- 第三者にレビュー前に一晩寝かせてセルフレビュー
- プリントアウト＋赤ペンで依頼
- 2〜3人の意見を聞く
- 公開後はSNS／メール／友人知人にシェア依頼

### Step 7-8: トラフィック分析 & リライト
- Google Search Console で実際の流入KWを確認
- 狙ったKWとズレていれば**タイトルを変える**、追記情報を分析・改善

## 4. ブログ制作の様々な手段

### 必要スキルの4分解

| スキル | 必要な工程 |
|-------|----------|
| マーケ知識 | 1. コアトピック / 2. サブトピック / 3. アウトライン / 5. レビュー / 7. 分析 / 8. リライト |
| 専門知識 | 3. アウトライン / 4. ドラフト |
| 構造化力 | 3. アウトライン |
| 文章力 | 4. ドラフト |

### 制作手段の選択肢

| パターン | 適性 |
|---------|------|
| マーケ担当本人 | 一人で全部こなすのは至難 |
| **社内コンサル/開発担当（専門知識者）** | 「リードが増える」「ソートリーダーとして市場価値が高まる」を訴求 |
| 社内営業担当（潜在顧客のニーズ熟知） | インタビュー（ゴーストライティング）で**1時間で3本分**の情報を引き出せる |
| 外部：会社（コンテンツ制作会社） | カネを時間・ヒトに換える |
| 外部：個人（クラウドソーシング） | 〃 |

外部依頼時には **「ペルソナ」と「カスタマージャーニーマップ」が必須**（書くことはプロに任せても、顧客インサイトを最も深く知っているのはビジネスオーナー）。

---

## まとめ

1. ブログはカスタマージャーニーの**「認知」と「検討」**ステージへの発信
2. SEOには**トピッククラスター戦略**が有効
3. **アウトラインの作り方**が良いブログ記事を書くために超重要
4. 自社の状況に合わせて最適な制作方法を選ぶ

---

## So What — 太一としての示唆

- 「ブログは問い合わせを増やすためのものではない」は経営層向け説明テンプレとして秀逸（CSとして提案するときに使える）
- アウトラインを「料理のレシピ」に例えるのは新人教育で使える比喩
- 「専門知識者を社内営業 / コンサルから引き出すゴーストライティング」は記事制作のリソース不足案件で即使える型
- 外部委託前のペルソナ／CJMマップの必須化は、後の修正コスト削減で大きい
