## 2023年2月のハイライト

### 1. AIコンテンツ検出ツール 5選（2/1）
OpenAI「AI Text Classifier」公開。他にも以下：
- GPTZero / AI GPT3 Detector by Kazan SEO / AI Content Detection by Content At Scale / AI Content Detector by Crossplag

**示唆**: 外部記事委託をしている場合はAIコンテンツチェック必須化が現実的。ただし精度はまだ不十分。

### 2. MFI移行未済サイトが依然として存在（2/9）
- 2018年3月に移行開始、最終バッチ実行中で完了時期は不透明
- → モバイル表示が崩れていないか、使いづらくないかを確認しておく

### 3. Googleがリンクのベストプラクティスを公表（2/15）
セントラルドキュメント英語版に追加：

| 項目 | 内容 |
|------|------|
| アンカーテキストの設置場所 | `<a>` タグの間に置く |
| 適切なアンカーテキスト | わかりやすく、ほどよく簡潔で、ページに関連したもの |
| 内部リンク | 全ページに最低1ページの内部リンクを設置 |
| 外部リンク | 信頼できない外部サイトはNofollow |

### 4. GoogleがPC検索でのサイト名とファビコン表示をテスト中（2/15）
- 2022年10月にモバイル検索で正式導入済
- PC検索でもブランド力のあるサイトがクリックされやすくなる可能性

### 5. Core Web Vitalsの指標改善は優先順位最高ではない（2/20）
> John Mueller氏：「中小企業やローカルを対象としたサイトにおいて、Core Web Vitalsの指標を改善する施策の優先順位は高くない」

- LCP / FID / CLS は明らかに遅い時のみ即対応
- コンテンツや内部施策など他にできることがあるなら、Core Web Vitalsよりそちらを優先

### 6. 2023年2月プロダクトレビューアップデート開始（2/21）
- 日本語圏は対象外（英語、スペイン語、ドイツ語、フランス語、イタリア語、ベトナム語、インドネシア語、ロシア語、オランダ語、ポルトガル語、ポーランド語）
- 質の高い商品レビュー／独自調査／専門家コンテンツを高評価

### 7. Microsoft Bing AIチャットで「トーン」設定をテスト中（2/28）
- Creative / Balanced / Precise の3種類

## 注目のトピック・施策

### A. Googleビジネスプロフィールにサービスを追加するとローカルランキングに影響
- Joy Hawkin（カナダ）の調査で順位上昇が確認された
- ローカル検索 = 関連性 × 距離 × 知名度
- → エリア限定でB2C展開している企業はGBPヘルプページを見て更新する

### B. 急増するサイト内検索結果ページを利用したスパム
**攻撃手口**：
1. 対象サイトのサイト内検索でスパム文章を入力して検索
2. Googlebotがスパムクエリで検索したサイト内検索結果ページのURLをクロール → インデックス

**対策**: サイト内検索の検索結果ページに `noindex` を設定する（自然検索流入を狙わない場合）

## So What — 太一としての示唆

- **「Core Web Vitalsは最優先ではない」**は、CS提案で過剰なエンジニア工数依頼を抑える根拠として使える
- サイト内検索ページのnoindex設定は、EC・記事サイト案件でチェック対象に追加
