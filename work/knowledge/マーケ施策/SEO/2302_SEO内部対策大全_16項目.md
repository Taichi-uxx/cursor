## 第1章: SEO内部対策とは

> **SEO内部対策 = 自社サイト内で実施する対策**。
> 被リンクなどの外部対策とは違い**減点方式**。
> 良質なコンテンツを最大限に伸ばすため、サイト運営上必要な対策。

### 3種類

| 種類 | 内容 | 対策例 |
|------|------|--------|
| コンテンツ最適化 | コンテンツ部分のSEO最適化 | タイトル/meta description |
| テクニカルSEO | 検索エンジンの技術仕様に合わせた対策 | HTMLタグ、サイトマップ |
| ユーザビリティ | サイト内のユーザー使いやすさ向上 | 404ページ、MFI対応 |

### 内部対策の目的
Googleからサイト情報を認識・インデックスされるため。**未実施だとSEO観点で減点**される。

```
サイトコンテンツ100点 × 内部対策実施 → 1位（100点）
サイトコンテンツ100点 × 内部対策未実施(-40点) → 6位（60点）
```

## 第3章: コンテンツ最適化 4選

### 3-1. タイトル（h1タグ）にキーワードを含める
- 上位表示を狙うキーワードを必ず含める
- Googleがウェブマスター向けガイドラインで「順位決定要因の1つ」と明言
- ユーザー視点でもキーワード一致でクリック率上昇

### 3-2. meta description を書く
- ウェブマスター向けガイドラインでは言及なし
- ただしスニペットで検索KWが太字化されるため、SEOに一定の影響

### 3-3. 見出しタグ（h1, h2, h3...）の使い分け
- 文章全体の構造を表現
- John Mueller氏（2020/8/7）「ページ見出しはコンテンツのよりよい理解になる」と明言
- 上位表示KWを見出しにも含める

### 3-4. 画像の alt 属性
- 検索エンジンは画像だけでは内容を把握できない
- ガイドライン明記：「alt属性をわかりやすく、具体的で正確なものに」
- 画像検索でも狙ったKWで上位表示可能

## 第4章: テクニカルSEO 9選

| # | 項目 | 要点 |
|---|------|------|
| 4-1 | XMLサイトマップ | XML形式でサイト構造を伝える。新規ページや大規模サイトに有効 |
| 4-2 | 内部リンク最適化 | クローラー巡回速度UP＋ページ内容の網羅性が正確に伝わる |
| 4-3 | パンくずリスト | 「サイトのどこにいるか」を伝える。Google公式推奨 |
| 4-4 | SSL適用（HTTPS） | ランキングシグナル。**Google公式採用** |
| 4-5 | Canonical | 重複ページのURL正規化。評価分散を防止 |
| 4-6 | robots.txt | クローラーの巡回制御 |
| 4-7 | 構造化マークアップ | 順位影響はないが**検索結果表示に影響**（リッチリザルト） |
| 4-8 | ディレクトリ構造 | 第3階層まで／トップから2クリックで末端へ |
| 4-9 | noindex | 質が低い／重複ページをインデックスから除外 |

### URL重複パターン（4-5 Canonical補足）
- `www`有無 / SSL有無（http vs https）
- パラメータ（?以下）の有無 / index.html有無
