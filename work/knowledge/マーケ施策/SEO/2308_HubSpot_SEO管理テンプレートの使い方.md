# HubSpot SEO管理テンプレートの使い方

## 出典
- HubSpot Japan「SEOテンプレート（SEO Template）」（移管元: `知見・ナレッジ移管/SEO/SEO管理のテンプレート.xlsx`、ファイル日付 2023-08-13）
- xlsx本体は同フォルダに保存済み: `SEO管理のテンプレート.xlsx`

## 用途（こんな時に見る）
- クライアントサイトのオンページSEOを「ページ単位で管理しながら最適化を回す」運用を組み立てたいとき
- どの列に何を書くか・上限文字数の目安を確認したいとき
- CTA/コンバージョン率をファネル別に記録する設計を参考にしたいとき

## テンプレートの構造（3シート）

1. **このテンプレートの使い方** — 各列の解説
2. **最適化テンプレート** — メインの記入シート（1002行 × 59列）
3. **HubSpotのツールの使い方** — KeywordsツールやPage Performanceツールの使い方

---

## 最適化テンプレートの列定義

### 現状把握列（A〜I）

| 列 | 項目 | 内容・上限 |
|----|------|-----------|
| A | コンテンツの種類 | トップ／内部／LP／ブログ／製品／サンキューなど。編集対象を明記 |
| B | 現在のURL | 手動 or サイトクローラー（HubSpot Page Performance、Xenu等）でエクスポート |
| C | 現在のページタイトル | 既存タイトル |
| D | （自動）長さ | — |
| E | 現在のページの説明 | 既存meta description |
| F | （自動）長さ | — |
| G | **ページの目的** | 製品情報／ソリューション説明／FAQ／イベントなど。最終的な目的は何か |
| H | **ターゲットオーディエンス** | バイヤーペルソナ。SEO施策で誰を惹きつけたいか |
| I | マーケティングキャンペーン | 関連キャンペーンを列挙 |

### 編集記録（J）

| 列 | 項目 | 内容 |
|----|------|------|
| J | 編集日 | 全ページ一度に編集は不可能。**進捗報告のために変更日を記録** |

### 新SEO戦略列（K〜N）

| 列 | 項目 | 上限・指針 |
|----|------|----------|
| K | 新しいページタイトル | **全角35文字以下**。「キーワード｜キーワードのバリエーション」形式が定石 |
| L | （自動）タイトルの長さ | — |
| M | 新しいページの説明 | キーワードを取り入れた簡潔文。ページ自体の文章をそのまま繰り返さない |
| N | （自動）説明の長さ | **150文字以下** |

### コンテンツ・構造（O〜T）

| 列 | 項目 | 指針 |
|----|------|------|
| O | ターゲットキーワード | **1ページ＝1KWに絞る**（トップページなど例外で4個ほど可） |
| P | コンテンツ | **少なくとも900文字程度**を目指す。読みやすいフォーマット |
| Q | ヘッダー（H1相当） | コンテンツ導入部。視覚的手がかり |
| R | サブヘッダー（H2相当） | 各セクションの先頭 |
| S | 画像（ファイル名） | キーワード＋関連語のファイル名（`internet_marketing_software.jpg` 等） |
| T | 画像（alt） | 代替テキストにできる限り説明 |

### リンク・シェア（U〜W）

| 列 | 項目 | 内容 |
|----|------|------|
| U | 内部リンク（アンカーテキスト） | 参照先がわかるキーワード入り |
| V | 内部リンク（リンク先ページ） | URL |
| W | ソーシャルメディアでのシェア | あり／なし。**シェアはSEOで重要** |

### CTA（X〜AD）— ファネル別

| 列 | 項目 |
|----|------|
| X | TOFU CTA（例：ホワイトペーパーDL） |
| Y | 最適化前のTOFUコンバージョン率 |
| Z | 最適化後のTOFUコンバージョン率 |
| AA | MOFU CTA |
| AB | 最適化前MOFU CVR |
| AC | 最適化後MOFU CVR |
| AD | BOFU CTA（例：無料デモ） |
| AE | 最適化前BOFU CVR |
| AF | 最適化後BOFU CVR |

→ **CTA編集／更新時はコンバージョン率の変化を必ず記録**。

### メモ（AG）

| 列 | 項目 | 用途 |
|----|------|------|
| AG | メモ | コンテンツ刷新要否／別ブログ用意の判断／URL変更時の301リダイレクト設定など |

## 運用ヒント（テンプレ説明から抜粋）

- HubSpotを使っている場合 `Reports → Page Performance` で全インデックス済ページをエクスポート
- 取り込み後は**重要度順に並べ替え、週5〜10ページずつ最適化**していく
- 最適化プロジェクトの手軽な第一歩 = **タイトル35文字超のページを全て新しくする**ところから

---

## 関連ツール（HubSpotのツールの使い方シートより）

### HubSpot Keywordsツールの3つの目的
- 検索ランクに入っているキーワードを探り出し、進展を追跡
- 競合サイトの上位KWと自社を比較
- 代替KWリストを作成し、コンバートしていないKWを発見

### 4つの活用シーン
- トラフィックの獲得
- キーワードのバリエーション探し
- ブレーンストーミング（新規ブログタイトル）
- チャンスの発見（競合より優位に立つ機会）

---

## So What — 太一としての示唆

- このExcelテンプレ構造（**TOFU / MOFU / BOFU × 最適化前後CVR**）はSpreadsheetに転記しておくとSEO案件のレポートテンプレとして即使える
- 「タイトル35文字超を全部直す」は最初の1〜2週間の効果実証ネタとして使えるクイックウィン
- 列定義の翻訳版を社内ドキュメント化すれば、外部委託先への発注スペックとしても流用可能
