## 概要
レキシ社は「経験豊富な専門家による営業コンサルティング＋アウトバウンドコールのアウトソーシング」をワンセットで提供するサービス。一般的な営業代行のアポインター（コール量勝負・アポ質低い・改善提案なし）と差別化し、コンサルタント水準の人材が「稼働量ではなく成果」にこだわって遂行する点を最大の特徴に据える。サービス範囲はインサイドセールス代行に留まらず、ターゲティング設計、トークスクリプト設計・改善、Salesforce等CRM活用支援、関連部門（マーケ／フィールドセールス／エンジニア）との連携設計まで含む包括型。対象はSaaS／IT・ハイテク／金融／医療など、規模は上場企業〜スタートアップまで。

## 本文

### 1. サービスが解こうとしている課題
日本の営業生産性の低さと、BtoB営業の役割分化トレンドが背景にある。

> 時間当たり労働生産性: 米国74.7ドル／日本46.8ドル（約6割）。OECD加盟36カ国中21位、主要先進7カ国では1970年以降最下位。（出典: マッキンゼー・アンド・カンパニー「日本の営業生産性はなぜ低いのか?」）

> 日本の典型的なBtoB企業の営業員の時間配分: 顧客への営業活動10〜25％ / 顧客関連活動（提案準備等）55％ / 営業活動ではない社内業務20〜35％。一方ベストプラクティスは50〜55 / 35 / 10〜15。

主流の営業手法は「マーケティング → インサイドセールス → フィールドセールス」と役割分化し、フィールドセールスはクロージングに集中、マーケ／インサイドセールスは質の高いアポ供給を担う形に移行している。

#### よく聞く現場課題（インサイドセールスを設立したが効率運用が困難）
- さらなる多くの質の高いアポが必要
- 人手不足だが採用できない
- 過去の営業代行業者がイマイチだった
- アポ獲得ノウハウが属人的
- Salesforceがうまく活用できていない
- 営業意欲の高い人材はフィールドセールス志望に流れ、インサイドセールスは「低いモチベーション／多忙／注力できない」が積算しがち

### 2. サービスの3階層（選ばれる理由）
ピラミッド構造で整理されている。

1. **Consultant（経験豊富な専門家）** — 大手コンサルティングファーム／証券会社／BtoB SaaSベンダー出身者。インサイドセールスチームを3人→35人に拡大した実績、未成熟プロダクトの完成度を上げた経験など。経営戦略実現の営業戦略立案／ロジカルで再現性ある営業プロセス構築／専門的で高いスキルを活かしたコールを担う。
2. **Service（卓越したサービス）** — 営業戦略に基づいたターゲティング／成果が出る仕組みの構築／関連部門との連携／セールスDX・CRMシステム活用支援／幅広いサービス（後述）。
3. **Quality（優れた品質）** — クライアントへのコミットの違い（後述の「通常のオペレーター vs 弊社のコンサルタント」）。

### 3. アウトバウンドコールの実行プロセス
ターゲティング設計から型化までを一気通貫で実施。

| ステップ | 内容 |
| --- | --- |
| ターゲティング | 対象企業の選定 |
| コール | 架電 |
| ゲート | 代表受付・アシスタントの突破 |
| コネクト | 担当者・決裁者との対話 |
| アポイント | 面談の約束 |

- 全ての会話を録音し、細かい要素（コールの曜日・日時／トーク内容／プロダクト説明内容／事例紹介内容／用いられているキーワード／アポの日程調整など）に分解して解析。
- ハイパフォーマーとローパフォーマーの差を精緻に把握し、次のコール・トークスクリプト改善へ反映。
- 思想は **「属人性を排除し、暗黙知を形式知へ」**。

### 4. ターゲティング
事業計画 → 営業戦略・営業活動 → 最適なターゲティングリストへの落とし込み、というトップダウン設計。

- 既存リストへのアプローチ／新規にリストを用意、どちらにも対応。
- 例:
  - BtoB向けSaaS → 展開を考え、業界を特定し、大企業にアプローチ
  - 新事業のテストマーケ → 幅広い業界と企業規模にアプローチ

### 5. 関連部門との連携（顧客内連携設計）
コールで得たユーザーの声を経営資源化するための部門間連携をセットで設計する。

- マーケティング部門 → リードジェネレーション／ナーチャリング
- フィールドセールス部門 → 営業活動／クロージング
- エンジニア部門 → プロダクトの改善／新しいプロダクトのヒント

「どんなユーザーが受注しやすいかを明確にし、スクリプトを改善」する循環を作る。

### 6. セールスDX・CRM活用支援
「CRMを導入したが結局エクセルになりがち」状況の改善を支援。

- 必要なデータ管理項目の見直し
- KPIの定義
- ダッシュボードの設定
- 円滑な運用に向けたコンサルティング
- 改善サイクル: アポイント獲得率の要因を分析 → トークスクリプトをブラッシュアップ → KPIの定点観測に基づきアクションプラン策定 → 更なる目標に向かって実施

### 7. サービスメニュー（包括的なサービス）
新規案件発掘のアウトバウンドコールを中心としつつ、以下も対応。

- **Inside Sales** — チームの立ち上げ・教育／コンサルティング・アウトソーシング／インバウンド・セミナー出席者・既存ユーザーのフォロー
- **Management** — 営業戦略構築／Salesforce等CRMシステム活用支援／MAツール活用支援
- **Marketing & Field Sales** — マーケ・フィールドセールスとの連携強化／フィールドセールスのコンサル・アウトソーシング／リードジェネレーション・ナーチャリングのコンサル

### 12. クライアントケース

#### CASE 1: BtoB向けSaaSベンダー
- 背景: 社長／営業マネジャー／フィールドセールスが営業。売上は出ているがストレッチ目標未達。質の高いアポが足りず、優秀な人材採用も困難。
- 依頼内容: 新規案件獲得のアウトバウンドコールのアウトソーシング。
- 得られたメリット: 短期間で質の高いアポを多数獲得／契約直結・ストレッチ目標達成／エンドユーザーからのプロダクトの感想をレポートし、プロダクト完成度向上。

#### CASE 2: 大企業の新規事業
- 背景: 大企業でSaaS型ビジネスモデルの新規事業立ち上げを検討。テストマーケで継続／ピボット／撤退を判断したいが、適した人材が社内にいない。
- 依頼内容: テストマーケティングのアウトソーシング。
- 得られたメリット: 短期間・低コストでテストマーケ実施／エンドユーザーへのアプローチ結果をレポート／新規事業の意思決定に必要な情報が整備。

#### CASE 3: 営業改革に取り組まれた企業
- 背景: セールスDX・営業改革の必要性からインサイドセールスチームを設立。アウトバウンドコールはしているがアポ質が低い。プロによる改善を希望。
- 依頼内容: 営業コンサルティング＋アウトソーシング。
- 得られたメリット: コール〜ゲート突破〜コネクト〜アポ取りまで詳細分析／時間帯・トークスクリプト・使用単語・クロージングの成功失敗パターン把握／トップ・ローパフォーマーを精緻に見える化／Salesforceダッシュボード分析／インサイドセールスチームの改善へ。

## 太一視点の示唆 / 次のアクション

### 自社（REHATCH）への適用観点
- **広告以外の獲得チャネル提案の引き出しに使える**: クライアントの売上停滞局面で「広告だけでは天井」と判断したとき、アウトバウンド営業をセットで提案する手札になる。特にBtoB SaaS／高単価商材のクライアントに対し、広告の媒体提案だけでなく「広告 × インサイドセールス」の統合提案ができれば、CSとしての提案幅が広がる。
- **CRM／Salesforce活用支援は要注目**: クライアントの広告データと営業データの連携が弱いケースは多い。「成果が出る仕組み構築」の中にCRM活用支援が含まれている点は、自社のLooker／データ統合構想（Client OS Hub）と相性が良い。レキシ社の支援内容を「広告代理店としての提案フレーム」に翻訳して活用できる。
- **「コンサル品質のアウトソース」というポジショニングは参考になる**: 通常のオペレーター vs コンサルタントの対比は、広告代理店業界での「単純運用代行 vs 戦略パートナー」の差別化と同型。自社のディレクター価値を言語化する際のフレームとして使える。

### クライアント案件への適用観点
- **「広告でリードは取れるがアポ質・受注率が低い」クライアントへの紹介候補**: 特にBtoB SaaS／高単価サービスで、社内インサイドセールスが弱い場合、レキシのような外部パートナーを薦めることでクライアントのCVR上流改善が見込める。広告KPI（CV数）だけでなく、その先の受注率まで責任を持つ提案姿勢に繋がる。
- **新規事業テストマーケ案件で活用余地**: クライアントが新規事業を立ち上げる際、広告（量検証）＋アウトバウンドコール（質検証）の両輪で短期テストする提案が組める。CASE 2は自社案件にも転用しやすい。
- **アポ獲得後の質分析の重要性を再認識**: 「コール量／アポ量での評価がアポ質低下を招く」というレキシの問題提起は、広告でも全く同じ構造（CV数最適化がCV質低下を招く）。クライアントへの説明素材として転用できる。

2. レキシ社の料金感・最低契約期間は資料に未記載なので、必要に応じて個別ヒアリング（推定: 月額数十〜百万円規模、3〜6ヶ月の契約期間か）。

4. CRM活用支援部分の具体メソッド（KPI定義／ダッシュボード設定）は、自社のクライアント向けレポーティング改善にも応用できそうなのでメモ化しておく。
