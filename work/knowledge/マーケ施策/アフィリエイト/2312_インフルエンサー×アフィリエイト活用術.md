## 用途 — 想定シーン

1. **クライアントへのインフルエンサー施策提案**: 純広型（フォロワー×単価）一辺倒の提案に「成果報酬型インフルエンサー」という第3の選択肢を加え、費用対効果を語れるようにする。
2. **SNS別の費用感を即答する**: Instagramフィード5万円〜、Instagramストーリーズ「フォロワー数×1〜3円」、YouTube動画作成費50万円〜、TikTok動画作成費10万円〜、といった「相場感」をクライアントとの初期会話で提示する。
3. **インフルエンサー施策のKPI設計**: 「実施したが効果がわからない」を防ぐため、認知／情報収集／比較検討／購買の4段階に応じたKPIテンプレ（ビュー数・いいね率・保存数・CPA等）として使う。
4. **クラス別アサインの判断軸**: 有名人／トップ／マイクロ／ナノの4階層を踏まえ、「マイクロ×成果報酬」が予算と効果のバランスで現実解になることをクライアントへ説明する。
5. **D2C／EC新規獲得施策の設計**: アンクオリジナル事例（売上前年比170%）のように、ヘアサロン発D2Cブランド等で「インフルエンサー起点でファンを増やす」モデルを提案する。

## 概要

本資料は、A8.net（FANCOM）が提供する「アフィリエイト基盤上で動かすインフルエンサーマーケティング」の解説書である。一般的なインフルエンサーマーケが「フォロワー×単価」「再生回数×単価」など露出ベースの**純広告型**で費用が発生するのに対し、A8.netを通じた施策は**アフィリエイト会員兼インフルエンサー**という位置づけで、原則**成果報酬型（CPA）での発注が可能**という点が最大の差別化ポイントになる。

構成は2章立て。第1章でインフルエンサーマーケ全体像（クラス分け／メリット・デメリット／SNS媒体比較／費用形態6型）を整理し、第2章でA8.net×インフルエンサーの座組み・SNS別掲載方法・4ステップの実施手順（目的明確化→媒体選定→キャスティング→KPI設定）・SNS別活用事例・導入事例（アンクオリジナル）まで落とし込む構造。BtoBの提案ツールとして「料金体系の選択肢を増やす」目的で設計されている。

## 本文

### CHAPTER 1 — インフルエンサーマーケティング

#### 1-1. インフルエンサーの定義と背景

> インフルエンサー（influencer）は、影響・感化の意味を持つ「Influence」を語源とし、web上ではSNSを通じて他者の購買行動に強い影響力を及ぼす人を指します。

- **語源**: Influence（影響・感化）
- **SNS別呼称**: YouTube=ユーチューバー／Instagram=インスタグラマー／TikTok=ティックトッカー
- **背景データ（総務省2020年）**:
  - 10〜20代の休日テレビ視聴時間: 平均約110分
  - 10〜20代の休日インターネット利用時間: 220分（テレビの**2倍**）
  - → 若年層を中心にSNSインフルエンサーの影響力が拡大

#### 1-2. インフルエンサーのクラス（フォロワー数ピラミッド）

| クラス | フォロワー数 | 特徴 |
|---|---|---|
| **有名人** | 100万人以上 | 芸能人・モデル等、テレビ含むマスメディアで活躍 |
| **トップインフルエンサー** | 10万〜100万人 | 多くが事務所所属。特定分野で高い知名度 |
| **マイクロインフルエンサー** | 1万〜10万人 | SNSで活動する中核層 |
| **ナノインフルエンサー** | 1,000〜1万人 | 同じくSNS活動の中核層 |

> SNSで活動する多くは、マイクロインフルエンサーやナノインフルエンサーに該当します。

→ **提案実務での意味**: フォロワー数で4クラスを切り、予算と影響範囲のトレードオフを定量的に語れる。

#### 1-3. メリット（3つ）

| # | メリット | 要点 |
|---|---|---|
| 01 | **情報拡散力** | フォロワーのいいね・リツイート連鎖でSNS瞬発拡散 |
| 02 | **広告っぽさの軽減** | 通常投稿形式のため受け入れられやすい（※PR表記は必須） |
| 03 | **消費者目線の発信** | 販売者目線ではなく実体験ベースで伝わるため共感を得やすい |

#### 1-4. デメリット（3つ）

| # | デメリット | 要点 |
|---|---|---|
| 01 | **炎上リスク** | 拡散力の裏返し。投稿内容は慎重に吟味。問合せ・アクセス集中対策も必要 |
| 02 | **インフルエンサー選定の難しさ** | ターゲットとフォロワー属性の一致／予算適合／実績確認に工数・リソースを要する |
| 03 | **効果の予測困難** | 認知は得意だが顧客獲得に直結しにくい。商材との相性・SNS媒体の状況に左右される |

#### 1-5. 各SNS媒体の特徴

| 媒体 | 国内ユーザー数 | 中心ユーザー層 | 特徴 |
|---|---|---|---|
| **Instagram** | 3,300万人（2019.6） | 10〜30代中心（利用率50%以上）、女性比率高 | 写真・動画の視覚訴求がメイン。世界アクティブ約10億人 |
| **X (Twitter)** | 月間5,895万人（2022.1） | 10〜30代中心（利用率60%以上） | 140字短文。リアルタイム情報×拡散力。RT・いいねでフォロワー外にも届く |
| **YouTube** | 7,000万人（2022.10） | 10〜50代と幅広（10〜40代利用率90%以上） | 動画プラットフォーム。テレビ代替視聴も多い |
| **TikTok** | 1,700万人（2021.8） | 10代中心（利用率57%）、Z世代 | 15秒前後の音楽連動動画。アプリ内で簡単制作、没入感が強み |

#### 1-6. 一般的な費用形態（6型）

| # | 形態 | 単価相場・特徴 |
|---|---|---|
| 01 | **フォロワー数×単価** | 投稿あたり「フォロワー×2〜6円」。クラス・フォロワー数・実績で単価決定 |
| 02 | **再生回数×単価** | 「平均再生回数×3〜20円」。チャンネル登録者数・高評価比率・コメント量も加味 |
| 03 | **成果報酬型** | 数百円〜数千円／件。購入・資料請求等の成果発生時のみ費用発生 |
| 04 | **売上割合型** | 売上に対し歩合 or 定率で算出。コラボ商品等のタイアップ施策で用いられる |
| 05 | **費用全額負担型** | PR実施にかかる費用（撮影・制作含む）を依頼主が全額負担する形態 |
| 06 | **ギフト型** | 商品・サービスを提供し、レビュー投稿してもらう（ギフティング） |

> ※相場は目安。

→ **提案実務での意味**: 「フォロワー×単価」「再生回数×単価」「成果報酬」「売上割合」「費用全額負担」「ギフト」の**6型をメニュー化**して提示できると、クライアントの予算とリスク許容度に応じた最適提案ができる。

### CHAPTER 2 — A8.net×インフルエンサー

#### 2-1. A8.netを通じたインフルエンサーマーケの座組み

> 位置づけとしては、アフィリエイト会員兼インフルエンサーです。

**座組みの流れ**:

```
広告主（依頼主）─[A8.netへ出稿]→ A8.net ─[インフルエンサーと提携]→ インフルエンサー ─[SNS投稿]→ ユーザー
```

**一般的なインフルエンサー施策との決定的な違い**:

> あくまでアフィリエイトの中の施策のため、基本的には成果報酬型（ユーザーが購入や申込に至った際に費用が発生）での実施が可能という点です。

- 成果に対して広告費を支払うため**費用対効果が高い**
- どのインフルエンサーからどれくらい獲得につながったか**計測可能**

#### 2-2. A8.netで繋げるインフルエンサー（媒体別マッピング）

| SNS | フォロワーの傾向 | 得意なジャンル | 費用形態 |
|---|---|---|---|
| **Instagram** | メインは20〜30代 | 教育教材、コスメ、ファッション、宅配食品 など | 基本は成果報酬＋固定費が必要な場合も |
| **X (Twitter)** | 20〜40代と幅広い | 食品、美容、サービス系まで幅広いジャンル | 成果報酬＋固定費が必要な場合も |
| **YouTube** | 20〜70代と幅広い | 家電、電子機器、美容、クレジットカード など | 成果報酬＋動画作成費用 |
| **TikTok** | 視聴者層は30代中心 | コスメ、占い、マッチングアプリ、借金減額 など | 成果報酬＋動画作成費用 |

→ **太一実務メモ**: TikTokのフォロワー傾向が「視聴者層30代中心」と書かれている点は、一般的な「10代中心」イメージと乖離。**A8.netに登録しているティックトッカー経由の視聴者層が30代寄り**という意味と解釈するのが妥当。提案時は注意。

#### 2-3. 各SNS媒体の掲載方法

##### Instagram

**フィード投稿**
- タイムライン上の標準投稿。ハッシュタグでジャンル・トレンドを訴求
- PR表記は必須
- **投稿に広告リンクは貼れない**
- 基本は**1回の投稿あたりで費用がかかる純広告での取り組み**
- **費用相場: 5万円〜**

**ストーリーズ投稿**
- 24時間限定、5〜15秒の写真・動画。ハイライト機能で保存可
- **webリンク掲載が可能** → 商品詳細サイト・記事への流入導線になる
- 規模・方法によっては**アフィリエイトの成果報酬（CPA）＋固定費・商品提供**が必要
- **費用相場: フォロワー数×1〜3円**

##### X (Twitter)
- ブログ・WEBサイトの紹介記事を作成→Xで拡散するパターン
- オールジャンル対応だが、**話題性が高い商材・予約販売・期間限定キャンペーンとの相性が良い**
- 基本は**成果報酬（CPA）での依頼が可能**、報酬額は依頼主側で設定
- 1投稿あたりの固定費がかかる場合もあり
- **成果報酬例**: 購入金額に対しての10%／資料請求あたり1000円 など

##### YouTube
- 動画内で紹介、詳細は概要欄テキストに記載
- 概要欄にwebリンク掲載可（広告リンク or 商品詳細記事への誘導）
- **基本は動画作成費用として固定費が必要**
- チャンネル登録者数が多い／知名度のあるユーチューバーは**数百万円かかる場合も**
- **動画作成費用目安: 50万円〜**

##### TikTok
- 動画投稿＋プロフィール欄にwebリンク
- ティックトッカーが作成・投稿したコンテンツを**依頼主が自社webサイト・LPに掲載する活用も増加**
- **成果報酬＋動画作成固定費（数十万円目安）**
- **動画作成費用目安: 10万円〜**

→ **提案実務での意味**: 「動画作成費の桁」がYouTube（50万円〜）とTikTok（10万円〜）で**5倍違う**。短尺動画でテストするならTikTokから入る合理性が高い。

#### 2-4. インフルエンサーマーケ実施手順（4ステップ）

```
STEP1: 目的の明確化 → STEP2: 媒体選定 → STEP3: キャスティング → STEP4: KPI設定
```

##### STEP1 — 目的の明確化

> 目的はユーザーの購買意欲の段階に応じて、「認知」「情報収集」「比較検討」「購買」の大きく4つに分けられます。

| 段階 | 落とし込んだ目的の例 |
|---|---|
| 認知 | ハッシュタグ付きの投稿数の増加 |
| 情報収集 | 投稿の拡散（エンゲージメント獲得） |
| 比較検討 | 口コミの投稿数の増加 |
| 購買 | ライブ配信による購買促進 |

→ 目的をここまで具体化することで**STEP4のKPI設定が自動的に決まる**。

##### STEP2 — 媒体選定

選定の3つの軸:

```
活用目的 × プロダクト × ターゲット → SNS媒体・インフルエンサー像
```

**資料の具体例**:
- 活用目的: 新規顧客の獲得／割引キャンペーンによる購買促進
- プロダクト: 食品宅配サービス／新鮮な食材と種類豊富なミールキット
- ターゲット: 共働きの世帯／育児中のママ／関東地方在住
- → **SNS媒体: Instagram／インフルエンサー: 子育て関連ママさん系**

##### STEP3 — キャスティング

```
広告主 ─[条件・要望]→ A8.net ─[選定・依頼]→ インフルエンサー
                                    ←─[費用交渉・スケジュール調整]─
```

- **広告主の役割**: 報酬額の設定／素材・商品の提供
- **A8.netの役割**: インフルエンサー選定／投稿依頼・条件交渉
- インフルエンサー規模・投稿形式で費用変動あり

##### STEP4 — KPI設定

> 目的とKPIの設定がずれてしまうと、「実施したけど効果がはっきりしない。」「どの様に改善につなげたらいいか分からない。」といったことが起こりうるので注意が必要です。

| 段階 | KPI例 |
|---|---|
| 認知 | 投稿のビュー数、動画再生数 |
| 情報収集 | いいね数・率、コメント数、ハッシュタグの数 |
| 比較検討 | 投稿の保存数、SNS経由のサイトアクセス数 |
| 購買 | コンバージョン数、CPA、CPI |

→ **提案実務での意味**: 「認知目的なのにCPAで評価する」というKPIミスマッチが現場で多発する。**4段階×KPI表をクライアントとの最初のキックオフで合意する**運用にするとブレない。

#### 2-5. 活用事例（SNS別 3パターン）

##### 事例1: Instagram × ファッション（購買目的）
- **目的**: インフルエンサーを起点とした新規顧客獲得
- **実施結果**: **新規注文1,000件**
- **費用**: 成果報酬＋クーポンコード（※インフルエンサー限定で高い報酬額の付与とクーポンコードを発行）
- **POINT**: ECサイトでのセールタイミングに合わせてクーポンコードを投稿。割引率の高さを訴求し購入ハードルを下げて新規顧客獲得

##### 事例2: X (Twitter) × アニメグッズ（購買目的）
- **目的**: SNSアカウントを活用した情報拡散とアニメ視聴者層の新規顧客獲得
- **実施結果**: **売上150万円**
- **費用**: 成果報酬のみ（※メディア限定の高い報酬額を付与）
- **POINT**: アニメ放映のタイミングに合わせて予約販売情報を拡散。アニメファンへの認知が広がり、高単価商品にも関わらず注文増加

##### 事例3: YouTube × 家電（比較検討目的）
- **目的**: YouTube内の商品紹介動画・関連動画の上位表示
- **実施結果**: **動画再生回数6万回**
- **費用**: 固定費＋成果報酬（動画作成費10万〜50万円ほど、※金額はインフルエンサーによって異なる）
- **POINT**: 認知拡大目的で生活・ガジェット系ユーチューバーによる動画投稿。操作方法・利用シーンを分かりやすく紹介

→ **太一実務メモ**: 3事例とも**「タイミングを合わせる」がPOINT**に入っている（セール／アニメ放映／—）。インフルエンサー施策は**単発投下ではなくマーケカレンダーとの同期設計**が成果の鍵。

#### 2-6. 導入事例: アンクオリジナル（ヘアケアブランド）

> インフルエンサー起点でファンを増やす「アンクオリジナル」のアフィリエイト活用事例

- **背景**: 都内中心に13店舗展開する人気ヘアサロン「ANKH CROSS」が2013年に発売したヘアケアブランド
- **成果**: **2020年売上高前年比170%**
- ヘアサロン発のD2Cブランド × インフルエンサー起点の新規ファン獲得モデル

## 太一視点の示唆 / 次のアクション

### 示唆 — 戦略家として何を学ぶか

1. **「インフルエンサー施策＝純広」という固定観念の崩壊**
   一般的なインフルエンサー施策の費用形態6型のうち、**成果報酬型はA8.net等のASP経由でしか実用化できない**。「インフルエンサーは高い・効果不明」と言うクライアントには、**ASP連携の成果報酬モデル**を最初に提示すべき。提案の選択肢が一段増える。

2. **マイクロ／ナノ層×成果報酬が最も費用対効果が高い理論的解**
   - トップインフルエンサー: 単価高（数百万円〜）、効果予測困難
   - マイクロ／ナノ: フォロワーとの距離が近く、消費者目線の発信で**説得力が高い**＝CVRが取れる
   - そこに**成果報酬**を組み合わせると「予算上限が読める×CVRが取れる」の両立が可能
   - これがA8.net提案の核心ロジック。

3. **「タイミング設計」こそが施策成否を分ける**
   3事例すべてで「セール／アニメ放映／（生活提案）」とタイミングを合わせている。インフルエンサー施策は**マーケカレンダー（自社／外部イベント）との同期**を前提に組まないと、単発の打ち上げ花火で終わる。

4. **KPIミスマッチを最初に潰す**
   認知目的でCPAを追わない／購買目的でいいね数を追わない。**4段階×KPI表を提案書に必ず差し込む**ことで、施策後の「効果がわからない問題」を防ぐ。

5. **媒体選定の3軸（活用目的×プロダクト×ターゲット）は他施策にも転用可能**
   この3軸はインフルエンサー施策に限らず、広告媒体選定全般に使える。CSのヒアリングシートに**この3軸テンプレ**を組み込むと、媒体提案の精度が一律で上がる。
