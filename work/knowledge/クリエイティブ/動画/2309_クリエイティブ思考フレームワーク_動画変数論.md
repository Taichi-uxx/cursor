# クリエイティブ思考フレームワーク — 動画変数論とインサイト設計

**出典:** 社内勉強会資料「クリエイティブの思考フレームワーク」/ 2023年9月  
**媒体:** 動画広告（基礎概念はバナー・静止画にも応用可）

---

## 用途（どんな時に活用できるか）

- 動画クリエイティブの「何が効いているか」を分析・説明する軸が欲しいとき
- 冒頭アイキャッチが弱い動画のボトルネックを特定したいとき
- ペルソナ・インサイトをクリエイティブに落とす設計フローを整理したいとき
- 勝ち動画から「次の一手」を導く横展開・アナロジーの考え方を確認したいとき

---

## 動画の変数構造

動画が静止画と異なる根本は「**時間軸（フロー）がある**」こと。

### 2種類の変数
| 変数種類 | 内容 |
|---|---|
| **クリエイティブ変数** | ビジュアル・コピーなど静止画的な要素 |
| **フロー変数** | シーンの移り変わり・ストーリー展開。動画ならでは |

**無限にある変数を評価可能な「必要変数」に落とし込む**ことが、動画PDCAを再現可能にする鍵。

---

## パーセプションフローモデルで設計する

動画を「再生 → 視聴 → ユーザー行動」の3段階で分解し、各段階に評価指標を持つ。

| ステップ | 問い | 評価指標 |
|---|---|---|
| **アイキャッチ** | 目や手を止めることができているか | 冒頭3秒視聴率 |
| **視聴体験の最適化** | 個人単位で視聴を継続させているか | 視聴維持率 |
| **ユーザー行動** | クリック・CVを喚起できているか | CTR / CVR / CPA |

## アイキャッチを設計する心理学的手法

### カクテルパーティー効果
「自分のことを言われている」と感じさせる。**対象を具体的に呼びかける**ほど効果大。
- 例：「○○好き必見」「10月入社を目指す転職希望者へ」

### ツァイガルニク効果
人は**完了したものより未完了のもの**に注目する。続きが気になる状態を作る。
- 例：書き途中の文字、歯抜けの吹き出し、不自然な空白

### シミュラクラ現象
**人の顔は注目を引きやすい。** 顔を冒頭に使うだけでアイキャッチ力が上がる。

## クリエイティブ変数の設計：インサイト深掘り

リスティングと異なり、ディスプレイ・動画広告は「意識が顕在化していないユーザー」に当てる。  
→ 表面的なベネフィットではなく、**内面的なインサイト**をつかむ必要がある。

### インサイトの深掘り順序
```
機能的ベネフィット → 情緒的ベネフィット → 自己実現ベネフィット
```

| レイヤー | 定義 | 例（転職サービス） |
|---|---|---|
| 機能的 | 商品の特徴がもたらすプラス効果 | お金・時間が欲しい |
| 情緒的 | 商品を持つことで得られるプラスの感情 | 余裕が欲しい |
| 自己実現 | 商品によって可能になる自己実現 | 理想の生活・夢が欲しい |

> 深掘るほど「そうそう、これ！」と刺さる訴求に近づく。

## 勝ちクリエイティブの展開方法

### 横展開（変数を最小限に変えて数を拡げる）
元の動画を踏襲しつつ、1変数だけ変える。
- 例：ビジュアルのみ変更して勝ち訴求を横に広げる
- 視聴傾向データを活用したブラッシュアップも有効

### アナロジー展開（構造的類似性で高度な転用）
勝ちクリエイティブの「構造」を別の表現に転換する。変数の深い理解が必要。
- 例：チャット形式で成果 → 「対話形式」「マンガ形式」「Web掲示板形式」へ転換

### メタファー展開（表現・演出の拡張）
訴求内容ではなく、訴求方法（デザイン・演出）で拡張する。

## クリエイティブシンキングを実務で鍛えるには

> 「日常が良いクリエイティブを作る」

日常で「なぜかこれに目が留まった」「これクリックしちゃった」を放置せず、  
「なぜこれに引き寄せられたのか」を自分なりに分析・深掘りし、クリエイティブに落とし込む。  
手品など「人の目線を引きつけるもの」を研究対象にするのも有効（小谷野式）。

**使えるフレームワーク（クリエイティブ思考）:**
ブレインストーミング / マンダラート / マインドマップ / ストーリーボード / リフレーミング / デプスインタビュー など

## 示唆

- 「アイキャッチ弱い」と感じたら、まずカクテルパーティー効果（ターゲット呼びかけ）から試す
- 横展開は「勝ち確認後」の量産。勝ち確認前にバリエーションを作っても無駄コストになる
- アナロジーは使いこなせると施策の枠が一気に広がる。「なぜそのCRが勝ったか」の構造分解が前提
