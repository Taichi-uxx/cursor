# 業界別バナーコピー勝ちパターン — LINE広告 × Yahoo!広告

**出典:** Yahoo Japan / LINE「【LINE広告&Yahoo!広告】バナー広告における効果的な文言・言い回し集」  
（広告主・広告代理店限定資料）/ 2023年  
**分析データ:** Yahoo: 2022年1月〜12月、LINE: 2023年1月（業種別50クリエイティブ）

---

## 用途（どんな時に活用できるか）

- LINE・Yahoo広告のバナーコピーを作るとき、業種別の「勝ちパターン」を参照したいとき
- クライアントの業種に合わせたキャッチコピーの方向性を提案するとき
- What（何を伝えるか）× How（どう伝えるか）の組み合わせに迷ったとき
- 新規クリエイティブのABテスト設計で、試すべき訴求軸を絞りたいとき

---

## 分析フレームワーク：What × How

バナーのキャッチコピーを**「何を（What）」×「どのように（How）」**で分類・分析。

| What（伝える内容） | How（伝え方） |
|---|---|
| ユーザー課題 / 商品名 / 効果効能 / メリット | ターゲット明示 / 命令 / 強調 / 暗示 |
| ブランド力 / 価格の提示 / 行動促進 | セリフ / 丁寧 / 逆説 / 感嘆 |
| 質・機能の優位性 / 口コミ人気 | 比較 / 問いかけ / 提案 / 造語 |
| 権威お墨付き / 希少性 / 割引 | 条件表現 / コンテンツ感 / 比較 |
| キャンペーン名 / 季節性 / 募集エントリー | | 

---

## 全体傾向（Executive Summary）

> **有形商材**は商品画像とセットで「！」などを伴う力強い言葉で訴求を高める傾向。  
> **無形商材**はターゲットをはっきりさせて「自分ごと化」させることで訴求力を維持。

| 商材タイプ | 勝ちパターンの傾向 |
|---|---|
| 有形（健康食品・ゲーム・コスメ・ファッション） | 商品名 or 効果効能 **× 強調** |
| 無形（金融・教育・人材・旅行） | ユーザー課題 or 募集エントリー **× ターゲット明示** |
| 不動産（中間） | コンテンツ感 × 価格 |

## 示唆

- **業種の「有形 or 無形」を最初に判断する**ことが、コピー設計の出発点
- 無形商材でターゲット明示を省くと「自分ごと化」されずにスルーされる確率が高い
- 「強調（！）」はほぼ全業種で有効だが、有形商材ほど効果が高い傾向
- LINEはYahooに比べて「セリフ・コンテンツ感・造語」など親しみやすい表現が多く登場。媒体ユーザーのトーンに合わせることが重要
