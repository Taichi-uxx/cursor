# 第1章｜直近のリスティング広告の市場トレンドから見る注力すべきポイント（P6〜P15）

### 本章のサマリ（P7）

リスティング広告市場は年間で約110%成長しており、結果としてCPCが上昇している。同じ効率を維持するにはCVRの上昇が必要であり、KPIツリーから見ると「LP」の要素が重要となる。特に顕在層である指名検索ユーザーと、準顕在層・潜在層が両方いる一般検索ユーザーそれぞれの検索語句のニーズに適したLPを制作することが重要。

### 市場トレンド：費用は年110%程度で堅調（P8）

背景には「各企業の出稿費用増」と「出稿企業自体の増加」の両方があると想定される（出典：電通 2024年広告費発表）。

### CPCの上昇が顕著（P9）

市場全体で出稿が強化されており、獲得効率の鈍化傾向に悩む企業も多い。

| 業界KW | 比較期間 | CPC変化 |
|---|---|---|
| 美容整形関連KW | 2022年2月〜2023年10月 | **2倍以上**に |
| 金融関連KW | 2021年〜2024年 | **1.5倍以上**に |
| PLAのCPC比較 | 2015年〜2024年（同一メニュー時系列） | **2.2倍程度**に |

※同一アカウントにおいて特定KW・メニューを切り出して比較

### 広告配信における変化（P10）

過去は「企業A・B」が中心だったターゲット群に対し、現在は「企業A〜D」と競合が増加。広告配信のクリック単価が上昇しており、過去と同じCVR感では効率が見合わなくなっている。効率維持のためにはCVRをより引き上げる必要がある。

### リスティング広告のKPIツリー（P11）

CVRをつかさどるのは「LP以降の導線」が変数となる。

| 運用レバー | 直接要因 |
|---|---|
| CPCを下げる | 入札戦略 |
| CTRを上げる | クリエイティブ（TD） |
| IMPを上げる | KW・入札戦略 |
| **CVRを上げる** | **クリエイティブ（LP）・フォーム** |

KPIツリー構造：CPA = COST ÷ CV、CV = CLICK × CVR、CLICK = IMP × CTR

### ニーズに合わせたLPの作り込み（P13）

リスティング広告内で異なるニーズに対し、インサイトに沿ってLPを制作することが重要。

| ユーザー区分 | 特徴 |
|---|---|
| 指名 | 商品名・サービス名を検索しており購買意欲が高いユーザー |
| 一般 | サービスに関連する悩みやカテゴリ名を検索し、具体的な商品検討段階前のユーザー |

一般KWの中身はさらに「顕在層（悩み・ニーズが顕在化、カテゴリ名検索など）」と「潜在層（まだニーズが顕在化していない）」に分かれる。

### 本ウェビナーのピックアップ（P15）

検索行動（認知→興味・関心→比較・検討→購入）に対し、LP〜CVまでの導線設計を **LPO・EFO・LINE公式** の3つの観点から紹介。指名・非指名検索ユーザーのモチベーションの違いからLP戦略の違いを整理：

- **指名検索ユーザー（顕在層）**：CVモチベが高いため、余計な情報を与えると逆にCVから遠ざかる傾向 → **減点方式検討スタイル**
- **一般検索ユーザー（準顕在層・潜在層）**：競合差分となる情報がCVへの後押しになりうる傾向 → **加点方式検討スタイル**

→ LP離脱対策（第2章）、フォームへの導線（第3章）、LINE公式（第4章）へ続く。

# 第2章｜ニーズ起点のアカウント設計とLP戦術（P16〜P42）

### 本章のサマリ（P17）

指名検索ユーザーと非指名（一般）検索ユーザー、それぞれの特徴を抑えたLP制作が必要。

| | 指名検索ユーザー | 一般検索ユーザー |
|---|---|---|
| 状態 | ブランド名を検索しモチベーションが既に高い | 検討〜情報収集段階と幅広いモチベーション |
| スタイル | 減点方式検討スタイル（余計な情報はCV阻害） | 加点方式検討スタイル（競合差分情報が後押し） |

### 指名リスティングにおける重要ポイント（P20）

「限定キャンペーン訴求」は非指名だからこそ優位な訴求であるという示唆、また一見有用そうなコンテンツ（メディア訴求等）を追加することで逆に効果が悪化する事例が見られた。

- 金融系事例：定常訴求LP vs 限定CP訴求LP
- 教育系事例：定常訴求LP vs メディア訴求LP（※有名メディア掲載実績をFV直下に追加）

### 検証から得られた示唆（P21）

メディア訴求LPへブラッシュアップした結果パフォーマンスが低下。「より訴求を追加しCVR向上を狙った施策が指名ユーザーには刺さらなかった」→ **指名検索ユーザーに共通する特性があるのではないか**、という仮説に至る。

### 検証事例①：テレビCM連動（P23・美容）

テレビCM実施時、コミュニケーションの整合性を合わせることでCVR向上。CM放映タイミングのみ、マス連動コミュニケーションLPがCVRの良い結果に。**テレビCMの成果最大化のためコミュニケーションを連動させるべき。**

### 検証事例②：デザイン変更（P24・金融）

定常LP vs 限定キャンペーンLP（「あんしん・かんたん」「月額〇〇円〜」「限定〇〇ポイントプレゼント」等、訴求・表現ともに全く異なる）。CM実施時の検証においてデザイン・訴求を大きく変えても有意差なし。**見た目を大きく変えてもユーザー特性を捉えていなければ施策効果はない。**

### 検証事例③：商品ページ vs タレント素材（P25・EC）

タレント素材よりも、シンプルな商品ページ導線（▼購入はコチラ▼）が優位な結果に。**とにかく最短CV導線を入れ込んでおくことはマスト。**

### 一般検索ユーザーのモチベーションを引き上げる手法（P29）

| ステップ | 手法 |
|---|---|
| 1. モチベーションの深堀からの戦略設計 | 外部データ活用（リサーチ・インタビュー等の定量・定性調査）／内部データ活用（リスティング・Displayの配信実績） |
| 2. モチベーションに合わせた戦術 | ①コミュニケーション仮説に対しメインメッセージを検証／②潜在的ニーズに対するクッションLP導入／③KW-TD-LPの一貫性を出すカスタマイザLP |

### メインメッセージ検証の成果（P34・インフラ・通信）

メインメッセージを複数検証しコミュニケーション仮説が立証され、既存LP対比でCVRを大きく改善、CPA改善に貢献。

| 検証パターン | 元LP対比CVR |
|---|---|
| 仮説A LP | **130%** |
| 仮説B LP | **110%** |
| 仮説C LP | **105%** |
| 仮説D LP | **115%** |

### カスタマイザLP（P36・生命保険例）

ニーズに沿ったコミュニケーションで申込までスムーズな導線を用意することが重要。「生命保険／女性／30代」など自分の条件を打ち込んで検索するユーザーには汎用LPでは不十分。広告文（例：「女性30代向け生命保険」）とニーズに沿った訴求文言をカスタマイザで設定し、女性を意識したFVのLPに反映する。

### クッションLPのメリット（P40）

記事LPやアンケートLPのような読みやすい・回答しやすいクッションLPを挟むことで購入意欲を高められる。広告色が薄く「つい読んでしまう」点が特徴。メディアの通常コンテンツの一部のように表示し違和感なく情報を与え、理解を深めることでモチベーションの高いユーザーを遷移させる。

### クッションLP検証事例（P41・美容）

一般KWで流入するユーザーは口コミ・評判などの“生の声”を探していると仮説（関連KW分析で「〇〇整形 おすすめ」「〇〇整形 バレる」等が見られた）。

- **Point.01**：ユーザーが抱く「施術に対する不安・心配事」にアンケート形式で答えていく構成
- **Point.02**：広告主側ではなく第三者が説明するようなライティングにする

### 広告文（TD）の訴求軸の分け方（P42・美容）

通常LPと記事LPで訴求軸を分けることを意識し、潜在層に刺さりやすいフレーズを中心にTD作成。

| | 通常LP TD例 | 記事LP TD例 |
|---|---|---|
| 訴求軸 | 公式・社名訴求／無料・料金訴求／地域・保証制度訴求 | 比較サイト風訴求／不安・悩み訴求／バレない・再施術訴求 |
| 例 | 「【公式】〇〇〇」「まずは無料でご相談」「●●から通える」「保証制度ありだから安心」 | 「美容整形おすすめのクリニック」「費用や痛みが不安な方へ」「周りにバレずに二重まぶたへ」「やり直しや再施術も可能」 |

記事を踏まえた**ライトな表現や、あえてネガティブワードを含める**等の工夫を行う。

# 第3章｜CVRに直結するフォームPDCA（P44〜P59）

### 本章のサマリ（P45）

EFOにおける障壁を超えるKAIZEN PLATFORMの導入、EFOの障壁を超える機能性とPJ体制、流入が多いSPを中心にした改善について、弊社改善事例とともに紹介。

### EFOにおける障壁＝よくあるお悩み（P46）

| | あるある |
|---|---|
| 01 | フォームは基幹システムと連動していて下手にいじれない |
| 02 | フォーム改修は自部署の権限だけで決められない領域 |
| 03 | リソースが不足している |
| 04 | そもそもどう改善すればいいかわからない |

→ EFOの重要性を理解していても様々な障壁が存在し、実行に踏み切れないケースが多い。

### KAIZEN PLATFORMのご紹介（P47）

システム変更一切不要でLPO/CVフォーム改善を実現。過去5万件以上の改善ナレッジでKPI達成に導くチーム。新規獲得におけるLP・フォーム導線（検索/リスティング/ディスプレイ/SNS → 商品LP → 申込みフォーム）の改善が重要で、課題解決する2つの仕組み（KAIZEN ENGINE × KAIZEN TEAM）を提供。

### 障壁を乗り越えるKAIZEN PLATFORMの強み（P48）

| 強み | 内容（対応するお悩み） |
|---|---|
| 01. | お面を被せるイメージでタグを一行設置するだけで完了するため **システム改修一切不要** |
| 02. | パラメータで管理して管掌領域経由の **一部トラフィックのみの実装が可能** |
| 03. | **豊富な改善実績と協業体制** による実行までのサポート |
| 04. | パッケージ売りで柔軟性の低い他社対比で **企業主様に合わせてカスタマイズ可能** |

### 強み③｜協業体制（P52）

豊富な改善実績と協業体制による実行までのサポート。CRO専門チーム／エンジニアチーム／案件ごとのフロントラインが連携。

| フォーム改善実績 | 改善率 |
|---|---|
| 金融系A社様 | 申込率 **174%改善** |
| 不動産系B社様 | 申込率 **131%改善** |

業種問わず多くのクライアントのCVRを大幅改善。

### 実際の事例｜課題（P54・店舗ビジネス／フィットネス）

申込フォーム到達後の離脱率が **80%以上** と大きかったためフォームを改修。

| 課題点 |
|---|
| 必須/任意項目がわかりづらい |
| スクロールが長い |
| 現在どこまで情報を埋めたのかわかりづらい |
| フリー回答欄があり埋めにくい |

→ ユーザーにとって情報量が多く見え、入力を手間に感じて離脱してしまう。

### 実際の事例｜改善（P55）

流入が多いSPを中心に入力しやすいよう改善。

| 改善ポイント | 内容 |
|---|---|
| SPに適したSTEP形式 | お客様情報 → 入力内容確認 → 完了（進捗バー 0%→33%→66%） |
| 入力負荷が高い項目の改善 | 「ご希望のコースは決まっていますか？」を選択式に |
| フリー入力欄を選択式へ | 「ダイエット／運動不足解消／ストレス発散／趣味／知人に勧められた／その他」 |
| コースが未定の方も選択しやすい仕様 | 30秒で記載可能、コースの詳細をご紹介 |

# 第4章｜LINE公式を活用した離脱ユーザーのナーチャリング施策（P60〜P72）

### 具体的な導線（P60〜P61）

離脱後にLINE公式のPOPUPを表示し、LINE公式を通してCVまでモチベーションを上げていく。

**フロー：** ①LP離脱 → LINEの友だち登録（LP到達数〔PV/セッション〕→ POPUP表示/クリック → 友だち登録数）→ ②LINE内コミュニケーション → CV（アンケート・シナリオ/Push配信・予約システム等々 → CV数）

**ポイント：** LINE公式へストレートに誘導するのではなく、ユーザーにとってハードルが低い「アンケート」や「診断」という言葉を用いて、自分自身を知るための手段として活用してもらうコミュニケーションが重要。
（例：「おすすめフィットネス診断 LINE公式でSTART」）

ウェルカムアンケート例：
- Q1「運動したいと思ったきっかけは？」（痩せたい・ダイエット／運動不足解消／ストレス発散・気分転換／趣味を増やしたい／友だちに誘われた／その他）
- Q2「運動は得意なほう？」（苦手／普通／得意）

### ウェルカムアンケートからのコミュニケーション出し分け（P67）

ユーザーの回答（設問の掛け合わせ）に応じてメッセージを出し分ける。

| 回答（きっかけ × 得意度） | コミュニケーション例 |
|---|---|
| 痩せたい・ダイエット × 苦手 | なりたい自分になるため、まずは運動に慣れることから！おすすめコースは… |
| 痩せたい・ダイエット × 普通 | なりたい自分になるため、運動を習慣づけよう！おすすめコースは… |
| 痩せたい・ダイエット × 得意 | なりたい自分になるため、運動の習慣を取り戻そう！おすすめコースは… |
| 趣味を増やしたい × 苦手 | 新しい趣味として軽い動作から身に着けやすいおすすめコースは… |
| 趣味を増やしたい × 普通 | 新しい趣味として人気のおすすめコースは… |
| 趣味を増やしたい × 得意 | 新しい趣味としてしっかり運動していきたいならおすすめコースは… |

### 予約システムとの連携含めてサポート（P68）

顧客データを元にしたLINE配信や、LINE内で取得したデータの貴社システムへの連携も可能。システム開発等が影響する「Technology Partner」の認定バッジを2つ保有。

**データの流れ：** インプット（サイト内行動データ／顧客データ／LINE関連データ／アンケート・診断データ）→ 統合・連携（DMP/CDPツール、データ統合ツール、APIツール）→ アウトプット（OAM配信/API配信、レポーティング、BI構築、SFTP/API）。データを適切に整えることで扱いやすくなり、スムーズに配信設計に活かせる。
