## 1. 基本事項

### 1.1 誰に（WHO）

#### 1.1.1「誰に」サービス・商品を届けるかをイメージできているか？
- **NG:** ペルソナを細かく作りすぎる。過剰に作り込むと、想定をしていないユーザーに対してのリーチに機会損失が起きるケースが多い
  - 例：英語教材を使うユーザーは主婦層という観点から主婦向けに作ったが、一番の売上のボリュームゾーンが30代以上のサラリーマンだった
- **OK:** 30代以上の女性、商圏が限られる場合は地域も設定。最終的に効果良好な地域は、広告でデータを「拾って」「寄せる」
- ポイント：ターゲットを明確化しないこと（明確にしすぎないこと）

#### 1.1.2 どのような流入元からユーザーが流入してくるか特定できているか？
- **NG:** 流入元・今後想定される流入元を把握せず、形だけのLPを作成する
- **OK例：** YouTubeの動画広告がメインの流入元となるため、ある程度動画でサービス概要は教育済み。そのため、浅いCV地点を用意したショートLPでユーザーのリスト確保を第1優先とする

#### 1.1.3 ユーザーの年齢層は特定できているか？
- **NG:** そもそもユーザーの年齢が不明、データが取れていない
- **OK例：** 購入数が最も多いのは30歳。次点で購入数が多く、LTVが高いのは35歳〜54歳。今後の戦略として、20代前半のティーン層の購入も増やしたいため、学生でも使えるローンや紹介割のようなオファーも準備

#### 1.1.4 ユーザーの住んでいる地域・活動している地域は想定できているか？
- **NG:** 顧客のデータがそもそも取れていない
- **OK例：** ユーザーのお住まいはXXXで、職場はYYYのため、小田急線を利用した通勤時の9:00前後が広告効果の良くなりそうな時間帯と推察できる

#### 1.1.5 ユーザーが自社のサービスにて解決したい悩みを3つ以上挙げられるか？
- **OK例（美容品）：** ニキビ・赤み / シミ・シワ / 10年後もたるんでない肌艶

#### 1.1.6 ユーザーが自社のサービスを使うことで享受するベネフィットを3つ以上挙げられるか？
- メリット = 商品やサービスの利点や長所（機能重視の価値）
- ベネフィット = そのメリットによって得られる恩恵（感情・恩恵重視の価値）
- **NG例（フェイスパック）：** 独自の特許技術によるブラシで、毛穴汚れ0が実現 / オールインワンで汚れの吸着から保湿まで / たっぷり50成分以上配合（→ 強みを羅列するのみで、使用したユーザーにどのような変化まで記載がないことが多い）
- **OK例（フェイスパック）：** 独自の特許技術によるブラシで、毛穴汚れ0が実現 **→ ファンデーションいらずで外に出歩けちゃう** / オールインワンで汚れの吸着から保湿まで **→ 忙しいあなたでも5秒で使えて、寝る前にパックするだけで翌朝の気分も爽快に** / たっぷり50成分以上配合 **→ だからこそ、20年後も変わらない羨望の美魔女パック**

### 1.2 ユーザー調査

#### 1.2.1 認識（事実）：貴社サービスの世間的な認識はどうか？
認識のフェーズを特定する：
- 誰も知らない
- なんか聞いたことがある（何%ぐらいのユーザーが？）
- A＝B,C,D,Eと関連想起される5つの中には入っている（例：高クオリティなフリーランスが集まってる会社といえば？= StockSunのような）
- A＝Bと第一想起される（例：高級な美容品といえば = 資生堂のような）

#### 1.2.2 妄想と仮説：貴社のサービスを購入・利用すると想定されるユーザーイメージができるか？

#### 1.2.3 事実：仮説上のユーザーイメージと乖離はないか？

#### 1.2.4 ベネフィット（インサイト）（顧客の声ベースに）：ユーザーがなぜ自社のサービスを「課金して」まで使用するのか？

#### 1.2.5 シーン（顧客の声ベースに）：どのような状況下で自社のサービスを利用するのか？

**イメージ例（ブレスウォッシュ）：**
- 一般常識：ご飯を食べた後、口臭予防しながら虫歯予防もできる
- 妄想と仮説：営業マンが昼食後、アポ前に使用
- 事実：どちらかというと、家事で大変な主婦層が、歯磨きの代わりに使っているケースの方が多かった
- ベネフィット（インサイト）：10秒で完結するため、忙しい家事の合間に利用できる
- シーン：袋タイプだからママ会ランチの外食にも使える
- 課金してまで使用する理由（お客様の声）：一般的な量販店にて販売しているサービスと比較すると、歯科医が開発しているため、安心。使用し始めてから、口臭が気にならなくなったし、何より虫歯になることがなくなった

### 1.3 何を届けるか（WHAT）

#### 1.3.1 メインベネフィット（訴求軸）は決まっているか？
- **NG：** プロダクトアウトの思想で決めると、大抵うまくいかない
- **OK：** 定量的なアンケートやお客様の声、競合を元にした訴求軸の決定。具体的にお客さんがどのようなポイントで喜んでいるかをメインの訴求軸におくことを推奨

#### 1.3.2 サブベネフィットを3つ以上挙げられるか？
- **NG：** プロダクトアウトの思想で決めると大抵うまくいかない
- **OK例：**
  - パッケージも可愛いから、置物としても使える → **インスタ映え訴求**
  - ホワイトニングだと思って買ったけど、歯石もごっそり落ちて大満足 → **歯石訴求**（※薬事観点は加味しない）
  - 彼氏がいつも以上にキスをしてくれるようになりました → **口臭訴求**（※薬事観点は加味しない）

#### 1.3.3 取り入れるにあたっての手軽さはあるか？
- 例：小分けタイプだからカバンにもスッッと入る / だからこそ、シーンを選ばずに食事後はすぐに使える / 口臭の元から絶ってくれるので、歯磨きいらず

#### 1.3.4 機能的価値は何か？
- 機能的価値 ＝ 商品やサービスそのものの機能や性能面
- 例：独自特許技術の銀チタンの効果で、1日中口臭に悩まない！

#### 1.3.5 情緒的価値は何か？
- 情緒的価値 ＝ お客様の感情に訴えかける価値
- 例：笑顔の時に、目一杯笑っても歯が輝く / 口臭を無かったことにしてくれるので、「いざ」という時にも安心 / 商談前にコレを使うだけで自信が持てる

## 示唆

- FVで最も多くのユーザーが離脱する。「2.5秒で何が伝わるか」がLP成否の9割を決める
- ビジネスモデル把握（限界CPA・LTV）なしにLP設計はできない。広告担当も必ず把握しておく
- ベネフィットはメリット（機能）を「→」でユーザーの変化・感情まで言語化して初めて機能する
- 悩みリストは@コスメ・Yahoo知恵袋・Amazonレビューから引っ張る。社内想定より精度が高い
- フォームはフィールド数を絞るほどCVRが上がる。「商談でヒアリングすればいい項目」はフォームから外す
- チャットボットの起動タイミングは流入元依存。一律即時起動は逆効果になることがある
