## ランキングLP

### 使いどころ
ランキングLPかなり使える（アフィリエイトが強いような商材は特に）。

対象KWで検索して、上位にアフィサイトやランキングサイトがあれば「第三者のレピュテーションが大事→ランキングサイトつくりましょう」みたいな論理で提案する。

- ステマ規制については「広告です」が明記されていれば問題ない（現状では）
- 例：Cloveや日本トレカセンター

### ランキングLPが強いクエリ

| クエリ種別 | 有効な理由 |
|---|---|
| **指名ネガティブワード** | ユーザーのネガティブな懸念を第3者の視点で消せるので |
| **比較検討ワード**（「おすすめ」「ランキング」など） | 第3者の視点で恣意的にランキングを1位にできるので |
| **Knowクエリ** | 教育され切っていない・モチベがやや浅いユーザーに教育できるので |
| **競合ワード** | 競合に流れそうなユーザーを奪取できるので |
| **1トークンのBIGワード**（「オリパ」とか「ポケカ」みたいな） | かけ合わせがない＝ニーズが定まってないということなので、ランキングLPを使うことで教育できる |

## フィルダクト提案資料（LPO）

### LPの問題点：流入元・ユーザーとの親和性が低い

流入元・ユーザーインサイトとLPとの親和性が低いと、ユーザーは自分ゴト化できず、離脱してしまう。

**よくある失敗例：**
- 例：流入元媒体がディスプレイでユーザーに与えられる情報が少ないにもかかわらず、LPも簡素的
- 例：バナーで価格訴求・ブランド訴求をしているにもかかわらず、LPのFV上にそのような記載無し
- 例：エリア掛け合わせのクエリで獲得ボリュームが多いにも関わらず、FVで場所について記載無し
- 例：ユーザーは価格がCVまでの最大のハードルであるにもかかわらず、FVで価格について記載無し

### LPの改善方針/改善例（FV〜セカンドビュー）

**獲得LPの基本：**
- FVでの離脱が最も多いため、一瞬で商材を理解させること・強い訴求をアピールすることが重要
- 流入元やユーザーとの親和性を意識し、モチベーションを落とさず読み進めてもらう工夫をする
- 例：価格やUSPをFV内に記載
- 例：商品の魅力が伝わるコンテンツを早めに出現させる

### LPの改善方針/改善例（CTA）

- クリックを促進する、CVに繋がりやすいUI
- 例：ボタンの色をよりアクションを促せるUIに変更・1種類に統一
- 例：CTAボタンが少なく間隔が広いとユーザーの離脱率が高まるため、コンテンツの要所ごとにCTAを配置、追従型CTAも追加し、モチベーションの上がったユーザーを取り逃さない設計に
- ※ただしこれは諸説ある。マウスピース矯正のようなユーザーに伝えるべきことが多い商材はこれでも良いが、シンプルな商材であれば上記は当てはまらない

### LPの改善案の例（コンテンツ/ストーリー）

- 離脱させない・「欲しい」を醸成する工夫を散りばめる
- 例：オファー訴求・権威訴求を上部に配置し、お得感を醸成させることですぐCVさせる

## LP内コンテンツ4つの型（法則）

商材・目的別にフレームワークを使い分ける。

### ①リピート商材：「AIDCASの法則」
⇒ **リピート後に得られるメリットの提示が肝**

| ステップ | 内容 |
|---|---|
| **Attention（注意）** | ユーザーはFVで商材の存在を知ります |
| **Interest（興味）** | 商材の魅力や特徴をアピールされ、ユーザーが興味を持ち始めます |
| **Desire（欲求）** | 購入後に得られるメリットを訴求され、商材を欲しいと思います |
| **Conviction（確信）** | 取りこぼした情報を補われ、買うしかないという思いに至ります |
| **Action（行動）** | 問い合わせ・資料請求・購買などの行動を起こします |
| **Satisfaction（満足）** | 購入者特典や購入後フォローなどがあり、満足度が上がりリピートにつながります |

### ②ブランドが確立している商材：「BEAFの法則」
⇒ **第三者観点で権威性を示し、1位であることを誇示する**

| ステップ | 内容 |
|---|---|
| **Benefit（購入メリット）** | 商材の魅力そのものが映り込んだ画像や好イメージを促す表現により、購入後に得られるメリットを印象付けられます |
| **Evidence（論拠）** | 受賞歴・ランキング順位・著名人からの高評価などの権威付け、数字的実績や口コミなどを見せられたユーザーが商材に信頼を寄せます |
| **Advantage（競合優位性）** | 似たような他社製品と比較検討しようとしたユーザーに対し、自社製品の優位点を訴求し、ユーザーは惹き付けられます |
| **Feature（さまざまな特徴）** | サイズ展開・色・成分・価格といったユーザーが知りたい具体的な商材情報が補われることで、ユーザーは買わない選択肢を失います |

### ③お悩み商材：「PASONAの法則」
⇒ **悩みの指摘で注意を引き、焦りを与えて「今」動かすことが肝**

| ステップ | 内容 |
|---|---|
| **Problem（問題提起）** | 悩んでいる内容と同様の事実や心理を指摘されてユーザーは動揺します |
| **Agitation（煽り）** | 悩みを放置しておくと後でもっと辛くなると煽情され、ユーザーは何とかしたいと焦ります |
| **Solution（解決策）** | 商材を購入すると悩みが解決できることをアピール。効能や特徴などの商材情報を与えられます |
| **Narrow Down（絞り込み）** | 期間限定の特典・料金などの提示により、今買う理由を与えられます |
| **Action（行動）** | 問い合わせや購買行動に出ます |

### ④専門的・特化型商材：「QUESTの法則」
⇒ **専門性が高い故、初期段階で絞り込み（余計なコスト削減）・共感を生むこと・さらに専門性が高いことを示す**

| ステップ | 内容 |
|---|---|
| **Qualify（絞り込む）** | その商材を必要とするユーザーのみが対象のサイトであることを知ります |
| **Understand（共感）** | 悩みや問題を共有され、ユーザーは興味を深めます |
| **Educate（啓発）** | 問題の原因・対策などに対する学習ほか、商材情報などを得ます |
| **Simulate（興奮）** | 商材を使えばこんな未来が待っていると想像させされ感情が高まります |
| **Transition（変化）** | 今だけのお得なセットや価格など特典を提示されることで、ユーザーは購入の背中を押されます |

## 画像形式をWebPに変更することによるLP表示速度・成果改善

- LP内の画像形式をjpeg/png/gif 併用からWebPに変更しただけで改善
- WebPとは：Googleが開発した画像ファイルの形式。より軽量に、透過画像もアニメーションも、フルカラーで実装可能
- 2020年にはInternet Explorer以外の主要ブラウザはWebPを表示できるようになった

**推奨案件：**
- LP内の画像をjpeg/png/gifで作成している案件
- LPが長く、読み込む画像の量が多いLP
- PageSpeed Insightのスコアが低い案件

## 媒体×LPの考え方

**公式：**
> **ユーザーを成約させるために必要な情報量 ー 配信媒体で伝えられる情報量 ＝ LPの情報量**

| 媒体 | 情報量 | LP設計 |
|---|---|---|
| **YouTube（スキップ可）** | 多い（クリエイティブで多く伝えられる） | 獲得特化のLP（短め） |
| **SNS（バナー）・ディスプレイ** | 少ない | 長めのLP |
| **TikTok** | 動画だが短尺なので中間程度 | 通常LP |

## ライティングを変えたことによる改善事例

参考動画：https://www.youtube.com/watch?v=zKsyhrF0SQY

LPやHPだけじゃなく、広告のテキストやSNS公式アカウントのサムネ等、マーケティングにおけるユーザーとの接触ポイントのすべてで使える。

### よくあるダメパターン①：スペックを並べすぎる

- 悪い例①：「6倍の高額ズームと5000万画素 手ぶれ補正で今までより高画質なカメラ」
- 良い例①：「動いてるお子さんもブレなく撮影 このカメラなら一瞬の思い出も逃さない」
- 悪い例②：「小さく畳めて運びやすい 汚れにも強いキャンプチェア」
- 良い例②：「使い終わったらリュックにポン A4サイズに畳めるキャンプチェア」

**ポイント：** ユーザーのメリットが想起しやすい表現に変えて訴求することが大事。スペック訴求は基本刺さらない・たいていの人はよくわからない。スペック訴求が刺さるとしたら、マニア向けの商材のみ。

### よくあるダメパターン②：ターゲットが広すぎる

- 悪い例：「投資を始めたいあなたへ 3日限定セミナー開催」（「投資を始めたい」と言っても広すぎる。もっとユーザー層をセグメンテーションする必要がある）
- 良い例：「給料だけで老後資金を溜める自信のない40代向け　3日限定初心者向け投資セミナー」

**ポイント：** カクテルパーティー効果を駆使。ターゲットを絞ることで相手に自分ゴト化させる。

### よくあるダメパターン③：なんか怪しい・読みたくならない

- 悪い例①：「この教材ならだれでも10万円稼げます」
- 良い例①：「自宅にいながら10万円を稼ぎたい方は他にはいませんか？」
- 悪い例②：「マイナス3キロ痩せたい方向け ダイエットサプリ」
- 良い例②：「間食しながらマイナス3キロを達成したたった一つの方法」

**ポイント：** 問いかけ型にすることで怪しさは払しょくできないものの、ユーザーの興味をそそる・読みたくなる。その後のコンテンツの質が高ければCVしてくれる可能性もある。断定型だと語気が強すぎてプッシュされてる感が出る。問いかけ型にすることで「ちょっと話聞いてから判断しようかな」っていう気持ちにさせる。**答えを出すのを後ろ倒しにすることでユーザーの興味を長い間引ける。**

## LPOの基本事例

参考動画：https://www.youtube.com/watch?v=aimhMRCBfKU

### LPOを行う上でのポイント

① **前提の重要性**
- 流入元はどこか？
- LPを閲覧しているユーザーの属性は？
- LPのトンマナは？ など
- これらの前提によって、取るべき施策が大きく異なるので注意！

② **改善点を定性的に見極める力**
- 知識や経験則がかなり影響してくるが、上記の前提にたったときに「自分がユーザーだったらどうだろう？」「UX的にどう感じるか？」などを踏まえて改善ポイントの目星をつけることが大事

③ **定量分析**
- GAやヒートマップを用いて、②で定性的に改善点として目星をつけた部分の確証・論拠を得るイメージ

### LPOを行う流れ

1. **1回目：** まっさらな状態で「LPが見やすいかどうか・使いやすいかどうか・わかりやすいかどうか」だけを注視して見る
2. **2・3回目：** 「きちんと訴求できてるか」を注視しながら深く読み込む。この段階で改善ポイントとなりそうなあたりをつける（同商材でLPの完成度が高いところをパクっていくというのも有効）
3. 例：「ここの視認率ってどうなんだろ？」「このCTAボタンのクリック率低そうだな」
4. 1・2で見つけたあたりに対して、GAやヒートマップを使って定量的なデータを集めることで上記のあたり・仮説を確かめに行く
5. 具体的に見るべき数値：**CVR・平均スクロール割合・平均滞在時間・離脱率・フォーム遷移率**
6. 定性・定量の両視点で「この施策はやったほうが良さそう」っていうものを優先度付けながらやる

### CTAボタンの色

- トンマナが緑ベースのLPにおいて、パターンAのトンマナを合わせた緑CTAボタンよりも、**CTAボタンを目立たせるオレンジCTAボタン**にした方が成果上がった

### ファーストビューのテキスト

- 流入元が検索広告のLPにおいて「新登場」と書かれたテキストよりも、「**サロン帰りのうる艶髪**」とユーザーメリット・商品使用後のイメージを想起させやすいテキストにした方が反応率が上がった
- 「サロン帰り」っていう表現はめっちゃうまい → ユーザーメリットや商品使用後のイメージをいかに短くかつ分かりやすく表現できるかがめっちゃ大事
- 流入元がリスティングだったため、このLPに流入してくるユーザーは「髪 パサつく」などのワードで流入していると思われる → この媒体から流入してくるユーザーはどんな状態心情でLPに流入してくるかを想像してLPの構成なり文言なりを変動させていくことがマジ大事

### LPの基本発想

- LPは縦長かつ**ユーザーは一度読んだら戻らない**と考えた方が良い
- 一度読んだら戻らないということは、**いかに視覚的に訴えかけるか・一目でわかりやすくするかがめっちゃ大事**

### 定量的な口コミ

- 口コミに定量的な数値を盛り込んだところ、CVR改善につながった
- よくある口コミ：「このドリンクを飲んで人生が変わりました。この商品に出会えて感謝です、ありがとうございます！」みたいな情熱的・定性的な言葉→これだけでは不十分
- 定量的な数値（「使用後2週間で○○」「★4.8 / 3,200件」等）を盛り込む

### フォームの住所アシスト

- 郵便番号入れるだけで住所が自動で入る（JavaScriptなどで簡単に設定できる）
- 商材単価・CV障壁が低いものについては、より効果的

## CVRを上げるためのLP設計（クイズ形式）

参考動画：https://www.youtube.com/watch?v=7-lvliwFfhw

### お題①：シャンプーのLPを作る場合、FVは商品が良いか人物が良いか？
**→ 基本的には人物が良い**

- LPで重要な事項として、その商品やサービスを使った後にユーザーがどんな状態になれるのか・どんなメリットを享受できるのかを視覚的に訴えかける・想起させることがめちゃくちゃ大事
- 特に女性の場合は「自分のなりたい姿・理想とする姿」を見せてあげる。その姿に近づきたいと強く行動を喚起される傾向（⇒つまり、人物のキャスティングに関しても外国人より日本人が良い）
- **FVに商品画像を使った方が効果が出る場合：**
  - めちゃくちゃ有名な商品・ブランドなど知名度が前提として高い場合
  - パッケージがめっちゃ映える・高級感がある
  - 有名インフルエンサーとのコラボ商品

### お題②：ヘッダー上部等にグローバルナビゲーションはあった方が良いか？
**→（いろんな前提によるが）無い方が良い**

- LPはストーリー性を持って作成されるべき。そのストーリー性を崩さないように、「LPは出来るだけシンプルにする」のが定石
- ナビゲーションをつけると上記のストーリー性を壊してしまう可能性がある。知りたい情報をすぐ見れるというユーザーメリットはあるものの、ストーリーによる需要の喚起ができないので料金だけ見てすぐ離脱してしまうみたいなことが往々にして起こり得る

**グローバルナビゲーションがあった方が良い場合：**
- LPで完結しない場合はナビゲーションがあった方が良い
- 「場所」「料金」「プラン」「症例」など、ユーザーが決めないといけない項目が多い場合
- 「○○ 料金」「○○ 東京」など、BIGワードからの流入ユーザーよりも確度が高く、知りたい情報が明確であると考えられる場合

**【個人的】導線が少ない方が良い場合：**
- 「買うか買わないか」「登録するか登録しないか」みたいなシンプルな選択肢しかユーザーにない場合（単品通販とか）
- BIGワードで流入するなど、ユーザーの中で「買うか買わないか、どのサービスを選ぶべきか」みたいな選択肢が不明瞭な場合・確度がそこまで高くない場合
- → 「興味ある・買うかどうか迷ってる」みたいな状態のユーザーに対してストーリーを見せることで態度変容を促す必要があるため、導線は少ない方が良さそう

### お題③：LP内にCTAボタンが2つある場合と3つある場合、どちらが良いか？
**→（CPAを安くするという観点では）一概に言えない**

| パターン | CTR | CVR |
|---|---|---|
| CTAボタン3つ | 高くなる | 低くなりやすい（ストーリーを途中までしか見ずに遷移してしまうため） |
| CTAボタン2つ | 下がる | 高くなりやすい（きちんとストーリーを見せられるので読了率が高い） |

上記2つの長短を理解して、どちらの方が効果が良いかトライアルする必要がある。

### お題④（番外編）：LPに遷移させるためのバナーデザインはインフルエンサーor商品画像？
- 前提：非リタゲ
- **→ 商品画像**
- インフルエンサーがめっちゃ権威性が高いとかならCTR高くなる可能性あるが、そうじゃないかつ非リタゲでそのインフルエンサーや商材を知らない人にも広告があたるため、このバナーだと「誰？」「何の商材の広告かわからん」ってなってしまう

## 示唆

- 「LP情報量 = 必要情報 − 媒体で伝えた情報」の公式は提案に使える。媒体とLPをセットで設計する視点が重要
- FVとバナー訴求の不一致は最も多いLP失敗パターン。FV改修前にバナーとの整合性を必ず確認する
- ターゲットずらしはリスクが少なく試しやすい拡張施策。既存LPに新セグメント配信だけで実験できる
- ランキングLP提案は「競合KW・比較KWで検索した際に上位にアフィサイトがある」場合の有力な一手
- CTAボタンの色はトンマナ度外視で目立たせることを優先（検証済み）
- 口コミは「定量的な数値」を入れることでCVRが改善する。感情的な声だけでは不十分
- ライティングの改善はスペック訴求→ユーザーメリット訴求への変換。「6倍ズーム→動くお子さんもブレなく撮影」
