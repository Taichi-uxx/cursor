## どんな時に活用できるか
- デマンド広告を新規導入する際の必要データ要件（リマケ2000件 / CV類似200件 / カスタマーマッチ類似2000件）を即引きしたいとき
- カスタマーマッチの裏技（MCC内オーディエンス共有で新規アカウントも利用可）を確認するとき
- デマンドの日予算拡大ステップ（5000→1万→2万→…→30万円）と倍率ルール（12時=3倍、14時=2.5倍、16時=2倍、18時=1.5倍）を確認するとき
- 好調時の数値感（CPM 1500〜2500 / CTR 3.5〜6% / CPC 40円 / MCVR 5〜7% / MCPA 600円）と照らし合わせて運用評価するとき
- デマンドが効果出ない時の判断フロー（キャンペーン立て直し→アカウント変更）を確認するとき
- 静止画キャンペーンと動画キャンペーンの戦略の違い（資産的vs予算踏み時）を整理するとき

## サマリ
**デマンドは「狭くて確度が高いターゲティングで開始→拡張ターゲに移行」がセオリー。**最重要は「キャンペーン/アカウント単位で実績CPAが安い状況をつくる」こと。日予算は段階的に拡大、悪化時は30〜50%下げて翌日様子見。

## 1. Googleデマンド広告とは

### 基本
- **ディスプレイ広告の亜種**
- 掲載面はすべて**Googleの自社媒体**
- 主にYouTube、ディスカバー、Gmailなどに掲載
- 画像も動画も可能（メインの掲載面が異なる）

### 強み
- **かなり幅広い商材で獲得できる**：通販健食コスメに関わらず、toC・toBのあらゆる商材で目標CPAをクリア
- **クリエイティブが枯れない**：一度効果が合うとほぼいじる必要がない。**BB実績で2年間同じTD・画像・記事LPで月次ROAS 200%**のものも
- **横展開で利用しやすい**：Meta等で効いているクリエイティブ・LP・記事LPがそのまま利用可能
- **Google広告で唯一類似オーディエンスが利用できる**：個人情報保護で一時廃止された類似オーディエンスがデマンド限定で復活（自社媒体のため独自ロジックで類似ユーザー算出という言い分）
  - ターゲットが絞られる商材でも効果を合わせることが可能

### 実践者の声
- リスティング：Day10件前後（ROAS 130%）／**Demand：Day30件前後（ROAS 200%）**
- Meta CPA 2,807円 → Google CPA：4月4,301円→5月2,459円→**6月現在1,512円**でMeta以上のパフォーマンス
- デマンド動画キャンペーンで**LTVの1/4くらいで新規獲得**

### 弱み
- **運用開始時にデータが必要**：いきなりブロードで合わせるのはハードル高い
- **審査が厳しい**：Google全広告メニューで最も厳しい。TD・画像ともにデマンド専用基準で通るラインを見極める必要、理不尽なLP審査落ちも多々
- **運用難易度高め**：拡張ロジックが強いため、コントロールしないと急に数値が崩れる

## 2. デマンド広告開始に必要なデータ

### 原則
- **狭くて確度が高いターゲティングで開始 → 拡張ターゲに移行がセオリー**
- 以下3パターンのどれかを満たしてから開始

### 1. リターゲティング
- **すべての訪問者が最低2000件**
- 足りない場合：リスティングや他媒体の出稿でマーク数を増やしてから開始

### 2. コンバージョン類似
- **CVに至った全ユーザー最低200件**
- これを元に類似オーディエンス2.5%を作成

### 3. カスタマーマッチ類似
- 購入者のメールアドレスや電話番号をアップロード
- 一致度（Google側がユーザー特定できる率）が低いため**最低2000件程度必要**
- これを元に類似オーディエンス2.5%を作成
- ⚠️ ただしカスタマーマッチをターゲに利用するには**アカウントの利用実績が必要**：**累計5万ドル相当**の利用が必要

### カスタマーマッチ深掘り
- オーディエンスマネージャー → 顧客リストよりアップロード
- 広告代理店向け：**SHA256でハッシュ化した顧客データをクライアントから貰えば個人情報漏洩の心配なし**

### 🎯 （マニアック）カスタマーマッチの裏技
- **1アカウントでも利用条件を満たしていれば、新規広告アカウントでも利用可能**
- 利用条件を満たしたアカウントでカスタマーマッチ＋類似オーディエンスを作成 → **MCCにオーディエンス共有** → 同じMCC配下の別広告アカウントでも利用可能
- 手順: https://support.google.com/google-ads/answer/6123188?hl=ja

## 3. デマンドの入稿設定

### 静止画と動画はキャンペーンを分ける
- 配信面が異なるため、必ず分けて入稿

### 設定フロー
1. 新しいキャンペーン作成 → **販売促進 or 見込み顧客の獲得**
2. キャンペーンタイプ：**デマンドジェネレーション**
3. キャンペーンの目標：**コンバージョン**

### 入札と予算
- **目標コンバージョン単価を必ず入力**
- **目標CPAの半分程度からスタート**し、露出する最低限の入札を探す
- **日予算は5000円**スタート → MCPAやCPAを見つつ予算アップ

### 地域・言語
- エリアを入力
- ⚠️ **店舗系などエリアが限られる場合のジオターゲは精度低め**

### オーディエンス
- リターゲティング / コンバージョン類似2.5% / カスタマーマッチ類似2.5% のいずれかを利用
- **カスタマーマッチは除外にも利用でき便利**

### 最適化されたターゲティング
- **基本オン（超優秀）**
- 質などの観点で年齢性別を区切りたい場合はオプションに✅
- 平均20%のコンバージョン増加実績

## 4. デマンドのクリエイティブ

### 原則
- ターゲ・配信面・最適化の状況で数値が大きく変わる
- **いきなりデマンドで新規案件の効果を合わせるハードルは高め**
- **Meta等で効いているクリエイティブを横展開する方法が鉄板**

### デマンド静止画キャンペーン
- **TD（見出し・説明文）の重要性が高い**
- 静止画は審査落ちで変更しても効果が変わらないことが多々

### デマンド動画キャンペーン
- **ターゲティングが絞られたYouTube広告という認識でOK**

### 静止画クリエイティブのコツ

#### TD
- 権威性、ターゲットの明確化、遷移先との調和

#### 静止画
- **媒体に溶け込みつつ、違和感を残す**
- 人物の顔
- 商品画像、テクスチャー、使用感
- ニュース記事擬態
- ※静止画内にあまりテキストは入れなくてOK（**特大テキスト静止画はアリ**）

### 静止画クリエイティブの例
- 楽天1位「毛穴の掃除機」
- 「韓国女性の間で話題。毛穴汚れ吸着ゼリーがすごい」
- 1080×1080サイズで人物顔×商品画像×使用感の4パターン

### クリエイティブPDCA
- 効果が良い（CVがついた）TD・静止画にインプレッションが偏る
- **目標CPAをクリアしていたら極力触らない**
- 効果が出ていない場合、**まずインプレッションが少ないものを入れ替え**

## 5. デマンドの審査面

### 原則
- TD・画像・LPすべてにおいてGoogle広告で最も審査基準が厳しい
- 動画の審査基準はYT広告と同様 → **先に露出テスト**
- それぞれの項目に分けて審査通過しているかチェック

### TD、画像、動画の場合
- **否認理由：クリックベイト、インタラクティブ要素の暗示など**
- 広告 → アセットの詳細を表示 → 落ちている項目のみ修正
- **全て「有効」なのに審査落ち = LPが審査落ちと判断**

### LPの場合
- **否認理由：信頼できない文言、不明なビジネス、ビジネス名の要件など**
- 明確な要因（LP内の文言や画像）が特定できないことがほとんど
- **コンテンツ内容を追記/削除して変化させ、Google機械審査を通過するまで繰り返す**のが早い
- **直近だと不明なビジネス、ビジネス名の要件は再審査請求で通りやすい**

## 6. デマンド広告運用の流れ

### 🔴 最重要
**キャンペーン単位、アカウント単位で実績CPAが安い状況をつくる**
- Googleは元々キャンペーン単位の最適化が強いが、**直近アカウント単位もかなり比重が重くなっている印象**

### 1. オーディエンス準備
- 類似オーディエンス生成まで1〜2日
- カスタマーマッチもアップロード後1〜2日 → **カスタマーマッチ類似の場合は4日程度**
- オーディエンスマネージャーで正しくボリュームが表示されていればOK

### 2. 入稿＆審査PDCA
- 1回ですんなり通らないことも多い → 要素分解しつつ通るまで繰り返し
- TD・画像で審査が通る基準も見極めていく
- TD・画像は審査に一貫性があるので分かりやすい（通らないものはもう通らないので少し変えて再審査）

### 3-1. 運用初動
- **日予算は案件にかかわらず基本5000円スタート**
- 露出開始まで数時間〜長いと1日かかる
- **開始3日ほどはかなり慎重に運用**：設定オーディエンスと反応を元に拡張先を選定している動き
- **KPI = MCPA**：MCVが目標MCPA内で発生していれば上々
- CVが発生した場合は予算1万円程度までは上げてOK
- 露出量が少ない場合は1〜2時間おきにtCPAを10%ほどアップ

### 3-2. 運用初動 開始1〜3日の動き

| 状況 | アクション |
|---|---|
| MCVが目標MCPA内で発生するがCVしない | 日予算据え置きで様子見 |
| MCVが目標MCPA内で発生しCVもつく | **日予算を最大3万円程度まで段階的に上げてOK**。4日目をめどに予算拡大フェーズへ移行 |
| MCVが目標MCPA内で発生しない | キャンペーン立て直し or クリエイティブ見直し |

### 3-3. 運用初動 数日経過後
- キャンペーン立て直し、クリエイティブPDCAを行ってもMCV・CV共に目標値内で発生しない
- → **アカウントを変える**
- アカウント単位で誤ったユーザー拡張になっている可能性
- キャンペーン立て直しても初動から悪い拡張に当たってしまうので、あきらめてアカウントを変える

### 4-1. 予算拡大
露出量が過度に減らない範囲で、tCPAをGoogleに反映している過去7日実績CPAの近似値まで段階的に下げつつ日予算アップ

#### 日予算アップのイメージ
**5000 → 1万 → 2万 → 3万 → 5万 → 7.5万 → 10万 → 15万 → 20万 → 25万 → 30万…**

#### 残時間を考慮した倍率設定
| 時刻 | 倍率上限 |
|---|---|
| 12時 | 消化予算の**3倍**まで |
| 14時 | 消化予算の**2.5倍**まで |
| 16時 | 消化予算の**2倍**まで |
| 18時 | 消化予算の**1.5倍**まで |
| 18時以降 | 直近1時間消化額×残時間で消化できる額 |

### 4-2. 好調時の数値感（通販商品、記事LPの例）
| 指標 | 値 |
|---|---|
| CPM | 1,500〜2,500 |
| CTR | 3.5〜6% |
| CPC | 40円前後 |
| MCVR | 5〜7% |
| MCPA | 600円 |

### 4-3. 好調なキャンペーンが1つ存在する場合
- CVユーザーの属性を見ると**Androidに偏っていることが多々**
- → **iOSのみに絞ったキャンペーンを作成して並走**
- オーディエンスやクリエイティブは同じでOK
- iOSキャンペーンのCVが増えると元のキャンペーンにもiOSのCVが増えてバランスが取れてくる

### 4-4. 予算拡大による効果悪化
- 日予算アップ後にMCPA・CPAが悪化 → **過度なユーザー拡張が起きている可能性**
- **日予算を30〜50%下げて翌日また様子見**
- 効果が回復したら再び予算を上げてOK
- **🔴 とにかくキャンペーン・アカウント単位で実績CPAを悪化させないことが大切**

### 最終系
- 日ブレによる実績悪化 → 露出減を緩和するためtCPAを微調整 → **2〜3日をめどにtCPAを再び下げたい**
- **静止画キャンペーンは日予算15〜30万円程度、目標CPAの半分程度でCVしている状態が1番安定**
- 過度に予算を踏みすぎず**資産的な広告として置いておくのがオススメ**
- **動画キャンペーンは動画URLが非承認になるリスクが比較的高いので予算を踏める時に踏んだ方が良い**

### クリエイティブ改善の判断
- **2〜3日でもCPAが好調だった** → ガチャやアカウント立て直しで効果の良いキャンペーンを生み出せる可能性。MCPA・CPAを重視しつつ実績CPAが安いキャンペーンを目指す
- **総じてCPAが悪い** → TD・画像・動画・LPに問題がある可能性。まずはこれらを入れ替えて数値感に変化が出るか確認

## 太一の示唆
- 「狭く高確度で開始→拡張」の原則は、Meta含む自動入札全般の鉄則。デマンドではこれが特に効く
- **MCC内オーディエンス共有の裏技**は、新規案件立ち上げ時に活用できる強力な技。MCC内の1アカウントで$50k達成していれば他全アカで使える
- 日予算拡大ステップ（5000→1万→…→30万）と時間別倍率（12時3倍→18時1.5倍）は**そのまま運用SOPに反映できる即引きルール**
- **CVがAndroidに偏ったら iOSのみキャンペーンを並走**するTipsは見落としがち、必ず属性確認すべき
- 「悪化したら30〜50%下げて翌日様子見」は感情で予算を止めずに済むルール
- 「静止画 = 資産的に置く、動画 = 予算踏める時に踏む」のキャラ分けは戦略レイヤーで効く
- 数値感ベンチマーク（CPM 1500-2500 / CTR 3.5-6% / MCPA 600）は提案や運用評価の基準値として常備
- カスタマーマッチ前提のSHA256ハッシュ化は、クライアントへの「個人情報懸念ゼロ」説明の鉄板
