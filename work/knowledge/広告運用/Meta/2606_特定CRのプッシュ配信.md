## プッシュ配信機能とは

### 概要（元投稿より）

> Meta広告のプッシュ配信が思った以上にいい働きをしてくれます。特定の広告を強制的に配信させることができるので、例えば「以前は当たりクリエイティブだったのに、最近配信が減ってセット全体の成果が落ちてきたな」という時にこの機能を使って強制的に配信すると回復するケース増えてきました。 — ふわり氏

### 設定画面の項目（添付スクショより）

| 項目 | 内容 |
|---|---|
| トグル | 「この広告をプッシュ配信」ON/OFF |
| 説明文 | 予算の一部を広告に割り当てることで、確実に配信できるようになります |
| **1日の消化予算の何パーセントをテスト広告に使用しますか?** | %で指定（スクショでは65%） |
| 補足 | 1日あたり平均〇〇円を消化することを目指しますが、全体で1日の予算または設定した上限を超えることはありません |
| **期間の長さ** | 日数で指定（スクショでは7日） |
| 終了後 | 既存の予算が広告に使用されます |

### 挙動の要点

- **広告セット単位で**、特定広告に対して1日予算の指定%を優先的に割り当てる
- 期間終了後は自動で通常配信に戻る
- **予算総額は超えない**（ADセット内での再配分）

## 太一の示唆

### なぜ「過去の当たりCRを強める」が効くのか（仮説）

Meta広告のアルゴリズムは、新規CRや直近のシグナルに引っ張られやすい。過去に安定してCVを取っていたCRが、下記のパターンで配信減 → セット全体の成果低下を引き起こすケースがある：

- 新規CRが投入され、学習期のシグナル拾いに配信が集中
- 直近の外部要因（季節・トレンド）で他CRのCTRが一時的に上がり、当たりCRの配信優先度が下がる
- フリークエンシー上限に達したと判定されて配信抑制

**プッシュ配信 or 手動で予算比率を上げる**ことで、これらの偏りを打ち消し、実績ある当たりCRのシグナルを再供給できる。

### プッシュ配信機能が使えない場合の代替策

シェバ氏の指摘通り、機能ロールアウト待ちのアカウントでも下記で近い効果が出せる：

1. **当たりCRを別ADセットに分離**し、専用予算を割り当てる（＝手動プッシュ）
2. 当該CRの入稿を **一度停止→再開** することで、配信優先度をリセット
3. 予算上限のあるキャンペーンでは、当たりCRを含むADセットの予算比率を段階的に増やす

### 使いどころの判断基準

- **セット全体のCPAが1.5倍以上に悪化**していて、原因が「配信偏り」の可能性がある時
- 過去30〜90日で **明確に成果を出していたCRの配信インプレッション比率が急落**しているとき
- 新規CRの投入直後に既存CRの配信が細っているとき

### 使うべきでないケース

- CRそのものが疲弊している（フリークエンシー・CTR/CVR共に長期低下トレンド）→ 新規CR投入が先
- 学習期直後で配信が安定していない時期 → まず学習完了を待つ
- 予算そのものが不足している（Budget Limited）ケース → 予算増額が先

## 検証したい仮説

- プッシュ配信の**最適な予算比率と期間の組み合わせ**（65%×7日は経験則の一例。50%×14日 vs 80%×3日 など）
- プッシュ配信で回復したCRは、**プッシュ終了後も配信優先度が戻らず高いまま維持されるか**（学習の書き換えが起きるか）
- 「当たりCRの延命」と「新規CR投入頻度」の**最適バランス**（プッシュ配信の存在で、新規CR制作サイクルを緩めても成果を維持できるか＝制作コスト削減の可能性）
