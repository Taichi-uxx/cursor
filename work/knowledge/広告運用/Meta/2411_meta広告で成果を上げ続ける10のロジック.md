## 第一章：Meta広告が優れている特徴

### Meta広告と他のSNS広告との違い

国内月間アクティブユーザー数（2024年時点）：

| SNS | MAU | ユーザー層 | 特徴 |
|---|---|---|---|
| LINE | 9,600万 | 全世代幅広く | インフラ化したメッセージツール／プッシュ通知／LINE API連携 |
| YouTube | 7,000万 | 年齢性別問わず | 動画中心、長尺も伸びやすい／コロナ禍で40代以上も利用増／SEOに強い |
| X（Twitter）| 4,500万 | 20代多／平均36歳 | リアルタイム性／興味感心で繋がる／短文 |
| **Instagram** | **3,300万** | 10〜20代で半数以上 | 雑誌感覚／ビジュアル訴求／フィードとストーリーズの使い分け／ハッシュタグ流入多 |
| **Facebook** | **2,600万** | 20〜30代多 | **実名性が高くリアルなつながりを反映**／ビジネスシーン活用／コンテンツ自由度高 |
| TikTok | 950万 | 10〜20代で半数以上 | 短尺動画中心／豊富な動画編集機能 |

Meta（FB＋IG）の独自価値：
- **FB＋IGで合計約6,000万人の異なるユーザー層に一度にアプローチ可能**
- **Facebookの登録情報をもとにターゲティング**できるため、**他SNSと比較して圧倒的に高いターゲティング精度**
- マーケティングファネル全体（潜在層〜顕在層）をカバー

### Metaが誇る圧倒的なターゲティング精度

設定できるターゲティングは3種類：

#### ① コアオーディエンス
基本情報やユーザーの興味関心、アプリ利用状況などから設定。新たな顧客層獲得や広範囲認知に適する。**「and設定」「or設定」「除外設定」**でターゲット細分化可能。

| 項目 | 設定内容 |
|---|---|
| 性別 | 男性・女性・両方含むから選択 |
| 年齢 | 13歳〜64歳まで1歳刻みで選択（65歳以上は「65＋」）|
| 地域 | FB登録の自宅住所もしくは最近の位置情報を元に設定 |
| 興味関心 | ユーザーがクリックやいいねしたデータを元に**8つのカテゴリで300種類以上**から選択 |
| 行動 | 購入行動や目的、電子機器の利用状況などから選択 |

例：「東京都内の25歳以上の男性会社員」「大阪府在住でお子さんがいる女性」

#### ② カスタムオーディエンス

| ソース | 内容 |
|---|---|
| Webサイト訪問者向け | 訪問日から**最大日数180日**で指定 |
| エンゲージメント | FB/IG上でいいねなどのアクションをしたユーザー |
| 顧客リスト | 自社所有のメアド・電話番号などをもとにターゲティング |

#### ③ 類似オーディエンス
- カスタムオーディエンスのデータを元に類似する特性のユーザーをターゲティング
- **既に接点のあるリストと類似したオーディエンスに配信**できるため、同じ特性をもつ潜在顧客にリーチしやすい
- 設定％：**1〜10%**（％が大きいほど配信されるユーザー数増、特性は散る）
- **予算が少ない場合は1%から始めるのがおすすめ**

### 業界・商材別おすすめターゲティング

| 商材 | おすすめターゲティング例 |
|---|---|
| ① 美容商材 | スキンケア化粧品のブランド名やデパート、エイジング関連。例：SK-Ⅱ、資生堂、アベンヌ、クラランス、高島屋、伊勢丹、西武百貨店、東武百貨店、メラニン、老化、Anti-Aging |
| ② 情報商材 | **個人事業主のターゲティング**が活用しやすい。例：役職：個人事業主、収入、富、お金、投資、不動産投資、投資家 |
| ③ 健康食品 | 健康系KWはもちろん、**オーガニック系KWや主婦層の興味関心**も。例：健康、健康づくり、体重、カロリー、有機農業、オーガニック、玄米、専業主婦 |
| ④ 占い | 単に占いだけでなく**結婚や恋愛関連**のターゲットが良傾向。例：占い、タロット占い、星占い、手相、結婚、結婚指輪、ウェディング、花嫁、スピリチュアル、瞑想、マインドフルネス |

→ 詳細ターゲティングでは**人気芸能人の名前や出会い系アプリ名**も設定可能。**商材問わず年代が若い層を狙いたい場合**におすすめ。

### 太一向け示唆
- **「とりあえずリスト類似」という時代ではない**（CPCも上がってCPA悪化する）→ **詳細ターゲティング**を商材ごとに研究
- 既存案件で「ターゲティングをずっといじっていない」場合、上記の業界別KW例を試す価値あり
- 類似オーディエンスは**まず1%から段階拡大**（5%・10%）が王道

## 第二章：Meta広告のパフォーマンスを引き出すアカウント設計

### Meta広告の3層構造

```
キャンペーン（広告の目的）
　├ 広告セット（オーディエンス／配置／予算／掲載期間）
　│  ├ 広告（フォーマット／クリエイティブ）
　│  ├ 広告
　│  └ 広告
　├ 広告セット
　└ 広告セット
```

### キャンペーンレベルのポイント

**1番大切なのはビジネスの目的にあったキャンペーン目的を選択できているか**。ここがズレると成果が出ない。

キャンペーン目的（以前11種類→現在**6種類に集約**）：

| 目的 | 内容 |
|---|---|
| 認知度 | 商品・サービスの認知度を高めたい場合 |
| トラフィック | 広告を見たユーザーをWebサイトやアプリのDL先に遷移させたい |
| エンゲージメント | FB/IG上でメッセージや動画再生数、投稿のエンゲージメント、イベントの参加者を増やしたい |
| リード | 商品・サービスに対して興味を起こしてもらい、メルマガ登録などの行動を促したい |
| アプリの宣伝 | アプリをインストールする人を増やしたい |
| **売上** | 商品やサービスを購入する可能性が高いユーザーに向けて配信したい |

→ ほとんどの案件は購入などのCV目的のため**売上目的が多い**。

### 広告セットレベル：3つのポイント

AIによる最適化の**学習が行われるのが広告セットのレベル**。

#### ① オーディエンス

**狭すぎても広すぎても良くない**。目安は**200万〜広くて1,000万**を捉えたターゲティング設定。

- 最低でも**50万**いないと目的を達成するためのユーザーを見つけることが難しくなる
- 逆に**1,000万を超えると広すぎて、予算の中で最適化のためのAIが働きづらい状態**になるため注意

#### ② 配置

**基本的には自動配置で設定、それが難しい場合でも6面以上の配置をしていく**。

- Meta広告では自動配置に設定することで**CPAが7割減少**するというデータも
- 6面以上とそれ以下で比較した際に**99%が6面以上に配置したほうが成果が良かった**という結果

#### ③ 予算／期間

AIの学習は情報収集期間を経て安定してCV獲得できるように最適化されるが、その**情報収集期間を早く終わらせるために週に50CVを獲得できるように予算を設定する**ことが推奨。

そのため、CPの中で広告セットを分けすぎていると、どの広告セットもパフォーマンスを最大化できない状態に。

**例**：CP配下に「女性20-30才」「女性30-40才」「女性40-50才」と3セット分割すると各セットあたり週20件CV → **「女性20-50才」と統合すれば1セットで週60件CV**達成

### 広告レベルのポイント（3点）

#### ① 動画と静止画が1広告セットに必ず含まれるようにする
- Instagramのストーリーズやリールの台頭で動画でアクションするユーザー増
- **動画使用すると、静止画だけでは配信できない「動画専用の面」に配信**されるため、ターゲット範囲が広くなる

#### ② 6〜10クリエイティブ/広告セットを意識
- 理想は**6〜10CRを広告セットに入れること**で、数値的な偏りも起きづらく、勝てるCRを見つけやすくなる
- 逆に**これ以上入れるとAIによる学習が追いつかない**

#### ③ 週1以上の差し替えは機械学習に支障
- できるだけ我慢、多くても**週1回程度を意識**
- 差し替えを多くすると機械学習がリセットされる
- 調整済みのCPAから再度調整が必要になるため差し替えはなるべく控える

### 太一向け示唆
- **広告セット分割しすぎている案件は統合候補**（週50CV確保が最優先）
- 既存案件で「広告セットあたり3〜5本」しか入っていない場合、**6〜10本**まで増やす
- 「成果悪い→CR差替え」を毎日のように繰り返している案件は**学習リセットしまくり**→週1ペースまで落とす
- 自動配置外しを「とりあえず」やっている案件は**99%データで自動配置勝ち**を根拠に戻す提案

## 第三章：Meta広告で成果を出すための10のロジック

成果に影響する要素の優先順位：
1. **クリエイティブ・広告文**（最重要）
2. **配信設定**
3. **LP**

### ロジック① コピー：「共感」「自分ごと化」を意識

#### SNSユーザーの心理状況
- ユーザーは商品やサービスを購入・検討するためにSNSを見ていない**見込みの低いユーザー**
- 見込みの低いユーザーにアクションしてもらうには**「共感」「自分ごと化」が重要**

#### コピーの作り方：ポジティブとネガティブの両側面で考える
例：ダイエットサプリ・「30歳女性OL、食べることが大好き」ペルソナの場合

| パターン | コピー例 |
|---|---|
| **ポジティブ用** | 大好きな食事をもう我慢しない♪たった2粒でスッキリ満足できる自分に |
| **ネガティブ用** | 「また食べちゃった...」食べることの後悔から卒業しませんか？ |

### ロジック② デザイン：ターゲットが見ている世界に寄せる

- ターゲットが**普段興味があることや趣味、見ているサイトや雑誌、SNSアカウント**などから写真やイラスト、色を決めていく
- CRパターンとして用意するもの：
  - 商品画像を使用したもの
  - 人物などの写真素材を使用したもの
  - イラスト素材を使用したもの
  - 文字メインで作成したもの
- ユーザーは高速でTLを閲覧するため、**「ユーザーの興味を惹けるポイントはあるか」**がCR作成の重要ポイント

### ロジック③ 画像選定：「3Bの法則」

- 動物を使用したCRで成果が良かった事例：「売らないM&A戦略」のCRに**ライオン・ゴリラ・トラ・馬・黒猫**を使用
- **3Bの法則**：心理学用語
  - **Beauty（美人）**
  - **Baby（赤ちゃん）**
  - **Beast（動物）**
  - これらをCRに取り入れると**ユーザーの目に留まりやすく、好感を持ってもらいやすい**
- 期待効果：サービスの印象付け／キャッチコピーの後押し／ユーザーの嗜好性補完
- ユーザーがサービスに期待する嗜好性を言語化（例：M&A=「頼りになる、強気、権威性、交渉上手、戦略的、挑戦、損したくない、リーダーシップ、積極性」）→ これらを補完する視点で画像選定

### ロジック④ 動画：3つのポイント

#### 1）基本的に動画は短尺
- **30秒以内**で作成。30秒以上だとユーザーが飽きて離脱され、CPMが高くなる傾向

#### 2）冒頭5秒以内に惹きの強い表現を入れる
- 例：「手のシワをハンドクリームでケアするのは時代遅れ」のように**ユーザーの常識を覆す新常識**を提示→「新しい情報を知りたい」心理状態に変わり離脱されにくい

#### 3）UGC風
- ペルソナの配信面に馴染ませて「読まない」壁を壊す
- 字体やデザイン、素材は**ペルソナに近いユーザーのインスタをリサーチして寄せる**
- テキストは**口語かつペルソナが親しめる表現**（例：ら抜き言葉、流行語、方言）
- **リールは93%が音声ありで再生**しているため、音声はつけて作成。動画内テキストとアフレコで若干言っていることを変えることで音声も聞きたくなる仕組みも効果的

### ロジック⑤ 広告文：2つのライティング

#### 1）冒頭2行のライティング
- Meta広告ではTL上で**冒頭2行しか表示されない**ため、この2行で興味引きできないと続きを読んでもらえない
- 冒頭2行で大事な2点：
  - **「課題の特定」**：ペルソナの課題・悩み・願望を特定し、同じ悩みを持っていると共感させ自分ごと化
  - **「解決の示唆」**：課題に対しての解決方法を示唆する文章を入れ込み、続きを読むことで解決できるかもと興味引き

例：
- 「美容院に来たのに、脚がむずむずして集中できない…」「それ、貯蔵鉄で解決するかも？」
- 「【後遺症で注目され始める"貯蔵鉄"の重要性】」「自律神経の機能維持に対し、貯蔵鉄の有効性が注目されています。」

#### 2）ベネフィットライティング
- 売り手が言いたいことではなく、**ユーザーにとって価値のあること**を表現
- × 「こんなに良い機能があります！買ってください！」
- ○ 「ユーザーにとって価値のあるもの」
- 有効：**顧客の体験談**を元に広告文を作成（リアルな描写で共感）
- テクニック：**比較ストーリー**（冒頭でストーリーを紹介して引き込む）
  - 米国経済紙「ウォールストリート・ジャーナル」で使われた**「2人の男のストーリー」**セールスレターが有名
  - 「25年前の春、二人の若者が同じ大学を卒業しました。この二人は、共に成績が良好で、共に人柄も良く、共に将来の夢と希望に満ち溢れています。大学を卒業する多くの若者がそうであるように……」
- **物語で終わらせず、次のアクションまで誘導することを必ず行う**

### ロジック⑥ 配信目的：キャンペーンを分ける条件

CP設定では、CP内に様々な商品のプロモーションが入っていると分析・閲覧しづらいため、下記のような条件でCPを分ける：

1）**商品が異なる**：購入や申込をするユーザーも異なる、反応するCRも異なる
2）**配信目的が異なる**：CV獲得目的とサイトのアクセス増加のための認知目的、通常配信と期間限定のイベント告知など指標が異なる場合

### ロジック⑦ ターゲティング：商品でなくユーザーをイメージ

詳細ターゲティング配信のコツ：「**商品からイメージして考えるのではなく、ターゲットとなる利用するユーザーをイメージして考えること**」

例：化粧水のターゲ
- ×（商品ベース）：メイク・化粧水・美容
- ◯（ペルソナベース）：**旅行好き・ファッション・Instagram・買い物・カフェ**

→ ターゲットとなるユーザーが**普段どんなものに興味があるか**の視点

#### CVデータが溜まってきたら
- **CV180日類似1%**などの類似ターゲティングが効果的
- CVしたユーザーと似ているユーザーに配信でき、さらに成果拡大を促進

#### 顧客リストがある場合
- **リスト類似1%**（顧客リストに行動や興味が似たユーザーに配信）
- **リマーケティング30日**（LPやサイトに訪れたが離脱したユーザーに配信）

### ロジック⑧ LP：FVの重要性

- LP見直しは大幅改善で時間がかかるイメージだが、**LPのFV（ファーストビュー）のコピーを変えるだけ**でも数値改善可能
- 事例：オリジナルCV0/CVR0.00% → 「売れるリソース」CV3/2.28% → 「毎月LPO」CV8/4.92% → 「審査落ち」CV11/8.33%
- 上記はコピー変更だが、画像を商品画像や人物画像、イラストにするなどテストも効果的
- まずは**手を入れやすく、成果に変化の出やすいFVから改善できる点はないか見つけていく**

### ロジック⑨ 商品の見せ方

- 記事LPを挟む場合でも商品の見せ方は重要、**季節要因や時事ネタに合わせて商品の見せ方を変える**だけで数値が改善した事例も
- 例：キットカット → ペルソナを受験生に変えて成功
- 同じ商品で見せ方を**花粉と絡めた**ことで「自分ごと化」させCPA約1/4に改善した事例（赤ら顔用化粧水）

### ロジック⑩ 不安払拭コンテンツ

- CVに繋げるためのLP内コンテンツとして重要なのが**不安払拭コンテンツ**
- 例：企業側の利益にならなそうな価格設定の理由／イベント無料開催の理由
- ユーザーが「**怪しい、本当に大丈夫かな？**」と不安を感じる部分に対して不安払拭コンテンツで安心感を与えることで行動に移させる

事例：
- 無料開催イベントで**「無料で開講を決めた理由」**＋開催責任者の顔を掲載
- ユーザー：「開催側にとっては利益なさそうな企画なのに、なぜ無料で実施するの？怪しい…」
- 不安払拭：無料で開催する理由とともに、**開催責任者の顔を掲載**
- ユーザー：「顔を出すってことは、怪しくないかも！こんなチャンスないし、応募してみよう！」
- 結果：**不安払拭コンテンツはクリック率がダントツで高く、ユーザーが求めているコンテンツ**であることがわかる

#### その他LPで意識すること
- **モバイルフレンドリー対応**であるか
- Meta広告の場合FB/IGというモバイルからのユーザーが多いため、LPや記事LPがモバイル用に最適化されているかで数値が大幅改善されるケース

### 太一向け示唆
- **3Bの法則（Beauty/Baby/Beast）**は提案資料・クリエイターブリーフで使える
- 動画は**30秒以内・冒頭5秒・UGC風・音声アリ**の4点をルーチン化
- 広告文は**冒頭2行で「課題特定→解決示唆」**の型を全案件で使う
- LP改善提案は**まずFVのコピー変更**から（コスト低・効果高）
- **不安払拭コンテンツ**（責任者の顔・無料の理由）はあらゆる案件で使える共通武器

## 第四章：Meta広告の最新トレンド

### ピン差し理論（最重要・運用思想）

#### ガチャ要素とは
- 同じキャンペーン、同じ広告グループでも自動最適化をどのように効かせるかによって**パフォーマンスが大きく変わってしまう現象**
- 例：同じADG内でCPA**4,061円 vs 8,690円**（2倍以上差）

#### なぜ起きるのか
- 自動最適化は**最適化のための情報収集期間**でCVデータを元にCVするユーザーを探して配信を拡張
- **初動の情報収集期間でCVユーザーにどれだけ遭遇するか**が重要
- 初動でCVユーザーに遭遇したら類似ユーザーへ優先的に拡張→数値が早く安定
- 逆に初動であまりCVが取れないとCPA悪化、停止せざるを得ない

#### 解決策：複製ガチャ
- 機械学習がメインの昨今では**CP単位、広告グループ単位で複数複製してパフォーマンスの高いものを採用**する工程が必要
- 「**生け簀の中にランダムで釣り糸を投げて、魚が群れているところに当たればすぐ釣れる**」というたとえ
- ヒットしなければ何度も釣り糸を投げ直す
- **最適化を上手く利用するには複製ガチャを何度も試しながら、平行してレスポンスの高い魅力的な広告を検証していくのが機械学習時代のニューノーマルな運用方法**

#### CRレベルでも同じ
- 同じCP・同じADG内で、広告クリエイティブを複製入稿するだけでもパフォーマンスに違いが出る
- 例：複製した同一CRでCPA¥2,074 vs ¥4,342 vs ¥1,317
- 例：同一CRでCPA¥3,476 vs ¥13,933 vs ¥9,181

#### デジタルアスリート社の運用ルール
- **1つだけの入稿では「たまたま運が悪かったのかどうなのか」が断定できない**ため、広告クリエイティブを新規で入稿する際は**3つ以上複製して判断**

### 太一向け示唆
- 新規CR入稿時は**「同じCRを3つ複製して並走」**をデフォルトの運用ルールにする
- 「成果出ない＝そのCRが悪い」と判断する前に、**複製してもう一度試す**
- 「広告配信＝確定的なもの」と思い込んでいると、運の悪い結果に振り回される
- **クライアントへの説明**：「ガチャ要素があるため、最初のCR入稿は複数本同時に試す運用設計です」

### ASC（Advantage+ ショッピングキャンペーン）

#### 概要
- MetaのAI広告ソリューション
- 従来の広告運用では入札／最適化／オーディエンス／掲載面など複数要素を**人の手で改善**してきたが、ASCではその大半を**AIに任せ、CRのみがレバーに**
- 運用の手間がなくなり、可変要素となるCRを良くすることだけに集中できる

#### 通常CV配信との違い

| 項目 | 従来CV（CV目的/カタログ販売）| **Advantage+ ショッピングキャンペーン** |
|---|---|---|
| 機械学習 | 従来の機械学習モデル | **改良された機械学習モデル** |
| 入札 | 手動で設定する | **自動入札のみ** |
| 最適化 | いずれかのPixelイベント（入札戦略に基づいて最適化に設定したイベントのCVを目指す）| **購入イベントのみ**（配信の予算で最大の購入CV、最小の購入CPAとなることを目指す）|
| オーディエンス | ターゲットを手動で設定する | **ターゲットを自動で設定**（国のみ指定する）|
| 配置面 | 手動で設定する（自動配置を選ぶことも可）| **自動配置のみ** |
| クリエイティブ | 手動で設定する | **ユーザーごとに最適な広告フォーマット、CR、配信先を自動で決定** |
| 入稿本数 | 制限なし（最大6件が推奨）| **1広告セットあたり最大150のCR**（CR数が多いことが推奨）|

#### ASCの機械学習の特徴
- 通常の機械学習：広告掲載後のデータを元に学習を重ねる
- **ASC：広告が掲載される前や広告からCVデータを収集する前に、広告アカウント内の過去のCVデータを元に配信すべきターゲットグループが仮説立てられ配信**
- 全体に向けて配信し当たるところを見つけるのではなく、**ターゲットの優先順位が高いグループから配信されるため、立ち上がりが早い**

#### 実績事例
- **Case 2 速読セミナー**：通常 CTR0.91%/CV10/CPA¥32,364/CVR1.32% → ASC CTR1.04%/**CV30/CPA¥15,543/CVR1.75%** → **CV3倍・CPA1/2**
- **Case 3 赤ら顔用化粧水**：通常 CTR0.45%/CV98/CPA¥9,507/CVR2.46% → ASC CTR0.34%/CV65/**CPA¥6,533/CVR3.18%** → **CVR1.3倍・CPA2/3**

→ ショッピングキャンペーンという名前から「D2C系でないと成果出ない」と思いがちだが、**無形商材でも成果が出ている**（速読セミナーで実証）

### 太一向け示唆
- ASCは「ECだけ」ではなく**情報商材・セミナー・サブスクなど無形商材でも有効**な事例あり
- ASC導入の判断軸は「**ターゲットを自動最適に任せられる過去CVデータがあるか**」
- CR本数150本まで入稿可能なので、**CR制作リソースとセットでの提案**

### 投稿広告（Instagramの投稿を広告として配信）

#### 概要
- **投稿広告**は、Instagramに投稿した内容を広告として配信すること
- SNSでの影響力が大きくなる中、企業アカウントの存在も増えてきた
- アカウントが拡大しないという課題を抱える企業も多い

#### 戦略：バズ目的ではなく、属性合致ユーザーに届ける
- CV獲得のためには必要以上に拡大させる必要はなく、**対象となるユーザーに情報を届けることが最優先**
- バズらせると対象外のユーザーにもインプレッションが広がりCV獲得できなくなる
- **広告を使い、有益コンテンツを属性にあったユーザーに届ける**

#### チャットボットツール活用フロー

```
広告 → クリック → LP → CV         （通常広告）
広告 → フォロー＋コメント → DM → LP → CV  （チャットボット）
```

- **チャットボットツールを導入**することで、フォローだけでなくコメントやDMを促す
- コメント促進で**広告色を抑えながら能動的なアクション**を獲得しやすく、DMで1対1のコミュニケーションが発生するため**アカウント評価が自然と高まる**

#### フォロワー増加サイクル
```
フォロワーからのアクションが増える
　→ 他のフォロワーへも露出されやすくなる
　→ ユーザーにとって求められる投稿・アカウントという評価
　→ フォロワー外への露出されやすくなりブースト！
　→ フォロワーからのアクションが増える（ループ）
```

#### 投稿戦略：2:8の広告/教育バランス
- 継続するごとにフォロワーが増え集客効率上昇、フォロワーには日頃の投稿で**教育ができるためCVR向上**
- 投稿は**2:8のバランスで広告用投稿と教育用投稿**
- 教育用：マーケ用語集55、速打ち＆時短、カラーマーケティング、ライフスタイル別訴求変化、ニーズorウォンツ違い
- 広告用（セールス）：Instagram限定提供、コメント特典など

#### CR制作の4段階
- **CTRを上げて**：興味・関心 → 共感・信用
- **CVRを上げる**：教育・納得 → アクション促進

### 太一向け示唆
- 投稿広告は**フォロワー獲得＋CV獲得**の両取り戦略として提案価値高い
- **2:8の広告/教育バランス**は運用ルール化できる
- チャットボット連携は**Instagram運用代行案件のスコープ拡大**に使える

## 第五章：運用における注意点

### CPA重視の運用の落とし穴

#### よくある誤った判断
「**CPAが上がってきたから、広告配信量を抑えてCPAを合わせよう**」というやり取りは現場でも多く行われているが、果たしてこれは正解か。

#### 広告運用の目的を再考
- 役割としては求められることがあるが、**会社にとって広告は売上を作るための手段に過ぎず、あくまでも目的は売上・利益**
- **CPAを重視するあまりに本来の目的を見失ってはいけない**

#### 具体事例：問い合わせ獲得のコンサル会社（月額20万円契約）

| 会社 | A社 | B社 |
|---|---|---|
| 広告費 | 1,000,000円 | 1,000,000円 |
| 問い合わせ件数 | 26件 | 40件 |
| **CPA** | **38,461円** | **25,000円** |
| **受注率** | **50%** | 20% |
| 受注件数 | 13件 | 8件 |
| **売上** | **2,600,000円** | 1,600,000円 |

→ 広告だけ見るとB社が良いが、**売上ではA社が勝つ**。
→ コスト効率は上がっていても、**他の費用対効果やコスト回収効率が悪くなる**ことが多分に起こる。
→ 獲得コストを下げることも重要だが、**広告コストだけ削減してもビジネス全体のパフォーマンスは上がらないケース**がある。
→ 費用対効果という点においてCPAを指標とすることは必要だが、**広告の部分だけでなくマーケティング全体から成功を定義**することが大切。

### 太一向け示唆
- 「**CPA改善＝売上改善ではない**」という事実をクライアントに先に共有
- **受注率／LTV／単価**まで含めた**マーケティング全体の指標**で提案する習慣
- 「CPA下がったが受注率も下がって売上ダウン」は典型的事故パターン、月次レポートで毎回チェック

---

### CPMは改善指標にするべきか

#### 課題：CPMの解釈
ある程度運用していくと「**CPMが上がったせいで成果が悪くなっている…**」という場面によく出会う。

例：CTRは1.2%のまま変化していない、むしろ良くなっているくらいなのに、CPCが120円から150円に上がってしまっている → CPMが400円も上がっている

#### Meta広告のオークション計算式
**総合的な価値 = ① 入札価格 × ② 推定アクション率 ＋ ③ 広告品質**

③広告品質は配信された広告が正しいターゲットユーザーに正しく届いているか、有益な情報を届けられているかという内容で、**どこで判断するのかは明確にされていない1番曖昧な項目**。

#### 分析結論
広告品質が管理画面のどの項目と関連しCPMに影響を与えているのかを分析した結果：

- **広告のCTRが上がるとCPMも上がる**
- **しかしCPMが高いとCPAも高くなるというわけではない**
- **品質ランキングが高ければCPMが安く、低ければCPMが高くなっている**

#### 品質ランキングとは
> 品質ランキングは、オーディエンスが同じ広告と比較したときの感性品質を表します。広告の品質は、さまざまなシグナルによって測定されます。広告を見た人や非表示にした人からのフィードバックのほか、低品質とみなされる広告の特徴（情報の隠ぺい、扇情的な表現、エンゲージメントベイトなど）などが判断材料となります。

#### 結論
- 配信してすぐに「この配信先はCPMが高すぎる」と早期に見切って配信を停止してしまうのは**機会損失につながる可能性**があるため、運用時には**CPMを第一指標にはせずサブ的に考える**
- CTRが低い状態でCPMを下げる目的でターゲティング設定をいじるのも意味がない
- **広告の品質が低いためにCPMが高くなっている**という点が考えられるので、やはり**基本のクリエイティブテストをしっかり実行**することが重要

### 太一向け示唆
- **CPMが上がった→停止**という安易な判断は機会損失リスク
- CPMの根本原因は**広告品質ランキング**（CR改善・LP改善・ネガティブフィードバック削減）
- 数値分析レポートで**CPMはサブ指標扱い**、第一指標はCPA／CVR／受注率／売上
