# ChatGPT広告をGA4で分析してわかった特性（現状は非顕在層向け）

## 出典
- @ishigurodo のX投稿（2026-07-07）
- https://x.com/ishigurodo/status/2074434698324172974

## 用途（どんな時に活用できるか）
- クライアントから「ChatGPT広告を試したい」と相談された時に、**期待値調整と初手の座組み提案**をするため
- 顕在層獲得を目的にChatGPT広告を検討している時に、**現状の限界とワークアラウンド**を即答するため
- ChatGPT広告で成果が出ないと相談された時に、**媒体特性起因なのか運用起因なのか**を切り分けるため
- LP設計を検討する時、記事LP / ディスプレイ用LPを選ぶ根拠として

## 要点

### 1. エンゲージメント率が他検索媒体の半分以下
- ユーザーはChatGPTと**雑談・情報収集フェーズ**で会話している最中に広告が表示される
- つまり「まだオークションとして顕在化していない状態」に広告が差し込まれている
- **示唆**: 現状のChatGPT広告は**顕在層向けではない**。検索広告の感覚で導入すると痛い目を見る

### 2. LPは「記事LP等 準顕在・潜在層向け」の方がCVR高い
- 顕在層向けの申込LPよりも、記事LP等の情報提供型LPの方がCVRが出やすい傾向
- ユーザーの心理状態（情報収集フェーズ）とLPの温度感が合うため

### 3. コンバージョン最適化機能がまだない
- 現状は「クリック最大化」寄りのアルゴリズムと推測される
- コンバージョンを軸にした自動最適化が効かないため、顕在層向けの位置付けにできない

### 4. 地域別配信の異常値：北海道士幌町が3位
- サイト全体の傾向から見て明らかな異常値
- 「低入札＝競合がいない地域の枠」を買い叩いている挙動と推測
- 入札を100円以下に下げたタイミングと地域偏りが連動
- **東京など人口比が多いエリアを取りに行くには、入札を高くする必要がある**
- 地域コントロールはコンテキスト（プロンプト）に入れても制御できない

### 5. 時間帯×曜日：日予算のペーシング機能はある
- 午前中に予算を使い切ってしまう挙動は見られない → ペーシングは効いている印象
- ただしCVRは悪い → やはりアルゴリズムは**クリック最大化寄り**
- 時間帯・曜日制御もコンテキスト入力では効かなかった

## So What（次のアクション）

### 現時点でChatGPT広告を扱う場合の座組み
1. **顕在層獲得CPAでは評価しない**。認知・準顕在層育成の予算として位置付ける
2. **LPは記事LPやディスプレイ広告用LP**（情報提供型）を用意する。既存の申込LPを流用しない
3. **入札は100円以上を維持**して、地域偏りを抑える（大都市を取りに行く）
4. **地域・時間・曜日の制御はプロンプトでは効かない**前提で設計。制御したい場合は媒体側の機能実装を待つ

### 待ちのシグナル
- 「コンバージョンの最適化」機能の実装 → これが来れば顕在層獲得にも使えるフェーズに入る

## 補足：この情報の位置付け
- 2026年7月時点の1運用者による観測結果。媒体側の仕様変更で急速に変わる領域
- 3ヶ月〜半年おきに再検証が必要。特に「コンバージョン最適化」実装の有無は継続ウォッチ
