# リスティング広告 初期設計チェックリスト

## ＜前提＞
このページは以下のような状況を前提とした内容になっています。
以下に当てはまらない場合、こちらのページが参考にならない可能性があります。
- 他からの移管ではなく、新規でリスティングのキャンペーンを立ち上げる必要がある
- 予算が100~200万/月またはそれ以下のレンジ
- ビジネスモデル的にCPAが1~2万に収まることは難しい

---

## 初期設計のチェックリスト(リスティング広告)

### ● 最初に確認すべきこと
#### キーワードについて
- [ ] 競合他社・他案件・過去実績等の情報を収集し、勝ち筋になる可能性の高いKWのあたりをつける（妥当なCPCのKW調査、検索のサジェスト、ラッコKWで検索、キーワードプランナーの活用、Yahoo!アカウントでのAIキーワード生成等）
- [ ] 上記KWで検索した際、主な競合名・競合の広告文・競合のLP・オーガニックサイトのラインナップを大枠把握しておく
- [ ] 上記KWのクリック単価の相場感をキーワードプランナーで把握しておく（以下参考）
  - [クリック単価の相場がわかる！無料ツールで調べる方法をカンタン解説](https://www.seohacks.net/basic/terms/cpc/)

#### LPについて
- [ ] FV上にCTAがわかりやすく設置されているか・CTAを押すのにスクロール不要かを確認する（toB向けであればPC画面で、toC向けであればSP画面で確認）
- [ ] FVにて、メインコピーに主力KWが含まれているかを確認する
- [ ] FVの訴求が、わかりやすい・ベネフィットが伝わるかを確認する
- [ ] CVまでのUXが著しく悪くないかを確認する
- [ ] 上記を1つでも満たしていない場合、LPを改修しないと効果が見合わない可能性があることを先方に伝える

#### 計測について
- [ ] GTMのプレビュー/タグアシスタント/デベロッパーツールなどを用いて設置したタグがきちんと発火するかを確認する
- [ ] パラメータ付きのURLでテストCVし、先方基盤にも反映されているかを確認する

---

### ● アカウント構造
#### <キャンペーン構成>
- [ ] 基本的には指名と一般の2キャンペーンで構成する
- [ ] 一般キャンペーンからは指名KWを除外する
- [ ] ただし、以下に当てはまる案件は以下のアカウント構造で構成する（都度追加します）
  - 人材業界・不動産業界
    - [ ] エリア名の掛け合わせでも一定量獲得が見込める場合、指名・一般・エリアの3キャンペーンで構成する
    - [ ] その際、エリアキャンペーンの広告グループは1つで設定する（エリアがキャンペーンごとにしか設定できないため）
    - [ ] その際、先方LPにてエリアごとのページが存在する場合はKWごとに該当エリアページを遷移先に設定する
    - [ ] その際、エリアキャンペーンの地域設定は日本全国に設定する
    - [ ] その際、除外KW/除外KWリストを用いて一般キャンペーンから想定されうるエリア名を除外する
  - 多品目EC
    - [ ] 指名・一般・商品名・DSAの4キャンペーンで構成する
  - 店舗系（多店舗の場合）
    - [ ] 店舗ごとにキャンペーンを作成する

#### <グループ構成>
- [ ] 基本的には1キャンペーン1グループで構成する
- [ ] ただし以下に当てはまる場合は、グループ分割を推奨
  - 分割が推奨される場合
    - 主力KW群の中で、想定CPCが3倍以上乖離する場合
    - 主力KW群の中で、想定CVRが3倍以上乖離する場合
    - 主力KW群の中で、LPが複数用意されている（≒ニーズが全く異なる）場合（男性向け、女性向けでそれぞれある、など）

### ● クリエイティブ
- [ ] タイトル15本・説明文4本はMAXで入稿する
- [ ] 広告カスタマイザもしくはキーワード挿入機能を活用した広告文を作成する
  - カスタマイザの活用例
    - 案件共通：ニーズが異なると想定されるキーワードごとに、そのニーズに沿った広告文を作成
    - 人材・不動産業界など（エリアが絡む場合）：キーワードに含まれるエリア名ごとに広告文を出しわけ
    - ポータルサイト系案件など：その日の日付に合わせて広告文を変動させる
      - 設定方法は以下参照
        - [広告文に今日の日付を入れる方法（Google広告の広告カスタマイザ）](https://www.letsai.co.jp/news/20211227/)
  - 特殊なキーワード挿入機能の活用
    - 地域の自動挿入機能（対象：多店舗に展開している店舗系案件など）
    - カウントダウン機能（対象：期間限定のセールなどがある案件）
      - 上記の設定方法は以下参照
        - [Google/Yahoo!広告 広告文の自動挿入機能について解説](https://digimarl.com/syllabus/column/auto-insert/)
  - カスタマイザの設定方法
    - Google: [Google広告カスタマイザ設定方法（外部リンク）](https://drive.google.com/file/d/1-XoVYk16UfSJL8qWDU0YHxxe1wZRye_f/view?usp=drive_link)
    - Yahoo!（Macでは設定できないので注意）: [Yahoo!広告 レスポンシブ検索広告のアドカスタマイザーとは？](https://anagrams.jp/blog/yahoo-ad-customizer/)
    - Microsoft（Googleとほぼ一緒）: [Microsoft広告カスタマイザの設定方法](https://www.engun.co.jp/blog/microsoft-ad-customizer/)
- [ ] 広告表示オプションを網羅的に設定する（以下は最低限設定）
  - [ ] サイトリンク（6本以上推奨：偶数推奨）
    - URLが1つしかない場合
      - 同じURLはサイトリンクに設定できないため、擬似的なパラメータを付与して別URLのような形で入稿する
      - パラメータは適当でOK（「?〇〇」の形で）
  - [ ] コールアウト（6本以上推奨）
  - [ ] 構造化スニペット
  - [ ] 画像（10枚以上推奨）
    - ※テキストやロゴが入ったものは不可
    - ※先方OKなら「無料のストック画像」よりGoogleが持っているフリー画像から選定
  - [ ] ビジネスの名前（適格性確認が完了していることが条件）
  - [ ] ビジネスのロゴ（適格性確認が完了していることが条件）
- [ ] 案件によってはその他表示オプションについても設定推奨
  - [ ] 店舗系案件：住所（これによりGoogle Mapへも配信可能）
  - [ ] 店舗系案件：電話
  - [ ] ECなどWEB決済可能な案件：価格
  - [ ] ECなどセールが存在する案件：プロモーション

### ● キーワード
- [ ] 最初に確認した、想定勝ち筋KWを軸に掛け合わせKWと組み合わせる
  - イメージ（Aが勝ち筋KW、B・Cが掛け合わせKW）
  - 掛け合わせKWを作る際の便利ツール
    - [キーワード掛け合わせツール | SEMカフェ](https://www.semcafe.com/tool/keyword/)
- [ ] マッチタイプは完全一致・フレーズ一致のみ
- [ ] また、フレーズ一致は3トークン以上のKWのみ初動では配信
  - トークンの説明と理由（例は部分一致だが、フレーズ一致でも同様）

---

### ● 入札・最適化
- [ ] 入札戦略は「ポートフォリオ入札」で「コンバージョン数最大化」を活用する
- [ ] 最適化対象はマイクロCV+本CVで設定する
  - マイクロCV設置箇所例(ものによってはサブCVにする)
    - 確認画面到達地点
    - フォーム到達地点
    - フォーム入力
    - ボタンクリック
    - スクロール○%
- [ ] ただし、(フォーム等別CV導線がある前提で)電話ボタンクリック・LINEボタンクリックは最適化対象から外すことを推奨
  - [ ] 電話導線がある場合は、コールトラッキングツールの導入を推奨
    - おすすめツール(20%バックされます)
      - [Google広告・Yahoo!広告と連携可能なコールトラッキングツール（電話計測）](https://www.calltracking.jp/)
  - [ ] LINE導線がある場合は、LINE計測ツールの導入を推奨
    - おすすめツール(20%バックされます)
      - [L Data Bank：エルデータバンク【公式】](https://www.ldatabank.co.jp/)

### ● その他
- [ ] リタゲリスト(RLSA)や興味関心オーディエンス(IMSA)等、紐付け可能なリストはすべて紐づける
- [ ] ネガティブワードは事前に除外しておく（ネガティブワードリスト作成中です、、、）
- [ ] 競合ワードは事前に除外しておく（競合ワードを積極的に買う方針でない場合）
- [ ] 検索パートナー面は事前に除外しておく（感覚3%ぐらい、アドフラリスクあるので除外）
- BtoB案件の場合
  - [ ] スマホ、タブレットは除外しておく（入札調整比率を-100%にする）
  - [ ] 時間帯は8:00-22:00までに限定する
  - [ ] 曜日は月〜金までに限定する
  - [ ] 地域は以下エリアに限定する

      - 神奈川県

      - 大阪府
      - 京都府
