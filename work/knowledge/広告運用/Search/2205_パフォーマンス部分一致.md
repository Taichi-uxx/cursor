# パフォーマンス部分一致

## 出典
- ファイル: `知見・ナレッジ移管/リスティング/パフォーマンス部分一致.docx`
- 内容: Google主催勉強会の社内まとめ。「進化した部分一致（パフォーマンス部分一致）」の概要・テスト方法・反対意見への返し方
- 投稿日: 不明（推定: 2021〜2022年頃。絞り込み部分一致廃止前後）

## どんな時に活用できるか
- クライアントから「部分一致は怖い」と言われた時の返し方を整理したいとき
- 既存アカウントを部分一致中心に切り替える際、D&Eの検証要件を確認したいとき
- 部分一致導入のメリット（CV増・CV値増）を数値で示してクライアント説得したいとき
- 除外KWのガイドラインを整理したいとき
- 部分一致の前提条件（自動入札の品質・固有シグナルの活用）をGoogleの公式見解として参照したいとき

## 1. 進化した部分一致とは

### 部分一致の世界シェア
- 日本：25%（部分一致比率）
- 世界Top：50%
- → 日本はまだ伸びしろがある

### 従来の部分一致 vs 改良版
| | 従来 | 改良版 |
|---|---|---|
| パフォーマンス | 低下リスクあり | 自動入札の品質向上で他マッチより優位 |
| 意向把握 | クライアント・ユーザーの意向不明 | LP・他KW・所在地などのシグナルを活用 |
| クエリ | 親和性の低いクエリも拾う | 関連性の品質閾値を更新 |

### 部分一致だけが使える固有シグナル
- LPの内容
- 広告グループ内の他KW
- 過去の検索履歴
- ユーザーの所在地
- 見込まれるパフォーマンス

### 使い分けの原則
- **CV重視** → 部分一致
- **CV以外を重視（ブランドセーフティ、KWの関連性絞り込み）** → 完全一致

## 2. 部分一致活用のメリット（クライアント説得材料）

- **費用対効果の向上**：成果に結びつくKWに投資、結びつかないCPC発生を回避
- **時間の節約**：膨大なKWリストを手動作成する手間を削減
- **リーチの拡大と一致率の向上**：目標達成しながら新しい価値あるクエリを発見
- **関連性**：シグナルをアルゴリズムに提供することで的確な意図把握

### 数値インパクト（Google公式）
フレーズ一致または絞り込み部分一致を部分一致に変更することで：
- **tCPAの場合：最大CV 25%増加**
- **tROASの場合：最大CV値 15%増加**

### 部分一致がもたらすメリットの例
- LPコンテンツ：「ROSE」（バラとワインのロゼ）のような多義語をLPで識別
- 所在地：「近くのホテル」で所在地連動の関連性高い広告
- グループ内他KW：「Paris Hilton」のような多義語をグループ構成で識別

### 活かし方
- 絞り込み部分一致・フレーズ一致 → 部分一致への移行
- 部分一致で入札候補となる新たなクエリ発見
- 効率性目標は従来のまま、CV数最大化

## 3. 部分一致のテスト方法（D&E）

### 検証の前提条件
- **検証目的をシンプルに**、ステークホルダー間で共通認識を持つ
- 改善したい指標は何か？（季節性・ノイズなく計測できるか）
- 管理画面で見られるか、オフラインで見るか
- Google推奨指標か

### 正しい評価方法
- 下書きとテストで、検証ポイントだけが異なり、他の条件は同一か
- 検証時期や環境が季節性・特殊変動を排除できているか

### D&Eの要件
- **4週間程度**はD&Eを継続
- 部分一致のCostが20%以下
- 絞り込み部分一致やフレーズ一致のKW割合が**全KWの80%超**
- 予算制約によるIMP損失がない
- 十分なCV件数（**デイリーCost ¥10,000以上**）

### テストプロセス
1. キャンペーン選択
2. 下書き作成
3. 検証
4. 検証停止（有意差確認後）

### 学習期間・コンバージョンラグの加味
- **1〜2週間の学習期間**を与え、評価期間からは除外
- **コンバージョンラグ**（クリック→CVまでの平均日数）も特定し、評価期間から除外
- 確認方法：アトリビューション → パスメトリクス → コンバージョンまでの平均日数（「最初のインタラクションからの測定」を選択）

---

## 4. 除外KWのガイド

### 設定して良いケース
- ブランドKWとそのタイプミスパターン
- 競合他社のKW
- 商品の不適切な関係づけ
- よく間違えられる単語

### 留意点
- **設定しすぎ注意**（機会損失につながる）
- 慎重に選択
- 定期的にチェック
- マッチタイプを間違えない

## 5. よくある反対意見への返し方（Q&A）

### Q1. なぜ部分一致に取り組まなければならないのか
- 現状の効率改善（IMPシェア改善など）よりも優先する意味は？という質問
- 回答軸：CPA目標の見直しは可能（パフォーマンスプランナーでKW追加・拡張によるCV増を試算）
- アカウント全体のカバレッジ増加でCVを増やしたい

### Q2. 拡張によるパフォーマンス悪化リスク
- そもそも検索Nに伸びしろがない → Displayなど他プロダクトを提案
- 伸びしろがある/わからない → Google営業担当と業界トレンド・競合比較・アカウント伸びしろを確認

### Q3. 他チャネルより検索を優先する理由
- 検索とDisplayを横並びで比較しない
- **検索は能動的なユーザーへのアプローチチャネル**であることを再強調
- 継続利用で拡大可能であることを強調

### Q4. 一般KWに投資するメリットを感じない
- タッチポイント作りで重要なKWであることをチャートで再説明

### Q5. 部分一致＝拡張度合いが読めない、悪化リスク
- 過去のテスト要件を確認 → 何が悪化要因だったかを導く
- まず検証（D&Eの利用）

### Q6. 最適化案の質が悪い
- 発生要件を把握、リスクヘッジを踏まえて導入可能なら実施、不可能ならGoogle社営業担当にFB

### Q7. リソース不足で対応できない
- Google社側のリソース活用：Auto Apply、Expansion向けサポートメニュー
- サポートメニューのアウトプット確認、NGリストがあればFB
- ベンダー側のクオリティコントロール説明を求める

### Q8. 現状の事業状況に合わない（コロナ影響、人的リソースなど）
- 拡大フェーズなら導入
- 困難なら再開タイミングで活用

### Q9. 3トークン設定の必要性
- 無理に3トークン設定する必要なし、2トークンである程度カバー可能

### Q10. 実績がないアカウントでは？
- **むしろ部分一致を積極導入した方が良い**

## 太一の示唆
- D&Eの要件（4週間・Cost20%以下・KW80%超・デイリー¥10k以上）は提案前のチェックリストとして使える
- 「CV 25%増（tCPA）/ CV値 15%増（tROAS）」はクライアント説得のキラー数字
- 反対意見への返しはQ&A形式でストックしておくと、SOWの説明資料に転用しやすい
- 「実績がないアカウントこそ部分一致」は逆説的だが強い説得材料
