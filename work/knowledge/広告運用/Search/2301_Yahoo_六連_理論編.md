## 第1章：消費者を取り巻く環境と行動の変化

### インターネット上の人々の行動変化と多様化

**ネット利用が2019年比で約1.4倍に**
- 出典: 総務省情報通信政策研究所「令和3年度情報通信メディアの利用時間と情報行動に関する調査」全年代の平日1日のデータ
- 2017〜2021年にかけて、ネット利用が急激に伸長（テレビリアルタイム視聴は減少）
- コロナの影響で「テレワーク／オンライン学習／ライブ配信／動画閲覧／情報収集／買物／SNSや電子メール／チケット予約」など多種多様な行動が増加

**ヤフーデータからも行動変化が表れる**
- Yahoo!トラベル: まん延防止解除でPV数増加
- Yahoo!ニュース: 注目度の高い時事ネタ（東京五輪・衆議院選挙）でPV数増加

### 拡大し続ける情報量

- データ通信量（モバイル経由）は2016年比で2022年に約**930%**、2025年には**191%**（2022年比）成長予測
- → **2025年にはネット利用が現在の約2倍に**

### 主要メディアの利用者状況

- 2022年TOP10メディアのうち**ほとんどが2020年比で利用者増**
- Yahoo! JAPANはA社・B社・C社らと並んで利用者増のトップ層

### ヤフーでの全体の利用者数

- 2022年平均月間PV数: 約**840億**（スマートフォン630億・パソコン210億）
- 推移: 2019年744億 → 2020年780億 → 2021年810億 → 2022年840億
- **毎年約30億PV増加**

### ヤフーは変化を捉えることができるプラットフォーム

- 月間アクティブID数: **5,000万ID/月**
- 提供サービス: 約**100**のサービス
- ニューステーマ数: 約**23,000テーマ**
- eコマース取扱高: 約**3.2兆円/年**
- 年間検索クエリ種別: 約**90億クエリ**
- PayPay年間決済回数: 約**20億回**
- 「**知る・調べる・買う**」を網羅する多種多様なサービスを保有する唯一の媒体

### ビッグデータの活用による「自動化」の推進

ターゲティング・入札・クリエイティブの**自動配信**へ。手動運用では捉えきれないユーザー行動変化や市場状況に柔軟に対応できる。

### 第1章まとめ

```
情報量の増加・行動変化と多様化
        ↓
ヤフー JAPAN：圧倒的なユーザー接点 × 多様なデータ × 行動変化を捉える自動化
```

## 第2章：広告主を取り巻く環境の変化

### 求められる広告のクオリティ

#### 広告に対するユーザー感情

> 広告ストレスは購買にも影響している

| 影響 | % |
|---|---|
| 広告ストレスによって企業やサービスを嫌いになったことがある | **54%** |
| 商品の印象が悪くなった | 46% |
| 広告掲載したメディアの印象が悪くなった | 44% |
| 企業の印象が悪くなった | 42% |
| 商品を買いたくなくなった | 34% |
| 広告に起用されたタレントの印象が悪くなった | 21% |

出典: Yahoo! JAPAN メディア利用実態調査自主調査（n=4125）2022年1月

- アドブロックも普及しており、「広告=不要な物」という認識も一定存在（Brave adblock、280blocker等）

#### 一方で、高い広告の受容度

- **約90%**が広告を受容
  - 71.8% 無料でサービス利用できるなら広告はあってもいい
  - 18.1% サービスの有料・無料にかかわらず広告はあってもいい
  - 10.1% 広告が表示されなくなるならサービスが有料でも構わない
- **広告役割・メリットへの共感度（5,000人回答）**
  - 広告役割共感（いずれかの役割やメリットに共感）: 58.7%
  - Yahoo!やGoogleなどのサービスを無料/安価で利用できる: 32.9%
  - 新商品を知ることができる: 22.3%
  - 新たな発見ができる: 17.7%
  - 企業情報を知ることができる: 11.5%

#### つまり、広告は「環境・タイミング × メッセージの内容」

→ **ユーザーフレンドリーな広告**がより重要

### ユーザーが求める広告

| ユーザーが見たいと思う広告 | % |
|---|---|
| **信頼できる根拠がある内容の広告** | **54.9** |
| **興味がある企業・ブランド・サービス・商品の広告** | **44.7** |
| **好きな企業・ブランド・サービス・商品の広告** | **39.2** |
| いつも利用している企業・ブランド・サービス・商品の広告 | 35.5 |
| 他の媒体で気になっていた企業・ブランド・サービス・商品の広告 | 27.2 |
| 推し（自分が好きなタレントなど）が起用されている広告 | 23.4 |

### ヤフーは信頼が厚いプラットフォーム

- **情報の信頼性・公共性があるメディア**: Yahoo! JAPANが1位
- **広告ストレス低 × 広告印象が残る**: Yahoo! JAPANが「低ストレス×印象残りやすい」象限の最右下

### 広告品質のダイヤモンド（ヤフーの取り組み）

ヤフーは独自の「広告品質における3つの価値と6つの対策項目」を定義：

```
              アドクラッター対策    ストレスのない広告体験の提供
ビューアビリティ                                    最適な広告フォーマット
              （視認性）              ┐
                          適正な広告効果   ◇   プライバシーへの配慮
                          の可視化       ／
              アドフラウド対策        ／
                          ブランドセーフティ（適切な配信面）
                              ↓
                ブランド価値とメディアの信頼性の担保（不正の排除）
```

品質を保つ仕組み：
- **ガイドライン**: 広告・サイト・トラフィックに関するガイドライン制定、社会情勢を鑑み常に更新
- **審査体制**: 機械学習を活用したシステム＋人の目による審査

## 第3章：これからの広告に求められること

### 配信土台 × 配信戦略設計

| プラットフォーム（ヤフー） | 広告運用者（広告主/代理店） |
|---|---|
| **量**: 圧倒的なPV数 / 豊富な1stPartyデータ | 求められる広告のクオリティ |
| **質**: メディアとしての信頼性 / 多種多様なユーザの行動データ | プライバシー保護への対策 |
| → **プロダクトの自動化による配信最適化** | → **配信戦略設計** |
| - ユーザーニーズを捉える | - 広告で届けるメッセージ |
| - 場所（掲出箇所） | - データを利活用する機能導入（プライバシー対策） |
| - 時（配信タイミング） | - チューニングメンテナンス |

**× 掛け合わせ → ユーザーへの最適な顧客体験と市場変化への柔軟な対応を実現**

### 配信の最適化と最大化の持続

| 軸 | 内容 |

| **配信の最適化** | ユーザーへの最適な顧客体験 |

**最適化と最大化の持続 = 広告効果の維持**。ユーザー行動とインターネット広告を取り巻く環境は変化し続けるため、両方を持続することが広告効果の維持に重要。

## 第4章：Yahoo!広告の効果を上げるための運用手法「六連」

### ヤフーの推奨運用手法の変遷

| Phase | 目的 | 内容 |
|---|---|---|
| **Phase1** 基礎固め | 最適なアカウント構造作りと可視化指標策定 | コンフリクトを回避し、機械学習による最適化がかかりやすいアカウント構造へ |
| **Phase2** 基礎から成長へ | 各コンポーネントの水準高度化 | 新プラットフォーム（Yahoo!広告ディスプレイ広告）への対応、入札・ターゲティング・クリエイティブの深掘 |
| **Phase3** 拡大と成果維持 = **六連（ろくれん）** | リーチ拡大・メンテナンスを意識した持続的成長 | 市況の変化を捉えたリーチ拡大、ユーザーへの最適な広告配信、メンテナンスによる効果の維持 |

### 「六連」の3つの柱

1. ユーザー・消費者への最適な顧客体験
2. 市場変化への迅速かつ柔軟な対応
3. 最適化と最大化の持続

→ 広告運用における**重要なステップとKPIを6パートに分類**し、広告効果を上げるための運用手法を提示。

### 六連（6つの花弁）の全体像

| Step | パート名 | 概要 |
|---|---|---|
| **1** | **基盤構築** | **アカウントの基礎を固め、効果を発揮できる土台を構築する** |
| **2** | **最適入札** | **入札を最適化し、投資対効果のある広告配信機会を逃さない** |
| **3** | **効果効率** | **ターゲティングを活用することで、配信の効果と効率の向上を狙う** |
| **4** | **拡大成長** | **リーチ拡大することで、変化する市場やユーザーのニーズを逃さない配信戦略を立てる** |
| **5** | **最適表現** | **ユーザーごとに適したクリエイティブを配信することで、成果の向上につなげる** |
| **6** | **成果維持** | **定期的に運用のメンテナンスを行うことで、恒常的に成果を上げられる状態を創る** |

### 検索広告（YSA）の6Stepと重要KPI

| Step | 重要KPI | 目的 |
|---|---|---|
| **1 基盤構築** | ユニーククエリー率／広告表示オプションご利用金額率／インプレッション損失率（予算）／エンティティ数 | アカウントの構造をシンプルにして基礎的な機能を使いこなすことで、機械学習による最適化がかかりやすいアカウントの基礎土台を構築 |
| **2 最適入札** | 自動入札ご利用金額率／入札鮮度 | 自動入札の利用によって、Yahoo! JAPANの膨大なデータをもとに様々なシグナルを参照しながら、自動かつリアルタイムで効果の高い入札価格になるよう最適化 |
| **3 効果効率** | サイトリターゲティングご利用金額率／対象外キーワード登録率 | パフォーマンス向上のために配信する検索クエリーの最適化とターゲティング機能を活用。より効率的な配信のために、リーチ拡大実施後にも配信する検索クエリーの最適化を行う |
| **4 拡大成長** | マッチタイプ完全一致以外のご利用金額率／アクティブキーワード数／キーワード最終更新日／DASご利用金額率 | 変化を続けるインターネット上でのユーザー行動を捉えながら、将来の顧客となりうるユーザーへのリーチを拡げることで、継続的な顧客獲得とビジネス発展に寄与 |
| **5 最適表現** | RASご利用金額率／タイトルのクエリー含有率／拡張クイックリンクご利用金額率／広告の最終更新日／キーワードの自動挿入・アドカスタマイザーご利用金額率 | ユーザーが求める情報に合致するクリエイティブを配信し、ユーザーに期待するアクションの確率を高める。広告の品質は配信によるパフォーマンスの良し悪しを分ける重要な要素 |
| **6 成果維持** | インプレッション損失率（予算）／キーワード最終更新日／対象外キーワード登録率／タイトルのクエリー含有率／広告の最終更新日 | 定期的に注視すべき重要指標をモニタリング・メンテナンスすることで継続的な顧客獲得とクライアントのビジネス成長に貢献 |

※DAS：動的検索連動型広告
※RAS：レスポンシブ検索広告

### ディスプレイ広告（YDA）の6Stepと重要KPI

| Step | 重要KPI | 目的 |
|---|---|---|
| **1 基盤構築** | キャンペーン数／広告グループ数・広告数／インプレッションシェア損失率（予算） | アカウントの構造をシンプルにして基礎的な機能を使いこなすことで、機械学習による最適化がかかりやすいアカウントの基礎土台を構築 |
| **2 最適入札** | 入札価格調整率または自動入札のご利用金額比率／自動入札ご利用金額比率 | 自動入札の利用によって、Yahoo! JAPANの膨大なデータをもとにさまざまなシグナルを参照しながら、自動かつリアルタイムで投資対効果の高い広告リクエストへの入札価格を最適化 |
| **3 効果効率** | リターゲティングご利用金額率／広告効果（CTR前週比が下がった広告の割合） | ユーザーの興味関心を捉え、購買意向の高いユーザーに対して確実に配信。効率的に顧客獲得することにより、クライアントのビジネスの土台を築く |
| **4 拡大成長** | 非リターゲティングご利用金額率／non_yj（提携パートナー面）ご利用金額率／インプレッションシェア損失率（ランク） | 変化を続けるインターネット上でのユーザー行動を捉えながら、将来の顧客となりうるユーザーへのリーチを拡げることで、継続的な顧客獲得とビジネス発展に寄与。ユーザーへの配慮や、プライバシー保護による広告配信影響の中でも配信の拡大を狙う |
| **5 最適表現** | レスポンシブ両サイズ&バナー300*250のご利用金額率／RAD（レスポンシブディスプレイ広告）ご利用金額率／動画のご利用金額率／広告の追加または更新の最終日／画像または動画の最終登録日 | ユーザーが求める情報に合致するクリエイティブを配信し、商品を効果的に訴求し、確実な誘導を狙う |
| **6 成果維持** | インプレッションシェア損失率（予算）／広告効果（CTR前週比が下がった広告の割合）／インプレッションシェア損失率（ランク）／広告の追加または更新の最終日／画像または動画の最終登録日 | 定期的に注視すべき重要指標をモニタリング・メンテナンスすることで継続的な顧客獲得とクライアントのビジネス成長に貢献 |

※non_yj：提携パートナー面
※RAD：レスポンシブディスプレイ広告

## 六連を進める上での重要な3つのポイント

```
1. 6つの要素を順番通りに進める
2. 変化するユーザーニーズに対応し最適化と最大化を定期的に繰り返す
3. 機能は組み合わせて活用する
```

## アカウント診断書

各パートの重要KPIの達成率、業種平均やより具体的なベンチマークとの比較を一目で把握できる診断書をヤフーが提供。

- アカウント情報（impressions/clicks/ご利用金額/conversions/ctr/cpc/cvr/cpa）
- スコア合計（100点満点）、アカウント評価（A〜E）
- 5: 100 / A: 90〜99 / B: 70〜99 / C: 50〜69 / D: 30〜49 / E: 29以下
- 各パート達成率（基盤整備100% / 最適入札100% / 拡大成長83% / 効果効率100% / 最適表現66% など）
- 業種平均との比較も可能

## So What — 戦略家視点での示唆

### 1. 「六連」はYahoo!広告版のロードマップフレームワーク

- 1〜6Stepの順番が重要 = 基盤を作らずに拡大しても効果は出ない
- → 新規クライアントオンボーディング時の「進捗管理表」として使える
- → 既存案件の「健康診断」として6Stepごとに採点できる

### 2. YSAとYDAで6つのパート構造は同じ／重要KPIだけ媒体特性に合わせる

- フレームワークの共通性が運用者にとっての学習コストを下げる
- 一方で、各StepのKPIは媒体固有（YSAはマッチタイプ・KW更新、YDAはランク損失・RAD等）
- → クライアントへの説明時、「Yahoo!の運用は媒体問わず6Stepで考えます」と伝えやすい

### 3. Phase1→Phase2→Phase3（六連）の系譜が示すYahoo!運用の進化

- Phase1: アカウント構造とKPI可視化（土台作り）
- Phase2: コンポーネント水準高度化（YDA運用型対応・自動入札深堀）
- Phase3 = 六連: リーチ拡大とメンテナンス
- → REHATCHでYahoo!運用始める際、案件の成熟度を「どのPhaseにいるか」で診断し、次のSTEPを設計できる

### 4. アカウント診断書を活用した改善提案

- ヤフー社が提供する診断書フォーマット（スコア100点満点）をクライアント提案時に使う
- 「現状スコア vs 業種平均 vs 上位ベンチマーク」の三角比較で、改善余地と優先度を可視化
- → 「なぜこの施策が必要か」のロジックを六連スコアの観点で説明できる

### 5. プライバシー保護対策の3階層は提案メニューに常備

- **1stPartyデータ活用** / **計測補完機能（CVマッチング・API・推定CV）** / **配信戦略設計**
- どの案件でも「これら3つにどう対応しているか」がチェックポイントになる
- 2024年Chrome 3rd party cookie廃止に向けて、対応していない案件は事前にロードマップ化する必要がある
