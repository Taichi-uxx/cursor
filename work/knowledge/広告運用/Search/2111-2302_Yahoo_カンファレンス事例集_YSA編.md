## Part 1：KW追加の方法論（2111ベース）

### キーワード追加の本質

> 本質は **既存と新規のクエリを意識しながら、価値のあるインプレッションの総面積を増やすこと**
> 多様化するクエリを捉え、ビジネス拡大の礎を築くとともに検索広告の新しいビジネス機会の創出を図る

「広告表示したクエリ数におけるImp数」の総面積を、以下2方向で拡大：
- 既存クエリからのIMP数を増やす
- 新しいクエリからのIMP数を増やす（**= キーワード追加**）

### ① ポテンシャルKW

#### 概要
自社アカウント/サイトや競合アカウント/サイトに流入したクエリーをすべて網羅し、差分クエリにCVの予測Scoreを付与（機械学習）し入稿に活用。

#### 4ステップ
1. 貴社と競合サイトに流入したクエリーをすべて網羅、未入稿のクエリーを抽出
2. 日々増える新しいクエリーを判定（先月検索流入がないもの）
3. 未入稿クエリに**予測Score**を付与（機械学習）
   - ※予測Score：明確なロジックはYahoo!独自ツールのため非公開。CVRを基に学習モデルを作成
4. 貴社のアカウント構造と入稿KWから**最適なキャンペーン/広告グループを提示**

#### 機械学習モデルの仕組み
1. クエリーを抽出
2. 品詞ごとに形態素解析
3. 検索クエリーを**200次元のベクトル**に変換し"意味"を数値化
4. ベクトルを特徴量、CVRを目的変数として学習モデル作成
5. クエリーをスコアリング（例: 沖縄SUP=0.95、北海道旅行=0.85、熱海天気=0.20）
6. 新規・推奨入稿アカウントをフラグ付け

#### アウトプット形式
- 入稿済みポテンシャルKWリスト
- 各KWに volume / ysa_coverage（0=なし,1=あり）/ pred_score（CVR推定値）/ pred_cv_volume / ss_cmpn_id / ss_ad_grp_id / cmpn_name / ad_grp_name を付与
- 太陽光発電・蓄電池業界の例：「ループ電気」「蓄電池 補助金 2021 国」など、IMPシェアの低いクエリを抽出

### ② 競合差分クエリ

#### 概要
自社と競合のアカウントにて、差分クエリをimp発生ベースで抽出。自社で拾えていないクエリを、競合のCVの有無や合算でのimp/クリックを可視化。

#### 出力例
- クエリ / 自社imp・click・cv / 競合click / 合算click / 前月差分 / 前年差分 / トークン数
- 「自社フラグ無し&競合CVフラグ有り」のクエリを参考にキーワード入稿

### ③ 除外KW（形態素解析）

#### 概要
クエリの形態素解析を用いた除外KW提案。
- リーチしているクエリを形態素解析し、形態素ごとの各指標を可視化
- 要素ごとの実績が可視化できるため、より適切な除外KW設定に繋がる

#### 出力例
形態素別に「ご利用金額」「CV」を見える化：
- 化粧品 1,511,417 / 78
- 代 1,022,577 / 39
- ランキング 657,374 / 31
- 50・40 など年齢系
- フォース 306,087 / 632（高CV、優良形態素）
- ライス 400,157 / 642
- コスメ・肌・スキンケア（CV少なめ）

## Part 2：YSA自動入札（t-ROAS）の運用ポイントと事例

### t-ROASとは

```
目標コンバージョン単価での売上最大化する入札戦略（自動入札）
```

#### 特徴
1. **広告の費用対効果の値を最大化**：価格帯や利益率が異なる複数のサービス・商品で、CVごとの価値の違いを考慮しながら全体価値を最大化
2. **設定した目標ROASを維持しながらCVを最大化**：目標CPAが異なるすべての商品・サービスでROASを最大化

#### メリット
1. **CVの価値を獲得できるよう自動調整**：機械学習で多様なシグナルを処理しCVの価値を獲得するよう入札価格を自動調整
2. **運用工数削減**：日予算を設定するだけで日々の入札調整工数が削減

### 仕様・実装の注意点

#### ① 媒体推奨CV数
- 直近30日以内に **50件以上** 発生しているキャンペーンを選択することが媒体推奨
- CV数が少ない場合は配信ボリュームの縮小や予測に十分な学習が集まらず、自動入札が上手く働かない可能性

#### ② 目標値の設定
- 設定した目標値が実態と乖離していないか実装時に確認
- 目標値が高すぎる・低すぎる場合は広告配信機会が制限される
- ROAS（広告費用対効果）の実態に即した目標値設定を推奨
- 変更時は **過去2週間の媒体ROAS ±20%以内** で設定

#### ③ 検証方法
- 自動入札では設定した目的に対して挙動が安定するまで一定の学習期間が必要
- ある程度の期間（**少なくとも1週間後**）を除外してパフォーマンス評価

### 3つの運用チェックポイント

#### ①CV数が直近30日以内に50件以上発生しているか？

> CVの先のユーザー行動（購買商品や申込商材など）を加味するため、他の自動入札タイプよりも多くのCV件数を確保して利用することを推奨

#### ②設定している目標値が実態と乖離していないか？
> 目標値が高すぎる場合や低すぎる場合、広告配信機会が制限されるため、ROASの実態に即した目標値設定を推奨

#### ③自動入札の設定直後にパフォーマンス評価していないか？
> 自動入札は設定した目的に対してシステムが安定的な効果を発揮するまでに一定の学習期間が必要。学習期間中は広告の配信結果に変動が発生するため、設定からある程度の期間をおいてパフォーマンスを評価

### CV数が少ない場合の対策案

| 対策 | 内容 |
|---|---|
| **CP/ADG統合** | 類似する訴求のCP/ADGを統合して1CPあたりのCV数を増やす（例: CP-A 30件 + CP-B 20件 → CP-C 50件） |
| **自動入札「CV数最大化」の利用** | CV数増加後に「広告費用対効果の目標値」へ切替 |
| **マイクロCVの設置** | カートページ等の実際のCVに近いポイントに設定 |
| **オフラインCVのインポート** | サイト外で発生したCVデータを連携 |

### t-ROAS事例集（2111〜2302）

#### 事例①：ファッションECサイト（CV50件設定）
- **結果**: ROAS目標達成しながらCV価値・CV数を大きく増加に成功
- ROAS目標達成率: 設定前29% → 設定後 312% → 242%
- CV数: 100% → 500% → 567%
- 設定1週間は目標値から上振れ、その後学習進み徐々に目標値を目指す動き

#### 事例①(2)：ファッションECサイト（CV10件設定 = 推奨未満）
- **結果**: ROAS・CV価値の向上は見られたが**配信ボリュームが大幅縮小**
- 配信量担保しながら成果向上には**CV数確保できているCPでの設定を推奨**

#### 事例②：高額商材の情報ポータルサイト（目標実態と近い）
- **結果**: 配信機会を活かしながらCV価値とCV数の改善に成功
- 改善を受けてさらに配信ボリューム拡大のためキャンペーン予算増額
- 予算増額後も目標値を捉えながらCV価値・CV数を大きく伸ばす

#### 事例②(2)：不動産関連産業（実態より高い目標値）
- **結果**: 日数経過しても挙動安定せず、1週間以降で配信量・CV数の減少傾向
- 大幅に高い目標値を設定 → 本来の配信機会を活かしきれない要因
- **ROASの実態に近い目標値を設定して運用することを推奨**

#### 事例③：日用品ECサイト（設定後の時間経過）
- **結果**: 設定から1週間は自動入札の学習期間でCost縮小したが、2週間以上経過で**学習が進行**し目標値に近いROASを維持しながら配信ボリュームを拡大できた
- ROAS目標達成率: 設定前55% → 100% → 142% → 93%
- CV数: 100% → 113% → 196% → 196%

#### 事例（病院・医療施設業界）
- 入札戦略のみ異なるキャンペーンを、手動or自動入札(YSA_tCPA) vs 自動入札(YSA_tROAS)で前後で成果検証
- コントロール（Google）では後期間でコスト増加しCPC上昇・売上単価減少でROAS低下
- Yahoo!でも後期間でコスト増加したが**ROAS横ばいのまま売上増加**しており、tROAS切替による改善と判断
- 高売上単価のPCデバイスへのシェア上昇が改善要因として考えられる
- 同一コストでの比較ではYSA改善率118.45% / GAW改善率98.11% → **YSA÷GAW=121%**

#### 事例（不動産業界）
- **結果**: 入札戦略をtROASに切り替えたことで、資料獲得数が多く取れるカテゴリにコストが寄る動きが見られ改善
- YSA改善率135% / GAW改善率62% → **YSA÷GAW=216%**
- 9月配信結果で広告グループ別を見ると、ROASの高いカテゴリにコストシェアが寄せられている
- CV数が少ない案件でもROASの高いカテゴリに寄せられている → 30日でCV50件以上の条件をクリアしている案件であればさらに精度高い最適化が想定される

#### 事例（遊び体験業界）
- **結果**: tROAS入札に変更により、媒体計測売上・クライアント計測売上ともに減少（成果悪化）
- カテゴリ・デバイス・マッチタイプなどのシェアはほぼ変動なく、**高単価ジャンルのCV増加**
- 高単価ジャンルは高CPC・低CVRの傾向 → 獲得売上の単価は上昇したものの、CPC・CVR悪化が影響しCV数減少
- 結果、最終的な売上総額も減少

#### 事例①：資格業界
- **結果**: コントロール（Google）では後期間でコスト増加に伴い獲得増加、商品単価も上昇
- 一方Yahoo!では入札戦略変更後、商品単価の高い商材に配信が寄ったものの、**CVRの悪化により獲得が減少しROAS低下**
- DAS（動的検索連動型広告）と一般メニュー別で比較すると、DASは高単価商材に寄った傾向、一般はCPC・CVR悪化でCV減少
- tROAS推奨件数（30日間でCV50件以上）を満たしていないことが影響している可能性
- Googleでも DSAで売上増加・ROAS上昇が見られ、改善幅大きく**レバー数の多いDSAの方が上手くワーク**する可能性

#### 事例②：アパレル業界
- **結果**: 売上単価上昇、CVR上昇によりROAS改善
- コントロール（Google）の同期間と比較すると改善幅自体はYahoo!の方が大きい
- **高単価のSPデバイスの配信シェア上昇が改善要因**として考えられる
- YSA改善率226% / GAW改善率202% → **YSA÷GAW=112%**
- デバイス別配信シェア比較：SPへのシェア上昇、PCとSPの単価比較するとtROAS切替前もSPの方がROAS高い傾向 → 自動入札切替でコスト減少に対しCVR上昇・獲得増加・CPA低減でROAS上昇

### t-ROAS検証結果まとめ

#### 改善傾向

- アカウント内の商材で**商品単価の幅があまりない**、また**季節トレンドが変化しない案件**に関しては比較的成果改善傾向

#### 悪化傾向

- アカウント内で商材に**複数の季節トレンドがある**、また**商品単価の幅が広い（数百円〜数万円）案件**では、季節トレンドは加味せず高単価商材に配信を寄せた挙動が見られ成果悪化傾向

#### 検証結果の要点

> 季節トレンドは加味せず、商品単価が高いデバイス別やカテゴリ別間にて、入札価格が自動的に調整され、コストシェアの変動が見られる。

## So What — 戦略家視点での示唆

### 1. tROASは「適性案件の見極め」が9割

- **適合する案件**: 商品単価の幅が狭い / 季節トレンドが変化しない / 30日でCV50件以上確保
- **不適合な案件**: 単価幅広い（数百円〜数万円）/ 複数の季節トレンドあり / CV少ない
- → クライアントへの提案時は、これらの条件チェックを先に行い、合わない案件には**他の入札戦略を提案**する。トライアル前のスクリーニングが工数削減につながる。

### 2. 「CV50件/30日」の条件は絶対視せず、対策で繋ぐ

- CP/ADG統合 → mCV → CV最大化への変更 → ROAS目標値への切替、というステップを設計しておく。
- CV不足はtROAS不可ではなく、「条件を作るアクションが先」と捉える。

### 3. KW追加の打ち手は「ポテンシャル × 競合差分 × 除外形態素」の3点セット

- ポテンシャル = 自社未入稿の機会クエリ
- 競合差分 = 自社が拾えていない競合の収益クエリ
- 除外形態素 = 既存リーチからのノイズ排除
- → 拡大方向（追加）と精査方向（除外）を同時に進めることで、価値あるIMPの総面積を最大化できる。

### 4. 不動産業界で再現した「資料数」というカテゴリ別最適化

- tROAS切替時、不動産業界で「ROAS高いカテゴリにコストシェア寄せ」の挙動が確認された
- → CV少なくても、目標達成しやすいカテゴリへ最適化が効くので、提案時に「カテゴリ別ROAS差」を可視化することが説得材料になる

### 5. YSAでのROAS最大化は「面の確保 × デバイスシェア」の連動

- アパレル業界・医療業界の事例から、**売上単価の高いデバイス（SP/PC）へのシェア変動**がROAS改善の主要因
- → 単純な入札戦略変更ではなく、デバイス別の単価・CVR・ROASを事前に分析しておくと、tROAS切替後の挙動予測ができる
