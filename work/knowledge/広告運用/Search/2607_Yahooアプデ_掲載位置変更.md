# LINEヤフー検索広告 — 掲載位置変更（ページ中間にも表示可能に）

## 出典

- 発信元: LINEヤフー株式会社 公式ニュース（LINEヤフー広告）
- 公開日: 2026年7月1日 / 更新日: 2026年7月15日
- 適用開始: 2026年7月15日（水）より順次
- URL: https://www.lycbiz.com/jp/news/ly-ads/20260701/

## 用途

- Yahoo検索広告の運用中案件で、7月中旬以降の指標変動を見たときの背景理解として使う
- クリエイティブ制作方針を「上部前提」から「中間掲載を織り込んだ設計」へ切り替える判断材料
- 競合が強くて上部を取りに行きづらい案件で、あえて中間掲載を狙う戦略の根拠として使う
- imp・クリックが増加傾向という前提を踏まえた予算・CPA目標のリセット議論に使う

## アップデート内容

- **対象**: LINEヤフー広告 検索広告 / 全デバイス
- **変更内容**:
  - 検索結果ページに掲載される検索広告の表示位置が変更
  - 「ページ上部を除き、検索ユーザーの利用状況に応じて最適な場所に広告を表示」
  - ページ上部への掲載は従前通り
- **意図**: 検索広告の効果の向上

### 注意事項（媒体側の告知）

- 配信傾向が変わる可能性がある
- **インプレッション数、クリック数が増加する傾向** がある
- 広告主に対し、各指標の確認を促している

## 太一の解釈・クリエイティブ設計への示唆

**上部だけでなく「ページ中間」に広告が挟まる場合、ユーザーの視界に入る文脈が変わる。**

- ページ上部 = 「広告」として意識されて見られる位置
- ページ中間 = オーガニック検索結果に混ざって、記事として読まれる位置

このため、**中間表示を前提とするなら、オーガニックの検索結果と同じ「記事っぽい見出し」と、それに合うLP** のほうが好相性の可能性が高い。

具体的には:

- **競合が強くて上部を安定的に取りに行きづらい案件** → 上部争いを諦めて、中間表示に最適化した「記事型」クリエイティブに寄せる
- **タイトル・ディスクリプション** = プロモ表現を減らし、オーガニック記事タイトルに近い自然な見出し
- **LP** = ゴリゴリの販促LPではなく、記事LP・比較記事・お役立ちコンテンツ型が中間表示と噛み合う可能性
- imp / クリックが増える前提 → **クリック単価は下がっても、CVRが低下する懸念** も抱いておく（中間表示のクリックは購買意欲がまだ浅い可能性）

### 運用時の観察ポイント

- [ ] 7/15以降、Yahoo検索広告のimp・クリックが増えたか確認する
- [ ] クリック増加分がCVにつながっているか、CVRの変化をチェックする
- [ ] 掲載位置レポート（あれば）で、上部/中間の比率とそれぞれのCPA/CVRを分解する
- [ ] 中間掲載の比率が高くなっている案件は、記事型クリエイティブ／記事LPのA/Bを検討する
