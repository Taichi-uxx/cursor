# TikTok運用型広告クリエイティブTips 〜クリエイター活用編〜

## 出典

- 元ファイル：TikTok運用型広告クリエイティブTips 〜クリエイター活用編〜_202110_final+.pdf（全14ページ）
- 発行：**TikTok for Business**（2021年10月）
- 分析対象：
  - 期間：2019年12月22日〜2021年5月18日の日本でのTikTokクリエイター起用実績のあるクライアントの運用型広告
  - 協力代理店：**TORIHADA様／スターミュージック・エンタテインメント様／Natee様**
  - 条件：oCPC・oCPM入札、10,000imp以上
  - 計**166素材**を最終的な分析対象

## 用途

- TikTok新規案件で**クリエイター起用を提案する根拠**として
- 既存案件で**非クリエイター素材中心になっている**場合に、クリエイター起用追加の提案
- **どんなクリエイター制作素材が成果に効くか**（語りかけ・UGCテキスト・インサートカット）の理解
- パフォーマンス型広告制作の**おすすめMCN紹介**（Natee／TORIHADA／スタークリエーション）

## 分析対象クリエイターのジャンル

- 非クリエイター起用：56%（全体の半分強）
- **コメディ系：30%**（クリエイター内では最多）
- 共感ネタ：4%
- ダンス：5%
- 日常：3%
- トランジション：2%

→ コメディ系クリエイターが最も活用されている。

## 1. パフォーマンスの高いクリエイティブの特徴

### A. クリエイターを起用した素材自体の効果

クリエイターを起用した素材は、非起用の素材に比べて：
- **CVRが約140%（10.63% vs 7.60%）**
- **6秒視聴率が約124%（14.15% vs 11.43%）**

→ **クリエイター起用するだけで成果向上**。

### B. クリエイターが「語りかける」と効く

クリエイターが話している広告は、話しかけていない広告に比べて：
- **CVRが約157%（11.15% vs 7.12%）**
- **6秒視聴率が約119%（14.06% vs 11.77%）**

※ クリエイターのセリフではなく、後から入れたナレーション素材は「話しかけなし」に分類。

→ **クリエイター本人が話す**ことが重要。後付けのアフレコでは効果が落ちる。

### C. UGCライクなテキストを入れる

TikTokのオーガニック投稿に即した**フォントのテキスト**がある素材は、そうでない素材に比べて：
- **CVRが約141%（10.02% vs 7.09%）**
- **6秒視聴率が約129%（13.62% vs 10.52%）**

※ テキストそのものが入ってない素材や、TikTokライクではないテキスト（文字が動くなど）は「テキストなし」に分類。

→ **静的なUGC風テキスト**（動くテキストではない）が効果的。

### D. 商品/サービスのインサートカットを入れる

クリエイター起用動画に商品やサービスのインサートが入っている素材は、そうでない素材に比べて：
- **CVRが約213%（13.75% vs 6.46%）**
- **6秒視聴率が125%（15.65% vs 12.89%）**
- **CTRが166%高い**

→ **クリエイター動画＋商品インサートの組合せが最強**。CVR2倍以上のインパクト。

### E. クリエイター起用の広告は「長く使える」

| 種類 | 一本あたりの連続出稿日数 |
|---|---|
| **TikTokクリエイター起用広告** | **50日** |
| 非クリエイター起用広告 | 33日 |

→ クリエイター起用広告は**約152%長く使える**（摩耗しにくい）。
※ 1日10,000impression以上出稿した日数でカウント。

### F. フォロワー数と広告効果に相関は見られなかった

クリエイターのフォロワー数別CVR・6秒視聴率：

| フォロワー帯 | CVR | 6s視聴率 |
|---|---|---|
| 8万以下 | 15.43% | 16.28% |
| 8万〜30万台 | 7.44% | 14.36% |
| 40万〜60万台 | 12.67% | 14.54% |
| 70万〜 | 6.64% | 12.30% |

→ **起用したクリエイターのフォロワー数と広告の効果には相関関係は見られない**。フォロワー数が多いトップクリエイター起用＝高成果とは限らない。

## 太一向け次アクション視点

### 既存TikTok案件で確認すること
- [ ] **クリエイター起用素材**が含まれているか（非クリエイター素材のみで配信していないか）
- [ ] クリエイターが**実際に話している**動画になっているか（アフレコのみではないか）
- [ ] **UGCライクな静的テキスト**が入っているか（動くテキスト・派手なテロップになっていないか）
- [ ] クリエイター動画に**商品/サービスのインサートカット**が入っているか
- [ ] **トップフォロワークリエイター起用**にこだわっていないか（中堅クリエイターでも効果同等）

### 新規TikTok案件 CR制作ブリーフテンプレ（クリエイター活用）

```
【起用クリエイター】
- ジャンル：コメディ系優先（最も使われている）／日常／共感ネタ
- フォロワー数：8万〜30万台でも可（トップクリエイターである必要なし）
- 制作実績：Natee / TORIHADA / スタークリエーション など

【動画構成】
- クリエイター本人が話す（後付けナレーションは効果落ちる）
- UGCライクな静的テキストを入れる
- 商品/サービスのインサートカット必須（CVR2倍以上）
- 6秒視聴率を高める設計（冒頭は人・ストーリー）

【期待効果】
- CVR約140%（クリエイター起用効果）
- 連続出稿日数 約152%長い（摩耗しにくい→制作コストROI高い）
```

### クライアント提案フレーズ
- **「クリエイター起用素材はCVR約140%・6秒視聴率約124%」**（基本効果）
- **「クリエイターが話している＋商品インサート」**でCVR約213%
- **「クリエイター起用は1本あたりの寿命が50日（非起用33日比152%）」** → **制作コスト回収率も高い**
- **「フォロワー数と効果に相関なし」** → 中堅クリエイターでコスト最適化提案

### Meta系との大きな違い
| 項目 | Meta | **TikTok** |
|---|---|---|
| クリエイター起用効果 | UGC風がベター（傾向）| **本人が話している動画**がCVR約157% |
| テキスト | テキスト20%未満推奨 | **UGCライクな静的テキスト**を入れる |
| インサートカット | — | **商品インサートカットでCVR約213%** |
| 起用すべきフォロワー数 | 「インフルエンサー」前提 | **フォロワー数と効果に相関なし**（中堅で十分）|
