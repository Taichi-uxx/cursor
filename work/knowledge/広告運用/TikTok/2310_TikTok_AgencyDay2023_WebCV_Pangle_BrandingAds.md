## 2. Web Conversion（ウェブコンバージョン）

### 2-1. シグナル基盤の構築：3つの利点

| 利点 | 内容 |
|---|---|
| **ターゲティング** | サイト訪問者・アプリ内イベントから**カスタムオーディエンス**作成／類似オーディエンス展開 |
| **最適化** | 「カートに追加」「ページ閲覧」「購入」イベントで最適化目標を設定→**コンバージョン可能性の高いオーディエンス**へ |
| **測定** | 一連のCVイベントで広告パフォーマンス＆**ROAS**を測定 |

### 2-2. シグナル設定の3点セット（最優先ステップ）

| 設定 | 効果 |
|---|---|
| **3つ以上のピクセルイベント** | **CV上昇** |
| **自動アドバンスドマッチング** | **CPA削減** |
| **1stパーティCookie** | **CV上昇** |

#### Pro Tip：ピクセル設定の即時化
- TikTok eコマースパートナープラットフォーム（Shopify／BigCommerce／Ecwid／WooCommerce／Prestashop／Square等）では**ワンクリックでピクセル設定可能**

### 2-3. 3つ以上のイベント（ファネル網羅）

```
UPPER FUNNEL：View Content（コンテンツ表示）→ 訪問者の興味をTikTokに伝える
MID FUNNEL：Add to Cart（カートに追加）→ CVへの意図を確立
LOWER FUNNEL：Complete Payment（支払い完了）→ 最重要アクションをTikTokに伝える
```

**3つ以上のイベント**：
1. コンテンツの表示
2. カートに追加
3. 支払い完了

### 2-4. 自動アドバンスドマッチング
- ピクセルが自動的にサイトをスキャンし**メール/電話番号**を収集（SHA-256ハッシュ化、コーディング不要、1クリック実装）
- TikTokユーザーのメールアドレスと**マッチング**してCVを広告に紐付け

#### マッチングの仕組み（例）
- ✅ TikTokメール`anh@gmail.com` ≒ サイトCVメール`anh@gmail.com` → マッチ
- ❌ TikTokメール`anh@gmail.com` ≠ サイトCVメール`anh123@gmail.com` → マッチなし

### 2-5. 1stパーティCookie
- アドバンスドマッチング＋Cookie併用で、サイト訪問者とTikTokユーザーの**マッチング率向上**
- 出典：TikTok Internal Data Analysis, May 2022

---

### 2-6. カスタムオーディエンスと類似オーディエンス（優先順位）

```
[見込み客を幅広く設定]
   ↓ カスタムオーディエンス
   ├ プラットフォームオーディエンス（エンゲージメント／ビジネスアカウントオーディエンス）
   └ ファーストパーティオーディエンス（サイトトラフィック／カスタマーファイル）
[広告パフォーマンスを向上させる]
   ↓ リターゲティング
[広告の関連性を向上させる]
   ↓ 類似オーディエンス
[広告配信を最適化する]
   ↓ 除外
```

#### 各ステップの推奨アクション
| ステップ | 推奨 |
|---|---|
| パフォーマンス向上（リターゲティング）| 1. TikTokプラットフォームオーディエンスから開始 → 2. ファーストパーティオーディエンスへ移行 |
| 関連性向上（類似）| 複数のカスタムオーディエンスから最も効果が高いものを使い、類似を作成。狭い/ノーマル/広いの3種を検証 |
| 配信最適化（除外）| 1. サイトトラフィックオーディエンスを除外 2. カスタマーファイルを除外 |

#### 事例：株式会社Techouse（求人サイト）
- カスタム/類似活用で **CVR 19%、クリック1,500超**

### 2-7. カルーセル広告

- **2〜34種類**の画像を順番にアップロードできる画像ベースクリエイティブ
- スワイプで切り替え、ユーザーが自分のペースで閲覧
- アスペクト比1:1の画像をJPEG/PNG形式でアップロード

#### ベスプラ
- 1つのカルーセル広告につき**6〜9枚**の画像
- 画像内テキストは長くなりすぎないように
- すべての画像でアスペクト比を揃える

#### 活用シーン
- 動画素材は限られているが広告予算はある
- TikTokで再利用したい高パフォーマンス静止画クリエイティブがある
- 動画クリエイティブよりも静止画制作が得意
- キャンペーンのCTRを向上させたい

- マンガ：comico、ピッコマ、マンガBANG、マンガMee

|---|---|

## 4. Branding Ads + BLS（ブランディング広告）

### 4-1. 広告の入り方（TikTok本体）

```
[アプリ起動]
   ↓
[TopView]（アプリ起動枠）
   ↓
[オーガニック投稿]（1-3枠目）
   ↓
[Reach & Frequency Top Feed]（4枠目）
   ↓
[Reach & Frequency Standard Feed / オークション広告]（4枠目以降ランダム）
```

### 4-2. 広告ソリューションマップ

| 利用シーン | メニュー | キャンペーン目的 | 課金形式 | プレースメント | BLS |
|---|---|---|---|---|---|
| 1日〜数日間で大型リーチ | **TopView** | - | CPM | TikTok | 可能 |
| 確実にリーチ達成 | **Reach & Frequency** | リーチ | 事前買付固定CPM | TikTok | 可能 |
| ブランディング目的で効率配信 | **Brand Auction** | リーチ/動画視聴数 | CPM / 6s Focused View | TikTok | 可能 |
| Spark Ads Only / フォロー | コミュニティインタラクション | フォロー/プロフィール訪問 | oCPM/CPC | TikTok | 不可 |
| サイトやアプリ誘導 | トラフィック | クリック/LP閲覧 | CPC/oCPM | TikTok / Pangle | 不可 |
| 見込み客情報取得 | リード生成 | リード | oCPM | TikTok | 不可 |
| アプリインストール | アプリプロモーション | - | oCPM/CPC | TikTok / Pangle | 不可 |
| サイトCV増加 | ウェブサイトのコンバージョン数 | - | oCPM/CPC | TikTok / Pangle | 不可 |
| 商品販売 | 商品販売 | - | - | TikTok | 不可 |

---

### 4-3. TopView

#### 特徴
- **最もインパクト高い枠**（アプリ起動直後3秒、3秒以降インフィード化）
- CPM形式の購入、在庫に応じ**100%買い切り可**
- TopView出稿データを通常配信に活用可
- ターゲティング利用可

#### 出稿規定
| 項目 | All targeting | Targetingあり |
|---|---|---|
| 最低出稿金額 | **グロス500万円/日〜** | 同左 |
| 課金 | CPM | CPM |
| CPM | 1,000円 | 1,250円 |
| 素材 | MP4/MPEG/3GP/AVI/MOV、500MB以内、推奨9-15秒、解像度9:16・540×960px以上、ビットレート2,500kbps以上 | 同左 |
| 種類 | Diversion / Spark Ads | 同左 |

#### 注意事項
- 提案前に担当へ実施可否確認
- **APA契約＋マージン契約（マージン率15%）**必要（2〜3週間）
- 発注は**キャンペーン開始20営業日前**まで
- クリエイティブ事前審査：**15営業日前**まで
- 支払い：請求書（後払い/支払いサイト30日）のみ

#### 最適フリークエンシー
| Impression購入% | 平均FQ | リーチ |
|---|---|---|
| 25% | 1.2 | 低 |
| 50% | 1.7 | 中 |
| **75% (黄金ゾーン)** | **2.2** | 高 |
| 100% | 2.7 | 最大 |

→ **最適FQは2〜3**。Imp 20%超えるとリーチは緩やかに上昇。
**広告想起の向上＝より多くのImp＝平均FQ増加**。

---

### 4-4. Reach & Frequency（R&F）

#### 特徴
- 2種類のフィードタイプ（**Top Feed / Standard Feed**）
- リーチとFQに最適化
- 事前在庫予約可
- TikTok広告マネージャーからCPM買付（CPM課金）
- **横型素材で入稿可**
- ターゲティング利用可

#### Top Feedの特徴
- 最もリッチなインフィード広告枠
- 通常インフィード比 **CTR +2% / Engagement +8% / VTR +5%**
- 横型素材でもOK（背景に静止画はめ込み）
- **アルコール商材等TopView NG業種も配信可**

#### R&F ベスプラ4つ

**① 早期在庫確保＆ブロードターゲティング**
- 早く在庫予約完了 → 低CPMになる傾向
- 在庫は**225日前**から予約可能
- 広いターゲティングで通常低CPMに

**② 週FQ3回を目指す**
- 週3回FQが高パフォーマンス&CPM上昇防止
- BLSリフトインパクト：
  - 2回/週：Ad recall 90% / Awareness 80% / Intent 65%
  - **3回/週：Ad recall 95% / Awareness 90% / Intent 85%**

**③ 最低50%のターゲットユーザーにリーチ**
- リーチ率50%超で**広告認知リフトが大きく高まる（〜1.3X）**
- 管理画面で「Reach Percent: 50.00%」設定

**④ キャンペーン期間3週間以上で設定**
- 3週間以上で**広告認知リフト〜1.2X**
- R&Fでは**最長90日**設定可
- キャンペーン期間が長いほど**CPM約-12%**

#### 注意事項
- 提案前に担当へ実施可否確認
- 最低出稿量：**1広告セットあたり10万リーチ以上**（最大配信期間90日）
- キャンペーン開始後の**配信変更不可**（コメントステータス変更／CR追加は可能）
- 動画CR審査：**キャンペーン3営業日前**まで入稿
- 支払い：請求書（後払い30日）または手動支払いのみ

#### TopView + R&Fでリーチ拡大（アジアテスト）
- **TopViewがリーチを+40%拡大**
- TopView単体：リーチ中央値75% / R&F単体：リーチ中央値60%
- 重複リーチ中央値：35%
- 広告想起：TopView単体 7.5 / R&F単体 8.4 / **TopView+R&F 9.0（+20% / +7%）**

### 4-5. Brand Auction

#### 特徴
- ブランディング目的に合わせて効率配信
- キャンペーン目的：**リーチ / 動画視聴数**
- 課金：CPM / **6s Focused View**
- 配信面：TikTok

#### Focused View課金とは
- **動画視聴**：6秒以上視聴する可能性の高いユーザーをターゲット
- **エンゲージメント**：広告にエンゲージする可能性高いユーザーをターゲット

---

### 4-6. R&F vs Brand Auction 比較

| 項目 | Reach & Frequency | Brand Auction |
|---|---|---|
| キャンペーン目的 | リーチ（FQ設定可）のみ | リーチ（FQ設定可）/動画視聴数 |
| 課金形態 | 事前買付（予約時固定CPM）| 各目的に応じたオークション課金 |
| 配信面 | TikTokのみ・2フィード選択 | TikTokのみ |

#### メリット/注意点

| | R&F | Brand Auction |
|---|---|---|
| メリット | Top FeedはStandard/BAより効果良／事前買付で**未消化リスク少** | 柔軟に調整可／R&F比**CPMが安価傾向**／リーチ以外の目的最適化可 |
| 注意点 | 配信時間固定／開始後配信内容変更不可（CR追加は可）| 運用型ためCPM変動などSIMとの乖離可能性 |

#### Pixel計測対応
- **R&F・Brand AuctionでもPixel利用可**になった
- 「広告」セクションで誘導先ページON →「トラッキング」でウェブトラッキングを選択
- ※計測（Webのみ）は可能。ピクセルによる配信最適化はかからない／App計測は現状不可

### 4-7. Branding Ads まとめ：求めることと最適メニュー

| 求めること | 最も適したメニュー |
|---|---|
| プレミアムプレースメント／高Impボリューム | **TopView** |
| プレミアムプレースメント／管理されたR&F | **Reach & Frequency Top Feed** |
| より効率的なCPM／管理されたR&F | **Reach & Frequency Standard Feed** |
| 最も効率的なCPM／高度なターゲティングと柔軟性 | **Brand Auction** |

## 5. Brand Lift Study（BLS）

### 5-1. BLSとは
TikTok広告がブランド指標に与える影響を測定。露出量・視聴数などのパフォーマンス指標に加え、CR・プランニングの**成功ポイント・改善ポイント分析**材料として活用。

### 5-2. 調査項目（10種）
| 項目 | 質問例 |
|---|---|
| **広告認知（必須）** | 過去2日間にTikTokで[ブランド/商品]のプロモーションコンテンツを見たことがありますか? |
| ブランド認知 | [ブランド/商品]を見たり聞いたりしたことありますか? |
| キーワード想起 | 下記内容を聞いた時、[ブランド/商品]が最も思い浮かびますか? |
| ブランド想起 | [メッセージ]と聞いて一番思い浮かべるブランドは? |
| 理解 | [ブランド/商品]についてどのくらい知っていますか? |
| 態度 | [ブランド/商品]の[機能特性]への評価は? |
| 好意度 | [ブランド/商品]をどの程度好きですか? |
| 意向 | [ブランド/商品]を[期間]で[行為する]可能性は? |
| 嗜好 | 下記の中で最も好きな[ブランド/商品]を1つ選んでください |
| レコメンデーション | [ブランド/商品]を他の人にお勧めしたいですか? |

※リーチ数に応じて最大合計4問まで選択可

### 5-3. BLS条件

| フォーマット | 形式 | 設問数 / 出稿金額 / 必要リーチ数 |
|---|---|---|
| **TopView** | TikTok BLS アンケート | 3問: 500万(G)/350万リーチ／4問: 1000万(G)/520万リーチ |
