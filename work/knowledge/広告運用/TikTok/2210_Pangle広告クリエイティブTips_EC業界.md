# Pangle広告クリエイティブTips 〜EC業界〜

## 出典

- 元ファイル：PangleクリエイティブTips+〜EC業界〜_0916.pdf（全78ページ・ファイル名"0916"だが内容は2022年10月版）
- 発行：**TikTok for Business**（Oct. 2022）
- 分析対象：
  - 期間：2022年1月9日〜2022年7月9日 の日本Pangleにおける**EC業界**（Chemicals & Energy / Clothing & Accessories / Fast-Moving Consumer Goods / Healthcare & Pharmaceuticals / Retail & E-commerce）の画像広告・動画広告
  - 画像広告：impression 5,000以上、CV>0
  - 動画広告：impression 100,000以上、CV>20
  - LPのpre-loading機能を使用しないクライアントを除外
  - 画像広告 計**118素材**、動画広告 計**433素材**

## 用途

- **Pangle面**（TikTok外のアプリ面ネットワーク）への配信を提案／配信中の案件で、CR制作の指針として参照
- 美容・健康食品・ヘアケア・スキンケア・FMCGなどEC系商材のPangle向け広告CR制作時
- TikTok本体面とは異なる「Pangle固有」のCR傾向を把握したいとき
- 画像広告（118素材）と動画広告（433素材）それぞれの効くポイントを区別したいとき

---

## 基礎相関データ（前提）

### 6秒視聴率とCTRの相関
- 相関係数：**0.38**（やや相関）
- **6秒視聴が高ければCTRも高い傾向**

### CTRとCPAの相関
- 相関係数：**-0.25**（負の相関）
- **CTRが高ければCPAは低い傾向** → CTR改善＝CPA改善に効く

→ Pangle案件改善の起点は**CTR**を上げにいくこと。

## #1 CTRが高い画像クリエイティブの特徴（N=118）

### 1-1. 人物に関する発見

| 要素 | CTR効果 |
|---|---|
| **人物あり** | **133% UP** |

→ 画像広告に**人を入れる**のは効果的。

### 1-2. 商品に関する発見

| 要素 | CTR効果 |
|---|---|
| **商品要素あり**（広告の98%） | （前提・必須）|
| **商品使用シーンなし** | **119% UP** |
| **商品の手持ちなし** | **110% UP** |

→ Pangle画像は **「商品を堂々と見せる」が正解**。使用シーン・手持ち演出はむしろ逆効果。

### 1-3. 画像デザインに関する発見

| 要素 | CTR効果 |
|---|---|
| **アスペクト比：スクエア型** | **191% UP**（縦・横より圧倒的）|
| **商品本体が画像半分以上を占めない**（パッケージ・文字・人で半分以上） | **194% UP** |

→ Pangleはスクエア最強。商品本体ドーンではなく、**パッケージ・テキスト・人で画面を構成**する。

### 1-4. 内容表現に関する発見

| 要素 | CTR効果 |
|---|---|
| **値段表示あり** | **127% UP** |
| **広告ターゲットへの呼びかけ**（「〇〇に困ってる人」「五十代の人必見」など）| **145% UP** |
| **権威的な表現あり**（受賞歴／売上／満足度／使用者数／製薬会社が作った）※第三者調査明記必須| **200% UP** |
| **「お詫び」表現あり**（「すでに購入の方すみません」等の値下げ前置き）| **141% UP** |

#### キャンペーン内容（実施広告のうち）
| キャンペーン内容 | CTR効果 |
|---|---|
| **値下げ** | **111% UP** |
| **1回限定** | 110%程度 |
| キャンペーンなし | 中位 |
| 初回限定 | 低い |
| お試し | 最も低い |

→ Pangle画像広告では **「値下げ」「1回限定」が効く**。「お試し」「初回限定」はあまり効かない。

#### キャッチコピーのキーワード
| キャッチコピー軸 | CTR効果 |
|---|---|
| **お詫び** | **157% UP** |
| **商品機能** | 約150%級 |
| **権威アピール** | 約140%級 |
| **無料** | 約130%級 |
| 限定情報 | 中位（下） |
| 定期ではない | 最低 |

→ キャッチコピーは **「お詫び／商品機能／権威／無料」** を印象付けると効く。

### 1-5. 商品種別

CTRが高い順：
1. **健康食品**（最高）
2. 飲料
3. ヘアケア
4. スキンケア

→ Pangle画像広告では**健康食品が断トツCTR高い**。

### Pangle画像広告のDEMO（医薬部外品仮想例）
1. 「すでにご購入の方すみません」＋「キレイサポートセット 1500円→**500円**」＋人物＋No.1表記
2. 「ニキビに困ってるあなたへ」＋人物＋商品パッケージ＋「サンプル7日分**無料**プレゼント」
3. 「ニキビに困っているあなた 遅くなってしまいすみません」＋「10万人のキレイサポートに役立ったニキケア化粧水」＋「1回限定価格 送料無料 **500円**」

## #2 CTRが高い動画クリエイティブの特徴（N=433）

### 全体構造（時間軸別フレーム）

| 0〜2秒以内 | 3〜6秒 | 7〜15秒 | CTA |
|---|---|---|---|
| 商品要素＆値段／キャンペーン情報を紹介 | 商品使用シーン／ターゲットへの呼びかけ／ベネフィット | ベネフィット紹介／安心させるメッセージ | 「気になる系」「アンケート系」「早く系」 |
| 共通：15秒尺／1カット2秒台／動画画像組合せしない／BGMあり／ナレーション関係なし |
| 共通：人物の有無は関係なし、**有名人起用が効果的** |
| 共通：権威アピール／「お詫び」／商品効果を感情的に表現 |
| 共通：動画全体の感情表現はネガからポジに |

### 2-1. 動画尺・カット・音声に関する発見

| 要素 | CTR効果 |
|---|---|
| **動画尺15秒以内**（0〜15秒）| **122% UP** |
| **1カット2秒台**（短すぎず・長すぎず）| **109% UP** |
| **アスペクト比** | **関係なし**（縦・スクエア差なし）|
| **動画画像組み合わせしない**（動画のみ or 画像スライドのみ）| **127% UP** |
| **BGMあり** | **114% UP** |
| **ナレーション** | **関係なし**（あってもなくてもCTRに大差なし）|

→ Pangle動画は **「15秒・2秒カット・BGMあり・組合せなし」** が黄金型。ナレーションは不要。

### 2-2. 人物に関する発見

| 要素 | CTR効果 |
|---|---|
| **人物の有無** | 関係なし |
| **有名人起用あり** | **109% UP** |

→ 一般人より**有名人を使うほうが効く**。一般人を使うだけではCTRには効かない。

### 2-3. 商品に関する発見

| 要素 | CTR効果 |
|---|---|
| **6秒以内に商品要素を入れる** | **116% UP**（7秒以降より）|
| **3〜6秒以内に商品使用シーンを入れる** | **132% UP** |

→ 商品要素は6秒以内、商品使用シーンは**3〜6秒**にピンポイント配置。

### 2-4. 内容表現に関する発見

#### 値段／ターゲット呼びかけ
| 要素 | CTR効果 |
|---|---|
| **6秒以内に値段表示** | **116% UP** |
| **3〜6秒以内に広告ターゲットへ呼びかけ** | **105% UP** |

#### 安心できるイメージ構築（権威・ベネフィット・安心メッセージ）
| 要素 | CTR効果 |
|---|---|
| **「金賞受賞」を権威アピール**（No.1／売上本数／製薬会社より上）| **135% UP** |
| **ベネフィットを7秒以降に**（冒頭ではなく後半）| **114% UP** |
| **安心させるメッセージあり**（「定期ではない」「いつでもキャンセル可」等）| **115% UP** |
| **安心させるメッセージを7秒以降に** | **117% UP** |

→ 権威は受賞系、ベネフィットと安心は**後半（7秒以降）配置**が効く。

#### 感情アピール表現
| 要素 | CTR効果 |
|---|---|
| **「お詫び」あり**（「すでに購入した方すみません、値下げしました」）| **113% UP** |
| **後悔アピールなし**（「買わなきゃ良かった」のようなネガ表現を入れない）| **113% UP** |
| **商品効果を感情的に表現あり**（「やばい」「すごい」「びっくり」）| **114% UP** |

→ 感情表現は**ストレート**にする。「買わなきゃ良かった」（皮肉系）はむしろ逆効果。「申し訳ありません、値下げしました」（素直）／「びっくりした」（素直）が効く。

#### 動画全体の感情ストーリー
| 要素 | CTR効果 |
|---|---|
| **ネガティブ→ポジティブ**（「毛穴がひどい」→「毛穴スッキリ」のような変化）| **111% UP** |
| 終始ポジティブ | 中位 |
| どちらでもない | 低い |

→ ストーリーは**ネガからポジへの変化を見せる**。

### 2-5. キャンペーン関連
| 要素 | CTR効果 |
|---|---|
| **キャンペーン実施あり** | **108% UP** |
| **2秒以内にキャンペーン情報を紹介** | **118% UP** |
| **「お試し」「1回限定」のキャンペーン内容** | **128% UP** |

→ 動画ではキャンペーンは**冒頭2秒で出す**。

#### キャンペーン内容（動画）
| キャンペーン | CTR |
|---|---|
| **お試し** | 最高（128% UP）|
| **1回限定** | 次点 |
| 値下げ | 中位 |
| 限定価格 | 中位 |
| キャンペーンなし | 中位 |
| 初回限定 | 最低 |

⚠️ **画像広告との違いに注意**：
- **画像広告**：値下げ／1回限定が効く、お試しは効かない
- **動画広告**：お試し／1回限定が効く、値下げは中位

### 2-6. CTAに関する発見

CTAの文言タイプ別CTR順位：
1. **気になる系**（「気になる人ダウンロード」）
2. **アンケート系**
3. **早く系**
4. 急いで系
5. 試して系
6. CTAなし
7. チェック系
8. 詳しく系
9. 今すぐ系（最低）

→ **「気になる」「アンケート」「早く」** がCTA上位。「今すぐ系」が**意外に最低**。

### 2-7. 商品種別

CTRが高い順：
1. **スキンケア**
2. **美容**
3. **ヘアケア**
4. オーラルケア関連
5. タバコ
6. 健康食品

→ Pangle動画では**スキンケア／美容／ヘアケア**が上位。画像と動画で順位が違うことに注意（画像は健康食品が最高）。

## 太一向け次アクション視点

### Pangle案件CR制作チェックリスト（画像）
- [ ] **人物を入れた**か（CTR 133%）
- [ ] **商品要素**は入っているが、**商品使用シーン・手持ちは入れていない**か
- [ ] **アスペクト比はスクエア**か（縦横は191%劣る）
- [ ] **商品本体が画像半分以上を占めない**よう、パッケージ／文字／人で構成
- [ ] **値段／ターゲット呼びかけ／権威アピール／お詫び**を入れたか
- [ ] **キャンペーンは「値下げ」「1回限定」**にしたか（「お試し」「初回限定」は弱い）
- [ ] キャッチコピーは**お詫び／商品機能／権威／無料**ベース

### Pangle案件CR制作チェックリスト（動画）
- [ ] **15秒尺・1カット2秒台・BGMあり・動画画像組合せなし**か
- [ ] **2秒以内**にキャンペーン＋お詫び
- [ ] **3〜6秒**に商品使用シーン＋ターゲット呼びかけ＋値段
- [ ] **7秒以降**にベネフィット＋安心メッセージ（順番が逆だと弱い）
- [ ] **有名人起用**したか（一般人だけだとCTRに効かない）
- [ ] **権威は「金賞受賞」**を最優先（No.1や売上本数より効く）
- [ ] **「お詫び」あり**＋**「後悔アピール」なし**にしたか
- [ ] 動画全体の感情を**ネガ→ポジ**に
- [ ] **キャンペーン内容は「お試し」「1回限定」**（画像と違う！）
- [ ] CTA文言は**「気になる」「アンケート」「早く」**系（「今すぐ」は使わない）

### TikTok本体面との違い（運用ルール整理）

| 項目 | TikTok本体 | Pangle |
|---|---|---|
| アスペクト比（動画）| 縦型ほぼ必須 | **関係なし**（縦・スクエアどちらでも） |
| アスペクト比（画像）| - | **スクエア最強**（191%）|
| ナレーション | 効果的 | **関係なし** |
| BGM | あり推奨 | **あり推奨**（114%）|
| 人物（動画）| 効果的 | **関係なし**、ただし**有名人なら効く**（109%）|
| キャンペーン（動画）| 122% UP | **108% UP**（弱め）|
| 動画長 | 15秒以下推奨 | **15秒以下推奨**（共通）|

→ Pangleは**よりダイレクト＆"広告らしい"作り**が効く。TikTok本体のような「オーガニック感」「縦型必須」は必須条件ではない。

### クライアント提案フレーズ
- **「Pangle面ではTikTok本体と違って、スクエア＆ダイレクト商品見せが効く」**
- **「画像CTRはキャッチコピーで157%、権威表現で200%」**（コピー設計の重要性）
- **「動画は冒頭2秒でキャンペーン、3〜6秒で使用シーン、7秒以降でベネフィット」**（時間軸テンプレ）
- **「商品種別TOP3は画像なら健康食品、動画ならスキンケア／美容／ヘアケア」**（商材ジャッジ材料）
- **「CTRとCPAは負の相関（-0.25）」**→ CTR改善がCPA改善に直結することの根拠
