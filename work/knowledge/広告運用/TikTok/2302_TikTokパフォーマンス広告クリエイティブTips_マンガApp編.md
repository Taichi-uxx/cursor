# TikTokパフォーマンス広告クリエイティブTips 〜マンガApp編〜

## 出典

- 元ファイル：TikTokパフォーマンス広告クリエイティブTips_マンガApp編.pdf（全46ページ）
- 発行：**TikTok for Business**（2023年2月）
- 対象データ：TikTokパフォーマンス広告（App Install）
- 対象期間：2022年6月1日〜2022年11月30日
- 除外条件：Cost $400以下 かつ CV50件以下（最適化未到達とみなす）
- 分析対象：Cost降順 **300本**のクリエイティブ
  - **アセット活用動画 278本**
  - **クリエイター動画 22本**

## 用途

- **マンガApp系クライアント**（jin社など）のクリエイティブ発注ガイドとして
- マンガ広告で**CTR / CPI / CVR が頭打ち**になった時の打ち手検討
- クリエイター起用提案時の**ROI根拠**（CVR +43%）として
- **アセット活用 vs クリエイター動画**のどちらを優先制作するかの判断軸
- マンガジャンル選定（ラブコメディ / 人間ドラマ等の好調傾向）
- 既存マンガ広告のクリエイティブ監査チェックリスト

## 1. アセット活用動画の効果分析

### 1-1. 全体傾向：サイズ・秒数より「動画内容」の差が大きい

| 観点 | 結果 | 推奨 |
|---|---|---|
| **動画サイズ** | 縦長 平均CTR **126%**（高CTR） / 横長 CPI最低 | 基本は**縦長**（画面占有率↑） |
| **動画秒数** | 31秒以上 平均CTR **153%** / 秒数短いほどCPI低い | マンガを長く読ませる構成なら**31秒以上** |
| **音声有無** | 音声**なし** 平均CTR **147%** / CPI **84%** | **音声なし推奨**（読書妨害） |

→ サイズや秒数より、**動画内容（演出・構成・内容）の差**が圧倒的に効く。

### 1-2. 効果分析の3軸フレーム
1. **演出**
2. **構成**
3. **内容**

---

## 2. ①演出：スワイプが効果的

### 2-1. 演出の3種類
| 演出 | 内容 |
|---|---|
| **リッチ** | コマのカットイン・SEなど演出に強弱あり |
| **スワイプ** | 一定速度で画面切り替え |
| **スクロール** | スクロールのみ |

### 2-2. 効果データ
| 演出 | 平均CTR | 平均CPI |
|---|---|---|
| **スワイプ** | **129%** | **62%** |
| リッチ | - | - |
| スクロール | - | (CPI最も高い) |

→ **スワイプ推奨**。一定速度でストレスなくマンガを読み進められ、**没入感が高まる**。

### 2-3. 補足テキストの活用法
| 動画秒数 | 補足テキスト | 理由 |
|---|---|---|
| **1〜30秒** | **あり推奨** | マンガ内容を端的に伝える |
| **31秒以上** | **なし推奨** | マンガページを多く見せる構成のため不要 |

→ 補足テキスト自体は CTR 117% / CPI 87% で**影響小**だが、秒数に応じて使い分け。

## 3. ②構成：冒頭キャッチ・中盤を重視した4幕構成

### 3-1. 4幕構成
| 構成 | 役割 | カット数 |
|---|---|---|
| **①冒頭キャッチ** | 目を引き継続視聴を促進 | **1〜2カット** |
| **②中盤** | 体験を通じて興味関心向上 | **11〜15カット**（CTR 120%） |
| **③ラストフック** | 考えさせ続きが気になるを創出 | **1カット** |
| **④行動喚起** | お得感などで背中を押す | **1〜2カット** |

### 3-2. 冒頭キャッチの重要性
- **6秒視聴率が高いほどCTRも高い**（正の相関）
- 冒頭キャッチあり：6秒視聴率 **102%** / 平均CPI **80%**
- **どんなキャッチが効果的？**
  | キャッチ要素 | 6秒視聴率 |
  |---|---|
  | **ビジュアル** | **303%**（最強） |
  | **コピー** | **249%** |
  | 音 | - |
  | 権威表記 | - |
  | インセンティブ | （最も低い→広告色強くなり関心↓）|
- → **ビジュアル or コピーで強烈なインパクト**を作る。インセンティブを冒頭に置かない。

### 3-3. 中盤
- **11〜15カット**が最適（平均CTR 120%）
- 過不及のないカット数が効果的。少なすぎ＝興味関心↑できず、多すぎ＝離脱

### 3-4. ラストフック
- **あり推奨**：平均CTR **128%** / 平均CPI **90%**
- **どんなラストフックが効果的？**
  - **「謎を仕掛ける」**：CTR **117%** / CPI **93%**（最も効果的）
  - 「続きを想像させる」もOK
- → ユーザーの中に**謎が残るような終わり方**にする

### 3-5. 行動喚起
- **なしでも可**（CTR向上には繋がらない傾向、平均CTR 100%）
- ただし行動喚起は8割以上のCRに入っている
- **入れるなら「作品名＋インセンティブ」が最強**（CTR **122%**）
  - 作品名 + インセン > 作品名 + アプリ名 > アプリ名 + インセン

---

## 4. ③内容：謎が残る作品・明るいテンションの作品

### 4-1. 効果的なマンガジャンル
| ジャンル | 効果 |
|---|---|
| **ラブコメディ** | CTR最高 |
| **人間ドラマ** | CTR高 |
| **サスペンス / 推理** | CTR高 |
| BL | - |
| 青年マンガ / 少年マンガ / 少女マンガ | - |

→ **不可思議な設定で謎が残る作品 or クスっと笑える明るい作品**と相性◎

### 4-2. 同一作品でもシーン選定で効果が激変
- 作品A × バトルシーン → 作品A × **恋愛シーン**
- 結果：CTR **45%** → CPI **50%** → **CVR 122%**
- → ジャンルだけでなく**切り出すシーン選定**が重要

### 4-3. 効果的なシーン
| シーン | 効果 |
|---|---|
| **怖いもの見たさ** | 高CTR |
| **謎を解明したい** | 高CTR |
| **恋への共感・憧れ** | 高CTR / CPI最低 |
| 異世界への興味 | - |
| 邪な恋への興味 | - |

→ **身近な設定への共感・憧れ** や **強い好奇心**を抱けるシーンを切り出す

### 4-4. メディア化作品は好調
- メディア化作品（アニメ化・実写化）：平均CTR **105%** / CPI **89%**
- 全体の **20%**がメディア化作品

### 4-5. 横型マンガ作品が強い
- **横型**：平均CTR **130%** / CPI **51%**
- 縦長マンガ（韓国式webtoon等）は効果**芳しくない**
- → 日本市場では**横型マンガ作品を選定**

## 5. アセット活用動画 まとめ（7原則）

1. マンガ広告は**動画内容で差が生まれる**
2. 演出は**スワイプを推奨**
3. 構成は**冒頭キャッチ・中盤を重視した4幕構成**
4. 内容は**謎が残る作品・明るい作品**が好調
5. **共感できる設定・強い好奇心を抱く設定**が効果的
6. **メディア化作品**も好調傾向
7. **横型マンガ作品**が強い

## 6. クリエイター動画の効果分析

### 6-1. 全体傾向
- **クリエイター動画は CVR +43%**（非クリエイター動画比）
- → 制作推奨。ただしクリエイター間の効果差は大きい

### 6-2. クリエイター間の効果差（実例）
- クリエイターA → クリエイターB
- **CTR 25% → CPI 66% → CVR 587%**
- → 同じマンガ案件でも**クリエイター選定で大差**

### 6-3. 好調動画の特徴：リアルな感想重視
| パターン | 説明 |
|---|---|
| **リアルな感想重視** | 具体的見どころ紹介や感想を**自らの言葉**で伝える |
| クリエイターのユーモア重視 | 自身の個性で構成（テンプレ化しやすくリアル感薄い）|

→ **リアルな感想重視**型のほうが好調

### 6-4. リアルな感想重視の構成テンプレ
```
① ターゲット特定
② 作品タイトル
③ 作品の魅力紹介
④ おすすめ・見どころ紹介
⑤ リアルな感想
```

### 6-5. ユーモア重視はテンプレ化リスク
```
① マンガ主人公紹介
② ストーリー
③ 急展開ポイント
④ ストーリー
⑤ 作品タイトル
```
→ 自身の個性重視 → **テンプレートになりやすくリアルな感想が薄い**

### 6-6. コンテンツ紹介系クリエイターは別格
- **コンテンツ紹介系クリエイター：平均CVR 549%**
- 理由：**コンテンツの魅力をユーザーに伝え慣れている**

### 6-7. ジャンル選定でも効果は変動
- 同クリエイター × サスペンス → 同クリエイター × ラブコメディ
- **CTR 73% / CPI 45% / CVR 247%**
- → **ネガティブよりポジティブな内容**が好まれる
- ジャンル別CVR順：異世界恋愛 > **ラブコメディ** > 人間ドラマ > 異世界転生 > サスペンス > スポーツ

### 6-8. フォロワー数の影響は少ない
- **50万人以下** 平均CVR **230%** > 50万人以上
- → **フォロワー数で選ばない**。コンテンツ伝達力で選ぶ

### 6-9. 動画秒数
- **1〜45秒** 平均CVR **273%** > 46秒以上
- → **45秒以内**で制作

---

## 7. クリエイター動画 まとめ（6原則）

1. クリエイター動画は**高CVR傾向**
2. クリエイターの**リアルな感想を重視**すると効果的
3. 中でも**コンテンツ紹介系クリエイター**が好調
4. マンガジャンルより**クリエイターの影響が大きい**
5. **フォロワー数による効果への影響は少ない**
6. 秒数は**45秒以内**を推奨

## 太一向け次アクション視点

### マンガApp案件 即実装チェックリスト

#### アセット活用動画
```
□ 演出はスワイプ（リッチ・スクロールではなく）
□ 音声なし
□ 縦長サイズ
□ 31秒以上なら補足テキストなし、30秒以内なら補足テキストあり
□ 冒頭1〜2カット：強烈なビジュアル or コピー（インセンティブを冒頭に置かない）
□ 中盤11〜15カットでマンガを読ませる
□ ラストフック1カット：「謎を仕掛ける」終わり方
□ 行動喚起入れるなら「作品名＋インセンティブ」
□ 作品ジャンル：ラブコメディ・人間ドラマ・サスペンス
□ シーン選定：怖いもの見たさ／謎解明／恋への共感
□ 横型マンガ作品を選ぶ（縦長webtoon系NG）
□ メディア化作品があれば優先選定
```

#### クリエイター起用
```
□ 「コンテンツ紹介系クリエイター」を優先（CVR 549%）
□ フォロワー数では選ばない
□ ジャンルはポジティブ寄り（ラブコメ・異世界恋愛・人間ドラマ）
□ 動画は45秒以内
□ 構成：ターゲット特定 → 作品タイトル → 魅力紹介 → 見どころ → リアルな感想
□ クリエイター自身の個性で押し切らせない（テンプレ化リスク）
```

### クライアント提案フレーズ（マンガApp案件）

**現状のCPI高騰時：**
> 「演出を**スワイプ単一**に切り替えると、CTR 129%・CPI 62% という改善傾向データがあります（TikTok for Business 公式分析、300本）」

**新規クリエイティブ提案時：**
> 「**コンテンツ紹介系のクリエイター** 1〜2本起用してCVR検証しましょう。マンガジャンルの選定で CVR は最大247%変動します」

**ジャンル拡張提案時：**
> 「現在サスペンス中心ですが、ラブコメ作品も走らせる価値あり。同一クリエイターでも**ジャンル差でCVR 247%差**が出ています」

### 既存運用診断フロー（マンガApp案件監査）

1. **CTR が低い場合** → 冒頭キャッチ確認。ビジュアル / コピーの強烈なインパクトがあるか
2. **CPI が高い場合** → 演出がスワイプか確認。音声が入っていないか確認
3. **CVR が低い場合** → クリエイター起用 or シーン選定見直し（バトル→恋愛のような転換）
4. **頭打ちの場合** → メディア化作品 or 横型マンガで未試行のものを投下
5. **アセット動画ばかりの場合** → クリエイター動画を最低2本制作（CVR +43%）
