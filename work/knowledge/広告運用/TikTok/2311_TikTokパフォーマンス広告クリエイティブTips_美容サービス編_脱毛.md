# TikTokパフォーマンス広告クリエイティブTips 〜美容サービス編（脱毛業界）〜

## 出典

- 元ファイル：TikTok+パフォーマンス広告クリエイティブTips〜美容サービス編〜.pdf（全51ページ）
- 発行：**TikTok for Business**（2023年11月）
- 対象データ：日本のTikTok Performance Auction **Web Conversion目的**
- 抽出期間：2022年7月5日〜2023年7月4日
- 抽出条件：imp 3万以上、Conversion 20以上、Lowest Cost、性別ターゲティングあり等
- 分析対象：**Web CV目的 計318本**の動画素材（美容サービス＝脱毛業界）

## 用途

- **脱毛クリニック / 脱毛サロン**案件（クライアントに該当業界あれば）のクリエイティブ発注
- **男女別**でクリエイティブ訴求が大きく異なる業界の参考ケース（他業界でもM/F差を考える時に）
- **Web CV目的**で CTR・CVR を別々に改善したい時のレバー特定
- **LPの理想構成**として（脱毛以外の美容サービスにも応用可）
- **広告審査ポリシー**の脱毛業界版チェック

## 重要前提：CTRとCVRの関係性

| 関係 | 相関係数 | 解釈 |
|---|---|---|
| 6秒視聴率 × CTR | **+0.67** | かなり強い正の相関 → 冒頭で引きつければCTR↑ |
| CVR × CPA | **−0.38** | やや負の相関 → CVR上げればCPAは下がる |

→ **CTRはアテンション、CVRはアクション**として分けて改善する。

## 1. 脱毛業界：TOP動画の3パターン

### 1-1. 体験×キャンペーン表現
冒頭でターゲット特定／課題提起 → 施術する様子 → キャンペーン・モニター募集を訴求

### 1-2. ビジネス文書風表現
公式からの「お知らせ」風に**あえて固い印象**のビジネス文書で見せる（テキストのみで惹きつける）

### 1-3. クリエイター活用×体験表現
**人気クリエイター起用**＋施術体験で興味喚起

→ TOP動画は基本「**施術体験風の撮影素材＋キャンペーン／モニター募集**」。

### TOP動画3事例の要点
1. **人気クリエイター×施術体験**：①冒頭にクリエイター ②夏フックのシーズナリー訴求 ③「各店舗30名限定」など限定表現
2. **年齢特定×施術体験**：①「1985〜1995年生まれの男性だけに」と具体年齢 ②「30万円分のチケット」インセン ③カウントダウン風CTA
3. **インセンティブ×アンケート誘導**：①冒頭で悩み「薄着をする時に自信がない」 ②「○○円相当の特典」 ③アンケート回答に誘導
4. **ビジネス文書風**：撮影素材が多い中、テキスト固表現でギャップ → 視覚的に目を引く

## 2. CTR好調要因（8項目）

### ① BGM：あり推奨（特にPOP系）
- 女性向け：BGMあり **CTR +12%**
- 男性向け：BGMあり **CTR +20%**
- → 脱毛への**不安を緩和するPOPなBGM**が効果的

### ② 動画の人物登場：冒頭から登場（**93%が冒頭人物あり**）
- 女性向け：冒頭から**紹介レビュー風**の人物
- 男性向け：冒頭から**施術シーン**でスタッフ登場
- → 6秒以内に必ず人物を入れる

### ② 顔出しの使い分け
| 対象 | 顔出し | 効果 |
|---|---|---|
| **スタッフ** | **顔出しあり** | CTR **+19%** |
| **利用者** | **顔出しなし** | CTRが高い |

→ **「スタッフ顔出しあり、利用者顔出しなし」が鉄板**（専門性・施術イメージ伝達 + プライバシー配慮）

### ③ 動画の表現
| 性別 | 効果的な表現 | 内容 |
|---|---|---|
| **女性向け** | **理想像映像** | 施術後の美しい肌を想起させる身体の映像＋料金・権威性 |
| **男性向け** | **紹介レビュー風** | 施術シーンを見せながらナレーションでキャンペーン・強み複数紹介 |

### 【ポリシー注意 - 脱毛業界】
- 肌の露出は一般的範囲、過度な強調しない
- 施術箇所の性的内容含めない
- 脱毛完了前の状態（脇のぶつぶつ等）クローズアップしない
- 胸のサイドの露出は標榜不可

### ④ 冒頭のカット数：**1〜3カットで緩やかに**
- 1カット・2-3カットがCTR高い、4-5カットになると低下
- → 情報量よりも**ゆっくり展開**してサービスイメージを作る

### ⑤ 契約への安心感表現：**あり推奨**（CTR +77%）
| 性別 | TOP3訴求 |
|---|---|
| **女性** | ①都度払い制 ②追加料金無し ③分割払い可能 |
| **男性** | ①無理な勧誘無し ②永久サポート付き ③追加料金無し |

→ 女性は**お金面**、男性は**面倒回避・サポート**で安心感

【ポリシー注意】「永久」「追加料金無し」は注釈と LP説明必須

### ⑥ クリエイター起用：**男性向けに効果的**（CTR +42%）
- 男性向けでは**人気クリエイター起用**が効く（女性クリエイター起用多数）
- 女性向けはTOP動画にクリエイター活用少なく影響限定的

### ⑦ 権威性訴求：**女性向けに効果的**（CTR +112%）
- 「No.1」「乗り換え数 80%以上」など**数字で見せる**
- 脱毛クリニックなら**エステからの乗り換え割合**
- エステ脱毛なら**人気No.1キャンペーン**

【ポリシー注意】「○○No.1」「□%の人が△△」は第三者機関調査期間必須。「自社調べ」では不十分

## 3. CVR好調要因（8項目）

### ① ナレーション：**あり推奨**（CVR +30%）
- 男女問わずナレーションあり → 動画の情報量を増やす → 刷り込みでCV

### ② 冒頭でターゲット特定：**男性向けに特に効果的**（CVR +33%）
- 男性：脱毛部位への言及／生まれの年代でターゲット特定
- 例：「今年こそVライン脱毛をめざすあなた」「1990年〜95年うまれの男性募集します」

### ③ 冒頭で料金提示
| 性別 | 推奨 |
|---|---|
| **女性向け** | **料金より、限定要素のあるキャンペーン・サービス特徴を冒頭で**（料金提示なしの方が CVR +28%）|
| **男性向け** | **料金を冒頭で**（CVR +6%）|

→ 女性は脱毛理解度が高く値段より特徴で動く、男性は理解度低く料金で試したくなる

### ④ 価格の表現
| 性別 | 最強の価格表現 |
|---|---|
| **女性向け** | **「半額」** > 分割支払い > 初回限定 > 激安・無料モニター |
| **男性向け** | **「初回限定」** > 激安・無料モニター |

→ 女性は信憑性ありつつお得感ある「半額」、男性は試したい心が動く「初回限定」

### ⑤ サービス名登場の秒数（女性向け）
- **16秒以上**が最高CVR
- 2秒未満が次点
- → 冒頭 or 終盤の二択。**中盤2-15秒は逆効果**
- ※男性向けは秒数N数分布の偏りで分析できず

### ⑥ 動画限定表現：**女性向けに圧倒的効果**（CVR **+331%**）
- 女性向け：「TikTok限定！」「この動画を見たあなただけに」→ **CVR +331%**
- 男性向け：効果見えず
- → 女性の方が「お得感」「特別感」に興味
- 【ポリシー】TikTok限定は事実なら制限なし、ロゴ使用は別途許諾

### ⑦ 施術シーン：**男女ともに効果的**
- 女性向け CVR **+11%**、男性向け CVR **+25%**
- 女性向け：利用者の施術部位を見せる
- 男性向け：スタッフを写した施術シーン

### ⑧ CTA：**矢印アニメーション**でアクション促進（CVR +29%）
- 女性向け：目立つ**矢印アニメーション**
- 男性向け：**矢印×カウントダウンアニメーション**

## 4. 女性向けLPの設計

### 4-1. LPタイプ：**サービス紹介LP**が圧勝
- サービス紹介LP（公式感あり、強み・料金・部位を直接訴求）が記事LP・アンケートLPより大幅にCVR高
- 女性脱毛はニーズ明確 → 2STEP構成より**直接サービス紹介**が効く

### 4-2. FV（ファーストビュー）必須3要素
| 要素 | CVR効果 |
|---|---|
| **キャンペーン訴求** | **+77%** |
| **人物画像** | **+168%** |
| **権威性訴求** | **+206%** |

→ FVには**キャンペーン×人物×権威性**の3点セットを必ず入れる

### 4-3. LPの長さ：**15〜20スクロール（中尺）**
- 短すぎ（15未満）・長すぎ（21以上）どちらもCVR低下
- 中尺が最適

### 4-4. 女性向けLPの構成項目（よく使われる）
- **KV**：女性顔イメージ
- 限定表現：TikTok限定 / この広告を見た人限定
- キャンペーン訴求：脱毛○○回○○円
- 権威性（クリニック）：エステからの乗り換え○○%
- 強み：施術機械、予約しやすさ、支払方法
- 安心感：追加料金無し、都度払いOK
- 口コミ：お客様の声
- 施術の流れ：画像＋文字
- Q&A、店舗紹介

### 4-5. 女性向けLP理想フロー（3カラム構成）
```
[列1: 上から]
LOGO → 権威性訴求 → KVキャンペーン訴求 → CVボタン → 強み訴求

[列2: 中段]
広告限定表現 → キャンペーン訴求 → CVボタン → 申込安心感 → 権威性訴求

[列3: 下段]
口コミ → キャンペーン訴求 → CVボタン → Q&A → 施術の流れ → 店舗紹介
```

## 5. 男性向けLPの設計

### 5-1. 男性向けLPの構成項目
- **KV**：施術者の顔など
- キャンペーン訴求：脱毛○○回○○円
- **アンケート（悩み）**：ムダ毛でお悩みはありますか？
- **アンケート（サービス）**：当サービスで魅力に感じる点は？
- **アンケート（理想）**：脱毛完了後、何をしてみたいですか？
- 強み、安心感、口コミ、施術の流れ、Q&A、店舗紹介

→ 男性向けはニーズ顕在度低 → **アンケート構成で自分ごと化**が有効

### 5-2. 男性向けLP理想フロー
```
[列1]
LOGO → KVキャンペーン訴求 → アンケート（意向→理想→サービス）

[列2]
広告限定表現 → キャンペーン訴求 → CVボタン → 強み訴求 → 申込安心感

[列3]
口コミ → 広告限定表現 → キャンペーン訴求 → CVボタン → 予約方法 → 店舗紹介
```

## 6. CTR・CVR要因まとめ（一覧）

### CTRを高める要因
- 脱毛への不安を払拭するPOPなBGM
- 冒頭から人物登場
- スタッフの顔出し（利用者は顔なし）
- 女性は**理想像映像**、男性は**レビュー風**
- 冒頭は**1〜3カット**で緩やかな速度
- 契約への**安心感表現**
- 男性向け動画では**クリエイター起用**
- 女性向け動画に**権威性を実数値**で

### CVRを高める要因
- **ナレーション**で情報量を増やす
- 男性向け：悩みや年代でターゲット特定
- 男性向け：サービス特徴より**料金を冒頭で**
- 女性向け：**広告限定表現**（CVR +331%）
- 女性向け：**「半額」**価格表現
- 男性向け：**「初回限定」**価格表現
- 動画の中に**施術シーン**
- **矢印やカウントダウン**でCTA強調

### クライアント提案フレーズ（脱毛案件）

**新規LP制作時：**
> 「FVに『キャンペーン訴求＋人物画像＋権威性訴求』の3要素を入れることで、CVRが**+77〜206%**改善するデータがあります（TikTok for Business 公式分析、318本）」

**男性向け強化時：**
> 「男性向け動画には**人気クリエイター起用でCTR +42%**、冒頭でターゲット特定（年代提示）で**CVR +33%** が見込めます」

**女性向け限定訴求時：**
> 「『TikTok限定』『この広告を見たあなただけに』の限定表現で CVR **+331%** という劇的な効果。今すぐ実装すべき施策です」

### 業界横展開（他の美容系サービス）

| 業界 | この資料の応用ポイント |
|---|---|
| **エステ** | 女性向けLP理想フロー＋施術シーン＋限定表現を流用 |
| **歯科美容（ホワイトニング等）** | 男性向け：年代×悩み特定／女性向け：理想像映像 |
| **美容医療（注射・施術系）** | 「半額」より「初回限定」（医療法配慮）／施術シーンは慎重に |
| **メンズ脱毛・メンズエステ専門** | 男性向け施策を全てそのまま適用可 |

### 既存案件診断フロー
1. CTR低い → BGM・冒頭人物・スタッフ顔出し・カット数 を確認
2. CVR低い → ナレーション・施術シーン・CTA・LP FV要素を確認
3. 男女別で施策を分けているか確認（同じ訴求を使っていないか）
4. 価格表現が「無料モニター」になっていないか（CVR下位）
