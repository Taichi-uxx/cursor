## 2. ビジネスアカウントへの切り替え方法

`設定とプライバシー` → `アカウント管理` → `ビジネスアカウントに切り替える`

### ビジネスアカウントでできること
| 機能 | 内容 |
|---|---|
| **インサイト** | パフォーマンス・エンゲージメント・フォロワー数を分析（App/Web両対応／**Web版のみダウンロード可**）|
| **商用楽曲ライブラリ** | 著作権フリーで安全に使える楽曲（**50万曲以上**）。TikTok内のみ利用可 |
| **ビジネスクリエイティブガイド** | 他社人気動画からヒント収集（トレンディング:ビジネス／エンゲージメント:ビジネス／トレンディング:コミュニティ）|
| **投稿予約機能**（Web限定）| Web版から動画アップロード予約 |
| **Q&A機能** | プロフィールにQ&Aセクション設置 |
| **TikTok LIVE** | **フォロワー1,000人以上＋18歳以上**で配信可能 |

⚠️ **注意**：ビジネスアカウントは**一般音楽ライブラリ**は使えず、**商用楽曲ライブラリのみ**。逆に、企業が個人アカウントで一般楽曲を使うと**レーベルの著作権リスク**がある。

## 3. ビジネスアカウント運用で抑えるべき3つのポイント

### 3-1. アカウント目標を設定する

#### TikTokのレコメンドシステム
> すべての投稿は一定数のユーザーのフィードに「必ず」表示される。
> エンゲージメント・ユーザー属性・視聴態度を機械学習し、反応が良い動画は自ずとより多くのユーザーに届く。
> **始めたばかりのユーザーでも多くにリーチ可能**＝**投稿すればするほど伸びる**仕組み。

#### 設定すべき目標は2つ
1. **フォロワーを増やすこと**
2. **エンゲージメントを上げること**（いいね／コメント／シェア）

### 3-2. コンテンツ設計（2つの軸）

#### 軸A. 伝えたいことを伝えること
- オーガニックポスト
- 広告配信
- プロモート
- ライブ配信

#### 軸B. コミュニティを活性化すること
- 公式アカウントからのコメント
- クリエイター起用、タイアップ（第三者から伝えてもらう）

### 3-3. PDCA：オーガニック投稿×Spark Ads配信

```
① ACCOUNT WARM-UP（ビジネスアカウント開設・初期投稿）
   ↓
② フォロー施策（ビジネスアカウントに誘導しフォロワー獲得）
   ↓ Spark Ads配信で山を作る
③ エンゲージメント施策（フォロワーへターゲティング配信／コミュニティ繋げ）
   ↓ Spark Ads配信で2回目の山
④ ORGANIC BEATS（成長したコミュニティを魅力的なコンテンツで活用）
```

## 4. コンテンツ制作フロー（3ステップ）

### Step 1：TikTokを観察する

#### モニタリングする4つ
| 対象 | 方法 |
|---|---|
| **トレンド** | ビジネスクリエイティブガイド、最新エフェクトをチェック |
| **コメント** | 定期的にコメント欄を確認、ユーモアをチェック |
| **ハッシュタグ** | ブランド・業界関連ハッシュタグをチェック |
| **競合社・クリエイター** | 同カテゴリの競合社・クリエイターを閲覧 |

#### 押さえておくべきクリエイター（ジャンル別）
| ジャンル | クリエイター例 |
|---|---|
| 料理・グルメ | バヤシBayashi |
| 日常・ファミリー | ろいたん |
| 美容 | やみちゃん |
| ファッション | マリナ |
| 書籍・マンガ | もつもつ漫画紹介のひと |
| 観光・Vlog | りょうまい夫婦【おでかけ夫婦】 |
| 映画・ドラマ | さかい｜映画紹介 |
| 教育 | Kevin's English Room |
| エンタメ | ウンパルンパ |

#### アプリ外情報源
- 公式 TikTok for Business（最新活用事例）
- 公式 note（最新情報・クリエイター情報）
- TikTok Presents 大久保佳代子とトレンド遊び（バズらせるコツ）
- TikTokクリエイティブセンター（最新トレンド）

### Step 2：コンテンツ立案（4つの柱）

人気の高い動画は**プラットフォームのトレンドやカルチャーをベース**にする。

| 柱 | 内容 | 手段 |
|---|---|---|
| **乗っかる** | TikTokのトレンドに乗り親近感醸成 | ハッシュタグに乗る／ジャンルに乗る／UXを活用した楽しみ方に乗る（例：スシロー／ロート社員の1日／SEGAのソニック止め） |
| **活用する** | 商品等アセットの活用や社員出演でファンを作る | 商品・サービス活用（ほっともっと）／他媒体と同じ素材活用（やまとり）／スタッフ・社員活用（資生堂） |
| **繋がる** | コミュニティや他クリエイターと交流 | クリエイターと繋がる（ドミノ）／ユーザーのコメントに動画返信（サブウェイ） |
| **教える** | 新鮮さ・意外性・お得感など学べる内容提供 | ストーリー性とともに教える（グーネット）／豆知識・裏技を教える（ANA） |

#### テクニック
- **飾らない姿を見せる**（@yomiuriland_comの「雪で休園ごめんなさい」のような親近感投稿）
- **コメントへ誘導する**（全てを動画に収めず、「実はドミノ…」のように続きをコメント欄で）

### Step 3：撮影・投稿（＋広告配信）

撮影方法は **TikTok for Creators (creator portal)** 参照。

## 5. Spark Ads：オーガニック投稿の広告配信

### 5-1. Spark Adsとは
オーガニック投稿（自社or起用クリエイター投稿）を**おすすめフィードで広告配信**できる仕組み。

### 5-2. メリット
- **ネイティブな配信**（強制視聴なし、他動画と並列の視聴体験）
- 計画的にターゲットにリーチ
- インフルエンサー投稿、ビジネスアカウント投稿のブースト可
- Brand Auction（運用型）でも利用可
- 商品への潜在的な興味喚起、瞬発力ある拡散・話題化
- 商材に合ったクリエイター選定可
- 細かなターゲティング、配信最適化（リーチ・視聴等）

### 5-3. 通常Infeed広告に対するSpark Adsの優位性
| 指標 | Spark Ads（vs Infeed）|
|---|---|
| ビデオ視聴完了率 | **+30%** |
| エンゲージメント率 | **+142%** |
| **CVR** | **+43%** |

※データソース：TikTok自社グローバルデータ Q4 2020〜Q2 2021

### 5-4. ターゲティング方式（Spark Ads）
- 年齢／性別／言語／端末／接続種類／興味・関心／所在地（国・都道府県）／キャリア・値段
- **カスタムオーディエンス**：
  - 企業コンテンツを見た／興味関心あるユーザー層
  - フォロワーや類似オーディエンスのリターゲティング

## 6. FAQ（よくある質問）

### Q. TikTokアカウントの認証マークは？
ZenDeskから申請可能。

### Q. 投稿頻度はどのくらいが良い？
- **2〜3回/週が目安**
- たくさん投稿する人ほどフォロワー数が増える傾向
- フォロワー50万超になると「たくさん投稿する派」が逆転（56% vs 44%）
- 厳選より**量で勝負**するのが伸びる近道

### Q. 投稿のおすすめ時間帯は？
- **夕方以降がボリュームゾーン**
- TikTok利用シーン上位：夜家に帰宅後 68.5% ／ 寝る前 31.8% ／ 帰宅後夜の空き時間 30.6%
- → **18時〜23時の投稿**が最も見られやすい

### Q. テキスト制作時の注意点は？
- **文字量によってセーフティゾーンが変わる**ため、制作動画に合わせてテキスト調整
- 右下UIアイコン・下部キャプション部分に重要要素を置かない

## 太一向け次アクション視点

### TikTok広告クライアントへのオーガニック併用提案

「**TikTokは『フルアテンション視聴』×『次のトレンド』×『コミュニティ』が他媒体比で圧倒的に強い**。広告だけでなくオーガニックアカウント運用で潜在層→ファン化を進めるべき」

### TikTok新規アカウント立ち上げチェックリスト
- [ ] ビジネスアカウントに切り替え（個人アカウントだと商用楽曲が使えず著作権リスク）
- [ ] **目標2つ設定**：フォロワー数／エンゲージメント
- [ ] **投稿頻度2〜3回/週**を最低ライン化
- [ ] 投稿時間は**18時〜23時**を中心
- [ ] コンテンツ柱を**「乗っかる／活用する／繋がる／教える」4分類**で設計
- [ ] **競合・クリエイターの観察**を週1ルーチンに
- [ ] フォロワー1,000人到達後は**LIVE活用**も検討
- [ ] 開設後3ヶ月でSpark Ads併用検討（オーガニック単体だと伸びが鈍化）

### Spark Ads提案フレーズ（既存TikTok広告案件向け）
- **「Spark Adsは通常Infeed広告に比べ CVR +43% / エンゲージメント率 +142% / 視聴完了率 +30%」**（数値根拠）
- **「ネイティブ配信なのでブランドリフトと獲得の両立が可能」**
- **「自社アカウント投稿だけでなく、起用したクリエイター投稿もブースト可能」**

### コンテンツ立案フレーム「4つの柱」を運用ミーティングで使う
クライアント定例MTGで「次月の投稿4本どうしますか？」と聞く代わりに：
- 「**乗っかる**1本（トレンドハッシュタグ便乗）」
- 「**活用する**1本（社員出演／商品アクションシーン）」
- 「**繋がる**1本（コメント返し動画／クリエイター起用）」
- 「**教える**1本（豆知識／裏技／キャンペーン告知）」

…と**4本セット**で枠を切る運用ルールにすると、企画立案ハードルが下がる。

### 重要な背景知識
- **TikTokのレコメンドアルゴリズム**：始めたばかりでもバズれば全ユーザーに届く構造。Meta/Instagramと違って**フォロワー0でも初動次第で爆発する**。「投稿数こそが価値」という運用思想は他SNSと真逆。
- **「次の流行りがわかる」369.4%**は、TikTokがトレンド発信地として唯一無二であることの証明。新商品・新サービス案件のローンチ媒体として最強。
