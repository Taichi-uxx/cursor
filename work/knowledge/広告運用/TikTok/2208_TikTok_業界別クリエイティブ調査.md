# TikTok 業界別クリエイティブ調査（Creative Tips）

## 出典

- 元ファイル：バーティカル別クリエイティブ調査+202208.pdf（全16ページ）
- 発行：**TikTok for Business**（公式）
- 調査時期：2022年6月23日〜27日
- 調査機関：株式会社マクロミル
- 有効回答数：本調査1,856サンプル
- 調査対象：マクロミルモニタ 15〜49歳の男女、TikTokを週に1日以上利用、直近1週間以内に利用、すべてのカテゴリ忌避層は除外

## 用途

- 新規TikTok案件で**どんな構成のCRを作るべきか**業界別に判断したいとき
- クライアントへのCR制作提案で**「興味を持つコンテンツ」「買いたくなるコンテンツ」**のデータ根拠を示したいとき
- 既存案件で**顕在層と潜在層で当てるべきCRが違う**ことをクリエイターチームに説明するとき
- 各業界の**「あてはまるものはない」率**（＝興味喚起の難易度）の指標として

## 調査設計

### 調査対象の分類
- **顕在層**：該当業界の商品情報に対して「好き・やや好き」と答える
- **潜在層**：該当業界の商品情報に対して「好きでも嫌いでもない・なんとも思っていない」と答える

### 調査項目
- 顕在層には「**興味を持つコンテンツ**」「**買いたくなるコンテンツ**」を質問
- 潜在層には「**興味を持つコンテンツ**」のみを質問

### 各業界の潜在層・顕在層の規模（TOP2＝とても好き＋やや好き）

| 業界 | 顕在層（TOP2）| 潜在層 | BTM2（嫌い）|
|---|---|---|---|
| エンタメ | **70.5%** | 24.8% | 4.8 |
| 旅行 | 68.1% | 27.6% | 4.3 |
| 食品/飲料 | 65.7% | 30.9% | 3.4 |
| ビューティ | 63.6% | 30.9% | 5.5 |
| ファッション | 71.1% | 25.3% | 3.6 |
| ゲーム | 50.5% | 35.9% | 13.6 |
| 家電 | 46.7% | 48.0% | 5.3 |
| ホームケア | 39.5% | 50.4% | 10.1 |
| 車 | 38.0% | 49.5% | 12.5 |
| 金融 | **34.5%** | 48.7% | **16.9** |

→ **金融業界が最も顕在層が少なく潜在層が大きい**（提案ハードル高）／エンタメ・ファッションは顕在層多く提案しやすい

## 1. ビューティー業界

> 興味を持つコンテンツ・買いたくなるコンテンツ共に**「使ってみた動画」が首位**。
> 興味コンテンツ：顕在層は「裏技」「商品紹介」、潜在層は「使い方」「商品紹介」。
> 買いたくなるコンテンツ：顕在層は「使い方」「商品紹介」「裏技動画」が上位。

### 買いたくなるコンテンツ TOP5（顕在層）

### CR制作の示唆
- **「使ってみた」**が圧倒的1位 → BAクリエイターやインフルエンサー起用のレビュー動画

## 全業界に共通する勝ち筋

### 興味喚起の3大パターン
1. **「使ってみた・試してみた」「作ってみた・食べてみた」**：実体験を見せる
2. **「商品紹介・解説」「キャラクター・登場人物紹介」**：対象そのものを紹介
3. **「裏技・活用方法」「ランキング」**：付加価値情報

### 顕在層 vs 潜在層の戦略差
- **顕在層**：商品の**具体的な使い方・買い方**まで踏み込む
- **潜在層**：商品の**「使ってみた」「興味を引く情報」**で接点を作る
- 「あてはまるものはない」率が高い業界（金融39%、車32.9%、ホームケア29.1%）は潜在層へのリーチが難しい → **顕在層に絞った戦略が現実的**

## 太一向け次アクション視点

### 新規TikTok案件のCR制作ブリーフ作成時
1. クライアントの業界を上記9つから特定
2. **顕在/潜在のどちらをメインターゲットにするか**判断
3. **TOP3〜5のコンテンツタイプ**をクリエイティブの基本構成に組み込む
4. **「あてはまるものはない」率**が高い業界は顕在層集中戦略

### 業界別 CR制作の基本パターン早見表

| 業界 | 顕在層向け基本パターン | 潜在層向け基本パターン |
|---|---|---|
| ビューティー | 使ってみた + 裏技 + 商品紹介 | 使ってみた + 使い方 |
| 飲食 | 作ってみた + 作り方 + 裏技 | 作ってみた + 作り方 |
| エンタメ | キャラ紹介 + ランキング + 作品紹介 | キャラ紹介 + 切り抜き |
| 旅行 | おすすめスポット + 行ってみた + Vlog | 同左（差なし）|
| **金融** | 裏技活用 + 銘柄紹介 + ランキング | **潜在層は撤退・顕在層集中** |
| ファッション | 着こなし + 着てみた + 購入品紹介 | 着こなし + トレンド |
| ホームケア | 使ってみた + 商品紹介 + 日常Vlog | 使ってみた + 裏技 |
| 車 | 車種紹介 + おすすめ + 愛車紹介 | 車種紹介 + ドライブ |
| 家電 | 使ってみた + 商品紹介 + テクニック | 使ってみた + テクニック |

### クライアント提案資料での使いどころ
- **「公式調査データ」**として根拠の強い説得材料
- 「**御社の業界では、顕在層に対しては〇〇動画が興味喚起1位、購買喚起1位です**」のような具体提案が可能
- 顕在層と潜在層を分けたターゲ戦略の根拠
