# Part 1. APP編

## 1-A. FX（APP）

### CTR を高める要因（APP / FX）
- **アプリ操作シーン**：**CTR +63%**（最大要素）
- **女性ナレーション**：CTR +5%
- **人物登場あり・顔出しなし**（操作・利用に集中させる構成）
- **UGC感のある撮影素材**（スライドショーは避け、撮影素材を活用）

### CVR を高める要因（APP / FX）
- **ずっとポジティブ感情**：CVR +16%
- **権威性表現**：CVR **+56%**（FXは新しい金融サービスのため、権威性が信頼を補完）
- **冒頭でターゲット特定**
- **ハードルを下げる表現を4個以上**
- **キャンペーン訴求**を入れる
- **サービス名は終盤で提示**

### 太一向け：FX案件チェックリスト
```
□ 動画にアプリの操作シーン（タップ / スワイプ / グラフ閲覧）が映っているか
□ 女性ナレーションを採用しているか
□ 顔出しなしで人物の手元・操作に集中させているか
□ 権威性訴求（メディア掲載 / ◯◯ランキング1位 / 規模感）を必ず入れているか
□ ハードルを下げる訴求（少額OK / アプリで完結 / 知識不要 / サポートあり）を4個以上入れているか
□ サービス名は冒頭ではなく終盤で提示
□ キャンペーン（口座開設特典等）が動画内にあるか
```

## 1-B. 株（APP / Appendix）

### TOP動画の表現手法
- **アニメーション**で投資の仕組みをわかりやすく解説する動画
- 「投資が難しい」と感じる初心者層に対して、**ハードルを下げる教育型コンテンツ**が効果的

### 訴求の傾向（TOP）
- **TOP1: ハードル下げ訴求**（少額から / アプリで完結 / 簡単操作）
- **TOP2: メリット訴求**（資産形成 / 配当 / 値上がり益）
- **TOP3: ターゲット特定**（初心者OK / ◯◯歳から / サラリーマン向け）
- **TOP4: インセンティブ訴求**（口座開設特典 / キャッシュバック）

### 理想の動画構成（株）
**導入（ターゲット特定）→ 課題喚起 → サービスメリット → 申込みハードル下げ**

→ 株は **「投資未経験者でも始められる」教育＋ハードル下げ**型動画でCV獲得が伸びる。

# Part 2. WEB編

## 2-A. クレジットカード（WEB）

### CTR を高める要因（WEB / クレカ）
1. **利用シーン要素**：**CTR +66%**（最大要素・買物 / 飲食 / 旅行などの利用シーンを映す）
2. **カード券面提示**：CTR +15%
3. **ナレーション活用**：**CTR +57%**
4. **CTA矢印**：CTR +16%
5. **メリット羅列風 or Vlog風**動画
6. **CMのまま出稿**もブランド広告との相乗で効果期待
7. **人物登場あり・顔出しなし**

### CVR を高める要因（WEB / クレカ）
- **ポジティブ感情**：**CVR +98%**（最大要素）
- **ターゲット特定**：CVR +36%
- **間接的なシーン**（利用想起シーン：買物・ATM・支払い）
- **ハードルを下げる表現**
- **キャンペーン（限定要素）** を入れる
- **サービス名は終盤で提示**

### LP関連（クレカ・CVR）
- **診断LP**が最も効果的
- **長さ：11〜15スクロール**（クレカは情報量必要なため中尺〜やや長め）
- **訴求要素：ポイント還元 / 年会費無料 / 最短即日発行**

### 太一向け：クレカ案件チェックリスト
```
動画：
□ 利用シーン（買物・飲食・旅行）が映っている → CTR +66%
□ カード券面を明確に映している → CTR +15%
□ ナレーションを入れている → CTR +57%
□ CTAボタンに矢印を付けている → CTR +16%
□ ポジティブ感情で統一されている → CVR +98%
□ 「30代女性に」「学生に」などターゲット特定 → CVR +36%
□ 限定キャンペーンを訴求

LP：
□ 診断LPになっているか（質問→おすすめカード）
□ ファーストビューは「テキストメイン or 人物画像メイン」
□ タレント起用ありか（CVR +45%）
□ ポイント還元 / 年会費無料 / 最短即日発行を強調
□ 長さは11〜15スクロール
```

## 2-B. カードローン・キャッシング（WEB）

### CTR を高める要因（WEB / カードローン）
1. **冒頭に景色シーン（考え事をさせる）**：CTR +31%
2. **顔出しで人物登場**：**CTR +59%**
3. **11秒以降に申込み画面を見せる**
4. **冒頭から課題喚起**（2個程度）：CTR +18%
5. **女性ナレーション**を活用
6. **スライドショーより撮影素材**を活用

### CVR を高める要因（WEB / カードローン）
- **ハードルを下げる表現3個以上**
- **審査・借入の手軽さを時間で提示**（最短30分 / 最短翌営業日 / 3秒シミュレーション）
- **実際に借りるシーンをスマホ残高で見せる**
- **冒頭で行動を促す呼びかけ**：CVR +43%
- **キャンペーン訴求**を入れる
- **サービス名は終盤で提示**
- **映像で見せる（スライドショーは避ける）**

### LP関連（カードローン・CVR）
- **記事LP**が圧倒的にCVR好調（記事14% / 比較サイト80% / 通常サービスLP6% / **CVRは記事LP最高**）
- **記事LPの流れ**：トーク風表現で悩み共感 → サービスのメリット/優位性 → 他社との比較 → 利用者の口コミ
- **ファーストビュー**：**テキストメイン or 人物画像メイン**が最効果
- **タレント起用**：CVR **+45%UP**
- **審査・借入時間の表現**：CVR **+35%UP**（最短30分 / 最短翌営業日 / 3秒シミュレーション）
- **長さ：10スクロール未満を推奨**（11スクロール以上は明らかにCVR低下）

### 太一向け：カードローン案件チェックリスト
```
動画：
□ 冒頭に景色シーン（考え事をさせる）→ CTR +31%
□ 顔出しで人物が登場 → CTR +59%
□ 冒頭から2個程度の課題提示 → CTR +18% & 共感
□ 11秒以降に申込み画面を見せる
□ 女性ナレーションを活用
□ 冒頭で「借りるならココ」など視聴者に呼びかけ → CVR +43%
□ ハードルを下げる表現を3個以上
□ 審査・借入の時間を明確に提示
□ スマホ残高シーンで借入を可視化
□ サービス名は終盤、キャンペーン訴求あり

LP：
□ 記事LPを最優先で作成（読ませる構成）
□ 流れ：課題共感 → メリット → 他社比較 → 口コミ
□ ファーストビューはテキストメイン or 人物画像メイン
□ タレントを起用 → CVR +45%UP
□ 審査・借入時間を明示 → CVR +35%UP
□ スクロール数は10未満に抑える
```

## 2-C. 銀行（WEB / Appendix）

### TOP動画の表現手法
- **コント風表現**（1人の演者が複数役を演じる、お得さをユーモアで訴求）
- **クリエイター紹介風表現**（サービスメリットを直接紹介、複数メリットを並べて紹介）

→ どちらも **UGC感のある動画**が好調。

### 訴求の傾向（TOP）
- **TOP1: アプリで簡単に口座開設訴求**（店頭不要）
- **TOP2: サービス訴求（定期預金）**（資産形成・通常預金との比較）
- **TOP3: 金利訴求**（店頭表示金利の100倍 / 年1.0% など）
- **TOP4: インセンティブ訴求**（今だけ口座開設で3000円プレゼント）

### 理想の動画構成（銀行）
**導入（女性が貯金喜ぶ）→ 課題喚起（そのお金…）→ サービスメリット（元本保証）→ 口座開設の簡易性（かんたんに口座開設）**

### 太一向け：銀行案件チェックリスト
```
□ コント風 or クリエイター紹介風（UGC感）で撮影
□ アプリで口座開設可能な簡易性を強調
□ 通常預金との比較で「お得感」を強調
□ 金利を具体的数値で訴求（年1.0% / 100倍 など）
□ 口座開設インセンティブ（◯◯円プレゼント）を訴求
□ 構成：導入 → 課題喚起 → メリット → 簡易性
```

## 2-D. NISA（WEB / Appendix）

### TOP動画の表現手法
- **投資の仕組みをイラストアニメーションで明確に表現**
- 手持ちのスマホ映像 + アニメーションの組み合わせ

### 訴求の傾向（TOP）
- **TOP1: 貯金/他の投資との比較訴求**（通常投資では約20%の税金）
- **TOP2: 利息訴求**（◯年で◯◯円積み立てた場合、利息は約500円）
- **TOP3: ネットで申込み完結訴求**（銀行にわざわざ行かなくていい）
- **TOP4: ポイントが貯まる訴求**（投資でポイント→ポイントで再投資）

### 理想の動画構成（NISA）
**ターゲット特定（つみたてNISAしてない人）→ 貯金/他の投資との比較（運用利益約290万円）→ 申込みの簡易性（銀行行かなくていい）→ ポイント貯まる/インセンティブ**

### 太一向け：NISA案件チェックリスト
```
□ イラストアニメーションで仕組みを解説
□ 冒頭で「NISA知らない人」とターゲットを特定
□ 通常投資との税金比較（NISAは非課税）を明示
□ 利息・運用利益を具体的数字で提示
□ ネット完結の手軽さを強調
□ ポイント二次活用などのお得感を訴求
```

## 2-E. 保険（WEB / Appendix）

### TOP動画の表現手法
- **リッチCM**（人気アイドル起用、主観でアイドルと会話風）
- **アドバイス風表現**（女性アドバイザーが特徴を紹介、ハードル下げ訴求複数）

→ **安心感（リッチCM）** か **UGCライクなアドバイス風** が双璧。

### 訴求の傾向（TOP）
- **TOP1: 月々◯◯円から訴求**（月々5000円から など、料金訴求）
- **TOP2: 担当者サポート訴求**（最後までしっかりサポート）
- **TOP3: インセンティブ訴求**（新規ネット契約で10000円割引）
- **TOP4: 販売実績訴求**（200万件以上の販売実績）

### 理想の動画構成（保険）
**ターゲット特定（お金溜めたい人絶対見て）→ 現状との比較（お金持ってると全部使う）→ サービスメリット（解約しても100%以上戻る）→ 権威性/実績（200万件の販売実績）**

### 太一向け：保険案件チェックリスト
```
□ リッチCM or アドバイス風（UGC）で撮影
□ 月々の料金を最小金額で訴求（◯◯円から）
□ 担当者のサポート手厚さを強調
□ 新規契約インセンティブを訴求
□ 販売実績・契約数で信頼性を担保
□ 構成：ターゲット特定 → 現状比較 → メリット → 権威性
□ 「解約してもお金戻る」など利用ハードル下げ表現
```

## 3-2. 全業界に通じる教訓

1. **スライドショーより撮影素材が全業界で優位**
2. **クレジットカード業界はブランド広告との相乗でCMそのままでも効く**（他業界は専用素材が必要）
3. **カードローン業界のみ、顔出しと冒頭課題提示を強く推奨**（他業界は顔出しなしでもOK）
4. **操作・利用シーンを重視するFXとクレカは「顔出しなし＋人物登場あり」が好相性**
5. **キャンペーン訴求はクレジットカード業界のみ多く実施**（他業界は少なめ → 入れると差別化）
6. **新しい金融サービス（FX）は権威性表現が必須**（信頼補完）
7. **カードローンとクレジットカードは利用者の気持ちをリマインドする間接シーン推奨**
