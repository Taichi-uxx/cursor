# TikTokパフォーマンス広告Tips 〜ランディングページ編〜 EC業界 + 金融業界

## 出典

- 元ファイル：Tips〜ランディングページ編〜EC業界+++金融業界.pdf（全38ページ）
- 発行：**TikTok for Business**（**2022年12月（Dec, 2022）**）
- 性質：TikTok運用型広告の**遷移先LP**を、業界別にCVR平均値以上の好調LPだけで分析した公式Tips
- データ抽出条件：
  - 2022/3/12〜2022/9/12（半年間）
  - Web Conversion 目的の TikTok広告
  - Impression 50万以上 / 獲得数 20以上
  - 同一LPの繰り返し出稿は実績合算
  - **平均CVRを超えたLPのみを分析対象**
- 分析サンプル数：
  - **EC業界** = 全体 n=289 → 平均CVR以上 n=83 → 最終分析 69 LP
  - **金融業界** = 全体 n=182 → 平均CVR以上 n=68 → 最終分析 34 LP（**多くがカードローン**）

## 用途

- TikTok広告の遷移先LPを**新規制作**するときの「何を入れるべきか／順番はどうあるべきか」の根拠資料
- 既存LPの **CVRが平均以下**で頭打ちのとき、改善ポイントを業界別に当てるとき
- **EC案件（特にスキンケア／美容／健康食品）** で「アンケートLP・記事LP・通常LP」のどれを採用すべきか提案するとき
- **カードローン案件**で「比較LPか／記事LPか／通常LPか」の構造選定をするとき
- LP制作会社・社内デザイナーに**LP構成仕様書**として渡すとき
- LPのファーストビュー（キャッチコピー / 人物画像）を業界別に最適化するとき
- クライアントに「LP構成順序＝決まったベスプラがある」と数字根拠で**説得**するとき

# Part 1. EC業界編

## 1-1. 好調LPはどんなタイプか

### LPタイプ別の出現比率（CVR平均以上のLP内）

| LPタイプ | 構成比 |
|---|---|
| **アンケート+記事** | **58%** |
| **アンケートのみ** | **18%** |
| 記事+アンケート / 記事のみ ほか | 残り |

→ **6割以上がアンケート付きLP**。

### LPタイプ別 平均CVR

| 順位 | LPタイプ | 備考 |
|---|---|---|
| 1位 | **アンケート+記事** | **記事LPより平均CVR +7%以上** |
| 2位 | アンケート（先）+ 記事 | アンケート先行型がベスト |
| 3位 | 記事 + アンケート | アンケート後置きは劣る |
| 4位 | 記事のみ | |

→ **アンケートと記事を組み合わせる場合は、必ずアンケートを先に答えさせる**。

---

## 1-2. アンケートLPの作り方

### 設問数：**3〜5問**
- 3問：41%
- 5問：39%
- 4問：20%
- 6問以上 / 2問以下 は推奨されない（多すぎず少なすぎず）

### 設問1：**悩みを問いかける**（80%以上）
- ユーザーに「自分ごと化」を促す
- 例：「Q1：この中で一番きつく感じることはなんですか？」（食事制限 / 運動 / そもそも続けること）

### 設問2：**ユーザーインサイトの興味・関心**（65%以上）
- 商品を通じて実現したい未来をイメージさせる
- 例：「Q2：脂肪が減って期待することはなんですか？」（夫とのイキイキした毎日 / 健康診断の改善 / おしゃれや外出を楽しむ）

### 設問3：**商品認知・商品特徴の確認**（合計74%以上）
- 商品認知：39% / 商品特徴：35%
- 例：「Q3：◯◯（商品名）を知っていましたか？」（知っていた / 知らない）

### 汎用的な設問構成（39%以上が採用）
**5問構成 = 悩み → インサイト → 商品認知 → 商品特徴 → 使用希望**

| 設問 | 内容 | 狙い |
|---|---|---|
| 設問1 | 悩み | ユーザーの悩み問いかけ → 自分ごと化 |
| 設問2 | インサイト | 叶えたい理想の姿を問いかけ → 自分ごと化 |
| 設問3 | 商品認知 | 商材についての認知問いかけ → 興味喚起 |
| 設問4 | 商品特徴 | 商材特徴について問いかけ → 興味喚起 |
| 設問5 | 使用希望 | 使用希望を問いかけ → 行動促進 |

### 商品説明は必ずセット（82%）
- アンケートと共に**商品説明を挿入**しているLPが82%
- 単純なアンケート展開だけでなく、回答後に商品情報を入手できる設計

### アンケート+記事LP・アンケートのみLP の具体イメージ
- **アンケート+記事LP**：記事LP風コンテンツ → 「さらに！このアンケートに答えると●●%OFFの特別価格で買えちゃうんです！」 → アンケート → CTA
- **アンケートのみLP**：「全4問 ●●%OFFで特別案内」→ Q1（悩み）→ Q2（認知）→ Q3（特徴）→ Q4（使用希望）→ CTA

## 1-3. その他のLP構成（CVR Top20のLP内容順序）

CVR上位20本のLPを分析した結果、**汎用的なLP構成順序**は以下：

| 順 | 要素 | 内容 |
|---|---|---|
| 1 | **キャンペーン紹介①** | 「通常5,000円の◯◯が、初回限定で◯◯円！」のようなオファー訴求でアテンションを取る |
| 2 | **ベネフィット提示①** | 「飲むと痩せることが期待できる◯◯のご紹介！」のように商材ベネフィット |
| 3 | **悩みへの共感** | 「食事制限をしているのになかなか痩せられない？」のように悩み共感コンテンツ |
| - | **CTAボタン** | （アクション機会を上部に設置） |
| 4 | **解決策の提示** | 「そんな悩みを持ったあなたのために◯◯は開発されました！」 |
| 5 | **ベネフィット提示②** | 「◯◯という成分を配合しているので、飲むと脂肪の分解を助ける」 |
| 6 | **第三者データ** | 「ヒトの体の構造上、◯◯が理由で食事制限だけでは効果が薄い」 |
| 7 | **利用者の声** | 「わたしは3ヶ月で10kg痩せることに成功しました！」 |
| 8 | **限定感の演出** | 「お陰様で売れ行きが好調のため、50個限定の販売です」 |
| 9 | **キャンペーン紹介②** | キャンペーン再訴求＋限定感で購買意欲を高める |
| - | **CTAボタン** | （最終CTA） |

→ **「キャンペーン→ベネフィット→共感→CTA→ベネフィット深掘り→第三者データ→利用者声→限定感→キャンペーン再訴求→CTA」** の流れが王道。

# Part 2. 金融業界編（**カードローンが中心**）

## 2-1. 好調LPはどんなタイプか

### LPタイプ別の出現比率（CVR平均以上の金融LP内）

| LPタイプ | 構成比 |
|---|---|
| **比較LP** | **82%**（圧倒的多数） |
| 通常LP | 9% |
| 漫画LP | 6% |
| アンケートLP | 3% |

→ **金融業界（特にカードローン）は『比較LP』が圧倒的支配的**。EC業界とは真逆。

### 比較LP の特徴
- **複数のサービス**（カードA / カードB / カードC など）を金利・融資までの期間で並べて比較
- 自社優位のための作為的比較はNG → 第三者作成・客観比較が前提（広告ポリシー・審査ルール準拠）

---

## 2-2. LP構成要素の考察（金融）

### ファーストビューのキャッチコピー：**CVR +17%以上**

| 訴求型 | CVR傾向 |
|---|---|
| **今すぐ借りれる** | 上位（+17%） |
| **共感を得る** | 上位 |
| **呼びかけ** | 上位 |
| ランキング | やや低い |
| 審査 | やや低い |
| 診断 | 最も低い |

#### 訴求イメージ
- **今すぐ借りれる**：「コンビニで今すぐ借りれる 最短即日融資！」
- **共感を得る**：「リボ払いのままだと年間◯◯万円も損してるって知ってた！？」
- **呼びかけ**：「審査に通るか不安な方！おすすめのカードローンをご紹介」

→ **カードローンは「緊急性」を求めるユーザー特性**。ファーストビューでスピード／共感／呼びかけを使う。

### ファーストビューに人物画像：**CVR +34%**
- 人物画像あり vs なし → **+34%**
- 安心感を与える効果

### Q&A セクション：**CVR +39%**
- Q&Aありの場合、CVRが+39%
- 例：「Q. 会社の同僚にバレないって本当…？ A. はい。会社の同僚や家族に、知られることなく借り入れが可能です！」
- ユーザーの不安払拭で CVR 向上

---

## 2-3. 金融LPでよく使われる内容項目

| 項目 | 役割 |
|---|---|
| **共感/問いかけ** | そうなんだね…（興味を引く） |
| **解決策提示** | これはいいかも！（サービス提示） |
| **ベネフィット提示** | 強み、選ばれる理由 |
| **カード情報詳細** | サービス内容を具体的に紹介（金利／審査期間／限度額） |
| **Q&A** | 疑問を解決する |
| **他サービス推奨** | 自社の他のサービスをおすすめ |
| **CTAボタン** | 購買・契約ページへ |
| **診断/シミュレーター** | 借り入れ可否の診断 |

---

## 2-4. 金融LPのCVR Top20構成順序（カードローン）

| 順 | 要素 | 内容 |
|---|---|---|
| 1 | **画像 + キャッチコピー（解決策提示）** | ファーストビューは速さ訴求＋人物画像「今日借りたいを叶えるカードローン！」 |
| - | **CTAボタン** | |
| 2 | **共感/問いかけ** | 「今日中に10万円借りたい…」「けど、周りにバレたくない…」 |
| 3 | **ベネフィット提示・比較内容** | 「そのお悩みを解決できるおすすめのカードローンを教えます！」＋ 比較表 |
| - | **CTAボタン** | |
| 4 | **カード情報詳細** | 金利／審査期間／限度額 |
| - | **CTAボタン** | |
| 5 | **その他のおすすめカードローン紹介** | メインで紹介していないカードの情報（単一サービスなら割愛） |
| 6 | **診断/シミュレーター** | 「借り入れ可能か3秒で診断」など申込前の後押し |
| 7 | **Q&A** | 「本当に会社にバレないの？」「怖い人から取り立てられないの？」など不安払拭 |
| - | **CTAボタン** | |

→ **CTAボタンは3〜4箇所に分散配置**。ファーストビュー直後／比較表後／カード情報後／Q&A後。

# Part 3. 業界横断まとめ

## 業界別「最強LP公式」

| 業界 | LP戦略 |
|---|---|
| **EC** | **「アンケート+記事」+ 5問構成（悩み→インサイト→認知→特徴→使用希望）+ 商品説明セット** |
| **金融（カードローン）** | **「比較LP」+ FVキャッチ（今すぐ／共感／呼びかけ）+ 人物画像 + Q&A + CTA複数** |

## 業界別「最大CVR向上要因」

| 業界 | CVR押し上げ要因 |
|---|---|
| EC | アンケート先行型 → 平均CVR **+7%以上**（vs 記事のみ） |
| 金融 | FV人物画像 → CVR **+34%** / Q&A → CVR **+39%** / FVキャッチ（今すぐ/共感/呼びかけ）→ CVR **+17%以上** |

## 太一向け次アクション視点

### クライアント提案フレーズ

> **EC案件**：「TikTok広告のLPは『アンケート先行型』が記事LP単体より平均CVRが**+7%以上**高いという公式データがあります。5問構成（悩み→理想→商品認知→特徴→使用希望）に商品説明を必ず添える形が王道です」

> **カードローン案件**：「金融業界のTikTok好調LPは**82%が比較LP**です。さらに、FVに人物画像で**CVR+34%**、Q&Aセクションで**CVR+39%**、『今すぐ/共感/呼びかけ』のキャッチで**+17%以上**伸びます。最低限この3要素＋CTA複数配置の構成を踏襲しましょう」

### LP制作 業界別仕様書テンプレ（社内デザイナー向け）

#### EC仕様
```
□ LPタイプ：アンケート先行 + 記事
□ アンケート設問数：3〜5問
□ 設問順序：悩み → インサイト → 商品認知 → 商品特徴 → 使用希望
□ 商品説明：アンケートとセットで挿入
□ FV：キャンペーン訴求（初回限定価格 等）
□ ボディ：キャンペーン①→ベネフィット①→悩み共感→CTA→解決策→ベネフィット②→第三者データ→利用者の声→限定感→キャンペーン②→CTA
```

#### 金融（カードローン）仕様
```
□ LPタイプ：比較LP（複数サービスを客観比較）
□ FVキャッチ：「今すぐ借りれる」「共感を得る」「呼びかけ」のいずれか
□ FV画像：必ず人物画像入れる（CVR +34%）
□ ボディ順序：画像+キャッチ → CTA → 共感/問いかけ → ベネフィット+比較 → CTA → カード情報詳細 → CTA → 他おすすめカード → 診断/シミュレーター → Q&A → CTA
□ Q&Aは必ず入れる（CVR +39%）
□ CTAは少なくとも3〜4箇所に配置
```
