# TikTok広告ベスプラ（運用Tips・ハック集）

## 出典

- 元ファイル：TikTok広告ベスプラ.boxnote（社内資料・2024年2月時点）
- 性質：実運用者が貯めたTikTok広告のベストプラクティスメモ
- 関連リンク：
  - Webキャンペーン関連：https://bytedance.sg.feishu.cn/docx/NQ7vdpkxVoXqCtxqGLelH095gBg
  - アプリキャンペーン関連：https://bytedance.sg.feishu.cn/docx/FAeodwZC0oVWqKxwkKzlid2fgUh

## 用途

- TikTok案件の**運用設計**（予算配分・広告セット構成・CR本数）で迷ったとき
- 「TikTokのガチャ要素」をクライアントに説明するとき
- 既存TikTok案件で**成果が伸び悩んでいる**ときのチェックリスト
- 新規TikTok案件の**運用ルール**として共有

## 運用ハック（核心ポイント）

### ① ガチャ要素が大きい → CPA 1.5倍ルール
> **ガチャ要素が大きいので、目標のCPAの1.5倍ほど配信が出てもCV出ない場合は再入稿した方が良い。**

- TikTokは初動のCV発生有無で大きく成果が変わる（ガチャ要素）
- 目標CPAの1.5倍までCost投下してもCVが出なければ、そのままズルズル続けるよりも**再入稿**でガチャを引き直すべき
- Meta広告のピン差し理論と同じ思想

### ② 入札戦略は「最大配信」で実施
> **最大配信で実施すべき**

- 最小単価入札（Lowest Cost）が基本推奨
- CPA上限を設定する戦略は最適化を制限してしまうため非推奨

### ③ 日予算は目標予算の10〜20倍で設定 → 徐々に落とす
> **日予算は目標予算の10〜20倍で設定→そこから徐々に落としていく運用**

- 例：目標日予算1万円なら、初期設定10〜20万円
- 配信開始直後はAIに「予算を気にせず最適なオークションを取りに行く」と認識させる
- ある程度の学習完了・成果安定後に目標予算まで段階的に縮小
- 「最初から目標予算で開始」は最適化が回らず失敗パターン

### ④ アドアフィ系の運用方針（参考）
> **アドアフィ系の会社は広告セット30位作って良かったやつだけ残して運用するみたいな感じで進めるんだとか。**

- アフィリエイト系運用会社の手法：30個ほどの広告セットを並行配信し、勝ち広告セットだけ残す
- TikTokのガチャ要素を**量で打ち負かす**戦略
- 通常案件でも、新規CR入稿時は**3〜5本の広告セット複製**で初動の運勝負を緩和

### ⑤ EC系は「高い購買力」を選択
> **EC系は高い購買力を選択した方が良い**

- TikTok管理画面のオーディエンス絞り込みで「購買力」設定がある
- ECは「高い購買力」フィルタを入れて、CVR・CPAを改善
- 単に若年層を狙うだけでなく、購買力の高い層に絞ることで効率化

### ⑥ 1広告セットあたり**3〜5本のCR**まで
> **１つの広告セットに3〜5までしかCR入れるべきではない。良い動画に集中するように。**

- Metaの「6〜10本/広告セット」とは異なる
- TikTokは**少数精鋭で勝ち動画に配信集中**させる方が良い
- 多すぎると一部の勝ち動画への集中が分散して機会損失

## 太一向け示唆

### 既存TikTok案件チェック
- [ ] **CPA 1.5倍ルール**：目標の1.5倍まで投下してCV出ない広告は再入稿しているか（漫然と継続していないか）
- [ ] **入札戦略**：最大配信（最小単価入札）になっているか、CPA上限を設定していないか
- [ ] **日予算**：初動で目標予算の10〜20倍を入れているか、それとも最初から目標予算でケチっていないか
- [ ] **EC案件の購買力設定**：高い購買力フィルタを入れているか
- [ ] **広告セットあたりCR本数**：3〜5本に絞れているか、それとも8本〜10本詰め込みすぎていないか

### 新規TikTok案件設計テンプレ
```
【入札戦略】
- 最大配信（Lowest Cost）で開始
- CPA上限は設定しない

【予算設計】
- 初動：目標日予算の10〜20倍
- 学習完了・成果安定後：目標予算まで段階的に縮小

【広告セット構成】
- 同一ターゲ・同一CR内容で「3〜5本の広告セット複製」並走
- 勝ち広告セットだけ残し、負け広告セットは停止
- 新規CR入稿時も複製運用（ガチャ要素対応）

【CR構成】
- 1広告セットあたり3〜5本まで
- 勝ち動画に配信集中させる方針

【オーディエンス】
- EC案件：「高い購買力」フィルタを必須
- その他：年齢/性別ターゲは広め、興味関心はテスト

【撤退ルール】
- 目標CPAの1.5倍を超えてもCV出ない → 再入稿でガチャ引き直し
```

### クライアント説明用フレーズ
- 「TikTokは**ガチャ要素**があるため、Meta系と異なり**複製ガチャ戦略**で進めます」
- 「初動の予算を**目標の10〜20倍**で設定するのは、AIに学習させるための投資です」
- 「広告セットあたりのCR本数は**3〜5本**に絞り、勝ち動画への配信集中を最大化します」
