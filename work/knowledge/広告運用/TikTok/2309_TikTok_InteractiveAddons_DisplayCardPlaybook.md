# TikTok Interactive Add-ons 〜Display Card Playbook〜

## 出典

- 元ファイル：TikTok+Interactive+add-ons+~Display+Card+Playbook~.pdf（全44ページ）
- 発行：**TikTok for Business**（2023年9月）
- 分析対象：**Display Card 247素材**（うちCTR上位100素材を要素分解）
- 性質：TikTok運用型広告のインタラクティブ要素「Display Card」の効果検証＋クリエイティブ制作ガイド

## 用途

- **CTR / CVR が頭打ちのTikTok案件**で、追加レバーとして Display Card 実装を提案するとき
- Display Card のクリエイティブを社内デザイナー / クライアントに**発注する際の仕様書**として

- 「Display Card の効果数値（CTR+30% / CVR+36% / CPA-24%）」を**営業トーク**で根拠提示するとき
- TikTok広告で**獲得効率を底上げ**したいクライアントへの一手目として

## 1. Display Card とは／効果サマリ

### 1-1. Display Card の概要
- TikTok 運用型広告の**Interactive Add-on（インタラクティブ追加要素）** の1つ
- 動画上に**追加の表示カード**を出して、CTAやオファーを補強する仕様
- 動画素材に**追加でレイヤーされる**ため、クリエイティブ実装ハードルは低い

### 1-2. 効果数値（Display Card あり vs なし）
| 指標 | 効果 |
|---|---|
| Impression | **+18%** |
| Card エリア平均 CTR | **+30%** |
| CVR | **+36%** |
| 獲得単価（CPA）| **▲24%** |
| Card エリアが動画全体クリックに占める割合 | **14%** |

→ **「最後の一手」として極めて効果が出やすい追加要素**。素材改善余地が薄くなった案件で必ず提案する価値あり。

## 2. クリエイティブ7要素分析（CTR上位100素材）

Display Card に**何を入れるべきか／どう入れるべきか**の7つの観点。

### 【何を入れるべきか】

#### ① 人物・キャラクター
| 要素 | 出現率 | CTR効果 |
|---|---|---|
| 人物登場 | **97%が「なし」** | （登場させない方が主流）|
| キャラクター登場 | あり | **CTR +13%** |

→ **人物は出さず、キャラクター（イラスト・マスコット）は積極活用**。

#### ② 商品要素
- 商品本体 / パッケージあり → **CTR +18%**
- メイン情報として大きく配置 → **CTR +31%**（後述 ⑥ と関連）

→ **商品本体やパッケージは必ず登場させる**。しかも大きく。

#### ③ メッセージ
| メッセージ要素 | CTR効果 |
|---|---|
| **「無料」訴求** | **+16%** |
| **CTAメッセージ**（「今すぐ確認」等）| **+8%** |
| **指 / 矢印アイコン** | **+25%** |
| **選択させる仕様**（「Aを選ぶ／Bを選ぶ」等）| **逆効果（CTR低下）** |

→ 「無料」「CTA文言」「指/矢印」は積極投入。**選択肢を提示するUIは避ける**（ユーザーが迷う＝離脱）。

#### ④ 文字数・行数
| 要素 | CTR効果 |
|---|---|
| **20文字以下** | **+12%** |
| **3行以下** | **+17%** |
| 全体目安 | **10文字以下／3行以下が理想**（do's & don'ts 推奨）|

→ **少ない・読みやすい・一瞬で意味が取れる**が鉄則。

### 【どう入れるべきか】

#### ⑤ 色
- **黒 > 白 > 寒色 > 暖色** の順でCTR高
- 鮮やかすぎる色（目立たせ目的の派手色）は**逆効果**
- 背景色は**重要メッセージを目立たせる色**にする

→ 黒・白ベース＋アクセントカラーが基本。目立たせたいからと派手色にしない。

#### ⑥ デザインのバランス
- 商品本体 / パッケージを**メイン情報として大きく配置**：**CTR +31%**

→ 商品は「添え物」ではなく**主役**として配置する。

#### ⑦ デザインの多様性（透過デザイン）
- **透過デザイン**（動画の上に直接要素を載せ、カード枠なし）：**CTR +16%**
- 漫画 → 本の表紙のように見せる演出が効果的

→ **可能であれば透過デザイン**で動画と一体化させる。

## 3. やるべきこと / 避けるべきこと（do's & don'ts）

### ✅ やるべきこと
- キャラクターがある場合、登場させる
- 商品本体 / パッケージがある場合、登場させる
- **無料情報がある場合、優先的に入れる**
- **CTAメッセージを入れる**
- **指アイコン / 矢印を使う**
- 全体文字数を**10以下**に、行数を**3行以下**に
- 背景色は重要メッセージが目立つ色に
- 商品 / パッケージは**ライアウトに拡大**する
- 漫画は**本の表紙のように**見せる
- 可能であれば**透過デザイン**を使う

### ❌ 避けるべきこと
- 文字を入れすぎて読めなくなる
- 目立たせるために**鮮やかすぎる色**でデザインする
- **選択させる仕様**でデザインする
- **入稿審査基準に沿わない**こと：
  - Display Card に影を付ける
  - 透過デザイン使用時に複数要素を分散させる
  - 枠内に透過デザインをする
  - 文字が極端に小さい

## 4. 業界別デモ事例（5バーティカル × 通常 / 透過）

重点バーティカル：**漫画 / ゲーム / EC / 人材 / トラベル**

### 4-1. 漫画
- **通常**：「無料配信中」＋作品名＋作品ビジュアル＋「今すぐダウンロード」CTA
- **透過**：本の表紙風に複数巻を斜めに並べ「ポイント溜めて無料配信」＋作品名＋指アイコン

→ 漫画は**本の表紙風レイアウト**が透過の鉄板。

### 4-2. ゲーム
- **通常**：「新キャラ続々登場 100連ガチャ 無料」＋キャラ立ち絵＋CTA
- **透過**：「初回だけ無料で100連ガチャ」＋キャラ＋オファー強調

→ ゲームは**キャラ＋無料訴求**が鉄板。

### 4-3. EC
- **通常**：「最大53%OFF 実質3着無料」＋商品画像＋CTA＋指
- **透過**：「50%OFF まもなく終了 お一人様一回限り」＋COUPON＋商品

→ ECは**割引率＋緊急性（まもなく終了）**で押す。

### 4-4. 人材
- **通常**：「今すぐバイト探したいあなた！◯◯バイト」＋指＋キャラ
- **透過**：「バイト探すなら◯◯バイト」＋イラストキャラ

→ 人材は**呼びかけ型＋キャラクター**で親近感を出す。

### 4-5. トラベル
- **通常**：「人気観光地 激安チケット 今すぐチェック」＋飛行機ビジュアル
- **透過**：「年末旅行どこいく？激安チケット いますぐ確認▶▶▶」＋飛行機

→ トラベルは**季節キーワード＋激安訴求＋矢印**。

## 太一向け次アクション視点

### 営業トーク：Display Card 追加提案
> 「現在のクリエイティブに加えて Display Card を実装すると、Card エリアの CTR が **+30%**、CVR が **+36%**、CPA が **▲24%** になります。動画素材はそのままで、追加レイヤーだけで効きます」

→ **CPA改善の打ち手が枯渇した案件で、最後の一手として必ず提案**。

### Display Card 制作チェックリスト（社内デザイナー発注用）

```
□ 商品本体 / パッケージを「主役」として大きく配置
□ キャラクター・マスコットを登場させる（人物は不要）
□ 「無料」訴求があれば最優先で入れる
□ CTAメッセージ（「今すぐ確認」「今すぐダウンロード」）を入れる
□ 指 / 矢印アイコンを使う（→ CTR +25%）
□ 文字数 10以下 / 3行以下
□ 背景色は黒・白ベース＋アクセント（鮮やかすぎる色NG）
□ 可能なら透過デザイン（カード枠なし、動画と一体化）
□ 選択肢を提示するUIにしない（迷わせ＝離脱）
□ 入稿審査NG項目：影／枠内透過／極小文字／要素分散
```

### 業界別テンプレ提案（クライアント別）

| クライアント業界 | 推奨パターン |
|---|---|
| 漫画App（jin社など）| **本の表紙風透過** ＋ 作品名 ＋ 「無料配信中」＋ CTA |
| ゲーム | キャラ立ち絵 ＋ 「100連ガチャ無料」＋ オファー強調 |
| EC（yuzen / zeal等）| 割引率 ＋ 「まもなく終了」＋ 商品 ＋ 指アイコン |
| 人材 | 呼びかけ ＋ 親近感キャラ ＋ CTA |
| トラベル | 季節キーワード ＋ 激安 ＋ 矢印（▶▶▶）|

### 改善打ち手の優先順位（既存案件）
1. **既に動画素材は十分動かしている** → Display Card 未実装なら**最優先で実装**
2. **既に Display Card あり** → 本資料の7要素チェックリストで**素材監査**
3. **CTR頭打ち** → 「指・矢印・無料訴求」が入っているか確認
4. **CVR頭打ち** → 商品本体を「メイン情報」レベルまで拡大
5. **文字読みづらい** → 10文字 / 3行 以下に削る
