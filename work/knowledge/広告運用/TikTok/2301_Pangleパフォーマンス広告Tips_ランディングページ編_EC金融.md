# Pangleパフォーマンス広告Tips 〜ランディングページ編〜（EC＋金融）

## 出典

- 元ファイル：Pangle広告Tips〜ランディングページ編〜EC業界+++金融業界.pdf（全33ページ）
- 発行：**TikTok for Business**（Jan, 2023）
- 分析対象：
  - 期間：2022年3月12日〜2022年9月12日 日本Pangle Conversion目的、impression 50万以上 / 獲得20以上
  - **EC業界**：n=1,071 → 同LP合算 n=344 → 平均CVR超え **n=65** LPを分析
  - **金融業界（Appendix）**：n=65 → 同LP合算 n=23 → **23 LP**を分析（うち**78%が診断LP**、すべて債務整理サービス）

## 用途

- Pangle案件のLP制作・LP改修の指針として
- 特に**EC（化粧品・健康食品・ダイエットなど）**と**金融（債務整理・診断系）**のLP戦略立案時
- 「記事LP／アンケートLP／診断LP」のどれを作るべきかの判定
- LP内の画像枚数・GIF比率・CTA数・LPの長さの**具体的な数値目安**を参照したいとき
- LPボディの**順番テンプレ**として（CVR Top20分析結果）
- アンケートLPの**設問設計**（3問テンプレ）

## 1. 好調LPの種類（EC業界）

平均CVR以上のLPは **8割以上が記事付き**。

| LP種類 | 割合 |
|---|---|
| **記事のみ** | 42% |
| **アンケート＋記事** | 39% |
| **記事＋アンケート** | 6% |
| **アンケートのみ** | 9% |
| その他 | 4% |

→ **記事付きLPが王道**。アンケートも記事と組み合わせる形で効果的。

## 2. 記事LPの作り方

### 2-1. ファーストビュー：キャンペーン訴求が最強

| FV訴求 | CVR |
|---|---|
| **キャンペーン**（「本格的なシミケアが企業努力でまさかの**半額**？？！」）| **46% up**（最高）|
| 成功の秘訣（「私が3ヶ月で-10kgのダイエットに成功した秘訣は」）| 中位 |
| 商材の強み（「人体のメカニズムから研究した健康なダイエット法／○○連続二年売上一位」）| 中位 |
| 悩みへの共感（「なかなか痩せられないけど 今度こそ痩せたい！そんなあなたに！」）| 下位 |
| 悩み（「あらゆるダイエットをしても全然痩せない…」）| 最下位 |

→ FVは**「キャンペーン半額？？」みたいなオファーの驚き**を全面に出すのが最強。悩み煽りスタートは弱い。

### 2-2. LP内 画像と文字のバランス：画像多めが◎

| 1スクロールあたり画像数 | CVR |
|---|---|
| 1〜1.3枚未満 | （基準）|
| **1.3〜1.5枚未満** | **73% up**（最高）|
| 1.5枚以上 | 56% up |

→ **1スクロールあたり1.3〜1.5枚**が黄金比。画像多めで記事をリッチにし読み進めるモチベを高める。

### 2-3. GIF画像の比率：2割〜4割が最強

| GIF画像比率（LP全画像のうち動的画像の割合）| CVR |
|---|---|
| 2割以下 | （基準）|
| **2〜4割** | **82% up**（最高）|
| 5割以上 | 71% up |

→ **静止画オンリーは弱い**。GIFを2〜4割混ぜる。

### 2-4. CTAボタン数：3個以上必須

| CTA数 | CVR |
|---|---|
| 2個未満 | （基準）|
| **3個以上** | **60% up** |

→ **記事を読み進めて購買意欲が高まったタッチポイントを逃さない**ため、3個以上を最低ラインに。

### 2-5. CTAボタンの動き：動き付き（GIFボタン）が効く

| 動き付きCTAボタンの割合 | CVR |
|---|---|
| 5割未満 | （基準）|
| 5〜8割未満 | 21% up |
| **8割以上**（ほぼ全部動的CTA）| **70% up** |

→ CTAボタンは**できる限り動き付き（GIF）**にする。

### 2-6. LPの長さ：25スクロール未満が◎

| LP長さ（スクリーン1170×2532基準のスクロール数）| CVR |
|---|---|
| 18スクロール未満 | 54% up |
| **18〜25未満** | **77% up**（最高）|
| 25以上 | （基準・最低）|

→ **長すぎNG**。18〜25スクロールが最適。長くなりすぎるとユーザーが飽きる。

## 3. LPボディの汎用順番（CVR Top20分析）

### よく使われる項目（12種）

| 項目 | 役割 |
|---|---|
| **悩みへの共感** | そうなんだね…（興味を引く）|
| **悩みの原因の提示** | 「悩みの原因は○○！？」のように原因を特定 |
| **解決策提示** | これはいいかも！（サービスを提示）|
| **ベネフィット提示** | 強み・選ばれる理由 |
| **キャンペーン内容紹介** | 今なら○○円OFFなど |
| **Q&A** | 疑問を解決する |
| **権威** | ○○売上No.1などサービス実績アピール |
| **実績紹介** | お客様の声、事例 |
| **限定感の演出** | 個数限定など |
| **申し込みから利用までの流れ** | 申込・契約の流れ |
| **第三者データ** | 効果・効能の客観的根拠 |
| **CTAボタン** | 購買・契約ページへ |

### 汎用LPボディ順番テンプレ（CVR Top20）

```
[FV：キャンペーン訴求]
↓
キャンペーン紹介（「通常5,000円の○○が、初回限定で○○円！」）
↓
悩みへの共感（「食事制限してるのに痩せられない？」）
↓
悩みの原因（「痩せない原因は○○！？」）→ 次の解決策の納得感を高める準備
↓
解決策の提示（「そんな悩みを持ったあなたのために○○は開発されました！」）
↓
ユーザー体験（「使ってみたら本当に○○kgのダイエットに1ヶ月で成功した！」）
↓
権威（「○○売上No.1」などで魅力アピール）
↓
[CTAボタン]
↓
キャンペーン紹介② → 改めてキャンペーン訴求しお得感を演出
↓
[CTAボタン]
↓
限定感の演出（「お陰様で売れ行きが好調のため、50個限定の販売です」）
↓
[CTAボタン]
```

**ポイント**：
- 構成は **「キャンペーン → 共感 → 原因 → 解決策 → 体験 → 権威 → キャンペーン② → 限定感」** の流れ
- 後半でも**キャンペーンを2回目訴求**する（リマインド）
- **限定感**を最後に演出することで購買後押し

## 4. アンケートLPの作り方

### 4-1. 設問数は3問が最強

| 設問数 | CVR |
|---|---|
| **3問** | **320% up**（最高・5問比）|
| 4問 | 120% up |
| 5問 | （基準）|

→ **3問が最強**。多すぎると回答モチベが下がる。

### 4-2. 設問1（最初）：悩みを問いかける

- **88%のアンケートLPがQ1で悩みを問いかけ**
- ユーザーの**自分ごと化**を促す
- サンプル：「Q1: この中で一番きつく感じることはなんですか？／①食事制限 ②運動 ③そもそも続けること」

### 4-3. 設問2：未来への期待 or 感じた商材の魅力

- 設問2では合計**70%以上**が「未来への期待（38%）」「商材の魅力（34%）」
- 設問形式で商材魅力を伝えるほうが、文章で読ませるより**理解されやすい**
- サンプル①：「Q2: 脂肪が減って期待することはなんですか？／①夫とのイキイキした毎日 ②健康診断の改善 ③おしゃれや外出を楽しむ」
- サンプル②：「Q2: ○○で魅力に感じるところを選んでください／①食事改善とともに本当に痩せた ②パッケージがおしゃれ ③フルーティな味わいで飲みやすい」

### 4-4. 設問3：商材への認知 or 未来への期待

- 設問3では合計**69%以上**が「商材への認知（41%）」「未来への期待（28%）」
- 最後に**商材認知を問いかけ→効果への期待感を作ってから記事文章へ**つなげる
- サンプル①：「Q3: ○○（商品名）を知っていましたか？／①知っていた ②知らない」
- サンプル②：「Q3: ダイエットに成功したらどうなりたいですか？／①好きな洋服を着て出かけたい ②外食を楽しみたい」

### アンケート3問の黄金パターン

#### パターン1：悩み → 未来期待 → 認知
```
Q1：この中で一番きつく感じることは？（悩み）
Q2：脂肪が減って期待することは？（未来への期待）
Q3：○○（商品名）を知っていましたか？（認知）
```

#### パターン2：悩み → 商材魅力 → 未来期待
```
Q1：この中で一番きつく感じることは？（悩み）
Q2：○○で魅力に感じるところを選んでください（感じた商材の魅力）
Q3：ダイエットに成功したらどうなりたい？（未来への期待）
```

→ **アンケートに記事と組み合わせるのがマスト**（単体は弱い）。

## 5. Appendix：金融業界（債務整理LP）

### 5-1. 金融Pangle LPの実態
- 分析対象23 LPのうち、**78%が診断LP**（全て債務整理サービス）
- 漫画LP 13%、通常LP 9%

### 5-2. 債務整理診断LPのテンプレ

#### 設問数：3問

#### 設問内容
| 設問 | 内容 | サンプル選択肢 |
|---|---|---|
| **Q1** | **借り入れ総額** | 50万以下 / 50万〜100万 / 100万〜200万 / 200万以上 |
| **Q2** | **借金の期間** | 1か月以内 / 1〜3ヶ月 / 3〜6ヶ月 / 6ヶ月以上 |
| **Q3** | **支払い状況/能力** | 支払えるが減らしたい / 定期収入あるが支払い不可 / 定期収入なく支払い不可 |

→ **「クレカor消費者金融の利用社数」よりも「借り入れ総額」**を問うのがCVR高い。

### 5-3. 債務整理広告の全体導線

```
[Pangle動画]
↓ 動画視聴
[LP：診断 Q1〜Q3]
↓ 診断完了
[Thanks page]
↓
[減額の仕組みについて説明する動画を視聴]
　・なぜ減額できる？？
　・それは、○○の利息を○○するため
　・詳しく解説すると…
　・なので、安心して減額の支援ができるのです
```

→ **診断後に「減額仕組み解説動画」**を再度見せ、モチベーションを高めてからCVへ。
**「動画→診断→動画」サンドイッチ構造**が債務整理LPの標準型。

## 太一向け次アクション視点

### Pangle LP制作チェックリスト（EC・記事LP）
- [ ] **FVはキャンペーン訴求**（「半額？？」みたいな驚きで入る／悩み煽りでスタートしない）
- [ ] **1スクロールあたり1.3〜1.5枚**の画像密度
- [ ] **GIF画像を2〜4割**混ぜる
- [ ] **CTAボタンは3個以上**、できれば**8割以上を動的（GIF）ボタン**に
- [ ] **LPの長さは18〜25スクロール**（25以上は長すぎ）
- [ ] ボディ順番は「**キャンペーン→共感→原因→解決策→体験→権威→キャンペーン②→限定感**」
- [ ] **キャンペーンを2回**訴求（FV含めると3回）
- [ ] **限定感（個数限定）を後半**で演出

### Pangle LP制作チェックリスト（EC・アンケートLP）
- [ ] **設問数3問**（4問・5問は劇的にCVR落ちる）
- [ ] **記事と組み合わせる**（アンケート単体は弱い）
- [ ] Q1：**悩みを問いかけ**（自分ごと化）
- [ ] Q2：**未来への期待 or 感じた商材の魅力**
- [ ] Q3：**商材への認知 or 未来への期待**

### Pangle LP制作チェックリスト（金融・診断LP）
- [ ] **診断系を選ぶ**（金融Pangleは78%が診断LP）
- [ ] **設問数3問**
- [ ] Q1：**借り入れ総額**（利用社数は弱い）
- [ ] Q2：**借金の期間**
- [ ] Q3：**支払い状況/能力**
- [ ] 診断完了後に**「減額仕組み解説動画」**でCVモチベ再加熱

### クライアント提案フレーズ
- **「Pangle LPは8割以上が記事付き」**（記事なしLPの非推奨根拠）
- **「FVは『キャンペーン訴求』で他訴求比46% up」**（悩み煽りスタートからの切り替え提案）
- **「アンケート設問3問が5問比320% up」**（設問削減の根拠）
- **「動的CTAボタン8割以上でCVR 70% up」**（GIFボタン採用の根拠）
- **「LP長さ18〜25スクロール超は逆効果」**（長文LPの削減根拠）

### 横展開可能な学び
- **「3問」というアンケート設問数の最適解**は他媒体LPでも応用可
- **「キャンペーン→共感→原因→解決策→体験→権威→キャンペーン②→限定感」**順は他LP制作のテンプレ化可能
- **「FV＝オファー・キャンペーン」**は他媒体LP（Meta／TikTok本体）にも適用可能性高い

### TikTok本体 LP（2202金融）との違い
| 項目 | TikTok本体（金融LP）| Pangle（EC LP）|
|---|---|---|
| FVベスト訴求 | プライバシー重視 | **キャンペーン**（半額等のオファー）|
| ボディ順番起点 | 共感表現 | **キャンペーン**から入る |
| CTAボタン数 | 5つ以上 | **3つ以上**（やや少なめ）|
| LP長さ | 幅の16〜20倍（=iPhone8で約8.9個分）| **18〜25スクロール**（やや長め）|
| 追従ボタン | 「診断系」が最強 | 動的CTA（GIF）8割以上 |

→ **同じLPでもTikTok本体面とPangle面で最適LPは違う**。配信面ごとに別LP用意できると理想。
