# TikTokプラットフォーム情報 〜2023年末版〜

## 出典

- 元ファイル：TikTok+プラットフォーム情報_2023年末版.pdf（全8ページ）
- 発行：**TikTok for Business**（2023年12月）
- 性質：日本TikTokにおけるユーザー投稿視聴傾向＋年末年始「お買い物」関連トレンドデータ

## 用途

- **年末年始キャンペーン**の提案根拠として（年末投稿数+30%、お買い物関連投稿+87%）
- EC・小売・コスメ・アパレル系クライアントの**Q4施策**で参考に
- TikTokに**福袋／冬コーデ／クリスマス**訴求を入れる根拠
- 検索広告活用時の**ブランド名付き検索ワード**の重要性
- 投稿時期戦略：投稿のピークが**年末**であることへの対応

---

## 1. 日本TikTok全体の視聴・投稿傾向

### 1-1. 全体傾向（2022-2023年）
- 日本国内のTikTok**視聴数・投稿数ともに増加傾向**
- 2022年から見ると**投稿のピークは年末（2022年10〜12月）**
- 視聴ピークは**夏期（2022年7〜9月）**

### 1-2. 季節指標
| 指標 | 時期 | 他月比 |
|---|---|---|
| 月平均**投稿数** | 年末時期（10〜12月）| **+30%** |
| 月平均**視聴数** | 夏期（7〜9月）| **+12%** |

### 1-3. 推測される理由
- **投稿ピーク=年末**：イベント・休日が多く、友達・家族との楽しいモーメントを記録投稿する人が増える
- **視聴ピーク=夏**：外出を控えて家でゆっくり過ごす人が多い

## 2. 「お買い物」関連の動画トレンド

※「お買い物」関連動画＝**買い物 / ショッピング / 購入 / 使ってみた / 開封**などのワードが入った動画

### 2-1. 視聴・投稿の伸び
- 視聴数・投稿数ともに**比較的伸び続けている**
- **年末年始は視聴・投稿ともに高い傾向**

### 2-2. 2023年10月の昨年同月比
- **投稿数 +87% UP**
- **視聴数 +58% UP**

→ お買い物コンテンツが**TikTokの主要ジャンルとして急成長中**。

## 太一向け次アクション視点

### Q4／年末年始キャンペーン提案フレーズ
- **「TikTokの投稿数ピークは年末（他月比+30%）」**→ クライアントの年末年始予算を厚くする根拠
- **「お買い物関連動画は前年同月比 投稿+87%、視聴+58%」**→ EC案件のQ4出稿提案根拠
- **「『ブランド名+購入品』が検索1位」**→ 検索広告活用＋自社ブランドハッシュタグ施策

### EC案件 年末年始投稿戦略（クリエイター起用 or 自社ハッシュタグ）
- **必須ハッシュタグ**：#購入品紹介＋自社ブランド名_購入品
- **季節キーワード**：#福袋 #冬コーデ #クリスマス #冬服（11-1月）
- **訴求軸**：#買わないと損 / #便利グッズ / #プチプラコーデ（価格・機能メリット）
- **コンテンツ型**：開封動画／買い物vlog／ハウル系

### 業界別アクション
- **コスメ・美容**：#美容 #コスメ＋ブランド購入品ハッシュタグで11-1月集中投下
- **EC全般**：福袋2023年版のような「年・季節特定キーワード」を活用
- **小売**：ブラックフライデー（11月末）・福袋（年始）の2山構造で予算配分

### 検索広告活用提案
- TikTok Search Adsで **「自社ブランド名 + 購入品」「自社ブランド名 + 開封」** をキーワード化
- ユーザーが**指名検索する瞬間を狙う**
- 通常のおすすめフィード広告では拾えない**潜在顕在化フェーズ**を獲得

### 投稿時期カレンダー（推奨）
```
8月： 視聴数ピーク → 認知系コンテンツ集中投下
11月〜12月： 投稿数ピーク（年末イベント）→ お買い物関連投稿展開
12月末〜1月： 検索ピーク（福袋/開封） → 検索広告で待ち受け
```
