## 用途

- **電話経由のCV（入電）を広告計測に組み込みたいとき**
- **媒体ごとの費用対効果を「電話含めて」正確に把握したいとき**（電話問い合わせが主な業種向け）
- **タップ電話と実入電のギャップを埋めたいとき**（タップCVのうち実際に繋がるのは約1/3問題）
- **キーワード単位で電話CVを計測したいとき**（SEO/SEM両方に対応）
- **Salesforce・GA4など他ツールと電話計測を連携したいとき**
- **クライアントが0120/0800番号を使っていて電話計測が難しいとき**（Google専用番号の不都合解消）

## 解決する5つの課題

| # | 課題 | Call Data Bankで解決できること |
|---|---|---|
| ① | 媒体費用対効果が不明（入電が把握できない） | 媒体別・KW別の入電数を正確に計測 |
| ② | どのキーワードから電話が入っているか不明 | KWトラッキングで入電KWを特定 |
| ③ | タップCVと実入電の大きな乖離（**実際に繋がるのは約1/3**） | 実際の通話有無を計測。タップ≠入電を正確に分離 |
| ④ | PCからの問い合わせが計測できない | PC・スマホ両対応。PCでも着信番号で計測 |
| ⑤ | Google専用電話番号の利便性問題 | 自社番号のままでも計測可能な仕組みを提供 |

## 3つのプラン

### ① Offline Tracking（オフライン経路向け）
チラシ・TVCM・看板・自社HPなどのオフライン流入を計測。
- 各媒体・施策ごとに異なる電話番号を設置し、入電経路を特定

### ② Media Tracking（デジタル媒体向け）
GDN・YDN・Facebook・Instagram等のディスプレイ広告経由の入電を計測。
- 媒体別に番号を割り当てて、媒体ごとの費用対効果を可視化

### ③ Keyword Tracking（PPC・リスティング向け）
Google・Yahoo!のリスティング広告で、**キーワード単位まで**入電元を特定する。

**番号節約ロジック（差別化ポイント）：**
- 通常KWトラッキングは「1KW = 1番号」が必要
- Call Data Bankは独自ロジックで**100KWを登録しても5番号で計測可能**
- 番号コストを大幅に削減できる

## 連携ツール

| ツール | 連携内容 |
|---|---|
| **Google広告** | オフラインCV自動インポート（入電をCVとしてGA4/Google広告に送信） |

## 主な機能

| 機能 | 概要 |
|---|---|
| **通話録音** | 全着信を録音。応対品質チェック・トレーニングに活用 |
| **音声ガイダンス（IVR）** | 自動音声メニューで部門振り分け |
| **API連携** | 独自システムへのデータ連携 |
| **SMS送信** | 通話後にフォローSMSを自動送信 |
| **ナンバーポータビリティ** | 既存番号をそのまま使いながら計測 |
| **CVメール通知** | 入電と同時に担当者へメール通知 |
| **ナンバーディスプレイ** | 発信元番号を通知 |
| **デバイス選択機能** | PC/スマホ別に異なる番号を表示する設定 |

## 導入検討時の留意点

- **KWトラッキングの50,000円/月は1,500セッションまで**。超過した場合の追加料金を事前確認
- 連携オプション（Google/Yahoo/Salesforce等）は**初期50,000円 + 月額の20%**が追加でかかる。複数連携するとコストが積み上がるため注意
- Salesforce連携は入電→商談管理を一元化できるため、インサイドセールスを強化しているクライアントに刺さる
- 通話録音機能は応対品質改善にも使える。運用部門だけでなく営業・カスタマーサクセス部門にも訴求ポイントあり
- 小規模スタートアップ（20名）なため、カスタマイズ対応力や継続性のリスクは念頭に置く
