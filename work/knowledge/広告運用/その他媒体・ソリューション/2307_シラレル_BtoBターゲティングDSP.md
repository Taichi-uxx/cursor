## 用途

- **BtoBクライアントで認知〜リード獲得を広告で支援したいとき**
- **ターゲット企業や業種を絞って配信したいとき**（業種・従業員規模・売上規模・上場区分など）
- **名刺管理データを活用して企業属性ターゲティングをかけたいとき**（Eight連携）
- **配信後に「どの企業に届いたか」をレポートで確認したいとき**（企業別・部署別・役職別imp/click）
- **BtoBのCPA改善でFacebook広告のターゲティング精度を上げたいとき**（Facebook連携オプション）
- **離脱ユーザーをリードに転換する施策を組み合わせたいとき**（LeadHackプランとのセット）

---

## サービス概要

シラレルは**企業データを活用したBtoB専用DSP**。IPアドレスと名刺管理サービス「Eight（Sansan）」のデータを組み合わせ、業種・規模・役職などの企業属性でターゲティングした広告配信を実現する。

- 導入実績：**100社突破**
- 運営：株式会社マイクロアド

---

## ターゲティング機能

### 企業属性カテゴリ（2,000以上）

| 軸 | 具体例 |
|---|---|
| 企業名 | 指定企業リストに直接配信 |
| 業種 | 製造業・IT・金融・医療 etc. |
| 上場区分 | 東証プライム・スタンダード・グロース・未上場 |
| 売上規模 | 〜1億円、1〜10億円、10〜100億円 etc. |
| 従業員数 | 〜50名、50〜300名、300名〜 etc. |
| 資本金 | 規模別 |
| 平均年収 | 高年収企業を狙った絞り込みも可 |

### データソース
- **IPアドレスデータ**：企業のオフィスIPから企業を特定
- **Eightデータ**：名刺管理で蓄積された個人×企業属性情報を活用

## 配信後レポート

**「どの企業に、誰が、どれだけ見たか」が分かるのがシラレルの最大の差別化ポイント。**

| レポート項目 | 粒度 |
|---|---|
| 企業別 | Imp / Click / CTR |
| 部署別 | Imp / Click / CTR |
| 役職別 | Imp / Click / CTR |

→ 配信後に「狙ったターゲット層にリーチできているか」を定量的に検証できる。

## オプション：Facebook連携ターゲティング

### 企業分析ターゲティング
- シラレルで配信した企業データをFacebook広告のカスタムオーディエンスに活用
- **CVR 1.42〜1.57倍の改善実績**

### スコアリングターゲティング
- シラレルの企業スコアデータをFacebook類似オーディエンス生成に活用
- 受注可能性の高い企業に似たユーザーへのリーチ拡大

## LeadHackセットプラン

### 概要
シラレルと「LeadHack」を組み合わせた離脱防止→リード転換プラン。

LeadHackは、サイト離脱直前のユーザーに**診断コンテンツ（ポップアップ）**を表示し、そのままリード（問い合わせ）を獲得するツール。

### 効果

| 指標 | 内容 |
|---|---|
| CVR改善 | **約1.5倍**（LeadHack導入実績平均） |
| コスト | シラレル契約でLeadHackが**無償提供** |

### フロー
```
シラレル配信で企業ターゲットにリーチ
→ サイト来訪
→ 離脱直前に診断ポップアップ表示（LeadHack）
→ 診断コンテンツで引き留め → そのままリード化
```

## 導入検討時の留意点

- **BtoBターゲティング＝認知広告**と割り切って使う。購買意欲が高いユーザーを集めるというよりも、ターゲット企業への接触頻度を高めるABM（アカウントベースドマーケティング）的な活用が本質
- IPアドレスベースのため、リモートワーク環境では精度が落ちる（自宅からのアクセスは企業特定できない）
- Facebook連携はオプション扱い。セットで提案するとリーチ×転換の一気通貫設計になりやすい
- LeadHackは**シラレル契約者への無償提供**なので、離脱率が高いサイトのBtoBクライアントにはセットで提案するとコスパがいい
- 導入実績100社突破しているが、具体的な事例は商談時に確認
