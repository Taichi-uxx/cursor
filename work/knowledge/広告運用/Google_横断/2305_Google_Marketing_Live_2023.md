# 1. Google AIによる検索キャンペーンの自動生成

## 概要
**Google 広告のキャンペーン作成画面に LP の URL を入力するだけで、Google AI が LP 情報を読み取り、検索キャンペーンに必要な要素一式（キーワード、広告見出し、説明文、画像アセット）を自動生成**する新機能。

## 要点
- インプットは LP URL のみ。**ゼロから人手で組まずにキャンペーンの素案が立ち上がる**
- 生成されたアセットに対して**チャット形式でフィードバック**を返すと、それを踏まえて再生成される（対話型ワークフロー）
- 検索キャンペーンの「セットアップ工数」を抜本的に圧縮することが狙い

## 詳細（実装・仕様・数値）
| 項目 | 内容 |
| --- | --- |
| インプット | ランディングページ URL |
| 自動生成されるもの | キーワード／広告見出し／説明文／画像アセット |
| 改善ループ | チャット形式でフィードバック → 新たなアセットを再生成 |
| テスト開始時期 | **2023年7月** |
| 一般提供（広告主拡大） | **2023年後半** |

# 2. 生成AIによる自動作成アセット（ACA）機能の強化

## 概要
2022年GMLで発表され、**2023年2月より英語のみオープンベータ提供**が始まっていた検索広告の**自動作成アセット（Automatically Created Assets：ACA）に生成AIを組み込む**強化。

## 要点
- ACA は LP や既存広告のコンテンツを使って見出し・説明文を自動生成する機能
- 生成AIを掛け合わせることで、**ユーザーの検索クエリの文脈に合わせて広告を出し分けられる**ようになる
- 既存のレスポンシブ検索広告（RSA）の枠組みの中で、関連性と網羅性が同時に上がる

## 詳細（実装・仕様・数値）
- 例: **検索クエリ「乾燥した敏感肌のためのスキンケア」 → 生成見出し「乾燥した敏感肌をケアしましょう」** といった形でクエリ文脈に寄せたコピーを動的に提示
- ローンチ予定: **2023年後半**
- 既存ステータス: 2023年2月から英語オープンベータ

# 3. P-MAXのアセット自動生成

## 概要
検索と同様、**P-MAXでも LP URLを入れるだけでブランドを学習し、テキスト／画像アセットを自動生成**。さらに **AIが新規生成した画像を提案**する機能を含む。

## 要点
- LP URL を起点に、Google AI が**ブランドを学習**しキャンペーン用アセットを自動生成
- **AIが新規生成した画像**を提案 → さまざまなフォーマットで顧客の注意を引きやすくする
- 検索と同じく**チャット形式でのフィードバック→再生成**のループを採用

## 詳細（実装・仕様・数値）
| 項目 | 内容 |
| --- | --- |
| インプット | LP URL |
| 出力 | テキストアセット／既存アセットの活用／AIによる新規生成画像 |
| 改善ループ | チャット形式のフィードバック → 再生成 |
| 提供開始 | **2023年後半**（第一言語が英語の国の広告主、機能の一部） |

# 4. Product Studio（Google Merchant Center Next 内）

## 概要
**Google Merchant Center Next 内で使える商品画像生成・編集ツール**。Google AI の原則に沿って設計されており、**無料で**独自カスタマイズされた商品画像を作成できる。

## 要点
- 既存の商品画像から**より多くの価値**を引き出す（再撮影せずに展開バリエーションを増やす）
- マーケティング都合（季節・キャンペーン）に合わせて**画像のシーンを柔軟に差し替え**できる
- **再撮影コストの削減**と**バリエーション展開スピードの向上**が主目的

## 詳細（実装・仕様・数値）
主な3機能。

| 機能 | 内容 | 想定ユースケース |
| --- | --- | --- |
| **背景画像のカスタマイズ** | テキストプロンプトで背景シーンを生成 | スキンケア会社が「桃に囲まれ、背景に熱帯植物がある」など季節バージョンの商品画像を生成 |
| **背景の削除** | 商品だけを切り抜き | 透過素材化、別背景への差し替え前処理 |
| **解像度の向上** | 小さい／低解像度の画像の品質をAIで底上げ | 古い在庫画像の再活用 |

- 提供時期: **米国の販売業者**に対し**今後数カ月以内**にGoogle Merchant Center Next内で提供開始予定

- **大企業も中小も同じ仕組みで安全に1stデータを扱える**ことを目指す

## 詳細（実装・仕様・数値）

# 6. Search Generative Experience（SGE）と広告

## 概要
Google I/O で発表された **SGE（生成AIによる検索体験）における広告の表示方針**が GML2023 で明示された。

## 要点
- SGEは**ユーザーの質問に生成AIで応答**し、検索行動をスマート／シンプル化する
- 検索が会話的に絞り込まれていく流れの中でも、**意図文脈に沿った広告が差し込まれる**設計
- **透明性重視**で、広告にはオーガニック結果と区別する**広告ラベル**が付与される

## 詳細（実装・仕様・数値）
- 例: 「マウイ島でできるアウトドアアクティビティ」検索 → 「子ども向けのアクティビティ」「サーフィン」と絞り込み → **子ども向けサーフィンレッスンを宣伝する旅行ブランドの広告が表示**
- オーガニック結果と広告は**明確に区別**される仕様（広告ラベル表示）

## 太一の示唆

- **「LP URL一発入力 → 検索／P-MAX両方のアセットが自動生成 → チャットで磨き込み」**という体験は、CSとして**初稿作成の工数を劇的に削減できる**。クライアントの新規キャンペーン立ち上げ時、コピー初稿は AI に出させて**人は「ブランド毀損チェックと差別化軸の注入」**に時間を寄せる運用に切り替えるべき。社内で**「生成AI初稿 → 人の編集ガイドライン」**を雛形化したい。

- ACA に生成AIが乗ることで、**クエリ文脈に合わせて見出しが動的生成**される＝広告主側で**RSAの見出し本数を網羅的に用意する重要性が相対的に下がる**。一方で**ブランドトーン・NGワード・薬機表現の制御**を Google 側の生成に委ねるリスクが上がる。**ブランド規約・除外語リストの整備**を 案件横断のチェックリストとして持っておくべき。

- **Product Studio で「再撮影せずに季節バリエーション画像を量産」**できる世界が来た。EC・D2Cクライアントには、**「撮影 → AI拡張 → 媒体出稿」**のクリエイティブ運用フローを提案できる。特に**新作投入が多いアパレル／コスメ／食品**では、**バナー制作費の削減と季節キャンペーン投入速度の向上**を同時に提案できる。

- **P-MAXのアセット自動生成 + 分析情報拡充**は、**P-MAX運用の「説明責任問題」**を緩和する方向の進化。今後は CSとして**「P-MAX任せにする部分」と「人が押さえる部分」**を案件ごとに**意思決定マップ化**して持っておくと、クライアントへの説明が一気にラクになる。

- **YouTube ショートが認知・視聴・獲得の全目的で配信可能**になった＝**ショートを「TikTok代替」ではなく「Google広告の正規メニュー」として扱える**ようになった。**縦型動画の在庫**を持っていないクライアントには、**横→縦のAI変換（動画広告の自動生成機能）**を前提に、**まず横型1本撮影→AI展開**という制作戦略を提案できる。

- **Demand Gen キャンペーンの登場**で、Discoveryキャンペーンの後継として**「ビジュアル×Gmail×Discover×ショート」を1キャンペーンで扱える**ようになる。**獲得目的だがディスプレイ／動画の入口を広く取りたい中間ファネル施策**として、**ファインドキャンペーンを Demand Gen に置き換える提案**を案件横断で走らせるべき。

- **SGEに広告が差し込まれる**＝**検索広告のクリエイティブが「ユーザーの会話の流れに沿うこと」**を求められる時代の入り口。**「単発クエリへの答え」ではなく「会話文脈の中で次の選択肢として置かれて違和感のないコピー」**という設計観点が必要。CS の広告原稿レビュー観点に**「会話文脈の中でも筋が通っているか」**を1項目追加する。

- **ファーストパーティデータ管理の簡素化＋PAIR**は、**ポストCookie時代の準備フェーズが「いまここ」**であることを示すサイン。クライアントには、**CRM／顧客リスト／フォーム入力データの「Google 広告連携状態」の棚卸し**を提案し、**1stデータ整備プロジェクト**として工数を取りに行ける。**「広告運用」ではなく「データ基盤」**として提案できると単価が上がる。

- **CTVのクロスデバイス計測**が現実的になることで、**「TV CMの代替としてのCTV」**を語れる定量根拠が増える。中堅以上のクライアントに**「TV予算の一部をDV360 CTVに振り替える」**シナリオを、ファネル可視化と合わせて提案できるようになる。

- 全体として **GML2023の本質は「広告主が触る工程を、設計と監督に寄せる」**こと。CSとしての職能を**「日々のアセット制作と入稿」ではなく「ブランド規約の設計／AI出力の品質ゲート設計／意思決定マップの維持」**に意識的にシフトしていく必要がある。**社内のCS業務フローを「AI生成前提」に書き換える**プロジェクトを、自分起点で立ち上げたい。
