## YDA（運用型）の基本構造

### 特徴

> ディスプレイ広告（運用型）は、ユーザーの属性情報や過去に閲覧したページなどの情報をもとに広告を表示することが可能。コンバージョン、サイト誘導、動画再生などさまざまな目的にあわせて広告を配信できる仕組み。

### 6つのキャンペーン目的と課金形態

| 目的 | 課金ポイント |
|---|---|
| **サイト誘導** | クリック |
| **動画再生** | 10秒再生（10秒未満の動画は視聴完了） |
| **アプリ訴求** | クリック |
| **コンバージョン** | クリック |
| **商品リスト訴求** | クリック |
| **ブランド認知** | ビューアブルインプレッション |

※その他「PayPayギフト」目的も一部のお客様向けに提供

### 使えるターゲティング例

性別・年齢・地域 / 曜日・時間帯 / デバイス / サイトリターゲティング / プレイスメント / オーディエンスカテゴリー / サーチキーワード

### 機能併用の重要性

YDAは各機能を**併用**することでパフォーマンスを最大化できる：

```
アカウント構造 × 入札価格の自動調整 × ターゲティング × クリエイティブ
       ↓
広告目的にあわせ    キャンペーン種類や目的    ターゲットユーザーの    フォーマット網羅・
最適なCP・ADG設計    に合わせ、適正な入札      細かなニーズに最適な    ユーザーニーズに
                    価格を自動調整・最適化     ターゲティング設定      合わせたクリエイティブ配信
```

#### 機能の併用による効果向上の事例

- 人材業種で、リタゲに加えて性別・年齢ターゲを実施した結果：
  - **CV数 137%増加**
  - **CV単価 変化なし**
  - **CPC 40%改善**
  - **CVR 40%低下**
- リタゲ偏重から少し広い層に拡張しても、CPC低減でCPA維持＆CV数拡大が可能

## Step1 基盤構築 (P.8-)

> 効果改善およびリーチ拡大のために、適切なアカウントの構造の構築と適切な運用を行い、パフォーマンス向上のための土台を整備することが重要。

### 3つのステップ

| Step | 内容 |
|---|---|
| **STEP01: オークションロジックの理解** | キャンペーンごとの最適化ポイントや、広告選択の仕組みを理解することで、最適な運用判断を行う |
| **STEP02: 適切なアカウント構造の構築** | 配信の最適化、最大化のためには適切なアカウント構造の整備が不可欠。拡大の土台を構築 |
| **STEP03: インプレッションシェア損失率（予算）を抑えた運用** | 1日予算による配信機会の損失が発生した状態では、最適化・最大化はできない。IMP損失率（予算）が発生しないような運用が重要 |

### 重要指標と確認ポイント

| 指標 | 目的 | アクションイメージ |
|---|---|---|
| **エンティティ数**（CP数・ADG数・広告数） | IMP分散を防ぐために、不要なCP/ADG分けをしないことが重要 | この数値がマーケット平均よりも大幅に高い場合、アカウント構造の見直しを検討 |
| **インプレッションシェア損失率（予算）** | CPの1日予算不足で広告表示されなかった割合の可視化 | 基準値より高い場合、1日予算引き上げを検討。変更難しい場合は入札価格抑制を検討 |

## オークションランクロジック（YDA独特の重要概念）

### 基本式

```
オークションランク = 入札価格 × 広告の品質（キャンペーン目的別の予測アクション率）
```

→ **効率的な改善ポイント = キャンペーン目的別の予測アクション率の向上**

### キャンペーン目的ごとの最適化ポイント

| キャンペーン目的 | 最適化ポイント |
|---|---|
| サイト誘導 | **クリック数**を最大化 |
| 動画再生 | **動画再生数**を最大化 |
| アプリ訴求 | **コンバージョン数**を最大化 |
| コンバージョン | **コンバージョン数**を最大化 |
| 商品リスト訴求 | **コンバージョン数**を最大化 |
| ブランド認知 | **ビューアブルインプレッション数**を最大化 |
| PayPayギフト | **コンバージョン数**を最大化 |

※アプリ訴求・コンバージョン・PayPayギフトでは、広告のクリック or 動画が10秒以上再生（10秒未満なら再生完了）後にサイトを訪問したユーザーがコンバージョンしたものを使用。推定コンバージョンも含む。

### 品質判定に利用するシグナル

| 区分 | シグナル |
|---|---|
| **ユーザー側** | 配信面（プレイスメント情報）/ ユーザーアクセス時間（週・時刻）/ 年齢 / 性別 / 地域 / デバイス / OS / キャリア / オーディエンスカテゴリー / 過去の検索KW情報 |
| **広告側** | 目的ごとの広告 / 広告グループ / キャンペーン / アカウント粒度の実績 / 広告フォーマット / 広告タイプ / 広告サイズ / ビューアブルフリークエンシー |

> キャンペーン、広告グループで設定可能なものの多くが読み込み可能。

### キャンペーン目的の選択フローチャート

```
                 ┌── CV数を増やしたい
                 │      │
                 │      ├── アプリ訴求のCP? Yes ──→ アプリ訴求
                 │      │
                 │      └── No ──→ ユーザーごとに最適なCRと自動生成希望のCP?
                 │                          │
                 │                          ├── Yes ──→ 商品リスト訴求
                 │                          └── No  ──→ コンバージョン
                 │
                 ├── サイト訪問者を増やしたい ──→ サイト誘導
                 ├── 動画の再生数を増やしたい ──→ 動画再生
                 ├── ビューアブルIMP数を増やしたい ──→ ブランド認知
                 └── PayPayと連動したい ──→ PayPayギフト
```

**※設定後は変更できないので慎重に！**

### オークションランクロジック（4フェーズ）

オークションは**キャンペーン内/キャンペーン外で算出ロジックが異なる**：

```
[広告グループ選択] → [広告グループ内広告選択] → [アカウント内広告選択] → [オークション]
       ↑                       ↑                          ↑                ↑
  キャンペーン内              キャンペーン内             キャンペーン外     キャンペーン外
  目的別の予測アクション率    目的別の予測アクション率    課金ポイントへの    課金ポイントへの
  ＋入札価格                  ＋入札価格                  予測アクション率   予測アクション率
                                                          ＋入札価格         ＋入札価格
```

#### キャンペーン内（同目的）vs キャンペーン外（他アカウントとの競争）

| 領域 | ランク式 |
|---|---|
| **キャンペーン内のオークションランク** | **目的別の予測アクション率**（例：CV目的ならCTVR）、入札価格をもとに決定 |
| **キャンペーン外のオークションランク** | **課金ポイントへの予測アクション率**（CV目的でもクリックベース）、入札価格をもとに決定 |

#### 動画フォーマットの場合（特殊）

- キャンペーン内: 予測CTVR、入札価格
- キャンペーン外: **予測課金再生率**、入札価格

### キャンペーン目的別の課金ポイント比較表

| キャンペーン目的 | 最適化ポイント | 課金ポイント |
|---|---|---|
| サイト誘導 | クリック数を最大化 | クリック |
| 動画再生 | 動画再生数を最大化 | 10秒再生（10秒未満は視聴完了） |
| アプリ訴求 | コンバージョン数を最大化 | クリック |
| コンバージョン | コンバージョン数を最大化 | クリック |
| 商品リスト訴求 | コンバージョン数を最大化 | クリック |
| ブランド認知 | ビューアブルIMP数を最大化 | ビューアブルインプレッション |

## Step2 最適入札

> 自動化の利用によって、Yahoo! JAPANの膨大なデータをもとにさまざまなシグナルを参照しながら、自動かつリアルタイムで投資対効果の高い広告リクエストへの入札価格を最適化。

### 重要KPI
- **入札価格調整率または自動入札のご利用金額比率**
- **自動入札ご利用金額比率**

### 自動入札タイプ（YDA）

| タイプ | 目的 | 推奨条件 |
|---|---|---|
| クリック数最大化 | 流入数増加 | なし |
| **CV数最大化（CVMax）** | 予算内でCV数最大化（IMPシェア損失改善時） | キャンペーン直近7日間でCV50件以上 |
| 拡張クリック単価 | 手動入札の機械学習補完 | なし |
| **CV単価の目標値（tCPA）** | 目標CPAでCV最大限獲得 | ADG直近30日間でCV40件以上 |
| **CV価値最大化** | CV価値合計を最大化 | 30日以内CPN単位50件CV |
| **ROAS目標値** | 目標ROASでCV最大限獲得 | 30日以内CPN単位50件CV |

詳細運用ポイントは事例編（`2111-2302_Yahoo_カンファレンス事例集_YDA編.md`）の Part 2 を参照。

## Step3 効果効率

> ユーザーの興味関心を捉え、購買意向の高いユーザーに対して確実に配信。効率的に顧客獲得することにより、クライアントのビジネスの土台を築く。

### 重要KPI
- **リターゲティングご利用金額率**
- **広告効果（CTR前週比が下がった広告の割合）**

### 主要な打ち手

1. **サイトリターゲティング**: 自社サイト訪問者への再アプローチ
2. **オーディエンスカテゴリー**: 興味関心ベースのターゲティング（500+カテゴリ）
3. **サーチターゲティング**: 検索KW・履歴期間・回数でターゲティング（競合KWも可）
4. **CTR前週比モニタリング**: 広告の摩耗・枯れを早期に検知して差し替え（事例集_YDA編 Part 4 参照）

## Step4 拡大成長

> 変化を続けるインターネット上でのユーザー行動を捉えながら、将来の顧客となりうるユーザーへのリーチを拡げることで、継続的な顧客獲得とビジネス発展に寄与。ユーザーへの配慮や、プライバシー保護による広告配信影響の中でも配信の拡大を狙う。

### 重要KPI
- **非リターゲティングご利用金額率**
- **non_yj（提携パートナー面）ご利用金額率**
- **インプレッションシェア損失率（ランク）**

### 主要な打ち手

1. **iOS14対策ターゲ**: 自社サイト流出ターゲ・ADクリッカーターゲ（事例集_YDA編 Part 1）
2. **CV予測/行動予測ターゲ**: リタゲ代替（検討〜潜在層）
3. **類似ユーザー**: 9月精度改善後の主力非リタゲ（運用マスター編参照）
4. **nonYJ面の活用**: CVR低・CPC低でCPA合うリーチ拡大手段（基礎編参照）
5. **予測ファネルターゲティング**: スコア0.6以上のユーザーには現状20%程度しかリーチできていない（事例集_YDA編 Part 5）

## Step5 最適表現

> ユーザーが求める情報に合致するクリエイティブを配信し、商品を効果的に訴求し、確実な誘導を狙う。広告の品質は、配信によるパフォーマンスの良し悪しを分ける重要な要素。

### 重要KPI
- **レスポンシブ（画像）両サイズ&バナー（画像）6:5のご利用金額率**
- **RAD（レスポンシブディスプレイ広告）ご利用金額率**
- **動画のご利用金額率**
- **広告の追加または更新の最終日**
- **画像または動画の最終登録日**

### 主要な打ち手

1. **必須サイズ網羅**: 1200×628 / 300×300 / 300×250（最小限、推奨は倍サイズ以上）
2. **RAD（アセット複数素材）の活用**: 画像15・タイトル5・説明文5を機械学習で最適選択（事例集_YDA編 Part 3 参照）
3. **動画フォーマットの追加**: 静止画との重複率9%でリーチ拡張
4. **クリエイティブPDCA**: 1ADG・1サイズあたり3〜5本、異なる訴求軸でトライアル（運用マスター編参照）
5. **CRの差し替えタイミング**: CTR前週比が下がったら差し替え（枯れ検出）

## Step6 成果維持

> 定期的に注視すべき重要指標をモニタリング・メンテナンスすることで継続的な顧客獲得とクライアントのビジネス成長に貢献。

### 重要KPI（モニタリング項目）
- **インプレッションシェア損失率（予算）**
- **広告効果（CTR前週比が下がった広告の割合）**
- **インプレッションシェア損失率（ランク）**
- **広告の追加または更新の最終日**
- **画像または動画の最終登録日**

### モニタリングルーチン

- 週次/月次で6Stepの重要KPIをアカウント診断書（六連スコア）で確認
- 業種平均との比較で改善優先度を判断
- 各KPIに対するアクションを継続実施

## So What — 戦略家視点での示唆

### 1. キャンペーン目的の選択は「設定後変更不可」の重要決定

- CV系・サイト誘導・動画再生・ブランド認知は最適化ポイント・課金ポイントが根本的に違う
- → クライアントヒアリング時に「最終KPI」と「中間KPI」を明確化、目的選定はそこで固める
- 後から目的を変えたい場合は新規CP作成が必要

### 2. オークションロジックの「内/外」切り替えはYDA設計の核心

- キャンペーン内: 目的別予測アクション率（CV目的ならCTVR）
- キャンペーン外: 課金ポイントへの予測アクション率（CV目的でもCTR基準）
- → アカウント外で勝つには「クリック率の質」も無視できない（CV目的でも）
- → 統計的優位性確保のため**ADGの不要な細分化はNG**（運用マスター編と整合）

### 3. 137%のCV増加事例は「リタゲ+性別年齢」の組み合わせ

- 完全な非リタゲ（広域）ではなく、リタゲに性別・年齢を「足す」アプローチ
- → 「いきなり非リタゲ拡大」ではなく、ターゲティング属性の追加が第一歩
- → CVR低下しても、CPC低減でCPAは維持できる構造を理解しておく

### 4. キャンペーン目的別シグナル理解で「効きやすい」打ち手を選ぶ

- 動画フォーマットは課金が「再生」になるので、予測課金再生率を意識
- ブランド認知ならビューアブルIMP最大化なので、ビューアブル率が高い面・サイズに寄せる
- → 目的別に「どのシグナルを動かすと最も効くか」を逆算してKPI設計
