## 1. 自動入札 vs 手動入札の使い分け（最重要）

### 推奨フロー（2308版・最新）

```
リタゲ案件
├ リーセンシー期間短め（1〜3日など）
│   → 手動入札推奨
│     ・オーディエンス小なので入札単価/日予算を可能な限り引き上げる
│     ・予算/ランクともにインプ損失をなくす
│
└ リーセンシー期間長め（30日以上など）
    → 手動入札推奨【NEW・2308】
      ・実績に見合った単価で入札し、日予算でなくCPC単価で配信制御
      ・余裕を持った日予算設定（インプ損失を防ぐ）

非リタゲ案件
└ 自動入札推奨
  ・学習完了に必要なCV条件（40CV/月）を担保
  ・上記難しい場合はmCV最適化の導入検討
  ・「イベント単価上限／目標」の配信戦略を利用
  ・初動に予算を寄せて配信、早期の学習完了を図る
```

### リタゲ案件での自動 vs 手動の検証（2208より）

リタゲオーディエンスサイズ別の結果：

| オーディエンス | 結論 | 根拠 |
|---|---|---|
| 小（2,000人）| **手動が低CPA** | 自動はimp多いがCTR非常に低く、入札上げないとクリック伸びない |
| 小（1,000人）| **手動が低CPC・高CVR** | 自動は高CPC・高損失率で日予算未消化 |
| 中（34,000人）| **自動が低CPA** | リタゲ枯渇前で新規ユーザーに配信できた |
| 大（697,000人）| **自動が大幅に低CPA（-80%）** | テストCPA ¥3,138 / コントロール ¥15,687 |
| 中（42,000人）| **手動が低CPA** | imp出たが低CTR・低CVRで自動が伸びず |

> 結論：**オーディエンスが狭い場合は手動が安価**。オーディエンスが広い場合はCVボリュームで判断。
> 自動入札は学習により安いオークションに多くimpを出すルールで配信されやすいため、低CPM&低CTRの傾向。

### 太一向け示唆
- リタゲ案件でCV40件/月未満 → **問答無用で手動CPC**。自動の「学習」が回らないだけでなく、安いオークションに引きずられて確度の低い面に出る
- リタゲでもオーディエンス大（5万人超）×CV月40件超 → 自動入札（クリック数最大化×CPC課金）が低CPAで着地しやすい
- 既存案件の入札方式を見直す際、「リーセンシーが長い案件で自動入札のまま」になっていたら手動切替を検討（2308検証で示唆）

## 2. 自動入札時の推奨tCPA水準（2302・新発見）

### 媒体担当者レベルで言われる理想の調整

> 他媒体：余裕を持った日予算調整（IMP損失最小に） × tCPAによる配信制限（目標値に近いtCPAで運用）
> LINE：**日予算による配信制限（IMP損失ある程度許容）× 余裕を持ったtCPA調整（実績の2倍〜3倍が推奨）**

### 検証結果（2302）

| 業界 | 期間 | tCPA水準 | 結果 |
|---|---|---|---|
| 美容（検証01） | 前期間 | ¥20,000（実績程度） | CPM¥450 / CTR0.41% / CVR0.51% / CPA¥21,331 |
| | 後期間 | **¥35,000（実績2倍弱）** | CPM¥569 / CTR0.45% / CVR0.75% / CPA**¥17,009** |
| ファッション（検証02） | 前期間 | **¥25,000（実績5倍超）** | CPM¥2,580 / CTR0.45% / mCVR**13.55%** / CPA¥23,994 |
| | 後期間 | ¥8,500（実績2倍程度） | CPM¥2,247 / CTR0.43% / mCVR10.98% / CPA¥25,728 |

両事例とも**高tCPAの方が低CPAで着地**。仮説通りCPMは上昇するが、それを上回るCTR・CVRで進捗。

### 考察
- tCPAを高い水準で設定することで、**より獲得の見込める層に配信が強化される**可能性
- IMP損失率（ランク）が改善→より最適なターゲットに配信できる
- **少なくとも実績の2倍程度**、可能であれば3倍以上の水準が効率改善につながる可能性

### 太一向け示唆
- 既存案件のtCPA設定を確認：**実績CPAより低い／同等のtCPA**で運用していたら即引き上げる
- 新規案件初動：媒体推奨水準を「実績の2〜3倍」と捉えて設定。CPA抑えたければ日予算を絞る方向で
- これは**LINEの最大の運用特殊性**。他媒体（Meta等）の「tCPAは実績付近に置く」の感覚を持ち込まないこと

## 3. 自動入札の4種の入札戦略

| 戦略 | 概要 | 配信の出やすさ | CPA最適化精度 |
|---|---|---|---|
| 入札額の上限を設定 | 上限CPAを超えない範囲で最適な入札額を適応 | 弱 | 強 |
| **イベント単価の上限**（推奨） | 設定した日予算消化を最優先、設定目標を獲得 | 中 | 強 |
| **イベント単価の目標**（推奨） | 日予算・目標CPAを超えないよう最適化（CPA上回る入札もありえる） | 中 | 中 |
| 単価の上限なしで1日の予算の消化を最大化 | 日予算範囲内で目標CPAに近づくよう最適化（CPA上回りやすい） | 強 | 弱 |

### 「単価の上限なし」検証（2208）

| 業界 | tCPA余裕 | 結果 |
|---|---|---|
| アパレル | 余裕あり | テストでCPM-64% / CTR-62% / mCVR-22%、CPA181% |
| アパレル2 | 余裕あり | テストでCPM-7% / CTR+8% / mCVR-59%、CPA138% |
| 金融 | 余裕あり | テストでCPM+4% / CTR-23% / mCVR+228%、CPA113% |
| 美容（中期間） | tCPAで制限あり | テストでCPM+23% / CTR0% / CVR-69%、CPA400% |

> 結論：**CV案件においては「単価の上限なしで日予算の消化を最大化」は非推奨**。
> 「イベント単価上限」「イベント単価目標」が引き続き推奨。

### 設定変更基準（2208より）
- STEP1：自動入札活用時は「イベント単価上限」を設定。ターゲットが広く拡大余地ある場合は「イベント単価目標」を検討
- STEP2：IMP損失率（ランク）が高く配信機会を損失している場合はtCPAの引き上げを行う
- 「単価の上限なし」はCPA度外視で日予算消化のみを求める場合に検討

## 4. 手動入札時の課金方式（CPC vs CPM）

### 2202検証結果
- 手動入札時は**CPC課金が推奨**
- CPM課金はCTR低クリエイティブにも一律で課金が乗るためCPA悪化リスク

### 2308検証（入札強化×課金方式の関係）

| 業界 | 課金 | 検証内容 | 結果 |
|---|---|---|---|
| 美容 | **CPM課金** | 入札単価 ¥500→¥1,000 | CPM+28% / CTR+24% / CVR+17% / CPA-27%（**改善**） |
| 教育 | **CPC課金** | 入札単価 ¥320→¥640 等 | CPM+33% / CTR-7% / mCVR-5% / mCPA+51%（**悪化**） |

> 結論：**CPM課金の場合は入札強化◎、CPC課金の場合は入札強化×の可能性**
> 手動入札/CPC課金の場合、Costで配信を抑制するよりも、**入札単価で配信を抑制し、余裕を持った日予算設定**が推奨の可能性

### 太一向け示唆
- 既存LINE案件で手動入札を使っているなら、**課金方式が何になっているか確認**。CPMだったら入札を強気に、CPCだったら入札単価で配信抑制＋日予算余裕設計
- ただし2308検証は事例少なく示唆レベル。要追加検証

## 5. 初期予算のかけ方・期間あたりCV数

### 必要なCV数
> 配信開始から累計**40CVsの獲得で学習が安定**し、以降も月に40CVs以上を安定的に獲得することが理想（CV目的の場合）

### 初動の予算のかけ方
> **初動に予算をかけ、早期学習完了を目指す**

### 太一向け示唆
- 新規LINE案件の予算設計：「月予算÷期間」で均等に置かない。初動2週間に予算を寄せて40CV取り切る
- 既存案件で「CVが月20-30件で頭打ち」「学習が安定しない」→ 一時的に予算強化して40CVラインに乗せ直す検討
- 40CV/月を割っている広告グループ → mCV（マイクロCV）最適化への切替検討（2308推奨）

## 6. クリエイティブ構成（フォーマット・サイズ）

### LINE広告のフォーマット一覧と優先順位

| フォーマット | サイズ | 導入推奨 | 在庫量 | 特徴 |
|---|---|---|---|---|
| 静止画 Square | 1080×1080 | ★★★★★ | 大 | 必ず導入。マイカード除く全配信面 |
| 動画 Square | 1:1 | ★★★★ | 中 | 動画FMTで最も配信面多い |
| **静止画 SIA**（Small Image Ad） | 600×400 | ★★★ | 中 | **トークリスト面に出る／CPM安価傾向** |
| 静止画 Card | 1200×628 | ★★★ | 大 | 唯一全面を網羅 |
| Carousel | 1080×1080 | ★★ | 小 | 在庫少なく高CPM傾向。リッチでCVR高い |
| 動画 Card | 16:9 | ★ | 中 | 1280×720で制作しないと見切れる |
| 動画 Vertical | 9:16 | ★ | 小 | タイムライン上では2:3比率で表示 |

### 配信面別在庫比率（2021/6時点）
- トークリスト：50.9%
- LINE NEWS：40.3%
- VOOM（旧タイムライン）：5.1%

→ **トークリストとLINE NEWSで90%超**。SIAはトークリスト面に最適化されるため低CPMで価値が高い。

### 複数サイズ追加検証（2208）

「静止画Squareのみ」vs「静止画Square+Card+SIA」を同一グループで配信：

| 課金/入札 | 結果 |
|---|---|
| 手動CPC（リタゲ） | テスト群が低CPC・高CVRでCPA安価。SIAに64%配信寄った |
| 自動CPM（興味関心） | テスト群が低CPM・高CVRでCPA安価。SIAに96%配信寄った |
| 自動CPM（リタゲ・美容医療） | SIA追加で予算+77%投下してもCPC低下・CVR上昇 |

> 結論：**同一グループで複数サイズを配信することで成果改善する可能性あり**。
> 静止画3サイズはCostシェアに大きな差がないため掲載単価の違いによる影響は少ない（Square 35% / SIA 27% / Card 17%）

### 別フォーマット追加検証（2208）
静止画グループに動画Verticalを追加 → 配信比率6%にとどまり、CPMが静止画の1.6倍で全体CPAに寄与せず。
静止画グループにCarouselを追加 → 配信比率1%、配信が伸びない。

> 結論：**静止画グループに別フォーマットを追加した場合、追加したフォーマットの配信が伸びない可能性あり**。
> CTRが高くてもCPMの観点から配信を伸ばせない。**目標CPA内でCV獲得できている場合、グループ分けして動画/カルーセル追加を検討**。

### 推奨方法
- **自動入札を使用 → 複数サイズのCRを同一グループで配信** → サイズ別CPA差があればグループ分け検討
- **手動入札を使用 → サイズ別にグループを分けて配信**（学習が影響しないためグループ分けによるデメリットなし）

### 太一向け示唆
- 新規LINE案件で「静止画Square」しか入れていないなら、**まずCard・SIAを追加**。これだけでCPA改善余地大きい
- 動画・カルーセルは「やってる感」のために追加しがち。**静止画グループに混ぜると死に在庫化する**。やるなら別グループで予算切り出し
- SIAは600×400という独特サイズ。クライアントに「LINEはSIA必須なので素材依頼します」と最初に通すのが効率的

## 7. クリエイティブ運用（カルーセル・サイズ・リフレッシュ）

### カルーセル統一性の有無（2202）
統一性なし（1枚目で完結する見せ方）の方が**高CTR・低CPC・IMP+148%/+90%**。

> 1枚目のバナー視認率は約70%。1枚目バナーが成果に最も寄与する。

### 画像サイズ指定機能（2302）
1つの広告枠で大小のサイズ枠ごとに別画像を設定できる機能。検証4事例で**CTR改善は確認できず、CPA改善には寄与しない**結果。

> 結論：枠毎のCostシェアが大幅に変動する場合があり、最適な配信比率ではなくなる可能性。**出し分けを利用せずとも媒体学習によって最適なものが選択**されている。

利用が推奨されるのは「大きいサイズ枠用に制作したクリエイティブ（1080×1080, 1200×628）を確実に小サイズ枠に掲載したくない場合のみ」。

### クリエイティブリフレッシュ（2202）
3事例の前後比較で**CPA改善はつながらない**結果（リフレッシュ実施後CTR・CVR低下）。

> リフレッシュ後、配信Costは新CRに再分配されるが、過去実績は加味されず初動実績で配信量が決定される可能性。
> クリエイティブの最適化がかかっている状況下では、**リフレッシュはCPA上昇要因になりうる**。

#### CR入替フロー（2202より）
```
新規クリエイティブの配信があまり出ない
  YES → クリエイティブ検証を実施したい
        YES → リフレッシュ後、細かく成果状況の確認、迅速なクリエイティブ精査が可能
              YES → クリエイティブリフレッシュを検討
              NO  → リフレッシュの必要なし／見送り

```

### バナーテキスト量・見出し検証（2111）

### 太一向け示唆
- カルーセル提案するなら「1枚目で訴求完結＋2枚目以降は補足」の構成で。「カルーセル＝ストーリー連動」の固定観念を捨てる
- 既存案件の「定期CRリフレッシュ運用」を見直し。学習が回っている案件では**リフレッシュ＝CPA悪化リスク**。明確な意図がない更新は避ける
- 「画像サイズ指定機能」は基本使わない。媒体学習に任せる方が結果良い

## 8. ターゲティング戦略

### CV類似 vs デモグラ（2202）
- 同一案件でCV類似配信とデモグラ配信を比較
- **デモグラはCV類似より低CVR・高CPA**になりやすい
- CV獲得メインKPIなら、デモグラ実施前にCV類似で拡大を優先

### 画像クリックオーディエンス（2202）

### ATT影響（2111）

### 太一向け示唆
- 拡大のためにいきなりデモグラに広げない。**CV類似→興味関心→デモグラ**の順で段階拡大
- CV類似の拡張率は「5%→10%→15%」と段階的にテスト

## 9. CBO（キャンペーン予算最適化）導入検証（2308）

### 機能概要
キャンペーン単位で日予算を設定すると、成果に合わせて広告グループ間で日予算を自動調整する機能。

### 必須条件
- 配下の広告グループに**手動入札の広告グループがないこと**（あると停止される）
- キャンペーン単位の日予算が5,000円以上
- THV/THVC以外のキャンペーンであること
- 広告グループ間のオーディエンスサイズ差が極端に大きくないこと（10倍以上差はNG）

### 検証結果（航空業界）
| 期間 | 結果 |
|---|---|
| CBO導入前 | 媒体CPA¥364 / 第三者CPA¥1,356 |
| CBO導入後 | 媒体CPA¥489 / 第三者CPA¥1,858 |

DID（差の差分析）で101%（≒変化なし）。Grp別実績ではCPAを最優先としたGrp間の予算傾斜は確認できず。

### 結論
> CBO実装による成果改善は見られず。**Grp間の配信傾斜は「CPA＜低CPM/低CPC」が重視される傾向**あり（Grp間のオーディエンスサイズ差が小さい場合でも低CPM/低CPCのGrpに配信集中）。
> **CBOの利用は非推奨**、Grp単位で入札コントロールができる構造が推奨。

### 太一向け示唆
- LINE案件でCBOを提案・採用しているクライアントがあれば、本検証を根拠に**手動アロケーションへの戻し**を提案
- 「CBOで全体最適」という言説に乗らない。CPA優先のロジックで動かないため、手動でCV確度高いGrpに予算寄せる方が結果良い

## 10. 媒体CVと第三者計測の乖離（2302）

### 検証結果（7案件横断データ）

| 媒体 | 乖離率平均 |
|---|---|
| GKT（Google検索）| 12% |
| YSA（Yahoo!検索）| 11% |
| YDA（Yahoo!ディスプレイ）| 38% |
| GDN（Google ディスプレイ）| 43% |
| Facebook | 61% |
| Twitter | 54% |
| **LINE** | **56%** |

> LINEはGoogle/Yahoo!と比較して乖離率が高いが、**FB/Twitterとは差なし（SNS3媒体は乖離率に差がない）**。

### 案件別の乖離傾向
| 業種 | 乖離率 | CVポイント | LP→CV階層 | 商材単価 |
|---|---|---|---|---|
| 美容 | 高 | カウンセリング予約 | 2階層以上 | 高（10万以上）|
| 保険 | 高 | 契約完了 | **8階層以上** | 高（3万/年〜）|
| サービス | 高 | 体験申込 | 6階層以上 | 無料 |
| 人材 | 高（誤差範囲）| 申込完了 | アドレス入力→メールからCV | 無料 |
| 金融 | 高（誤差範囲）| 承認・受付 | 8階層以上 | 無料 |
| **コスメ** | **低（誤差範囲）** | 商品購入 | 3階層以上 | **低（¥1,000以下）** |

→ **検討期間が長い商材／CV階層が深い商材は乖離率が高い**。コスメのような即決系は乖離率が低い。

### リタゲ／非リタゲでの差
- **リタゲ**：GDN/YDA/LINEで乖離率は誤差範囲（媒体間で差なし）
- **非リタゲ**：LINEの乖離率がGDN/YDAと比較して低い傾向（CVデータ少なくデータ信頼性低い）

### アトリビューション短縮検証（2302・金融業界）
最適化を「クリック30日」→「クリック7日」に短縮：
- 乖離率は78%→76%（**有意差なし**）
- CV7日のCVシェア（CV30日に占める）：89%→85%（4ポイント低下）

> アトリビューション期間の短縮は最適化への+効果をもたらさない可能性。短期でCVしやすいユーザーに最適化をかけられるかは判断できず。

### 太一向け示唆
- クライアントから「LINEは乖離が大きすぎて停止検討」と言われたら、**「SNS媒体共通の特性」「商材のCV階層を見直すべき」**と返す
- 検討期間が長い商材（保険・金融・人材・美容）はLINEで乖離高いことを最初に提示しておく。後出しジャンケンにしない
- アトリビューション短縮は施策として優先度低い。CVポイント手前のmCV最適化に時間使う方が効率的

## 11. Talk Head View Custom (THVC) 活用方針（2202）

### THVCとは
予約型Talk Head View（THV）と同様にLINEのトークリスト最上部に表示できる、より配信に柔軟性を持たせたメニュー。

| 比較項目 | THV（予約型）| **THVC（運用型）** | LINE広告 |
|---|---|---|---|
| 最低出稿金額 | 1,000万円〜 | **200万円〜**（2022/3以降50万〜）| 特になし |
| 配信期間 | 1日 | 1〜31日 | 柔軟 |
| 入札 | ー | 手動入札CPM課金（最低¥800）| 目的に応じて |
| ターゲティング | 指定不可（性別のみ）| デモグラ・興味関心・類似・カスタムなど | 同左 |
| 配信面 | トークリスト | トークリスト | トークリスト・VOOM・NEWS等 |

### 検証結果（5事例）

| 事例 | KPI | 結果 |
|---|---|---|
| 事例01_金融（同期間比較）| 獲得 | 通常配信よりCTR-65%、CVR+355%だがCPC916%でCPA201% |
| 事例02_飲料メーカー（同期間比較）| 獲得 | CPM¥800、CTR-59%、CPA339% |
| 事例03_金融（メニュー比較・THV vs THVC）| 流入 | THVCはCPM+34%、CTR-96%でCPC高騰 |
| 事例04_金融（フォーマット比較・静止画 vs 動画）| 流入 | **静止画の方がCTR+2170%・低CPC**。流入なら静止画推奨 |
| 事例05_不動産（リーチ）| リーチ | デモグラ広いとリーチ単価安価（¥1.60、Yahoo!プラパネ¥1.47、Facebook¥2.92） |

### 結論
> **CPMが高くコントロールできないため、現時点での獲得・流入目的での活用は難しい**。
> オーディエンス設定を広く担保すれば、**リーチ目的において活用の余地あり**。

| KPI | 傾向 | 相性 |
|---|---|---|
| 獲得（CPA）| CPM高くCPC・CPAが見合わない可能性高い | × |
| 流入（CPC）| 獲得同様CPM高くCPCが見合わない | × |
| リーチ（リーチ単価）| 広いオーディエンスを担保すれば他媒体比安価の可能性 | △ |

### リーチ目的の活用想定ケース
- 広いオーディエンス（デモグラ・ブロード）で配信したい
- セール開始時や新商品ローンチで幅広いオーディエンスに配信
- 他媒体のリーチ補完

### 太一向け示唆
- THVCを「LINE最強の運用型」と提案するクライアントには注意。**獲得KPIなら絶対推奨しない**
- リーチ施策で予算500万以上動かせるなら検討余地あり。それ未満は通常LINE広告で

## 12. 配信面アップデート（2302・2022年10月実施）

### アップデート内容
LINEファミリーアプリ（ディズニーツムツム、LINE占い等）がネットワーク面からLINE面に移動。

### 検証結果（3事例モニタリング）
| 業界 | LINE面Costシェア変化 | ネットワーク面CPC変化 |
|---|---|---|
| 金融 | 97%→94%（むしろネットワーク面シェア上昇）| ¥199→¥335（+68%）|
| 人材 | 52%→60%（やや上昇）| ¥22→¥29（+32%）|
| 人材 | 96%→99%（ほぼ変化なし）| ¥20→¥26（+30%）|

### 結論
- Costシェアの変動は明確に見られない
- **3案件共通してネットワーク面でCPC上昇**
- ネットワーク面活用案件・Costシェアの大きい案件ではCPC/CPA上昇に注意

### 太一向け示唆
- 古い「LINE面とネットワーク面のCostシェア」のデフォルト感覚（70:30など）は2022/10以降通用しない可能性
- 既存案件で**ネットワーク面のCPCがじわじわ上がっていたらアップデート影響**。配信面別の成果モニタリングを定期実施

## 14. まとめ（次アクション視点）

### 既存LINE案件の即チェック項目（優先度順）

1. **tCPA水準** — 実績CPAと同等/それ以下になっていないか？ → 2〜3倍に引き上げ
2. **入札方式** — リーセンシー長めのリタゲが自動入札のままになっていないか？ → 手動入札への切替検討
3. **手動入札の課金方式** — CPMで運用していないか？ → CPCへ切替
4. **CR最低構成** — 静止画3サイズ（Square/Card/SIA）揃っているか？ → 揃ってなければ素材依頼
5. **動画・カルーセル混在** — 静止画グループに混ぜていないか？ → 別グループ化
6. **40CV/月閾値** — 各広告グループが月40CV割っていないか？ → 予算寄せ or mCV最適化へ
7. **CBO使用** — キャンペーン予算最適化を使っていないか？ → Grp単位アロケーションへ
8. **定期CRリフレッシュ** — 学習が回っている案件でルーチン更新していないか？ → 中止検討
9. **THVC活用** — 獲得目的でTHVC提案していないか？ → 通常LINE広告へ
10. **配信面別モニタリング** — ネットワーク面のCPC上昇を放置していないか？ → 配信面別チェック

### 新規LINE案件の設計テンプレ

```
【ターゲティング】
- リタゲ（リーセンシー短・長で広告グループ分割）
- CV類似5%/10%（拡大用）
- 興味関心（業種関連）
- デモグラ（広めの拡大層・最後の選択肢）

【入札】
- リタゲ：手動CPC（オーディエンスサイズで判断、5万未満は手動確定）
- 非リタゲ：自動入札／イベント単価上限／tCPA = 実績想定の2〜3倍

【クリエイティブ最低構成】
- 静止画 Square 3本
- 静止画 Card 3本
- 静止画 SIA 3本
- （Optional）動画 Square 2本 → 別グループで切り出し

【予算設計】
- 初動2週間に総予算の40-50%を投下（早期学習完了狙い）
- 月40CV/グループを最低ライン、割れたらmCV最適化検討
- CBO使わず、Grp単位で日予算手動アロケーション

【計測】
- 第三者計測との乖離率は媒体特性として説明準備（50-60%が標準帯）
- アトリビューション短縮による改善は期待しない
```
