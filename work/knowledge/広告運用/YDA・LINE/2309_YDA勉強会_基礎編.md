# YDA勉強会① 基礎編：媒体特性・初期構造・PDCA

## 出典

- 資料名: `YDA勉強会①.docx`（アイレップ社内勉強会資料）
- ファイル更新日: 2023年9月21日
- 提供元: 株式会社アイレップ → REHATCHへの引き継ぎ知見

## 用途

- 新規YDA案件の初期構造設計（CP分割・ADG分割・リスト分割）を考える時
- 既存YDAアカウントの構造見直し・改善余地の洗い出しをする時
- 自動入札（tCPA/CV最大化）の導入判断・設定基準を決める時
- YDA配信が伸び悩んでいてIMP損失改善の打ち手を整理したい時
- クライアントにYDAの媒体特性（YJ面/nonYJ面の違い）を説明する時

## YDA媒体の3つのポイント

### 1. 掲載面：YJ面 vs nonYJ面の使い分け

| 区分 | 代表例 | CVR | CPC | CPA | 役割 |
|---|---|---|---|---|---|
| **YJ面** | Yahoo!検索結果、トップ、ニュース等 | 高 | 高 | 低 | ターゲティング精度高い・コアCV |
| **nonYJ面** | 東洋経済オンライン、ライブドアニュース、朝日新聞デジタル、食べログ等 | 低 | 低 | 結果的に合う | リーチ拡大 |

- nonYJ面は性別推定層・年齢不明層のボリュームが特に多い → **これらを除外せずに配信するのが媒体推奨**
- 運用の流れ: 最初は広げて配信→徐々に絞っていく（精査判断は約3か月の有意差で）
- Criteo・GDNからも同面に配信される場合があるので、重複除外の設定が必要

### 2. クリエイティブ：網羅性と倍サイズ入稿

- **主要サイズは網羅して入稿**しIMP・Costを担保
- 主要サイズ以外を停止することでAD単位のCV数集約・学習精度向上の余地あり
- **新規入稿は倍サイズ以上を推奨**（スマホ画面の大型化、引き伸ばし時の画質劣化、CTR改善事例）
- 動画フォーマット追加で網羅性UP（静止画との重複率9%とリーチ拡張効果が高い）

**ブラパネ入稿サイズ**
- SPブラパネ: バナー・動画ともアスペクト比16:9、最小640×360
- PCブラパネ: バナー1:1、動画は1:1と16:9両対応、最小600×600
- 動画16:9は拡大配信可能でCTR向上

### 3. ターゲティング：Yahoo!IDベースが強み

| 種類 | 特徴 |
|---|---|
| 属性（年齢・性別） | 「設定しない」で全ユーザー配信 |
| オーディエンスカテゴリ | 興味関心ベース、500+カテゴリ |
| サイトカテゴリ | 掲載サイトを指定、277カテゴリ |
| 類似ユーザー | 累積期間短縮アップデートで導入ハードル低下 |
| サーチターゲ | 検索KW・履歴有効期間・検索回数で指定、競合KWもOK |
| プレースメント | 1アカウント100件まで、1リスト1000URLまで、除外設定可 |
| リターゲティング | タグ取得→設置→リスト作成→ADG紐付け |

ユーザー特徴：SP約8割・PC約6割にリーチ、40代以上が過半数と若干上の年代向け。

## 獲得型運用の注意点

- 新規CP作成時は基本「CV」目的を選ぶ（一度設定後は変更不可）
- SPブラパネは「ブランド認知」目的のみ
- 最低日予算 50,000円以上 が必要（CPC課金ではないため）
- 掲載制限カテゴリ（美容・健康食品等）は停止連絡が来ないので注意

**獲得向けの初期推奨**: サイトリタゲ、サーチターゲ、SPブラパネから入る。

## 初期推奨構造：「分割」と「統合」のバランス

### キャンペーン分割の軸
- **メニュー（広告掲載方式）** と **日予算管理** の2軸

### 広告グループ分割の軸

| 観点 | 推奨 |
|---|---|
| **自動入札** | ADG単位で40件以上/月CVが目安。少ない場合はADG統合 or mCV導入 |
| **クリエイティブ** | 静止画と動画は別ADGに（CTR・CVR傾向が異なる、同一だと静止画に寄る）。訴求軸が違う場合も分割（男性訴求・女性訴求など） |
| **CVR傾向差** | PCブラパネ枠は切り出し（成果が大きく違う・入札高くしないと配信出ない）。シグナル粒度でCVR乖離大きい場合も分割 |

> 原則として非リタゲキャンペーンの運用は **できる限り統合** が推奨。ただし「人」と「面」のターゲを同一ADGに紐付けるとAND条件になり配信ボリューム減少するので注意。

### ユーザーリスト分割

- 自動入札では入札調整比率は反映されない
- 1ADGに対し10リストまで（サーチKWリスト/ターゲットリスト/プレイスメントリスト）
- 複数紐付け初動は成果悪化傾向あり
- 自動入札導入予定なら、手動時点で調整比率かけてから切替するとリスト最適化がスムーズ

**サーチターゲKWリスト例**: 指名 / 非指名①レディース / 非指名②メンズ / 非指名③競合
**リタゲリスト例**: 媒体推奨は「1日」「3日」「7日」「15日」「30日」。上限10個なので「top」「ほか」「EF」のように粒度集約。各リストに「CVユーザー」除外を必ず設定。

## YDAのPDCA：7つの運用レバー

1. **自動入札の導入・改善** — コールドスタート（CV少状態での導入）も可能だが媒体推奨は手動→自動の流れ
2. **オーディエンス拡張** — 類似ユーザー拡張度合い（1〜10）、非リタゲメニュー開始検討
3. **サーチターゲKWの追加・停止・分割** — 検索広告で獲得できているKW・クエリを参考
4. **アカウント構造の見直し** — 自動入札前提なら基本まとめる
5. **配信メニュー検証** — 導入後放置せず非リタゲ他メニューと比較
6. **YAD未実施案件での導入検討**
7. **クリエイティブトライアル**

## 広告配信の仕組み

- 掲載機会発生時に**広告オークション**が走り**オークションランク**が算出される
- **オークションランク = 入札価格 × 広告の品質**
- 広告の品質は「過去のインプレッション」「過去のアクション率」「推定クリック率」で構成
- → IMP・CTRにも着目しつつ最終KPI（CPA等）を網羅的に見る

## IMP損失率を下げる打ち手

### IMP損失発生時の構造
日予算増加に対してCPAは収束し、CPCは上昇しない → 同水準CPAでのCV積み増し・予算拡大提案ができる。

### 対応方法

| 方向性 | 手段 |
|---|---|
| 日予算を上げる | 上限緩和は一気にではなくパフォーマンス見ながら徐々に。一時的にCPA高騰の可能性あり（学習期間） |
| 入札抑制 | CPC・CPAを下げて捌ける量を増やす |
| **tCPA変更** | ±20%以内で実績CPAに近い値を設定。50CV/月確保。広告総入れ替えは学習リセットになるので段階的に |
| FQ設定 | 週単位/月単位設定時は週初/月初にIMP損失上がる可能性あり |
| プレイスメント配信/除外 | |
| サーチKWリスト配信/除外 | |
| サーチターゲKW増減（検索期間・回数含む） | |
| ターゲットリスト訪問履歴の延長/短縮 | |
| デモグラ配信/除外（推定ユーザー停止含む） | |
| 入稿広告サイズ限定 | |

### tCPA変更の運用フロー

- **変更前**: 実績CPA ±20%以内で設定、50CV/月確保、効果の高い広告を残して徐々に入れ替え
- **変更時**: 7日後にtCPAに合わせに行く挙動 → 7日目以降に判断。それより前に変更するなら2日空ける。戻りCV多い商材はCPA変動幅大きいので加味する
- **変更後**: 思うようなCPAにならなければ±20%で再調整。7日経過しても「学習中」消えなければ「CR改善」「ターゲ確認」「mCV導入」を検討

## So What — 戦略家視点での示唆

1. **YDAは「面の網羅」と「人の絞り込み」の2軸思考**: クリエイティブサイズ・配信面の網羅で母数を作り、ターゲティング・リスト・ADG設計で確度を上げる。
2. **過度な分割は学習を阻害する**: 統合できる単位は統合し、CV40件/ADG/月を確保することが自動入札成功の前提条件。
3. **IMP損失率は提案機会のシグナル**: 損失大きい案件は「日予算上げてもCPA収束」できる構造なので、予算拡大提案の根拠になる。
4. **手動→自動の橋渡しを設計しておく**: 手動時点で入札調整比率をかけておくと、自動切替後のリスト最適化がスムーズに進む。
