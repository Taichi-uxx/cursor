## 11種類のカスタムターゲティング

### ① 検索ターゲティング（p.8-9）

YDA（運用型）のサーチキーワードと同様のターゲティングだが、**YAD連携で実施することでより柔軟にターゲティング設定が可能**。

- **完全一致／部分一致を選択可能**
- **YDAのサーチKWに無いワードも使える**

#### 設定例（トラベルクライアント）
- 完全一致: 「国内旅行」のみ → 検索したユーザー全員が対象
- 部分一致: 「ANA 国内旅行」「国内旅行 クーポン」「jtb 国内旅行」「年末年始 国内旅行」など、含むKW多数

### ② 流出ターゲティング（p.10-11）

**ヤフードメインから特定のサイトへの訪問者（流出）をターゲティング**。競合/比較サイトのURLを指定することで、他社へ流れてしまうユーザーに対しても訴求可能。

#### 対象パターン
- 自社サイトに流出しているユーザー（タグを利用できない場合に活用＝**リタゲ代替**）
- 競合他社サイトに流出しているユーザー
- 比較サイトに流出しているユーザー（迷っている**浮動層**）

#### 注意事項
- URLのドメイン配下のパスまで指定可能
- ヤフードメインなど一部指定できないURLもある

### ③ モーメントターゲティング（p.12-15）

**「興味関心」「購買意向」「属性・ライフイベント」のカテゴリータイプで構成されているオーディエンスカテゴリーに時間軸を掛け合わせてターゲットを絞り込む手法**。

#### 仕組み
- 「1ヶ月前から興味があるユーザー」vs「以前から興味があるユーザー」で訴求を分ける
- 例: ベビー服興味関心ユーザー
  - 最近ベビー服に興味あり（1ヶ月前から）→ **出産前子育て準備中** → 子育て準備訴求
  - 以前からベビー服に興味あり → **出産後子育て中** → ベビー服品質訴求
- 例: 美容興味関心ユーザー
  - 最近美容に興味あり → 一時的な肌荒れ悩み → ニキビや肌荒れ訴求
  - 以前から美容に興味あり → 美容オタク → 成分や効能訴求

#### 活用ポイント
> ユーザーのステータスを細分化してターゲティングできるため、施策を変えることでユーザーのアクション率向上を狙うことが可能

## So What — 戦略家視点での示唆

### 1. LAETOLI/REHATCH案件の現状診断

- リタゲ79.42% : 非リタゲ20.58% という比率は**リタゲ偏重型**
- iOSリタゲ縮小トレンド（2022年時点で-10〜20%）が続くと、リタゲ依存の構造は獲得縮小リスクが高い
- → 非リタゲ拡張を「コスト比率40-50%」に持っていくのが当面のロードマップ

### 2. 11ターゲの優先導入順序（不動産投資 = COZUCHIを想定）

| 優先 | ターゲ | 理由 |
|---|---|---|
| **最優先** | 自社流出ターゲ / 自社広告クリッカー（リタゲ代替） | iOS14対策の即効性、既存リタゲの欠損補完 |
| **高** | 検索ターゲ（YAD連携） / 流出ターゲ（競合・比較サイト） | 顕在ユーザーをYDAサーチKWより柔軟に捕捉 |
| **中** | モーメントターゲ / ニューステーマ | 「興味関心 × 時間軸」で投資検討初期層を捕捉 |
| **中** | ビジネスターゲ（LBCデータ） | 高額投資商材なので「年収・職位」の代替として「企業規模・役職」が機能する可能性 |
| **任意** | ヤフーショッピングデータ / 動画視聴リタゲ / スタンバイ / 在宅者 | LAETOLIの商材特性とのフィット要検証 |

### 3. ビジネスターゲ（LBC × Eight）のBtoB活用

- 単独データ（LBCのみ、Eight名刺のみ）では取り切れない領域がある
- **「企業属性（LBC） × 個人ポジション（Eight）」の掛け合わせ**がBtoB案件の差別化打ち手になり得る
- Eight名刺は2024年9月までの試験活用なので、**期限内に検証・実績化することが急がれる**

### 4. ニューステーマの「24,000バリエーション」が他媒体との差別化点

- Yahoo!興味関心が500、ニューステーマが24,000という規模感は他媒体にない強み
- 検索行動に出ない有名人テーマ、潜在的興味関心の捕捉は、特に**認知拡大・ブランド広告**のフェーズで効く
- 事前審査必須なので、案件で活用する場合は早めにスケジュール組み込み必要

### 5. 在宅×子供を持つ親セグメントの応用範囲

- LAETOLI案件以外でも、子育て世代を狙う案件（学習教材・通信教育・宅食・保険等）で有効
- 就学状況別（乳幼児／未就学／小〜大学）でアプローチ訴求を分けられる
