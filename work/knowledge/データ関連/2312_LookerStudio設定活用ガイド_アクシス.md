## 用途（どんな時に活用できるか）
戦略家として、本資料は以下のシーンで再利用できる。

1. **クライアント向けLooker Studioダッシュボードを新規構築するとき**
   レポート設計の初期テンプレ（スコアカード＋時系列＋円グラフ＋表）を、社内の若手にレクチャー／引き継ぐ際の標準教材として利用できる。
2. **GA4／Google広告データの可視化を新人CSに教えるとき**
   「空のレポート → データソース接続 → グラフ追加 → 期間コントロール → 共有」の最短手順を、操作画面キャプチャ付きで再現できる。
3. **クライアントから「Lookerでこういう見方をしたい」と言われた要件をすぐ形にしたいとき**
   円グラフ（性別／デバイス）、時系列（セッション・新規UU・PVの複合グラフ）、表（チャネル別パフォーマンス）といった典型ビューの再現手順を即参照できる。
4. **クライアント／社内へのレポート共有設定でハマったとき**
   「制限付き／限定公開／公開」のリンク設定の違いと、メール配信スケジュールの設定箇所を素早く確認できる。
5. **重い／遅いLookerダッシュボードをチューニングするとき**
   注意点（データ量過多による動作低下）の対処の入口として、Google公式の改善ドキュメントを参照する起点に使える。

## 概要
Looker Studio（旧称: Googleデータポータル、2022年10月に改称）は、Googleが無料で提供するセルフサービス型のBI／データ可視化プラットフォーム。Googleアカウントがあれば誰でも利用でき、ドラッグ＆ドロップ操作で棒グラフ・円グラフ・表・スコアカードなどを組み合わせたインタラクティブなレポートを構築できる。

本ガイドは制作会社・代理店ユーザー向けに、「Looker Studioの概要 → 使い方の全体像 → 実践編：GA4のサンプルデータを使ったレポート作成の10ステップ → 注意点 → まとめ」の順で組み立てられている。実践編はGAのウェブ指標（セッション・新規ユーザー・PV・直帰率・チャネル・LP・性別・デバイス）を一画面に集約したダッシュボードを完成形に置く、最も典型的な「ウェブサイト分析ダッシュボード」のレシピ集である。

データソースは100以上のコネクタ（Google製品の無料コネクタ23種＋外部パートナーコネクタ719種）と連携でき、Googleアナリティクス／Google広告／スプレッドシート／BigQueryなどへの接続が標準で用意されている。作成したレポートは自動更新されるためリアルタイム性が高く、共有も「特定ユーザー」「リンクを知っている全員」「メール定期配信」など多様な手段を選べる。

注意点として、本ガイドは末尾で「レポート作成は手段でしかなく、目的は現状分析と改善策の実行」だと明確に釘を刺している。Looker Studio自体は道具であり、可視化したデータからSo Whatを引き出すことが本来の価値、という思想が貫かれている。

## 本文構造

### 第1部 Looker Studioの概要

#### Looker Studioとは
- Googleが提供する無料のBI（ビジネスインテリジェンス）ツール
- 旧称「Googleデータポータル」→ 2022年10月に「Looker Studio」へ改称
- Googleアカウントがあれば誰でも使える
- 視覚的にわかりやすい分析ダッシュボードが用意され、棒グラフ・円グラフ・表・カード形式をドラッグ＆ドロップで直感的に配置できる

> BI（ビジネスインテリジェンス）ツール：企業がデータを収集、分析し、ビジネス上の意思決定を行うために使用するソフトウェアプログラムのこと。

#### Looker Studioの主な特徴（5つ）
- [ ] **1. 無料**：Googleアカウントを持っていれば誰でも無料で利用できる
- [ ] **2. 視覚化**：収集したデータを視覚的にわかりやすいレポートでまとめることができる
- [ ] **3. 表現力**：グラフ（棒・円・表など）、テキスト、画像などを使った自由なレイアウトや表現が可能
- [ ] **4. 自動更新**：作成したレポートは自動で更新される（リアルタイムのデータが確認できる）
- [ ] **5. 共有**：作成したレポートは他の人に共有することができる

#### 100超のデータソース（コネクタ）と連携可能
| 種類 | 内容 | 代表例 |
| --- | --- | --- |
| Google Connectors（23種） | Looker Studio公式が構築・サポート。Google製品に無料接続 | Looker / Googleアナリティクス / Google広告 / Googleスプレッドシート / BigQuery / AppSheet / Amazon Redshift / Cloud Spanner / Cloud SQL for MySQL / Google Cloud Storage / Google アドマネージャー / Microsoft SQL Server |
| Partner Connectors（719種） | Looker Studioパートナーが構築・サポート。Google製品以外の外部データソースに接続 | Facebook Ads / Salesforce / Snapchat Ads / LinkedIn Ads / Semrush / Chrome UX Report / Funnel など |

### 第2部 Looker Studioの使い方（全体像）

利用フローは以下の4ステップ。

- **Step1**: Looker Studioにログインする
- **Step2**: データソースを選択し、接続する
- **Step3**: レポートを作成する
- **Step4**: レポートをもとに現状を分析し、改善策を検討する／他の人へレポートを共有する など

#### Step1. ログイン手順
1. Looker Studioのウェブサイト（ https://cloud.google.com/looker-studio?hl=ja ）にアクセスする
2. 「使ってみる」ボタンからGoogleアカウントでログインを進める

> 接続したいデータソースのアクセス権を持つGoogleアカウントでログインすること。アクセス権限が付与されたアカウントでなければ、ログイン後にデータソース選択画面に表示されない。

#### 管理画面の構成
- 左上の **「+作成」** ボタン：新規レポートを作成
- 上部の **テンプレートエリア**：用意されたテンプレートから作成
- 中段の **一覧**：過去に作成したレポートを表示

#### テンプレート活用
カテゴリ別にテンプレートギャラリーが用意されており、レポート作成の時間を削減できる。
- Googleアナリティクス用テンプレート（Acme マーケティング / eコマース / Google Merchandise Store / Google Analytics Behaviors Overview など）
- Googleスプレッドシート用テンプレート（世界人口データ / オリンピックテレビ広告の反響 / Google Account CPA/ROAS tool など）
- Google広告用テンプレート（Google Ads Overview / eコマース / Google Ads Search Auction Insights / Google Ads Search performance など）

### 第3部 実践編 レポートの作成手順（10ステップ）

完成形は、以下の要素を1画面に集約したGAウェブダッシュボード。

| 要素 | 内容 |
| --- | --- |
| 期間コントロール | レポートに表示させたい期間を選択 |
| ウェブサイトの各指標 | セッション・ページビュー・ユーザー・新規ユーザー・直帰率・ページ/セッション（スコアカード）と、その時系列推移（時系列棒グラフ＋折れ線） |
| 集客チャネル | ウェブサイトへの流入経路（表） |
| ランディングページ | ユーザーが閲覧を開始したページ（表） |
| ユーザーの性別 | サイト訪問者の性別（円グラフ） |
| デバイスの種類 | 訪問端末の内訳（円グラフ） |

#### 1. 「空のレポート」から新規レポートを作成する
- 左上「+作成」または管理画面トップの「テンプレートを使って開始」内の **「空のレポート」** をクリック

#### 2. 「データのレポートへの追加」でデータソースを選択
- ここでは **Googleアナリティクス** を選択
- 「データに接続」タブからGoogle Connectors一覧を開き、Googleアナリティクスをクリック

#### 3. 連携したいGoogleアナリティクスのアカウントを選択する
- **アカウント** → **プロパティ** の順に選択
- ユニバーサルアナリティクスのレポートビュー、またはGoogle アナリティクス 4 プロパティに接続可能

#### レポート編集画面のレイアウト
コネクタ接続後は編集画面に切り替わる。3つのエリアで構成。
| エリア | 役割 |
| --- | --- |
| メニューバー | ページやデータの追加、グラフの挿入など表現方法やツールを選択 |
| キャンバス | テキストやグラフを配置するレポートの作業エリア |
| データ | ディメンション・指標・フィルタなどのデータ設定や、色・フォントなどスタイル設定を行う |

#### 4. レポート名・レイアウトを変更する
- 左上の **「無題のレポート」** をクリックして任意のタイトルに変更
- 右上の **「テーマとレイアウト」** からテーマ・キャンバスサイズなどを変更可能

#### 5. スコアカードの作成手順
1. メニューバー → **グラフを追加** → **スコアカード** を選択（クリックでキャンバスに挿入。デフォルトは「新規ユーザー」）
2. 右側「データ」パネルの **指標** から表示したい指標へ変更（例: 「セッション」を選択するとスコアカードがセッションの数値に切り替わる）

#### 6. レポートの期間設定（全体）
1. メニューバー → **挿入** または **コントロールを追加** → **期間設定** を選択
2. 開始日／終了日のカレンダーから、レポートに表示させたい期間を指定（例: 2022年1月1日〜2022年1月31日）
- 「絶対指定」「相対指定」が選べる
- 設定した期間がレポート内の全スコアカード・グラフに反映される

#### 6-補. 特定の表やグラフだけ期間を固定する場合
- 対象オブジェクトをクリック → 「データ」パネル内の **「デフォルトの日付範囲」** で **カスタム** を選択し、固定したい期間を設定
- カスタム指定したオブジェクトは、上記「6. レポートの期間設定」の影響を受けない
- 「比較期間」も同時に設定可能

#### 7. 時系列グラフの作成
時系列グラフは、年・月・日ごとの指標の変化をわかりやすく表現し、数値の変動をひと目で理解できる。

- **STEP1**: メニューバー → **グラフを追加** → **期間（時系列グラフ）** を選択
- **STEP2**: 右側「指標」に、表示したい複数の指標を追加（例: セッション／新規ユーザー／ページビュー数）
- **STEP3**: 桁が大きい指標を別軸にしたい場合は、グラフ表現を変える（複数指標が同じ軸だと推移が読み取りにくい）
- **STEP4 グラフのスタイル変更**:
  1. グラフを選択し、右側「スタイル」タブをクリック
  2. 系列3（ページビュー）を **折れ線 → 棒グラフ** に変更
  3. 軸を **「左」→「右」** に変更（第2軸化）
- 結果として「セッション・新規ユーザー（折れ線・左軸）」と「ページビュー数（棒・右軸）」が読みやすく同居する複合グラフが完成

#### 8. 円グラフの作成
1. メニューバー → **グラフを追加** → **円** を選択
2. **訪問者の性別を表示**: ディメンションを **「性別」** に変更（male / female の構成比が出る）
3. **デバイスの種類を表示**: ディメンションを **「デバイスカテゴリ」** に変更（desktop / mobile / tablet の構成比が出る）

#### 9. 表の作成
1. メニューバー → **グラフを追加** → **表** を選択
2. ディメンションと指標を変更：
   - ディメンション: **Default Channel Grouping**（デフォルトチャネルグループ）
   - 指標: **セッション** / **ページビュー数** / **ユーザー** の3つを追加
3. **項目名の日本語化（任意）**: ディメンション欄の「Default Channel Grouping」をクリック → 「名前」欄を **「アクセス経路」** に変更。同様に指標も「アクセス数 / PV数 / ユーザー数」など日本語表示に変更可能
- 1つのディメンション（アクセス経路）に対して複数の情報を一覧で確認できる

#### 10. 作成したレポートを他者に共有する

##### ① 特定の人物に共有する場合
1. レポート画面右上の **「共有」** ボタンをクリック
2. ユーザー追加欄に **「名前」または「メールアドレス」** を入力
3. **「閲覧者」** または **「編集者」** の権限を設定
4. 「ユーザー通知の送信元メール」にチェックを入れて送信すると、共有通知メールが追加ユーザーへ届く

##### ② リンクを知っているすべての人物に共有する場合
1. レポート画面右上の **「共有」** ボタンをクリック
2. **「リンク設定」** からレポートの公開条件を選択：

| 公開条件 | 内容 |
| --- | --- |
| 制限付き | 追加されたユーザーのみが、レポートのリンクから開ける |
| 限定公開 | リンクを知っているインターネット上のユーザーであれば、誰でも閲覧できる |
| 公開 | リンクを知っているインターネット上のユーザーであれば、誰でも検索・閲覧できる |

3. 変更を保存し、リンクを共有したい人に送信

##### ③ 決まった時間に定期共有する場合（メール配信スケジュール）
1. レポート画面右上の **「共有」ボタン横にある「▼」** をクリック
2. **「メール配信をスケジュール」** をクリック
3. 宛先・（共有する）ページ・開始時刻・リピートを入力 → スケジュールをクリック
- これで共有の手間が省け、常に最新のレポートを各自が確認できる

### 第4部 Looker Studioを使用する際の注意点

#### 1. データソースの接続に注意しましょう
- レポート作成にはまずデータソースに接続する必要がある
- 間違ったデータソースに接続すると正しい計測ができない
- 接続先データソースの追加または変更は、メニューバーの **「データを追加」** から選択

#### 2. レポートの共有先に注意しましょう
- 作成したレポートを他者へ共有する際は、共有先やアクセス権限の設定に注意が必要
- 間違った共有設定で、機密データが外部漏洩するリスクがある
- 共有設定は1つずつ確認しながら進めること

#### 3. Looker Studioの動作が重くなることがある
- 複数のデータソース接続、1ページに複数のグラフ・表を使用すると、処理データ量が増えて動作が遅くなる
- 改善方法はGoogle公式サイトを参照: https://support.google.com/looker-studio/answer/9967561?hl=ja

### 第5部 まとめ
- Looker Studioは無料でレポートを作成できる便利なBIツール
- ただし **レポート作成は手段でしかない**。レポート作成が目的化することがよく起こりうる
- レポート作成前に **「確認したいデータは何か」** を明確にする
- レポート作成後は **現状の課題を発見し、改善策を考え、実行する** ことが大切

## 太一視点の示唆 / 次のアクション

### 既存のLookerマスターに反映したい知見
1. **「目的が先、可視化は手段」の冒頭明記をテンプレ化する**
   このガイドが最後に強く釘を刺している「レポート作成は手段」というメッセージは、自分がクライアントに渡すLookerダッシュボードの一番上に **「このダッシュボードで意思決定したい問い」** を必ず記載するルールに昇華する価値がある。「眺めて終わる」レポートを減らせる。

2. **項目名の日本語化を標準フローに組み込む**
   p.28の「Default Channel Grouping → アクセス経路」「セッション → アクセス数」のような **項目名のカスタム名変更** は、クライアントが英語＆GA用語に慣れていないケースで効く。社内のLooker作成チェックリストに「英語フィールドはそのまま出さない」を入れる。

3. **複合グラフの第2軸テクニックを標準化する**
   セッション・新規ユーザー（左軸折れ線）＋ PV（右軸棒）の構成は、桁の違う指標を1グラフで見せる定番形。**KPI単位の桁差で読みにくいクライアントレポートはほぼこのパターンで救える**。

4. **「特定のグラフだけ期間固定」の使いどころを明文化する**
   「比較期間」や「直近30日間 vs 全体期間」のような、全体コントロールに従わせたくないオブジェクトの作り方は知らないと詰む。社内マニュアルに「ハマりポイント」として追記したい。

5. **共有設定3階層（制限付き／限定公開／公開）の使い分けをルール化**
   情報漏洩リスク観点で、**クライアント納品時は「制限付き」をデフォルト**にする運用ルールを作る。社内共有も含め「公開（検索可）」は原則NG、というガイドラインに落とせる。

### 次のアクション（具体）
- [ ] 自分のLookerマスター（社内ナレッジ）に「① 問いの明記欄」「② 項目名日本語化チェック」「③ 共有設定の原則『制限付き』」の3つを追加する
- [ ] クライアント向けレポート設計テンプレに「複合グラフ（左右軸）」を1ブロック標準採用する
