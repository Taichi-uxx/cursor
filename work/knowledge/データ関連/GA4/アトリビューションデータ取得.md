# GA4アトリビューションの生データ取得はBigQuery連携が必須

## 出典

- **形式**: 単発メモ（田村太一が受領してストック）
- **収録日**: 2026-09
- **原典**: 出典URLなし（内容の一次情報は Google 公式 GA4 ヘルプ「BigQuery Export」）
- **関連**: [2309_GA4資料.md](2309_GA4資料.md)（GA4完全リファレンス。BigQuery連携も含む370pの教科書）／ [2309_BigQuery勉強会.md](../2309_BigQuery勉強会.md)

## 用途（どんな時に活用できるか）

- クライアントに「GA4のアトリビューション、標準レポートで見えないところまで追いたい」と言われた時の第一の答え
- 「広告接触履歴（どの広告 → どの広告 → CV のパス全部）」を SQL で自由分析したい時のセットアップ判断
- Looker Studio や自作BIで、GA4標準レポート以上の粒度でアトリビューション可視化する時の前提整備
- 提案書で「MMM / データドリブンアトリビューション の高度化」文脈で BigQuery連携の必要性を説明する時

---

## 要点

- **GA4の管理画面上ではアトリビューションのローデータ（生データ）は取れない**
- **Google Cloud「BigQuery」と連携すると、ユーザーが購入に至るまでの全広告接触履歴などの詳細データを SQL で分析可能**になる
- **GA4無料版でもBigQuery連携は可能**（GA4の大きなアップデートポイント。旧UAでは有料版のみ）
- 連携は GA4管理画面 → プロパティ設定 → BigQueryのリンク から設定

## 太一の示唆

### なぜこれが広告運用者にとって重要か

- **GA4標準のアトリビューションレポートは、モデル固定＋粒度制限**があり、以下ができない：
  - CV前の**全接触チャネル・全キャンペーンの完全パス**の可視化
  - 「初回接触が Meta広告 → 検索指名で CV」のような**チャネル横断の中間貢献度**の任意集計
  - **Facebook Click ID / GCLID など広告ID単位**でのパス分析
- BigQueryに落とせば、GAM/Meta/Google広告のコストと **JOIN してROI視点でのアトリビューション分析**が可能

### 導入時の実務注意点

- BigQuery連携で流れてくるデータは **前日分（Daily Export）** が標準。ストリーミングExportは追加コスト
- **クエリ課金**（オンデマンド $6.25/TB程度）が発生するため、大規模サイトでは想定コスト試算が必要
- **BigQuery Sandbox（無料枠）** で小規模検証は可能。10GBストレージ・1TB/月クエリまで
- 一度連携すると **過去データは遡ってExportされない**（連携日以降のみ）→ **早めに繋げる**のが得

### クライアントへの提案タイミング

- GA4移行完了後、標準レポートで見たいアトリビューションが取れない不満が出た時
- MMM／データドリブンアトリビューションを本格導入したい時
- 広告費が月100万円以上で、チャネル横断の投資配分最適化を数値で判断したい時
