---

## ① パーソナルエージェント

「自分専属の秘書」的存在。以下を自動化する。

### 具体例
- **モーニングブリーフィング**: 毎朝、カレンダー予定・未完了タスク・未読メールをピックアップして通知
- **面接／会議／会食の事前ブリーフィング**: 同席者の会社概要・直近トピック・その人の経歴/最新発信/関心領域をDeep Researchで調査
  - 結果を**自分のみ権限のGoogleドキュメント**に出力
  - **Googleカレンダーの該当予定に添付**
- **日程調整**: 自分の好み（スコアリングロジック）を教え込んで最適化
  - 移動時間考慮
  - 「金曜は集中したいから予定入れない」
  - 「面接・登壇後はソフトな予定にする」
  - 候補日仮入れ→確定後に他候補を削除、といった日程調整サービス相当の動きもSkillで実現可能

### 前提の重要ポイント
> 社内データを扱う場合はアクセス権限や保存先などのガバナンスをきちんと設計することが前提

### 効果
> これを作り込んでからはあまりによすぎて調整系サービスを使わなくなりました

## ② パーソナルナレッジベース

自分に関連するコンテキスト・データを溜め、以下を自在に：
- RAG的に自由に質問
- Deep Research的にレポート生成
- ダッシュボードアプリ生成

### NotebookLMとの違い（自作するメリット）

| 観点 | Gemini Notebook（旧NotebookLM） | 自作KB |
|---|---|---|
| ソースファイル数 | ノートブックごと制限あり | 無制限 |
| データ取得・加工フロー | カスタム不可 | 独自ロジック作り込み可 |
| 出力の動作ロジック | ブラックボックス | 全て制御可能 |
| データ量スケール | 増えるとカオス化 | アーキテクチャ次第で無限に耐える |

### コア設計思想：メダリオンアーキテクチャ

オリンピックの金・銀・銅メダルに由来する **3層データアーキテクチャ**。データ分析基盤の基本形。

```
┌──────────────────────────────────────────┐
│ 🥇 Gold層                                │
│ KPI化・集計・分析済みデータ                │
│ → レポート／ダッシュボードの直接ソース      │
└──────────────────────────────────────────┘
              ↑ 集計・分析
┌──────────────────────────────────────────┐
│ 🥈 Silver層                              │
│ 人物・企業・会議など単位で構造化・正規化    │
└──────────────────────────────────────────┘
              ↑ 解析・構造化
┌──────────────────────────────────────────┐
│ 🥉 Bronze層                              │
│ PDF/PPTX/XLSX/メール/議事録などの原本      │
│ → 触らず保存（再生成の起点）              │
└──────────────────────────────────────────┘
```

### メダリオンの決定的メリット
> Bronze層は取得したPDFやPPTX、XLSXなどのデータそのものを触らず保存しておくことで、**Silver層のロジックを変えてもいつでも再生成できる**ことがポイントです。

- **データ量が増えても破綻しにくい**
- **ロジック変更＝再生成で済む**（原本が守られているため）
- **用途ごとにGold層を作り分けられる**（同じBronze/Silverから複数の用途別Gold）

この2つを作り込んでいくと：
1. どんどん大規模化
2. AIレベルがガンガン上がる
3. 開発効率化のため **loop engineering / graph engineering** 的なことをやりたくなる

5. 「つくりたいものだらけ」の状態に

### 実装のコツ
> 小さくつくるのはそこまで難しくないので、毎日の業務の中から少しずつ育てていける

## 太一の活用アイデア

### パーソナルエージェント編

**モーニングブリーフィング（毎朝）**
- Gmail未読／Slack未読／Chatwork未読の重要度判定＋要約
- Googleカレンダーの当日予定＋前後日のクライアント予定サマリ
- work/個人/dailyreport/の前日日報から未完了アクション抽出

**クライアントMTG事前ブリーフィング**
- 同席者のLinkedIn・X・会社最新プレスリリースをDeep Research
- 過去の議事録・チャット履歴から論点・懸案事項を抽出
- 「前回言ってた〇〇の進捗どう？」レベルまで拾える資料を自動生成
- 出力先: 自分のみ権限のGoogleドキュメント → カレンダー予定に添付

**カジュアル面談／会食の事前調査**
- 相手の経歴・最近の発信・関心領域
- 太一からの刺さりそうな話題候補3つ
- appeal-matchスキルの出力とセットで運用

### パーソナルナレッジベース編（メダリオン適用）

**Bronze層（原本保存）**
- クライアント別の議事録・提案書・レポートPDFをそのまま `work/client/{クライアント}/bronze/` へ
- 参考記事・X投稿・YouTube書き起こしを `work/AI活用/bronze/`
- 日報を `work/個人/dailyreport/`

**Silver層（構造化）**
- クライアント単位・案件単位・KPI単位で正規化
- `work/client/{クライアント}/silver/` に構造化mdを配置
- 例: `client_overview.md` `kpi_history.md` `key_persons.md`

**Gold層（用途別集計）**
- 月次レポート用サマリ: `client/{クライアント}/gold/monthly_report_2609.md`
- クライアントヘルスチェック用ダッシュボード用: `gold/health_dashboard/`
- AI Hourネタ集計用: `AI活用/gold/ai_hour_topics.md`

**再生成のポイント**
- Silverロジックを変えても、BronzeがあればいつでもSilver→Gold再構築可能
- クライアント別の月次レポートテンプレを変更したら、Gold層だけ全案件分バッチ再生成

### 次にやること（Boot Camp的な段階設計）
1. **Week 1**: モーニングブリーフィングだけ作る（Gmail要約→Slackポスト）
2. **Week 2**: クライアントMTG事前ブリーフィング（Deep Research連携）
3. **Week 3**: メダリオン層のフォルダ設計＋Bronze層への原本流し込み自動化
4. **Week 4以降**: Silver→Gold層のロジック・Skill化して、月次業務ルーチンに組み込む
