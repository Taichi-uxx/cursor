# Claude Code のエージェント「App Store」= aitmpl.com が登場

100+のプリメイドエージェント・スキル・テンプレートを `npx` 一発で導入できるオープンソースライブラリ「[aitmpl.com](https://aitmpl.com/)」がリリースされ、Xでバズった、というJuntaro氏の紹介投稿。Anthropicの「エージェントを作るな、スキルを作れ」という方針が具現化した形。

## 用途（どんな時に活用できるか）

- Claude Code で新しいエージェント／スキルを自作しようとした時、まず「既製のものが aitmpl.com にないか」を確認する初動チェック用として
- 「デスクトップ整理」「ファイル分類」など**汎用的な業務効率化タスク**を Claude Code に任せたいが、自分で書くのは面倒 → 既製エージェントをそのまま使う判断材料に
- 社内メンバーに Claude Code の実用例を紹介する時のネタ元（「車輪の再発明しなくていい時代」のわかりやすい例）
- Anthropicの「スキル中心」思想が実運用レイヤーでどう現れているかを理解する材料として

## 要点

### 何が起きたか

- **aitmpl.com** という Claude Code 向けのオープンソーステンプレートライブラリが公開された
- 100以上の**プリメイドエージェント・スキル・テンプレート**が入っている
- インストールは `npx claude-code-templates@latest xxx` で一発。100%無料
- 引用元の Alvaro Cintas 氏の英語投稿は表示24万超・いいね2,500超でバズ

### Juntaro氏の使い方（実例）

> 私はこれの「File Organizer」エージェントをインストールして、デスクトップの整理をしてもらいました。笑

### 提供される4パターン

- ✅ 再利用可能な**スキル**を組み合わせる
- ✅ **テンプレート**をベースにカスタマイズする
- ✅ **プリメイドエージェント**をそのまま使う
- ✅ `npx claude-code-templates@latest xxx` のシンプルなインストールコマンド

### 大きな流れ

> 「AIエージェント開発」から「AIスキル組み合わせ」へ。
> Claude Codeのエコシステム、急速に成熟してきた。

Anthropic が公言している「**エージェントを作るな、スキルを作れ**」という方針が、コミュニティレベルの実装として具現化した位置付け。

## 太一の示唆

- 自分で `create-skill` を叩く前に、aitmpl.com で既製スキルを1度は探すクセをつける。特にファイル整理・議事録整形・定型出力系はほぼ既製で足りる可能性が高い
- 自作スキル（AI-Studio制作系など）は「aitmpl.com にはない、太一固有の業務ロジック」に絞る方向で棲み分けると、スキル数が肥大化しない
- 社内・クライアントに Claude Code の実力を1分で伝える時、「aitmpl.com からエージェント引っ張ってきてデスクトップ整理してくれた」は超わかりやすい導入エピソードとして使える
- 「エージェント開発」→「スキル組み合わせ」の潮流は、CS業務の自動化設計にも同じことが言える。個別プロンプトを書く前に「既存スキルの合成で解けないか」を先に問う
