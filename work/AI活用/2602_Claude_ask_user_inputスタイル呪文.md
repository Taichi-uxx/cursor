# Claude「ask_user_inputスタイルでお願い」呪文

## 出典
- 著者: テツメモ（@tetumemo）｜AI図解×検証
- URL: https://x.com/tetumemo/article/2020942907918909493
- 投稿日: 2026年2月10日
- 前提: Claude Opus 4.6以降で使える新機能

## 用途（どんな時に活用できるか）
- **フワッとしたアイデアしかなく、詳細プロンプトが書けないとき** — 「AI◯◯を作りたい」レベルの粒度で放り込みたい時
- **要件定義・企画の壁打ちを一問一答でやりたいとき** — キーボード入力せずポチポチ選択で進めたい
- **クライアント案件のヒアリング項目を漏れなく詰めたいとき** — Claudeに「何が足りないか」を先に聞かせる
- **プロンプト設計に疲れた／時間がないとき** — 長文プロンプト作成の代替として

## 呪文の中身

プロンプト末尾に以下1行を追加するだけ：

```
ask_user_inputスタイルでお願い
```

これでClaudeが回答の代わりに **選択肢＆チェックリスト形式のインタラクティブカード** を出してくれる。ユーザーはポチポチ選ぶだけ。

## 最強セット（推奨）

以下2つをセットで使うと100%この動作になる：

```
[やりたいこと]
という指示をしようと思っているけど、
指示で不足してる部分があればステップバイステップで
ユーザーに一問一答で確認して

ask_user_inputスタイルでお願い
```

`ask_user_input` を辞書登録しておくと呼び出しが楽。

## 実際の挙動（例：AI Tuber英会話アプリを作りたい）

### ①キャラクター設定の確認（単一選択）
```
- 既存のキャラクターデザインがある
- 新しくキャラクターを作りたい
- シンプルなアバターで良い
- キャラクターは不要（音声のみ）
- その他
```

### ②機能の確認（複数選択チェックボックス）
```
☐ フリートーク会話練習
☐ シチュエーション別会話（旅行・ビジネスなど）
☐ 発音チェック・矯正機能
☐ 文法・語彙の解説機能
☐ その他
```

### ③アプリ形式の確認
```
- Webアプリ（ブラウザで動作）
- ネイティブアプリ（スマホにインストール）
- スマホアプリ風のUI
- まだ決めていない
- その他
```

### ④最終アウトプット
選択結果をまとめて要件定義書（プロジェクト概要／ペルソナ／機能／技術スタック等）を自動生成。そのまま次の設計書・仕様書作成フェーズへ移行できる。

## なぜチート級か（示唆）

- **入力コストがゼロに近づく** — キーボード入力→クリック選択への変換で、思考エネルギーを「選ぶ」だけに集中できる
- **AI側が「何が足りないか」を提示してくる** — 従来はユーザーがコンテキストを想像して埋めていたが、逆転する
- **選択肢が示されることで発想が広がる** — 自分では思いつかない選択肢（例：「発音チェック機能」）を提示される
- **要件定義の抜け漏れが構造的に減る** — Claudeが標準的な確認項目を網羅してくれる

## 太一の活用アイデア

- **クライアントヒアリング前の下準備** — 「◯◯業界のクライアントに広告運用提案する時、確認すべき項目は？」でチェックリスト化
- **新規スキル/ワークフロー設計時の要件詰め** — フワッと「◯◯を効率化したい」と投げて選択で詰める
- **企画壁打ち** — コンテンツ企画・LP企画の初期段階、選択形式で叩き台を作る
- **辞書登録推奨** — `askuser` → `ask_user_inputスタイルでお願い` で登録して習慣化
