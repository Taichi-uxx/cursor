# n8n ショート動画半自動生成ワークフロー詳細

## 概要

このワークフローは、n8nを使用してショート動画を半自動で生成するシステムです。アイデア入力から完成動画の保存まで、AIを活用して効率的に動画コンテンツを作成します。

### 基本コンセプト

従来の動画制作では、台本作成、音声録音、字幕作成、画像・動画編集など、多くの手作業が必要でした。このワークフローでは、**AIを活用して各工程を自動化**することで、最小限の入力（アイデア）から高品質なショート動画を生成します。

### 主な特徴

- **最小限の入力**: アイデア（例：「恋愛雑学」）を入力するだけで動画作成が開始
- **AI活用**: OpenAI API、VOICEVOX、ElevenLabs STTなど、複数のAIサービスを組み合わせ
- **自動化**: 台本作成から動画レンダリングまで、ほぼ全自動で処理
- **高品質**: 自然な音声、適切なタイミングの字幕、シーンに合った画像を自動生成

---

## ワークフロー全体構成

このワークフローは以下の7つの主要ステップで構成されています：

1. **アイデア入力** - 動画のテーマを入力
2. **台本作成** - AIで台本を自動生成
3. **音声作成** - VOICEVOXで音声を生成
4. **字幕作成** - STTとAIで字幕とタイミングを調整
5. **画像作成** - AIでシーン別画像を生成
6. **動画レンダリング** - ffmpegで素材を統合
7. **完成品保存** - Google Driveに保存

## ステップ1: アイデア入力

### 目的

作りたい動画のアイデアやテーマを入力するためのステップです。これがワークフローの起点となります。

### ノード構成

#### 1. Set ノード（アイデア入力）

- **ノードタイプ**: Set
- **処理内容**: 動画のテーマやアイデアを設定
- **設定例**:
  ```json
  {
    "idea": "恋愛雑学",
    "video_length": "60秒",
    "style": "エンタメ"
  }
  ```
- **出力**: 1 item（アイデア情報を含むデータ）

### 実装のポイント

- **シンプルな構成**: Setノード1つだけで完了
- **柔軟な入力**: テキストだけでなく、追加パラメータ（動画の長さ、スタイルなど）も設定可能
- **拡張性**: 後続のステップで使用するパラメータをここで定義

### 使用例

- 「恋愛雑学」→ 恋愛に関する雑学動画を生成
- 「健康の豆知識」→ 健康情報の動画を生成
- 「プログラミングTips」→ 技術系の動画を生成

## ステップ2: 台本作成

### 目的

入力されたアイデアを基に、動画用の台本をAIで自動生成します。JSON形式で出力することで、後続の処理で構造化データとして扱いやすくします。

### ノード構成

#### 1. Message a model ノード（台本生成）

- **ノードタイプ**: OpenAI / Message Model
- **モデル**: `gpt-4.1-nano`
- **処理内容**: アイデアを基に動画用台本を生成
- **プロンプト例**:
  ```
  以下のテーマでショート動画用の台本を作成してください。
  テーマ: {{ $json.idea }}
  
  要件:
  - 60秒程度の動画に収まる長さ
  - シーンごとに分割
  - JSON形式で出力
  - 各シーンに画像生成用のプロンプトも含める
  
  出力形式:
  {
    "title": "動画タイトル",
    "scenes": [
      {
        "scene_number": 1,
        "script": "台本テキスト",
        "duration": 10,
        "image_prompt": "画像生成用プロンプト"
      }
    ]
  }
  ```
- **出力**: 1 item（JSON形式の台本データ）

### 実装のポイント

#### JSON形式の強制出力

- **システムプロンプト**: 「必ずJSON形式で出力してください」と明示
- **出力パース**: CodeノードでJSONをパースし、構造化データとして扱う
- **エラーハンドリング**: JSON形式でない場合のリトライ処理

#### 台本の品質向上

- **シーン分割**: 動画をシーンごとに分割し、各シーンに適切な画像を割り当て
- **長さ調整**: 動画の長さに合わせて台本の文字数を調整
- **画像プロンプト**: 各シーンに対応する画像生成用プロンプトも同時に生成

### 出力データ構造

```json
{
  "title": "恋愛雑学：初デートの意外な真実",
  "scenes": [
    {
      "scene_number": 1,
      "script": "初デートで意外と知られていない事実があります。実は、初デートの場所選びで、その後の関係性が決まると言われています。",
      "duration": 15,
      "image_prompt": "初デートのカップル、カフェで話している様子、明るい雰囲気、イラスト風"
    },
    {
      "scene_number": 2,
      "script": "特に、静かな場所よりも、適度な賑わいがある場所の方が、会話が弾みやすいという研究結果があります。",
      "duration": 12,
      "image_prompt": "賑やかなレストラン、カップルが楽しそうに会話している、温かい雰囲気"
    }
  ]
}
```

## ステップ3: 音声作成

### 目的

生成された台本を基に、VOICEVOXを使用して音声を生成します。VOICEVOXはローカルで動作する無料の音声合成エンジンで、高品質な日本語音声を生成できます。

### ノード構成

#### 1. Split Out ノード（シーン分割）

- **ノードタイプ**: Split Out
- **処理内容**: 台本の各シーンを個別のアイテムに分割
- **入力**: 1 item（台本データ）
- **出力**: N items（シーン数分のアイテム）

#### 2. VOICEVOX Request ノード（音声生成）

- **ノードタイプ**: HTTP Request
- **エンドポイント**: `http://localhost:50021/synthesis`（VOICEVOXのローカルAPI）
- **メソッド**: POST
- **処理内容**: 各シーンの台本テキストを音声に変換
- **リクエストボディ例**:
  ```json
  {
    "text": "{{ $json.script }}",
    "speaker": 3,
    "speedScale": 1.0,
    "pitchScale": 0.0,
    "intonationScale": 1.0
  }
  ```
- **出力**: N items（各シーンの音声データ）

#### 3. Upload audio file ノード（音声ファイル保存）

- **ノードタイプ**: Google Drive (Upload)
- **処理内容**: 生成された音声ファイルをGoogle Driveに保存
- **ファイル名**: `scene_{{ $json.scene_number }}.wav`
- **出力**: N items（保存された音声ファイル情報）

#### 4. 音声ファイルIDセット ノード（ID記録）

- **ノードタイプ**: Set
- **処理内容**: 保存された音声ファイルのIDを記録
- **設定**:
  ```json
  {
    "audio_file_id": "{{ $json.id }}",
    "scene_number": "{{ $json.scene_number }}"
  }
  ```
- **出力**: N items（音声ファイルIDを含むデータ）

### 実装のポイント

#### VOICEVOXのセットアップ

- **ローカル実行**: VOICEVOXはローカル環境で実行する必要がある
- **APIエンドポイント**: デフォルトで `http://localhost:50021` で起動
- **スピーカー選択**: 複数の音声キャラクターから選択可能（例：ずんだもん、四国めたんなど）

#### 音声パラメータの調整

- **speedScale**: 話す速度（0.5〜2.0）
- **pitchScale**: 音の高さ（-0.15〜0.15）
- **intonationScale**: 抑揚の強さ（0.0〜2.0）

#### エラーハンドリング

- **VOICEVOX接続エラー**: ローカルサーバーが起動していない場合の処理
- **音声生成失敗**: リトライ処理や代替手段の実装

## ステップ4: 字幕作成

### 目的

生成された音声に合わせて、適切なタイミングでテロップを表示できるように字幕（SRTファイル）を作成します。ElevenLabsのSTT機能で文字単位のタイムスタンプを取得し、AIで自然な改行とタイミングを調整します。

### ノード構成

#### 1. Download file ノード（音声ファイル取得）

- **ノードタイプ**: Google Drive (Download)
- **処理内容**: 保存された音声ファイルをダウンロード
- **入力**: N items（音声ファイルID）
- **出力**: N items（音声ファイルデータ）

#### 2. Loop Over Items ノード（ループ処理）

- **ノードタイプ**: Loop Over Items
- **処理内容**: 各シーンの音声ファイルを順次処理
- **出力**: N items（ループ処理中のデータ）

#### 3. Transcribe audio or video ノード（音声文字起こし）

- **ノードタイプ**: ElevenLabs / Speech to Text
- **処理内容**: 音声を文字起こしし、文字単位でタイムスタンプを取得
- **出力形式**: 文字ごとのタイムスタンプ情報
- **出力例**:
  ```json
  {
    "words": [
      {
        "word": "初デート",
        "start": 0.0,
        "end": 0.8
      },
      {
        "word": "で",
        "start": 0.8,
        "end": 0.9
      }
    ]
  }
  ```

#### 4. get words timestamp ノード（タイムスタンプ処理）

- **ノードタイプ**: Code
- **処理内容**: STTの結果を整形し、後続処理用のデータに変換
- **出力**: N items（タイムスタンプ情報を含むデータ）

#### 5. Paging ノード（改行・タイミング調整）

- **ノードタイプ**: OpenAI / Message Model
- **モデル**: `gpt-4.1-nano`
- **処理内容**: タイムスタンプ情報を基に、自然な改行とタイミングを調整
- **プロンプト例**:
  ```
  以下の音声文字起こし結果を基に、自然な改行とタイミングで字幕を作成してください。
  
  文字起こしデータ:
  {{ $json.words }}
  
  元の台本:
  {{ $json.script }}
  
  要件:
  - 不自然な改行を避ける
  - 意味のまとまりごとに改行
  - タイムスタンプは文字起こし結果を基に調整
  - SRT形式で出力
  
  出力形式:
  {
    "subtitles": [
      {
        "index": 1,
        "start": "00:00:00,000",
        "end": "00:00:03,500",
        "text": "初デートで意外と知られていない"
      }
    ]
  }
  ```
- **出力**: N items（調整された字幕データ）

#### 6. get pages ノード（ページ分割処理）

- **ノードタイプ**: Code
- **処理内容**: 長い字幕を適切な長さに分割
- **出力**: N items（分割された字幕データ）

#### 7. Merge2 ノード（データ統合）

- **ノードタイプ**: Merge
- **処理内容**: 字幕データとシーン情報を統合
- **モード**: Combine
- **出力**: N items（統合されたデータ）

#### 8. Write srt ノード（SRTファイル作成）

- **ノードタイプ**: Code
- **処理内容**: 字幕データをSRT形式のファイルに変換
- **SRT形式例**:
  ```
  1
  00:00:00,000 --> 00:00:03,500
  初デートで意外と知られていない
  
  2
  00:00:03,500 --> 00:00:07,200
  事実があります。
  ```
- **出力**: N items（SRTファイルデータ）

#### 9. align timestamp ノード（タイムスタンプ調整）

- **ノードタイプ**: Code
- **処理内容**: タイムスタンプを微調整し、音声と完全に同期
- **出力**: N items（調整されたSRTデータ）

#### 10. Convert srt File ノード（ファイル変換）

- **ノードタイプ**: Convert to Text File
- **処理内容**: SRTデータをテキストファイル形式に変換
- **出力**: N items（SRTファイル）

#### 11. Upload srt file ノード（SRTファイル保存）

- **ノードタイプ**: Google Drive (Upload)
- **処理内容**: SRTファイルをGoogle Driveに保存
- **ファイル名**: `scene_{{ $json.scene_number }}.srt`
- **出力**: N items（保存されたSRTファイル情報）

#### 12. set srt file id ノード（ID記録）

- **ノードタイプ**: Set
- **処理内容**: 保存されたSRTファイルのIDを記録
- **設定**:
  ```json
  {
    "srt_file_id": "{{ $json.id }}",
    "scene_number": "{{ $json.scene_number }}"
  }
  ```
- **出力**: N items（SRTファイルIDを含むデータ）

### 実装のポイント

#### ElevenLabs STTの活用

- **文字単位のタイムスタンプ**: 単語だけでなく、文字単位でタイムスタンプを取得可能
- **高精度**: 音声認識の精度が高く、正確なタイムスタンプを取得
- **API制限**: 使用量に応じたコストが発生するため、効率的な処理を心がける

#### AIによる改行・タイミング調整

- **自然な改行**: 意味のまとまりを考慮した改行をAIが判断
- **タイミング最適化**: 音声の速度や間を考慮してタイムスタンプを調整
- **不自然さの排除**: 単語の途中での改行など、不自然な表示を避ける

#### SRT形式の詳細

- **タイムスタンプ形式**: `HH:MM:SS,mmm --> HH:MM:SS,mmm`
- **エンコーディング**: UTF-8で保存
- **改行コード**: CRLF（Windows形式）またはLF（Unix形式）

## ステップ5: 画像作成

### 目的

各シーンの台本に合わせて、適切な画像をAIで生成します。画像生成用のプロンプトもAI自身が作成することで、シーンに合った画像を自動生成します。

### ノード構成

#### 1. Message a model ノード（画像プロンプト生成）

- **ノードタイプ**: OpenAI / Message Model
- **モデル**: `gpt-4.1-nano`
- **処理内容**: シーン別の台本を基に、画像生成用のプロンプトを作成
- **プロンプト例**:
  ```
  以下のシーンの台本を基に、画像生成用のプロンプトを作成してください。
  
  シーン番号: {{ $json.scene_number }}
  台本: {{ $json.script }}
  
  要件:
  - シーンの雰囲気を表現
  - スタイルを明確に定義（例：イラスト風、写真風、アニメ風）
  - 色調や構図を指定
  - 英語でプロンプトを作成（画像生成AI用）
  
  出力形式:
  {
    "image_prompt": "A couple having their first date at a cozy cafe, warm lighting, illustration style, soft colors, peaceful atmosphere"
  }
  ```
- **入力**: N items（シーン情報）
- **出力**: N items（画像プロンプトを含むデータ）

#### 2. Message a model1 ノード（画像生成）

- **ノードタイプ**: OpenAI / DALL·E (Image Generation)
- **モデル**: `gpt-image-1`（または `dall-e-3`）
- **処理内容**: 生成されたプロンプトを基に画像を生成
- **パラメータ**:
  - **prompt**: `{{ $json.image_prompt }}`
  - **size**: `1024x1024`（または動画のアスペクト比に合わせて調整）
  - **quality**: `low`（コスト削減のため、lowでも十分な品質）
  - **n**: `1`（1枚生成）
- **出力**: N items（生成された画像データ）

#### 3. Upload file ノード（画像保存）

- **ノードタイプ**: Google Drive (Upload)
- **処理内容**: 生成された画像をGoogle Driveに保存
- **ファイル名**: `scene_{{ $json.scene_number }}.png`
- **出力**: N items（保存された画像ファイル情報）

#### 4. スライド画像IDセット ノード（ID記録）

- **ノードタイプ**: Set
- **処理内容**: 保存された画像ファイルのIDを記録
- **設定**:
  ```json
  {
    "image_file_id": "{{ $json.id }}",
    "scene_number": "{{ $json.scene_number }}"
  }
  ```
- **出力**: N items（画像ファイルIDを含むデータ）

### 実装のポイント

#### プロンプト生成の重要性

- **シーンに合った画像**: 台本の内容を理解し、適切な画像を生成するためのプロンプトが重要
- **スタイルの統一**: 動画全体でスタイルが統一されるよう、プロンプトにスタイル指定を含める
- **多言語対応**: 画像生成AIは英語プロンプトの方が高品質な結果を得やすい

#### 画像生成のコスト最適化

- **qualityパラメータ**: `low`でも十分な品質の画像が生成可能
- **サイズ調整**: 動画の解像度に合わせて適切なサイズを指定
- **バッチ処理**: 複数のシーンを並列処理することで効率化

#### 画像の品質向上

- **プロンプトの詳細化**: 具体的な描写を追加することで、より意図した画像を生成
- **ネガティブプロンプト**: 不要な要素を除外する指定も可能
- **リトライ処理**: 生成結果が不適切な場合の再生成処理

## ステップ6: 動画レンダリング

### 目的

これまでに作成した素材（音声、字幕、画像、BGM）を統合し、ffmpegを使用して動画をレンダリングします。このステップは2つの並列ブランチで構成されています。

### ノード構成（ブランチ1: シーン別動画作成）

#### 1. Append or update row in sheet ノード（データ記録）

- **ノードタイプ**: Google Sheets (Append or Update)
- **処理内容**: 各シーンの素材情報をスプレッドシートに記録
- **記録内容**:
  - シーン番号
  - 音声ファイルID
  - 字幕ファイルID
  - 画像ファイルID
  - 動画データID（後で更新）
- **出力**: N items（記録されたデータ）

#### 2. aggregater1 ノード（データ集約）

- **ノードタイプ**: Code
- **処理内容**: 全シーンのデータを集約し、動画全体の情報を生成
- **出力**: 1 item（動画全体の情報）

#### 3. Execute Command1 ノード（初期化処理）

- **ノードタイプ**: Execute Command
- **処理内容**: 動画レンダリング用のディレクトリを作成
- **コマンド例**:
  ```bash
  mkdir -p /tmp/video_render/scenes
  mkdir -p /tmp/video_render/audio
  mkdir -p /tmp/video_render/subtitles
  mkdir -p /tmp/video_render/images
  ```
- **出力**: 1 item

#### 4. get video data1 ノード（動画データ取得）

- **ノードタイプ**: Google Sheets (Read)
- **処理内容**: スプレッドシートから全シーンの素材情報を取得
- **出力**: N items（シーン数 × 素材種類分のデータ）

#### 5. get video items1 ノード（動画アイテム整理）

- **ノードタイプ**: Code
- **処理内容**: 取得したデータをシーンごとに整理
- **出力**: N items（シーンごとの整理されたデータ）

#### 6. Download audio1 ノード（音声ファイルダウンロード）

- **ノードタイプ**: Google Drive (Download)
- **処理内容**: 各シーンの音声ファイルをダウンロード
- **出力**: N items（音声ファイルデータ）

#### 7. Write audio file1 ノード（音声ファイル保存）

- **ノードタイプ**: Write File to Disk
- **処理内容**: ダウンロードした音声ファイルをローカルに保存
- **ファイルパス**: `/tmp/video_render/audio/scene_{{ $json.scene_number }}.wav`
- **出力**: N items

#### 8. Download srt1 ノード（字幕ファイルダウンロード）

- **ノードタイプ**: Google Drive (Download)
- **処理内容**: 各シーンの字幕ファイルをダウンロード
- **出力**: N items（字幕ファイルデータ）

#### 9. Write srt file1 ノード（字幕ファイル保存）

- **ノードタイプ**: Write File to Disk
- **処理内容**: ダウンロードした字幕ファイルをローカルに保存
- **ファイルパス**: `/tmp/video_render/subtitles/scene_{{ $json.scene_number }}.srt`
- **出力**: N items

#### 10. Download image1 ノード（画像ファイルダウンロード）

- **ノードタイプ**: Google Drive (Download)
- **処理内容**: 各シーンの画像ファイルをダウンロード
- **出力**: N items（画像ファイルデータ）

#### 11. Write image file1 ノード（画像ファイル保存）

- **ノードタイプ**: Write File to Disk
- **処理内容**: ダウンロードした画像ファイルをローカルに保存
- **ファイルパス**: `/tmp/video_render/images/scene_{{ $json.scene_number }}.png`
- **出力**: N items

#### 12. create ass1 ノード（ASS字幕ファイル作成）

- **ノードタイプ**: Execute Command
- **処理内容**: SRTファイルをASS形式に変換（ffmpegで使用するため）
- **コマンド例**:
  ```bash
  ffmpeg -i /tmp/video_render/subtitles/scene_{{ $json.scene_number }}.srt \
  ```

## トラブルシューティング

### よくある問題と解決方法

#### 1. VOICEVOXに接続できない

- **原因**: ローカルサーバーが起動していない
- **解決**: VOICEVOXアプリケーションを起動し、APIサーバーが動作していることを確認

#### 2. 音声と字幕がずれる

- **原因**: タイムスタンプの計算ミス
- **解決**: STTの結果を再確認し、タイミング調整のロジックを見直す

#### 3. 画像が生成されない

- **原因**: APIキーの問題やプロンプトの形式エラー
- **解決**: APIキーを確認し、プロンプトが適切な形式か確認

#### 4. ffmpegで動画が作成されない

- **原因**: ファイルパスの問題やコーデックの問題
- **解決**: ファイルパスを確認し、ffmpegのバージョンとコーデックを確認

#### 5. 動画の結合が失敗する

- **原因**: ファイルリストの形式エラーやファイルの欠損
- **解決**: リストファイルの形式を確認し、全シーンの動画ファイルが存在するか確認
