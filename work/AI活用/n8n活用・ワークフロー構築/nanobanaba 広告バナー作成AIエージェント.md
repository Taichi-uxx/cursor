# 広告画像作成AIエージェントの作成方法：nano-banana×n8n

## 要約・サマリ

このワークフローは、**n8n**と**nano-banana**（Googleの画像生成モデル）を組み合わせて、商品画像と人物素材を入力すると自動的に広告画像を生成するAIエージェントを作成する方法を解説。

**主な特徴**:
- 商品画像と人物素材を組み合わせて広告画像を自動生成
- Google Driveから人物素材を自動検索・ダウンロード
- 複数の人物素材に対してループ処理で一括生成
- 生成した画像をGoogle Driveに自動アップロード
- 高品質な広告画像を効率的に作成可能

**ワークフローの流れ**:
1. フォームで商品素材をアップロード
2. 商品素材をBase64に変換
3. Google Driveから人物素材を検索
4. ループ処理で各人物素材を処理
5. 人物素材をダウンロードしてBase64に変換
6. nano-banana APIで広告画像を生成
7. 生成した画像をファイル形式に変換
8. Google Driveにアップロード

**参考動画**: [広告画像作成AIエージェントの作成方法を解説！【nano-banana×n8n】](https://www.youtube.com/watch?v=WaDrew6LEZc)

## nano-bananaとは

### 基本情報

- **開発元**: Google
- **正式名称**: Imagen 2.5 Flash（プレビュー）
- **特徴**: 2つの素材を組み合わせて画像を作ることができるモデル
- **品質**: 非常に高く作れる素晴らしいモデル

### 主な機能

- **素材の組み合わせ**: 商品画像と人物素材を組み合わせて広告画像を生成
- **高品質な画像生成**: クオリティが非常に高い
- **API経由での利用**: HTTPリクエストで利用可能

## ワークフロー全体の流れ

### 詳細な処理フロー

1. **商品素材のアップロード**: フォームで商品画像をアップロード
2. **ファイル変換**: 商品素材をBase64形式に変換
3. **人物素材の検索**: Google Driveの指定フォルダーから人物素材を検索
4. **ループ処理**: 見つかった人物素材を1枚ずつ処理
5. **人物素材のダウンロード**: Google Driveから人物素材をダウンロード
6. **Base64変換**: 人物素材もBase64形式に変換
7. **画像生成**: nano-banana APIで商品素材と人物素材を組み合わせて広告画像を生成
8. **データ整理**: 生成された画像データを整理
9. **ファイル変換**: Base64形式を元の画像ファイル形式に変換
10. **Google Driveにアップロード**: 生成した広告画像をGoogle Driveにアップロード

## 各ノードの詳細設定

### ノード1：フォームトリガー

**ノードタイプ**: n8n Form Trigger

**設定項目**:
- **認証**: なし（None）
- **フォームタイトル**: ADクリエイティブメーカー（任意）
- **フォーム説明**: 「商品の素材をアップロードするので、画像を上げてください」
- **フィールド名**: image
- **エレメントタイプ**: File
- **マルチプルファイルズ**: オフ（1つの商品素材のみアップロード）
- **レスポンドレ**: フォーム（フォーム素材を送信してから反応）

**役割**: 商品画像をアップロードするためのフォームを提供

### ノード2：商品素材をBase64に変換

**ノードタイプ**: Extract from File

**設定項目**:
- **操作**: Move File to Base64
- **インプットバイナリーフィールド**: image（前のノードからドラッグ&ドロップ）
- **デスティネーションアウトプットフィールド**: data（デフォルトのまま）

**役割**: アップロードした商品素材のファイルをBase64形式に変換

**理由**: nano-banana APIが画像ファイルそのままでは受け取れないため、Base64形式に変換する必要がある

### ノード3：人物素材の検索

**ノードタイプ**: Google Drive

**設定項目**:
- **認証**: Google Driveアカウントの認証（初めての場合は「Create New Credential」をクリック）
- **リソース**: Files / Folders
- **オペレーション**: Search（フォルダー内の素材を検索）
- **サーチメソッド**: Search File / Folder Name
- **サーチエリア**: 空欄（指定不要）
- **リターンオール**: オン
- **フィルター**: 
  - **By ID**を選択
  - **フォルダーID**: 人物素材を入れてあるフォルダーのIDを入力
    - フォルダーをクリックすると、URLの「folders/」の後ろの部分がID
    - このIDをコピーして貼り付け

**役割**: Google Driveの指定フォルダーから人物素材を検索

**注意点**: 事前に人物素材を入れたフォルダーを作成しておく必要がある

### ノード4：ループオーバーアイテムズ

**ノードタイプ**: Loop Over Items

**設定項目**:
- **バッチサイズ**: 1（デフォルトのまま）

**役割**: 見つかった人物素材を1枚ずつ処理するためのループ

**処理の流れ**:
- フォルダーに45枚の人物素材がアップロードされている場合
- 1枚目の人物素材と商品素材を組み合わせて広告画像を生成
- 2枚目の人物素材と商品素材を組み合わせて広告画像を生成
- 3枚目の人物素材と商品素材を組み合わせて広告画像を生成
- これを全素材に対して繰り返す

### ノード5：人物素材のダウンロード

**ノードタイプ**: Google Drive

**設定項目**:
- **認証**: 先ほど認証したGoogle Driveアカウント
- **リソース**: File
- **オペレーション**: Download
- **ファイルバイID**: `{{ $json.id }}`（前のノードからドラッグ&ドロップ）

**役割**: 検索で見つかった人物素材のファイルをダウンロード

### ノード6：人物素材をBase64に変換

**ノードタイプ**: Extract from File

**設定項目**:
- **操作**: Move File to Base64
- **インプットバイナリーフィールド**: data（前のノードから）
- **デスティネーションアウトプットフィールド**: data（デフォルトのまま）

**役割**: ダウンロードした人物素材もBase64形式に変換

### ノード7：nano-banana APIで画像生成

**ノードタイプ**: HTTP Request

**設定項目**:
- **メソッド**: POST
- **URL**: `https://generativelanguage.googleapis.com/v1beta/models/imagen-3.0-generate-001:predict`
  - 正式名称: Imagen 2.5 Flash（プレビュー）
  - このURLは動画内のLINE QRコードから無料で提供
- **認証**:
  - **認証タイプ**: Generic Credential Type
  - **Generic Credential Type**: Header Auth
  - **ヘッダー名**: X-Goog-Api-Key
  - **値**: Gemini APIキー
    - 初めての場合は「Create New Credential」をクリック
    - 名前: X-Goog-Api-Key
    - 値: Gemini APIキーを入力

**Gemini APIキーの取得方法**:
1. Google検索で「Google AI Studio」と検索
2. 1番上のサイトをクリック
3. Googleアカウントでログイン（持っていない場合は作成）
4. 左側のメニューから「Get API Key」をクリック
5. 「Create API Key」をクリック
6. 既存のGoogle Cloudプロジェクトを選択（ない場合は作成）
7. APIキーが生成されるので、コピーして使用

**ボディ設定**:
- **Send Body**: オン
- **Body Content Type**: JSON
- **Specify Body**: JSON

**JSONボディの内容**:
```json
{
  "instances": [
    {
      "prompt": "化粧品と、化粧品を、画像2の女性が手に持っている広告素材を作成してください。その化粧品を使おうとしている、または紹介しているような自然な状態で。女性は明るく清潔感のある場所に座っていて、温かい映画でカメラを見つめています。これはプロフェッショナルな商品撮影ではなく、インフルエンサーが日常的に投稿するような親しみやすく自然な写真にしてください。"
    }
  ],
  "parameters": {
    "sampleCount": 1,
    "aspectRatio": "1:1"
  }
}
```

**プロンプトの変数部分**:
- `{{ $json.data }}`: 商品素材のBase64データ（Extract from Fileのアイテムから）
- `{{ $json.data }}`: 人物素材のBase64データ（前のノードから）

**注意点**:
- 変数の部分は、自身が設定している前のノードの名前によって若干変わる可能性がある
- その場合は、前のノードから直接ドラッグ&ドロップして設定する
- プロンプトは、作りたい画像に沿って書き換えることができる

### ノード8：データ整理

**ノードタイプ**: Edit Fields

**設定項目**:
- **モード**: Manual Mapping
- **フィールドセット**: image_result
- **タイプ**: String
- **値**: `{{ $json.predictions[0].bytesBase64Encoded }}`（前のノードからドラッグ&ドロップ）

**役割**: 生成された広告画像のデータを整理

**設定方法**:
1. 前のノード（HTTP Request）まで実行
2. HTTP Requestノードの「data」という部分をドラッグ&ドロップ
3. これで生成された画像データが反映される

### ノード9：Base64をファイルに変換

**ノードタイプ**: Convert to File

**設定項目**:
- **操作**: From Base64 File
- **Base64インプットフィールド**: image_result（Edit Fieldsからドラッグ&ドロップ）
- **アウトプットファイルフィールド**: data

**役割**: Base64形式のデータを元の画像ファイル形式に戻す

### ノード10：Google Driveにアップロード

**ノードタイプ**: Google Drive

**設定項目**:
- **認証**: Google Driveアカウント
- **リソース**: File
- **オペレーション**: Upload
- **ファイル名**: 任意（商品素材のファイル名を指定することも可能）
- **フロームリスト**: My Drive
- **ペアレントフォルダー**: 作成した広告画像をアップロードするフォルダーのID
  - フォルダーを作成して、そのIDを入力
  - フォルダーをクリックすると、URLの「folders/」の後ろの部分がID

**役割**: 生成した広告画像をGoogle Driveにアップロード

### ループの接続

**重要**: アップロードファイルノードの後から、ループオーバーアイテムズノードに接続する

**接続方法**:
- アップロードファイルノードの「コネクト」から、ループオーバーアイテムズノードに接続
- これにより、複数の人物素材に対してループ処理が可能になる

## 技術的な詳細

### Base64変換の必要性

**理由**:
- nano-banana APIが画像ファイルそのままでは受け取れない
- Base64形式に変換することで、APIが受け取れる形式になる
- 生成後、再度ファイル形式に戻す必要がある

### ループ処理の仕組み

**処理フロー**:
1. 人物素材の検索で複数のファイルが見つかる
2. ループオーバーアイテムズで1枚ずつ処理
3. 各人物素材に対して、商品素材と組み合わせて広告画像を生成
4. 生成した画像をGoogle Driveにアップロード
5. 次の人物素材に進む

**メリット**:
- 複数の人物素材に対して一括で広告画像を生成可能
- 手動で1枚ずつ処理する必要がない
- 効率的に大量の広告画像を作成できる

### Gemini APIの認証

**認証方法**:
- Generic Credential TypeのHeader Authを使用
- ヘッダー名: X-Goog-Api-Key
- 値: Gemini APIキー

**APIキーの取得**:
- Google AI Studioから取得
- 無料で利用可能
- 使用量に応じた制限がある場合がある

## トラブルシューティング

### よくある問題

### 1. APIキーが取得できない

**解決方法**:
- Google AI Studioに正しくログインしているか確認
- Google Cloudプロジェクトが作成されているか確認
- APIキーの作成権限があるか確認

### 2. フォルダーIDが取得できない

**解決方法**:
- Google Driveでフォルダーを開く
- URLの「folders/」の後ろの部分がID
- このIDをコピーして貼り付け

### 3. Base64変換がうまくいかない

**解決方法**:
- 前のノードから正しくデータをドラッグ&ドロップしているか確認
- フィールド名が正しいか確認
- ノードの実行順序を確認

### 4. ループがうまく動作しない

**解決方法**:
- アップロードファイルノードからループオーバーアイテムズノードに接続されているか確認
- バッチサイズが1になっているか確認
- 前のノードが正しく実行されているか確認
