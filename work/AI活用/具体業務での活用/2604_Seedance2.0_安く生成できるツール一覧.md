## 軸ごとの示唆（So What）

### 1. 1本あたりコストで見たとき
- 同じSeedance 2.0でも、**経由するプラットフォームで1本あたりコストが288円〜1,700円とおよそ6倍開く**。
- 同じ動画を量産する案件なら、**プラットフォーム選定だけで原価が1/6になる**。月50本作るなら ¥288×50=¥14,400 vs ¥1,700×50=¥85,000。

### 2. Real Face対応の壁
- Real Face対応は **Sjinn・Zopia・Lovart・Runway・PolloAI** に限られる（Runway・PolloAIは※付きで条件あり）。
- 人物起用案件は**選択肢が一気に5つに絞られる**。その中での最安は **Sjinn 288円**。

### 3. Canvasモード／エージェント機能
- Canvasモードや専用エージェント機能を持つのは **Sjinn・Lovart・Tapnow**。
- 編集・修正を含めた制作フロー全体で見るなら、**1本コストだけでなくCanvas/エージェントの使いやすさも判断軸**に含める。

### 4. 「安いけど使いづらい」罠
- **Dreamina**：安いがWatermarkあり → 商用案件では使えない
- **PixVerse**：安いが日本語セリフが英語に化ける → 日本市場向け案件NG
- **Capcut**：エージェントが勝手にセリフを変える → セリフ厳密性が必要な案件NG
- **SousakuAI**：NSFW判定が厳しい → 表現の幅が制限される
- 単価だけで決めず、**案件要件と「使えない条件」のすり合わせ**が必須。
