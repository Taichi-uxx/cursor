# Gemini 2.5 Flash Image（Nano-banana）マーケティング活用事例

**作成日**: 2025年9月1日  
**参照元**: [話題のGemini画像生成AIがマーケティング現場で使えること多すぎた。](https://note.com/ayumi_ai/n/nb959ad8dcb5d)

---

## 要約・サマリ

**Gemini 2.5 Flash Image（通称：Nano-banana）**は、Google/DeepMindが2025年8月26日に発表した画像生成・編集モデル。マーケティング現場での実用性が高い特徴として、**人物・キャラクターの一貫性を保ったまま編集可能**、**複数画像の自然な合成**、**自然言語での局所編集**が挙げられる。

主な活用シーンは、広告素材の背景差し替え、商品と人物の合成、サイズ感の可視化、画像の質感向上、写真の漫画風変換、バナーやLPの改善など多岐にわたる。商用利用も可能で、Geminiアプリ（Web/モバイル）で無料利用できるほか、開発者向けにはGemini APIやVertex AIでも提供されている。プロンプトの精度向上には、具体的な内容指定、背景と意図の説明、イテレーションによる改良、ステップバイステップの手順、セマンティックネガティブプロンプト、カメラ用語の活用が重要。ただし、サイズ感や日本語文字の精度など、注意点もあるため実際の運用ではこれらを考慮する必要がある。

---

## 1. Nano-bananaとは

### 1-1. 正式名称と発表日

- **正式名称**: Gemini 2.5 Flash Image
- **通称**: Nano-banana
- **発表日**: 2025年8月26日
- **開発元**: Google/DeepMind

### 1-2. 主な特徴

#### 一貫性の保持
- 人物・キャラクターの一貫性を保ったまま編集可能
- 髪型や服装だけを変更、背景だけを差し替えるなど、部分的な編集が可能

#### 画像合成
- 複数画像の自然な合成（人物A＋場所Bで自然な一枚に）
- 商品と人物の合成写真生成

#### 自然言語での局所編集
- 「背景をぼかして」「シミを消して」などの自然言語での指示が可能
- 被写体を維持したまま、特定部分のみを編集

#### 透かし機能
- 生成・編集した画像には**SynthIDの不可視透かし**が入る
- アプリ内では可視透かしも表示

### 1-3. 利用場所

#### 一般ユーザー向け
- **Geminiアプリ（Web/モバイル）**
  - 無料/有料ユーザーともに利用可能
  - モデルは**Gemini 2.5 flash**を利用

#### 開発者向け
- **Gemini API**: プレビュー提供中
- **Google AI Studio**: プレビュー提供中
- **Vertex AI**: エンタープライズ向け
  - モデルID: `gemini-2.5-flash-image-preview`

### 1-4. 商用利用について

Google Cloudの公式サイトによると、以下の記載がある。

> お客様は、この生成 AI プレビュー版を本番環境または商用目的で使用し、生成された出力を第三者に開示することができます。

**参照**: [Google Cloud公式ドキュメント](https://cloud.google.com/vertex-ai/generative-ai/docs/multimodal/image-generation?hl=ja#googlegenaisdk_imggen_mmflash_with_txt-console)

## 2. マーケティング現場での活用事例

### 2-1. 同一被写体のシーン変更

#### 活用シーン
- 同じ人・同じ商品で、季節・天気・時間帯だけを切り替えて量産
- 広告素材の作成効率化

#### プロンプト例
```
この写真の背景画像を夕日の画像に変えて。人物は維持したまま背景だけ変えて。
```

#### 活用メリット
- 撮影の時間やコストを削減
- 複数シーンの素材を短時間で生成可能
- 商品画像のシーン変更にも対応

#### 注意点
- 細かい部分で気になる点がある場合がある
- 比較的自然な形で背景変更が可能だが、完全な精度は保証されない

### 2-2. 商品と人物の合成

#### 活用シーン
- 商品紹介のCM風シーン作成
- AI生成のタレントに商品を持たせる、飲ませるなどのシーン生成
- 複数シーンの生成が可能

#### プロンプト例
```
1枚目の女性が2枚目の商品を紹介するCMのようなシーンをお願い
```

#### 注意点
- **サイズ感に注意が必要**
- AIは正確なサイズを把握しているわけではないため、比率がおかしい画像が生成される場合がある
- 基準物の寸法をきちんと入力しておくと、実測と視覚の齟齬が出にくい

### 2-3. サイズ感・利用シーンの可視化

#### 活用シーン
- 商品のサイズ感を「ひと目でわかる」形で表現
- 手や500mlペットボトル、ノートPCなどを一緒に置いて、サイズ比較画像を生成

#### プロンプト例
```
商品のサイズはペットボトルの一回り大きいくらいであることを示して、
商品右横に500mlペットボトルを自然合成。視差と影を合わせ、誇張はしない。
"高さ 約19cm"の小さな注記を下部に追記
```

#### 活用メリット
- 基準物の寸法を入力することで、実測と視覚の齟齬を抑制
- 視覚的に分かりやすいサイズ比較が可能

### 2-4. 画像質感アップ

#### 活用シーン
- 写真のレタッチ作業
- 人物や商品画像の加工・修正
- 被写体を維持したまま、質感や見た目を向上

#### プロンプト例
```
アップロードした写真を、広告用に再撮影したような高品質な一眼レフ写真にしてください。
```

#### 活用メリット
- 誰でも数秒で修正可能
- もとの被写体が変わらないようにする必要があるが、ちょっとした修正を簡単に実行可能

### 2-5. 写真を漫画風に変換

#### 活用シーン
- 写真の被写体を維持したまま、漫画やアニメ風の画像に変換
- ブランドのトーンに合わせたスタイル変換

#### 活用メリット
- 被写体の一貫性を保ったまま、スタイル変換が可能
- 多様なクリエイティブ表現が可能

### 2-6. バナーやLPの改善

#### 2-6-1. バナーのデザイン案作成

##### 活用シーン
- 同じ訴求でも、背景や構図、光の組み合わせでクリック率が変わるため、Nano-bananaで多様なデザイン案を迅速に生成
- 複数のバリエーションを短時間で作成

##### プロンプト例
```
商品画像はそのまま利用して、背景のイメージを夏のキャンペーンに合わせて
夏っぽい爽やかなイメージが伝わるバナーを5パターン作成。
```

##### 活用メリット
- デザイン案の作成時間を大幅に短縮
- 多様なバリエーションを迅速に生成可能

#### 2-6-2. LP改善案の作成

##### 活用シーン
- LPの画像を入力し、CVR向上のための改善案を画像内に指摘・コメントとして表示
- 視覚的な改善提案の可視化

##### 注意点
- **日本語の文字入れ精度が低い**
- 文字化けや読みにくい状態になることがある
- 日本語文字が崩れる場合は、「キャンバス素材+日本語入力を含む貼り付ける素材」で生成する方法がある

#### 2-6-3. ABテスト案のアイデア出し

##### 活用シーン
- 同一構図のまま、一要素を変えたABテストパターンを生成
- デザイン面でのテスト案出しをサポート

##### プロンプト例
```
このサムネイル画像をABテストで別バージョン作るとしたら
どんな案が考えられるか3パターン作成し、それぞれ画像を出力。
```

##### 活用メリット
- ABテストのデザイン案を迅速に作成
- 複数のバリエーションを同時に検討可能

#### 2-6-4. バナー内の文字や装飾の修正

##### 活用シーン
- 画像内の文字装飾や加工を、テキスト指示で簡単に修正
- 細かいデザイン調整を迅速に実行

##### プロンプト例
```
「Gemini」の文字をリッチなゴールドの文字にして。
```

##### 活用メリット
- デザインソフトを使わずに、テキスト指示で修正可能
- 迅速なデザイン調整が可能

## 3. ベストプラクティス

Google公式が公開しているプロンプトガイドに基づく、精度の高い生成のためのベストプラクティス。

### 3-1. 非常に具体的な内容にする

詳細な内容にするほど、より細かく制御できる。

**悪い例**: 「ファンタジー アーマー」

**良い例**: 「銀の葉の模様がエッチングされた、装飾的なエルフのプレート アーマー。高い襟とハヤブサの翼の形をした肩当てが付いている」

### 3-2. 背景と意図を説明する

画像の目的を説明することで、モデルのコンテキスト理解が最終出力に影響する。

**悪い例**: 「ロゴを作成して」

**良い例**: 「高級でミニマリストなスキンケア ブランドのロゴを作成して」

### 3-3. イテレーションと改良

最初の試行で完璧な画像が生成されるとは限らない。モデルの会話的な性質を利用して、小さな変更を行う。

**プロンプト例**:
- 「素晴らしいですが、照明をもう少し暖かくしてもらえますか？」
- 「すべてそのままにして、キャラクターの表情をもう少し真剣なものに変えてください」

### 3-4. ステップバイステップの手順を使用する

多くの要素を含む複雑なシーンでは、プロンプトをステップに分割する。

**プロンプト例**:
```
まず、夜明けの静かで霧がかった森の背景を作成します。
次に、前景に苔むした古代の石の祭壇を追加します。
最後に、祭壇の上に光る剣を1本置きます。
```

### 3-5. セマンティックネガティブプロンプトを使用する

「〜がない」と言う代わりに、望ましいシーンを肯定的に説明する。

**悪い例**: 「車がない」

**良い例**: 「交通の兆候がない空っぽの寂れた通り」

### 3-6. カメラを制御する

写真や映画の用語を使用して、構図を制御する。

**使用可能な用語例**:
- `wide-angle shot`（広角ショット）
- `macro shot`（マクロショット）
- `low-angle perspective`（ローアングル視点）

## 4. プロンプト作成のコツ

### 4-1. 日本語文字が崩れる場合の対策

日本語文字が崩れる場合は、「キャンバス素材+日本語入力を含む貼り付ける素材」で生成する方法がある。モックアップイメージやデザインカンプの作成などで活用可能。

### 4-2. プロンプトがうまく作れない場合の対策

- **英語プロンプトの方が効きやすい傾向がある**
- 公式ドキュメントを参考にしたi2i専用のGPTsなどのツールを活用
- プロンプト生成支援ツールを利用

## 6. まとめ

Gemini 2.5 Flash Image（Nano-banana）は、マーケティング現場での実用性が高い画像生成・編集ツール。特に、**被写体の一貫性を保ったまま編集できる**点が、広告素材制作において大きなメリットとなる。

活用シーンは多岐にわたり、背景差し替え、商品と人物の合成、サイズ感の可視化、画像の質感向上、写真の漫画風変換、バナーやLPの改善など、従来は時間とコストがかかっていた作業を短時間で実行可能にする。

プロンプトの精度向上には、具体的な内容指定、背景と意図の説明、イテレーションによる改良、ステップバイステップの手順、セマンティックネガティブプロンプト、カメラ用語の活用が重要。商用利用も可能で、Geminiアプリで無料利用できるため、マーケティング担当者にとって導入のハードルが低い。

ただし、サイズ感や日本語文字の精度など、注意点もあるため実際の運用ではこれらを考慮する必要がある。生成AIとマーケティング領域の可能性は広く、モデルの進化とともにさらに活用シーンが拡大していくことが期待される。
