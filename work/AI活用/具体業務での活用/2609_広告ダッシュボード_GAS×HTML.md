# GAS HTML Service × Claude Code / Codex で広告ダッシュボード構築

- 著者: あやみ｜マーケティング（@ayami_marketing）

- 投稿日: 2026年9月頃（yymm推定＝2609）

## 用途（どんな時に活用できるか）
- **クライアントに配る広告レポート／社内共有ダッシュボードをサクッと作りたい時**（Looker Studio立ち上げるより軽い時）
- **スプシに溜めた広告データを、AIチャットの指示だけでビジュアライズしたい時**
- **非エンジニア向けの社内AIアプリを立てたい時**（アクセスを社内限定にできる）
- **Looker Studioでは表現しづらいカスタムUIやワークフロー**を組みたい時
- クライアントごとに **微妙に違うレポートUI** を、AIに丸投げして量産したい時

## 元投稿のポイント

### あやみさんの発見
> このやり方で、スプシの広告データをGASでダッシュボードにしてみた！
> ・ClaudeCodeやCodexで簡単に作れる
> ・グラフ追加などの修正もチャットでできる
> Looker Studioも好きなんだけど、AIでダッシュボード作れるという点ではこっちのほうが便利だった。

### 引用元の技術ポイント
> あまり知られてないですが、Google Apps ScriptにはHTML Serviceという機能があり、HTMLで自由にUIを構築できます。
> バックエンドとしてスプレッドシートやDriveが使えるのでちょっとした業務アプリは十分に作成可能。
> 社内のみアクセスにもできるので、非エンジニア向けのAIアプリ環境としてオススメ

## 仕組み（3層構成）

```
┌────────────────────────────────────────┐
│ フロント: HTML Service（HTML/CSS/JS）  │  ← Claude Code/Codexが生成
│  - グラフ描画（Chart.js等）             │
│  - フィルタUI・タブ・入力フォーム        │
└────────────────────────────────────────┘
              ↕ google.script.run
┌────────────────────────────────────────┐
│ ロジック: GAS（Google Apps Script）    │  ← Claude Code/Codexが生成
│  - スプシからデータ取得                 │
│  - 集計・変換                          │
└────────────────────────────────────────┘
              ↕
┌────────────────────────────────────────┐
│ バックエンド: Spreadsheet / Drive       │  ← 広告データ格納先
└────────────────────────────────────────┘
```

## Looker Studioとの違い（比較表）

| 観点 | GAS HTML Service + AI | Looker Studio |
|---|---|---|
| **UI自由度** | HTML/CSS/JSで無制限 | 用意されたパーツの組み合わせ |
| **AI生成しやすさ** | ◎ コード全体をチャットで生成・修正 | △ 手動組み立てが中心 |
| **修正の速さ** | ◎ 「棒グラフ追加して」で即反映 | △ UIポチポチ |
| **カスタムロジック** | ◎ GASで自由に書ける | △ 計算フィールドのみ |
| **共有** | Webアプリとして公開・社内限定可 | URL共有 |
| **ログイン統合** | Googleアカウント自動 | Googleアカウント自動 |
| **リアルタイム反映** | ○ 手動更新 or トリガー | ◎ 自動 |
| **DBコネクタの豊富さ** | △ GASでゴリ書き | ◎ BigQuery等ネイティブ |
| **メンテ属人性** | Claude Codeで書き直せるので低 | GUI操作で誰でも触れる |

**要点**: 「AIで作れる／AIで直せる」を最優先するならGAS+HTML Service。定型的なマルチクライアント運用ならLooker Studioがまだ強い。

## 太一の活用アイデア

### クライアント向け
- **月次広告レポートの自社仕様ダッシュボード**: 媒体横断のKPI集計をスプシに落とし、Claude Codeで見た目カスタム版のダッシュボードを生成。クライアントごとにブランドカラーやKPI優先度を反映
- **カスタムアラートUI**: CVR低下・CPA悪化などを閾値ベースで色分け表示、施策提案リンクを埋め込む
- **クライアント発表用のマイクロサイト**: Google Slides代わりに、当月の成果ハイライトをHTMLで映える形で

### 社内・自分用
- **AI Hourネタ管理ダッシュボード**: ネタ候補スプシ→タグフィルタ・優先度で並び替えるUI
- **業務時間トラッキング**: 案件別工数をスプシで管理→サマリUI
- **クライアントヘルスチェックボード**: 各クライアントのKPI推移・直近の会話履歴・次アクションを1画面に

## 構築ステップ（想定）

1. **スプシに広告データを整える**（媒体API連携 or 手動貼り付け）
2. **Claude Code / Codex に指示**：
   ```
   スプシID [xxx] のシート「Meta_daily」からデータを取得し、
   日別のCV/CPA推移を棒グラフ+折れ線グラフで表示するGAS HTML Serviceの
   Webアプリを作って
   ```
3. **生成されたコードを新規GASプロジェクトに貼り付け**
4. **デプロイ → Webアプリ公開**（アクセス範囲を「自分のみ／組織内」に設定）
5. **修正はチャットで**：「フィルタタブ追加して」「クライアント選択機能つけて」

## 注意点

- **セキュリティ**: 社外に公開する場合はアクセス制御を厳密に。デフォルトの「自分のみ」から広げる時は要注意
- **実行時間制限**: GASは1実行6分の制限あり。大量データ集計は事前バッチで
- **スプシは大量データに弱い**: 数万行超えたらBigQueryを検討
- **バージョン管理**: GASのバージョン管理はやや面倒。Claude Code側でコードを残しておく
