# データ分析はAIで次のステージへ。GA4×生成AIで実現する超高速PDCA

**公開日**: 2026年1月8日

## 概要

Google アナリティクス 4（GA4）と生成AIをMCPサーバーで連携することで、自然言語でのデータ分析とレポート作成を実現する手法を紹介。従来の月次レポート作成に必要な時間と労力を大幅に削減し、PDCAサイクルを高速化する。

生成AIがデータ分析の現場で本格的に活用できる段階に入り、特別なスキルがなくても日常業務に取り入れられるレベルに達したとされています。

## MCPサーバーとは

### 基本情報

- **正式名称**: Model Context Protocol
- **役割**: AIアシスタントと外部データソース（GA4、BigQuery、Google Adsなど）を接続する橋渡し役
- **機能**: GA4のUIを直接操作せずとも、生成AIを通じてデータの取得・分析・レポーティングが可能

### 主な特徴

1. **データ取得機能**
   - Google AnalyticsなどのAPIを通じてデータを取得
   - リアルタイムデータの取得も可能（対象システムによる）

2. **セキュア連携**
   - OAuth2などを使用して安全に認証
   - サービスアカウントによる安全なアクセス管理

3. **自然言語処理対応**
   - AIからの質問をAPIリクエストに変換
   - 結果をわかりやすい形で返す

4. **料金体系**
   - MCPサーバー自体は基本的に無料で利用可能
   - 生成AIサービス側に無料枠の制限があるため、利用状況によっては有償版の検討が必要
   - 分析量が多い場合は有償プランの利用が推奨

## 従来の課題と解決策

### 従来の課題

1. **月次レポート作成の負担**
   - 月次レポート作成に多大な時間と労力が必要
   - データのエクスポートや手作業の集計が負担
   - 分析から改善施策の実行まで時間がかかる

2. **スキル要件の高さ**
   - データ分析には専門的なスキルが必要
   - レポート作成に時間がかかり、施策実行までのサイクルが遅い

### MCPサーバー活用による解決

1. **自動データ取得**
   - GA4から必要なデータを自動で取得
   - 手動でのエクスポート作業が不要

2. **AI分析**
   - 生成AIが文章やグラフ、表として分析結果を提供
   - 自然言語での質問に対応

3. **効率化**
   - データのエクスポートや手作業の集計といった負担が大幅に軽減
   - 仮説の立案から改善施策の実行までのPDCAサイクルを迅速に回すことが可能

## 詳細な設定手順

### 1. MCP SuperAssistantの導入（ChatGPT使用の場合）

ChatGPTとGA4を連携させるために、Google Chromeの拡張機能「MCP SuperAssistant」をインストールします。

**インストール手順**：

1. [Google Chromeウェブストア](https://chrome.google.com/webstore)にアクセスし、「MCP SuperAssistant」を検索
2. 「Chromeに追加」をクリック
3. 拡張機能が有効になると、ブラウザ右上にアイコンが表示されます

セットアップ後、ChatGPTを開くと、画面右側にMCP SuperAssistantのサイドバーが表示され、接続するサーバーの管理が可能となります。

### 2. Google CloudおよびGA4の設定

MCPサーバーの設定前に、Google Cloud側でGA4のデータを外部から利用できるように準備します。

#### 2-1. Analytics Data APIの有効化

1. Google Cloud Consoleにログイン
2. プロジェクトを選択（新規作成も可）
3. 「APIとサービス」→「ライブラリ」を開く
4. 「Google Analytics Data API」と「Google Analytics Admin API」を有効化

#### 2-2. サービスアカウントの作成

1. Cloud Consoleで「IAMと管理」→「サービスアカウント」を開く
2. 「サービスアカウントを作成」をクリック
3. 名前例：`ga4-mcp-access`
4. ロールは特に付与不要（後でGA4側でアクセス権を与えるため）
5. 作成後、「鍵」タブから「鍵を追加」→「新しい鍵を作成」し、JSON鍵ファイルを取得

#### 2-3. GA4プロパティへのサービスアカウント追加

1. GA4管理画面を開く
2. 「管理」→「アカウントのアクセス管理」を開く
3. 作成したサービスアカウントのメールアドレスを追加
4. 権限は「閲覧者（Viewer）」または「アナリスト（Analyst）」を選択

#### 2-4. GA4プロパティIDの確認

1. GA4管理画面で「プロパティ設定」を開く
2. 「プロパティID」を確認（後でMCPサーバー設定時に使用）

### 3. 生成AIサービスの登録

- **推奨**: Claude（UIで設定可能でデスクトップアプリとして利用可能）
- 設定は約1時間で完了
- 権限設定に注意が必要

### 設定時の注意点

- 権限設定を適切に行うことが重要
- サービスアカウントのJSON鍵ファイルは安全に管理
- GA4プロパティIDを正確に入力

## 活用方法とプロンプト例

### 基本的な活用方法

設定が完了すると、ChatGPTやClaudeなどの生成AIを通じて、自然言語でGA4のデータを分析し、レポートを作成できます。

**例**：
- 「先月のセッション数を教えて」
- 「コンバージョンが増えた要因を分析して」
- 「今月のPVと前月比を教えて」

これらの質問を投げかけるだけで、AIがGA4から最新データを取得し、回答や改善案を提示します。
