```
1. アカウント全体のKPIを集計し、期間間の変化を把握する
2. 各「キャンペーン-広告グループ」セットの全体成果への影響度を算出する
3. 全体成果に最も影響を与えた「キャンペーン-広告グループ」セットを1つ特定する
4. 構造化されたサマリレポートを出力する

# 影響度の算出方法

以下の3軸で各ADGの全体成果への影響度を複合的に評価してください。

## 軸1: コスト変化寄与率
そのADGのコスト変化（ΔCost）が、全体のコスト変化（ΔCost_全体）のうち何%を占めるか。
```
Cost寄与率_i = ΔCost_i / ΔCost_全体 × 100
```

## 軸2: CV変化寄与率
そのADGのCV変化（ΔCV）が、全体のCV変化（ΔCV_全体）のうち何%を占めるか。
```
CV寄与率_i = ΔCV_i / ΔCV_全体 × 100
```

## 軸3: CPA変化インパクト（加重CPA寄与法）
各ADGのコストが全体CVに対してどれだけのCPA負担を生んでいるかの変化量。
```
CPA寄与_i（対象期間） = Cost_i_対象 / CV_全体_対象
CPA寄与_i（比較期間） = Cost_i_比較 / CV_全体_比較
ΔCPA寄与_i = CPA寄与_i（対象） - CPA寄与_i（比較）
```

## 複合影響度スコア
```
影響度スコア_i = |Cost寄与率_i| × 0.3 + |CV寄与率_i| × 0.3 + |ΔCPA寄与_iの偏差値| × 0.4
```
CPA変化インパクトの偏差値は、全ADGのΔCPA寄与の絶対値を母集団として算出する。

# 出力フォーマット

以下の4セクション構成で出力してください。

## セクションA: 全体KPIサマリ

以下のテーブルを出力した上で、全体の変化を1-2文で要約する。

| 指標 | 2025年12月 | 2026年1月 | 変化量 | 変化率 |
|------|-----------|-----------|-------|-------|

対象指標: IMP, Click, Cost, CV, CPA, CTR, CVR
- 変化率は小数点1桁まで
- コスト・CPAは円単位で「¥」を付与
- 変化量の符号は明示（+/-）

## セクションB: ADG別影響度ランキング

影響度スコアの降順で全ADGをテーブル表示。

| 順位 | キャンペーン | 広告グループ | 影響方向 | ΔCost | ΔCV | ΔCPA | Cost寄与率 | CV寄与率 | 影響度スコア |
|------|-----------|------------|---------|-------|------|------|-----------|---------|------------|

- 影響方向: 全体成果にとってポジティブかネガティブかを判定
  - ネガティブ: CPA悪化方向に寄与（Cost増+CV減、CPA上昇等）
  - ポジティブ: CPA改善方向に寄与（Cost減+CV増、CPA低下等）

## セクションC: 最も影響の大きいキャンペーン-ADGセット

ランキング1位のセットについて以下を記載:

1. **対象セット**: {キャンペーン名} - {ADG名}
2. **影響の方向性**: ポジティブ or ネガティブ
3. **各KPIの変化**: 全指標の変化を簡潔に記載
4. **指標連鎖分析**: IMP → CTR → Click → CVR → CV → CPA の流れで、どの指標の変化がどの指標に波及したかを因果チェーンで説明
5. **全体への影響度**: 「全体CPA悪化のうち約XX%はこのADGに起因」のような定量表現
6. **推定原因仮説**: データから推論される変化の原因を1-3個提示。ただし「推論」であることを明示

## セクションD: 総合所見

- アカウント全体の状態評価（改善基調 / 悪化基調 / 横ばい）
- 特に注視すべきポイント（2-3点）
- 次のアクションとして「詳細分析」に進むことの提案

---

# 厳守ルール

1. 数値は必ず入力データから算出すること。推測や概算で数値を生成してはならない
2. 「事実」（データから算出した数値・変化）と「推論」（原因仮説・解釈）は明確に区分すること
3. 「大幅に」「かなり」等の曖昧な表現を避け、必ず定量的に表現すること（例: ×「大幅に増加」→ ○「+32.5%増加」）
4. 影響度スコアの算出過程は省略せず、計算根拠を示すこと
5. 出力はすべて日本語で記述すること
```

## 使い方

1. 上記のプロンプト本体をコピーする
2. 「分析対象データ」のCSV部分を実データに差し替える
3. 期間名（「2026年1月」「2025年12月」等）を実際の期間に変更する
4. Geminiに貼り付けて実行する

## 実データに差し替える際の注意

- CSV形式を維持する（カンマ区切り、ヘッダー行あり）
- CPA/CTR/CVRが元データに含まれていない場合は、ヘッダーからそれらのカラムを削除し、プロンプト内に「CPA, CTR, CVRは算出して分析に利用すること」と一文追加する
- ADG数が多い場合（50以上）でも基本的にそのまま入力可能。ただしGeminiのコンテキスト上限に注意

## ダミーデータの設計意図

上記のダミーデータには以下の分析ポイントを意図的に仕込んでいる:

| ADG | 意図した変化 | 期待される検出 |
|-----|------------|-------------|
| 美容液_効果 | Cost +19%増、CV -18%減、CPA +46%悪化 | 全体CPA悪化への最大寄与候補 |
| 美容液_おすすめ | Cost +21%増、CV -4%減、CPA +26%悪化 | コスト増の寄与大 |
| リマケ_サイト訪問者 | Cost -11%減、CV -13%減 | CV減少の寄与大だがCPA微悪化 |
| リマケ_CV未完了 | Cost -14%減、CV -21%減 | CV減少寄与大、CPA +9%悪化 |
| ブランド_完全一致 | Cost -3%減、CV -11%減、CPA +9%悪化 | ブランドの効率低下 |
| スキンケア系全体 | 全般的にCPA悪化 | キャンペーン単位では影響大 |

「美容液_効果」が最も影響度の大きいADGとして特定されることを期待。Cost増+CV減+CPA大幅悪化の三重苦パターン。

## プロンプト改善のためのチェックリスト

テスト後、以下の観点で出力を評価し、プロンプトを改善する:

- [ ] 全体KPIの集計値が正確か（手動計算と照合）
- [ ] 影響度スコアの算出過程が明示されているか
- [ ] Top1の選定が「美容液_効果」になるか（ダミーデータの場合）
- [ ] 指標連鎖分析が論理的に正しいか
- [ ] 原因仮説が「推論」と明示されているか
- [ ] 数値に¥や%が正しく付与されているか
- [ ] 曖昧な表現がなく、すべて定量的か
- [ ] 出力の構造がセクションA-Dに沿っているか
- [ ] 次のアクション提案が含まれているか
