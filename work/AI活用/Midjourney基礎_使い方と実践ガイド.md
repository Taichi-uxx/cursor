# Midjourney基礎：使い方と実践ガイド

## 要約・サマリ

Midjourneyは、世界中で使われている画像生成AIで、AI画像生成の王様とも呼ばれる高品質な画像を作ることができる特徴を持つ。本ガイドでは、Midjourneyの基礎知識から実践的な使い方までを解説。

**主な特徴**:
- 高品質な画像を一瞬で生成可能
- コミュニティ内で他のクリエイターが作った画像やプロンプトを見ることができる
- エディット機能で細かく修正が可能
- プロンプトを書く技術より、最終的なアウトプットのイメージを持つことが重要

**実践的な活用方法**:
1. エクスプローラーで事例を探してプロンプトをコピー
2. ChatGPTやGeminiで翻訳・編集
3. クリエイトで生成
4. エディットで修正・編集

**V7の新機能**:
- 実行回機モデル（質感がよりリアル、アニメスタイルも可能、全体の統一感、同じキャラクターを使用）
- ドラフトモード（約10倍早く生成）
- リテクスチャ機能（同じ構図で素材を変更）
- イメージプロンプト、スタイル、キャラクターリファレンス機能

**参考動画**: [【第9回】Midjourney基礎](https://www.youtube.com/watch?v=tWVuJTE6y08)

## Midjourneyとは

### 基本特徴

- **世界中で使われている画像生成AI**: チャットGPTやGeminiでも画像を作れるが、より画像に特化した生成AI
- **AI画像生成の王様**: 高品質な画像を作ることができる特徴
- **コミュニティ機能**: コミュニティ内で他のクリエイターが作った画像や、その画像を作るために書いたプロンプトを見ることができる
- **エディット機能**: 一旦作った画像をエディット機能で修正するのがかなり細かくできる

### 主な用途

- **広告・SNS運用**: バナーや投稿画像
- **新規事業の企画**: 企画資料用の画像
- **ブランディング**: コンセプトのロゴなどの叩き台
- **プレゼン**: 仕様にインパクトのある画像を入れる

### 重要なポイント

- **プロンプトを書く技術より、最終的なアウトプットのイメージを持つことが大切**
- イメージが簡単に湧くプラットフォームが1番の特徴

### 画面構成

大枠4つに分かれている：

1. **サイドバー**: 色々なメニューがある
2. **入力欄**: 新しく画像を生成するためのプロンプト入力欄
3. **エクスプローラー**: 過去のクリエイターが作った画像を検索

## 主要メニュー

### エクスプローラー

**機能**: 他のクリエイターが作った画像とプロンプトを閲覧するメニュー

**使い方**:
- 検索で「コスメ」などと検索すると、コスメに関係する画像でクリエイターが作ったものを見ることができる
- クリックして、この画像を作るために使ったプロンプトを見ることもできる
- プロンプトをコピーして自分で使うこともできる

### クリエイト

**機能**: 自分でプロンプトを入力して作成していく、そのアウトプットを確認していくメニュー

**使い方**:
- プロンプト入力欄に「犬の画像を作って」などと入力
- 送信すると、左のサイドバーのクリエイトに「1/」などと表示され、画像が作られる
- 生成完了すると、4つの画像が表示される

### エディット

**機能**: 作成した画像や、自分が持っているローカルの画像をアップロードして、修正ができる機能

**使い方**:
- 画像をアップロードして変更ができる
- 詳細は後述

### オーガナイズ

**機能**: 自分の生成履歴や、過去作ったものを一覧で見ることができる

### チャット

**機能**: コミュニティみたいになっており、他のユーザーの事例や会話も見ることができる

**内容**:
- どんな風に作っているのか
- そこに対するコメント

## 画像生成の実践

### プロンプト設計の基本

**Midjourneyの特徴**: 先にあるプロンプトを結構優先的に構築され、画像に反映させるような特徴がある

**基本的な流れ**:
1. **主役**: 何が誰がを入れてくる
2. **詳細**: 詳細を付け加える
3. **背景・スタイル**: 背景とかはこれで、スタイルとかはこれにしてください

**例**:
```
若い男性が透明なデジタルスクリーンを操作している
背景には、ネオン
```

### 日本語プロンプトの対応

**V7から**: 日本語が使えるようになった

**それまで**: 英語でしかプロンプト依頼することができなかった

**特徴**:
- 英語のプロンプトで作った場合は、アウトプットも外国人になる
- 日本語で言えた場合は、出力も日本人により近くなる

**推奨**: 基本的に日本語でもやってもいいが、元々プロンプトは英語の方が精度が高かった

**使い分け**: 日本語で色々試した上で、精度が悪いとかであれば英語で試すのも1つの手段

### プロンプト生成の実践手順

1. **参考にしたいプロンプトを選ぶ**
   - エクスプローラーで「コスメ」などと検索
   - 好きな画像をクリック
   - その画像を作るために使ったプロンプトを見る

2. **プロンプトを日本語に変更**
   - 英語で作られていることがほとんど
   - Geminiなどで日本語に変更
   - 音声で入力することも可能

3. **細かい修正**
   - テキストで変更してもいい
   - 音声で入力する方が早い場合もある
   - 例：「先ほどのプロンプトを、若い日本人女性モデルに変更して再度最適なプロンプトを作ってください」

4. **生成**
   - クリエイトで生成
   - 方向性として近しいものを作ってくれる

### 実践的なワークフロー

**推奨される流れ**:
1. **エクスプローラーで事例探してプロンプトコピー**
2. **ChatGPTやGeminiで翻訳させたり編集したりする**
3. **クリエイトで生成**
4. **エディットで修正して編集**

**理由**: 画像のプロンプトはなかなか考えても出ないので、参考にしたいものを使ってそのまま色々修正していった方が早い

## エディット機能

### 基本的な使い方

1. **画像の選択**: 生成した画像を選択
2. **右クリック**: セーブイメージで画像をダウンロード
3. **編集方法**:
   - モアの部分からエディターを押す
   - または、ダウンロードした画像をエディットのところにドラッグアンドドロップ

### 編集の手順

**大枠の手順**:
1. **変更したい箇所をクリック**: ここはちょっと削除したいとかを示す
2. **変更したいプロンプトを追加**: プラスして追加
3. **生成開始**: 変更できる

**具体例**:
- セレクトボタンを押すと、自動で選択範囲が見える
- 選択範囲を削除するか、選択範囲以外を削除するか
- 例：「日本人女性のモデル。ベージュの右の着用じゃなくて、赤いにしましょう」

### よく使う機能

#### 1. 画角の変更

**用途**: 画像の画角を変えたい場合

**方法**:
- スマホ用に変えたい時など
- プロンプトはそのままで大丈夫
- 生成ボタンを押す
- 全身のものもすぐ作ってくれる

#### 2. アップスケール

**用途**: 高品質にする

**説明**: 
- アウトプットは結構綺麗だが、Midjourneyで色々なドラフトを作ってくれているので、改造度が低めになっている
- 実際に使うものは、アップスケールで改造度を上げて、実際生成すると、そのまま色々なメディアで使える画像になる

**方法**:
- いいなってものがあれば、アップスケールボタンを押す
- 改造度がいいものを作ってくれる

**活用例**: InstagramやGoogle AIスタジなどでコスメの画像とか切り替えたりして商品変えるとかもできる

## V7の新機能と応用

### V7の特徴

**実行回機モデル**: 新しく加わった機能

**特徴**:
- 質感が上がっている
- 質感がよりリアルになっている
- アニメスタイルも可能
- 全体の統一感を出したり、同じキャラクターを使って画像を生成することができる

### ドラフトモード

**機能**: 右上にある機能

**特徴**:
- オンにしておくと、通常よりちょっと画像の改造度が落ちる
- アウトプットをすぐ確認して、約10倍早く生成することができる

**使い方**:
- アイデア出しの段階、方向性段階はこのドラフトモードをオンにしておくのが大切
- 気に入った画像や実際に使いたい画像を、アップスケールで高品質に上げるというやり方が1番ベスト

**推奨**: 方向性決める場合は、オンに常にしちゃって作ってもらって大丈夫

### スタンダードモードとローモード

**切り替え方法**: モードボタンを押すと、スタンダードとローボタンを切り替えることができる

**スタンダードモード**:
- いわゆるMidjourneyっぽい画像になる
- 「これMidjourneyで作ったっぽいな」って画像

**ローモード**:
- リアルな写真っぽい画像を作ったりできる
- よりリアルに寄せたい場合は、ローボタンを押して生成するのも実務で使うポイント

**注意**: ローとかをする場合は、忠実に詳細とか書き込んだ方がいい

**デフォルト**: スタンダードになっているので、リアルにしたい場合はロードボタンを押して設定する

### エステティックの設定

**パラメーター**: 3つある

**機能**: このパラメーターをいじると、アウトプットをよりAIで遊びを持たせたりできる

**パラメーターの説明**:

1. **スタイライズ**:
   - 値上げるとよりAIがアート的なアウトプットを出すようになる
   - 下げるとそこまでアートよりではない
   - リセットボタンを押すとデフォルトに戻る

2. **ウィアドネス**:
   - どれだけ予測不能で風代わりなアウトプットを出せるかのパラメーター
   - マックスインするとより予測不可能なアウトプットを出してくれる

3. **バラエティ**:
   - 今回画像を作る時に4つアウトプットイメージを出してくれるが、これのランダム性
   - 色々な方向性見たい時は、ここをマックスにしておくと、かなり4つの画像が違う形で表示される

**活用**: ちょっと想像つかないようなものとか、よりアートりなものを使え、作りたい場合は、逆にここのパラメーターを上げたりすると非常に面白い画像が作れる。ロゴとか作る時は非常に便利な機能

### リテクスチャ機能

**機能**: 同じ構図だが、服装はちょっと小の、小物の素材を変えたいみたいな、ちょっと他のバリエーションも欲しい時に使える機能

**使い方**:
1. 画像をダウンロード（自分で撮った写真でも大丈夫）
2. エディットのところに画像を入れる
3. リテクスチャーというボタンを押す
4. 自動でおすすめのプロンプトを作ってくれるモードがあるので、これを押す
5. いろんなパターンを出してくれるプロンプトを作ってくれる
6. 生成

**特徴**: 構図は一緒だが、アウトプットのイメージが違う。ポーズはそのままなんだけどアウトプットちょっと変えたいみたいな場合に使える

### イメージプロンプト、スタイル、キャラクターリファレンス

#### イメージの追加方法

**方法**: イメージの部分で、@イメージというところを押すと、色々と画像を追加できるようになる

**3つの機能**:

1. **アニメーション化**:
   - 左側に入れると、この入れた画像をアニメーション化させることができる
   - スターティングフレームで参考にしたい画像を入れてあげるだけ
   - 再生してもらって大丈夫
   - 画像にすることができる（動画にすることができる）

2. **イメージプロンプト**:
   - イメージプロンプトにアップロードした上で、プロンプトとか入れると、この雰囲気や色、構図とかはそのままに、別の画像を作ることができる
   - 例：「場所外にしてください」とかって依頼すると、外の場所になるが構図とかは一生近しい

3. **スタイル**:
   - スタイルの部分に画像をアップロードして、その上で「例えばなんか男性版にして」とかってやると、いわゆる画像の風とかテーストとかはそのままにしたままで、別のものを作るみたいなことが可能
   - この画像のトーンを合わ、参考にしてこういうの作ってみたいな依頼が可能

4. **キャラクターリファレンス**:
   - 同じ画像、同じキャラクターをそのまま使って、別のものを作ることができる
   - **注意**: バージョン7だと使えない。6.1に変更した上で使う
   - 例：「ちょっとワクワクしてる女性にして」と依頼すると、顔とか人物は同じものを持ってきて作っている

**応用**: 複数入れてもいいし、色々な項目に参考ガス入れた上でプロトとか作っても大丈夫なので、結構応用くもので、多くが深いものになる

### パーソナライズ機能

**機能**: 自分がどっちが好みかというのをAIに覚えさせることができる

**使い方**:
- こちらが好み、こちらが好みみたいな選択をしていく
- 結構な量あるので時間かかる

**効果**: これをやると、アウトプットをなるべくそのユーザー個人に合わせたプットを出してくれるようになる

**推奨**: 長期的に使ってくるのであれば是非使った上で、接生していただければ
