## 用途（どんな時に活用できるか）
- 3媒体クロスでの戦略を組むとき
- どの媒体に投資すべきか判断するとき
- ToB案件でYouTubeを推す根拠を整理するとき
- TikTok×Instagramの連動施策を組むとき
- YouTubeを「単体運用」にすべき理由を説明するとき

## 各媒体のざっくり特徴

| 媒体 | 特徴 |
| --- | --- |
| **YouTube** | 長尺で見せられる → 教育に適している／他媒体からの流入（特に質の悪い流入）を嫌うアルゴリズム |
| **Instagram** | YouTubeとTikTokの中間／リールで認知・フィードで教育・ストーリーズで教育とロイヤリティ強化 |
| **TikTok** | 短尺・認知特化／フットワークの軽い行動（アプリDL／低単価購入／来店）に向く |

## 業界・サービスでの使い分け

| 媒体 | 向く業界・サービス |
| --- | --- |
| **TikTok** | コスト（金銭・時間・判断・行動）が低い業界（小売・外食・アプリ・割引キャンペーン等の特別企画） |
| **YouTube** | 説明コストがかかる商材／比較検討が必要な商材 |
| **Instagram** | TikTokとYouTubeの間 |

## ターゲットでの使い分け

### YouTube
- ToB・ToC高収入・高学歴など**明確なターゲット**に刺したい場合
- 理由：TikTok/Instagramにも検索機能はあるが、**実情ほぼ使われていない**
  - TikTokはホームでレコメンドされた動画をどんどん見る
  - Instagramは発見タブでレコメンド投稿を見る
- YouTubeは**ユーザーの自発的検索行動が活発** → 明確ターゲットに絞った発信が可能
- **ターゲット-コンテンツの一貫性を保ちやすい**
- 概要欄にリンクで外部遷移を促せるのも◎

### TikTok
- 認知を取りたい／人気者になりたい／商品名を拡散したい場合
- 広告でない限り**動画内リンクを貼れない**
- プロフィール経由のリンクしかない
  - （例外：食べログ・Filmarks・Cookpad は貼れる）

## 媒体の連動

### ❌ TikTok × YouTube は絡めない方が良い
- ユーザー層に差分がある
- TikTokで惹かれるユーザーと YouTube で惹かれるユーザーは毛色が違う
  - TikTok：面白さ・キャッチーさで評価
  - YouTube：コンテンツの質・ためになるかで評価
- YouTubeは視聴履歴でアルゴリズムが働く → **狙うユーザーと違う属性が引っ張られるTikTokは絡めない方が安全**

### ✅ TikTok × Instagram は相性が良い
- TikTok で認知 → Instagram のストーリーズで好意度UP・フィードで理解度UP → CV
- 「認知 → 教育 → CV」の鉄板の流れを2媒体で実現できる

### ✅ YouTube は単体運用が良い
- YouTube は他媒体からの流入を嫌うアルゴリズムの可能性
- 視聴履歴ベースなので **他媒体からの質の悪い流入で履歴が汚れる**
- → 単体で完結させる

## So What（戦略家としての示唆）
- **媒体選定の決定木**：
  - 説明コスト高 or ToB → YouTube単体
  - 認知拡散重視 × 低単価 → TikTok × Instagram連動
  - その中間 → Instagram単体
- 「TikTokとYouTube絡めるな」原則は**バズりたい欲求**で踏み外されやすい。提案時に明示
- YouTube概要欄リンクは**TikTokにはない強み** → 高単価リード獲得型では決定的な差
