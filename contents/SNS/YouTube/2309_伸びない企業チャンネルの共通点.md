# 伸びない企業チャンネルの共通点 — 4つの典型ミス

## 出典
- 元動画: [YouTube](https://www.youtube.com/watch?v=pjsgZtmYfq8)
- 元ナレッジ: 知見・ナレッジ移管/YouTube運用/伸びない企業チャンネルの共通点.boxnote
- 作成: 2023年9月

## 用途（どんな時に活用できるか）
- 既存チャンネルの「ここがダメ」を1ページで指摘するとき
- 改善箇所を絞り込む際の優先度判断
- クライアントへ「これが伸びない原因」と直接的に伝えるとき

## 4つの典型ミス

### ①サムネが無い
- 動画と同じくらい大事かつクリティカル
- デフォルトサムネのままは論外

### ②企業の宣伝しかしない
- 視聴者が見るメリットがない
- 設計すべきこと：
  - なぜその動画を見る必要があるのか
  - なぜその動画に興味を持ってもらえるのか
  - 見たらどんなメリットを享受できるのか

### ③チャンネル名で何系か分からない
- チャンネル名・アイコン・カバーアート → **一目でどんなチャンネルかわかる**ものに

### ④編集が雑
- 間延びしたカット
- テロップがない／少ない
- 重要ポイントにテロップがない
- 耳障りなSE／BGM
- **MAが雑**（MA: 声・BGM・SEのボリューム調整）

## So What（戦略家としての示唆）
- 4ミスのうち最も簡単に潰せるのは**①サムネ作成**と**③チャンネル名**。提案で「即やる項目」として出せる
- ②の「企業宣伝チャンネル」問題は決裁者の理解が必要 → ユーザー目線への切り替え提案が必要
- ④MAの観点は**動画編集者の質**を測る指標として面白い。発注時にチェックポイントとして使える
