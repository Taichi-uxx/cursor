### 提供チームの実績
- YouTube: 0人 → 23.9万人（WHITEBOX）
- TikTok: 0人 → 56.4万人
- Instagram: 0人 → 2.0万人

## 用途（どんな時に活用できるか）
- 既存YouTubeチャンネルの現状診断テンプレートとして
- クライアントへの「改善提案」の出だしに使う初期チェックリストとして
- チャンネル運用の月次レビュー前の自己点検として
- 「黄色信号」シグナルでアラートを上げる仕組みとして

## ① 選んでいるカテゴリは YouTube内の需要があるか

- [ ] **競合を調べてジャンルのMAX値を理解する**
  - 競合のチャンネル登録者数が100万人 or 1万人で目指す数値が変わる
- [ ] **ライバルが少なすぎるジャンルは危険**
  - 全く需要がない可能性。YouTubeではなくTikTok/Instagramの可能性も検討
- [ ] **ジャンルは絞ってずらす**
  - 例: 美容系の需要があるからといって闇雲企画ではダメ
  - ターゲット層をズラす／**○○コスメに特化**等の工夫

## ② 伸びやすい企画の切り口を使えているか

- [ ] **検索ボリュームや関連を意識できているか**
  - ツールでKWを把握 → 見られやすい企画を作る
  - 関連動画に露出しやすい設計も大切
- [ ] **クリックしたくなる訴求になっているか**
  - サムネは少ない文字数で理解させる
  - ついついクリックしたくなる文言か
- [ ] **競合のコメント欄から企画の分析をできているか**
  - 競合の伸びている企画を参考に
  - コメント欄に書かれている内容から**真の需要を分析**

## ③ 一目でわかりやすいチャンネル設計になっているか

- [ ] **チャンネル名がわかりやすいか**
  - 名前だけで何のチャンネルかイメージできる
  - 誰向けが明確 → チャンネル登録率UP
- [ ] **ヘッダーやアイコンは設定できているか**
  - 画像・テキストでチャンネルを理解させる
- [ ] **チャンネルのトンマナが揃っているか**
  - これから先どんな動画がアップされるか**イメージできるか**
  - コンセプト・雰囲気に一貫性

## ④ サムネイルを工夫できているか

- [ ] **スマホからでもわかりやすいか**
  - 文字サイズ・色などスマホで視認できるか
- [ ] **正しいサムネイルの構成になっているか**
  - **14文字程度で収まる**形が良い
  - 人物・背景で企画がわかりやすく伝わる
- [ ] **内容と一致しているか**
  - クリック率が高くても離脱率が高ければ良いサムネとは言えない
  - **クリック率と視聴維持率の両方**を意識

## ⑤ 正しい運用体制になっているか

- [ ] **エンゲージメントが落ちる運用になっていないか**
  - 登録者数に対して再生数が低い → 長期的に伸び悩む可能性
- [ ] **クリック率、視聴維持率を確認できているか**
  - 再生数だけでは正しい改善はできない
  - サムネ／動画内容／企画のどこに問題か把握
- [ ] **定期的な更新ができる体制になっているか**
  - データが集まり改善できる
  - ユーザーの視聴習慣を作る

## ⑥ 見直しの黄色信号

- [ ] **競合のチャンネルと比べた際の伸び率**
  - 伸びの推移が異なる場合は見直し
  - 需要に対して正しい動画を出せているか
- [ ] **インプレッション数と再生数のズレ**
  - IMPあるのに再生伸びていない → **サムネ見直し**
  - 正しい訴求になっているか
- [ ] **視聴維持率が低くなっていないか**
  - どこのシーンで離脱したか確認

## So What（戦略家としての示唆）
- 6カテゴリ × 3項目（計19）は**月次レビューのチェックシート**にそのまま使える
- 「**サムネ14文字**」は実用Benchmark
- ⑥黄色信号3項目（伸び率／IMP-再生ズレ／維持率）は**アラート設定**として運用できる
- 「ライバルが少なすぎる＝需要がない可能性」の発想は[[2309_YouTubeチャンネル構築でやってはいけないこと]]の「市場が小さすぎる」と一致
- 「サムネはクリック率＋維持率の両方」発想は[[2309_CTR_視聴維持率を上げる方法]]の「サムネに答えを書かない」と整合
