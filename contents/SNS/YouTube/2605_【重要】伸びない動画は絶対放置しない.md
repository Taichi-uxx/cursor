# 【気づいて】伸びない動画は絶対放置しないでください【YouTubeのしくみ】

## 詳細
https://youtu.be/TI1ONv1vHLA

## 概要

伸びない動画が出てしまうのは、再生回数が広がっていくルートのどこかで止まっているからである、というYouTubeの構造を解説した動画。「リピーター層 → ターゲット層 → ジャンル全体層 → 全般層」と外側に広がっていく再生回数の動きを図式化し、止まったラインを特定する方法（YouTube公式のアナリティクスメッセージの読み解き方）を示す。さらに「伸びないテーマは2度と使わない」「半年経過＆データ不良の動画は非公開にする」など、具体的な分析〜対処の流れを整理。

## 結論：伸びない動画は分析してから対処する

伸びない動画を「伸びないな」で終わらせるのは最大のもったいない。
- 削除・非公開の前にまず**ライン引きを分析**する
- 2度と同じ過ちを繰り返さないために、**伸びなかったテーマを把握**する
- それを徹底することで「伸びるテーマの確率」が自然と上がる

## YouTubeの再生回数が広がる構造

### 全体に広がるのではなく、反応が高い人を選んで広がる

- 動画が伸びた = 運がよかったではなく、**反応のいい視聴者に接続できた**結果
- 反応のいい視聴者の近くに似た人がいる → さらにルートが繋がる → インプレッションが広がる

### ライン引き（広がりの層）

外側に広がるほど再生回数が増える、4つの層：

1. **リピーター層**（一番内側）
2. **ターゲット層**（チャンネルが狙う視聴者層）
3. **ジャンル全体層**（例：料理のレシピ全般に興味がある人）
4. **全般層**（一番外側、最も多くの人）

→ どこで止まっているかで動画の評価が変わる。**手前で止まっているほど伸びない**。

### 各止まりラインの意味

- **リピーター層内で止まる**：いつも見てくれている視聴者には興味あり。しかし新規はクリックしない
- **ターゲット層で止まる**：ターゲットにはクリックされるが、その外側に届かない
- **ジャンル全体には届かない**：チャンネルが内向きになる
- **全般層まで到達**：爆発的に伸びる

### 内向きチャンネルの末路

- リピーターだけに受けるチャンネルになる
- 100人ファンがいても3ヶ月後・半年後と少しずつ減る（人の興味は移ろう）
- 外に開かないと縮小する

### 外側に広げる手段

- 動画のテーマを狙った層に届くものに設計する
- **テーマ選定がYouTubeで最も大事**
- 例：このチャンネルは最初「YouTubeの設定」をテーマにしていたが、興味のある人がごく一部だった → 「YouTubeの伸ばし方」にテーマ変更 → ターゲットが何倍にも広がり右肩上がり

## アナリティクスでライン引きを判定する方法

### どこを見るか
- アナリティクス → 右下「直近10本の動画の成績」
- インプレッションのクリック率にカーソルを合わせる
- YouTubeからのコメントメッセージで層が分かる

### YouTube公式メッセージの読み解き方

#### パターン1：「この動画の視聴者は通常ほど広くありませんが、クリック率は他の動画と同じ程度です」
- → **リピーター層止まり**（最悪パターン）
- リピーターにしかインプレッションされていない → クリック率は維持されるが再生は広がらない
- このまま続けると内向きチャンネル化 → 反省すべき

#### パターン2：「この動画をユーザーが選択して視聴する割合はお客様の他の動画と同じ程度です。クリック率は良好です」
- → **そこそこ良い**

#### パターン3：「パフォーマンスは良好です。YouTubeのユーザー通常よりも高い割合でこの動画を選択して視聴しています」
- → **幅広い層まで届いている＆クリック率も高い**
- 非常に良い状態。さらに外側に広がる可能性

#### パターン4：「この動画のクリック率が通常より低いのは幅広い視聴者にリーチしているためです。視聴者が広がるとユーザーが選択して視聴する割合が下がることがあります。ただしクリック率が低いために動画の視聴回数に悪影響が生じることはありません」
- → **全般層まで届いている**（最高パターン）
- 奥まで届くと初見の人にも当たるため、クリック率は構造的に下がる
- それでもYouTubeは「いい動画」と判断して広げている

### 結論
- **パターン3・4が来る動画**を目指す
- **パターン1が来る動画**は二度と同じテーマで作らない

## 鉄則：伸びなかったテーマは2度と使わない

### テーマとは
- 動画の企画・ネタのこと（例：「動画の始め方」「伸びない動画放置しないで」「登録者別まずやること」）

### なぜ繰り返してはいけないか
- どんなにサムネ・中身が良くても、テーマ自体が微妙だと伸びない
- 繰り返すとチャンネル全体が内向きになる
- 一発バズっても、伸びないテーマを繰り返したらまた内向きに戻る

### 数学的な希望
- 自分の頭の中のテーマが9個間違いで1個当たりだったとする
- 9個を試して使わない → 残るテーマで作る
- また10個ネタを出した時、過去の失敗パターンを除外しているので**伸びるテーマの比率が上がる**
- 繰り返すうちに伸びるテーマの比率がどんどん上がる
- 結果：チャンネルが伸びやすい状態に近づく

## 仮説検証：なぜ伸びなかったかを言語化する

### どこを見るか
- **サムネイル**と**タイトル**
- なぜ視聴者は興味を持たなかったのか、原因を言語化

### 実例：「2025年お疲れ様」動画
- 菅野氏のチャンネルで2026年に入って一番伸びなかった動画
- 仮説：このチャンネルの視聴者は「YouTubeを伸ばす方法」が知りたい
- 「お疲れ様」「成果出す方法」はそこから外れている
- → 視聴者の知りたいことを念頭に置けていなかった

### 視聴者の正直さ
- 興味があったら見る、なかったら見ない
- 興味があること = 大きなメリット／強く知りたいこと／面白そう
- これを**一撃で当てる**スキルが必要

### 確率の組み合わせ
- テーマ50%、サムネ50%、タイトル50%、撮影50%、編集50%、台本50%…
- 全部当てるのは構造的に低確率
- でも全項目で「当てに行ける」スキルがあれば全部当たる
- → これがYouTube攻略の本質

## 伸びない動画への具体的対処

### 削除・非公開の前にやること
1. ライン引きを分析する（公式メッセージを読み解く）
2. 伸びなかったテーマを2度と使わないと決める
3. サムネ・タイトルの仮説検証をする

### 削除すべき動画
- **YouTube規約／日本の著作権／収益化ポリシーに違反している動画**
- 後から見つかると：
  - 収益化剥奪
  - チャンネルban
  - 複数チャンネル所有時に**他のチャンネルも一斉ban**になる現象あり

### 非公開にすべき動画の3条件（全て当てはまる）

1. **動画の成績が悪い**
   - 例：いつもクリック率7%なのに今回4%以下
   - 例：10分動画でいつも平均視聴率40%なのに今回20%未満
2. **チャンネル平均の再生回数より明らかに低い**
   - 例：いつも1000回なのに今回400回（700-800回程度ならまだ置いておく）
3. **半年以上経過している**
   - YouTubeでは後から再生回数が伸びるパターンがある
   - 1ヶ月で非公開すると、後伸びを潰してしまう

### 推奨頻度
- 4〜6ヶ月に1回まとめて整理する
- 毎日やる必要はない

### 非公開のメリット：インプレッションの再配分
- YouTubeでは1動画見た人が、関連動画・チャンネルページから他動画を見る回遊が発生
- 微妙な動画を非公開にすると、その分のインプレッションを他のいい動画に回せる
- 回遊が起きれば、視聴者がそのチャンネルのファンになる確率が上がる

### いい動画とは
- 編集が凝っていることではない
- 例：猫の動画は編集ほぼなしカット編集だけで20〜30万回再生
- **動画の素材自体が良いか**が本質
- YouTubeは凝った編集を強要しない、シンプルに「いい動画」なら伸びる

## 田村太一としての示唆

- **再生回数が広がる構造（リピーター→ターゲット→ジャンル全体→全般）の4層モデル**は強力な分析フレーム。広告運用でも「リターゲ→興味関心→類似→広域」の段階的拡張と同じ構造。LPの効果検証でも転用できる
- アナリティクスの**YouTube公式メッセージ4パターン**を判定基準として使うのは秀逸。SNS全般で「公式が出してくる定型コメント」をテンプレ判定に使う発想は広告管理画面の評価コメントでも応用可能
- **「伸びないテーマは2度と使わない」原則**は、運用案件のクリエイティブテストにそのまま使える。負けクリエイティブのテーマを学習し、勝ちテーマの確率を上げていく
- **非公開判断の3条件（成績悪／平均以下／半年経過）**は具体的で明快。クライアントの広告審査落ち／停止判断のロジックにも転用可能
- **「ファンが多いチャンネルほど回遊が起きる」**事実は重要。ストック資産が次の動画の自然増を引き寄せる仕組み（前動画の「岩盤」概念と一致）
- 「全項目で当てに行くスキル」 = テーマ／サムネ／タイトル／撮影／編集／台本のそれぞれで打率を上げる、というメッセージは、自分の発信開始時の学習計画の指針になる
