## 1. 基本：再生回数の分解
```
再生回数 = インプレッション数 × CTR
```
- インプレッションの3経路: **YouTube検索／ブラウジング機能（ホーム）／関連動画**
- どれも動画が良質と見なされるとインプレッション数が増加

## 2. YouTube検索

### 検索流入の重要性
- 年収チャンネル全期間で検索流入は **8%（=238万再生）**
- 割合は少ないが累積効果大
- KWがうまくハマれば**検索流入90%超え**の動画もある

### 検索流入は積み重なる
| 時期 | 検索流入の割合 |
| --- | --- |
| 2018/5（始動時） | 0% |
| 2019/1 | 4% |
| 2019/7 | 5% |
| 2020/3 | **8%** |

> **公開時はCTR重視のクリックされやすいタイトル → 1ヶ月後にKWを含めたタイトルに変更**するのが良い

### 狙うKW
- ビッグワードはハイリスクハイリターン
- スモールワードはローリスクローリターンだが積み重なれば大きい
- **開設初期はスモールワード → チャンネルパワーがついたらビッグワード**

### タイトル文字数
- **30文字前後が最適**（40文字以上はNG）
- 多すぎるとCTRが下がる（タイトル省略で見えなくなる）
- データ：30字以上ではCTRが少し下がっている

### バズキーワード①（汎用）
> YouTubeにはバズキーワード = クリックされやすい文言がある。**負の感情を強く動かすものが多い**

代表的なバズワード：
- 暴露／リアル／闇／驚愕／実は〜だった／裏事情
- 放送事故／閲覧注意／ドッキリ／まさかの結果に／ガチギレ／腹筋崩壊
- 削除覚悟／過激

→ 毎動画使うとくどくなるので**満遍なく散らす**

### バズキーワード②（チャンネル個別）
年収チャンネルで伸びやすかったKW：
1. 年収
2. 公開
3. 〜万
4. リアル
5. 注意

→ **チャンネル趣向に沿った個別バズキーワード**を見つける

## 3. 視聴者維持率の定義
- 動画の各時点での視聴回数 ÷ 動画の全視聴回数
- 100万回再生で1:00地点の維持率80% → その地点が80万回再生されたこと
- 同一ユーザーが何回見てもカウント → **100%以上の値も存在する**

## 4. 維持率を上げるテクニック

### 構造的ポイント
- **真ん中の女性が発言時**
- **質問読み上げて植本がディスった時**
- **株本が毒づいた時**
- **何かの場所を伝えてる時**（質問箱・ゲストch等）

### 維持率の目安（年収チャンネル基準）

| 動画長さ | 維持率の目安 |
| --- | --- |
| 10分以上 | **42%以上** |
| 7〜10分 | 50%以上 |
| 4〜7分 | 57%以上 |
| 4分以下 | 62%以上 |

- 年収チャンネル全体平均：**52.6%**

### 上げる具体テクニック

#### ジェットカット
- 1秒以上話していない間は極力カット

#### 結論を後半に
- 結論=ユーザーが一番知りたい箇所 → 後半に持ってくる
- 対談形式でコントロールできない場合 → キラークエスチョンを後半に投げる／セクションごとに切り離して編集

#### 冒頭で自己紹介
- 新規ユーザー目線：「誰だこいつ？」を冒頭で潰す

#### フルテロップ
- ユーザビリティ向上 → なるべくフルでつける

#### 動画最後におまけ
- 「実咲の一言」のようなおまけで最後まで見せる
- 撮影オフショット／NGシーン／次回予告も有効

## 5. 動画の長さ

### 結論
> **長ければ長いほどYouTubeは良い評価をする傾向**

- **10分以上の動画は明らかにインプレッション数が増加**
- **4分以下はかなり低い**
- → 視聴者維持率より**視聴時間**が大事

### 具体例
- 4分動画で維持率80% (= 視聴時間192秒)
- 15分動画で維持率50% (= 視聴時間450秒)
- → **15分動画の方がインプ数が増える**

### CTRとの関係
- 動画尺が1分長くなるごとに**平均CTRは0.3%減少**

## 6. チャンネル登録者数の増減

> **登録者数が減る動画は明らかに再生回数が少ない**

### データ比較
|  | 動画長さ | 維持率 | 視聴時間 | 視聴回数 | ch登録者数 | CTR | 高評価率 | IMP |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| チャンネル平均 | 6:43 | 56.6 | 3:42 | **40000** | 2542 | **64** | 5.7 | 78.2% | 556080 |
| 登録マイナス動画平均 | 7:10 | 55.1 | 3:47 | **19000** | 1226 | **-6.5** | 5.4 | 64.4% | 266178 |

→ 登録者数の増減もYouTube側が評価軸にしている可能性

## 7. 投稿タイミング

### 時刻
- **17〜22時**がYouTube閲覧者が増える時間帯
- 年収チャンネルは**毎日19時／土日祝13時**
- 19時00分ジャストは他チャンネルと競合 → **19時01分に手動公開**

### 曜日
| 曜日 | 平均視聴回数（万回） |
| --- | --- |
| 月曜 | 2.76 |
| 火曜 | 2.93 |
| 水曜 | 2.88 |
| 木曜 | 2.96 |
| **金曜** | **3.34** |
| **土曜** | **3.36** |
| 日曜 | 2.80 |

→ **自信ある動画は金・土曜に投稿**

## 8. 関連動画

> **高評価率が50%以下だと関連動画に表示されにくい**

- 高評価率50%以下の動画の関連動画流入は**通常より30%減少**
- 「興味なし」ボタンも評価以上に大きな影響を与える可能性

### YouTube公式の評価軸
- 視聴者がどんな動画を見ているか／見ていないか
- どれくらいの時間見ているか
- **動画への高評価・低評価**
- **「興味なし」のフィードバック**

## 9. CTR

### 平均CTRと動画の質に相関はない
- YouTubeは「CTRが高いから良い動画」とは判断しない
- → CTRはIMP数を増やす要因にはならない
- 代わりに **「初日CTR」が重要**

### 初日CTRの重要性
- 初日CTRだけが高くて伸びた動画が多数確認された
- "勢い"の指標として機能（YouTubeは「急上昇」メニューで勢いを見ている）
- **YouTubeは動画の質をリアルタイムで計測している**
- → **一度公開した動画を非公開にして再度公開はNG**（初日CTRが下がる要因）

### 公開後1時間で伸びない時の改善
- サムネ or タイトルを変更
- 実例: 「大学を辞めてフリーランスになる方法」 → **「MARCH未満の大学って卒業する意味ある？」**

### 良かった/悪かった事例
- **良**: 「自分がディスられてるんじゃね？」という不安からクリックしたくなる → 「この動画で傷ついちゃった人ごめんなさい」
- **良**: バズキーワードがハマる → 「《削除覚悟》ジャニーズが禁断の給料暴露」
- **悪**: 「初登場サイバーエージェントを知り尽くした男」→ サイバーエージェントに興味ある人しか巻き込めない
- **悪**: 「StockSunのビジネスモデルはマネできる？」→ ターゲットが狭い

## 10. ストーリー機能
- 1ヶ月間、週2本のペースでTikTok用縦動画を投稿
- → 月間チャンネル登録者の**4.5%（=210人増）**
- 「**とりあえず投稿しておくだけでも効果がある**」

## 11. 付録：YouTubeアルゴリズムのイメージ
```
[土台] ブラウジング機能 ← 総合評価（土台はある程度保証）
[+α] 関連動画           ← 影響大の評価軸
[+α] YouTube検索／chページ
```

### 動画の評価軸（影響大）
- 高評価率
- 視聴者維持率
- ch登録者増加数
- 共有数
- **初日CTR**
- **公開後の勢い**

## So What（戦略家としての示唆）

### 数字で覚えるBenchmark
- **10分以上動画は維持率42%以上**でOK（年収チャンネル基準）
- **平均CTRより初日CTR**が重要（13.9% / 12.9% の好例あり）
- 投稿は**金土19時01分**が最強
- 一度公開した動画は**非公開→再公開NG**
- 動画尺は**長いほど評価高**（10分以上 vs 4分以下で雲泥の差）

### 反直感的な発見
- 「CTRが高い＝良い動画ではない」（YouTubeはそう判断していない）
- **初日CTR**が決定的、その後のCTRはあまり影響しない
- 動画を長くするとCTRは0.3%/分減るが、それでもIMP増加メリットが上回る
- 登録者数マイナスは**再生回数に直接ヒット**する → 不快コンテンツは避ける

### バズワード活用
- 汎用バズワード（暴露・闇・驚愕等）×チャンネル個別バズワードの掛け算
- 自社チャンネルの個別バズワードを実測で見つけるプロセスは他案件にも横展可
