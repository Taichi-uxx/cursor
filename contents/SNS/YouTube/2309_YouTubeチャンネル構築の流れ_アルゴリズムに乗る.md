# YouTubeチャンネル構築の流れ（アルゴリズムに乗るために）

## 出典
- 元動画: [YouTube](https://www.youtube.com/watch?v=0zBRl0TPZ1M)
- 元ナレッジ: 知見・ナレッジ移管/YouTube運用/YouTubeチャンネル構築の流れ（アルゴリズムに乗るために）.boxnote
- 作成: 2023年9月

## 用途（どんな時に活用できるか）
- YouTube案件初動の「種の作り方」を設計するとき
- KWのPDCA（粒度調整）の指針を作るとき
- 視聴完了率／総再生時間のKPI設定をするとき
- 案件の期間設計（最短3ヶ月／平均6ヶ月／1年判定）を組むとき
- 「1000時間／4000時間の壁」をマイルストーンとして提示するとき

## 前提：YouTubeアルゴリズム
- **視聴履歴をもとにアルゴリズムが働く**（登録者は関係ない）
- 「この動画を視聴したAさんはどんなチャンネルが好きで、どんな動画やch経由で来るのか」を読み込み、それに近しいユーザーにレコメンド表示
- 例：株本SS → 年収チャンネル／令和の虎の視聴者・Webマーケ系視聴者にレコメンドが回る

## Step1: 検索流入で「最初の種」をつくる
- ユーザーが検索するKWに対し、しっかりした動画を作成
- これを何度もつくることで「この動画はこんな人が見る」というデータが媒体に溜まる
- KWについてもPDCAを回す

## Step2: KW粒度のPDCA

### ゲーム系を例にした粒度分解
```
ゲームBIGワード（ゲーム実況）
 ↓
ゲーム機器（プレステ・スイッチ）
 ↓
タイトルワード（ドラクエ・FF）
```

### 進め方
- どの粒度のKWで流入が獲得できるか **PDCA を回す**
- 良いKW（例: ドラクエ）が見つかったら、そこに**ゴリゴリ寄せて作り込む**
- ある程度成長したら粒度を1つ上げる or 同粒度別ワード（FF）でも流入を取りに行く

## Step3: 視聴完了率を上げるPDCA

### 重要な数式
```
総再生時間 = IMP × CTR × 視聴維持率
```

- アルゴリズムが乗るためには「総再生時間」を稼ぐ
- 狙うべき層にちゃんと「総再生時間」を溜めていくのが最終ゴール

### 視聴維持率のボーダー
- **10分動画なら 40% が基準**
- 40%切ったらマズい

### 維持率を上げる施策
- **編集をプロ（YouTube特化）に頼む**
- 登場人物のキャラを濃くする
- 台本・構成を作り込む
- **まこなり社長**の動画は参考にしまくる
- エンタメ系じゃないのに伸びているチャンネルを分析し徹底的に盗む

## 期間設計

| 段階 | 期間 |
| --- | --- |
| 最短 | 3ヶ月 |
| 平均 | 6ヶ月 |
| 撤退判定 | 1年改善なし |

### マイルストーン
> 総再生時間が **「1,000時間」「4,000時間」**を超えるタイミングで急にガッと成長するケースが多い

→ この2つのスパイク点を案件のマイルストーンとして設定する

## So What（戦略家としての示唆）
- 「最初の種」フェーズは**検索流入KWでデータ蓄積**が正解。レコメンドを狙うのは後
- KWは「粒度を細かくして1点突破 → 拡張」が定石。「ゲーム系」のような粗い粒度ではアルゴリズムが乗らない
- 視聴維持率40%（10分動画）は提案資料に即引用可能なBenchmark
- **1,000時間・4,000時間の壁**は案件のマイルストーン設計に使える。クライアントへの説明にも◎
