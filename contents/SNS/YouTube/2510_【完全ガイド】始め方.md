## YouTubeアカウント作成手順

### Step 1: Googleアカウント作成

#### パソコンの場合
1. YouTubeを検索して開く
2. 右上の「ログイン」を押す
3. 新しいGoogleアカウントを作成する場合：
   - 「アカウント作成」をクリック
   - 「個人で使用」を選択
   - 名前を入力（ニックネームでも可）

#### 新規Googleアカウント作成のポイント
- **新しく作ることをお勧め**：YouTubeチャンネルと紐づいたメールがGmailに来るため管理しやすい
- **Gmailアドレスを取得**：「既存のメールアドレスを使用」ではなく「Gmailアドレスを取得」
- **安全なパスワードを作成**：アルファベット、数字、記号を組み合わせる
- **電話番号で確認**：6桁の確認コードでロボットによる操作でないことを証明

#### スマホの場合
1. YouTubeアプリを開く
2. 右下の「マイページ」を押す
3. 同様にGoogleアカウントを作成

### Step 2: YouTubeチャンネル作成

#### パソコンの場合
1. YouTube Studioを開く
2. 右上のアイコンをクリック
3. 「チャンネルを作成」を選択

#### スマホの場合（デスクトップ表示にする必要あり）
1. 左上をクリック
2. 3点マークをクリック
3. **「デスクトップ用ウェブサイトを表示」**を選択（重要）
4. 右上のアイコン → 「チャンネルを作成」

#### チャンネル作成時の注意点
- プロフィール写真、名前、ハンドルは後で設定可能
- 一旦「チャンネルを作成」をクリック

### Step 3: チャンネルの初期設定

#### 基本的な設定項目

##### 1. チャンネル名
- **変更制限**: 14日間で2回のみ変更可能
- **入力タイミング**: ジャンル・コンセプトを決めてから入力
- チャンネル名 = YouTubeのデザイン チャンネルなど

##### 2. ハンドル
- **ハンドルとは**: YouTubeチャンネルのURLの最後に入る名前
- **入力可能**: 日本語・ローマ字どちらでも可
- **注意点**: 日本語URLの場合、長い文字列になることがある
- **確認方法**: チェックマークがつけば他ユーザーと被っていない

##### 3. 大名詞（新しい機能）
- **説明**: 視聴者から自分をどう呼ばれたいかを設定
- **例**: 海外では「she/he/they」など
- **現状**: 日本語フィルターがないため日本語入力は不可
- **対応**: 任意で設定するかスキップ可能

##### 4. 説明欄
- **表示場所**: チャンネル詳細の「さらに表示」から確認できる
- **閲覧者**: チャンネルに興味のある熱心な視聴者
- **推奨内容**:
  - 毎週の配信曜日・時間の告知
  - 自己紹介
  - 動画を始めた目的・思い

##### 5. リンク
- **表示場所**: 説明欄の下
- **用途**: 宣伝したいURLを設定
- **例**: SNS、公式サイト、メールアドレスなど

## YouTubeチャンネルのデザイン設定

### 使用ツール: Canva
- **サイト**: canva.com
- **アプリ**: App Storeで「CANVA」をダウンロード

#### Canvaアカウント作成
- Googleアカウントで連携可能
- 以前作成したGoogleアカウントを使用

### デザイン要素1: チャンネルアイコン

#### サイズ
- **比率**: 縦×横が同じ（正方形）
- **用途**: 丸形のロゴ

#### Canvaでの作成方法（パソコン）
1. 「AIでロゴを作成」を選択
2. 質問に答えて進める
3. 無料トライアルでOK（課金部分はスキップ）

#### Canvaでの作成方法（スマホ）
1. 「テンプレート」を選択
2. 「YouTube アイコン」で検索
3. 王冠マークのない無料テンプレートを使用
4. カスタマイズ（色、画像、文字など）

#### カスタマイズのポイント
- 背景色を変更できる
- キャラクターやイラストを追加・削除可能
- 素材ライブラリから画像・ステッカーを追加
- AIで画像生成も可能

#### ダウンロード方法
- **パソコン**: 右上の「共有」→「ダウンロード」（PNG推奨）
- **スマホ**: 右上のダウンロードボタン → 写真への許可 → カメラロールに保存

#### YouTubeへの設定
1. チャンネルをカスタマイズ → アイコン設定
2. 「アップロード」をクリック
3. 画像を選択・調整
4. 丸い部分に合わせて調整
5. 数十分待つと反映される

### デザイン要素2: チャンネルバナー

#### 重要性
- **表示場所**: YouTubeチャンネル上部の横長画像
- **理由**: 
  - チャンネルの世界観を大きく表現できる
  - サムネイルやアイコンは面積が小さい
  - チャンネル全体の世界観を示すには最適

#### Canvaでの作成方法
- **パソコン**: 「YouTube バナー」で検索
- **スマホ**: 「デザインを作成」→ 「YouTubeバナー」で検索
- 王冠マークのない無料テンプレートを選ぶ
- 30日間無料トライアルも利用可能

#### バナー画像の3つの表示領域
1. **テレビで表示可能**: 最も外側の範囲
2. **パソコンで表示可能**: 横長の範囲
3. **全てのデバイスで表示可能**: スマホで表示される範囲（重要）

#### 重要ポイント
- **スマホで表示される範囲を重視**
- YouTubeはスマホ閲覧者が多い
- スマホで見えない位置に重要な要素を配置しない

### デザイン要素3: 動画のスカッシュボタン

#### 説明
- 動画右下に表示されるチャンネル登録ボタン
- 登録者増加に効果的

#### 作成方法
- Canvaで「ロゴ」を検索
- 丸い素材をカスタマイズ
- **ポイント**: 文字をできるだけ大きくする（ボタンが小さいため）

#### 設定タイミングの推奨
- **おすすめ**: 「動画の最後」
- **理由**: 動画を最後まで見た視聴者は好意を持っている
- 中盤・後半まで見る人の方が登録意欲が高い

## YouTubeの機能解放

### なぜ必要か
現在の状態では以下ができない：
- 15分以上の動画を投稿
- カスタムサムネイルを設定
- 再生リストを作成
- ライブ配信

### 中級車向け機能の解放

#### パソコンの場合
1. チャンネルをカスタマイズ → 設定
2. 「チャンネル」をクリック
3. 「機能の利用資格」をクリック
4. 「電話番号を確認」を選択

#### スマホの場合
1. 左上のマークをクリック
2. 3点マーク → 「デスクトップ用ウェブサイトを表示」
3. 右上のアイコン → 設定 → 詳細設定
4. 「チャンネルのステータスと機能」をクリック
5. 「電話番号を確認」をクリック

#### 確認コードの受け取り
- **SMSまたは電話**で確認コード受信
- 6桁の確認コードを入力
- 「電話番号を確認しました」で完了

#### 解放される機能
- カスタムサムネイル
- ライブ配信
- 15分を超える動画投稿

### 上級車向け機能の解放

#### 解放方法
1. **動画認証**: スマホカメラで指示通りに対応
2. **有効な身分証明書**: マイナンバーカード、運転免許証、パスポート
3. **チャンネル履歴**: コミュニティガイドラインに沿った動画を2ヶ月投稿

#### おすすめ: 有効な身分証明書
- **時間**: すぐに解放される（動画認証も同じ）
- **チャンネル履歴**: 2ヶ月かかる

#### 手順
1. 「身分証明書の写真を撮影」をクリック
2. メール受信を確認
3. IDタイプ選択（運転免許証またはパスポート）
4. 利用規約に同意
5. 表面・裏面を撮影
6. 情報を確認して送信
7. **24時間後に確認完了メールが届く**

#### 解放される機能
- サムネイルのABテスト
- 1日あたりのアップロード数上限引き上げ
- 収益化の申し込み資格
  - **広告収益**:
    - 登録者1000人 + 直近1年で4000時間
    - ショート動画: 90日間で1000万回再生 + 登録者1000人
  - **500人での収益化**:
    - 過去90日間で3回以上動画アップロード
    - 過去12ヶ月で3000時間以上
    - スーパーチャット、メンバーシップ、投げ銭など

## 動画撮影

### カメラはスマホでOK
- 高価なカメラは不要
- スマートフォン1台で十分
- YouTubeアプリで直接撮影可能

### YouTubeアプリでの撮影方法
1. YouTubeアプリを開く
2. 「+」ボタンを押す
3. カメラ向きを切り替え（インカメ用）
4. 撮影ボタンを押す

#### エフェクトの活用
- キラキラマークを押すとエフェクト選択可能
- AI系、アニメ風など面白い機能
- ユーモアのある動画が撮れる

#### ショート動画 vs 横動画
- **ショート動画**: 縦型で50人登録者でライブ配信可能
- **横動画**: 「動画」を選択してスマホの写真フォルダから選択
- ショート用・横用に切り替え可能

### ショート動画の投稿
1. 「+」ボタン → 「ショート」を選択
2. 録画
3. 編集（文字追加、フィルター、BGM追加）
4. 次へ → 公開設定 → アップロード

### 横動画の投稿
1. 「+」ボタン → 「動画」を選択
2. 他のメディアを選択
3. 動画を選択 → 完了
4. 横動画として設定
5. タイトル入力 → 次へ
6. 視聴者層を選択 → アップロード

## 動画編集

### おすすめアプリ: CapCut（キャップカット）

#### 取得方法
- App Storeで「キャップカット」を検索
- インストールして開く

#### 商用利用について（2025年6月更新）
- **商用利用可能**
- TikTokと同じ会社運営
- TikTokショッピング動画にも使用可能
- YouTube投稿に使用してOK

### CapCutでの編集方法

#### 基本的な編集
1. 「新しいプロジェクト」を選択
2. 動画を追加
3. カット編集:
   - 編集ポイントで「分割」を押す
   - 不要な部分を選択して「削除」
4. 元に戻す：右上の戻るボタン

#### BGM追加
- 「音声を追加」を押す
- TikTok人気の音源など選択可能
- 宝石マーク = 有料プラン

#### テロップ追加
1. 「テキストを追加」を選択
2. テキストを入力
3. 位置を調整（タッチで移動）
4. 大きさを調整
5. コピーも可能

#### 保存方法
1. 「エクスポート」を押す
2. 1080pで保存
3. **注意**: 無料プランは1ヶ月2回まで
4. 完了後、「ダウンロード」ボタンを押す
5. カメラロールに保存

### その他の編集アプリ
- **スマホ**: CapCut（おすすめ）
- **パソコン**: Adobe Premiere Pro、Final Cut Pro（Mac）

### 画質設定（スマホカメラ）
1. 設定アプリを開く
2. 「カメラ」 → 「ビデオ撮影」
3. **推奨**: 4Kの24-60fps
4. **1080pとの違い**: 4Kの方が明らかに画質が良い
5. **FPSの注意**: フレームレートが高いとファイルが重くなる
6. パソコンのスペックに合わせて調整

## サムネイル作成

### なぜサムネイルが重要なのか
- **YouTubeの再生回数の7割**はサムネイルで決まる
- サムネイルで視聴者が興味を持つかどうかが重要
- 視聴者への興味関心を引く文字・画像が鍵

### サムネイル作成の基本: Canva

#### Canvaでの作成方法（パソコン）
1. 「YouTubeサムネイル」で検索
2. ジャンル別テンプレートを選択:
   - Vlog系
   - 商品紹介系
   - 旅系
   - ハウツー系
   - キャンプ系など

#### Canvaでの作成方法（スマホ）
1. 「デザインを作成」を選択
2. 「YouTubeサムネイル」で検索
3. ジャンルに合ったテンプレートを選ぶ
4. カスタマイズ

#### サムネイルの比率
- **縦:横 = 9:16**
- Canvaで選択できるサムネイルは全てこの比率

### より高品質なサムネイル: Adobe Photoshop
- **用途**: 本気で再生回数を伸ばしたい人向け
- **特徴**: 画像作成の品質が高い
- YouTubeで成功しているチャンネルの多くが使用

### サムネイルの作り方特集動画
- チャンネル「YouTube集客チャンネルプラス」で検索
- 「サムネイル」で動画を探すと完全解説がある

## 動画をアップロードする

### アップロード方法

#### パソコンの場合
1. YouTube Studioを開く
2. 右上の「作成」をクリック
3. 「動画をアップロード」
4. ファイルを選択

#### スマホの場合
1. YouTube Studioアプリを開く
2. 「コンテンツ」 → 「作成」
3. 動画を選択

### アップロード時の重要設定

#### 1. タイトル
- **重要性**: 高い（サムネイルとタイトルで興味を引く）
- **タイトルの前半**: 興味関心を引く言葉（クリック率が上がる）
- **例**: 「この1本で全てOK」→ キャッチコピー
- **キーワード**: 「YouTubeの始め方」→ メインテーマ
- **検索対策**: タイトルにキーワードを入れると検索結果に表示されやすくなる

#### 2. サムネイル
- 上級車向け機能が解放されていれば「サムネイルテスト」可能
- 2種類のサムネイルをテストして良い方を選択

#### 3. 概要欄（説明欄）
- **視聴者に宣伝したいこと**を掲載
- **自己紹介**も有効
- **検索対策**: 冒頭2-3行にキーワードを複数入れると検索結果に表示されやすくなる

#### 4. 再生リスト
- 「再生リストを作成」で新規作成可能
- タイトル・説明を入力
- チェックして動画を追加

#### 5. 子供向けの動画かどうか
- **完全に子供向け**: 「はい、子供向けです」
- **それ以外**: 「いいえ、子供向けではありません」（推奨）

### オプション設定

#### 1. 終了画面
- 動画の最後に別動画やチャンネル登録ボタンを表示
- 動画への導線作成に有効
- 時計マークでアイコンを表示
- 位置・タイミングを調整可能

#### 2. カード
- 動画の途中で関連動画や再生リストを表示
- 基本的には設定不要

### 公開設定

#### 公開オプション
1. **公開**: すぐに全世界に公開
2. **スケジュール**: 未来の日時に設定
   - **おすすめ時間帯**: 夕方18時〜夜20:30頃
   - 再生回数を集めやすい
3. **限定公開**: リンクを知っている人だけが見られる
4. **非公開**: 自分だけが見られる

#### スケジュール機能の活用
- 1週間後、1ヶ月後の投稿を設定可能
- 時間まで指定できる
- 週次の定時投稿に便利

### アップロード完了
- アップロード処理が完了すると公開される
- YouTube Studioで確認可能
- スマホでも確認・再生できる
