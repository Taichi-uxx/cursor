## 前提：個人チャンネル vs 法人チャンネル

| 観点 | 個人 | 法人 |
| --- | --- | --- |
| 目的 | 広告収益（再生回数連動） | 問い合わせ・成約 |
| 達成方法 | 多くの人にリーチ | **狙った層**にリーチ |
| コンテンツ | 幅広いジャンル・エンタメ系 | ノウハウ系 |

→ チャンネル設計が大きく異なる

## 20ステップ

### Step1: 目的を決める

**目的設定が大事な理由**
1. あらゆる意思決定の基準が明確になる
2. 工数・費用に対してコミットモチベが湧かなくなり継続困難になるため

**チャンネル作成目的例**
1. バックエンド商品の購入（商品・BtoB SaaS）
2. 人材採用
3. 案件受注
4. 知名度向上／ブランディング強化

→ **最終的には売上に繋がる目的**でやるのがオススメ

### Step2: ターゲットを決める

#### 目的 → ターゲット → 企画の例
| 目的 | ターゲット | 企画 |
| --- | --- | --- |
| 新卒入社の増加 | 就活生 | 面接通過ノウハウ |
| YouTube案件の受注数増加 | 経営者・WEB担当 | YouTube立ち上げ方法 |

### Step3: 目標を決める

#### 4つの主要指標
- **チャンネル登録者数** — バックエンド単価が低いほど目標値高く
- **再生数** — 同上
- **公式LINE登録数** — ターゲットに刺さっているかの指標
- **商品へのCV数** — CV増えた動画＝良質コンテンツ

#### 業種別目標感（1年後）

| 区分 | 特性 | 目標 |
| --- | --- | --- |
| **toB** | バックエンド単価高／経営者層／視聴者ボリューム少 | 登録者 **1,000〜3,000人** |
| **toC** | バックエンド単価低／ターゲット広／年間120〜180本投稿 | 登録者 **1〜3万人** |

> 企業チャンネルは**浅く広くではなく、狙ったターゲットに狭く深く刺す**

### Step4: 競合分析
- **「kamui tracker」が便利**
  - 攻めたいKWで検索
  - 同KWを扱うchを見つける
  - 全体方針・企画・クリエイティブを参考
- 競合chを**10〜20個洗い出し**
- 更新頻度・期間・現登録者・再生数を把握

### Step5: 強みを見つける

| 競合のタイプ | 差別化方向 |
| --- | --- |
| **個人** | 資金力・準備で差別化（更新頻度／ゲストの質／コンテンツの質／編集の質） |
| **法人** | コンテンツで差別化（有名人起用／属性近い大手とコラボ） |

### Step6: 演者を決める

| 演者 | メリット | デメリット |
| --- | --- | --- |
| **社長** | 演者退職リスクなし／話せるコンテンツの質が高い | 収録に時間が取られる |
| **社員** | 社内の雰囲気が伝わり採用に繋がる／社長の工数削減 | 辞める際にchが止まる可能性 |
| **外注** | 演者が辞めるリスクなし | 費用がかかる／熱量を持ってもらうのが難しい |

### Step7: 制作チームを作る

#### 募集方法

| 方法 | メリット | デメリット |
| --- | --- | --- |
| Twitter公募 | 圧倒的に安い | 制作初心者かつビジネスコミュ取れない場合多 |
| クラウドソーシング | 安い | 定着しない／品質低い／コミュコスト膨大 |
| **制作会社に外注** | コミュスムーズ／連絡途絶えない／納期遅延起きにくい | 費用高／土日対応難しい |

#### 社内の役割分担

**演者の役割**
1. 実際に動画に出演
2. 動画で話す内容を考案
3. 自身でしか繋げないゲストのアサイン
4. 完成した動画の最終確認

**YouTube担当者の役割**
1. 企画案作成
2. ゲストアサイン（SNSで呼べる方）
3. 完成動画の最終確認とサムネタイトル文言作成
4. 発注した編集ディレクターとの主なコミュニケーション

### Step8: 撮影スタジオの準備

#### 場所選定

| 場所 | メリット | デメリット |
| --- | --- | --- |
| レンタル撮影スペース | 機材揃ってる／購入より経済的 | 毎回借りる手間／移動／撮影時間オーバー不可 |
| 会社内のスペース | 演者移動なし／撮影時間短縮 | 機材事前準備が増える／**カメラと演者の間に3m弱必要** |

#### 必要機材
- グリーンバック／ガンマイク／カメラ／照明
- ピンマイク／三脚／ハンディレコーダー

### Step9: 企画を作る（VSEO意識）

#### KW洗い出しの3手順
1. **Googleキーワードプランナー** でKWを洗い出す
2. 出てきたKWを **Ubersuggest** にかけ、組み合わせKWを洗い出す
3. そのジャンルでGoogleトップのサイトへの流入KWを **Ahrefs** でピックアップ
- → **vidIQ** はYouTube検索特化なのでオススメ

#### 競合動画を参照する理由
1. 再生されやすい動画作りの参考
2. そもそも狙ってるKWがYouTubeと相性悪い可能性

#### 見るべきポイント
1. 動画映えするKWか
2. どういう構成か
3. どういうトピックが扱われているか
4. **登録者数に対する再生数が多いか**（100万人登録で1万再生 < 1,000人登録で1万再生）

### Step10: キャスティングを行う

#### 企画の3種類

| タイプ | 特徴 |
| --- | --- |
| **1人語り** | 演者にファンつきやすい／量産可能／演者側の準備が一定以上必要 |
| **対談** | 話が盛り上がり厚みある／司会にファンつきにくい／キャスティング工数 |
| **ロケ** | 動画映え／カメラマン・演者の移動で工数増／撮影本数担保しにくい |

→ **対談企画は事前準備ほとんど無くても成立、月10本など量を投稿するチャンネルに効果的**

#### キャスティングのパターン
1. クライアント側のつながりを使う（立ち上げから数回程度）
2. **SNSで募集**（テーマの単語をTwitterで検索→DM）

### Step11: 台本を作る

#### 骨子（台本）に必要な5要素
1. 導入OPセリフ
2. 本編テーマ
3. 本編のトピック
4. トピックで話す内容
5. 締めのセリフ

#### 維持率を高める4要素
1. **権威性**（例：「業界歴〇年の中で経験したことをもとにお話していきます」）
2. **悩みの代弁**（例：「皆様も〜といった思いをしたことがあると思います」）
3. **見ないことによる損失**（例：「この動画を見ないことで〇〇という事態になりかねません」）
4. **視聴の訴求**（例：「ぜひ最後までご視聴ください」）

→ 骨子（箇条書き程度）がオススメ。前提知識ある方を司会にする方が長期運用しやすい

### Step12: 撮影をする

#### 撮影頻度・本数目安
- 時間: **3時間/回**
- 本数: **6〜10本/回**
- 頻度: **2回/月**
- 慣れたら1本20分で、3時間で約9本収録可能

#### 撮影スタイル比較

| スタイル | メリット | デメリット |
| --- | --- | --- |
| スタジオ撮影 | 1収録あたり工数少／多数の動画作成可 | 大バズりはしにくい |
| ロケ撮影 | 手の込んだ企画／バズコンテンツ生み出せる可能性高 | 工数が膨大 |

→ **スタジオで量、ロケでバズ用を作る**バランス戦略が基本

#### よくある撮影ミス
- カメラのボタン押し忘れ
- 台本の見過ぎ
- 手ブレ機能忘れ
- ピンマイクが衣服に擦れて雑音
- グリーンバックに影
- SDカードが4K非対応

#### 撮影時に取るべきメモ
- 動画の演出に関しての注文（分数と共に）
- 動画自体の元の長さ
- 映像番号と音声番号
- ゲストの名前と顔隠し・変声などの詳細設定

### Step13: チャンネル・企画のクリエイティブ制作

#### メイン9つのクリエイティブ
1. 通常字幕
2. 特殊テロップ
3. 上部テロップ
4. ツッコミテロップ
5. BGM（無料サイト使用）
6. 背景画像（グリーンバック背景時に必要）
7. SE（無料サイト使用）
8. オープニング（最近はOPの代わりにダイジェストを入れるchが多い）
9. エンディング（動画の回遊に使用）

→ 全素材作ってから振り分けると遅くなる。**重要素材を先に決め、残りは編集途中で**

### Step14: 編集者振り分け＆ディレクション

#### 完成までのフロー
1. **振り分け** — GoogleDrive・ギガファイル便・Dropboxで素材渡し
2. **編集** — 初め1分間編集したものを見て品質方針すり合わせ
3. **チェック** — セリフ字幕タイミング／音量／誤字脱字／程よい演出／邪魔しないSE

→ **10分弱の動画で初稿8〜12時間／修正1〜2往復／完成まで5〜6日**が目安

### Step15: サムネタイトル作成

#### 良いサムネの特徴
- 動画内テーマで最も重要なワードはサムネ内に含める
- **文言数13文字以内**（多くても20文字）
- 文章は**2行まで**（多くても3行）
- サムネとタイトルは別々のメッセージを含ませる
- **色はモノトーン除いて2色まで**
- 背景と同系色は文字に使用しない
- チャンネルのテーマカラーで縁取り
- **座布団**（ペーストを敷いた縁取り）で文字を見やすく＝高級感

### Step16: チャンネルを立ち上げる

#### チャンネルアイコン

| パターン | 内容 |
| --- | --- |
| 通常 | 演者の顔が望ましい |
| 属人性を排除したい場合 | 文字・イラストで作成（例: 年収チャンネル） |

#### チャンネル概要欄に入れる要素
- 登録誘導文章リンク
- バックエンドにCVさせる用の文章
- 演者の自己紹介文章
- ハッシュタグ
- 動画の説明
- 動画の目次
- 同じch内のおすすめ動画

#### その他必要な設定
- ホーム画面をリッチに
- 右下に登録者訴求用のうっすらロゴを常に表示
- チャンネルの通貨表示を**日本円**に設定
- チャンネル説明欄にも動画の概要欄と同じ文章を挿入
- HP・SNSと関連付けてチャンネルから飛べる
- 電話番号登録でサムネ自由設定
- 広告収益化条件で通知設定

### Step17: 動画公開時の注意点

- 別の動画をアップしていないか確認
- 動画ED部分にチャンネル登録とおすすめ動画の設定
- 動画ごとのタグ・ハッシュタグを追加
- 公開予約前に**「限定公開」**にしておくとミスが減る
- 概要欄の目次・ゲストSNSリンク漏れチェック

→ **公開時間は18〜21時／日曜の夜投稿がオススメ**

### Step18: 上がった動画の分析

#### 評価指標と目標値

| 指標 | 目標 | 改善ポイント |
| --- | --- | --- |
| サムネのクリック率 | **9%以上**（1日後） | 公開後1時間で順位悪ければサムネ/タイトル変更 |
| 視聴者維持率 | **40%以上**（10分程度） | 離脱ポイント確認→余計なセリフカット |
| チャンネル登録率 | **1.5%以上**（登録者1,000人まで） | コンテンツ・演者の種類でch統一感 |

→ 最低でも月1回データを振り返る

### Step19: データに基づき次の企画に反映

| 動画タイプ | 役割 | 注意 |
| --- | --- | --- |
| **再生数の多い動画** | リーチ拡大・ch全体パワー上げ | 演者の権威性に繋がり採用効果も |
| **登録率の高い動画** | ファンを増やす | 対談より**1人語り動画の方が登録率高い傾向** |
| **CVに繋がる動画** | 売上貢献 | 視聴者が辟易しないよう間隔を開けて更新 |

### Step20: PDCAを繰り返す
撮影 → 公開 → データ分析 → 企画に反映 → 撮影 …

## スケジュール（3日に1本ペース）

| Step | 内容 |
| --- | --- |
| 1 | 企画会議で次回撮影10本詳細＋次々回10本アタリ |
| 2 | 2週間で次回撮影の企画詳細・骨子を演者考案 |
| 3 | 3時間撮影で5〜10本撮影し振り分け |
| 4 | 1週間〜10日で動画完成（誤字等の単純ミス0に） |
| 5 | 2日以内にYouTube担当者で確認・修正点洗い出し |
| 6 | 修正点を制作チームが2日以内に修正 |
| 7 | 公開（最終的に撮影から10〜14日程度） |

## 業務範囲・工数

### 演者
- 月1〜2回の企画会議: **1時間×2 = 2時間**
- 月2回の出演: **3時間×2 = 6時間**
- 月10本の動画テーマ詳細決め: **30分×10 = 5時間**

### 企画担当者
1. 企画テーマ考案
2. 最終動画確認
3. キャスティング
4. サムネ・タイトル文言作成
5. カメラマンのアサイン
6. YouTubeディレクターのアサイン
7. 公開動画のPDCA
8. チャンネル数値担保

### ディレクター
1. 編集者への振り分け
2. 動画の品質担保
3. 動画の工程管理
4. 企画担当者が行う業務のたたきを作成

## 最後に
- チャンネルが伸びるのは**最短でも半年間以降**のイメージ
- 内製化は**優秀なYouTubeディレクター**を見つけるのが鍵
- 企業のYouTube担当者にディレクタースキルを落とし込むのは非効率 → **内製化しても企画担当までがオススメ**

## So What（戦略家としての示唆）

### 数字で覚えるBenchmark
- toB目標: 1年後**登録者1,000-3,000人**
- toC目標: 1年後**登録者1-3万人**（年間120-180本）
- サムネCTR: **9%以上**（1日後）
- 維持率: **40%以上**（10分動画）
- 登録率: **1.5%以上**（登録者1,000人まで）
- サムネ文字: **13文字以内**
- 10分動画の編集: **8-12時間**で初稿、5-6日で完成

### スケジュール骨格
- **3時間×6-10本×月2回**が撮影標準
- 撮影から公開まで**10-14日**
- 動画が伸びるのは**半年以降**

### 戦略系
- 個人と法人でYouTube戦略は**全く違う**（広告収益vs問い合わせ／広くvs狭く深く）
- 内製化のボトルネックは**ディレクター**。社内で兼任は非効率
- **スタジオで量／ロケでバズ**のバランス戦略
- **「対談企画は事前準備少なく成立」**は月10本量産に効く

### 工具系
- 競合分析: **kamui tracker**
- KW: **キーワードプランナー × Ubersuggest × Ahrefs × vidIQ**
