## Part1: なぜ今YouTubeか

### YouTube市場規模
- **Googleに次いで世界で2番目に訪問されたメディア**（Top 50 Websites調査）
- → 1企業につき1動画メディアを持つ可能性

### SNS利用率（令和3年情報通信メディア調査）
| 媒体 | 全年代 | 10代 | 20代 | 30代 | 40代 | 50代 | 60代 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| LINE | 92.5% | 92.2% | 98.1% | 96.0% | 96.6% | 90.2% | 82.6% |
| **YouTube** | **87.9%** | 97.2% | 97.7% | 96.8% | 93.2% | 82.5% | 67.0% |
| Instagram | 48.5% | 72.3% | 78.6% | 57.1% | 50.3% | 38.7% | 13.4% |
| Twitter | 46.2% | 67.4% | 78.6% | 57.9% | 44.8% | 34.3% | 14.1% |
| Facebook | 32.6% | 13.5% | 35.3% | 45.7% | 41.4% | 31.0% | 19.9% |
| TikTok | 25.1% | 62.4% | 46.5% | 23.5% | 18.8% | 15.2% | 8.7% |

> YouTubeは若者だけのメディアではない／全年代で前年比+2.7%上昇

### 情報量
- **1分間動画 = 一般的なWEBページ × 3,600ページ分**
- 視覚（映像）×聴覚（声/音楽）×言語（テロップ/セリフ）の3情報を一度に届けられる

### 3H戦略（Google提唱）

| 動画タイプ | ファネル位置 |
| --- | --- |
| HERO動画 | 認知 |
| HUB動画 | 興味・関心／比較検討 |
| HELP動画 | 比較検討／行動 |

> 認知〜行動までを**チャンネル内で一気通貫**で完了できる

- 目的: 新規顧客獲得 / 採用 / 既存顧客フォロー → **1つに絞る**
- 対象: 年代・性別・属性
- 強み: 何が強みか
- **「認知向上」をただ目的にすると上手くいかない**
- **「あれもこれも」はNG**

## Part3: 具体的なチャンネルグロース戦略

### YouTubeのコンテンツ拡散の流れ
> YouTubeは視聴者の興味関心を把握し、それに沿って適切なコンテンツを視聴者毎にレコメンドする

- このチャンネルの視聴者が見ている他のチャンネル
- 視聴者が再生した他の動画
- → 視聴者の**視聴履歴**に重点を置いて判断

### 初期構築の流入設計（3経路）

| 経路 | 特性 |
| --- | --- |
| **検索流入** | KW検索の結果。**初期でも上位表示可能性あり**。属性コントロールしやすい |
| ブラウジング | ホーム画面に表示。視聴履歴・検索履歴から自動判断。**拡散性高いが初期は狙いにくい** |
| 関連動画 | 視聴中動画のサイドバー/下部表示。回遊や他chからの流入確保。**初動は確保しにくい** |

> 初期は**検索流入でユーザー属性をばらけさせず、同一属性の流入を確保** → 属性固まったら量の取れるブラウジング/関連を意識

### YouTube SEO の基本3項目

#### タイトル
- 上位表示を狙うKWをタイトルに含める
- 関連KWも含める
- 狙いたいKWは**タイトル左側**に
- **30文字前後**で設定

#### 概要欄
- 上位狙いKWを概要欄に盛り込む
- ハッシュタグを設定（**つけすぎ NG。3つくらい**）
- タイムスタンプを設定

#### 内部施策
- メタタグに狙いたいKWを入れる
- 重要なKWほど**序盤に設定**
- 関連KWをカバー
- 動画のキャプションテキストを入れる

### KW選定の2軸

#### 軸となるKW
- 流入獲得のメインKW
- 例: 「ダイエット」のように検索ボリュームが大きいもの
- チャンネルコンセプトに合わせて、同属性ユーザーが集まるKWを複数選定
- ダイエット系なら：筋トレ・痩せる等

#### 関連KW
- 軸KWと関連するKW
- 「ダイエット 方法」「ダイエット 食事」等の掛け合わせ
- ロングテール含めれば膨大 → ある程度のボリュームで足切り
- **企画考案の軸**になる

### タイトル付け4ルール

1. **軸となるKWをタイトルの左側に**
2. **視聴者の興味を引くワード**（【】で囲って視認性UP・冒頭に置く）
3. **30文字程度に収める**（32文字以上では全文表示されない）
4. **関連KWまで記載**（「軸×関連」の検索でも上位表示）

#### 例
- 【2021年版】本当に買って良かったもの4選｜vol.868
- 【最新版】隠れ優良企業ランキングTOP8(後編)｜vol.905
- 【放送事故】ホリエモンにガチギレされた回の裏話を暴露｜vol.281

### 引きが良いワード集（一例）
- 〇分でわかる／〇選／完全版／最新版
- 放送事故／閲覧注意／まさかの結果に
- ガチギレ／腹筋崩壊／削除覚悟／過激／大公開
- 暴露／リアル／驚愕／実は〜だった／裏事情／もしも〜

### 概要欄の設定詳細

#### KWの記載
- 冒頭50文字を目安に、軸KW・関連KWを複数盛り込む
- 関係ないKWを無理やり含めるのはNG
- CTR向上目的の興味引きKWの必要性は低い（視聴前に概要欄を見ない）

#### ハッシュタグ
- そのKWでの検索上位表示も可能
- 視聴者がタグクリック → そのタグを含む他動画一覧表示 → 他ch流入/回遊率向上
- **1動画15個以上で全て無効化**される → 必要なものに絞る

#### タイムスタンプ
- 例: `00:00 opening / 01:23 ダイエットの失敗例 / 03:45 おすすめダイエット方法`
- 視聴者が長く動画に留まる可能性UP

### メタタグ・キャプション

#### メタタグ
- 視聴者からは見えない、動画内容をYouTubeに伝えるタグ
- **500文字まで設定可能**
- 重要なKWほど序盤、その後関連KW
- 関連しないKW・禁止KWは設定しない

#### キャプション
- YouTubeは自動で字幕起こしするが**結構アバウト**
- より正確に伝えるため**キャプションテキストを設定**（テロップとは別）
- 軸KWや関連KWが動画前半に、かつ全体を通して複数回登場するのが良い
- 台本にてコントロールする必要あり

### 評価の高い動画を作る

#### 評価のループ
```
①既存視聴者にレコメンド
②既存視聴者からフィードバック
③未視聴者にレコメンド
④未視聴者からフィードバック
```

#### 重要指標①: 初日CTR

> 平均CTRよりも**初日CTR**を重視する

- 全期間CTRとIMP数には相関なし（IMP拡大で徐々にターゲット属性から離れた視聴者にもリーチするため）
- **公開後初日のCTR 10%以上を目標**

#### CTR向上6ポイント
1. サムネテキストの色を**3〜4色に収める**
2. サムネテキスト文字数は**20文字以内**
3. **一番見せたいものは文字で隠さない**
4. **タイトルと同じ文言を採用しない**（限られた視聴前訴求の無駄使い）
5. テキストの大きさにメリハリ（スマホで見えるか意識）
6. サムネの中で**「一番伝えたいこと」を決める**

#### 重要指標②: 視聴維持率

##### 基準値（年収チャンネル基準）
| 動画長さ | 維持率の目安 |
| --- | --- |
| 10分以上 | **42%以上** |
| 7〜10分 | 50%以上 |
| 4〜7分 | 57%以上 |
| 4分以下 | 62%以上 |

##### 維持率向上テクニック
1. **ユーザーが見たい箇所を最後部に持っていく**（サムネに記載した内容・盛り上がる部分・結論を後半に）
2. **間をできるだけカット**（ジェットカット）
3. **全ての発言をテロップに**
4. **小まめにSEを入れる・場面転換**（HIKAKIN TVは3秒に1回SEが入っているとも）

## Part4: チャンネル立ち上げまでの検討フロー

| Step | 内容 |
| --- | --- |
| ① 目的の明確化 | 売上向上？採用？売上なら新規？既存？「あれもこれも」NG |
| ② ターゲット設定 | 年齢・性別・ライフスタイルを明確に。「たくさんの人に」は失敗 → 「あなたのための動画」 |
| ③ ニーズの洗い出し | ターゲットの悩み・興味を**周辺領域含めて**洗い出し。検索KW／競合動画／Google検索結果から |
| ④ コンセプト/企画設計 | 3H視点で各動画に役割を持たせる。「とりあえず動画を作る」はNG |
| ⑤ KPI/KGI設計 | 「登録者数」「視聴回数」だけにフォーカスしない。目的達成に繋がっているか確認できる指標 |

### チャンネルグロース手段の比較

| 手段 | メリット | デメリット |
| --- | --- | --- |
| **通常動画** | ターゲットコントロールしやすい／訴求力強／資産性高 | 伸びるまで時間／運営手間 |
| **YouTube広告** | 短期で成果／配信手法多／クリエイティブテストが高速 | 広告費／資産性なし／ターゲットコントロールしにくい |
| **コラボ** | 短期認知UP／コラボ先の信頼性を借りられる | コラボ費高額／ターゲットコントロール難 |
| **Shorts** | 伸びが早い／運営手軽 | 教育に繋がりにくい／ターゲットが広がりすぎる |
| **外部施策** | アルゴリズム依存にならない | グロース速度が外部依存 |

## So What（戦略家としての示唆）

### データ系
- **「YouTube全年代87.9%利用」**は年配層含むtoB提案でも使える
- **「1分動画=Webページ3,600ページ分」**の情報量比較は説明強い
- **「初日CTR 10%以上が目標」**は具体的Benchmark

### 設計系
- **3H戦略（HERO/HUB/HELP）**は提案フレームとして必ず使える
- **マネタイズの段階設計**（広告→案件→スポンサー→サロン→アフィリ→マッチング）は年収チャンネルから抽出した黄金パターン
- 「初期は検索流入で属性を固める → 量の取れるブラウジング/関連にスケール」が**戦略テンプレ**

### SEO実装系
- **ハッシュタグ15個以上で全無効化**は意外と知らない実装Tips
- **メタタグ500文字／重要KW序盤** はLステップ/Linyのタグ命名規則と同じ発想
- **キャプションテキストはYouTubeの自動字幕より精度高い** → 台本で軸KWを動画前半に複数回登場させる
