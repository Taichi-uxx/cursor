# これすれば登録解除を減らし、逆に登録者を増やすことができます【YouTubeアナリティクス分析手法】

## 詳細
https://youtu.be/zBzXEE2wmu4

## 概要

長く運営しているチャンネルほど、登録解除は起きる宿命。発信者のチャンネルは登録者7万人に対して3万人以上が解除済み。気にしすぎないことが前提だが、**どの動画から最も解除が起きているか**は分析する価値がある。YouTube Studioのアナリティクスで「拒絶反応の割合」と「解除率」を計算する具体手順、それを使って出すべき動画／出さない方が良い動画を切り分ける方法、ファン化と再生回数のトレードオフをどう設計するか、新規視聴者向け動画こそ登録者を増やす本命であるという結論まで踏み込んだ実践的な分析手法。

## 大前提：登録解除は宿命、気にしすぎなくていい

### 数字の前提
- 発信者のチャンネル：登録者7万人＋、登録解除3万人＋
- 解除は寂しい現象だが、長く運営してきた以上避けられない

### なぜ解除は必ず起きるか
- 3年以上動画を出していれば、最初の頃の視聴者の多くはそもそもYouTubeを離れている
- 継続投稿していれば「もう見ないかな」という人には登録欄でうっとうしく感じられて解除される
- 動画を出し続けるチャンネルにとっては避けられない

### 投稿は止めない・頻度は落とさない
- 今いる視聴者を大切にし、新しい視聴者と出会うために動画は出し続ける
- 解除を気にして頻度を落とすのは間違い

## ただし「どの動画で解除が起きているか」は分析する

### 解除を見る視点
- 登録解除は「このチャンネルの動画をもう見ない」という意思表示
- 動画単体ではなく**チャンネル全体への評価が下がった**と読むのが自然
- 1本2本見てもらえなくなったこと以上に重要なシグナル

### 分析の目的
- 自分のチャンネルの成長速度を最も落としている動画 = **出さない方がいい動画**を特定する
- 出すべき動画だけを出せば、登録解除が減り、登録者数が積み重なる

## YouTube Studio 解除分析の具体手順

### Step1：解除数の多い動画を特定する
1. YouTube Studio → アナリティクス
2. 真ん中のグラフの「詳細」ボタン
3. 左上の期間を「全期間」に
4. 内訳：コンテンツ（デフォルト）
5. 指標を開く：
   - 概要：**視聴回数**＋**チャンネル登録者**にチェック、他は外す
   - リーチ：全部外す
   - 交流：**登録者減少数**にチェック
6. 適用ボタン → 解除数の多い動画ランキングが出る

### Step2：エクスポートして2つの指標を計算する
1. 右上のエクスポートボタン
2. スプレッドシートで以下を計算

#### 拒絶反応の割合（再生回数あたりの解除）
```
拒絶反応 = チャンネル登録解除 × 100 ÷ その動画の再生回数
```
→ 自分のチャンネル内で「拒絶している視聴者の割合」が多い動画を特定

#### 解除率（登録者あたりの解除＝新陳代謝）
```
解除率 = チャンネル登録解除 × 100 ÷ チャンネル登録者数
```
→ どれだけ既存ファンが離れ、一方で新規をどれだけ獲得しているかの新陳代謝

## 分析結果の読み解き方（事例）

### 拒絶反応が高い動画 = ノウハウと関係ない動画
- 発信者の場合：個人的な思いを語る動画／演者個人を語る動画
- 視聴回数あたりの解除が多い
- 「ファン化を進める動画」だが、合わない層には拒絶される

### 拒絶反応が低い動画 = ノウハウ／役立つ解説
- このチャンネルではノウハウ解説を軸にすると拒絶反応が小さい

### 解除率が高い動画
- 思いを語った動画／少しネガティブなテーマ／演者以外が出る動画

### 解除率が低い優秀な動画
- ニュース系、ノウハウ解説系
- 例：再生10万回超で解約率1.6%
- 既存が離れる以上に**新規登録がはるかに多い**＝右肩上がりの動画

## 分析結果を使った運用方針

### 拒絶反応が高い動画も止めない判断もあり
- 拒絶反応が高くても、それが「ファン化を進める役割」の動画ならむしろ続ける
- 一部の視聴者に拒絶されても、多くの視聴者の心に響く動画には価値がある
- 思いの込もった動画、人生の重みを増す動画は出すべき

> AIが台頭してきている以上、人間味を削ぎ落としたチャンネルほど生き残るのが難しくなっている。そこに希少価値が生まれ、結果的に今後はそれが登録者を増やす側面もある。

### 解除率が低く登録者が多い動画を増やす
- 例：登録者3360人獲得・解除53人の動画
- 離れる人が少なく、評価する人が圧倒的に多い「素晴らしい動画」
- このパターンをチャンネルで量産できれば右肩上がり

### 方向性は2択（どちらでも可）
1. **AI最適化路線**：効率重視で量産・最適化
2. **人間味・ファン化路線**：1再生あたりの重みを上げる

→ どちらを取るにせよ、解除分析でヒントを掴むことは必須

## 重要な気づき：登録者を増やすのは「新規向け動画」

### 多くの人が抜け落ちている発想
- 「リピーター向けの動画が登録者を増やす」と思いがちだが、実は逆
- 登録する人の多くは新規視聴者
- 新規視聴者がその動画を見たメリットが大きいほど登録される

### 新規向けに効く設計
- サムネ閲覧時の当初の期待を**超える**メリットを提供
- 思いを語る動画は新規にとってはピンと来ない
- 「YouTubeこうやって伸ばせるよ」というノウハウ動画は新規メリットが大きく登録される

### 計測のコツ
- 動画再生回数を**新規視聴者とリピーターで分けて分析する**
- これを分けて見ている人がほとんどいない
- 登録者を増やしたいなら新規向け動画に焦点を当てる

### 二本立て運用
- 新規向け動画 = 登録者を増やすブースト
- リピーター向け動画 = 既存ファンを維持・深化
- 両方を計画的に組み込む
