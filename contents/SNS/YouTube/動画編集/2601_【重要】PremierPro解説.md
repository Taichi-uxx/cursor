### ワークスペース最低限

## プロジェクト・シーケンス作成

### プロジェクト命名
- 「日付＋動画タイトル」が推奨
- **1案件＝1プロジェクト**（新しい部屋に入る感覚）

### シーケンス作成
- 「新規項目 → シーケンス」
- **標準設定：1080P / 29.97 FPS**
- **横（16:9）**：デフォルト1920×1080
- **縦（ショート）**：フレームサイズを1080×1920に変更
  - ショートはワークスペースを縦長に持っていくのがおすすめ

## 素材読み込み

- プロジェクトパネル選択後 `Cmd+I`（ショートカット推奨）
- 画像はショートカット、BGM/SEはドラック&ドロップも可
- **フォルダ整理**：Premiere内では「フォルダ」ではなく「ビン（新規ビン）」と呼ぶ
- フォルダごと読み込みも可能

## タイムライン基礎

- グレーの太い線から上＝映像トラック（V1・V2・V3…）
- グレーの下＝オーディオトラック
- **数字が大きいほど上のレイヤー**（表示優先）

### アイコン機能

| アイコン | 機能 | 使い所 |
|---|---|---|
| **ロック** | クリップ動かなくする | 動かしたくない素材の保護 |
| **目玉** | トラック表示ON/OFF | 下レイヤーの見え確認 |
| **M（ミュート）** | 音を消す | オーディオトラック用 |
| **S（ソロ）** | そのトラックだけ再生 | 特定トラックの音チェック |
| **スナップイン** | クリップを吸着 | ぴったり配置に必須（基本ON） |
| **リンク選択** | 映像＋音声を一括選択 | メイン素材ではON、片方消したい時はOFF |
| **マーカー** | しおり | 場面メモを残せる |

## カット作業

### 表示最適化（時短の要）
- オーディオトラックの下を伸ばして**波形を縦長表示**
- タイムライン下部のスクロールレバーを右に持って**横方向も最大伸長**
- こうして波形が最大に見える状態でカットする

### カット操作
- **レーザーツール**でクリップ分割
- 選択ツールに戻して削除

### 効率化ショートカット
- タイムラインのトラックにカーソル → **Alt/Option + マウスホイール**で縦方向拡大
- タイムラインエリア → **Alt/Option + マウスホイール**で横方向拡大
- 頻用するので必須で覚える

## 色補正

### 前提
- **調整レイヤー**を使う（映像クリップに直接適用すると処理が重くなる）
- 調整レイヤーはビン→新規項目→調整レイヤーで作成
- 調整レイヤーの下にあるクリップ全てにエフェクトが適用される

### ルメトリーカラーで補正
- **「自動」ボタン**でベース補正（映像に合わせて綺麗に補正）
- そこから微調整（明るさ・彩度・カラー）
- 演出用途：
  - 彩度を下げる → ショック感／暗い雰囲気
  - 青みを増やす → 寒いイメージ
  - 黄みを増やす → 温かみ

## テロップ

### 基本操作
- 横向き文字ツール（初期ショートカット：`Cmd+T`）
- モニターをクリックして入力

### セーフマージン必須
- 下ボタン「+」→ セーフマージンをドラッグ&ドロップ
- **どのデバイスでも見切れない領域**
- テロップは絶対にこの内側に配置

### プロパティで表示調整
- **中央揃え**
- **下揃え**（下1テロップの場合。上揃えだと開業した際にはみ出す）
- 中央テロップは中央揃え
- 位置合わせは**水平方向中央揃え**ボタンで一発

### ターゲットトラック活用
- V3にテロップトラックを作った時、V3にターゲット固定
- メニュー → 「再生ヘッドの位置を自動」にチェック
- 再生ヘッドが動いてもV3が選択状態を維持 → カット位置に手間なく編集点追加できる

### 見やすい文字設定
- おすすめフォント：**源の明朝／源の角ゴシック**（太さ「Heavy」推奨）
- アピアランス：**ストローク（境界線）**
  - 白服＋白テロップなら黒境界線
  - 太さ：太すぎず細すぎず、7〜8程度
  - **10以上は境界線同士が被るので12未満推奨**
  - 位置：**外側**が最も太く見せられる
- **シャドウ**で立体感、**背景**で強調

### テキストスタイル保存・使い回し
- リンクスタイル → **スタイルを作成 → プロジェクトに保存**
- 他プロジェクトへの共有：**リンクスタイル書き出し**
- **スタイルブラウザ**でスタイル一覧表示可能

### テロップアニメーション
- **エフェクトコントロール**で位置・スケール・回転を調整
- **ベクトルモーション**＝クリップ全体
- **キーフレーム打ち**で動きを作る（開始点と終点で位置を変えるだけ）
- パラメーターリセットボタンで初期値に戻せる

## 音声調整（数字基準）

### 音量推奨値

| 種類 | 目安 |
|---|---|
| **声（メイン音声）** | -6dB |
| **BGM** | -25〜-30dB |
| **SE（効果音）** | -12〜-18dB |

### 音声設定手順（オーディオトラックミキサー）
1. トラックミキサーの左上「エフェクトと鮮度の表示」を開く
2. ドロップダウン→**振幅と圧縮 → ダイナミック**
3. ダイナミックをダブルクリック
4. **リミッターON**（-6dB以上に音量が上がらないように制限）
5. **コンプレッサーON**（補正で音量を上げる）
6. 上げすぎるとリミッターがチカチカ → 制限がかかっている証拠

### SE音量調整
- ダイナミックで調整すると反響音のようになる
- **右クリック → オーディオゲイン → 全てのピークをノーマライズ → -18程度**

### BGMを動画尺に合わせる
- BGMが動画より短い時 → **リミックスツール**
- クリップの最後を伸ばすとPremiere側で自動繋ぎ
- 10分程度なら綺麗にリミックス可能

## 最終チェック

### 時間を置く
- 完成→即書き出しではなく**10〜20分クールダウン**
- チェック漏れ防止

### 特に注意すべき2点
- **誤字脱字漏れ**
- **クリップズレ**（1フレームのズレは目視で気づきにくい。再生すると気づく）

## 書き出し

### ショートカット
- `Cmd+M`（Mac）／ `Ctrl+M`（Win）

### 設定
- **ファイル名**：動画名
- **保存先**：事前に作った書き出しフォルダ
- **プリセット**：
  - 通常YouTube → **YouTube 1080P Full HD**
  - **ショート → 必ず「アダプティブビットレート 高」**（フルHDのままだと横で書き出される）

## クライアント共有

- **ギガファイル便**が一般的
- **保存期間を必ず100日に設定**（アップロード後は変更不可、間違えたら再アップロード）

## 田村的示唆（What I Learned）

- **数字基準がすべて具体的なので、そのままSOP化できる** — 音量-6/-25/-12 dB、オートセーブ15〜30分、カット尺、フォントHeavyなど。編集者への発注時の"最低基準表"としてそのまま提示可能
- **「1案件＝1プロジェクト（新しい部屋）」の考え方** — 広告運用でも同じ。「1施策＝1シート」「1クライアント＝1ダッシュボード」など、混ぜないルールが仕事の質を保つ
- **調整レイヤー原則は"重い処理を集約する"思想** — 分析業務でも「元データに直接触らず、加工層を挟む」原則と同じ
- **リンクスタイル保存＝資産化** — スタイルを毎回作り直さず保存して使い回すのは、ドキュメントテンプレ運用と同じ。この原則を自身の広告バナー・LPコピーテンプレにも徹底
- **書き出し後の10〜20分クールダウン** — チェック漏れ防止の"時間を置く"は、レポート提出前・提案書送信前にも使える普遍的な習慣
- **ショート専用プリセット「アダプティブビットレート 高」** — 発信で縦動画を作る際の必須知識
- **他の解説動画（[[2507_プロの動画編集風景まるごと解説_高取]]）との補完関係** — かさんは「操作手順」、高取氏は「編集思想」を体系化。両方セットで完成度が上がる
