# 【大規模】過去最悪レベルの収益化停止...。まずいことが起きています。

## 詳細
https://youtu.be/Jb9hCVvJUgc

## 概要

2026年1月以降、YouTubeで過去最悪レベルの収益化停止祭りが発生している。AIスロップ（AIによる大量生成コンテンツ）への締め付けが本格化し、ショート系・AI架空世界系・2ちゃんねる系・雑学系・動物系・ゆっくり解説系・顔出しなし考察系・ゲーム解説系・雑談系・朗読・地理ショート系など、極めて幅広いジャンルで収益化が停止されている。本動画では「停止されているチャンネルの共通点」「予防のための4つの対策」「収益化停止後の復活手順」「AIスロップでなくとも停止された事例から学ぶ価値設計」を解説。視聴者目線で価値ある動画を作ることが、収益化維持と再生数増加の両方を実現する最も本質的な対策。

## 収益化停止の現状

### 大規模な停止が起きているジャンル
- ショート系
- AIによる架空世界系
- 2ちゃんねる系
- 雑学系
- 動物系
- ゆっくり解説系
- 顔出しなしの反応・考察系
- 通常動画のゲーム解説
- 雑談系
- 朗読
- 地理のショート系
- AIによる人の顔を入れ替えた系

### YouTube側の本気度
- 残す動画と残さない動画を分けようとしている動き
- 残るチャンネルになる対策をしないと、いつ停止されるか分からない状態

## 停止されているチャンネルの共通点

### 共通点1: ゆっくり機械音声／AIによる人工音声
- 9割くらいのチャンネルが該当
- ゆっくり系の停止は数年前から続いていた現象
- ただし**今回はAIスロップが大量に停止されている**点が新しい

### AIスロップとは
- AIを使って量産されたコンテンツ
- 人間が考えた独自の価値がほとんどない、中身がスカスカなコンテンツ
- 構成要素: AI音声 / 自動生成テキスト / AIが作ったフリー素材 の組み合わせ
- 1日3〜4本のペースで対応に出されているチャンネルが該当

### YouTubeの公式方針
- AIスロップを減らしていく
- 対策として収益化剥奪を強化する

## 重要な誤解: AIを使うこと自体は禁止されていない

### 事実関係
- Veo3などのAI動画サービスはGoogle（YouTube運営元）がリリース
- 公式もAIで動画を作りやすくしたと発信
- **AI使用そのものは禁止ではない**

### 本当に禁止されているもの
- **AIに丸投げした大量動画生成**
- 質より量で大量生成された中身の薄い動画
- 他人のチャンネルをコピーして同じサムネ・内容でアップする悪質ケースも含む

### 菅野氏の考察
- YouTubeは「コピペしやすい領域」を先回りで潰している
- これから穴を見つけてコピペ運用しても、短期間で潰される

## 予防対策（4つ）

### 対策1: 動画に「生の人間の声」を入れる
- これだけで収益化停止リスクが大幅に下がる
- 収益化判定はYouTubeのアルゴリズムが自動で行う
- 判定材料は映像と音声
- **人間の声はその時点でかなり免れる確率が上がる**

### 対策2: 映像で「人間の手作り」を伝える
- アニメ映像の大部分流用、コンテンツ流用、AI出力映像の大部分使用は停止対象になりやすい
- どこかしらに人が介在する映像を入れる
- 画面に手作りの証拠を残す

### 対策3: AIによる大量生成をしない
- 効率化目的での部分的AI使用はOK
- 1日3〜4本量産のような運用は完全NG

### 対策4: 視聴者に求められる価値を「人間が」考えて作る
- AIで効率化しても、価値設計は運営者が担う
- ここがあれば収益化停止リスクは下がる
- 同時に再生数も伸ばせる

## 裏話: AIスロップでなくても停止される事例

### 事例1: 動物系（猫ちゃん）チャンネル
- 撮影は実物の猫
- それでも停止されている
- 視聴者目線の価値設計ではなく「自分目線で可愛さを撮っている」状態だった可能性

### 事例2: 顔出しあり雑談系
- 顔出しありで停止されるのは数として少ない（全体の中で稀）
- このケースは雑談系であることが原因と推測される
- 「今日こういうことがあった」だけでは視聴者ニーズに応えていない
- → YouTubeから「価値を生んでいない」と判定された可能性

### 共通の学び
- **AI/機械音声/テンプレ化でなくても、独自価値がないと停止リスクがある**
- 「視聴者目線」が抜けると、どんなジャンルでも危険

## 日記・日常系チャンネルへのアドバイス
- 普段の自分の思いや日常を動画にしている人は、必ず「情報的な価値」を入れる
- 「こういう時はこうするといいよ」という体験から得た知見を盛り込む
- これだけで収益化停止リスクは下がる
- 実際、菅野氏のハウツー系チャンネル群（4〜5年運営の複数チャンネル）では1度も停止経験なし

## YouTubeで提供できる価値の種類

情報だけが価値ではない。以下のいずれかを動画に込めれば「価値ある動画」になる。

| 価値の種類 | 説明 |
|--|--|
| 情報 | ハウツー・ノウハウ・知識 |
| ストーリー | 自分の経験・物語。人を引きつける |
| 共感 | 視聴者の感情に寄り添う「めちゃ分かる」コンテンツ |
| 考察 | 事実への自分の見解。「考察面白い」と評価される |
| エンタメ | 単純に面白い、笑える |
| コミュニティ | 視聴者とのつながりを増やす場としてのチャンネル |
| 励まし・モチベーション | 視聴者を奮い立たせる動画 |
| 社会貢献 | 動画を通じた社会への寄与 |

### YouTubeの本音
- 視聴者からの反応をアルゴリズムで巻き取り、満足度で動画を伸ばすか判定
- 収益化停止判定も同じ思想で行われている
- 「視聴者にとって価値がある」と判定された動画は伸び、収益化も維持できる

## 万一収益化停止された場合の復活手順

### Step1: 動画を消さない
- 停止から90日後に再申請（最新審査）が可能
- 動画を消すと不利になる可能性がある
- 停止された瞬間に何も変えない

### Step2: 人の介在を証明する
- 再申請時に「人の手で作っている」ことの証明が必須
- 制作過程を動画として撮影
- YouTubeサポートに送信
- 「ちゃんと人が作っている、オリジナリティがある」が証明できれば復活可能性が上がる

### Step3: YouTubeサポートへの異議申し立て
- まず大元のYouTubeサポートチームへ意義申し立て

### Step4: X上で「チームYouTube」に申告
- XでアカウントがあればXで「チームYouTube」にメンションして不当性を訴える
- これで実際に復活した事例がある
- ただしStep3が先

### 注意: Xでの活動順序
- 異議申し立て(Step3)が先
- それからチームYouTubeへのX申告
- 順序を守る

## 動画価値設計チェックリスト

- [ ] 視聴者目線で動画テーマを選んでいるか
- [ ] 情報／ストーリー／共感／考察／エンタメ／コミュニティ／励まし／社会貢献のいずれかの価値を込めているか
- [ ] 生の人間の声が入っているか
- [ ] 映像のどこかに人間の手作りが伝わる要素があるか
- [ ] AIで効率化していても、価値設計は人間が考えているか
- [ ] 1日複数本の大量投稿になっていないか

## 復活手順チェックリスト

- [ ] 停止後に動画を消していない
- [ ] 制作過程の動画を撮影した
- [ ] YouTubeサポートに異議申し立てを送信した
- [ ] Xでアカウント作成・チームYouTubeへのメンション投稿準備
- [ ] 90日後の再申請に備えている

## 田村太一としての適用メモ

- 旅・グルメ＋生き方発信は顔出し前提の手作り型コンテンツになる想定で、AIスロップ判定リスクは低い
- ただし「情報的価値」を必ず動画に組み込む設計を初期から徹底（旅の知見、現地で気づいた働き方のヒントなど）
- ストーリー・共感・考察・励ましの4軸を意識的に組み合わせる構成テンプレを作成
- 編集効率化でAIを使う場合も、価値設計と人間の声は必ず残す
- 万一の停止に備え、撮影過程・編集過程を記録する習慣を発信開始時から作る
- 同ジャンル（旅・ノマド系）で実際に停止された事例があれば収集し、回避ポイントをログ化
