# YouTubeチャンネル構築でやってはいけないこと

## 出典
- 元動画: [YouTube](https://www.youtube.com/watch?v=WIQKOmwGH4Q)
- 元ナレッジ: 知見・ナレッジ移管/YouTube運用/YouTubeチャンネルの構築においてやってはいけないこと.boxnote
- 作成: 2023年9月

## 用途（どんな時に活用できるか）
- 新規YouTube案件のキックオフでNG事項を共有するとき
- 「広告でブースト」「友達に拡散依頼」を提案されたときの反論材料
- プレゼント企画を提案されたときの判断材料
- 市場規模選定の指針が欲しいとき

## NGパターン①：不明瞭な目的
- 「認知」なのか「リスト獲得」なのか「採用」なのか
- リスト/採用なら「どんな層を取りたいのか」まで固める

## NGパターン②：市場選定・競合調査をしない

### 前提準備
- 商材の客単価から、何回再生で黒字化するかを把握
- 顕在層が検索するKWをキーワードプランナー等で把握
- そのKWでYouTube上を検索して市場と競合を調査

### 市場規模の判断
- **大きすぎる**: 競合が多い／決め込んだサムネばかり → リスト取れない
- **小さすぎる**: そもそも検索ユーザーがいない → リスト取れない
- → **「大きすぎず・小さすぎず」の絶妙な市場規模**を選ぶ
- 検索ボリュームは専用ツールで確認

## NGパターン③：統一性のないコンテンツ

### 危険信号
- パッと見て「これ、○○系のチャンネルだ」がわからない

### アルゴリズム観点
- 媒体に「このチャンネルはこういう人に好かれる」というデータを学習させたい
- 共通性がない → データの質が悪い → 関連動画に出ない

### 粒度の重要性
- 「FFのチャンネル」「ドラクエのチャンネル」レベルでなら可
- ざっくり「ゲーム系のチャンネル」では現在のアルゴリズムはハックできない
- → **「誰に」「何を」を綿密に設計**

## NGパターン④：初期の広告／無意味なプレゼント企画

### 原則
> 質の悪い・不純なデータを媒体に読み込ませることになるから絶対にダメ

### 広告の問題
- カテゴリ指定しても、最初はランダムなチャンネルに掲出される
- **広告でも視聴履歴がつく** → 狙いたい層じゃない人の視聴履歴が混入
- → 全く違うデータを学習 → **再起不能**

### プレゼント企画の問題
- Amazonギフト券のような「誰でも欲しがる特典」は全然関係ない人の視聴データが付く
- 媒体に質の悪いデータが入りアルゴリズムが機能しなくなる

→ **「誰に」「何を」を初動で綿密に設計し、質の良いデータを媒体に読み込ませる**

## NGパターン⑤：外部流入が多すぎる
- 質の悪い外部流入も**質の良いデータ蓄積を妨げる**
- 例: 友達や自社社員に動画視聴・チャンネル登録を促す

## So What（戦略家としての示唆）
- 「広告ブースト」「プレゼント企画」「内部拡散依頼」の3つは初期チャンネルでは絶対NG。提案ヒアリングで必ずクライアントに確認
- 「市場規模の絶妙ゾーン」の見極めは経験値が必要。**大きすぎる市場の方が誤判定しやすい**ので要警戒
- 「ざっくりゲーム系」レベルの設計では伸びない → 提案時のコンセプト具体性を上げる根拠として使える
