# 企業がYouTubeを始めるべき理由

## 出典
- 元動画: [YouTube](https://www.youtube.com/watch?v=6uYFpb3zODs)
- 元ナレッジ: 知見・ナレッジ移管/YouTube運用/企業がYouTubeを始めるべき理由.boxnote
- 作成: 2023年9月

## 用途（どんな時に活用できるか）
- 「うちはSEOと広告でやってるからYouTubeは不要」と言う経営陣を説得するとき
- 他媒体（SEO/広告）の難易度上昇を背景に、YouTube参入の機会を提案するとき
- 「いつ始めるか」のタイミング論を整理するとき
- チャンネル設計の標準フロー（KW調査→競合→座組み→形式→コンテンツ）を組むとき

## なぜ今YouTubeなのか

### YouTubeの構造的なメリット
- **ユーザーが自発的にクリックする → 流入の質が高い**
- 動画で伝えられる → ユーザーの理解度を高められる
- 文字 → 動画/音声へのインプット手段の変化に合致
- **登録者以上の再生数が出る場合があり、コスパが良い**
- 資産性がある

### 他媒体の難易度上昇
- **SEO**
  - アップデートで第三者メディアやドメイン配下以外のオウンドメディアが評価されにくい
  - 事業ドメイン配下のオウンドメディアは伸びるが、比較記事で「ここの商品良いですよ」訴求ができない
- **広告**
  - どの企業も出稿 → レッドオーシャン化

### 今が参入のタイミング
> YouTubeもいずれSEOや広告のように難易度が上がる → **現時点では参入の余地が十分**

## チャンネル設計の標準フロー

### Step1: KW調査と分類
- SEOでもYouTubeでも同じ → KWボリュームを調べる
- 分類・まとめて、**需要がどこにあるかを発掘**
- 切り口の設計

### Step2: 競合調査
- 上記KWでYouTube上の競合を調べ、自社のリストと照らし合わせる

### Step3: コンテンツ全体設計
- 一連のコンテンツとして、出していく動画群を計画
- **この段階で、動画を作り続ける体制（人的リソース・金銭リソース）があるかが重要**

### Step4: 1本毎の形式選定
- 話す方が良いのか、見せる方が良いのか
- ロケ／対談／一人語り、どれが良いのか

### Step5: 具体コンテンツ制作
- 形式が決まったらコンテンツを作成

## So What（戦略家としての示唆）
- 「SEO難易度上昇 × YouTubeはまだブルーオーシャン」の構図で経営陣に説明できる
- 設計フローは Step1（KW）と Step3（リソース見極め）が肝。残りは作業
- 「動画を作り続ける体制があるか」を Step3で確認しないと、案件が空中分解する典型パターンに陥る
- [[2309_YouTubeを始める上で_目的と前提]] と合わせて、提案の冒頭で使える
