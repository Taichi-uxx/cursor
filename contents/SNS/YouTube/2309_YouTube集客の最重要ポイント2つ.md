# YouTube集客における最重要ポイント2つ

## 出典
- 元動画: [YouTube](https://www.youtube.com/watch?v=NRq2qX1eBXo)
- 元ナレッジ: 知見・ナレッジ移管/YouTube運用/YouTube集客における最重要ポイント2つ.boxnote
- 作成: 2023年9月

## 用途（どんな時に活用できるか）
- YouTube案件の初期ヒアリングシートの設計指針として
- 「YouTube何のためにやる？」が曖昧なクライアントを整理するとき
- YouTubeから先のLP/メルマガ/LINE導線を組むとき
- ターゲット設定（Who/What）を案件冒頭でロックしたいとき

## 最重要ポイント①：導線設計

### 確認すべき2軸
- **YouTubeを使う目的は何か**
- **YouTube接触前後で何を行うか**

### YouTubeの用途4分類
| 用途 | 内容 |
| --- | --- |
| 認知 | 新しいユーザーに知ってもらう |
| 比較・検討 | 既に検討中のユーザーを後押し |
| リスト獲得 | メールアドレス/LINE登録の獲得 |
| 登録者（ポテンシャル顧客）増加 | チャンネル登録者数を増やす |

### 飛ばし先の設計
- YouTube → どんなLPなら最適か
- リードタイムが長い商材なら **メルマガ/LINEに一旦誘導してから刈り取る**方が良い

## 最重要ポイント②：ターゲット設定（Who & What）

> どんな顧客が欲しくて、そのためにどんなユーザーに見てもらいたいのか・そのユーザーは何に困っているのか・そのユーザーに対して何を届けるのか

- **Who**: どんな顧客が欲しくて、そのためにどんなユーザーに見てもらいたいのか
- **What**: そのユーザーは何に困っているのか／何を届けるのか

## So What（戦略家としての示唆）
- 「導線設計 × ターゲット設定」の2軸はYouTube案件の初期ヒアリングシートに固定で組み込むべき項目
- リードタイムの長い商材は YouTube → LINE/メルマガ → CV の二段ロケットが効く（直接LPに飛ばすと取りこぼし大）
- [[2309_YouTubeを始める上で_目的と前提]] の「目的①リード獲得 / 目的②採用」と組み合わせると提案の骨格が固まる
