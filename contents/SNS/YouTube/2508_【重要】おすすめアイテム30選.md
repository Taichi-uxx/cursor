## 用途（どんな時に活用できるか）

- **自分の動画編集環境を整えるとき** — YouTube発信を本格化させる前に、ツール・環境を一気に揃える判断材料に
- **編集を外注する編集者・ディレクターに"最低限これは揃えろ"を伝えるとき** — 発注側として編集者に求める作業環境の基準を持てる
- **編集者としてクライアントに提案の幅を広げたいとき** — キャンバでのOP/EDテンプレ提案・エンディングカード提案など、単価UPに直結する提案ネタが拾える
- **効率化への"1秒思考"を仕事全般にインストールしたいとき** — 「1秒×2000回で分単位」の考え方は編集以外でも使える

## 全体サマリ

動画編集CAMPが自社の経験ベースで「編集者が入れるべきツール／グッズ30選」を紹介。無料は全部、有料は財布が許す限り入れろというスタンス。単なるツール紹介ではなく、「編集者→ディレクター→マーケター」へのステップアップに必要な思考も随所に含まれる。特にビジネスコミュニケーション作法（Facebook必須、経営者はスマホ前提など）は編集領域を超えて示唆的。

## 1. ブラウザ・拡張機能系（最優先）

### Google Chrome — Safariから即変更
- **理由**: ショートカットの豊富さ＋拡張機能の充実。Safariユーザーとは仕事しないレベル
- **示唆**: プロと組みたければ「相手が使うツールに合わせる」のは基本作法。iPhoneのブラウザもChromeに揃える

### Chrome拡張機能（全て無料 or 必須）

| ツール | 用途 | ポイント |
|---|---|---|
| **スコスタンプ（Scostamp）** | ボタン1つでタイムスタンプ貼付 | 修正指示・目次作成に必須。「1秒×2000回=分単位」の効率化 |
| **Ubersuggest** | キーワード検索ボリューム表示 | タイトル提案時のエビデンスに使える |
| **VidIQ** | サムネ・企画・タイトル精度向上／サムネ高画質保存 | 編集者→ディレクター→マーケター昇格に必須 |
| **YouTubeタグ** | 動画に設定されている内部タグを可視化 | 伸びてる企画のタグ研究に |
| **ビデオスピードコントローラー** | 動画速度を最大制御・1秒スキップなど | 動画チェック・情報収集の高速化。「10秒戻して残り9秒無駄」問題を解消 |

> YouTubeのデフォルトで「,」「.」キーで1フレームずつ移動できる（コンマ・ピリオド）。

## 2. タスク管理・コミュニケーション系

### Asana — タスク管理ツール
- **強み**: タスクを入れ子（サブタスク化）できる
- **本質的示唆**: 「仕事ができない人＝タスクをTODOに分解できない人」
  - 例: 「ホームページ作る」を50〜100個のタスクに細分化できるかどうかで納期が変わる
  - 編集業務も同様に「カット→テロップ→演出」と分解して積み上げる
- 個人利用は無料でOK、チームは有料

### Facebook Messenger — 経営者との接点で「必須」
- **なぜ必須**: 30〜40代の経営者層は今もFacebookを重視。「やってない人＝普通の人ちゃうんか」と思われる
- **強み**: オンライン状態が見える／クイックに送れる／広告費を使う経営者層と繋がりやすい
- **示唆**: 発注者層のいる場所を選ぶことが営業効率を決める

### X（Twitter）— 編集者アカウント運用
- **必須設定**:
  - アイコン: 顔出し
  - 名前: 本名
  - プロフィール: 特技・強み・稼働量・単価・本業/副業を明記
- **NG例**: 「トリにゃん」のような不明アイコン＋あだ名 → 「面接会場にマスクで来て採用されるか」の話
- **超重要戦略「プロセスエコノミー」**:
  1. 実績を出してから投稿 → 「すごい」or「本間か（本物か疑い）」の2択反応が返る
  2. **始める前の悩み段階から投稿しておく** → 過去の家庭が全部残った状態で実績を出すと、「本間か」を過去投稿が潰す
  3. 主婦・サラリーマン・学生など「自分と似た層」が多いほど、その層からの共感でバイラルしやすい
- **やる順序（例：動画編集キャンプ受講の場合）**:
  - 悩み投稿を10本 → キャンプ発見「怪しい」投稿 → 受講「良かった」投稿 → ポートフォリオ投稿 → 案件獲得投稿（メンション付き） → 実績投稿（メンション付き） → 引用RTされる → 対談 → 認知拡大

## 3. AI・ドキュメント系

### ChatGPT — 編集者にも必須
- **用途**:
  1. 誤字脱字チェック（プレミアからXML書き出し→GPTへ）
  2. 動画構造（白い見出し）の作成 → 倍速視聴・スキップ需要に対応
  3. 文章の構成整理（結論先出しへの変換）
- **示唆**: 編集者に足りないのは技術ではなく「仕事ができるか」。文章の結論先出し・ネクストアクション明示ができる編集者は無双できる

### スプレッドシート／Googleドキュメント
- **スプシ使い方（コミュニケーションコスト削減）**:
  - 修正点・確認事項を画像＋限定公開動画付きでシート化
  - チェックボタン方式で完了確認
  - チャット/LINEで数十通ポンポン送る「メンヘラLINE」を排除
- **重要な使い分け**:
  - **経営者相手はスプシではなくドキュメント**（スマホでスプシは超視認性悪）
  - 経営者ほどスマホしか見ない → **スマホで見られる前提で文章を書け**
  - PC上で3行の文章がスマホでは7行になる。開業・改行を意識

> パソコンでみんな打つでしょ、編集者って。だから開業とかパソコン上ではたったの3行じゃん。だけどスマホで見た瞬間にこれって7行とかになんのよ。

## 4. リサーチ・分析系（有料だが価値大）

### カタセル（勝たせる）
- 月額1〜2万円
- YouTubeで「どのジャンルの登録者数に対してどれくらい再生数が出てるか」を一元化して見れるリサーチツール
- ジャンル指定＋再生数指定で「直近1週間で1番伸びてるやつ」が上位表示
- 動画広告分析プロ開発のパクさん最新ツール

### 動画広告分析プロ
- Meta広告・YouTube広告で今何が伸びているかが全部わかる
- ジャンル・フォーマット・台本パターンが分析可能
- 「動画編集は暇な時間にこれで分析→クライアントに提案」で差別化・重宝される

### フリーランスメーカー（月4,400円）
- フリーランス用履歴書
- 希望時給・単価・職業を全部登録できる
- 「意外と営業電話・メールが来る」ので使わない手はない

## 5. 制作素材系

### Canva
- OP/ED制作テンプレが豊富。無料でほぼ使える
- **提案のコツ**: OP/EDは1回作れば継続利用で資産性高 → 1本3〜5万で余裕で通る
- **エンディングカードの提案**: おすすめ動画への遷移率が6割ある（あるデータ）→ 提案一発で「ありがとうございます」

### モーションアレイ／モーションエレメンツ
- アニメーションテンプレをPremiereで編集可能な形でDL
- フリー動画と違い「動いてる箇所削除」「文字変更」が可能

### 写真AC／Adobe Stock（画像素材）
- **必ず有料化する**
- 無料で持ってきた画質の荒い画像を編集にぶっ込むと、クオリティが一気に下がり単価も上がらない
- ディレクター視点でも「荒い画像使われるとマジで萎える」

### Artlist（BGM）
- ジャンル豊富＋量が半端ない
- ジャンル絞り＋キーワード補足でイメージ通りのBGMが出る
- 規約が難しいので要注意

## 6. ハード・環境系

### いい椅子（3万円〜）
- 高いやつでなくてOK。3万クラスでも十分
- **投資の理由**: 労働時間の延長ではなく、集中力維持時間の低下防止
- 腰痛・首肩こり対策は必ず必要

### モニター
- **推奨スペック**:
  - サイズ: 21インチ以上、個人的には24〜27
  - 画質: **4Kは不要**。MacBookの画質「WQHD」に合わせるのがベスト
  - 接続: Type-C 1本で完結（給電＋映像）
- **4Kが不要な理由**: MacBookガソ自体がWQHDで、4K処理する機会がない。字が小さくなるだけで、仕事用途では合わない

### パソコン（必須スペック）
- **M2以上のMacBook**
- **メモリ 16GB以上**（予算許すなら拡張）
- **ストレージ 500GB以上、できれば1TB以上**
- 参考: M4 32GB 512GB = 20万円台。M2 Pro 32GB = 60万円クラスより書き出し早いケースあり
- **クライアントは書き出し速度を考慮してくれない前提** → いいスペックを買え

### 拡張アダプター（USBハブ・約2,000円）
- Type-C 1本から USB3.0 / HDMI / Type-C 増設
- ピンマイク・モバ充・Apple Watchなど充電機器が多い編集者に必須

### 電動昇降デスク
- 人体は「立って作業する」構造で、立ってる方が集中力が上がる（研究データあり）
- 座る/立つを切り替えることで「無限労働」が可能

## 7. ヘルス・体調系

### サプリメント一式（月5,000円程度）
- **必須**: マルチビタミン、ビタミンC、ミネラル（亜鉛）、DHA（魚系）、プロテイン
- **理由**: 編集者は食事を取れないタイミングが必ず出る。日本人は食事から栄養素を取れていない

### マットレス・枕（睡眠環境）
- **投資理由**: コスパよく回復＋疲労蓄積を最小化
- 参考: ブレインスリープ枕（2万円台）／ヒカルチャンネル紹介の10万円マットレスなど

### 水（ペットボトル）
- 眠くなる原因は「呼吸が浅い」「睡眠不足」「水分不足」
- 1日4L推奨
- モンスター・レッドブルは翌日に響く。水縛りが正解

## 田村的示唆（What I Learned）

- **「1秒×2000回で分単位」の思考は編集領域を超えて広告運用でも活きる** — レポート作成、Slack返信、Loocker確認など、小さな作業ほどショートカット整備を優先すべき
- **経営者はスマホしか見ない → 文章はスマホ前提で書く** — クライアント（=経営者）への提案・レポートは全てスマホ実機で確認するフローを組み込む
- **プロセスエコノミー戦略はYouTube発信立ち上げの型として直接転用可能** — 「世界一周する発信者」を目指すなら、渡航前の"悩み期"からXで発信を始めるのが定石
- **編集者に求めるべき最低条件が明確化** — 外注時は「Chrome、Asana、スプシ運用、スマホ視認性、テロップは調整レイヤー」あたりを最低条件として提示できる
- **タスク細分化ができる=仕事ができる** — この定義は自分のディレクション作業にも当てはまる。50〜100個に分解できないと、進捗が「まだできてない」で止まる
