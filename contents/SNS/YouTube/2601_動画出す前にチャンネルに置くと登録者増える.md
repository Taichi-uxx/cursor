# 知らないともったいない。動画出す前にチャンネルにこれ置くと登録者増えます【YouTubeのコツ】

## 詳細
https://youtu.be/23LSOKvO5w8

## 概要

動画を出す前にチャンネル側を「登録されやすい体質」に整える方法を解説した動画。動画を出す前にこの仕込みをすることで、その後どんな動画を出しても登録者が積み上がる差が、半年・1年・2年と経つにつれて大きくなる。前提として「チャンネル登録されやすい動画」を作れるようになるのが先決で、その上でホームの動画配置・新規/既存の投稿スケジュール設計・再生リスト設計の3つを仕込むと、同じ再生回数でも登録者数が2倍に増える土台ができる。

## 大前提：登録されやすい動画がないと仕込みは効かない

### 登録されやすい動画の特徴（ジャンル別）

#### ノウハウ系
- 有益で分かりやすい
- 具体的手順の公開
- 重要性の高い情報の公開
- 常識の破壊

→ できている度合いが高いほど登録率が上がる

#### 最新情報系（トレンド／時事／都市伝説など）
- その情報を今後も追うべき理由があること
- 分かりやすいこと
- そもそもの情報の鮮度・希少性が高いこと

#### 属人性の強いコンテンツ
- 他にないキャラクター（=その人からでしか得られない栄養・価値がある）
- そのジャンルの視聴者が求めている理想の体現者であること

### 全ジャンル共通で最重要：独自性

> そのチャンネルでしか得られない栄養がある。そのチャンネルでしか得られない価値がある。これを自分のチャンネルで作れるとめちゃくちゃ強い。

- 結果として競合チャンネルに勝てる
- 登録率だけでなく再生回数・ファン形成にも効く
- 自分のチャンネルにおける「登録率の高い動画」はYouTube Studioで確認できる。傾向を見て自分のチャンネルの強みを把握する

## 独自性の見つけ方：コメント欄を起点に「極振り検証」

### きっかけはコメント欄の評価1個から
- 継続している中で「ここが良かった」「この人のこういうところが好き」など、視聴者の好意的なコメントが1つでも出てきたら、それはチャンネルにとっての**風向きが変わるタイミング**
- そのコメントが指している部分が動画の何分何秒なのかを必ず特定する

### 検証手順：極振りで反応を測る
1. 評価された要素を**思いっきり強化**した動画を3〜4本出す
2. コメント欄の風向き（好意的コメントの数・コメント率の変化）を観察
3. 「ちょっと変えただけ」だと極振りになっておらずコメントに反映されない。**明確に分かるレベルで振る**ことがコツ
4. 好意的コメントが増え、再生数あたりのコメント数の割合も上がっていたら、それは多くの視聴者に受け入れられる強み＝独自ポイント

> 自分の頭で「私これが強みかも」と思っても外れることは大いにある。視聴者から「ここいいね」と思ってもらえたところは少なくとも一定数の視聴者にとって外れではない。

### 例：話し方の極振り
- 普段「今日のポイントはこちらです」と話している人が、ある回で「絶対YouTubeはこうやった方がいい」と熱弁
- 「そっちの方が好き」「今日は熱血ですね」などのコメントを観察し、行為的コメントと数が伸びれば強み認定

### 栄養の積み重ね：5〜6個揃えると最強
- 1本の動画では「栄養」は1つしか発見できない
- 50投稿、100投稿と続けることで栄養を5〜6種類備えたチャンネルになる
- 表層ニーズ（例：YouTube攻略を学びたい）だけでなく、奥にある潜在ニーズを全部取りに行く
  - モチベーションが欲しい
  - シンプルにこの人が好き
  - 暗闇の中の1筋の光が欲しい
  - 女性目線で見られるチャンネルが欲しい
  - 癒されたい
- 栄養が複数あると「一席山頂」状態になり、飽きない動画になる＝視聴時間が伸びる

## 仕込み1：ホームに登録率が高い動画を置く

### なぜホームが重要か
- 視聴者がチャンネルアイコンをクリックした時に開くのは「動画一覧」ではなく**ホーム**
- 動画再生中にアイコンをクリックしてもホームに飛ぶ
- チャンネル登録は「今後どんな動画を出すか」を確認した上で押される。だから視聴者は登録前にホームを見る

### 何を置くか
- 視聴者に1番見てほしい動画＝**チャンネル登録率が高い動画**
- 登録率の高い動画は満足度の高い動画とほぼイコール
- まだ数字が集まっていないチャンネルは、再生リストよりも1本の登録率高い動画を置くのが推奨
- 数字が集まっているチャンネルは再生リストでもOK

### なぜ登録率はこれからも重要なのか
- 登録者が増える直接メリットだけでなく、その動画の再生回数にも影響している
- YouTubeが公式で「満足度の高い動画のインプレッションを増やす」と公言している
- 満足度の指標の中でも、登録率の重要度はここ数年で上がっており、今後さらに上がる可能性が高い

## 仕込み2：新規向け／既存向けを交互にスケジュール

### 動画タイプの分類

| 登録者が増えにくい | 登録者が増えやすい |
|---|---|
| 既存向け | 新規向け |
| 身内ネタ | 初見向け |
| 登録者向け | 検索ユーザー向け |
| ファン向け | バズる動画 |
| エンタメ系 | ハウツー系 |
| よくある企画 | 新鮮な切り口の企画 |

### なぜ両方必要か
- **新規向けだけ**：登録するきっかけは作れるが、既存ファンが育たず1本あたりのスコアが伸びない
- **既存向けだけ**：流入の供給がなく、徐々に回遊が小さくなる
- **理想形**：新規向けで初見が入る → 既存向けで回遊が回る → リピーター化 → スコアが上がってさらに新規が増える、というぐるぐる循環

### なぜ「交互」がいいか
- YouTubeの関連動画は1個前の動画が表示されやすい
- 「新規 → 既存 → 新規 → 既存」と並べると、新規流入の次に関連動画で既存向けが出てリピーター化が進む
- 結果として回遊が最大化し、登録率も最大化される

### 視聴者の理想ルート
```
新規向けの動画で流入
  ↓
チャンネル登録（高い登録率）
  ↓
既存向けの動画で回遊
  ↓
リピーター化
  ↓
スコア上昇 → 新規にもっと配信される
```

## 仕込み3：再生リストを細かく設置する

### 再生リスト経由の影響は大きい
- 例：チャンネルの全再生1000万回のうち1.9%（20万回）が再生リスト経由
- 登録率1.5%を当てはめると、再生リスト経由で約3000人の登録者を獲得している計算

### 再生リストの3つのメリット
1. **作成コストが低い**：新しい動画を作らなくても置くだけ
2. **回遊が強化される**：再生リスト視聴者は1リストあたり何本も動画を見る
   - 1動画あたりの平均視聴時間が6分40秒のチャンネルで、再生リストの平均視聴時間は10分超え
   - **平均視聴時間という重要指標が爆裂に上がる**
3. **再生リスト単体で検索表示される**：例「YouTube設定」「YouTube再生回数」などのキーワードで検索結果に表示される

### 設計のコツ：細かいニーズで分ける
- ざっくりした再生リスト1〜2個ではなく、視聴者の細かいニーズごとに分けてまとめる
- 「このチャンネルのこの動画だけ見たい」というニーズに刺さるリストを作る
- 結果としてクリック率が上がり、回遊が強まり、重要指標が改善し、チャンネル全体が伸びる

## 戦略の優先順位：登録率の改善が再生回数を追うより先

### なぜ登録率改善が先か
- 多くの人は「登録者が増えない → 再生回数を増やせばいい」と考えがち
- しかし**登録率が0.5% → 1.0%に上がれば、同じ再生回数で登録者は2倍**になる
- 1万人増えるところが2万人に増える
- 「再生回数を上げる」より「登録されやすい体質を作る」方が、最終的にレバレッジが効く

### 正しい順序
1. 登録されやすい動画を作れるようになる（本質）
2. ホーム・スケジュール・再生リストで体質を整える（仕込み）
3. 再生回数を全力で取りに行く（実行）

## 戦略家・運用者向けのアクションチェックリスト

### 仕込みフェーズ
- [ ] YouTube Studioで自分のチャンネルの登録率が高い動画TOP3を確認する
- [ ] その動画の共通要素を抽出し、独自性の仮説を立てる
- [ ] 好意的コメントが指している部分（タイムスタンプ）を特定する
- [ ] 強みの仮説を「極振り」で3〜4本テストする
- [ ] ホームの先頭に登録率が高い動画を置く
- [ ] 投稿スケジュールを「新規向け／既存向け」交互で組み直す
- [ ] 視聴者の細かいニーズで再生リストを再設計する

### 計測指標
- 登録率（動画別／チャンネル全体）
- 再生数あたりのコメント数の割合（極振り検証用）
- 再生リスト経由の視聴回数・平均視聴時間
- 関連動画からの流入比率（既存向けが新規向けを受け止められているか）

## まとめ

- 登録されやすい動画を作る前に仕込みだけしても効果は出ない。**本質（独自性）と仕込みは両輪**
- 独自性はコメント欄の好意的な反応を起点に、極振り検証で発見する
- 仕込みは3つ：①ホームに登録率高い動画 ②新規／既存を交互投稿 ③細かいニーズの再生リスト
- 登録率の改善は再生回数を追うより先。**レバレッジが効くのは登録率の方**
