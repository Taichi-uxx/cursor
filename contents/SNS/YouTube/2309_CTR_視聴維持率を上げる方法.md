# YouTubeでCTR・視聴維持率を上げるために

## 出典
- 元動画: [YouTube](https://www.youtube.com/watch?v=ZygYnz-3O5M)
- 元ナレッジ: 知見・ナレッジ移管/YouTube運用/YouTubeでCTR・視聴維持率を上げるために.boxnote
- 作成: 2023年9月

## 用途（どんな時に活用できるか）
- 投稿初日のCTR・維持率を上げるアクションを設計するとき
- サムネ・タイトルの良し悪しを判断するとき
- 動画の構成（結論ファースト/最後）を議論するとき
- 「台本は不要」と言われたときの反論材料

## 前提：YouTubeの評価指標
```
総再生時間 = IMP × CTR × 視聴維持率
```
- IMPは登録者外へのレコメンドで伸びる（投稿直後はMaxでも登録者数まで）
- 拡散の流れ：**登録者にリーチ → 登録者からのエンゲージメント高い → 登録者外にレコメンド**
- → 初動（登録者からの）CTR・視聴維持率が拡散の鍵

## 参考データ
- 1動画の視聴回数比率：**登録者 : 非登録者 = 2 : 8**
- **初日のCTRが9〜10%** あると登録者外へのレコメンドが多くなる傾向

## CTR向上の打ち手（サムネ・タイトル設計）

### ダメな例
- **ポジティブな投稿ばかり**（人はネガティブの方が反応する）
- **背景がパステルカラー**（ダークカラーの方が視認性高い）
- **サムネに答えを書いてしまう**（答えを知れたら動画を見る気にならない）
  - ただし**衝撃的すぎる答え**なら例外的にサムネに書く方が良い

### 鉄板の改善
- センスが大事 → **伸びている人のサムネ・タイトルを真似る**のが有効

## 視聴維持率向上の打ち手

### テンポを良くする（ダメな例）
- ダラダラ話す
- カットが少ない
- チャプターごとの区切りがわからない
- 「えー」「あー」が残っている

### 動画の構成
- **結論ファーストはNG**（結論・重要な情報は後）
- **自分のトークには価値がないと思う**
- 価値があるのは事前に練った台本・コンテンツ

### 台本のメリット
- 後から見返せる
- 定量データと照合して「どこが良かった/悪かったか」が分析できる
- ライブコマースのコマーサー発言記録と同じ発想

### 学び方
- 伸びている人のテンポ・話すスピード・構成を参考にする
- 丸々真似るのではなく、**自分なりのオリジナリティ**をはめ込む
- 核となる情報は何百個もない → 数個を見せ方を変えて発信
  - 例：年収チャンネル・西野亮廣

## So What（戦略家としての示唆）
- **「初日CTR 9〜10%」**は提案資料に即引用可能なBenchmark
- **「登録者:非登録者 = 2:8」**は登録者ベースKPIを否定する根拠として使える
- 結論ファースト原則を「YouTubeでは捨てる」のが反直感的だが重要。ビジネス書系の演者には特に注意して伝える
- 「核となる情報は数個」を「見せ方を変えて発信」は、コンテンツ枯渇の悩みへの回答として強力
