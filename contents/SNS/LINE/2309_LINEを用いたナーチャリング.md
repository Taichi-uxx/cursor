# LINEを用いたナーチャリング — ステップ配信の構成・順番・ABCテスト設計

## 出典
- 元動画: [YouTube](https://www.youtube.com/watch?v=diH5izR-AU4)
- 元ナレッジ: 知見・ナレッジ移管/LINE公式/LINEを用いたナーチャリング.boxnote
- 作成: 2023年9月

## 用途（どんな時に活用できるか）
- ステップ配信の構成案を組むとき／既存ステップ配信のCVRが伸び悩むとき
- セグメント別配信の設計指針が欲しいとき
- メッセージ1通1通の役割（信頼→理想→問題指摘→…）が曖昧で改善が打てないとき
- 工数の見積もり（メッセージ何通必要か）をクライアントに説明するとき

## 前提：誰に向けて書くか

### 構成・順番がCVRを決める
- 100人中95人くらいは読まない。読むのは5人
- **大事なのは95人に嫌われないことではなく、5人をどうCVまで運ぶか**
- 「読まれることを前提にした少数特化」で設計する

## ナーチャリング施策の準備物

### 1. 現状とゴールの明確化
- ターゲットは
  - どういう悩みを抱えていて
  - どういう心理状態になったらCVするのか
- スタート（現状）とゴール（CV直前）を明確化
- その2点を結ぶコンテンツ群を設計
- セグメント別に設計する
- 1通目アンケートでどんな情報を取るか逆算

### 2. セグメント分けと配信設計
- 最低3セグメントに分ける
- セグメント毎にABCテスト
- **最低3×3＝9シナリオ**に対してステップ配信を設計
- 1シナリオあたり10〜20通 → **トータル100通以上のメッセージ**を組む
- 工数はエグいが、その分CVRの上がり幅が大きい

### ABCテストで変えるところ：構成
| パターン | 内容 |
| --- | --- |
| A | 動画4本くらい送った後にオファー |
| B | 1本本気の動画を送り、見ましたかと催促していく |
| C | テキストのみでオファー |

業界やタイミングによって「今アツいパターン」が異なるので試行が必要。

## メッセージ内容の7ステップ構成

| 順 | 役割 | 伝える内容 |
| --- | --- | --- |
| 1 | 信頼の確保 | こういう会社のこういう者です（怪しい者じゃありません） |
| 2 | 理想の刺激 | こんな状態になりますよ |
| 3 | 問題点の指摘 | 現状だとこういう状態だから理想になれてないんです |
| 4 | 解決策 | こういうロジックでこれをやれば、問題点が潰せて理想に近づきます |
| 5 | 再現性の確保 | 理想論じゃなく、実際に○％の人が成功しています |
| 6 | 投資の教育（有料時） | 理想になれるなら投資する意義がありますよね |
| 7 | 行動の教育 | 期限○○時間／××人限定／残り△人・▼時間（追い込み） |

## So What（戦略家としての示唆）
- ステップ配信の質は「95人に嫌われない設計」を捨てた瞬間に跳ねる。万人向け文体はCVを殺す
- 「7ステップ構成」は LP の構成原則（PASONA等）と同じ骨格。ステップ配信＝LPを時間軸で分解したものと捉えると設計しやすい
- セグメント×ABCテスト＝9シナリオ100通超は、案件規模・予算と合わせて優先度判断が必要。最小は「1セグメント×3パターン」から入って勝ち筋を見つける
