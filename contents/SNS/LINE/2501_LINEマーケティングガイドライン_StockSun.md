- 新規LINE案件の「品質基準」として全工程の抜け漏れチェックに使う
- LINE案件の提案書作成時に章ごとの設計指針として引く
- クライアント先のLINE運用診断（リサーチ→構築→配信→分析→運用）の枠組みとして
- Lステップ／LINE Tag／オーディエンス設定など技術的な実装基準のリファレンスとして
- 「BAN対策」「クレーム対応」「アクセス権限」など見落としがちな運用ルールの確認用
- 各セクションがNG/OK例つきなので、新人ディレクター教育・チーム標準化資料としても

## 1. 事前リサーチ

### 1-1 市場トレンド
- 【他社商品の特徴/強み】【市場共通の悩み】【ターゲット層】を分析
- 推奨フレーム: PEST / 3C / SWOT / 5F
- 監修者推奨: **市場マーケット情報は最低でも3年分**を見る。競合は上位5社をリサーチ

### 1-2 競合のLINE活用状況
- 競合LINEには可能な限り**早めに登録**（フォローしないと過去配信を遡れない）
- 調査項目: 配信頻度／内容／時間帯／セグメントの有無／キャンペーン／使いやすさ

### 1-3 競合のキャンペーン・コンテンツ
- ツール／リッチメニュー／キャンペーンタイプ（割引／期間限定／ポイント／無料サンプル／リファラル）
- 各キャンペーンが「新規 vs リピーター」どちら向けかを分析
- コンテンツ（ブログ・動画・ホワイトペーパー・Webセミナー）の分類とボリューム傾向

### 1-4 ペルソナ／ユーザーニーズ
- LINEを利用しやすい時間帯
- カスタマージャーニー分析
- 機能的ニーズ（使いやすさ・性能）× 感情的ニーズ（安心感・ステータス）

## 2. アカウントコンセプト

### 2-1 アカウントの役割

| NG（曖昧） | OK（明確） |
| --- | --- |
| LINEを導入してお客様を増やしたい（新規/リピートが不明） | 新規顧客獲得 |
| LINE登録者を増やして販売数を上げたい（販売停滞の原因解決が先） | 既存顧客リテンション強化 |
|  | 成約率を高める／リピーター獲得／業務改善／フィードバック収集／プロモーション告知 |

### 2-2 KPI設計
- 短期（3〜6ヶ月）: 友だち数・有効友だち数・開封率・成約数
- 長期（1年以上）: ブランド認知・顧客ロイヤリティ・新規市場開拓
- 計算式
  - **件数 = 配信数 × 回数 × CTR × CVR**
  - これで月間に必要な友だち追加数も逆算可能

## 3. アカウント戦略（導線設計）

### 3-1 ユーザー購買プロセス
- 興味 → クーポン・購入 → LINEメッセージ → リピート → 共有・拡散
- 各フェーズの心理／行動／感情変化をマッピング
- 流入経路（YouTube/Instagram/広告）ごとに属性が異なるため、属性に合った発信を検討

### 3-2 登録タッチポイント
| オンライン | オフライン |
| --- | --- |
| サンクスページ／バナー／離脱POP／メルマガ／SNS | 店頭POP／お客様への声掛け |

事例：ECサイトの離脱アクションに合わせたポップアップで **対象サイト月間PVの1.5%が友だち追加**

### 3-3 登録ベネフィットの4パターン
1. **割引クーポン** — 顕在層にしか刺さりにくい点に注意
2. **診断機能** — 迷っているユーザーの後押し（例: 歯科の歯の健康度診断）
3. **PDF/資料** — 比較検討層にも刺さる（例: LINEの教科書／13のチェックリスト）
4. **サービス提供フローに組み込む** — 美容院カウンセリングシート／飲食メニュー表示など。**100%登録させる方法**

### 3-4 プロフィール設計
- アイコン: シンプル／ブランドカラー／高解像度
- 名前: 20文字以内、ブランド名 or サービス名、「公式」で信頼度UP
- **背景画像** は売りたい商品／サービス／キャンペーンのバナーとして活用（必須）

### 3-5 ターゲット別カスタマイズ導線
例（美容）:
- 20代: トレンド敏感／InstagramでビフォアフタDD → 「最新美肌治療20%OFF」
- 30代: 短時間で効果 → 「忙しいあなたに短時間ケア、特別価格」
- 40代: アンチエイジ重視 → 「初回カウンセリング無料」

### 3-6 各フェーズの目標
LINE登録 → メッセージ開封 → クリック・アンケート → 購入 → リピートの5フェーズに分けて、それぞれ指標を設定

### 3-7 友だち追加時アンケート
- **アンケートで約3割が離脱**するため慎重に
- SNS経由ユーザーは既に教育済みなのでアンケート無しが多い
- ユーザーID取得には拡張ツール必須

## 5. シナリオ構築

### 5-1 シナリオの目的（ゴール例）
- 商品購入／サービス申込／ユーザー登録／資料請求／面談予約／セミナー参加

### 5-2 シナリオ設計の6ポイント
1. **心理的トリガー**: 希少性・社会的証明・権威・一貫性
2. **ストーリーテリング**
3. **緊急性と希少性**: 「今すぐ」「残りわずか」「限定オファー」
4. **感情的利益**: 「これで安心」「特別な気分に」
5. **社会的証明**: レビュー・実績を組み込む
6. **透明性と誠実さ**: 価格・条件を明確に

### シナリオ配信の順番（取りこぼし最小化の鉄板順）
1. ウェルカムメッセージ
2. ステップ配信
3. 定期配信
4. **クリックリターゲティング配信**（クリックユーザーへリマインド）
5. **トラフィックリターゲティング配信**（離脱者へリマインド）

### 5-3 ヘッドコピーの5原則
- 冒頭2行が**トーク画面のアカウント名の下に表示される**ので開封率に直結
- 冒頭2行に興味を引く内容／簡潔／感情訴求／差別化／顧客メリットを入れる

### 5-4 CTA設計

| NG | 理由 |
| --- | --- |
| 「もっと詳しく知る」 | 行動が不明確 |
| 「こちらをクリック」 | メリットが伝わらない |
| 「後で申し込む」 | 緊急性がない |
| 小さく下部に配置 | 視認性不足 |

| OK | 効果 |
| --- | --- |
| 「今すぐ無料体験を申し込む」 | シンプルで明確 |
| 「限定20名！今すぐ登録で割引」 | 緊急性・限定性 |
| 「無料カウンセリングで子どもの学習状況を診断」 | ユーザーメリット明示 |
| 「今すぐ予約する」ボタンが中央大表示 | 目立つデザイン |

## 6. アカウント構築

### 6-1 アカウント作成
- プロバイダ名はアカウントごとに変更
- **Lステップは全て新規アカウントで開設**（過去アカ流用しない）

### 6-2 回答フォーム（Lステップ）
- アクション設定で**「回答フォームを開く」はNG**（データ取得不可）
- **「URLを開く」+ 外部ツールで短縮URL** にすると開封タグでデータ取得可能

### 6-3 リンク設定
- 外部リンクには `?openExternalBrowser=1` を必ず付与
- LINEアプリと外部ブラウザが並行起動 → 意図しない離脱を防いでCVR向上

### 6-4 URLアクション設定（Lステップ）
- 全URLにタグ付け（クリックの有無を計測するため）

### 6-5 カルーセル代替テキスト（Lステップ）
- 代替テキスト未設定だと「LINEアプリでご覧ください」が表示され開封率が下がる
- 例: 「2日間限定で〇〇が全員にもらえる！」「年収350万→600万！その驚きの方法とは？！」

### 6-6 リッチメニュー
- **常時ON**にしないとユーザーが重要情報を見逃す

### 6-7 命名規則（Lステップ）
| 対象 | 命名規則 |
| --- | --- |
| テンプレート | 項目名_OO（例: リッチメニュー_店舗紹介_アクセス） |
| タグ | 項目名_OO_タップ（例: シナリオ配信_1通目_挨拶_配信済） |
| 回答フォームタグ | アンケート名_OO_回答内容 |

→ 複数人作業簡便化、修正対応のしやすさ、工数削減

### 6-8 動作テスト
- 必ず**納品前チェックシート**で2人体制ダブルチェック

## 7. データ取得

### 7-1 取得項目
- 友だち登録数／ブロック数／累計
- 登録特典の受取率／動画視聴率
- 配信数・開封率／URL・ボタンクリック率
- 回答フォーム回答率／**反応スコアリング**
- CVR／リッチメニュータップ分布／問合せ数／友だち登録日／最終反応日

### 7-2 LINE Tag・オーディエンス（LINE公式）
| タイプ | 内容 |
| --- | --- |
| メッセージクリック | 過去配信のリンクをクリックしたユーザー |
| メッセージインプレッション | 過去配信を開封したユーザー |
| リッチメニュークリック／インプレッション | 同左 |
| 友だち追加経路 | 特定経路で追加したユーザー |
| チャットタグ／予約 | チャット属性／LINE経由予約者 |

### 7-3 テンプレート／アクションからのデータ抽出（Lステップ）
- LINE内全てのアクションにタグ付け & 日付データ取得
- 用途: リードタイム測定／セグメント活用／スコアリング

### 7-4 クロス分析（Lステップ）
- 友達登録日 × シナリオ各通目の到達数 × 個別面談申込数のクロス集計
- 「どの登録日のユーザーがどこで離脱しているか」を可視化

## 8. 配信方法（13項目）

### 8-1 初回メッセージのオファー
- 登録直後が最も熱量高い → **オファー必須**
- パターン: ①行動+未来提示 ②締切訴求 ③アクションを軽くする
- ECサイトはID連携も初回メッセージで取得することが多い

### 8-2 メッセージ作成の重要ポイント
- 文字数最小限／文字大きく視認性確保
- **LINEトークルームは下から開く** → リッチメッセージ（画像）は一番下に
- CTAは画像内に配置
- リッチメッセージは**3段とも設定**（CTR向上）

### 8-3 画像活用
- テキストだけだと視覚インパクト弱い → 画像でCTAを目立たせる

### 8-4〜8-5 リッチメニュー
- 最も訴求したい内容がビジネス目標／キャンペーンに直結しているか
- 視認性／立体感（ボタン感）でタップ場所を主張
- **基本6ボタン or 4ボタン構成**
- **右側が一番クリックされる**ので最重要コンテンツは右配置

### 8-6 定期配信の4要素
1. いつ（曜日・時間） → 2. 誰に（年代別） → 3. 何を（悩み／効果／時事／権威／評価／形状／仕様／使い方／限定／特典／価格） → 4. 表現（ビジュアル／コピー／フォーマット／レイアウト）

### 8-7 長文配信（Lステップ）
- LINEは元来短文コミュニケーション
- 長文は**回答フォーム機能**でコラム形式にして読ませる（見る意思表示を介して離脱率↓・読了率↑）

### 8-8 効果測定の手順
KPI設定 → 開封率 → クリック率 → CVR

### 8-9 セグメント配信
| セグメント | 例 |
| --- | --- |
| 全員 | 共通の採用情報やイベント告知 |
| クリック | 「エントリーありがとうございます！詳細送付」 |
| 開封 | 「説明会登録まだの方はお早めに！残席わずか」 |
| デモグラ別 | 「20代の新卒向けポジション、今すぐ応募」 |
| 友だち追加経路別 | 「Web経由登録の方限定セミナー招待」 |
| LINE Tag活用 | 「採用サイト訪問者へリマインド」 |

> **適切なセグメントでブロック率が10%以上下がった事例あり**

### 8-10 配信時間（業種別目安）
| 業種 | オススメ配信タイミング |
| --- | --- |
| ビジネスマン向け英語スクール | **20〜22時**（夜リラックスタイム） |
| 主婦向け育児アカ | 10〜14時（子ども不在時）／20時〜（寝かしつけ後） |
| 美容院 | **9〜11時**（美容院に行く前） |
| スーパー | 10〜12時（買物前）／16〜18時（仕事後買物前） |

- **金曜は他LINE配信が多いので避ける**を推奨

### 8-11 通知メッセージ
- LINE公式に**友だち追加していないユーザー**にも電話番号ベースで送信できる機能（要審査）
- OK利用例（22パターン）: 配送通知／予約通知／リマインド／障害通知／申込完了／料金確定／購入完了／支払完了 等
- NG: 営利目的／広告／個人識別情報

### 8-12 アカウント満足度評価（NPS）
- LINE公式の**無料機能**で90日に1回計測可能
- 推薦者(9-10) − 批判者(0-6) = NPSスコア
- 配信きっかけでトーク開く回数も増え、エンゲージメント向上に寄与

## 9. 配信時の注意

### 9-1 配信前確認チェック
- 吹き出しサイズ（200〜300文字以内、スクロール不要か）
- 誤字脱字（固有名詞・数値特に）
- リンク切れ（全クリック確認）
- 設定（日時・時間帯・セグメント）
- **設定者と無関係の人で2人ダブルチェック**

### 9-3 テスト配信
- 「友だちリスト」→「歯車マーク」→「テスト送信対象に追加」
- スマホ実機で確認（LINEは100%スマホ）

### 9-4 トラブル対応
1. リンク切れ・誤情報の確認と修正
2. ユーザーへのお詫び配信
3. 関係者への情報共有と予防策検討

## So What（戦略家としての示唆）

### 戦略レイヤー
- **「役割が明確でないアカウントが多い」**（監修者高橋）— 提案時、まず「役割」を1つに絞らせる
- KPIロジック `件数 = 配信数 × 回数 × CTR × CVR` は提案資料の根拠として使える
- **チャネル別成約率の差（X 1% vs YouTube 3.6%）**は集客チャネル選定の説得材料

### 実装レイヤー
- **「URLを開く」（タグ取得可）vs 「回答フォームを開く」（取得不可）** はLステップ案件で頻発する落とし穴。チェック必須
- リッチメニューは **6or4ボタン × 右下に重要CTA** が鉄則
- カルーセル代替テキスト未設定で開封率が下がる点は見落としやすい
- 命名規則（テンプレ・タグ）は「見えないが工数削減で効く」標準

### 配信レイヤー
- **業種別配信時間目安**（英語スクール20-22時／美容院9-11時／主婦10-14時+20時〜／スーパー10-12時+16-18時）は提案で即使える
- **金曜回避**は競合配信過多で埋もれるため
- セグメント配信でブロック率10%↓ の実例
- 通知メッセージ22パターンはECや予約商材で全件チェック

### 数字で覚えておくべきベンチマーク
- 友だち追加直後アンケートで **3割離脱**
- 離脱ポップ施策で **1.5%程度の友だち追加上乗せ**
- 飲食ガチャ施策で **登録率10.9倍／ブロック率4.9%**
- 休眠掘り起こし1キャンペーンで **1,500万円売上**
