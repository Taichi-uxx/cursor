## 1. 2023年6月の料金プラン変更（実質値上げ）

### 変更前 → 変更後

| 項目 | フリープラン | ライトプラン | スタンダードプラン |
| --- | --- | --- | --- |
| 月額固定費（変わらず） | 0円 | 5,000円 | 15,000円 |
| 月間無料メッセージ数 | 1,000→ **200通** | 15,000→ **5,000通** | 45,000→ **30,000通** |
| 追加メッセージ料金 | 不可 | 5円→ **不可** | 〜3円/通 |

### インパクト試算（月45,000通配信していたアカウント）
- 月額: 15,000円 → **60,000円**（4倍）
- 年額: 180,000円 → **720,000円**（差 +540,000円）

### 関連影響
- LステップなどのAPIツールにも料金影響が波及する想定
- **「友だち数が多いから無条件で全配信」が成立しなくなった**

## 2. 料金改定に対する4つの対応施策

### 施策①：セグメント × スコアリング

#### 基本的な数字感
- 配信内のボタン／リンクをタップするユーザーは **5〜30%**
- 業種や商材によるが、成約までするユーザーは **最大10%程度**
- → この10%だけに配信できれば通数を節約しながらCVを維持できる

#### スコアリングとは
配信／リッチメニューのタップ回数に応じてユーザーに点数を付与する仕組み。

例：リッチメニューの各項目をタップした際に
- 青枠（一般情報）: +1点
- 紫枠（中位）: +2点
- 赤枠（問い合わせCTA等）: +3点
- 各項目を1回ずつタップ → 1×3 + 2×2 + 3×1 = **10点**

#### セグメント分けの例（スコアによるランク）
| ランク | スコア帯 |
| --- | --- |
| Dランク | 1〜25 |
| Cランク | 26〜50 |
| Bランク | 51〜75 |
| Aランク | 76〜100 |
| Sランク | 101〜 |

#### スコア × 成約率の実データ（MARKELINKアカウント 2020-2021）
| スコア帯 | 成約率 |
| --- | --- |
| 〜99 | 〜10%未満 |
| 100〜129 | **11.97%** |
| 130〜159 | **19.54%** |
| 160〜199 | **25.86%** |
| 200〜 | **33.86%** |

> スコアが高いユーザーほど成約しやすい → **そのユーザーに絞れば配信数を節約しながら成約数を獲得できる**

### 施策②：リスト獲得のための登録特典の切り口

#### 基本フロー
- 浅い診断 → 友達増えない・流行らない
- **濃い診断** → ユーザーの期待を超える → 拡散 → 新規登録

#### 事例：婚活サービス「ヒトオシ」
- 登録特典: **「婚活こじらせ診断」**（全25問の濃い診断コンテンツ）
- 質問例: 初回デートは割り勘か／異性と話すのは楽しいか／お付き合いの経験は／完璧主義か／自分からデートに誘うか
- 結果: 自分の婚活タイプが表示される

#### 結果
| 月 | 友だち登録数 |
| --- | --- |
| 7月 | 286人 |
| 8月 | **1,952人** |
| 9月 | 1,631人 |
- 月間友だち登録数: **6.25倍**
- 累計登録者数: **11,929名**（2022年11月時点）

### 施策③：配信A/Bテストの実施

#### テスト①：効果的な配信時間帯（5パターン）
題材：「LINEマーケサミット2022」参加者募集

| 配信時刻 | 配信数 | タップ率 | 申込率 |
| --- | --- | --- | --- |
| 12時 | 2,284 | 3.81% | 0.35% |
| 17時 | 2,313 | 3.72% | 0.82% |
| 19時 | 2,393 | 4.22% | 0.84% |
| 20時 | 2,344 | 3.84% | 0.38% |
| **21時** | 2,370 | **5.06%** | **0.97%** |

> 一般に「20時が反応良い」と言われるが、実測すると21時が最強。20時で全配信していたら最大の39%しか獲得できていなかった。

#### テスト②：申込方法（直接LINE登録 vs Web経由）
| 指標 | ①直リンク（LINE直接） | ②Webサイト経由 |
| --- | --- | --- |
| 配信母数 | 5,886 | 5,818 |
| タップ率 | 4.13% | 4.14% |
| **LINE登録数** | **143名** | 59名 |
| **LINE登録率** | **2.43%** | 1.01% |
| 申込数 | 41 | 38 |
| 申込率 | 0.70% | 0.65% |

> 申込率はほぼ同じだが、LINE登録数で **2.42倍** の差。LINE登録者には追撃配信できるため**直接LINE登録を促す方が長期で効果的**。

#### A/Bテストで変えるべき3要素
1. **配信時間**
2. **配信曜日**
3. **デザイン**

> 配信時間や方法でCVRに **2.5倍** の差が生まれる。ターゲット属性（会社員多い等）で最適解が変わるので必ず実測する。

### 施策④：追撃配信と鉄板配信の確立

#### 題材
- 商品①：動画コンテンツ 188,000円 → 138,000円
- 商品②：動画＋コーチング 288,000円 → 188,000円
- 4日間キャンペーン

#### 比較データ（9/27〜9/30）

| 配信タイプ | 配信数 | 成約数 |
| --- | --- | --- |
| 初日のみ配信（追撃なし） | 11,576通 | **1名** |
| 初日 + 追撃配信あり | 12,049通 | **19名** |
| **追撃配信のみ効果** | **473通** | **18名** |

> たった **473通の追撃配信で成約19倍、売上327.2万円**を達成

#### 追撃が効いた3要因
1. **セグメント分け**: 反応した成約可能性高い人にだけ配信
2. **キャンペーン**: 期限付き割引でお得感
3. **相談窓口**: 高単価商品なのでチャット相談で丁寧フォロー

> セグメント追撃配信＝「**必ず売上が立つ鉄板配信**」を作る。年4回実施すれば **年間1,200万円売上の鉄板配信** に育つ。

## 3. まとめ：2023年6月以降の運用思想

> **売上が上がるリストと、そうでないリストを分類する仕組みの構築が重要**

- ✅ スコアリングで可視化する
- ✅ 有益な登録特典を作り、登録者を増やす
- ✅ A/Bテストを実施し、売れる状況を確立する
- ✅ 鉄板配信を作り、追撃配信で確実に売上を立てる

## 4. 2023年用 LINE公式アカウント重要指標チェックリスト

### 基本設定
- [ ] アイコン設定: 企業キャラ／担当者／経営者の顔出しで「キャラ」を浸透させているか
- [ ] 導線設計: メニュー・料金・申込などの必須項目が分かりやすい導線か
- [ ] ライティング: 配信文の行間は見やすく、LINEらしい親近感ある文章か
- [ ] リスク管理: 月内使用通数を予測し、適切なプランで運用できているか（不足するとアカウント停止）
- [ ] ベンチマーク数値
  - **ブロック率**: 平均 **35%前後**
  - **開封率**: 平均 **60%前後**
  - **タップ率**: 平均 **5〜10%**
  - **配信ブロック率**: 24時間以内に対配信者 **1%以下** を目標

### 友だち追加・リスト獲得
- [ ] 友だち遷移率: 各SNSからのLINE登録率KPIを設定（目標: SNSフォロワー数の **15%以上**）
- [ ] 流入経路: オンライン・オフラインで専用URL/QRを発行して計測
- [ ] 導線設計: オンラインオフライン問わず追加したくなるオペ・声かけができているか
- [ ] 登録特典: 見込み客が思わず欲しくなり、自社商品の購買促進にもつながる特典か
- [ ] 広告: LINE友だち追加広告から流入リスト単価／成約率／成約数を明らかにできているか

### ステップ配信
- [ ] 商品訴求: 売りたい商品が明確で文章/動画で十分訴求できているか
- [ ] 導線設計: 視聴後に「買いたい」と思った時いつでも買える分かりやすい導線か
- [ ] ライティング: 1日目→2日目もすぐ見たくなる引きの設計
- [ ] コミュニケーション: 一方通行でなく、感想や行動を引き出す設計
- [ ] 分析: 視聴数を分析し、未購入だが成約可能性高い登録者を炙り出して追撃配信

### アカウント構築
- [ ] スコアリング: リッチメニュー／ステップ配信／回答フォーム全てでスコアがつく設計
- [ ] セグメント: 性別／年齢／居住地以外に分類すべきカテゴリを把握し、追加時アンケートで取得
- [ ] リッチメニュー: ペルソナに合ったデザインとボタン押したくなる工夫
- [ ] リッチメニュー②: HP代わりではなく、LINEならではの診断・クイズ・ゲーム等を盛り込む
- [ ] チャットボット: リプライ応答だけでなく、LP風回答フォームで長文訴求も活用

### 月次配信
- [ ] オペレーション: 配信担当・対応者・分析者が明確で、月1回はすり合わせミーティング
- [ ] 配信計画①: A/Bテストで反応の良い曜日・時間帯・クリエイティブを把握
- [ ] 配信計画②: その月に売りたい商品を決め、季節キャンペーンに絡めた配信
- [ ] 配信頻度: **最低月4回** の計画的配信
- [ ] 配信戦略: ①双方向コミュニケーション意識 ②タップ者への追撃 ③セグメント絞り、のいずれかを意識

## So What（戦略家としての示唆）
- **2023年6月の値上げで「全配信」モデルは終わった**。スコアリング × セグメント絞り込みは前提化（実測値: スコア200+で成約率33.86% vs 全体10%）
- 「21時 vs 20時」「直リンク vs Web経由」は**業界の通説と実測がズレる典型例**。提案時は「実測する」を主張する根拠として引用可
- 鉄板配信フォーマット（年4回キャンペーン × 追撃配信）は1,200万円ARR相当のアセット。LINE案件は単発施策でなく「鉄板の型を作る」発想で組む
- ベンチマーク数値（ブロック率35%・開封率60%・タップ率5-10%）は提案資料にそのまま使える定量基準
- 「濃い診断（25問）で月286→1,952人（6.25倍）」のヒトオシ事例は登録特典設計の到達点として引用可
