## 用途（どんな時に活用できるか）
- 「LINE登録を促しているが放置している」状態のクライアントへ「教育配信」を組む提案するとき
- ステップ配信の構成テンプレートが必要なとき（特に有料商材／高単価商品）
- 説明会型／LP成約型のプロモーションパターンを使い分けたいとき
- 1通1通の役割（ペルソナの過去→壁→成功→未来…）を具体的に設計するとき
- 1人あたり1万円が見込める市場で1,000人放置している → そこから1,000万円の機会損失を回収する設計を組むとき

## 大前提：LINEプロモーションの3ステップ
```
①集客（LINE登録） → ②教育（LINE配信） → ③販売 or 採用
```
> **②の質を上げて①→③への誘導率を上げる**のがプロモーション設計の核心

## 3つのプロモーションパターン

LINE登録〜CVまで、**最もCVRの高い型をABCテスト**で見つける。代表的な3パターン:

| パターン | 流れ | 向いている商材 |
| --- | --- | --- |
| A | 7通ステップ → LP成約 | テキスト訴求中心、安〜中単価LP商材 |
| B | 4本教育動画 → 説明会 | 高単価／無形商材／コーチング系 |
| C | 1本長尺動画 → 説明会 | 熱量高い登録者を一気に説明会へ |

## パターンA：7通ステップメール → LP成約

### 全体フロー
```
シナリオ① → シナリオ② → シナリオ③ → シナリオ④ →
シナリオ⑤ → シナリオ⑥ → シナリオ⑦ → LP誘導
```
※各シナリオは「動画 or コラム」

### 各通の構成要素

#### 1通目（過去 → 一歩）
1. ペルソナの辛い過去
2. 辛い過去からの一歩／過去を超える一歩
3. 明日の動画の予告

#### 2通目（壁 → 気づき）
1. ペルソナが実際に衝突した壁
2. 新たなる気づき／解決の予兆
3. 明日の動画の予告

#### 3通目（成果 → 改善策）
1. ペルソナの成功体験や成果
2. 改善策の提示
3. 明日の動画の予告

#### 4通目（実現したい未来）
1. ペルソナの実現したい未来
2. 未来を実現するためのアクション提示
3. 明日の動画の予告

#### 5通目（4通目アクションで衝突しうる壁）
1. 4通目のアクションで衝突しうる壁
2. その壁の解決方法
3. 明日の動画の予告

#### 6通目（さらなる理想の未来）
1. さらなる理想の未来
2. そのためのtoDoとアクション
3. 明日の動画の予告

#### 7通目（理想の未来の実現）
1. 理想の未来の実現
2. お客様の声／第三者の実績
3. お礼メッセージ

### 構成原理
> **過去 → 壁 → 成果 → 未来 → 新たな壁 → 理想 → 実現** という7段階のストーリーアーク。各通の終わりに必ず「明日の動画予告」で離脱を防ぐ。

## パターンB：4本教育動画 → 説明会

### 全体フロー
```
Day①動画 → Day②動画 → Day③動画 → Day④動画 → 説明会参加リマインド → 説明会
```

### 各Dayの構成要素

#### Day①動画
1. ペルソナが実際に衝突する壁
2. 壁を打開する方法／解決した方法
3. 明日の動画の予告

#### Day②動画
1. ペルソナの成功体験や成果
2. 成功の先の不安／未来への不安の提示
3. 明日の動画の予告

#### Day③動画
1. 不安を解消した未来／理想の未来
2. お客様の声／第三者の実績
3. **説明会があることの告知**

#### Day④動画
1. 説明会の告知／特典の案内
2. 説明会の内容／ベネフィット
3. お客様の声／説明会実績

### 説明会リマインド配信の3要素
1. **参加しない理由の削除** — 参加特典の用意・不安感の解消
2. **反響の共有** — 「既に○人の方が参加予約しています」
3. **締め切り** — 「残り○日です」「残り○人です」

### 構成原理
> Day①は「壁」、Day②は「不安」（成功した先の新たな課題提示でフックを作る）、Day③で説明会告知、Day④で参加促進。**3日目に予告して4日目で押し切る**のがポイント。

## パターンC：1本長尺動画 → 説明会

### 全体フロー
```
長尺教育動画1本 → リマインド配信 → 説明会
```
> 熱量の高い登録時にメリットを感じてもらい説明会へ。スピード感重視。

### 1本長尺動画の基本構成（8要素）

| 順 | 要素 |
| --- | --- |
| ① | 自己紹介・権威性・動画概要 |
| ② | ストーリー／自分が語る理由 |
| ③ | 問題提起 |
| ④ | 解決手段の提示 |
| ⑤ | ④を踏まえたさらなる問題 |
| ⑥ | 実例を用いた解決方法 |
| ⑦ | 実際のtoDo／その先の未来像 |
| ⑧ | オファー |

### リマインド配信の3要素（パターンBと同じ）
1. 参加しない理由の削除（特典・不安解消）
2. 反響の共有（既に○人が予約）
3. 締め切り（残り○日／○人）

## So What（戦略家としての示唆）
- 「LINE放置 = 機会損失」を金額換算する視点（1人1万円 × 1,000人 = 1,000万円）は提案で必須。クライアントが動く動機になる
- **どのパターンを選ぶかは商品単価で決める**
  - 低〜中単価＋テキスト中心 → A（7通ステップ）
  - 高単価＋ストーリー必要 → B（4本動画→説明会）
  - 熱量利用型／時間勝負 → C（1本長尺→説明会）
- 各パターンに共通する設計原理：「過去→壁→成功→未来→新たな壁→理想→実現」のストーリーアーク。これは [[2309_LINEを用いたナーチャリング]] の7ステップ構成と同型
- リマインド3要素「参加しない理由を消す × 反響共有 × 締切」はBC共通の鉄板テンプレ。LINEだけでなくセミナー集客全般に使える
- 「3日目に告知 → 4日目に決め打ち」の押し方は LP の Above the Fold → 最終CTA の構造と同じ。時間軸で分解して使うイメージ
