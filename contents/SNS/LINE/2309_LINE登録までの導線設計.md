# LINE登録までの導線設計 — 友達登録率を最大化する1通目とオファー設計

## 出典
- 元動画: [YouTube](https://www.youtube.com/watch?v=gEPFi0hWOig)
- 元ナレッジ: 知見・ナレッジ移管/LINE公式/LINE登録までの導線設計.boxnote
- 作成: 2023年9月

## 用途（どんな時に活用できるか）
- LINE公式アカウントの「友達登録率が低い」案件で改善打ち手を考えるとき
- LP・HPで「LINE登録CTA」をどう設計するか議論するとき
- 拡散を狙うLINE企画（診断系コンテンツ等）を企画するとき
- ステップ配信の入口（1通目）の設計指針が欲しいとき

## 大原則：1通目の設計が全てを決める

1通目で何を届けるかによって決まるもの
- 友達登録率（その後の集客）
- 登録後の口コミ拡散

### ❌ 1通目に送りがちなNG例
- 「私たちは～な会社で、・・・」（自己紹介から入る）
- 「登録してくれたらクーポンあげます」（汎用クーポン訴求）

### ✅ 1通目に送るべきもの
> **ターゲットユーザーが求めているコンテンツ**を「プレゼント」する

- 化粧品会社 → 化粧の仕方が学べる動画/PDF
- 年収チャンネル → 有名企業の年収一覧PDF

## LINE登録オファー設計

### LP/HP側での訴求
- 「LINE登録で○○プレゼント！」
- これでLP/HP訪問 → LINE登録のCVRが上がる
- 登録後の1通目で約束通りのコンテンツを渡す

### オファー設計のポイント
- **「今すぐ」使えるものを訴求する**（プロスペクト理論）
  - 飲食店なら「今回の会計から使える」がベスト
  - 「次回以降使える」は弱い
- **何をプレゼントすれば登録率が上がるか**は試行錯誤が必要

## 口コミ拡散につながるオファー設計

### 拡散を促す3要素
- 「めっちゃタメになる」
- 「これもらえるのめっちゃラッキー」
- 「めっちゃ面白い」

### 最近の流行り：診断系コンテンツ
- 例: 整形クリニックの「顔面偏差値チェッカー」
- どの業種・ジャンルでも企画しやすい
- 拡散にもつながりやすい
- **三次元的に友達リストを集められる**（友人経由で広がる）

## 診断系コンテンツがナーチャリングにも効く理由

診断の過程でアンケートを取れる:
- 性別・年齢・職種・住所
- 興味のあること
- 悩んでいること

→ 取得した属性に応じてステップ配信を出し分け → CTVR上昇（カスタマイザ的発想）

### 配信フロー設計
- CVに至ったユーザー → LTV向上コンテンツ配信
- CVに至っていないユーザー → 再度オファー設計
- → 一人残らず刈り取れる可能性のある人を取り切る

## So What（戦略家としての示唆）
- LINE登録率の改善は「登録CTAの文言」より「1通目で渡すコンテンツの設計」がレバレッジ大
- 「今すぐ使える」プロスペクト原則は飲食・美容・EC全てに適用可。「次回から」訴求は機会損失
- 診断系コンテンツは「拡散装置 × データ収集装置 × セグメント配信の起点」の3役を1つで担える。LINE案件の初期企画候補として常に検討する価値あり
