# LINE公式アカウント運用チェックリスト 50項目（クウゼン版）

## 出典
- 提供: 株式会社クウゼン（KUZEN）／LINEテクノロジーパートナー
- 元ナレッジ: 知見・ナレッジ移管/LINE公式/LINE公式アカウント運用チェックリスト.pdf
- 作成: 2023年12月

## 用途（どんな時に活用できるか）
- 新規LINE案件の初期診断（運用の抜け漏れチェック）
- 既存LINE運用の改善ポイントの洗い出し
- クライアントへの改善提案書のたたきとして
- LINE運用代行の見積もり前ヒアリング項目として
- 月次・四半期レビューでの自己点検チェックリストとして

## チェックリストの4カテゴリ構成

| カテゴリ | 内容 |
| --- | --- |
| 全体方針・設計 | アカウント全体の方針・KGI/KPI・ターゲット定義 |
| 友だち追加の促進 | LINE登録導線・広告・アカウント情報設計 |
| LINE内施策 | ウェルカム／アンケート／メッセージ配信／リッチメニュー |
| 高度な施策 | ファーストパーティデータ活用・パーソナライズ |

## ① 全体方針・設計（6項目）

- [ ] LINE公式アカウントの目的が明確になっているか
  - 新規ユーザー登録促進／再来店促進／既存ユーザー利便性向上など、目的を1つに絞る
- [ ] 目的に沿った成果指標（KGI/KPI）が定義され、定期的に施策改善が実施されているか
  - 高頻度で計測できる指標になっているかも確認
  - 会員登録数や購入額をKPIにする場合はWeb計測ツールやCRMでの計測が必要
- [ ] ターゲットユーザーが定義されているか
- [ ] 上記の目的や対象ユーザーと整合性のとれた施策が立案されているか
  - 「あれもこれも」になりがちなので一貫性をチェック
- [ ] 同業他社などのLINE公式アカウントを把握し、参考にしているか
- [ ] 定期的な成果指標の確認と施策の改善が行われているか
  - 目安: **月に一度** の現状把握と改善

## ② 友だち追加の促進（8項目）

- [ ] Webサイトバナー・離脱防止ポップアップ・SNS・店頭ポップ・チラシなど、友だち追加導線を十分に設置しているか
  - 離脱防止ポップアップによるLINE案内は有効なケースが多い
- [ ] 友だち追加のためのオンライン広告施策に適切に取り組んでいるか
  - LINE広告のCPF活用が有効
  - 反応率の悪い友だちを集めないようプランニングが必要
- [ ] 友だち追加導線で、アカウント内容と追加メリットが訴求されているか
  - シンプルかつ明確な表現で
- [ ] モバイルユーザーとPCユーザーの違いに考慮した導線設計か
- [ ] どの友だち追加導線が最も効果的かを検証しているか
  - 特に有料施策では各導線の追加数とCV数を把握
- [ ] タグラインや画像の変更によって、友だち追加数の増加に取り組んでいるか
  - 離脱防止ポップや店頭ポップの**画像・タグライン変更で反応率が大きく変動**する
  - 定期的にABテストを実施
- [ ] 友だち追加画面の「アカウント紹介文」「アイコン」「背景画像」が設定されているか
  - 必ず3つ設定
- [ ] 紹介文や背景画像が、友だち追加促進導線（バナーやポップアップ）と整合性が取れ、追加を促す内容になっているか
  - 友だち追加画面での離脱を最低限に抑える

## ③ LINE内施策

### ③-A 友だち追加時のフロー（11項目）

#### ウェルカムメッセージ
- [ ] 友だち追加時に「ウェルカムメッセージ」が流れるようになっているか
- [ ] ウェルカムメッセージの内容に、アカウントのコンテンツ紹介やメリットの記載があるか
- [ ] ウェルカムメッセージで、画像を適切に利用できているか
  - リッチな画像メッセージで反応率UP
- [ ] ウェルカムメッセージのテキストコンテンツは目安として **100文字以内** になっているか
  - 長文は読了率が低く、離脱・ブロックにつながる

#### 友だち追加直後のユーザーアンケート
- [ ] 友だち追加時に、今後の施策で活用するセグメント作成に必要な情報の取得（ユーザーアンケート）ができているか
  - **アンケート回答率は友だち追加直後がもっとも高い**ので必ず実施
- [ ] ユーザーアンケートはセグメント作成に必要な問いで構成され、不要な質問は除かれているか
  - 質問数が多いほど回答完了率は下がる
  - 目安: **5問以内**
- [ ] アンケートの選択肢や入力形式はユーザーが入力しやすい形式になっているか
  - ボタン／クイックリプライ／フレックスメッセージ／テキスト入力など
- [ ] アンケートに回答するメリットや、回答完了にかかる時間の記載はあるか
  - 「あなたにあった情報が届きます」「3分で終わります」など
- [ ] アンケート回答へのインセンティブがあるか
  - クーポン付与などが効果的なケース
- [ ] アンケート開始から完了までの離脱率をモニタリングし、必要に応じて改善策を実施しているか
- [ ] 友だち追加導線ごとに適切な追加時フローを出し分けているか

### ③-B メッセージ配信（9項目）

#### 計画
- [ ] 目的や対象セグメント、効果測定指標を明確にしたうえで、配信を計画・実施しているか
  - 目的の曖昧な配信は不必要なブロックにつながる
- [ ] ユーザーの反応率が高い配信日／時間で配信を行っているか
  - 一般: 通勤通学時間や食事のタイミングが高反応
  - アカウント属性によって異なるので検証必須
- [ ] 適切な配信頻度で配信できているか
  - 高頻度過ぎ → ブロック
  - 低頻度過ぎ → 存在感が薄れて開封率低下
- [ ] 安易に全ユーザー配信せず、適切なセグメントに絞った配信をしているか
  - **無関連メッセージはブロックの主要因**

#### リターゲティング・ステップ配信
- [ ] 過去の特定配信における開封・クリックユーザーへのリターゲティング配信を活用できているか
- [ ] 過去の複数配信の少なくとも1つでクリックしたユーザーへのリターゲティング配信を活用できているか
- [ ] 友だち追加日を起点に、数週間に渡る「ステップ配信」を実施しているか
  - 追加直後はアクティブでCVが見込めるタイミング
  - 「友だち追加からX日後」配信を自動設定

#### 表現
- [ ] テキストだけでなく、画像やフレックスメッセージなどのリッチコンテンツを効果的に活用しているか
- [ ] メッセージ配信のテキストは目安として **100文字以内** になっているか

### ③-C メッセージ配信のデザイン（5項目）

- [ ] 配信画像は、情報を端的に伝えられるデザインになっているか
  - スマホで読みやすいレイアウト
  - 目線がスムーズに動く（Z型／F型／上から下）
- [ ] 1つ目の吹き出しのテキストが、メッセージ着信時に通知されることを想定して設定しているか
  - 通知メッセージが開封率に大きく影響
- [ ] 最後の吹き出しのテキストが、トークリスト上に表示されることを想定して設定しているか
  - トークリスト表示も開封率に影響
- [ ] ユーザーのアクションポイント（CTA）を適切に設置しているか
- [ ] 開封率やクリック率を配信ごとに確認し、効果検証や改善策の検討に活用しているか

### ③-D リッチメニュー（6項目）

- [ ] ユーザーに取ってもらいたいアクションを明確化したうえで、構成要素を決定しているか
- [ ] 直感的にわかりやすく、視認性の十分あるデザインになっているか
- [ ] 左上や右下など、タップされやすい領域に重要なコンテンツを配置しているか
- [ ] 重要なセグメントに基づき、リッチメニューをパーソナライズしているか
  - 性別／地域だけでなく「ID連携済/前」「アンケート回答済/前」「新規/既存顧客」など
- [ ] 必要に応じて、タブ機能で複数枚のリッチメニュー切替ができるようにしているか
  - コンテンツ数が多いと視認性・操作性が落ちる
- [ ] 各コンテンツのクリック数を計測し、効果検証や改善策の検討に活用しているか

## ④ 高度な施策（5項目）

- [ ] 自社の顧客データベースとデータ連携し、1stパーティデータを活用した施策を行っているか
  - 顧客ステータスや重要度データの活用には**ID連携**が必要
  - Salesforce／kintone／PORTERS等との連携実績
- [ ] 遷移先ウェブサイトでのユーザー行動データを有効活用できているか
  - 実際にCVしたかのデータをセグメント設計に活かす
- [ ] 1-to-1チャットとボット機能を相互補完し、適切に使い分けられているか
  - 工数はかかるが、個別対応でCV獲得しやすい
  - 自動返信／シナリオと使い分け
- [ ] ECサイトでカート落ちユーザーへのリアルタイムリマインド配信ができているか
  - カートシステム連携で**メールリマインドを大きく上回る開封・購入**につながる
- [ ] 売上額や有料会員転換率など、ビジネスインパクトに関連性の高い指標で成果を測れているか
  - GA連携やID連携で計測精度向上

## So What（戦略家としての示唆）
- 50項目あるが、案件初期診断は **「①全体方針 → ②友だち追加導線 → ③Aウェルカム＋アンケート」** の19項目を優先するのが効率的（ここが最も改善インパクト大）
- 「テキスト100文字以内」「アンケート5問以内」「月1回の改善」は具体的なBenchmarkなので、提案資料にそのまま引用可能
- 「友だち追加直後がアンケート回答率の最大値」は重要な前提。アンケートは絶対に追加直後フローに組み込む
- リッチメニューのパーソナライズ（ID連携済／未／会員ステータス別）まで踏み込んでいる代理店は少ない。差別化提案として使える
- 高度施策の「カート落ちリマインド」は EC案件の即効性高い打ち手として覚えておく
