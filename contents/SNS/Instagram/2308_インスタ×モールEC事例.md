## 1. 立上げ1年で無名ブランドが1モールで月商1,000万超、年商2億

> **広告費10%以下で立ち上げ1年で2億を達成**

### 2022年12月の実績データ
- 投稿予算: 1,000,000円
- 消化率: 84.68%
- CTR: 0.26%
- クリック数: 11,063
- 実績数: 846,854
- CPC実績: 77円
- **売上金額**: 4,294,521円
- 売上件数: 1,122
- CVR: 10.14%
- **ROAS: 507.11%**

## 2. SNS活用で一般KWにブランドKWを出現

> **SNSを活用することで検索SEOへの貢献も可能**

- 一般KW「ダニ取りシート」検索時に**ブランドKW「ダニ取りシート dr.ダニトル」**が候補表示される
- → モール内検索SEO×SNSのシナジー効果

## 3. UGC1投稿で売上200万、指名検索数が増加

### 「まつ毛美容液どれ買えばいい？」のUGC1投稿の効果
- リーチ: 793,311
- IMP: 762,076
- いいね: 3,402
- 保存: 22,706
- **モールECの売上が200万円増加**
- **指名検索クリック数が16倍に増加**（23 → 369）
- **指名検索表示回数も9倍に増加**（464 → 4,150）

## 5. 自社の発信はほぼいらない

### 「商品発信で信頼するのは誰ですか？」アンケート（4,000名）

| 信頼源 | 割合 |
| --- | --- |
| **友達や家族** | **59.8%** |
| 好きなインフルエンサー | **22.7%** |

## 6. 直接CVは1割以下

### 「Instagramで閲覧していいなと思う商品があったらどう行動しますか？」（4,000名）

| 行動 | 割合 |
| --- | --- |

## So What（戦略家としての示唆）

### 即実用Benchmark（数字一覧）

| 指標 | 数字 |
| --- | --- |
| **広告費比率** | 10%以下で年商2億可能 |
| **ROAS** | 507%（モールEC×Instagram） |
| **CVR** | 10.14% |
| **UGC1投稿の売上影響** | +200万円 |
| **指名検索クリック数** | 16倍増 |
| **指名検索表示回数** | 9倍増 |
| **立上げ最短期間** | 2ヶ月で月商200万 |

### 反直感的な発見（戦略家視点）

#### ① 「自社発信より口コミ/インフル」
- 自社公式発信を信頼する人は**14.1%**
- 友達/家族(59.8%) + インフル(22.7%) = **82.5%**が他者発信を信頼
- → **企業はUGC生成に投資すべき、自社投稿は補助**

#### ② 「直接CVではなく検索」が主導線
- Instagram → 直接購入は**5.9%**しかいない
- Instagram → ネット口コミ検索が**50.6%**
- Instagram → 保存(23%) → 後日購入
- → **Instagramは「指名検索ドライバー」として機能**

#### ③ Instagram×モールECのシナジー構造
```
Instagram投稿
   ↓
（指名検索の認知）
   ↓
モール内検索でブランドKWが候補表示
   ↓
モール内CV / 一般KW検索結果でも上位
```

### クライアントワークでの応用

#### モールEC案件への提案テンプレ
1. **直接CV指標で評価しない**（5.9%しかない）
2. **指名検索クリック数/表示回数**を中間KPIに
3. **UGC1投稿の売上影響額**で費用対効果を可視化
4. **ギフティング×自社運用×モール広告**の3点掛け合わせ

#### 商談での殺し文句
- 「**広告費10%以下で年商2億**」
- 「UGC1投稿で**売上200万＋指名検索16倍**」
- 「**ROAS 507%**」
