## 用途（どんな時に活用できるか）
- Instagramを始める前の網羅的チェックとして

## So What（戦略家としての示唆）

### 即実用Benchmark（数字一覧）

| 指標 | 数字 |
| --- | --- |
| **保存率（KPI）** | **2%** |
| **ホーム率（KPI）** | **40〜50%**（目標50%） |
| プロフィールアクセス率（コスメ系） | **1〜3%** |
| フォロワー転換率（コスメ系） | **5〜10%** |
| インタビューN | **3〜5人** |
| アフィリエイト収益（事例） | 100万円/月 |

### 反直感的な発見（戦略家視点）

#### ① 「ハッシュタグ重要」は嘘
- 半年で20万フォロワー達成のアカウントでも**ハッシュタグからの流入はほぼゼロ**
- 「SEOでメタタグが有効でなくなった」のと同様、**本質的なニーズに合わせたコンテンツ**が重要

#### ② 「フォロワー増やすロジック」=「保存率×ホーム率」
- 保存率＝**投稿の質**
- ホーム率＝**アカウントの質**
- → この2軸で改善打ち手が決まる

#### ③ 「N=1ペルソナ」の重要性
- 架空ペルソナ設定だけだと逆効果リスク
- **実際3〜5人インタビュー**してペルソナ設定
- 「綺麗な写真を見たい人」vs「実際に観光地を探す人」でニーズ全く違う

#### ④ 「本格ノウハウより親近ノウハウ」
- ダイエット系：トレーナーの本格トレ法より**1分ストレッチ/ヘルシー食事**が伸びる
- **共感**＞正論

#### ⑤ 「ストーリーズの並び順」アルゴリズム
- ストーリーズは**毎日見るアカウントほど左側**
- 見ないと右側に溜まって発見されにくくなる
- → 毎日「思わず見てしまう」コンテンツが必要

### 7カテゴリの順序の意味
順序自体が**正しい運用順番**を示している：

```
①目的設定（成果から逆算）
   ↓
②Instagramユーザー理解
   ↓
③アカウント設計
   ↓
④アルゴリズム理解
   ↓
⑤実施策
   ↓
⑥PDCA
   ↓
⑦外部活用判断
```

→ ②③が抜けると④以降の打ち手も無効化される
