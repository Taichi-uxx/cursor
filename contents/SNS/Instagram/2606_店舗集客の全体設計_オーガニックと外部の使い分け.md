## 用途
- 店舗系クライアント（飲食店・宿・小売）のインスタ運用設計を提案するとき
- 「うちの店もインスタやった方がいい？」という相談に、構造化された全体像で返したいとき
- ECや採用など「物・人を売る」タイプのアカウント方針を整理するとき

---

## サマリ

店舗集客でインスタを使う際、多くの人がつまづくのは「店舗のアカウントを作って料理写真を上げよう」という発想から入ってしまう点。この前提のままだと、オーガニック（自分のアカウントでインプレッションを取る）でうまくいくケースはほぼ存在しない。

問さんが提示する全体設計は、まず**「内部からインプ（オーガニック＝自分のリール）」と「外部からインプ（広告／インフルエンサータイアップ）」の2軸**で考えること。次に、オーガニックで戦うなら**「機能的訴求（料理・宿の写真）」では伸びず、「人（ダディダディ的キャラ）／エンタメ／知識／企画」のいずれかの要素が必要**になる。料理写真や宿写真は更新頻度の低い「保守運用」コンテンツとして構え、そこに**インフルエンサータイアップやMEO（Google Map最適化）から外部インプを流し込む**のが合理的な型。

オーガニックで店舗集客を完結させようとするのは消耗戦であり、それなら**MEO・食べログ・タイアップへの投資を優先**すべき。それでもオーガニックで戦うなら、店舗の機能訴求とは切り離して「人格」や「企画」「プロセスエコノミー」で勝負する設計が必要、というのが結論。最後の意思決定は店舗・オーナー・スタッフの手札次第で個別最適となるため、フレームに自分の状況を当てて判断することが必須。

---

## 大前提：店舗インスタで多くの人がつまづくポイント

- 「店舗のアカウントだから料理・宿・サービスの写真を上げる」という発想から入ると思考が狭まる
- 「〇〇市にお住まいの方向け」のような狭いセグメント狙いだけでは持続的な成果は出ない
- **料理写真や店舗写真をオーガニックで伸ばしているアカウントは事実上ほぼ存在しない**

> 「オーガニックでうまくいってるアカとか見たことなくねっていう。」

→ まず「店舗アカウント」という枠を外して、**インプレッションをどこから引っ張るか**で設計し直す必要がある。

---

## 全体設計：2軸×4要素のフレーム

### 軸①：インプレッションの取り方

| 種別 | 手段 | 特徴 |
|------|------|------|
| **内部インプ（オーガニック）** | 自分のリール／ショート動画 | 自走できるが伸ばすのが難しい |
| **外部インプ** | 広告（AD）／インフルエンサータイアップ | 費用がかかるが意図したインプを取れる |

### 軸②：オーガニックで戦うときの訴求要素

オーガニックで伸ばすには、**店舗の機能的訴求では足りない**。以下のいずれかの「フック要素」が必要。

| 要素 | 具体例 | 特徴 |
|------|--------|------|
| **人（キャラ）** | ダディダディ、ギフトのバー店主 | ファンが「人に会いに行く」状態を作れる |
| **エンタメ** | スキンヘッドの寿司大将など | キャラ＋見せ方で滞在時間を稼ぐ |
| **知識** | 寿司のマナー解説、店主の専門解説 | 役立ち情報で保存・シェアを取る |
| **企画** | 「笑わなかったら無料」焼肉、長野のワッフル屋 | 単発で跳ねるが持続性に課題 |

> 「料理のお写真とかお店の動画とかでインプレッションが大きく回ってるものって見たことないですよね。」

## ファネル全体図：店舗集客の合理的な型

```
           [外部インプ]                [内部インプ／オーガニック]
              │                            │
   ┌──────────┴──────────┐       ┌────────┴────────┐
   │広告(AD)│インフルエンサー│       │人 / エンタメ / 知識 / 企画│
   └────┬───┴───────┬─────┘       └────────┬────────┘
        │           │                      │
        ▼           ▼                      ▼
   ┌─────────────────────────────────────────────┐
   │ 受け皿：店舗アカウント（料理・宿・サービスの写真／動画）│
   └─────────────────────┬───────────────────────┘
                         ▼
                  ┌──────────────┐
                  │ MEO / Google Map │ ← 検索された時の最終CV受け皿
                  │ / 食べログ        │
                  └──────────────┘
```

- **受け皿（フィード）**：料理・宿・サービスの写真。動画である必要は薄く、**初期セットアップ＋更新時メンテで十分**（毎日更新する必要はない）
- **流入源（外部）**：インフルエンサータイアップ／広告で「外からインプを引っ張ってくる」
- **MEO**：実は「梅田 焼き鳥」等で検索された時の**最も尖った受け皿**。広告・タイアップ・写真メンテと並列で必ず押さえるべき

## なぜオーガニックで「機能的訴求」が伸びないのか

- 焼き鳥メニューを動画で見て覚えている人はいない（情報として価値が薄い）
- 飲食・宿の機能的訴求は**フォローする理由を作れない**
- 有名な店舗アカウントが伸びている例は、ほぼ全て**インフルエンサー投稿バズ起点**

> 「店舗アカウントの集客をするってなった時にダディダディ的要素とお店の機能的要素を分けてそもそも運用しなきゃいけない。こっちをオーガニックでやろうとすると多分うまくいかない。」

---

## オーガニックを選ぶなら：4要素のどれかに振り切る

### 1. 人（人格・キャラ）リード
- 例：ギフトのバー、ダディダディ、犬系の店主
- 「お店に行く」ではなく「**この人に会いに行く**」状態を作る
- 店舗アカウントというより**店長／オーナーの個人アカウント**に近い設計

### 2. エンタメリード
- 例：スキンヘッドの寿司大将（2人組）
- キャラ＋見せ方で**滞在時間とエンゲージメント**を稼ぐ
- お店の機能訴求ではなくショートコンテンツとして成立させる

### 3. 知識リード
- 例：寿司のマナー、業界の裏側解説
- **役立ち情報**で保存・フォローを取り、店舗認知につなげる
- プロとしての知識を持つ業態に向く

### 4. 企画リード
- 例：「笑わなかったら無料」焼肉、神戸の犬系企画、長野のワッフル「青春を止めたい」
- 単発でロケットのように跳ねる（クルーガー曲線）
- **持続可能性が低く、コストもかかる**（毎回新企画を作り続けられない）
- 跳ねた瞬間に**フィード・ストーリーズの受け皿に流す設計**が必須

> 「企画リードでやるやつは持続可能性がないんよな。それだったらそもそもMEOやった方がいいと思う。」

---

## プロセスエコノミーという第5の選択肢

- 長野県ゴ藤のワッフル屋「母の青春を止めたい」型
- ママという「人」に対してストーリーを走らせる
- **物語にファンをつける**アプローチ
- お客さんは「ワッフル」ではなく「ママに会いに駅で降りる」状態に
- フィード／ストーリーでワッフルや日常を上げる導線とセットで機能

---

## 意思決定フロー（提案時の整理）

1. **手札の確認**：店舗・オーナー・スタッフに何があるか？
   - 顔出しできる人格／キャラがあるか？
   - 業界知識を発信できる人がいるか？
   - 企画を継続的に出せる体力があるか？
2. **MEO・食べログ・タイアップは必須投資**として確定
3. **オーガニックをやるなら腹を括る**
   - 人 / エンタメ / 知識 / 企画 / プロセスエコノミーのどれで戦うか
   - 半端な「店舗アカウント」では伸びない前提を共有
4. **受け皿フィードは保守運用**で構える（高頻度更新は不要）

> 「どれがいいとかないと思う。やるしかない全部。で、その中でどれで行くかみたいなのは個別最適。」

## 重要ポイントまとめ

| カテゴリ | ポイント |
|---------|---------|
| **思考の枠** | 「店舗アカウント」という枠を外し、内部インプ／外部インプの2軸で考える |
| **オーガニックの限界** | 機能訴求（料理・宿写真）はオーガニックでは伸びない |
| **オーガニックの正解** | 人 / エンタメ / 知識 / 企画 / プロセスエコノミーのどれかに振り切る |
| **受け皿フィード** | 初期セットアップ＋更新時メンテで十分。日々の頻度は不要 |
| **外部インプ** | 広告とインフルエンサータイアップで流入を作る |
| **MEO** | Google Map検索の受け皿として実質最も尖った経路。必ず押さえる |
| **意思決定** | 店舗の手札次第で個別最適。フレームを当てて判断するしかない |

## 太一としての応用メモ

- **店舗系クライアント提案の標準フレームに採用**：オーガニック×外部の2軸＋4要素マトリクスを、店舗インスタ提案書のテンプレに組み込む。「店舗アカウントを作って料理写真上げましょう」という提案は今後しない
- **MEOを必ずセットメニューに**：インスタ提案だけで完結させず、MEO・食べログとの並列投資をクライアントに提示する。費用対効果が見えづらい広告にお金を入れる前に、まず検索の受け皿を固める
- **自分の発信設計への転用**：旅・グルメをフックにしたコンテンツ設計でも、「機能的な店舗紹介」ではなく**人格・知識・物語**で勝負する。世界一周発信は完全にプロセスエコノミー型として設計すべき
- **企画リードの罠を覚えておく**：「笑わなかったら無料」系の企画は短期的に跳ねても続かない。バズった瞬間に**フィード受け皿への導線設計**が間に合っていないと無意味
- **意思決定の最後は個別最適**であることをクライアントに先に伝える：フレームで全体像を共有した上で、「最終判断はあなたの手札次第」と握っておくと、その後の壁打ちが機能する
