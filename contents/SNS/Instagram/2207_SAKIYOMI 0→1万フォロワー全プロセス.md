## 第1章：SAKIYOMIメソッド — Instagram運用 全4ステップ

### ① コンセプト設計（アカウントの運命を9割左右）

アカウントのコンセプト設計は**アカウントの存在価値そのもの**。最初に行うのは**3C分析**。

| 3C | 意味 |
| --- | --- |
| Customer | 市場・顧客 |
| Company | 自社アカウント |
| Competitor | 競合アカウント |

#### コンセプト設計を誤ると起こる問題
> 「フォロワーが増えたのに売上が上がらない」
> 
> → 表面的にバズる投稿を作っても運用にブレが生じ、コンバージョンに到達できない

#### 正しいコンセプト設計の効果
> ターゲットの深層心理（インサイト）を突いたコンセプトなら、
> フォロワーを無理に増やそうとせずとも**ある地点から2次関数的に急激な伸び**を見せ始める

#### 「バケツの穴を塞ぐ」の意味
- 運用でフォローしたユーザーがアカウントに興味を持ち続け離脱しない状態
- コンセプト設計が不十分だとフォロワーが投稿を見なくなる → アルゴリズム評価↓ → **負のループ**

### ② コンテンツ作成（結局一番差がつく）

#### ロールモデル探しのコツ
- 3C分析の結果が似ている**同じジャンル**のアカウントを探す
- 同ジャンルにない場合 → **異ジャンル×3C分析の結果が似ている**アカウントを参考にする
  - → 自アカウントの存在価値を**抽象度の高い視点**から見られる

#### ロールモデル設定後の流れ
1. コピーから内容まで徹底的に分析
2. 成功理由を言語化
3. 自アカウントのコンセプトに合うようアレンジ・調整
4. コンテンツ案作成
5. 表紙のコピーやデザイン、中身の構成、行動喚起画像などの詳細を詰める

### ③ フォロワー増加施策（ロジックがある）

**大原則：最初から最終目的のCVを取りにいかない**

#### 釣りの比喩
> 釣り針をおもむろに投げても獲れる獲物はよくて1-2匹。
> 多くの人に魚を提供したいなら、船で魚の多いところを探ったり、魚を集めた上で釣り針を垂らす。
> → まずは**フォロワーを増やし母集団を形成**することが大切

#### 「保存率」がフォロワー増加の最重要変数

```
質の良い投稿 → 保存率↑ → 
アルゴリズム評価↑ → 発見欄に掲載 → 
フォロワー外リーチ↑ → フォロワー転換 → 
母集団形成 → さらに質の良い投稿 → ...
```

#### PDCAの回し方
| 段階 | 内容 |
| --- | --- |
| P（Plan） | アカウント分析＆戦略立案 |
| D（Do） | 投稿作成＆配信 |
| C（Check） | 投稿分析 |
| A（Adjust） | 投稿のブラッシュアップ |

#### 見るべき4つの数値と基準値
| # | 数値 | 意味 |
| --- | --- | --- |
| ① | プロフィールアクセス率 | プロフィールのアクセス効率 |
| ② | フォロー率 | フォローの効率 |
| ③ | **保存率** | **投稿の質** |
| ④ | **ホーム率** | **アカウントの質** |

### ④ コンバージョン施策（集客力を売上に）

#### コンバージョンのセオリー
- フォロワーの信頼性を高める施策
- コンバージョンへの導線を引く

#### 最重要ポイント：オリジナルの主観的なクチコミ
> ユーザーは実際に使っていないクチコミを絶対に参考にしません。
> ましてやそんな訴求では購買まで至らない。
> **「主観的なクチコミ」をいかに表現するかによってCVRが変わる**

#### 前提
> 母集団をしっかり形成した上でCV施策を実行していれば、目的達成はさほど難しくない。
> なぜならアカウント自体、最初のコンセプト設計からCV達成を念頭に置いて作られており、
> アカウントのコンセプトに共鳴したユーザーがフォロワーとなって母集団を形成しているから。

## 第2章：戦略設計・コンセプト設計編

### 3C分析：SAKIYOMI公式アカウントのマーケット戦略

#### ❶ Customer（ターゲット理解の徹底）

**ターゲット**: Instagram運用に挑戦したい、あるいはしなければならないと思いつつ、**暗中模索で不安を抱える人たち**

##### なぜこのターゲット？
Instagram運用は**再現性の高い情報（ノウハウ）が少ない**：
- SEOなら詳細な情報・書籍・専門企業が存在
- Instagramは部分的・表面的な情報しか手に入らない
- 具体的な方法・基準数値・頻度などの情報が非常に少ない
- **専門書やバイブルとなるものがない**

##### ターゲットが抱える具体的な疑問
- 何をどれくらいの頻度で実行すればいいのか
- どの数値をチェックして指針とすればいいのか
- アカウントの状態は何で判断すればいいのか
- 打った施策はいつまで続ければいいのか

→ **顧客ニーズ = 具体的で実用的で再現性のある情報（ノウハウ）**

#### ❷ Competitor（差別化ポイントの整理）

**現状**:
- 企業としてノウハウを発信しているアカウントは（ほとんど）ない
- 個人アカウントは「楽して伸ばせます！稼げます！」「毎日頑張ったら人生変わりました！」など個人経験の結果論のみ
- **再現性のある情報を提供しているアカウントは皆無**

→ SAKIYOMIの勝機がここにある

#### ❸ Company（SAKIYOMIの強みの整理）

| # | 強み |
| --- | --- |
| ① | 数百以上のアカウントの運用実績 |
| ② | 累計**400万フォロワー**を超える運用データ |
| ③ | 最新事例の豊富さ（常に100以上のアカウント同時運用） |
| ④ | 再現性の高い運用セオリー |

**もたらされる価値**:
- 「Instagramのアルゴリズムの攻略法」
- 「ユーザーのインサイト（深層心理）」
- 定量（具体的数値）＋定性（抽象的解釈）両側面

### 3C分析の結論

> **【ターゲット】** Instagram運用に挑戦したいと思いつつ、暗中模索で不安を抱える人たち
> **【提供価値】** 具体的・実用的・再現性のあるInstagram運用セオリー（SAKIYOMIメソッド）

### アカウントコンセプト × 投稿コンセプト

| コンセプト | 内容 |
| --- | --- |
| **アカウントコンセプト** | 「インスタ運用のプロ」（あえて「プロ」で個人名アカと差別化） |
| **投稿コンセプト** | 暗中模索のユーザーに再現性のある解を発信する |

> SAKIYOMIが企業支援する際も、**約1ヶ月**を専門チームがコンセプト設計だけに費やす。

## 第3章：投稿作成・デザイン編

### ロールモデル設定 — なぜ「投資系アカウント」を選んだのか

SAKIYOMIには直接参考になるアカウントがなかったため、投資系アカウントをロールモデルに設定。

#### 3つの理由
1. **市場的な3Cが似ている** — 情報が少なく再現性のない情報が多い市場感
2. **無形商材で情報に価値がある** — 表紙のメインが言葉になる
3. **Instagram上ですでに市場ができあがっている** — レッドオーシャンだから洗練されている

#### 実際に分析した投資系アカウント
| # | アカウント |
| --- | --- |
| 1 | @insta_money_school |
| 2 | @yuppi_kabu |
| 3 | @ryofinance |

### タイトル作成 — 「キャッチコピー × ベースコピー」の2要素

| 要素 | 役割 |
| --- | --- |
| **①キャッチコピー** | 心理学（目に止める） |
| **②ベースコピー** | ベネフィット（行動シーンを思わせる） |

#### 例①：バズる投稿には"ワケ"がある
```
＜キャッチコピー＞ バズっている投稿には"ワケ"がある
＜ベースコピー＞ インスタで使える心理学10選
```
- **キャッチ**: 「バズるのは運」の一般論を逆張り → 「？」を作り興味喚起
- **ベース**: 「おすすめの心理学」ではなく「**インスタで使える心理学**」→ 使うシーンをイメージ

#### 例②：本当は教えたくない
```
＜キャッチコピー＞ 本当は教えたくない、、
＜ベースコピー＞ 誰もがフォローしちゃうプロフィールのコツ5選
```
- **キャッチ**: 「**カリギュラ効果**」（禁止されるほどやってみたくなる）
- **ベース**: 「プロフィールのコツ」ではなく「**フォローしちゃうプロフィールのコツ**」→ 動詞で行動をイメージ

#### タイトル作りの2大原則
1. ユーザーの目に止まる言葉（**心理学**）を用いる
2. 行動シーンが思い浮かぶ**ベネフィット**を訴求する

#### 補足：タイトルが思いつかない時の3手法
1. **名詞を動詞にしてキャッチーにする**
2. **セリフで表現してみる**
3. **言い換え辞書で検索してみる**

### 表紙デザインの4要素

| 要素 | ポイント |
| --- | --- |
| **①フォント** | 視認性最優先、コンテンツ内容と合う |
| **②配置** | あえて崩してリズムを生む |
| **③大きさの強弱** | フォントの太さバリエーションで幅を出す |
| **④色合い** | **3色のみ**で統一感＋リズム |

#### ①フォント：SAKIYOMIは**『源ノ角ゴシック体フォント』**を採用
理由:
- 日本語に最適
- 払いや線に癖がなく、太さ均一で可読性◎
- 目にする機会が多く違和感なし

**ジャンル別定番例**: 旅行系 = 「明朝体＋白文字」が王道

#### ②配置：あえて崩す
- 例：「上級者」の部分を真っ直ぐではなくあえて崩す → リズムが生まれ目に止まりやすい

#### ③大きさの強弱
- **ゴシック体**は太さの種類が豊富で強弱がつけやすい
- **文字に影を入れる**ことで立体感→「プロっぽさ」の印象

#### ④色合い：SAKIYOMIは基本**3色のみ**
理由:
- コンテンツの統一感
- 3色の変化でリズム作り

**Tips**: 表紙の色に迷うときは、今使っている色を反転させて使う → 統一感を保ちながら印象を変える

#### 昔と今の表紙の比較 — 初期の失敗要因
- タイトル自体に興味を惹く要素がない
- 文字の視認性が低い
- 文字の配置が平板で目に飛び込んでこない
- タイトルのどこに注目すればいいのかわからない

### 2枚目以降 — 「読み飛ばしやすさ」を意識

#### ユーザーは投稿を**2周読む**
> パッパッと読み飛ばして2-3枚確認 → 「イケてる」と判断すれば少し前に戻ってじっくり読む

#### 2つの必要な工夫
1. **ストレスなく読み飛ばせるデザイン**
2. **詳細に読んだ時にベネフィットがある**

##### ①ストレスなく読み飛ばせる = 固定性
> 人間はシンプルで安定した秩序を持つものに心地よさを感じる

**固定性の工夫例**:
- レイアウト固定：見出しは左上、要約は中央上、詳細は最下部
- 文字の大きさに意味を持たせる：大=見出し、中=ポイント、小=詳細解説

##### ②詳細に読んだ時にベネフィットがある
- 読み飛ばした時と同じ印象しかないと「情報が浅い」と判断される
- **ゆっくり細かく見なければ拾えない情報**を配置

### 保存トリガーを用意する

#### 有形商材の場合
- 「あとで買おう」がトリガー
- 商品が必要になるタイミングやメリットを訴求

#### 無形商材（情報系）の場合
- 「あとで参考にしたい」「見逃したくない」がトリガー
- あとで見返した時にユーザーの期待値を超える何かを仕込む

#### 発見したトリガーの例：「数値の基準値を記した表」
- Instagram運用の重要指標を体系的にまとめた一枚の表
- **「あとで自分のアカウントの数値を照らし合わせてみよう」→ 保存**

#### 他の図解パターン
- 「保存率を上げる施策4選」を「1回にかかる時間×難易度」の**4象限マトリクス**
- 初心者〜上級者までレベル別に施策一覧
- アカウントのフェーズ別「これができていたら○点」の**点数診断**

### コンテンツ作成でこだわる3要素（要約）

1. **表紙**
2. **中身**（読み飛ばしやすさ＋ベネフィット）
3. **保存を生み出すトリガー**

> よく言われる小手先のテクニックよりも、この3点の質を高め続けることが何よりも重要。
> 逆に言えば、この3点にこだわれば誰でもバズる投稿を作り出すことができる。

### 反直感的な発見（戦略家視点）

#### ① 「異ジャンルからロールモデル選定」の3条件
- 同ジャンルにロールモデルがない場合、SAKIYOMIは**投資系**を選んだ
- 3条件：**市場3Cが似ている / 無形商材 / Instagram上で市場成立**
- → 「自ジャンルにお手本がない」は言い訳にならない

#### ② タイトルは「心理学×ベネフィット」の2要素
- キャッチコピー（心理学）で目を止める
- ベースコピー（ベネフィット）で行動をイメージ
- → 「メリット」ではなく「動詞で行動をイメージ」がベネフィットの本質

#### ③ 「ユーザーは投稿を2周読む」
- 1周目：パッパッとスワイプ → 2-3枚で判断
- 2周目：少し戻ってじっくり
- → **1周目対策（固定性）＋2周目対策（細部の価値）**の両方が必要

#### ④ 「保存トリガーは有形/無形で違う」
- 有形：買うタイミング/メリット
- **無形（情報）：数値表・4象限マトリクス・点数診断**
- → 情報系こそ「あとで見返す価値」を明示的に設計

#### ⑤ 「コンセプト設計に1ヶ月」の重要性
- SAKIYOMIが企業支援する際は**約1ヶ月**を専門チームでコンセプト設計に費やす
- ここが不十分だと「フォロワー増えても売上上がらない」問題が発生
- → 急いで運用開始しない

#### ⑥ 「オリジナルの主観的なクチコミ」がCVを左右
- 借り物のクチコミではCVR上がらない
- 「自分たちが使ってみた」を語る必要
- → これが[[2308_Instagram_モールEC事例_StockSun富田竜介]]の「UGC」戦略と共通
