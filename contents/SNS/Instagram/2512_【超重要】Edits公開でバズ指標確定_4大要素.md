## サマリ

Instagram公式編集アプリ **「Edits（エディッツ）」** に、バズっているリールが**なぜ伸びたのか**が全て明示される新機能が搭載され、2026年のバズの答えが事実上確定したことを解説した動画。

Editsの「インスピレーション」画面では、各リールに「高保存率アップ」「高コメント率アップ」「トレンド中の音源」「Editsで作成」といったラベルが表示され、その投稿が伸びた最大要因が一目で分かる仕様になっている。これを大量に観察した結果、Instagramが評価している指標は事実上 **①高保存率 ②高コメント率 ③トレンド中の音源 ④Editsで作成** の4つに集約されていることが判明。

競合投稿のインサイト（いいね数/コメント数/シェア数/保存数、およびそれぞれの率）まで丸見えになるため、バズの再現性を大幅に高められる。本動画では、この4指標が重要な理論的背景（滞在時間最大化による広告収益構造）と、それぞれを引き上げる具体的な施策まで網羅している。

## Editsとは

- Instagram公式の**動画編集 × 分析アプリ**
- Instagramアプリ内でできる分析より深い分析が可能
- **自分のアカウントと紐付け**することで、自分の投稿だけでなく**他人（競合）の投稿の詳細インサイトも全て閲覧可能**
- 導入手順:
  1. アプリストアから「Edits」をダウンロード
  2. アプリを開き、Instagramでログイン（ビジネス用アカウント）
  3. 「インスピレーション」タブで注目されているリールを分析

## Editsで見られるインサイト

投稿を開くと以下が全て表示される:

| 項目 | 内容 |
|------|------|
| **基本数値** | いいね数、コメント数、シェア数、保存数、再生数 |
| **率** | いいね率、シェア率、コメント率、保存率 |
| **バズ要因ラベル** | 「保存率アップ」「コメント率アップ」「トレンド中の音源」「Editsで作成」など |

ラベルを見れば、その動画が**どの指標で評価されて伸びたか**が一目で分かる。

### コレクション機能の活用（分析用の保存）
1. Instagramで分析したい投稿を**保存** → 新規コレクション（例: 「Edits分析」）に登録
2. Editsアプリの左側「コレクション」から該当コレクションを開く
3. 保存した投稿のインサイトを全てEdits上で確認可能

※単なる保存ではEdits側で表示されないため、**必ずコレクションに入れる必要がある**。

## 2026年バズの4大要素（Instagramが評価する指標）

Editsの大量観察から判明した、Instagramが実際に評価している指標は以下の4つのみ。

| 優先度 | 要素 | 性質 |
|:------:|------|------|
| **最重要** | 高保存率 | 主力指標（どの動画にも効く） |
| **重要** | 高コメント率 | 副次指標（動画との相性あり） |
| **補強** | トレンド中の音源 | バフ的ブースト |
| **補強** | Editsで作成 | 公式アプリ優遇 |

## なぜ「保存率」と「コメント率」が最重要なのか

### Instagramのビジネスモデル
- Instagramの収益源は**広告費**
- 広告をたくさん載せるには **ユーザーの滞在時間** と **ユーザー数** が必要
- → Instagramは「ユーザーをアプリ内に長く留めるアカウント・投稿」を優遇する

### 保存率が最強の理由
- いいね = 1回見て「良かった」の合図（1回で完結）
- 保存 = **後から見返す可能性がある** = **2回以上の視聴が発生する可能性大**
- 保存が100つけば、実質200回以上見られる可能性 → 滞在時間が倍増
- Instagramが最も欲しい「時間」を生む指標

### コメント率が次に強い理由
- コメント欄はそれ自体が**滞在時間を伸ばす装置**
- コメントがたくさんついている投稿は、ユーザーが「どんなコメントがついているか」を見に行く
- コメント内の議論・応酬も滞在時間を増やす
- 間接的にだが確実に**滞在時間を伸ばす**

**重要ポイント**: 「保存数」ではなく「**保存率**（=保存数÷再生数）」が評価対象。再生100人に対して何人が保存したか、の比率が大事。

## 【施策①】高保存率を上げる5つの方法

### 1. 数値を細かくしてリアリティを出す
- ふわっとした説明ではなく、**具体的な数値・工程**を入れる
- 例（悪）:「醤油少々、塩少々入れて感覚で」
- 例（良）:「醤油小さじ1、砂糖小さじ1/2、みりん大さじ1を混ぜ、電子レンジ500W・40秒加熱」
- 再現性が高いほど、未来の自分が使えると感じ、保存される
- 工程に**自分だけのひねり**（ワンポイント）を加えるとさらに保存される

### 2. テンプレ化できる投稿を作る
- 「このステップを踏めばできる」構造を徹底
- 保存されやすいジャンル: ダイエット/トレーニング、料理レシピ、ファッション、掃除
- 共通点 = **テンプレ化しやすい**＝再現性が高い
- 例: プロフィール改善なら「この7ステップでプロレベルに」

### 3. 比較系リストで作る
- 「伸びるアカウントの特徴／伸びないアカウントの特徴」のような**左右比較形式**
- 保存率が伸びやすい鉄板フォーマット

### 4. 未来の自分が使う情報に変換する
- 単なる知識の提供ではなく「**使い方**」まで落とし込む
- 抽象論ではなく、再現性のあるHow-to
- 解説で終わらせず「このアクションをしてください」まで提案する

### 5. フォロー誘導を捨てて保存誘導をラストに仕込む
- フォロー誘導と保存誘導を併用すると分散して効果が薄まる
- **保存1点突破**でラストのCTAを設計
- 例:「後で見返せるように保存してね」「明日使えるので今のうちに保存」「1回じゃ覚えきれないので保存推奨」
- 再生数が伸びれば結果的にフォロワーは勝手に増える

## 【施策②】高コメント率を上げる方法

### 前提: 動画によって保存型／コメント型で寄せ方を変える
保存率に強い動画とコメント率に強い動画は性質が異なる。投稿ごとに**どちらを狙うか**を意識して構成する。

### 1. コメントを質問に変換した投稿構成
- 投稿内で結論を全て言い切らず**余白**を残す
- 最後に問いかけを入れる: 「あなたはどっち？」「この中で1つ選ぶなら？」「正直どう思う？」
- 例: 料理投稿で本編は丁寧に解説 → ラストで「わさびオムライス流行ってるけどどう思う？」

### 2. 共感や反論を生むテーマを作る
- コメントが付くのは「**強い共感**」または「**軽い反論**」が発生するとき
- 例: 「インスタは継続じゃなくて○○で決まる」「男の価値は○○で決まる」
- 全員に受けようとしない（8割共感/2割反論、もしくは5:5のトピック）
- **自分の心が動いたこと**を発信することがコア（ロジックではなく感情）

### 3. 体験談を投げかける
- 人は自分語りが好き
- 「あなたの失敗談は？」「同じ体験ある人いる？」「営業でうまくいった話ある？」
- ユーザーが喋りたくなる質問で自然コメントを誘発

### 4. キャプション文でコミュニケーションを取る
- キャプションを読むのは濃い客層（再生100に対して約10人）
- 「この投稿を作った理由」「あなたはどう考えますか？」などで議論を誘発

### 5. コメント特典型の誘導
- 「○○とコメントしたらPDFをDMで送ります」
- コメント＋DMのダブル指標を稼げるが、自然発生コメントより滞在時間増加効果は薄い
- バックエンドの戦略（オファー誘導など）と組み合わせて使う

## 【施策③】トレンド中の音源を使う

### 仕組み
- Instagramがライセンス契約して「使える音源」として搭載している楽曲
- その音源を使ってもらうことでInstagram側もメリットがあるため**優遇される**
- 通常のBGMをトレンド音源に差し替えるだけでバズ確率アップ

### トレンド音源の見つけ方
**方法①: Edits内で見つける**
- インスピレーション画面で「トレンド中の音源」タグの投稿を探す
- 音源ボタンをタップ → そのまま使える

**方法②: Instagramアプリ内で見つける**
- 任意のリールの音源ボタン（右下）をタップ
- 「トレンド中」タブを開く → 現在のトレンド音源一覧が表示
- 「フォロワーに人気」タブもあるが、影響力は「トレンド中」のほうが強い傾向

### 注意点
- **自分の動画と音源の相性（雰囲気）を合わせる**こと
- 「トレンドだから」で適当に使うのではなく、**その音源が合う投稿を作る**視点が重要

---

## 【施策④】Editsで動画を作成する

- Edits = Instagram公式の動画編集アプリ
- Instagramは自社アプリのユーザーを増やしたい → **Editsで作成した動画を優遇**している
- インスピレーションでも「Editsで作成」「トレンド中の音源」のタグ付き投稿が非常に多い
- Edits以外の編集アプリ（CapCut等）を使っている人は、Editsに切り替えるだけで優遇を受けられる

| **高コメント率** | 問いかけの余白 / 共感・反論テーマ / 体験談の投げかけ / キャプション活用 |

**結論**: Editsの公開により、2026年のInstagramバズは「**高保存率×高コメント率×トレンド音源×Edits作成**」の4点に集約された。カンニングペーパーが公開された状態なので、競合の投稿ラベルを観察しながら再現性高く運用していくのが最適解。
