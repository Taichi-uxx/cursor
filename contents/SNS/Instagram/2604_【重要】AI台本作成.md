## 用途
- AIに台本／コピー生成を任せる際に「単発出力に頼らない」フィードバックループ設計のリファレンス
- クライアント案件で「短時間で量と質を両立する台本生成プロセス」を構築するとき
- 自分の発信で「AI使うことの意味」「人間として何を残すか」を再考したいとき

## サマリ

問田氏が **「AIだけで台本を作って投稿したら、共感コメントとDMが大量に来た（運用者本人は1文字も書いていない）」** という実験結果を公開した回。最低な話と言いつつ、再現性のあるプロセスとして詳細に手順を解説している。

ポイントは **「単発でAIに台本を作らせる」のではなく、「AIの中に仮想空間を作り、投稿した場合のシミュレーションを採点ロジック付きで自走させる」** こと。Claude Opus 4.6（Maxプラン）をスマホで音声入力（タイプレス使用）しながら回し、V1=54点 → V7=100点（採点ロジック内）→ 120点目標で再ループ → V13=120点と段階的にブラッシュアップしていく。

しかし最終AIは **「V7の100点は採点ロジック内での100点であって、本当に100万再生する台本かと聞かれたら答えはNo」** と自白する場面もあり、AIに「自己採点の限界」まで吐かせるところに価値がある。

裏テーマは **「人間としてどう生きるのか」**。AI化／自動化で完結する発信が増えるほど、自分でなければならない理由は薄れる。情報発信は厳しくなる一方で、フィジカルに紐づく生き方や面白い生き様をSNSが繋ぐ「古典的な使い方」に立ち戻る瞬間が来ているという視座が提示される。

## 実験の前提と環境

- **モデル**: Claude Opus 4.6（Maxプラン契約。月額3万円相当）
- **代替案**: Proプランでも理論上は使える可能性あり（月3,000円程度）
- **デバイス**: スマホのみで完結
- **音声入力**: スマホ=タイプレス、PC=アクアボイス。デフォルト音声入力ではなくAIが文脈整形してくれるツールを使うのが必須
- **検証外**: ChatGPT・Grok・Geminiでの同様検証はしていない。各モデルの頭の良さに依存する想定

## コア手法: AIに仮想空間を作らせて自走させる

### やっていることの全体像

1. AIに台本を作らせる
2. **AIの中に「仮想空間」を作り、その台本を投稿した想定で再生数／コメント数／DM数／コンバージョンを予測させる**
3. 採点ロジックを **AI自身に作らせる**
4. 100点（理想値: 100万再生＋LINE登録1,000件）を目指して、AI自身がループで台本を書き直す
5. 100点に到達したら「120点を目指せ」と再要求 → ループ継続

### なぜこの設計が効くか
- 「今出ている台本がいい／悪い」の文言レベルの議論に降りない
- 「投稿された場合に何が起きるか」を予測させて自己採点ロジックを構築させる
- → 修正のクオリティを上げるためのフィードバックループをAIに自走させる発想
- テストリール／トライアルリールを台本レベルだけでAI上で再現するイメージ

### 初期質問のラリー（Opus／Sonnetどちらでも回答可能）
- アカウントジャンル（節約家計／投資／副業／お金の基礎知識）
- 達成目的（フォロワー増／保存／LINE誘導）
- 既存テーマの有無
- リール形式（アフレコ／テロップのみ）
- 動画尺（30秒以内 / 30-60秒 / 60-90秒）
- ナレーションの性別（メインターゲットが男性7割なら男性）
- ターゲット年齢層（20代／30代／幅広く） → 狭い方が刺さる
- 4テーマから選択（損失回避型／診断型／結果先出し型／常識破壊型） → 王道は損失回避

### 仮想空間投入の音声入力プロンプト（要約）

> 仮にこの動画をInstagramのリールとして撮影し投稿した場合、大体何再生になってどれぐらいのコメント数とDMが来るのか、LINEのコンバージョンが生まれるのかを、仮説を立ててください。理想は100万再生でLINE登録1,000件＝100点。その状態を100点として、仮想空間の中でリールを何回もテスト投稿し、再生回数とLINEコンバージョンを採点ロジック付きで評価し、100点になるまで台本を作り続けてください。

### AIの自己否定モード（重要）
- V7到達後に「本当に100万再生・LINE1,000件いくか?」と聞くと、Claudeは **「答えはNo」** と正直に返してきた
- 「V7は採点ロジック内の100点であって、本当のバズ台本ではない」と自己否定
- 現実的着地予想: **再生数5万〜15万、保存3,000〜8,000、コメント100〜300、LINE登録50〜150件**

### 再ループで採点ロジック自体を更新
- 今度はAIが採点ロジック側のフィードバックを自分で回す
- フォーマット根本転換 → V8(78点) → V9(89点) → V10(98点) → V11(107点) → V12(114点) → **V13(120点)** で出力

### V13 最終台本の構造例（節約系お金リール）
- **0-3秒（フック）**: スマホ通知画面（引き落とし通知が複数並ぶ）→ 電卓画面アップ「年6万7,000円消えてた」
- **ナレーション**: 「自分の口座調べたら年6万7,000円知らない間に消えてた」
- **設計意図（AI自記述）**: 「ん、これ何?」のテロップ＝発信者の素反応で「教える人」ではなく「発見した人」ポジション
- 全10カット分の映像指示、テロップ、設計意図を出力
- **投稿戦略**: 金曜21時／月末25日前後（給与日近接）／ストーリーズ連動（投稿3時間前・直後・1時間後・翌日アンケート）
- **コンテンツ展開**: 3日後ストーリーズ、1週間後カルーセル投稿、2週間後リール第2弾（コメント欄から題材）
- **注意事項**: 銀行アプリ・金額は必ず実数値／保険について「入るな」とは絶対言わない／「この金額が高すぎないか」という問いかけに留める

## 効果が出た理由（実投稿の事例から）

- 知り合いの運用アカウントに台本を渡し、そのまま撮影投稿 → 共感コメントとDMが大量
- 完全再現できれば理論上は予測どおり伸びる可能性が高い
- ただし演者の演技力（表情・トーン）という人間側変数は残る

## 音声入力ツールの重要性

- AppleデフォルトはNG（「えと」「あと」をそのまま拾う）
- **タイプレス（スマホ／PC両対応）** / **アクアボイス（PCのみ）** がおすすめ
- 喋ったものを一旦AIにプールして文脈整形してから出力
- AI操作時は **タイピングで考えながら書くより、自然言語で口頭で吐き出した方が情報量が増える**

## 裏テーマ: AIで完結するなら人間は何を残すのか

### 太一視点の整理
- 一昔前は「AIが書いた台本なんて」とバカにしていた側が、自分で巻き起こしてしまった事実
- AIに指示しているように見えて **AIに指示されている** 構造
- この動画を見た人が得るもの: ①時短 ②想像の数倍強烈なコメント／DM ③ **「人間として今後どう生きるべきか」に悩める**

### 王道は実は強い説
- 問田・大輔のような熟練者は「変化球の台本」を作りがちで、王道を出されると刺さらないと感じる
- だがAIが王道を組むと普通に伸びる → 「自分たちの感覚が市場とズレている可能性」
- YouTube企画も「ノリで明日撮ろう」のような変化球が好きだが、視聴者は意外と王道で良い

### 電卓と微積の比喩
- 電卓登場時「計算力が落ちる」と言われたが、結果として **数学全体の進化（微積など新分野誕生）** に繋がった（諸説）
- 生成AIによってロジカルシンキングや知識回答が代替されると、その上に人間が乗っかって何が起きるかが本質
- いま想像できない概念が、AI基盤の上に必ず生まれる

### 情報発信の未来観
- ノウハウ／知識を吐き出す系の発信は、今後きつくなる
- 面白い生き方／フィジカルに紐づく体験／キャンプ・筋トレ等の遊び に重心を移すべき
- リアル空間は制限ありだが **SNSがエリアフリーに繋ぐ「古典的な使い方」** に立ち戻る瞬間が来ている
- 「自分はAI時代にどう生きるのか」と向き合った結果、繋がる手段としてのSNS

## 太一としての応用メモ

- **仮想空間ループは自分のコピー／LP制作にも転用可能**: lp-build・copy-buildのスキル設計に「採点ロジック自走 → 自己採点限界の自白までさせる」ステップを足せば、出力の信頼度を一段上げられる。特に「採点ロジック内の100点」と「市場で本当に勝てるか」を分離させる質問は強力。
- **AIに「これは本当に達成できるか?」を後追いで聞く習慣**: 自分の運用案件提案でも、AI出力後に「ロジック内の最適と現実の最適のギャップを言語化して」と問うフローを常設する。
- **音声入力ツール導入**: タイプレス（スマホ）／アクアボイス（PC）を即導入。クライアント企画案・コピー案出しのスピードが断違いになる可能性。
- **自分の発信で「王道」を恐れない**: 世界一周コンテンツの設計で、自分が「変化球じゃないと面白くない」体になっていないか定期チェックする。AI出力を王道のベンチマークとして使う。
- **生き様 × SNSの設計**: 情報発信単体ではなく「ノマド／旅／フィジカル体験」を核に据え、SNSは「同じ価値観の人と繋がる手段」として位置付ける方針を、AI時代の必然として確信できた。contents/CLAUDE.md記載のスタイルと完全一致。
