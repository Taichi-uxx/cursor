## 用途（どんな時に活用できるか）
- インスタのインサイト数値を**正しく読み解く**
- 月次レポートで「どこに改善余地あるか」を診断
- 「リーチ→保存→フォロー」の流れの**ボトルネック特定**
- 数値が悪いときに何を変えるか判断

## インサイト6指標の役割

| 指標 | 定義 |
| --- | --- |
| **リーチ** | 投稿を見た**人数** |
| **インプレッション数** | 投稿が見られた**回数** |
| **ホーム** | ホームボタンを表示したときフィードで投稿を見られた回数 |
| **プロフィール** | プロフィール画面から投稿が見られた回数 |
| **ハッシュタグ** | ハッシュタグ検索から投稿を見られた回数 |
| **発見から** | 検索画面で検索する前に表示されている画面から見られた回数 |

## 数値の解釈ポイント（7ルール）

### ❶ 第一画像で「リーチ数」を伸ばす
> 第一画像を変えることで**リーチ数を伸ばすことは可能**

### ❷ 「インプレッション獲得しているのに伸びない」場合
> インプレッション数を獲得できているのに投稿が伸びない場合は**コンテンツの質に問題**がある

### ❸ 「ホーム」を増やすにはフィード世界観の統一
> ホームからフォローさせるためには、**フィード欄の世界観を統一していることが大切**

### ❹ 「プロフィール」の数字を高める
> ユーザーからのフォロー率を高めるためには『プロフィール』の数字を高めること

### ❺ ハッシュタグは「100万件以上は2つ」
> 初期の段階で100万回以上のタグは2つほどでOK。それよりも**ユーザーが検索しそうなワード**でタグを付けよう
> ※[[2209_ハッシュタグの選定方法_SAKIYOMI]]の「3つまで」と若干異なるが、初期は2つ推奨

### ❻ 発見欄が成長のカギ
> アカウントを成長させるためには、**発見欄に載るようなコンテンツ**を作成することが大切

## So What（戦略家としての示唆）

### 6指標の戦略マップ

| 指標 | 高い時 | 低い時 |
| --- | --- | --- |
| **リーチ** | 第一画像が良い | 第一画像を改善 |
| **インプレッション** | リピート閲覧多い | コンテンツ質を上げる |
| **ホーム** | 既存フォロワーに刺さる | 世界観統一・接触頻度を上げる |
| **プロフィール** | 投稿→プロフ動線良い | 投稿内CTA設置 |
| **ハッシュタグ** | タグ選定上手 | ニッチタグ選定 |
| **発見から** | アルゴリズム評価高い | 保存率向上 |

### 反直感的な発見

#### ① 「インプレッション数が高いのに伸びない」のシグナル
- リーチは取れている＝第一画像はOK
- でもインプレッション/リーチ比が低い＝**コンテンツ本体の問題**
- → 中身の質を見直す（再現性/網羅性/独自性）

#### ② 「ホーム数 vs 発見からの比率」が成長フェーズの指標
- 初期: ホーム比率高い（フォロワー中心）
- 成長期: **発見から比率高い**（フォロワー外拡散）
- → 発見からの比率がアルゴリズム評価のシグナル

#### ③ 「プロフィール経由」の数字に注目
- プロフィール経由でその投稿を見られている＝**フォロワーが意識的に見に来ている**ファン度合いの証拠
- 強いファンが多ければホーム率も上がる
