- **動画URL**: https://www.youtube.com/watch?v=jZJHIMvO3j4

## サマリ

Instagram公式編集アプリ **「Edits（エディッツ）」** の全5機能を徹底解説した動画。

Edits は Instagram (Facebook社) が時間とお金をかけて開発した公式アプリのため、**使用ユーザーはアルゴリズム上で優遇される可能性が高い**。実際にリール上でも「Editsで編集した」ことを示すラベルが表示されるほど強くプッシュされている。またCapCutなどと違い商標利用面でもクリアなメリットがある。

現在搭載されているのは**①アイディア（付箋メモ）②インスピレーション（トレンドリール閲覧）③プロジェクト（動画編集）④カメラ（撮影）⑤インサイト（分析）**の5機能。特に **インサイト機能** が最強で、リールのリテンション曲線（視聴維持率）が秒単位で確認できる点はこれまでInstagramになくTikTokにしかなかった機能であり、これだけでもEditsを使う価値がある。

動画編集機能自体はまだCapCutの劣化版レベルだが、新機能リリース直後は新規参入が優遇されるタイミング。初心者ほど今すぐ導入すべきアプリ。

---

## Editsとは（導入のメリット）

- Instagram（Facebook社）公式の動画編集アプリ
- Instagramアカウントと連携可能
- **Editsで編集した動画は優遇される可能性が高い**（開発への投資額と公式プッシュから）
- CapCut等と違い商標利用面がクリア
- リール上で「Editsで編集」というラベルが表示されるほど公式が推している
- **新機能リリース直後は新規参入者が優遇されるタイミング**

---

## Editsの5つの機能

### ① アイディア（付箋メモ機能）

**基本**
- 開くと黄色い付箋が表示され、メモを書ける
- 色は黄/オレンジ/赤/ピンク/紫など変更可能

**真価**: 保存投稿への付箋添付
- 上部タブから **「保存済み」「コレクション」** に切り替え可能
- Instagramで保存した投稿が一覧表示される
- **保存した投稿に対して付箋でメモを付けられる**
- 「Instagramで保存したが後で見返さない」問題を解決

**使い方のポイント**
- リサーチ結果の解像度を上げるのに有効
- メモをつけることで「何が良かったのか」を後からすぐ振り返れる

---

### ② インスピレーション（トレンドリール閲覧）

**機能**
- 今バズっているリール（国内・海外）を一覧で閲覧可能
- 下部のボタンから **付箋を貼れる**（例: 「猫のドアップがエモい」）
- 付けた付箋は **保存済みのコレクションに自動追加**される → リサーチ資産化

**切替タブ: Following**
- フォローしているアカウントの最新投稿・ライブを確認可能
- 自分の普段見ないジャンルのインスピレーションも得られる

**改善してほしい点**
- キーワード検索ができない
- 同ジャンルだけを絞って表示する機能がない
- リサーチ完結まではできず、Instagramでの保存＋付箋という二度手間が残る

---

### ③ プロジェクト（動画編集機能）

**できること（基本機能）**

| 機能 | 内容 |
|------|------|
| 動画の分割・速度調整 | タイムライン上で操作可能 |
| 倍速 | **最大10倍まで**（CapCutは30〜50倍可能で、ここは劣る） |
| 効果音 | 種類豊富 |
| ステッカー | ストーリーズで使うようなステッカーを挿入可能（強調表現に便利） |
| テキスト | シンプル/手書き風/遊び心あり など種類豊富 |

**アフレコ機能**
- 「音声」ボタンから録音可能
- ボイスエフェクトは使えるが **ノイズ除去ができない**（動画クリップにはノイズ除去があるのにアフレコ側にはない）
- アフレコ中心の編集にはクオリティ面で物足りない

**フォント**
- 種類は豊富だが、**有料フォント・フリーフォントのインポート不可**
- 既存の編集スタイル（独自フォント統一）がある人には不向き

**総評**
- 必要最低限は揃っているが、現状は **CapCutの劣化版** という印象
- 編集初心者や未発信者には十分
- 既に発信中で品質にこだわる人（1万人超えレベル）にはやや物足りない
- 今後のアップデートに期待

---

### ④ カメラ（撮影機能）

**最強ポイント①: 背景変更（グリーンバック不要）**
- 左側のボタンで背景を自動生成できる
- 手だけ映る状態（背景を切り抜く）などが簡単に実現
- オーバーレイ処理やグリーンバックの用意が不要
- トークリールをかなり手軽に作れる

**最強ポイント②: 解像度・フレームレート選択**
- 解像度: **HD / 2K / 4K** 選択可能
- フレームレート: 24 / 30 選択可能
- 色空間: SDR / HDR 対応

**4K撮影の活用テクニック**
- Instagram投稿時は1080pに落ちるが、**アップ編集（拡大・キーフレーム）で解像度が荒れない**
- 横で4K撮影 → 右下のボタンで編集画面へ → 指で回して縦配置 → ズームしても綺麗に映せる
- iPhoneの機能に頼らず4K撮影できる点が優秀

**撮影データの扱い**
- 撮影素材は自動でプロジェクトに追加される
- 途中で編集を中断しても、後から再編集可能

---

### ⑤ インサイト（分析機能）★Editsの最大の強み

#### アカウント全体の状況を確認可能

**動画ごとのエンゲージメント指標**（各指標の定義説明付き）

| 指標 | 定義 |
|------|------|
| **スキップ率** | リール最初の3秒以内にスキップされた割合 |
| **平均再生時間** | リール動画の平均再生時間 |
| **いいね率** | 閲覧数のうちいいねされた割合 |
| **シェア率** | 閲覧数のうちシェアされた割合 |
| **コメント率** | 閲覧数のうちコメントを受け取った割合 |
| **保存率** | 閲覧数のうち保存された割合 |

→ 動画タップだけで全てのエンゲージメントが％表示。分析が一気に簡単化。

#### 閲覧数の構成分析

**閲覧数の内訳**
- フォロワー／非フォロワーの割合

**閲覧数上位のソース**
- フィードタブ / リールタブ / 発見タブ
- どこから見つけられて視聴されたかが一発で分かる

#### リテンション曲線（視聴維持率）

- 動画再生中の各瞬間の合計オーディエンス維持率を曲線で表示
- **これまでInstagramにはなくTikTokにしかなかった機能**
- 例: 3秒→4秒の間で7%落ちていれば「3秒時点に離脱原因がある」と特定可能
- 全体を漠然と修正するのではなく、**ピンポイントに改善**できる
- リール分析の精度が飛躍的に向上

**→ インサイト機能だけでもEditsを使う価値あり**

| 機能 | 評価 | コメント |
|------|:----:|----------|

## 推奨ユーザー

**今すぐ全面導入すべき人**
- これからInstagramを始める人
- リール投稿を始めたばかりの初心者
- リサーチ・分析精度を上げたい中級者

**部分導入が適している人**

**全員に共通: インサイト機能は必ず使うべき**

## まとめ

| カテゴリ | ポイント |
|---------|---------|
| **優遇** | Editsで編集するだけでアルゴリズム優遇の可能性 |
| **最強機能** | インサイト（リテンション曲線・各率指標） |
| **付箋×保存** | リサーチ資産化の仕組みとして秀逸 |
| **カメラ** | 背景自動切り抜き＋4K撮影で実質的にプロ撮影が簡単に |
| **編集機能** | 現状はCapCutの劣化版。今後のアップデート待ち |
| **タイミング** | 新機能リリース直後は新規参入が優遇される絶好のタイミング |

**結論**: 編集機能は発展途上だが、**インサイト機能 + 優遇アルゴリズム**の2点だけで導入する価値がある。特にInstagramを本気で攻略するなら必須アプリ。
