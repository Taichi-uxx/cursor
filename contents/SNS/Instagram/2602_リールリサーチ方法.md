## サマリ

2026年以降もずっと使えるリールのリサーチ方法を、YouTubeライブで実演解説した回。リールが伸びない・ネタが尽きるという問題の根本原因は**リサーチ不足**であり、リサーチさえ攻略すれば本質的に変わらない普遍的なスキルになる。

リサーチに使うのは**①Instagram（85%）②TikTok ③GenSpark（AI）**の3つ。メインはInstagramアプリ上での手動リサーチで、発見タブのキーワード検索 → おすすめアカウント → 類似アカウントの芋づる式展開で「今伸びているリール」を30本程度ストックする。重要なのは**2年前に1000万再生のリールより、今月上げて20万再生のリール**を参考にすべきという「鮮度」の基準。保存したリールはPCでダウンロード → AIで文字起こし → フック文章と本文を分離してAIに学習させ、台本作成に活用するところまでがワークフロー。

## リサーチに使う3つのツール

| ツール | 役割 | 比重 |
|--------|------|:----:|
| **Instagram** | メインのリサーチ。発見タブ→キーワード検索→おすすめアカウント展開 | 85% |
| **TikTok** | トレンド音源・ダンス・流行りの把握。暇な時にざっくり見る程度 | 少 |
| **GenSpark（ジェンスパーク）** | AIで競合アカウントの候補を効率的にリストアップ | 補助 |

## GenSpark（AI）でのリサーチ方法

- GenSparkは無料プランあり
- 「AIチャット」機能を使い、複数AIの結果をまとめて表示してくれる（ChatGPT/Gemini/Claude等の横断検索）

### 使い方
- 「○○について発信しているインスタアカウントで、2026年に伸びているアカウントを調べて」と入力
- アカウント数が多いジャンル（レシピ/ダイエット/飲食店等）で特に有効
- 自分で探す作業とAIに調べさせる作業を同時並行で進めると効率的

### 注意点
- AIはInstagramにログインできないため、フォロワー数や再生数の精度は低い
- あくまで候補リストの参考程度

## TikTokでのリサーチ方法

- 目的: **今どんな音源・ダンス・動画スタイルが流行っているか**のざっくり把握
- 詳しくは見なくてよい。暇な時間にサッと見て「こういうの流行ってるな」を掴む程度
- TikTokで採用がうまくいっている業種（現場作業系、キャバクラ、ホスト等）のリサーチにも有効

## Instagramでのリサーチ方法（メイン）

### Step 1: 発見タブでキーワード検索

1. 下部の虫メガネマーク（発見タブ）をタップ
2. 自分の発信ジャンルに関連するキーワードを入力（例: 「占い」「ダイエット」「節約レシピ」等）
3. おすすめアカウントとおすすめ投稿が表示される
4. **今はInstagramがおすすめを出してくれるため、リサーチしやすくなっている**

### Step 2: リールの「鮮度」を重視して選別

**最重要ルール**: 2年前に1000万再生のリールより、**今月上げて20万再生のリール**の方が参考になる

- 参考にすべきリールの条件: **直近3ヶ月以内**に投稿されたもの
- 投稿日の確認方法: リールを開く → 「…」をタップ → 投稿日が表示される

### Step 3: アカウントの評価基準

| チェック項目 | 判断基準 |
|------------|---------|
| **アカウント開設日** | プロフィール右上「…」→「このアカウントについて」で確認 |
| **投稿数とフォロワーの比率** | 投稿数少×フォロワー多 = 最近急成長 → 参考になる |
| **平均再生数の算出** | 直近10投稿の再生数を足して÷10 → **平均の2〜3倍**あるリールが「バズリール」 |

### Step 4: 参考リールの保存

1. リールの「…」→「保存」をタップ
2. **コレクション（フォルダ）を作成**: 「2026年4月_占い」のようにジャンル×月で管理
3. 後から見返しやすいようにフォルダ分けを徹底

### Step 5: 類似アカウントの芋づる式展開

1. 参考になったアカウントのプロフィールを開く
2. **プロフィールの「＋人間マーク」をタップ** → 類似アカウントのおすすめ一覧が表示
3. そこからまた同様にリサーチ → さらに類似アカウント → と芋づる式に展開
4. **ジャンルがズレ始めたら即戻る**（占い→スピリチュアル→波動… とズレ出したら「占い」に集中し直す）
5. 普段占い系じゃない人がたまたま検索結果に出ているケースもあるので、そういうアカウントはスキップ
6. 有名すぎる人（例: ゲッターズ飯田）は「リールが良いから伸びた」のか「知名度で伸びた」のか判別不能なので参考にしない

### Step 6: 30本ストックを目標に

- 上記を繰り返し、**30本程度のリール**を保存フォルダにストック
- 同じジャンル内でもスタイルの分類が見えてくる
  - 例（占いジャンル）: タロットカード映像系 ／ カメラ目線トーク系 ／ 手相系 ／ 文字のみ系
- 自分がどのスタイルで行くかをリサーチ結果から決める

## リサーチ後のワークフロー（PC作業）

### 1. 保存リールをGoogleスプレッドシートに転記

- PCのInstagramから「保存済み」を開く
- 各リールの「…」→「リンクをコピー」
- スプレッドシートにリンク・再生数・特徴などを記録

### 2. リール動画をPCにダウンロード

- **Chrome拡張機能「Instagram Reels Video」** を使用
  - Chrome Web Storeで「Instagram Reels Video」を検索 → Chromeに追加
  - ワンクリックでリール動画をPCにダウンロード可能

### 3. AIで文字起こし

- **Notta（ノッタ）**: 文字起こし専用AI（無料プランあり）
  - 動画をアップロード → 言語を「日本語」に設定 → 文字起こし自動生成
- **Gemini**でも文字起こし可能（無料。途中で切れた場合は「続きも文字起こしして」と指示すれば対応してくれる）
- ChatGPTにアップロードして文字起こしする方法も可

### 4. フック文章と本文を分離してAIに学習させる

| 分類 | 内容 | 目的 |
|------|------|------|
| **フック文章** | リール冒頭の1〜2行目だけを抽出 | 冒頭特化のAIボットを作る |
| **本文** | 全体の文字起こし | 台本全体の参考資料 |

- リールにおいて**冒頭の1〜2行が最も重要**
- フック文章だけを100パターン集めて専用AIに学習させると、冒頭アイデア出し精度が飛躍的に上がる
- 長文を全部まとめて学習させると精度が下がるため、分離する

## リールの撮影・編集Tips

### カメラ目線・台本読みのコツ
1. 台本を書いておく
2. 1行だけ覚えてカメラを見て喋る
3. 2秒間カメラ目線のまま停止
4. 台本を見て次の1行を覚える → 繰り返し
5. 撮影後に台本を見ている部分をカット → 自然に仕上がる

### 編集の時短: Brew（ブリュー）
- 無音部分を自動カットしてくれるAI編集アプリ
- 「0.3秒以上の無音区間を0秒にカットして」のような指示が可能
- 手動で1つずつカットする作業が一括で完了

## リサーチの本質・マインドセット

- **リールが伸びない時は、もう一度リサーチに戻る**。これが全ての答え
- リサーチは毎回PCでスプレッドシートに転記する必要はない。保存は毎日行い、時間がある時にPCで整理
- 一度作ったAIの学習データは蓄積されていくため、毎回ゼロからやる必要はなくなる
- リサーチして成功確率を上げてから1本出す方が、何もせず10本出すより効果的
- 成功体験が積み重なれば継続でき、継続できれば加速度が上がる

---

## 発信ジャンルの注意点

- 1アカウントにつき発信テーマは**必ず1つに絞る**
- 複数テーマ（例: 離婚×自己理解×夫婦関係）を1アカウントにまとめると「何のアカウントか分からない」と判断され離脱される
- ユーザーは1〜2秒でそのアカウントが何かを判断する
- 3つテーマがある場合は1つに絞る or 別アカウントに分ける
