## Case 01: 美容系「こまちメイク」— 権威性で差別化し王道のメディアに

### 数字
- 運用7ヶ月で1万フォロワー / 運用21ヶ月で**9万フォロワー**（420→92,530）
- フォロワー転換率約**7%**
- 月間約1000万リーチ・月間1万フォロワー増加
- バズ投稿例: 「自まつげ派伸びすぎ注意」235万リーチ・保存53,852・フォロー944

### 課題
美容ジャンルで先行者利益を取り、ナレッジを蓄積したい。

### プロセス
**専門家（湘南美容クリニック先生）に監修で入ってもらい、信頼性のあるメディアを構築**。インスタライブを毎週開催しエンゲージメント向上。

### 3C分析〜コンセプト
- 王道路線の美容アカウントが増えてきたが伸び代あり
- 美容ジャンルは競合性強まる可能性
- **ニッチセグメンテーションよりも、王道筋を狙いながら一定の母数を拾う**
- 独自性のある表現で勝負が必要
- **「美容外科医監修」**＝信頼性／透明性を出す

## Case 02: 美容系「港〇女子の遊戯」— PR用メディア新規構築

### 数字
- 運用6ヶ月で5,000フォロワー / 13ヶ月で1万フォロワー（673→10,569）

### 課題
インスタでメディアを構築したいが、競合が多く勝ち筋が見えない。

### プロセス
**絶対的な差別化ポイントをトリガーにファン化を醸成**。
ターゲット分析にインタビュー実施、**約1ヶ月かけてコンセプト策定**。「エッジの効いたキャラクター設定」がドライバーに。

### 3C分析〜コンセプト
- セグメンテーション差別化も飽和 → **キャラクターの独自性**を意識
- ターゲット: 美意識の高い**25歳以上の女性**
- 「**港区女子**」というイメージに偏見はあるが、自分磨きを徹底している点は権威性に
- アカウント名「**港〇女子の遊戯**」、化粧室で互いの戦果を話し合っているイメージ

## Case 03: 歯の情報メディア「デンタルタイムズ」— 先行者優位ポジション獲得

### 数字
- 運用7ヶ月で1万フォロワー / 15ヶ月で**5万フォロワー**（4,844→50,202）
- バズ投稿例: 「口臭が臭くなる行動」61.5万リーチ・保存3,685
- インスタからYouTubeへの誘導でYouTubeも収益化

### 課題
"歯に関する情報メディア"という特化型でInstagramでの先行者利益確立。マーケット未成熟による投資リスク懸念。

### プロセス
- マーケット未成熟 → 初期はフィード投稿のみでは難しい
- **フィード投稿＋TikTok動画を活用したリール投稿**に注力
- **新規フォロワー向け長文系ストーリーズ投稿**がエンゲージメント向上のトリガー

### 3C分析〜コンセプト
- コロナ禍のマスクブームで**口臭ケアのニーズが急速に高まり**
- 「歯の美容/健康/知識」を手軽にキャッチアップ
- 「**実際にやってみた**」系の投稿でリアルな情報
- 歯科医インスタライブで信頼性担保

## Case 04: 住宅系メディア「make_happy_home」— 1年で5万フォロワーの巨大メディア

### 数字
- 運用7ヶ月で1万フォロワー / 15ヶ月で**5万フォロワー**（378→51,649）
- 月920万リーチ
- 不動産（高額報酬ジャンル）で**月10件以上CV**を安定獲得
- バズ投稿: 「絶対忘れちゃいけない入居前準備」130万リーチ・保存25,181

### 課題
アフィリエイト収益化したいが企画〜運用のリソースがない。

### プロセス
**「住宅」「不動産」は直接的な切り口ではInstagramにフィットしづらい → 派生テーマ「暮らしの節約術」「インテリア紹介」**という生活情報ニーズに着目。
ホーム率を高める**ストーリーズ施策**でフォロワーの親密度UP。

### 3C分析〜コンセプト
- 競合アカウントがほとんどなく参入余地あり
- 家作りで絶対押さえるべきポイントを掴みたい
- リアルな体験談・失敗談を知りたい
- **「後悔しない家づくり」**をテーマに、知らないと損するホーム系Tipsを発信

## Case 05: 旅行系メディア「旅Ness（tabiness）」— 観光事業のハブとなる巨大メディア

### 数字
- 運用3ヶ月で1万 / 12ヶ月で5万 / **19ヶ月で10万**（8,427→147,076）
- 月間400万人閲覧
- 月1000万リーチ
- バズ投稿: 「USJだけじゃない大阪旅行」283万リーチ・保存70,608

### 課題
観光事業のハブメディアを構築し、タイアップで収益化したい。

### プロセス
- **表紙クリエイティブのPDCAを継続的に回す**
- 「**表紙クリエイティブの型化**」に成功 → 保存率UP → 月1000万リーチ
- ハッシュタグ**「#tabiness」**でUGC発生

### 3C分析〜コンセプト
- 旅行系は「特定スポット詳細解説」と「インスタ映え写真のみ」で二極化
- Google検索は情報量が多すぎる
- 楽しい時間（**ハピネス**）＋旅で「**旅ネス**」というアカウント名

## Case 06: 旅行系（カーリース事業）「どこいこ！？」— 驚異的スピードで10万フォロワー獲得

### 数字
- 運用5ヶ月で1万 / **16ヶ月で10万フォロワー**（240→100,067）
- 月1万人増という驚異的スピード
- ストーリーアンケートで**62%が「サービスに興味ある」**と回答
- バズ投稿: 「デートで行きたい体験型スポット7選」210万リーチ・保存81,902

### 課題
広告依存から脱却するメディア構築、リード獲得。

### プロセス
**「カーリース」と「Instagramユーザーの興味」の接点を探りながらインサイト分析徹底**。投稿コンセプトがフィットしているかを**「保存率」**で評価。

### 3C分析〜コンセプト
- 自分は車を持っていないがドライブ/遠出したい
- 「休日に何をしていいかわからない」が選択肢に旅行・お出かけ
- ターゲット: **20代の若いカップル**
- 「**お得なオトナ旅**」をキャッチーに落とし込み、「どこいこ」というアカウント名

## Case 07: 店舗系メディア「たまプラーザ テラス」— 地域密着型のモールでリピート率UP

### 数字
- 毎月約**800フォロワー増加** / バズ投稿で月**2,700フォロワー増加**（2,052→11,578）
- **ホーム率約60%**まで転換
- リーチ数約10倍増加
- バズ投稿: 「UNIQLO新作これは買い！」38.1万リーチ・保存2,666

### 課題
セール・イベント情報を適切なユーザーに届けられていない。

### プロセス
**現地に足を運びインタビュー実施**してターゲットの解像度を高めた上で方向性変更。ストーリーズに反応してくれた方には**DMでメッセージ**を送りファン化。

### 3C分析〜コンセプト
- 競合はHPと同じ情報発信しかしていない
- 「主婦ターゲット＝節約」のバイアス
- ショッピングモールのあるエリアは**世帯所得高い閑静な住宅街**
- **「安い」「節約」は生活の豊かにするヒントではない。「質」を重視**
- コンセプト: 主婦向けだが節約情報には触れず、「シンプル」「品がある」

## Case 08: ダイエット系「スリムケア」— 2ヶ月で1万人のフォロワー増

### 数字
- 運用5ヶ月で1万 / 11ヶ月で5万（4,089→55,179）
- **2ヶ月で1万フォロワー増加**のペース
- バズ投稿: 「骨盤矯正5選」175万リーチ・保存40,123

### 課題
ダイエット食品の商品PR、継続的な広告予算捻出が難しい。**広告戦略ではなく資産性の高いコンテンツマーケティング**を実施したい。

### プロセス
**運用初期からリールを週5回投稿**。「ビフォーアフター系」「NGな行動・食事」を中心に。初期から1万リーチ超え。
**DM経由というライトなアクション**で熱量の高いユーザー獲得。

### 3C分析〜コンセプト
- コロナ禍「おうちダイエット」「ボディーメイク」がトレンド
- 痩せたいが辛い思いはしたくない
- **ながらストレッチ**でハードルを下げる
- **ビフォーアフター投稿で疑似体験**

## Case 09: 大学法人「がんばれ受験生！」— 大学アカウントでNo.1の影響力

### 数字
- 運用10ヶ月で5,000フォロワー / 13ヶ月で1万（589→11,350）
- バズ投稿: 「ノートに使っている記号」48.7万リーチ・保存12,912・フォロー1,320

### 課題
紙媒体広告→デジタルシフト。受験志願者の資料請求数を増やしたい。

### プロセス
**「がんばれ受験生」のテキスト画像アイコンとアカウント名**でフォロワー転換率を向上。
受験生の不安や悩みに**DMで相談窓口**を設け、共感コンテンツでエンゲージメントUP。

### 3C分析〜コンセプト
- 競合は受験生＜在校生寄りコンテンツが多い
- 本当は勉強しないといけないが勉強したくない
- **「あなたはがんばっているよ」と肯定し、応援するメディア**
- フォローしているだけで頑張れる**「感」**

## Case 10: アウトドア系「NOASOBI」— ニーズの強いキャンプ事業を牽引

### 数字
- 運用4ヶ月で5,000 / 13ヶ月で1万 / 15ヶ月で2万（1,215→22,310）
- 月間100万リーチ
- バズ投稿: 「キャンプが10倍楽になる必殺裏技」42万リーチ・保存3,860・フォロー2,669

### 課題
キャンプグッズ事業の集客で広告依存常態化。脱却したい。

### プロセス
運用初期は**ホーム率**を意識、保存率高い投稿をストーリーズに横展開。
低迷期は月10万リーチだったが**ストーリーズ施策手厚く**してホーム率改善 → **月100万リーチ超え**。

### 3C分析〜コンセプト
- キャンプトレンドが盛り上がりニーズ高いがコンテンツ供給不足
- 興味あるが行動ハードル高い
- **「キャンプそのものに行かなくても、非日常を味わえる」**キャンプ飯/遊びを発信
- アカウント名「**NOASOBI**」"こどもごころ"くすぐる

## Case 11: 節約系「ためるん」— Instagram×公式LINEで150件/月の送客

### 数字
- 運用6ヶ月で1万 / 13ヶ月で**8.5万フォロワー**（210→84,689）
- 月1000万リーチ
- **公式LINEに150件/月の安定送客**
- ストーリーアンケート1万回答→**1ヶ月で2万回答**（倍増）

### 課題
飛び込み営業をしていたがコロナ禍で対面営業ができなくなった。

### プロセス
**「インスタを見て真似したこと」という表紙はバズ投稿**となりアカウント成長のドライバー。
**Instagram→公式LINEへ送客で精度の高いCV獲得**。

### 3C分析〜コンセプト
- 自社ベネフィットは年間電気代が数千円安くなる
- 固定費削減への興味関心高いのは**家計を支える主婦層**
- 今の収入と将来かかる資金（養育費/老後）を考えると不安
- **家計管理・収入増加・資産運用・固定費削減**「お金」直結コンテンツ
- 簡単に真似できる**「How to 投稿」**中心

## Case 12: ダイエット系「みんなのパーソナルトレーナー」— 月100万円の収益を生むメディア

### 数字
- 運用9ヶ月で**10万フォロワー** / 14ヶ月で**15万フォロワー**（535→157,928）
- **月間1800万リーチ**
- **アフィリエイトで月100万円の副収益**安定獲得
- 月2.3万人のフォロワー増加

### 課題
YouTubeの集客に注力していたが時間対効果が悪い。

### プロセス
**「ビフォー/アフター」系投稿中心**で保存率/エンゲージメント率を意識。
リール投稿で**'ルーレット方式'のコンテンツが爆発的延び** → 月1800万リーチ。
**定期的なインスタライブ**でファン化、アフィリエイト商材を直接アピール。

### 3C分析〜コンセプト
- 「パーソナルトレーナーを探している」顕在層はパイ少ない
- 痩せたいが意志が弱くて継続できなさそう
- 彼氏が欲しいから痩せたいが無理はしたくない、ご飯は食べたい
- **日常生活から簡単に取り入れられるトレーニング/ダイエットレシピ**
- **「これなら続けられそう」**と感じる、モチベーションアップ

## So What（戦略家としての示唆）

### 即実用Benchmark（数字一覧）

| フォロワー10万到達まで | 9〜19ヶ月 |
| 優秀なフォロワー転換率 | 約**7%** |

| 公式LINE送客 | 150件/月（節約系） |
| アフィリエイト収益 | 100万円/月（ダイエット系） |
| 商品CV | 月10件以上（住宅系） |

### 共通する勝ちパターン
1. **ターゲットの解像度UP**（現地インタビュー / インサイト1ヶ月かけて策定）
2. **「直接ニーズ」より「派生ニーズ」を切り口に**（住宅→暮らし術／カーリース→おトクなオトナ旅）
3. **権威性／監修で差別化**（医師監修／パーソナルトレーナー）
4. **ビフォーアフター・How to系・◯選**が伸びやすい
5. **表紙クリエイティブの型化**（旅Ness）
6. **ストーリーズ施策でホーム率を上げる**（60%まで）
7. **公式LINE/DMで精度の高いCV**

### SAKIYOMI流の設計フレーム（全ケース共通）
```
3C分析 → インサイト → ジャンル・ニーズ → コンセプト
```
これを必ず通すと、競合の中で「**勝ち筋**」が見える。

### 反直感的な発見
- **住宅・不動産はInstagramに直接フィットしない** → 派生テーマで攻める
- **「節約」「安い」は逆効果**（モール案件・所得高いエリア）→ 「品がある」が刺さる
- **DM／公式LINEへのライトアクション**が高熱量CVを生む（フォロワー→売上の最短距離）
- **「がんばってる感」「これなら続けられそう」**＝モチベーション提供型コンセプトが伸びる
- **派生テーマ**（住宅→暮らし術／カーリース→旅）は競合のいない場所で先行者優位
