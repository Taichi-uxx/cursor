# フェーズごとのInstagram運用の攻め方 — 1000人 / 1万人で戦略が変わる

## 出典
- 元ナレッジ: 知見・ナレッジ移管/Instagram運用/フェーズごとのInstagram運用の攻め方.boxnote
- 動画解説: https://www.youtube.com/watch?v=17GVIR7DuI4
- 入手: 2023年9月

## 用途（どんな時に活用できるか）
- フォロワー数別の運用戦略を組むとき
- クライアントの現状フォロワー数から「次にやること」を即提案するとき
- 「1万人いかないとストーリーリンク貼れない」の制約をクライアントに説明するとき

## 3つのフェーズ

| フェーズ | 主戦場 | 主要KPI |
| --- | --- | --- |
| **〜1000人** | ハッシュタグ・リール・ストーリーズエンゲージ | フォロワー絶対数 |
| **1000〜10000人** | 発見タブ（CTR最重視） | CTR |
| **10000人〜** | ストーリーズURL → LP → CV | CV |

## フェーズ1：フォロワー〜1000人

### 前提
- **発見タブに載るには「エンゲージメント率」だけでなく「エンゲージメント総量」が必要**
- 約1000人未満では総量が溜まらない → **初期はハッシュタグハック**が必要
- 現在は**リール活用**も有効施策

### ハッシュタグ
- ボリュームの大小**バランスよく配置**

### ストーリーズ
- **ストーリーズ閲覧率が重要**
- 双方向コミュニケーションが評価される
- 一方通行はNG
- **アンケート**などで双方向コミュニケーション誘発
- コメント/いいねを誘発する仕掛けも有効

### その他：テーマずらし
- 初期フォロワー確保で、本業からずらしてInstagramで伸びやすいトピックを投稿
- 例：**新宿の不動産賃貸会社 → 新宿のカフェ投稿**で初動フォロワー確保

## フェーズ2：フォロワー1000人〜（発見タブに載るようになったら）

- **発見タブで目立つこと**が主戦場
- 指標で言うと**CTRをいかに上げるか**

## フェーズ3：フォロワー1万人〜

### 解放機能：ストーリーズURLリンク
- フォロワー1万人を超えると**ストーリーズにURLを貼り付け可能**
- → ストーリーズ → LP / 記事LP → CV
- **記事LP vs 通常LP**は検証推奨

### 1万人未満の代替策
- ストーリーズから他URLへ飛ばせない
- ECサイト：**ショップタグ**
- 投稿の1番最後で**プロフィールに誘導**する文言追加 → プロフィールURL → LP

## So What（戦略家としての示唆）

### 即実用Benchmark
- **1000人**：エンゲージメント総量の壁
- **1万人**：ストーリーズURL解放の壁
- ストーリーズ閲覧率＝双方向コミュニケーション量

### 反直感的な発見
- **本業からテーマをずらして初期フォロワーを稼ぐ**戦略（新宿不動産→新宿カフェ）→ コンセプト1個ルール（[[2309_Instagramアカウントの伸ばし方]]）と矛盾するが、**初動だけの特例**
- **一方通行のストーリーは媒体評価が下がる** → 「投稿しただけ」は逆効果
- 1万人前後で**運用戦略が全く別物**になる（ロードマップ設計の起点）

### クライアントワークでの応用
- フォロワー数を聞くだけで「今何やるべきか」を1分で答えられる
- 1万人前後のクライアントには**LP/記事LPのABテスト**を即提案できる
- 1万人未満のECには**ショップタグ**を必ず提案
